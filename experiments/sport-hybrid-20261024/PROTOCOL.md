# 종목별 하이브리드 비교 규칙

운영 변경 없는 로컬 탐색. 2023 학습 / 2024 가중치 선택 / 2025 최종 평가.
다음 fold는 2024까지 학습 / 2025 선택 / 2026 부분 연도 평가.
과거에도 연구한 데이터이므로 완전히 새로운 독립 holdout이라는 주장은 금지한다.

축구 승무패 3분류, 야구·농구·배구 승패 2분류만 비교한다.
핸디캡·총점과 적중률을 섞지 않는다. 충돌 재발매 가격은 제외한다.
시장(Shin), 시장 절편 보정, Elo, 기존 종목별 피처 logistic,
시장 offset+기존 피처, 시장+기존 모델 convex blend를 비교한다.
blend 시장 비중은 0/25/50/75/100%를 validation Brier로 선택하고
전체 후보 중 validation Brier 최소 모델도 별도 고정 평가한다.
동률은 단순한 시장 모델을 우선한다. 테스트 결과로 재선택하지 않는다.

보고: 적중률, class-summed Brier, log loss, 리그·확률구간별 오차,
7개 관측일 block bootstrap paired Brier CI, 고정 단위 베팅의 회고적 ROI.
2폴 모의는 주 최대 2/3회, 1만원, 월 손실 5만원 위험 예약을 유지한다.
시장별 결과를 고르는 것이 아닌 전체 후보군 사전 고정 선택의 성능으로 판정한다.
아카이브 배당 관측 시각과 실제 구매 가능성이 불명하므로 실제 수익 검증 또는
운영 자동 승격에 사용하지 않는다. 관측 상관을 오류의 인과 원인으로 단정하지 않는다.
