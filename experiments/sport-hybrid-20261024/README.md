# 종목별 하이브리드 모델 비교 — 2026-10-24

## 결론

시장 확률에 기존 팀 단위 예측을 추가해도 개선 폭은 작았다.
가중치를 validation 구간에서 정한 선택 절차의 평가 적중률은
농구 68.20%→68.69%, 야구 56.53%→56.72%, 축구 52.17%→52.17%,
배구 67.63%→67.74%였다. 비시장 단독 모델은 대체로 시장보다 못했다.
시장 대비 Brier 개선의 7개 관측일 블록 95% 구간은 선택 모델 모두 0을 포함한다.
운영 변경이나 자동 승격 근거로 사용하지 않는다.

이 적중률은 **모든 평가 경기의 가장 높은 확률 선택지** 기준이다.
웹에 표시되는 추천 조건 통과 경기, 최근 10건, 실제 사용자 구매 내역과 다르다.
축구는 승무패 3분류이고 나머지는 승패 2분류다. 종목 간 원시 적중률이나
class-summed Brier를 그대로 비교해 모델의 우열을 판단하지 않는다.

## 자료와 비교 설계

기존 로컬 `accuracy-formula-lab/data/processed/games.csv`를 읽기 전용으로 사용.
SHA256: `dfe95c2ace14ee42142ea0c86912b68359bc8ebee9ad3cb566812815bdec0eb0`.
원본 184,473행, 모든 시장 대상 재발매 충돌 584개 제외.
주요 승패/승무패 시장과 인과 피처를 결합한 경기 45,184개, 점수·결과 충돌 0개.
핸디캡·언더오버는 이번 비교에 포함하지 않았다.

실행 전에 PROTOCOL.md를 커밋 `85b136ce`로 고정했다.
2023 학습→2024 모델/가중치 선택→2025 평가,
2024까지 학습→2025 선택→2026 부분 연도 평가를 반복했다.
모델 종류와 혼합 가중치는 선택 기간에서만 고른 뒤 평가 기간을 열었다.
확정된 모델의 계수는 평가 전까지의 자료로 재학습했다.
팀 피처는 같은 날짜 경기 결과를 그 날짜 전체 예측이 끝난 뒤 반영한다.

비교 모델은 Shin 시장, 시장 절편 보정, Elo logistic, 기존 종목별 피처 logistic,
시장 log-probability offset+기존 피처, 시장/기존 피처 확률 혼합의 여섯 가지다.
혼합 시장 비중 후보는 100/75/50/25/0%. 선택 기준은 Brier 최소이며 동률은
시장에 더 가까운 모델을 우선한다. 기존 피처는 Elo 및 pi-rating에 종목별
최근 득실 마진·폼·백투백을 포함한다. 모델 함수·정규화·학습법을 통일한
재학습 비교이지 과거 운영 모델의 모든 산출물을 그대로 재현한 것은 아니다.
모든 가능한 알고리즘을 탐색한 전역 최적값이 아니다.

  시장 잔차 모델 68.82%, 혼합 68.20%.

  2026 평가에는 시장 잔차 모델을 선택했다.

  다중 비교 보정 전 탐색 결과이며, Brier 개선이나 양수 수익을 입증하지 않는다.

## 낮은 적중률에서 실제 확인한 것

관측은 원인의 증명이 아니다. 선수 부상·라인업·동기 등이 원인이라는 주장을
이 자료만으로 할 수 없고 해당 요인 제거 실험이 별도로 필요하다.

- 축구: 전체 9,767경기 중 4,893경기는 시장의 최상위 선택 확률부터 50% 미만.
  해당 구간 평균 예측 42.52%, 실제 적중 42.20%다. 이런 박빙 3분류 경기가
  전체 평균을 낮춘다. 높은 적중률을 위해 약한 경기를 제외하면 추천 수가 줄며
  전체 예측 성능이 좋아졌다는 뜻은 아니다.
- 야구: 50~60% 구간이 4,514경기이고 예측 평균 54.82%, 실제 53.21%다.
  60~70% 구간은 예측 63.76%, 실제 60.41%로 과신이 보인다.
  팀 단위 Elo/pi만으로 그 오차를 충분히 보완하지 못했다.
- 농구: 80% 이상 구간은 예측 평균 87.08%, 실제 84.28%.
  절편 보정과 작은 시장 잔차가 후보이나 독립 개선을 확정하지 못했다.
- 배구: 70~80% 구간 예측 평균 74.74%, 실제 70.51%.
  KOVO여 시장 최고확률 적중률은 203경기에서 59.61%, KOVO남은 203경기에서
  67.98%다. 리그별 후보 구성 차이가 큰데 전체 배구 평균만 보면 가려진다.
  차이가 리그 난이도 때문인지 가격 분포·표본 때문인지는 별도 검증 대상이다.

## 수익과 손실 제한

평가 경기마다 최고확률 선택에 같은 금액을 베팅하는 회고적 단폴 ROI는
사전 선택 모델 기준 농구 -11.08%, 야구 -13.33%, 축구 -11.55%, 배구 -12.18%.
적중률의 작은 개선이 플러스 수익으로 이어지지 않았다.

2폴은 각 픽의 예상 이익 양수만 허용하고 하루 최대 한 장, 주 최대 2/3회,
장당 1만원으로 비교했다. 다음 장 전패 시 월 -5만원 아래로 내려가면 진입하지
않았다. 사전 선택 모델은 농구·축구 0장, 야구 3장 모두 실패 -3만원,
배구 2장 모두 실패 -2만원으로 수익성을 뒷받침하지 못한다.
0장은 수익률 0%가 아니라 거래가 없어 ROI를 계산할 수 없다는 의미다.

사전 선택에서 탈락한 축구 Elo를 사후 고르면 주2회 +171,380원이지만
주3회는 -693,220원이다. 기존 피처 축구 모델도 주2회 +42,911원,
주3회 -787,889원으로 불안정하다. 플러스 결과를 숨기지 않되 이를
운영 승격의 근거로 선택하지 않는다. 모든 조건은 report.json에 남긴다.

## 한계와 후속 판단

- 과거 연구에 사용된 자료여서 완전히 새로운 독립 검증은 아니다.
- 관측 시각/판매 상태 없는 보관 배당이다. 경기 전 실제 구매 가능 ROI는 미검증.
- 2폴은 하루 종료 후 다음 날 전 정산, 베팅일 월 귀속을 가정한다.
  실제 연기·정산 지연·배당 반올림·세금은 재현하지 않는다.
- 2026년은 8월까지 일부 자료이며 오늘의 수집 상태·최근 팀 상태를 반영하지 않는다.
- 후보 간 다중 비교가 있으므로 이번 실험의 사후 최고값을 배포하지 않는다.
- 우선 후보는 농구의 시장 보정/잔차, 야구·배구의 낮은 비중 혼합이며,
  축구는 이번 후보군에서 시장 기준을 유지하는 것이 선택 규칙의 결과다.
  최신 경기 전 기록에서 추가 검증하기 전에는 모두 연구 후보다.
