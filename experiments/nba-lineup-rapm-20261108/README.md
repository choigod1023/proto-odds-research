# NBA 선수 조합 RAPM 회고 프로토타입 — 2026-11-08

이 문서는 최초 5경기 감사 후 진행한 후속 실험을 포함한다. **실제 동일 배당 비교는 0건이며 수익성, 운영모델 개선, 과거 경기 전 실제 자료 수신을 증명하지 않는다.**

## 데이터와 검증

[ramirobentes/nba_data 원본 README](https://github.com/ramirobentes/nba_data)는 `lineup_stats`를 10명이 유지되는 stint 단위로 설명한다. 직접 받은 2025-26 정규시즌 parquet 스키마에는 경기 ID, 홈/원정 팀, 양쪽 5명, 시작·종료·경과 초, 양쪽 점수와 점유가 있다. 79,202행은 같은 stint의 홈과 원정 2행이다. 수신 시각·URL·해시는 `lineup-manifest.json`, 스키마와 계산은 `prototype.py`에 있다. 타인이 복원한 자료이며 NBA 원본과 바이트 동등이나 당시 게시를 입증하지 않았다. [nba-on-court](https://github.com/shufinskiy/nba-on-court)는 PBP에서 코트 선수를 복원하는 공개 패키지이나 이번에는 설치·실행하지 않았다. 그 대신 별도 공개 stint 자료를 사용했다.

이전 NBA CDN 출처 제3자 PBP 아카이브 SHA와 수신 기록은 `archive-manifest.json`이다. 원본 19.3MB는 커밋하지 않았다. PBP의 최초·최종 `timeActual`을 경기 시작·종료 대용으로 삼았고 공식 예정 시작이나 최초 가용 시각의 증거는 아니다. 점수는 PBP 최종 기록을 이용했다. 2026-01-01 미국 동부 날짜의 공식 일정 5경기와 ID·최종 점수를 대조했으나 나머지 경기는 공식 원본과 개별 대조하지 않았다. 사전 4일 규칙은 최종 이벤트 시각 기준이다.

정규시즌 원본 1,230경기 중 `0022500029`는 stint 점수 115–148과 PBP 114–148이 달라 경기 전체를 제외했다. 나머지 1,229경기는 홈/원정 stint 대칭, 선수 10명 중복, 시간 경계, 전 경기 시간 및 PBP 최종 점수 일치를 검사했다. 유효성 실패 stint 노출은 0초였지만, 불일치 1경기 2,880초는 전체 홈 stint 노출 3,561,000초의 약 0.081%로 별도 제외했다. 이 구조 검사는 매 순간 10명이 실제로 코트에 있었음을 독립 검증하지 않는다. KBL의 해당 공개 원천은 확보하지 못했다.

## 실험과 누출 방지

- UTC 기준 2026-01-15 전 594경기로 선형 ridge stint 득실차를 학습하고, 1월 15일~2월 14일 224경기로 승리 확률을 로지스틱 보정했다. 이후 2월 20일~4월 13일 411경기를 평가했다. 시작일 경계는 UTC이며 경기 시작의 대용값에 의존한다. 세 모형은 동일 평가 경기·점수로 비교한다.
- 팀 대조군은 홈 효과와 팀 효과, 선수합 후보는 여기에 경기 중 10명 선수 지표, 선수쌍 후보는 같은 팀 선수쌍 상호작용을 추가했다. 종속변수는 stint 득실차의 48분 환산치, 가중치는 stint 시간/2,880초다. 정규화 계수 20, 선수쌍 벌점 10배, 난수 seed 20261108을 사용했다. 논문의 정확한 재현이 아닌 탐색용 후보이다.
- 평가 경기의 실제 출전 선수·시간·교체는 입력으로 사용하지 않았다. 각 팀의 경기 종료가 대상 경기 시작 대용시각보다 4일 이상 이전인 최근 5경기의 stint 비율에서 선수·선수쌍 가중치를 만들었다. 평가 구간에 들어간 이전 경기도 4일 조건을 충족한 뒤 사용한다. 학습 계수는 고정하고 예상 조합만 갱신했다. 당시의 자료 수신을 증명하지 못하므로 이 결과는 **사후 재구성 실험**이다.
- 모델 설정은 평가 라벨로 조정하지 않고 실행한 고정 설정이다. 다만 단일 시즌·단일 기간의 탐색 결과로 독립적인 사전 등록 연구가 아니다. 팀 대조군은 이 실험의 재학습 대조군이며 실제 운영 M0가 아니다. 실제 동일 상품·가격·정산과 운영 예측은 연결되지 않았다.

## 결과

같은 평가 411경기의 팀 대조군 / 선수합 / 선수쌍 순서다.

- 득실차 RMSE: **16.067 / 15.515 / 15.493점**.
- 승패 적중률: **69.34% / 72.75% / 74.21%**.
- Log loss: **0.57013 / 0.56366 / 0.56363**. Brier: **0.19282 / 0.18966 / 0.18966**.
- 선수쌍은 선수합 대비 8경기의 선택을 바꿔 7대 1로 맞혔다. 적중률 차이는 +1.46%p이며 9개 UTC 주 단위 paired bootstrap 5,000회의 95% 구간은 +0.27~+2.36%p다. 바뀐 경기가 8건뿐이고 주가 9개여서 구간의 안정성은 낮다. 선수합 대비 팀 대조군의 차이는 +3.41%p, 구간 −0.76~+7.48%p다.
- 월별 표본은 2월 73, 3월 237, 4월 101경기다. 모든 수치와 추가 비교는 `metrics-detail.json`, 검증·평가별 경기 예측은 `predictions.jsonl.gz`, 모델 입력인 검증된 stint는 `stints.jsonl.gz`에 있다. 같은 상품 가격·정산이 없어 ROI, MDD, 월별 ROI와 가격 기반 paired CI는 미산출이다.

선수쌍 개선은 극히 소수의 바뀐 선택에 기대며 관측 이후의 독립 시즌, 실제 사전 기록, 공식 원천 교차검증이 필요하다. 실제 성과나 향후 이익으로 간주하지 않는다. 취소·무승부가 포함된 타 종목은 연구하지 않았고 NBA 이외로 일반화하지 않는다.

## 선행 연구와 원천 제한

기존 농구 감사의 14개 lineup 레코드는 확정 5명이 아닌 선수 ID 미검증 부상 보고서이며 KBL 선수기록은 사후 박스스코어다. 기존 NBA workload 연구는 동일 정산 비교에 필요한 교집합이 없었고, 동적 점수 연구는 선수 조합을 구현하지 않았다. [Grassetti 등](https://doi.org/10.1093/imaman/dpaa022)은 개인·전체 조합을 다루는 extended RAPM 연구다. 출판사 본문 접근은 실패했으므로 초록만 확인했으며 수식 재현을 주장하지 않는다. [Bajons·Hornik](https://arxiv.org/abs/2407.17832)은 축구 점유 시퀀스 연구다. RAPM이나 조합 항 자체는 새로운 발명이 아니다.

공식 CDN PBP·boxscore 각 2회 요청은 403이었다 (`source-manifest.json`). 수신 시각은 2026-11-08이며 과거 가용성 증거가 아니다. 과거 배당의 실제 구매 가능성도 입증되지 않았다.

## 재현

두 입력 파일의 URL 및 SHA-256은 manifest에 있다. 동일 바이트를 별도 수신한 뒤 `python -X utf8 experiments/nba-lineup-rapm-20261108/prototype.py --pbp <archive.tar.xz> --lineup <lineup.parquet>`와 `python -X utf8 experiments/nba-lineup-rapm-20261108/metrics.py`를 실행한다. 원본 해시가 다르면 중단한다. numpy, pandas, pyarrow, scipy, scikit-learn이 필요하며 실행은 BLAS/OMP 1스레드다. `python -X utf8 -m unittest discover -s tests -p test_nba_lineup_rapm_20261108.py -v`는 경기 연결, 4일 이내 정보 제외, 쌍 특성, 평가 건수 및 가격 미연결을 검사한다.
