# NBA 선수·조합 RAPM 회고 실험 — 2026-11-08

시점 경계를 보수적으로 수정한 최종 평가 411경기에서 **시장 기준 승패 적중률은 76.40%, 선수쌍 후보는 72.26%**였다. 선수합은 70.80%, 팀 대조군은 70.07%였다. 가격 원장과 경기 411건을 연결했지만 개별 상품 ID와 연장 포함 정산 규칙은 원장에 없으므로 **엄격한 동일 상품·정산 입증은 0건**이다. 참고가격 가상 ROI는 동일 정산을 가정한 회고 수치이며 실제 구매 가능성이나 수익성을 입증하지 않는다.

## 시점 수정과 표본

PBP 최초·마지막 `timeActual`을 경기 시작·종료 대용으로 사용했다. 기존 실행의 시작 시각 기준 분할에는 다음 구간 경계 이후 종료된 경기가 학습 0건, 보정 0건이었다. 그러나 결과가 경기 종료 후 최소 4일 뒤에 알려진다는 보수적 가정을 적용하면 기존 학습 594건 중 28건, 보정 224건 중 21건이 경계에 걸렸다. 이들을 제외해 같은 모형 설정으로 **566건 학습, 203건 보정, 411건 평가**했다. 이전 74.21% 결과는 `pre-purge-summary.json`과 `pre-purge-predictions.jsonl.gz`에 이력으로 보존하며 최종값이 아니다.

공식 NBA 일정 5경기의 최초 PBP 사건은 공식 예정시각보다 10.3~11.6분 늦었다. 참고 가격 원장의 시각을 KST로 가정한 411건에서는 6.1~18.5분 늦었다. 기존 첫 사건 기준의 최근 5경기 입력 중 3팀 사례는 가격 원장 예정시각 기준 4일 경계를 넘을 수 있었다. 따라서 최초 사건보다 30분 앞을 대상 판단 시각 대용으로 고쳐 다시 계산했다. 위 KST 가정 아래 경계 초과는 0건이지만 가격 원장 시각의 시간대는 인증되지 않았고 5경기 외 공식 예정시각은 대조하지 못했다. `clock-audit.json`에 근거를 기록했다. 실제 사전 수신 시각을 증명한 것은 아니다.

훈련과 보정 라벨은 각각 다음 고정 구간 시작 4일 전까지 끝난 경기만 사용했다. 평가 경기 입력은 대상 대용시각보다 4일 이상 전에 종료된 최근 5경기의 선수·선수쌍 stint 비율이다. 평가 경기의 실제 출전 선수·시간·교체는 입력하지 않았다. 사용한 이전 경기가 당시 실제 수신되었는지는 미확인이다.

## 자료와 비교

[ramirobentes/nba_data](https://github.com/ramirobentes/nba_data)는 `lineup_stats`를 10명이 유지되는 stint 단위로 설명한다. 직접 받은 2025-26 정규시즌 파일은 경기 ID, 홈·원정, 10명, 시간, 점수와 점유를 제공한다. 동일 출처 NBA CDN 재배포 PBP 및 stint는 제3자 자료이며 NBA 원본과의 바이트 동등성을 입증하지 않았다. [nba-on-court](https://github.com/shufinskiy/nba-on-court)는 PBP 코트 선수 복원 공개 패키지이나 이번에는 설치·실행하지 않았다.

전체 1,230경기 중 `0022500029`는 stint 점수 115–148과 PBP 114–148이 달라 제외했다. 나머지 1,229경기는 양 팀 stint 대칭, 선수 10명 중복, 시간 연속성, 전체 경기시간 및 PBP 점수를 검사했다. 제외 2,880초는 전체 홈 stint 노출의 약 0.081%다. 이 구조 검사는 실제 코트 10명을 독립 보증하지 않는다. 공식 일정·최종 점수는 기존 5경기만 대조했고 KBL 라인업 원천은 확보하지 못했다. 수신 시각과 원천 해시는 manifest에 있다.

팀 대조군은 홈·팀 효과, 선수합은 선수 10명 지표를 추가하고 선수쌍은 같은 편 선수쌍 항을 추가한 가중 ridge다. stint 득실차를 48분으로 환산하고 시간 비율로 가중했다. 정규화 20, 선수쌍 벌점 10배, seed 20261108을 그대로 유지했다. 보정에는 로지스틱 회귀를 썼다. 기존 운영 M0는 재현하지 않았다. NBA 경기 원본 전체연장 포함 PBP 결과를 사용하며 다른 종목의 취소나 무승부로 일반화하지 않는다.

## 최종 비교

같은 411경기에서 시장 / 팀 대조군 / 선수합 / 선수쌍 순서다.

- 승패 적중률: **76.40% / 70.07% / 70.80% / 72.26%**.
- Log loss: **0.49064 / 0.56918 / 0.56319 / 0.56262**. Brier: **0.15910 / 0.19227 / 0.18957 / 0.18933**.
- 득실차 RMSE는 팀 / 선수합 / 선수쌍 순으로 **16.089 / 15.624 / 15.597점**이다. 시장에는 득실차 예측이 없다.
- 가격 원장 승패 레이블과 PBP 승자가 일치하는 조건에서, 각자 선택에 1단위를 가상 투입하고 보관된 2-way 배당과 PBP 최종 승자로 정산한다고 가정한 **참고가격 가상 ROI**는 시장 / 팀 / 선수합 / 선수쌍 순으로 **−7.42% / −9.98% / −9.25% / −6.12%**다. 각 상품의 정확한 정산 규칙이 미확인이라 실제 동일 상품 정산 ROI가 아니다. 사전 가격 수신과 구매 가능성도 미확인이다.
- 선수쌍은 선수합보다 선택 10건을 바꿨고 8대 2로 적중했다. 적중률 차이의 주 단위 paired bootstrap 95% 구간은 **−0.48~+3.19%p**다. 선수쌍 대 시장의 참고가격 가상 ROI 차이는 +1.29%p, 구간은 **−6.55~+9.44%p**다. 주 9개와 적은 변경 선택으로 구간이 불안정하다. 평가를 본 뒤 시점 결함을 바로잡은 탐색 결과이므로 독립 전향 검증이 필요하다.

가격 연결은 기존 `all-sports-underdog-20261031` 원장의 NBA 2026년 804행에서 한국어 팀 별칭, KST 날짜 및 홈·원정이 유일하게 일치하고 승패 레이블이 PBP 승자와 일치한 411건이다. 연결 실패·중복·승패 불일치는 각 0건이다. 원장 연구 프로토콜은 전체 경기 2-way 시장이라고 기술하지만, 개별 행에는 공식 상품 번호·확정 정산 규칙·배당 관측시각이 없다. 사후 선택된 보관 자료의 참고 비교이며 실제 가격의 경기 전 수신·구매 가능성을 증명하지 않는다. 원장 SHA-256과 월별·주별 계산은 `priced-summary.json`, 개별 기록은 `priced-matches.jsonl.gz`, 전체 경기별 예측은 `predictions.jsonl.gz`, 평가 집계는 `metrics-detail.json`에 있다.

## 기존 연구·문헌 및 재현

기존 농구의 14개 lineup 레코드는 확정 5명이 아닌 선수 ID 미검증 부상 보고서이며 KBL 선수기록은 사후 박스스코어다. 기존 NBA workload와 동적 팀 점수 연구는 이 선수 조합 실험을 수행하지 않았다. [Grassetti 등](https://doi.org/10.1093/imaman/dpaa022)의 출판사 초록은 선수·라인업을 다루는 확장 RAPM을 설명한다. 본문 접근 실패로 정확한 수식 재현을 주장하지 않는다. [Bajons·Hornik](https://arxiv.org/abs/2407.17832)은 축구 점유 시퀀스 연구다. RAPM이나 조합 항 자체는 새로운 발명이 아니다.

두 대용량 원본 URL·SHA는 각 manifest에 있다. 동일 바이트를 따로 받은 뒤 `python -X utf8 experiments/nba-lineup-rapm-20261108/prototype.py --pbp <archive.tar.xz> --lineup <lineup.parquet>`를 실행하고 `metrics.py`, `price_join.py`, `clock_audit.py`를 순서대로 실행한다. 원본 해시가 다르면 중단한다. numpy, pandas, pyarrow, scipy, scikit-learn이 필요하고 BLAS/OMP는 1스레드다. `python -X utf8 -m unittest discover -s tests -p test_nba_lineup_rapm_20261108.py -v`는 경계 경기, 가격 중복·결과 불일치, 선수쌍 입력과 실제 평가 건수를 검사한다.
