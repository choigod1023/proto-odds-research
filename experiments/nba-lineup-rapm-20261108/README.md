# NBA 라인업 RAPM: 자료 연결 감사 (2026-11-08)

## 결과와 범위

요청한 선수합과 조합 효과의 시간 분리 학습 및 예측 비교는 **미완료, n=0**이다. 2026-01-01 미국 동부 날짜의 NBA 공식 일정 표본 전체 5경기를 사전 선택했고, 제3자 보관 PBP를 공식 경기 ID에 연결해 사건 2,663행을 추출했다. 5경기 모두 PBP 마지막 점수는 공식 일정 결과와 일치한다. 이는 경기·점수 연결만 확인한 것이며 PBP의 완전성이나 원본 NBA 바이트 일치를 보증하지 않는다. 경기별 PBP 기록은 491~582행이고 교체 행은 90~104행이다. 경기별 검산 자료는 `event-audit.json`과 `events.jsonl.gz`다. 추출 대상 5경기 외 전체 리그를 다뤘다고 주장하지 않는다.

실제 코트 5명의 쿼터 시작 상태 및 사전 출전 예상 시간이 확보되지 않아 교체 행만으로 안전하게 라인업 전체를 복원하지 못했다. 5경기만으로 과거 학습과 시간 분리 평가를 구성할 수도 없다. 실제 후보·대조군 예측, 적중률, LL, Brier, 변경 픽, 주별 paired CI는 모두 미산출이다. 동일 경기·상품·배당·정산을 입증한 건수는 0이며 ROI와 MDD도 미산출이다. 운영 M0 입력·계수를 연결하지 않았으므로 재현하지 않았다. 빈 `predictions.jsonl.gz`는 평가 행 0건을 뜻한다. 실제 성과나 구매 가능성을 증명하지 않는다.

## 원천 및 시간 감사

- 기존 `nba-2025-sample.jsonl`은 2025-01-01의 8경기, `nba-2026-sample.jsonl`은 2026-01-01의 5경기 공식 일정과 결과다. 후자 SHA-256은 `edc7e446e867c8905b596f1c38c36ef75395d1d115907956e3da7720dd436104`. 기존 수신 시각/근거는 원본 manifest를 따르며 `timestamp_basis=unknown`: 과거 경기 전 수신 증명이 아니다.
- 새 자료는 [shufinskiy/nba_data](https://github.com/shufinskiy/nba_data)의 NBA CDN 출처라고 명시된 제3자 시즌 아카이브다. 2025라는 파일명은 2025-26 시즌에 해당한다. 수신 완료 시각, URL, 바이트 수와 해시는 `archive-manifest.json`에 기록했다. 제3자 재배포본이고 수신 시각은 과거 최초 공개 또는 실제 사전 가용 시각을 입증하지 않는다. 압축 원본 19.3MB는 커밋하지 않았다. 공식 경기·팀 ID와 최종 점수를 연결했으나 당시 가격·상품·정산은 연결되지 않았다.
- NBA 공식 CDN PBP와 boxscore에 경기 2개씩 순차 요청했으나 모두 HTTP 403이었다 (`source-manifest.json`). 다른 경기 2개 요청은 고정 탐색용이며 2026 표본 다섯 경기 전체 수집이 아니다. KBL 공식 사전 라인업과 비교 가능한 PBP 원천은 확보하지 못했다.
- 기존 농구 자료의 14개 lineup 레코드는 선수 ID가 검증되지 않은 부상 보고서이며 확정 출전명단이 아니다. 기존 KBL 박스스코어 2건은 사후 기록이다. NBA workload 연구는 공식 결과 및 사전 부상 자료를 감사했지만 NBA 동일정산 학습 교집합을 확보하지 못했다. 동적 점수 연구는 팀 상태를 사용했고 실제 선수·라인업을 구현하지 않았다. 따라서 이번 PBP 연결은 실제 사건 자료라는 차이가 있으나 새로운 성능 결과는 아니다. K리그 workload의 사전 과거 출전 시간과 사후 선발 회고는 구분되어 있다.

## 문헌과 가능한 모형 설계

[Grassetti 등](https://doi.org/10.1093/imaman/dpaa022)은 개인 및 전체 라인업으로 RAPM을 확장한다는 출판사/저자 페이지의 초록을 확인했다. 본문은 접근 실패했으므로 정확한 수식 재현을 주장하지 않는다. [Bajons·Hornik](https://arxiv.org/abs/2407.17832)은 축구 점유 시퀀스와 정규화 논문이며 농구 라인업 논문이 아니다. 기존 RAPM 자체는 새로운 발명이 아니다.

후보 설계는 교체 사이 검증된 stint의 홈-원정 점수차를 종속값으로 하여 홈·시간 등 통제와 선수별 ±1에 ridge를 적용하고, 별도 후보에서 같은 편 5인 조합 또는 선수쌍 항에 더 강한 수축을 적용한다. 이것은 구상이며 구현·적합·하이퍼파라미터 선정이 아니다. 누출 방지를 위해 실제 과거 stint만 학습하고, 평가 경기 입력은 경기 전에 알 수 있는 명단 또는 이전 경기에서 추정한 분수만 쓴다. 사후 실제 명단은 오라클 분석으로만 따로 표시한다. 시점별 팀 로스터, period 시작 5명, 정확한 교체 순서·동시 교체·연장·누락 검증과 학습/검증/평가 날짜 고정이 선행돼야 한다. 경기 중 점수로 만든 예측은 경기 전 성능과 합치지 않는다.

## 재현 및 검증

원본 URL과 해시는 manifest에 있다. 원본을 따로 받은 후 `python -X utf8 experiments/nba-lineup-rapm-20261108/extract.py <archive>`를 실행한다. 해시 불일치와 예기치 않은 아카이브 구조에서는 중단한다. `python -X utf8 -m unittest discover -s tests -p test_nba_lineup_rapm_20261108.py -v`는 다섯 공식 점수 일치, 사건 ID 중복, 사전 명단·가격 미확보 게이트를 검사한다. 표본의 ID와 점수 대조는 원천의 모든 오류를 검출하지 않는다. 원시 이벤트는 사후 자료이고 독립 제3자 시각 증명은 없다.
