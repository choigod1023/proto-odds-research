# NPB 공식 경기 기록 연결: 2026년 3~9월

공식 경기 기록 137건에서 양 팀의 실제 선발 타순과 선발투수를 연결했다. 모두 2026-11-03에 수신한 경기 후 기록이며, 당시 경기 전 확정 명단을 수신했다는 증거는 아니다. 모델 학습이나 적중률·ROI 평가는 하지 않았다.

## 표본과 분모

사전 커밋 `65d8d0c9982c9f8032ef70f6ec7ad80f2cce1058`의 2026년 3월 27~31일, 4월 14~20일, 5월 12~18일, 6월 16~22일, 7월 14~20일, 8월 4~10일을 대상으로 먼저 40일을 조사했다. 이 중간 결과를 확인한 후 실제 기간이 6개월을 넘도록 9월 25~30일을 추가하는 규칙을 `cf44b0aa7a3947c958bc085ae1d64897c20d049d`에서 사전 고정하고 해당 날짜를 요청했다. 합계 46일의 공식 일별 목록을 확인했다. 이 창에서 공식 경기 경로 208개를 확인했고 날짜·경로순 월별 첫 20개씩 140경기를 성적·선수·배당과 무관하게 선택했다. 68경기는 선택 규칙에 따라 경기별 원문을 수집하지 않았다. 이는 2026시즌 전체 경기 목록이나 전체 미수집 경기 수가 아니다.

선택 140경기는 모두 공식 원문을 받았다. 완료 137, 우천 취소 3이며 최종 파싱 실패와 선택 후 미처리는 0이다. 수집 중 연결 오류 1회는 이후 한 번 재시도해 성공했다. 완료 137에는 우천 콜드게임 2경기가 포함된다. 월별 완료는 3월 20, 4월 19, 5월 20, 6월 18, 7월 20, 8월 20, 9월 20이다. 실제 완료 경기 날짜 범위는 2026-03-27~2026-09-29다. 일별 목록의 실제 응답과 208개 경기 경로는 `fixture-census.jsonl`, 선택된 140건과 상태는 `postgame-records.jsonl`에 있다. 최초 3~8월 집계는 9월 창을 고정하기 전에 이미 열람했으며, 어느 기간도 새로운 성능 블라인드 표본이 아니다.

## 공식 선수와 시점

완료 137경기 모두 양 팀 선발 타순 9명씩 2,466 선수행과 양 팀 선발투수 274행을 공식 선수 ID에 연결했다. 선발 타순의 서로 다른 선수 ID는 336개다. 교체 타자 등 타순표의 별도 행 1,264개와 구원투수 865행은 선발과 나눴다. 출전 선수 전체를 앞에서 9명 잘라 선발로 취급하지 않고, 각 타순 번호 1~9가 한 번씩 있고 선발 위치가 괄호로 표시됐으며 공식 프로필 링크가 있는지 검사했다. 투수표 첫 선수행에 ID가 없으면 다음 구원투수를 선발로 대신 쓰지 않는다. 이닝은 5.2이닝을 17아웃으로 환산하고, 다음 이닝에 등판했으나 아웃을 잡지 못한 `5 +`는 15아웃으로 표시하면서 원문 표기도 보존한다.

공식 경기 페이지 원문에는 대상 경기의 최종 점수·개인 경기 기록이 들어 있다. 추출 결과의 해당 값과 실제 출전 타순·투구수는 모두 `postgame` 아래에만 두었고, 현재 경기 전 특성으로 제공하지 않는다. `received_at`은 실제 2026-11-03 HTTP 수신 완료 시각이다. 과거 출판 주장 시각, 예고 선발, 실제 등판, 사전에 확정된 타순은 서로 다르다. [NPB 공식 일정](https://npb.jp/games/2026/schedule.html)은 예고 선발/책임투수 항목을, [공식 출전선수 등록·말소 공시](https://npb.jp/announcement/roster/)는 등록 상태를 제공하지만 이 수집은 해당 시점의 독립 수신 스냅샷이나 경기 전 확정 9인 타순을 확보하지 못했다. 엄격한 경기 전 수신 인증은 **0/137**이다.

## 가격과 결과 연결

다른 작업이 보존한 공식 Betman 회차 응답을 읽기 전용으로 조사했다. KBO 자료와 K리그 자료의 중복 바이트를 제거한 2026년 응답 76개 중 11개 응답에서, 선택 완료 경기 77/137개에 팀 ID·경기일·공식 실제 시작과 회차 예정 시작 30분 이내·일반 야구 승패 상품 ID·양 선택 가격을 연결했다. 동일 날짜 같은 팀 조합의 공식 경기가 복수면 제외하고, 소스의 거부/라이브 표시와 결과 점수 불일치도 제외했다. 연결 77행의 공식 경기 최종 점수와 응답 점수는 77/77 일치한다. `retrospective-price-links.jsonl`은 가격과 점수 확인을 보존하고, `price-raw/`는 해당 응답 11개의 원문과 메타데이터를 보존한다.

이 가격은 **2026-11-03에 받은 사후 회차 응답**이며 발매 당시 실행 가능 가격이나 T-30 가격이라는 증거가 아니다. 응답만으로 상품의 적용 기간과 정산 규칙도 확인하지 못해 완전히 검증된 동일 시점·동일 정산 가격의 교집합은 미측정이고 엄격한 경기 전 가격 수신 인증은 0건이다. 76개는 확보한 캐시의 범위이며 모든 회차를 조사했다는 뜻은 아니다. 일반 승패, 승1패, 핸디캡, 언더오버, SUM/홀짝은 별개 상품이고 섞지 않았다.

실제 [2026-05-14 DeNA–주니치 공식 기록](https://npb.jp/scores/2026/0514/db-d-08/box.html)에는 12회 종료 0:0이 표시된다. NPB의 [2026 센트럴리그 클라이맥스 시리즈 요강](https://npb.jp/games/2026/info_cscl.html)도 해당 시리즈에서 12회 종료 동점은 무승부라고 명시한다. 이는 이 연구의 2026 정규시즌 전체 규칙이나 Betman의 각 상품 환급·적중특례를 인증하지 않는다. 특히 2-way 승패의 무승부·콜드게임 처리, 핸디캡·합계 상품의 정산은 공식 상품별 약관 원문과 버전을 확보하기 전까지 미확정이며 임의 환급·ROI를 계산하지 않았다.

## 후속 가설과 한계

한 가지 후속 가설은 **선수 구성은 같지만 공식 경기 전 확정 타순에서 상위 1~3번의 순서가 이전 경기와 달라진 경우**, 동일 시점 시장과 타순 정보가 없는 기준 모델을 넘는 예측 정보가 있는지다. 기존의 선발 변경·결장 유무 가설과 달리 동일 선수 집합 내 타순 이동을 보되, 이전 경기의 실제 수신된 종료 기록과 대상 경기의 실제 수신된 T-30 이전 확정 타순, 가격·상품·결과 및 정산 규칙이 모두 필요하다. 공식 ID와 타순 칸이 존재한다는 출처 근거만 확보했으며 이 자료로 가설의 효과를 실증하지 않았다. 검토한 선행 문서에서 동일한 제한 가설은 확인하지 못했지만 전체 선행연구의 독창성을 보증하지 않는다.

직접 NPB 요청은 총 187회로 186회 HTTP 200, 1회 연결 오류였다. 이후 정상 응답을 확인한 다음 그 경기만 한 번 재개해 확보했다. 동일 호스트의 연속 요청 시작 최소 간격은 1.064239초였다. 500회 제한과 15초 timeout, 단일 수집기 잠금, 응답 캐시와 재개 기능을 적용했다. 수집은 `python experiments/npb-official-information-20261103/collect.py`로 재개하며, 모두 캐시된 현재 상태에서는 추가 요청 없이 재생된다. `price_join.py`는 원래 두 외부 가격 캐시 경로가 있을 때만 가격 연결을 재생한다. 186개 NPB 응답과 11개 사용 가격 응답의 URL·파라미터·실제 수신·HTTP 상태·원문/압축 SHA는 `source-manifest.json`과 각 메타데이터에 있다. 해시는 바이트 무결성만 확인한다.

회귀 검증은 `python -m pytest tests/test_npb_official_information_20261103.py -q`로 실행했다. 137개의 실제 경기 원문에서 선발 행·선수 ID·선발 투수와 공식 점수를 파생물과 대조했으며, 교체 선수 구분·5.2이닝·동일 카드 중복·불완전 가격 및 거부 표시도 검사했다. 생산 추론 설정·운영 DB·원장·자동화·스케줄은 변경하지 않았다.
