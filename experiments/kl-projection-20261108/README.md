# K리그 회고 가격의 KL 연성 투영 실험

## 결과와 범위

2023-02-25~2026-06-07의 K리그1·2 공통 1,491경기에서 승무패·정수 3방향 핸디캡·반점 언더오버를 비교했다. 2023~2024 928경기와 2025~2026 563경기로 날짜를 나눴다. 결과 라벨로 학습하거나 설정을 선택하지 않았으며, 각 경기의 가격에만 모형을 맞춘다. 별도 학습·검증 데이터가 필요 없는 고정 설정의 회고 비교다. 설정은 사전 등록되지 않았고 과거 연구에 사용된 기간이므로 독립 미공개 시험이나 운영 사전 성과가 아니다.

후반 563경기에서 승무패만 맞춘 Poisson과 KL 후보의 적중률/ROI/로그손실/Brier는 각각 승무패 47.42%/-11.76%/1.0363/0.6230 대 47.42%/-11.76%/1.0359/0.6227, 핸디캡 54.00%/-8.33%/0.9991/0.5959 대 54.17%/-7.98%/1.0001/0.5963, 언더오버 53.11%/-12.57%/0.6952/0.5019 대 55.60%/-10.40%/0.6852/0.4921이다. 일별 종가 기준 최대 낙폭은 각각 74.83/54.33/70.79단위 대 74.83/52.32/58.75단위다. 세 시장은 각각 경기당 1단위이며 합산 투자나 실제 지갑이 아니다. 모든 모형과 전후 기간·리그별 수치는 `summary.json`에 있다.

55개 달력 주 묶음의 쌍체 부트스트랩 3,000회에서 KL−승무패 Poisson 언더오버 적중률 차이는 +2.49%p, 95% 구간 -1.06~+6.33%p, ROI 차이는 +2.17%p, 구간 -4.03~+8.57%p, 로그손실 차이는 -0.0101, 구간 -0.0216~+0.0022였다. 모든 구간에 0이 포함되며 안정적 개선이나 수익을 입증하지 않는다. 다른 상품의 구간은 `uncertainty.json`에 있다. 같은 자료의 다른 가격까지 입력했으므로 승무패만 쓰는 대조군과의 차이를 순수한 수학 변환 효과라고 할 수 없다. 같은 세 시장 입력의 Poisson/DC와의 비교는 `summary.json` 참조. 

## 신규성 감사

`src/cross_market_edge.py`는 타깃 시장을 제외한 상품에서 Poisson 평균을 적합하고 타깃 시장을 복원한다. `origin/codex/kleague-cross-market-nba-20261106`의 893경기 연구는 같은 응답의 회고 가격을 사용한 시장 회귀 비교이며 2025~2026의 별도 원천과 선택 기준이다. `2d9000e2`의 `kleague-market-information-20261106/MANUSCRIPT.md`는 세 시장의 KL 목표로 두 Poisson 평균을 맞췄고 후속 Dirichlet은 별도 전향 확률 보정이다. 기존에도 KL 및 일관된 점수분포 개념이 있으므로 KL 일반이나 교차시장 자체를 새 연구라고 주장하지 않는다. 여기서는 승무패 Poisson을 기준분포로 하고 121개 점수 상태의 확률을 직접 KL 정규화하며 모든 시장을 연성 제약으로 맞춘다. 분포의 형태가 Poisson에 제한되지 않는다. 두 자료의 정확한 경기별 교집합은 검산하지 않았고 893경기와 기간이 겹친다. 기존 893경기와 별도 원천의 비교이며 이를 대체한 복제가 아니다.

Csiszár의 [I-divergence 투영 논문](https://web.mit.edu/course/6/6.291/www/handouts/csiszar_Idiv.pdf)은 선형 제약의 정보 투영을 다룬다. 요청한 원문 URL은 열람 시 404여서 동일 논문의 MIT 사본을 참조했다. 여기의 제곱 오차 연성 벌점은 논문의 하드 제약 정리 그 자체가 아니라 그 개념에 기반한 변형이다.

## 방법과 한계

원본 `games.csv.tmp` SHA-256 `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`. 기존 충돌 제거 로더와 동일 자료의 승무패 점수를 연결하고 각 상품 결과와 일치하는 유일한 상품만 허용했다. 127경기는 상품 부족 또는 중복으로 제외했다. 공식 점수와 독립 검증한 자료가 아니다. 가격의 동시 HTTP 수신, 관측 시각, 경기 전 판매 및 체결 가능성은 증명되지 않은 회고 가격 묶음이다. 선수·픽스터·운영 모델 입력은 없다. NBA/KBO는 이 연구에서 지원되는 공통 세 상품·정산 근거를 재검증하지 않아 포함하지 않았다.

각 가격은 시장별 역배당을 정규화해 마진 제거 근사치로 사용한다. 사전분포 q는 승무패 가격에 맞춘 독립 Poisson이며, 후보는 `KL(p||q)+10*sum((M p - target)^2)`를 확률 단체 위에서 최소화한다. 시장 가격을 정확한 진실로 강제하지 않는다. 대조군은 승무패만 맞춘 Poisson, 세 시장 Poisson, 세 시장 Dixon–Coles(ρ [-0.05,0.05], 0.02ρ² 벌점)이며 모두 경기 결과 없이 가격 제곱오차를 최소화한다. 모든 격자는 0~10점으로 정규화한다. Poisson 평균 상한 exp(1.3)에서 격자 밖 확률의 합집합 상한은 약 0.00295이므로 유한 격자 근사 오차가 남는다. KL도 이 격자에 한정된다.

세 확률은 같은 비음수 합 1 분포의 사건 합이다. 정수 핸디캡 무승부는 별도 결과, 정수 총점 적중은 환불로 정의하며 실제 실험에서는 반점 총점만 사용한다. 최고 확률 방향을 고르고 적중 시 배당-1, 실패 시 -1이다. 로그손실은 자연로그, Brier는 다중 결과 제곱오차 합의 평균, 낙폭은 일별 손익을 누적한 고점 대비 최대 하락이다. 주 단위 재표집 구간은 시간 의존성에 대한 근사치다. 재현과 검산에는 입력 원본이 별도로 필요하다.

```powershell
python -X utf8 experiments/kl-projection-20261108/run.py --raw <games.csv.tmp> --out experiments/kl-projection-20261108
python -X utf8 experiments/kl-projection-20261108/uncertainty.py
python -m pytest -q experiments/kl-projection-20261108/test_information_projection.py
```

`predictions.json`은 경기·점수·상품·기준점·가격·각 선택 확률·선택·결과·손익을 모두 보존한다. 실행 시 사용한 원본 로더 버전은 이 브랜치 커밋에 고정된다. 연구 기록이며 운영 채택, 실매수, 배포 또는 미래 수익의 증거가 아니다.
