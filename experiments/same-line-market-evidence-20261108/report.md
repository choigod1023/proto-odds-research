# 같은 기준점 배당 변화의 방향 비교: 수정된 회고 분석

2026-11-08. 기존 214경기·추가 적중 3건 보고는 정식 방향 매핑, 물리 경기 중복, 늦은 원장 선택 기준을 반영하기 전의 수치다. **수정된 주 분석은 210경기, 추가 적중 2건(+0.95%p)**이다. 이 값은 보조 회고 결과이며, 근거 부족과 불확실성 때문에 운영모델 변경을 지지하지 않는다.

## 주 비교

같은 상품·기준점에서 보존된 최초 배당과 T-30까지의 마지막 배당을 각각 마진 제거한 후 최고확률 방향을 선택한다. 양쪽 모두 마지막 사전 관측의 각 선택 방향 배당으로 1단위를 가상 정산한다. 경기당 원장에 고정된 상품만 비교하며, 해당 원장의 선택·캡처가 T-30 이전인 경우만 포함한다. 이는 상품을 원장 선택으로 조건화한 회고 비교다. 원장 캡처 전부터 상품과 가격을 실시간으로 실행할 수 있었다는 뜻이 아니다. 이력의 첫 행은 발매 최초가 아니며 상품별 최대 50행으로 잘렸을 수 있다. 마지막 행도 T-30 직전의 실제 판매가격을 증명하지 않는다.

선택 방향은 가격 배열의 우연한 일치로 추정하지 않는다. `src/bets.py`의 `SEL_NAMES[(market, 2)]` 순서로 선택지 이름을 매핑하고, 같은 순서의 이력 배당 벡터 및 정산 방향을 연결한다. 두 방향을 모두 확인할 수 없는 사례와 동률은 제외한다. 회차를 뺀 종목·리그·홈팀·원정팀·킥오프를 물리 경기 키로 하여 적격 후보에서 중복이 발견되면 해당 경기의 행을 전부 제외한다. 이번 후보에서 제외된 물리 중복은 0행이다. T-30 뒤 또는 시각 불명 원장은 별도 분리한다. 이러한 정합성 기준은 기존 결과를 코드 감사한 뒤 수정한 것이므로 완전한 사전등록 검증으로 간주하지 않는다.

전체 210경기에서 최초 방향은 117적중(55.71%), 마지막 방향은 119적중(56.67%)이었다. 승→패 13건, 패→승 15건이다. 각 정책의 가상 손익은 -29.87→-29.36단위, ROI는 -14.22%→-13.98%, 시간순 최대 낙폭은 31.31→32.19단위다. 방향이 실제 바뀐 28경기는 13→15적중(+2건, +7.14%p), 손익 -3.52→-3.01단위, ROI -12.57%→-10.75%, 최대 낙폭 5.36→6.45단위다. 같은 시각 경기의 순서는 입력 순서이므로 최대 낙폭은 그 순서에 민감하다.

43개 UTC 날짜를 짝지어 5,000회 재표집한 전체 적중률 차이의 95% 구간은 -3.70~+5.81%p다. 방향 변경 경기의 16일 블록 구간은 -26.67~+45.45%p다. 이는 추출·선정 편향을 교정하지 않는다. 시간순 전반 105경기는 +3건(+2.86%p), 후반 105경기는 -1건(-0.95%p)이다. 분할은 기술적 비교이며 모델을 학습하거나 평가 표본으로 임계값을 최적화하지 않았다. 상품별 정확한 기간·단위·공식 정산은 독립적으로 증명하지 못했으며, 결과는 2방향 원장 hit/miss로 추론한다. 무효·환불 및 불명확한 정산은 제외한다.

T-30 뒤 캡처 4경기는 주 결과에서 제외했다. 이 4경기만의 최초→마지막 방향 적중은 1→2건이나 표본이 매우 작고 사후 상품선택 편향이 있으므로 효과로 해석하지 않는다. 기존 픽의 확률 비교는 주 표본 210경기에서 최초→마지막 이진 로그손실 0.68161→0.67564, Brier 0.24452→0.24178이다. 고정 픽 111/210 적중, 원장 가격 기준 ROI -18.72%는 확률만 변경해도 변하지 않는다. 이 픽을 최초 배당 관측 당시에 알고 있었다는 증거는 없다. 서로 다른 시점의 실제 집행 정책은 실행하지 않았다.

## 입력, 연결과 한계

입력은 2026-11-08 저장된 `market-changes-audit-live-20261108.json`과 `settlement-deploy-all-after-20261108.json`이다. SHA-256은 `audit.json`과 `direction-results.json`에 기록했다. 이력은 31회차, 상품 키 17,415개, 행 25,455개며 이는 경기 수가 아니다. 목록 3,314행 중 회차·종목·리그·홈·원정·날짜가 같은 유일한 결과 2,940건, 유일한 기록 선택 ID 1,991건, 정식 두 방향 선택지 1,102건, hit/miss 1,063건, T-30 이전 이력 2행 이상 236건, 같은 기준점과 완전 배당 226건, 동률 제외 214건에서 물리 중복 0건과 늦은 캡처 4건을 제외했다. 최종 종목별 경기 수는 축구 102, 농구 50, 야구 29, 배구 29다. 킥오프 범위는 2026-09-03 09:00 UTC~2026-11-07 07:00 UTC다.

읽기전용 132회차 제한 DB 추출은 `truncated=true`여서 전체 회차를 대표하지 않는다. 최종 표본 132회차 11경기 모두 상품 식별은 맞았으나 첫·마지막 관측의 정확한 시각과 전체 가격이 동시에 일치한 건은 각각 0건이다. 같은 가격의 시각이 서로 다른 사례가 있으며 원인은 미확인이다. DB 기록 시각은 HTTP 응답 원문 수신 시각이나 판매 가능성의 증명이 아니다.

별도의 102~132회차 source=proto 점수 수정 이력 7,139행은 잘림 없이 추출됐다. 상품별 최신 상태와 정확한 경기 정보를 대조한 결과 주 표본 210경기 중 75경기가 최신 confirmed 점수와 연결됐고, 연결된 경기에서 확인된 동일 물리 경기의 최신 confirmed 점수는 합의했다. 나머지 135경기는 해당 상품 점수에 연결되지 않았다. 최신 미확정을 과거 확정으로 되살리지 않으며 정규시간/연장 범위와 공식 정산이 불명확한 점수로 새로운 결과를 만들지 않았다. 상세와 입력 해시는 `db-crosscheck.json`, `score-crosscheck.json`에 있다.

## 기존 연구와 재현
