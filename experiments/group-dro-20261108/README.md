# Group DRO 오프라인 비교 — 2026-11-08

## 질문과 신규성 감사

[Sagawa 외 group DRO 원문](https://arxiv.org/abs/1911.08731)은 미리 정의한 그룹 중 최악의 학습 손실과 정규화의 관계를 연구한다. `rg -i 'group.?dro|distributionally robust|worst.group' docs/research experiments scripts`에서 해당 명칭의 기존 구현을 찾지 못했다. 명칭 검색만으로 선행 연구 전체의 부재를 증명하지는 못한다. `scripts/sport_model_tournament.py`의 시장 offset 보정·ridge·부스팅은 기존 연구다. 이번 모형도 시장만을 사용한 단순 보정이며 새 입력이나 새로운 모델 계열이 아니다. 차이는 동일 모형에서 경험 평균 손실과 리그 최악 손실을 혼합한 목적함수뿐이다.

## 자료와 설계

입력은 `experiments/all-sports-underdog-20261031/results/{bs,bk,sc}/domestic_archive/ledger.jsonl.gz`의 보존된 경기·배당·결과다. 각 입력 SHA-256은 summary.json에 기록했다. 원본 전처리 및 제외는 해당 실험의 `prepare.py`와 `inputs/domestic-audit.json`을 참조한다. 이 원장은 광범위 원시 아카이브와 기존 캐시를 결합한 2차 자료이며, 공식 원본의 당시 수신이나 체결 가능성을 입증하지 않는다. 팀명 원문에 인코딩 손상이 있고 원시 바이트를 이 실험에서 재검증하지 않았다. 야구·농구의 2-way 원장 구성 시 원래 무승부는 제외됐으며 축구는 홈/무/원 3-way를 그대로 유지했다. 취소·환불 경기는 포함되지 않는다. 배구 원장은 리그명이 손상돼 그룹 신원을 안전하게 구분할 수 없어 제외했다. 선수·픽스터·실제 운영 예측은 사용하지 않았다.

2025년 학습, 2026-01-01~2026-08-26 보존 범위 평가. 이전 연구에서 사용한 기간으로 독립 미공개 검증이 아니다. 그룹은 자료 감사 후 결과 비교 전 종목별 MLB/NPB/KBO, NBA/KBL/WKBL, EPL/MLS로 고정했다. 리그를 나눠 각각 학습하지 않고 종목별로 하나의 모형을 학습한다. 각 시장의 정규화 역배당 로그를 offset으로 두고, 절편과 log(p_home/p_away)를 입력으로 하는 다항 잔차를 사용한다. 양쪽 모두 동일한 계수 및 L2=0.01이며 절편도 규제한다. ERM은 전체 평균 로그손실, DRO는 전체 평균 0.5 + 학습 리그별 평균 손실의 최대 0.5를 최소화한다. 강도와 규제는 사전 고정된 단일 설정이며 평가 결과로 선택하지 않았다. 평가 리그의 정규화·가중치를 학습하지 않는다. 이는 최악 그룹의 순수 minimax가 아니라 고정 혼합 변형이다.

각 경기에서 확률 최대 선택지를 같은 가격으로 1단위 가상 정산한다. 적중시 배당-1, 실패시 -1, 날짜순 같은 날 ID 순으로 최대낙폭을 계산하며 실제 매수나 지갑 거래가 아니다. Brier는 클래스별 제곱오차 합이다. 전체 차이의 불확실성은 고정 시드의 날짜 블록 재표본 1,000회 95% 분위 구간이며 학습 변동과 리그별 다중비교를 반영하지 않는다. 월별·리그별 모든 지표와 구간은 summary.json, 경기별 양 모형 확률·선택·배당·결과·손익은 predictions.jsonl에 있다.

## 실제 결과

- 야구: 학습 3,887, 평가 2,959. ERM 대비 DRO 적중률 57.52%→57.38%, 로그손실 0.67996→0.68017, ROI -10.94%→-11.03%. 평가 최악 로그손실 MLB 0.6818→0.6821.
- 농구: 학습 1,736, 평가 1,016. 적중률 69.98%→69.98%, 로그손실 0.57246→0.57321, ROI 모두 -10.47%. 평가 최악 KBL 0.6332→0.6335.
- 축구: 학습 941, 평가 503. 적중률 47.32%→47.71%, 로그손실 1.03521→1.03438, ROI -18.85%→-17.72%. 평가 최악 EPL 1.0606→1.0579. 전체 로그손실 차이의 날짜 블록 95% 구간은 -0.00356~0.00157, ROI 차이는 -0.53~3.46%p로 0을 포함한다.

평가 최악 리그의 개선이 전체 성능 향상을 입증하지 않는다. 야구·농구는 최악 리그도 개선되지 않았다. 집계는 가격 가용성과 과거 예측 시점을 입증하지 않으며 운영 채택이나 수익성 근거가 아니다. 하위 그룹 및 시간별 표본이 작고 평가를 반복 사용했으므로 추가 독립 전향 검증이 필요하다.

## 재현

Python, NumPy, SciPy 필요. 저장소 루트에서 `python experiments/group-dro-20261108/run.py` 및 `python -m unittest discover -s experiments/group-dro-20261108 -p test_group_dro_research.py -v`. 테스트는 합성 예제로 3-way 확률·목적함수 및 정산을 검증하며 위 실제 성과와 별개다. 고정 데이터와 종목 선택만 읽고 운영·DB·예약 작업을 변경하지 않는다.
