# K리그 세 상품 동시 배당과 NBA 정산 연결

## K리그

2026년 11월 6일 14:07:24 KST에 베트맨 132회차 발매 중 응답 본문을 수신했다. 같은 회차·응답에 90분 승무패, 언더오버, 3방향 정수 핸디캡이 함께 있고, 세 상품 모두 접수 당시 판매 중인 K리그1 6경기와 K리그2 8경기를 확인했다. 14경기 모두 K리그 공식 일정과 시작 시각 및 홈·원정 팀 코드가 일치했다. 당시 결과가 없었으므로 아래 모의 정산에 합치지 않았다. `round-260132.json`과 압축 원문은 본문 완료 시각과 SHA-256으로 연결한다.

과거에는 2025년 2월~2026년 11월 공식 점수와 승무패 배당이 연결된 K리그1 412경기 중 406경기, K리그2 507경기 중 487경기에서 세 상품을 같은 베트맨 응답에서 확인했다. 배당 원본은 마감 후 받은 결과 응답이다. 이 893경기의 발매 당시 수신은 검증되지 않았다. 기준점이 여러 개면 언더오버는 가장 낮은 기준점, 핸디캡은 0에 가장 가까운 기준점으로 고정했다. 절댓값이 같으면 음수 핸디캡을 택했다. 전반 상품, 중복 기준점, 특수 상품, 거절된 상품을 제외하고 선택 상품의 정산 방향을 리그 공식 점수와 대조했다. [스포츠토토 고정배당률 세부규칙](https://www.sportstoto.co.kr/terms_allocation.php)

모의 비교는 2026년 7월 4일~11월 1일의 공통 표본을 썼다. 모두 같은 승무패 가격에서 최고 확률 1개 선택, 경기당 1단위로 정산했다. 기존 팀 전력 Poisson은 앞선 실험의 동결 예측이다. 승무패 단독은 역배당을 합계 1로 정규화했다. 추가로 같은 회귀 방식으로 보정한 승무패 단독과 세 상품 모델을 나란히 비교했다. 두 보정 모델 모두 2026년 6월 24일까지의 공통 경기(K리그1 293경기, K리그2 361경기)만 사용했고, 같은 L2 패널티를 적용했다.

- **K리그1 113경기**. 기존 모델은 42적중(37.17%), ROI −23.73%. 승무패 단독은 44적중(38.94%), −26.22%. 승무패 보정은 43적중(38.05%), −28.52%. 세 상품은 44적중(38.94%), −26.07%.
- **K리그2 126경기**. 기존 모델은 56적중(44.44%), ROI −18.74%. 승무패 단독은 61적중(48.41%), −12.24%. 승무패 보정은 58적중(46.03%), −17.59%. 세 상품은 57적중(45.24%), −13.68%.

세 상품 모델은 승무패 보정보다 두 리그에서 ROI가 높았으나, 승무패 단독 대비 K리그1은 +0.15%p, K리그2는 −1.44%p였다. 주 단위 재표집 5,000회로 얻은 ROI 차이 95% 구간은 각각 −6.97~+7.24%p와 −18.87~+17.54%p다. 이번 사후 배당으로는 세 상품의 일관된 개선을 확인할 수 없다. 14경기 신규 캡처에 대해서는 적중률과 ROI가 아직 없다.

Git 원본 배당·비교 모델은 `kleague_replay.py`의 커밋으로 고정했다. 기존 K리그 공식 가격 및 라인업 비교 브랜치의 Git 개체가 있으면 오프라인으로 재현할 수 있다.

```powershell
$d = 'experiments/kleague-cross-market-nba-20261106'
python -X utf8 "$d/kleague_replay.py" --pregame "$d/round-260132.json" --output .local-test/kleague_results.json
python -m pytest -q tests/test_kleague_cross_market_replay.py
```

## NBA

베트맨 G101 원본에서 현대 일반 승패를 `betId=3`, `betTypId=2`, `농구 승패`, `일반 승패`, `handi=21`로 확인했다. 2방향 무조정 상품만 남겼고, 스포츠토토 규칙에 따라 연장 포함 최종 점수로 대조했다. 발매 취소·무효·미정산, 핸디캡, 언더오버는 제외했다. 상품 표기가 비어 있는 예전 자료 676행은 별도 진단으로 남겼다. [스포츠토토 공식 규칙](https://www.sportstoto.co.kr/terms_allocation.php)

정산과 배당이 있는 일반 승패 **147상품** 중 **110상품, 고유 102경기**가 NBA 공식 일정의 시작 시각·홈·원정과 최종 점수에 일치했다. 팀 코드가 다른 경우 다른 날짜·회차의 공식 결과와 대조해 확인한 별칭을 적용했다. 공식 최종 박스스코어와 경기 전 부상 보고서가 모두 연결된 것은 131회차 **14경기(부상 상태 119행)**다. 이 중 두 경기는 연장까지 포함한 공식 박스스코어 점수와 베트맨 정산이 일치했다. [131회차 베트맨 원본 페이지](https://www.betman.co.kr/main/mainPage/gamebuy/gameSlip.do?gmId=G101&gmTs=260131) · [연장 경기 공식 박스스코어](https://www.nba.com/game/0022600179/box-score)

14경기 모두 양 팀의 과거 공식 일정 일부가 연결됐다. 양 팀의 이전 경기 공식 박스스코어가 함께 있는 경기는 0건이고, 이전 7일의 리그 일정에도 빠진 날짜가 있다. 최종 박스스코어의 해당 경기 주전 출전 시간은 과거 예측 입력으로 쓰지 않았다. 이 NBA 자료는 공식 기록 연결 결과이며 모의 ROI를 계산한 표본이 아니다.

`nba_replay.py`는 기존 147회차 베트맨 원본과 `nba_http_evidence.zip`의 새 증거를 해시 검증한 뒤 `nba_results.json`을 만든다. 원본의 로컬 경로가 달라졌으면 `--source-root`를 매니페스트 순서대로 두 번 전달한다.
