# 픽스터 상관 조정·확률 보정의 시간순 재검증

2026-10-25 로컬 실행. 운영 모델·DB·추천 정책을 변경하지 않는다.

## 실제 사용한 자료와 실험

입력은 PR #367의 `verified-results.json`에 보존한 173경기다. 새로운 경기·종목·시즌을 추가한 실험이 아니다. 그중 9월 5~13일 미국 동부시간의 109경기를 평가하고, 매일 00:00 ET 이전 자료로만 학습한다. 기존에 살펴본 과거 자료를 시간순으로 다시 재생한 것이므로 완전히 새로운 홀드아웃이나 전향 모의 운용이라고 부르지 않는다.

원자료는 운영 원장/Git의 사전 확률·배당, Tailslips의 저자별 최초 사전 투표, 공식 MLB 결과다. 입력 해시와 매일 학습·평가 ID, 학습 계수, 그룹 연결 근거, 경기별 확률을 `results.json`에 저장했다. 입력의 운영 확률은 모두 당시 시장 확률과 같으며 별도 학습형 독자 모델이 아니다.

학습에는 과거 경기의 `settled_at`이 해당일 00:00 이전인 **당시 게시자 판정 `publisher_y`**만 사용한다. 나중 공식 결과와 일치하는 학습 행만 고르는 것도 사후 정보가 될 수 있으므로 하지 않는다. 공식 `y`는 평가에만 쓴다. 관측 시각 자체가 외부의 변경 불가능한 증명은 아니라는 기존 한계는 남는다. 일별 학습 표본은 53→124경기다.

고정 비교군은 다음 여섯 개이며, 평가 성과를 보고 가중치/임곗값을 재탐색하지 않았다.

1. 운영: 저장된 확률 그대로.
2. 고정 9:1: 운영 90% + 저자별 투표 비율 10%.
3. 상관 조정 9:1: 과거 공통 경기 5개 이상·의견 일치 90% 이상인 저자들을 연결 성분으로 묶고, 현재 경기에서는 그룹별 평균 투표에 같은 가중치를 준다. 실제 복제 확인이 아니라 민감도 실험이다.
4. 수축 9:1: 위 투표를 유효 그룹 수와 시장확률 가상 표본 5개로 평균해 소수 투표의 영향을 줄인 뒤 9:1로 혼합한다.
5. 운영 보정: 운영 logit에 과거 학습한 절편만 더한다.
6. 보정 하이브리드: `logit(p) + a + b * (logit(q_shrunk) - logit(p))`. 합계 로그손실과 ridge=10 페널티를 최소화한다. a∈[−1,1], b∈[0,1], 최소 학습 30경기. p/q의 logit 입력은 0.01~0.99로 제한한다. 운영 보정 대조군은 b=0이다.

## 109경기 동일 조건 결과

한 경기당 한 단위, 각 확률의 최고 방향을 선택한 과거 가상 ROI:

- 운영: 63/109 적중, ROI **−12.64%**, Brier **0.23559**.
- 고정 9:1: 65/109, **−8.92%**, Brier **0.23665**.
- 상관 조정 9:1: 65/109, **−8.92%**, Brier **0.23670**.
- 수축 9:1: 63/109, **−12.58%**, Brier **0.23580**.
- 운영 보정: 65/109, **−9.25%**, Brier **0.23646**.
- 보정 하이브리드: 65/109, **−9.25%**, Brier **0.23646**.

Brier와 로그손실은 작을수록 좋다. 어느 후보도 운영값보다 확률 오차를 줄이지 못했다. 보정 하이브리드의 b는 9일 모두 0으로, 운영 보정과 예측이 같았다. 이번 작은 표본·수축·정규화 설계에서 추가 픽스터 효과가 학습되지 않은 것이며 모든 픽스터 정보가 무용하다는 뜻은 아니다.

상관 연결은 9/9부터 1개, 9/10부터 2개뿐이었다. 집계 확률은 조금 달라졌지만 최종 선택과 ROI는 고정 9:1과 같았다. 공통 경기 5개는 상관을 안정적으로 추정하기에 작고 연결 성분의 간접 연결도 가능하므로, 이를 복제 탐지 성과라고 주장하지 않는다.

추천 필터(p≥55%, 배당≥1.50, 배당 상한 없음)를 적용한 단폴은 비교 표본 자체가 달라진다:

- 운영: 25픽, 14적중, ROI −13.32%.
- 고정/상관 조정 9:1: 27픽, 13적중, ROI −24.07%.
- 수축 9:1: 27픽, 15적중, ROI −13.63%.
- 운영 보정/보정 하이브리드: 35픽, 21적중, ROI −5.29%.

즉 ‘모든 경기를 한 단위씩’과 ‘필터로 추린 추천’의 순위가 다르다. 필터 결과가 상대적으로 낫더라도 양수 수익을 입증한 것은 아니며, 동일 경기 비교와 섞어 설명하지 않는다.

## 수익 안정성과 월 한도

동일 T−30·동일 발매 회차·서로 다른 경기 2폴, 1장 1만원, 주 최대 2/3회, 구매월별 총투자액 5만원 이하·이익 재투자 없음으로 계산했다. 정확한 순손실 5만원 도달 중단이나 정산월 한도 재현은 아니다. 실제 정산 시각과 해당 배당의 구매 가능성은 검증하지 못했다.

주 2회/3회 상한 모두 결과는 같았다: 운영 3장 −3만원, 고정/상관 조정 9:1 1장 −1만원, 수축 9:1 3장 −3만원, 두 보정 모델 4장 −4만원. 모두 0적중이다. 구매 횟수가 적어 덜 잃은 것을 적중 성능 향상으로 해석하지 않는다. 한 달 중 9일·최대 4장이라 월간 수익 안정성 평가에는 부족하다.

경기 시작 순서의 단위 수익 최대 낙폭은 운영 14.55단위, 고정/상관 조정 9:1 12.34, 수축 14.48, 보정 14.13이다. 이는 실제 정산 순서의 현금 잔고 낙폭이 아니다. 날짜별 5,000회 재표집 차이 구간도 결과 JSON에 보존했다. 9일뿐이며 이전 모델 탐색·여섯 비교·날짜 간 의존성까지 보정한 유의성 검정은 아니다.

## 검증과 해석

- 공식 결과 전체를 뒤집어도 모든 예측 확률·학습 계수가 변하지 않는 테스트.
- 9/10 이후의 투표·게시자 판정을 바꿔도 9/10 이전 예측이 변하지 않는 테스트.
- 미래/중복 투표 거부, 최소 학습 수, 확률·계수 범위, 상관 규칙의 결과 비의존성 테스트.
- 사후 공식 판정으로 과거 학습 행을 선택하거나 정답을 수정하지 않는다.
- 운영 적용이나 승자 자동 선택 없음. 이번 결과는 추가 조정의 개선 실패도 그대로 보존한다.

후속 검증은 더 많은 독립 날짜와 사전 시점이 확인된 자료에서 같은 규칙을 고정해 진행해야 한다. 현재 109경기에 다시 임곗값을 맞춰 얻은 최고값을 새 검증 성과로 제시하지 않는다.
