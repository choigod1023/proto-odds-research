# M0·M1 오류 구간 감사 (2026-11-04)

이미 반복 열람한 2026 KBO 자료의 회고적 기술 분석이다. 경기 전 원천·가격 수신과 실제 거래는 입증되지 않았고 독립 블라인드 평가가 아니다. 운영 선택은 픽스터 투표이고 M0는 연구 대조군이다. 어떤 수치도 인과 효과, 미래 수익 또는 운영 성과를 뜻하지 않는다. 새로운 후보 탐색·재학습·수집은 하지 않았다.

## 입력과 연결

기존 `experiments/m1-service-20261104/replay/service-replay.json`의 667행을 외부 `kbtmodel/experiments/kbo-actual-training-20261103/inputs/paired-test-actual.jsonl.gz`, `evaluation-inputs/test-labels.jsonl.gz`에 fixture ID로 연결했다. 동결 `research/m1_service/frozen-models.json`의 M1 학습 선수 사전으로 unknown을 판별했다. 각 파일 SHA-256은 `results.json`에 기록했다. 중복·누락 ID, 날짜, 점수 승자, 종료 상태와 정산액, 기존 재생의 전체 및 103/564 부분집합 합계를 검증했다. 라벨의 정산 규칙은 313/667(46.93%)에서 비어 있어 라벨만으로 정산 규칙을 검증할 수 없다. 환급과 가격은 기존 replay의 2-way 무승부 환급 재생 규칙을 사용했고, 라벨에 기록된 다른 규칙은 거부한다. 실제 경기 전 수신을 검증한 것은 아니다.

모두 동일한 경기 결과를 사용한다. M0_actual은 실제 타순 학습 M0, M0_projected와 M1_projected는 예상 명단 학습 계수다. 세 모델 모두 이 replay에서는 보관된 실제 타순·선발을 평가 입력으로 사용한다. 이름의 projected는 학습 조합이며 경기 전 예상 명단을 입력했다는 뜻이 아니다. 학습 계수와 선수효과가 함께 달라 M0_actual과 M1의 차이를 선수효과만의 효과로 분리할 수 없다. M0_projected도 함께 보여준다.

## 입력 결측과 표본 구성

- 구장 667/667(100%) 결측이다. 원본 어댑터가 구장 변수를 항상 None으로 처리한다. 불펜은 전부 None이 아니다: 홈 41/667(6.15%), 원정 37/667(5.55%), 양쪽 모두 23경기, 한쪽만 32경기 결측이다. 불펜은 아웃 수 대용치이며 일정 포괄성은 검증되지 않았다.
- 타선 집계 지표는 양쪽 모두 0/667 결측이지만 개별 타자 이력까지 완전하다는 뜻은 아니다. 선발 지표는 홈·원정 각각 16/667(2.40%), 양쪽 모두 3경기, 한쪽만 26경기 결측이다. 양쪽 선발 지표가 있는 638경기의 M0_actual/M0_projected/M1 오류는 248/260/292다. 집계 지표 결측과 선수 ID unknown은 서로 다르다.
- M1 학습 사전에 없는 타자는 919/12,006 명단 슬롯(7.65%), 선발은 426/1,334 슬롯(31.93%)이다. 명단/선발 ID 자체는 전부 존재한다. 적어도 한 명 unknown인 경기는 613건(91.90%), 모두 사전에 있는 경기는 54건이다. 해당 구간의 M0_actual/M1 오류는 각각 231/280, 26/25다. 중복 선수가 여러 경기에 등장하므로 고유 선수 수가 아니다. unknown 효과는 중립 계수 및 표시 변수를 사용하며 이것이 성과 차이의 원인이라고 판단할 수 없다.
- 휴식 100일 이상이 양쪽 중 하나라도 있는 경기는 5/667(0.75%), 모두 3월 28일 개막 경기이며 10개 팀 측 값은 147~178일이다. 이 5건의 M0_actual/M0_projected/M1 오류는 3/4/4다. 시즌 사이 달력 간격이 포함된 값이므로 일반적인 경기 간 휴식과 같은 의미로 해석하지 않는다. 휴식 0~1일 구간 612건, 2~99일 구간 50건이다.
- 제공된 평가 입력에서 팀별 보존 이력은 1,334/1,334 측 모두 10경기, 타자 이력은 12,006 슬롯 중 11,801개가 10경기, 17개가 0경기다. 이 자료에 30경기 전체가 보존되어 있지는 않다. 따라서 요청한 history30 모집단에서 누락된 경기와 그 편향 크기를 이 세 입력만으로 복원할 수 없다. 10경기 요약은 최근성·보존·선발된 명단에 조건부인 표본이며 전체 선수·전체 경기의 대표성을 보장하지 않는다.
- 보존 이력 중 이전 시즌 기록 비율은 팀 550/13,340(4.12%), 타자 6,804/118,966(5.72%)이다. 선택 103건에서는 팀 232/2,060(11.26%), 타자 2,310/18,159(12.72%); 나머지 564건에서는 팀 318/11,280(2.82%), 타자 4,494/100,807(4.46%)다. 선택 표본의 시간 구성이 다를 가능성을 보여주지만 원인이나 history30 전체의 누락률을 증명하지 않는다.

## 기존 연구와 중복 모델

- `kbeffects/experiments/kbo-player-effects-20261103/REPORT.md`, `contract.json`: 동일 M0 집계 Poisson, M1 선수 역할 Poisson, M2 선수 역할 3-way와 기존 동결 참조. 예상 명단으로 학습하고 2025년 규칙에서 M2를 선정했다. M1은 추가 비교 후보이며 동일 계열을 새 모델로 중복 제안하지 않는다.
- `kbtmodel/experiments/kbo-actual-training-20261103/REPORT.md`, `contract.json`: 동일 경기에서 실제/예상 명단 학습 M0와 M2, 기존 전체 학습 M0/M2를 비교한다. 기존 전체 학습 모델과 매칭 학습 모델은 학습 경기 수가 다르다.
- 현재 작업 트리 `experiments/m1-contract-audit-20261104/REPORT.md`, `experiments/m1-service-20261104/REPORT.md`: 동결 방정식·결측 변환 감사와 동일 709 예측/667 가격 재생. 이 감사는 그 결과를 구간별 재집계한 것이며 독립 실험이 아니다.
- `kbtmodel/findings/라인업타선.md`, `선발투수.md`, `파크팩터.md`, `타선무용.md`는 관련 기존 주제다. 연구 범위·표본이 같다고 단정하지 않는다.

## 재현

```powershell
python scripts/audit_m0_error_slices.py --replay experiments/m1-service-20261104/replay/service-replay.json --features C:/Users/user/Documents/Codex/kbtmodel/experiments/kbo-actual-training-20261103/inputs/paired-test-actual.jsonl.gz --labels C:/Users/user/Documents/Codex/kbtmodel/experiments/kbo-actual-training-20261103/evaluation-inputs/test-labels.jsonl.gz --models research/m1_service/frozen-models.json --output experiments/m0-error-slices-20261104/results.json
python -m pytest tests/test_m0_error_slices.py tests/test_m1_frozen_contract_audit.py tests/test_m1_service_runtime.py -q
```

입력 파일이 같은 SHA인 별도 위치에 있으면 인자만 바꿔 실행한다. 결과는 정렬된 JSON이며 시간·네트워크에 의존하지 않는다. 전체 모집단·원시 history30 및 미선택 경기의 데이터는 연결하지 않았으므로 원천 수집 편향이나 보존 이전 누락률은 계산하지 않았다.
