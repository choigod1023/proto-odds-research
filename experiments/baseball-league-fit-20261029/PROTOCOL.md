# 리그별 야구 변수·산정식 비교 — 실행 규칙

- KBO·NPB·MLB 각각 따로 계수와 득점 분산을 적합한다. 시장 및 시장90:픽스터10, 투표 단독과 같은 #402 회고 공통 경기를 비교한다. 새 독립 홀드아웃이 아니다.
- 2023 학습→2024 검증으로 모형/변수/윈도/가중치 후보를 선택한다. 2025 평가 경기는 ≤2024 재적합, 2026 평가 경기는 ≤2025 재적합한 계수를 쓴다. 피처의 상태는 날짜 순서로 갱신하며 같은 날 결과는 모든 예측 입력을 만든 뒤 반영한다.
- 후보: 포아송/음이항 × core(과거 팀 득실)/schedule(휴식·최근3일 경기)/rotation(과거 로테이션 추정 선발의 팀실점 대용치). KBO만 rich(이전 투수 이닝·K-BB·불펜 이닝, 예상타순 출루 대용치·log5 대용치)를 추가한다.
- 각 후보에서 최근 20/60경기, 학습 반감기 무가중/90/180일을 고정해 모두 공개한다. ridge=0.03, 음이항 logshape 사전 중심5/penalty0.001. 예측 평균 득점은 0.14~15로 제한한다.
- 2024 적중률 최대(동률 Brier→이름)와 Brier 최소(동률 적중률→이름)를 별도 선택한다. 2024 경기 전 픽스터가 없으므로 9:1의 역사적 동결 모형을 학습/검증했다고 주장하지 않는다. 2025/26 평가 결과로 후보를 고르지 않는다.
- 현재 경기의 실제 선발 이름·당일 개인/팀 성적을 primary 입력으로 사용하지 않는다. 선발은 과거10회 팀 선발 중 과거 등판 사이 달력 간격에 가까운 후보를 추정한다. 30일 넘게 낡으면 결측 처리한다. 규정/보장된 로테이션이 아닌 실험용 규칙이다.
- KBO 예상 타순은 이전 3개의 확보된 타순에서 추정한다. HBP·SF·좌우손·진루 기록이 없어 출루율/log5는 대용치이며 정식 OBP·Bayesian log5·Markov 모형 완성이라고 부르지 않는다. 14일 넘게 낡은 상세 피처는 중립값과 결측 표시로 복귀한다.
- 원시 선발 파일의 9회 미만/빈 상태는 결과 이력으로 직접 쓰지 않는다. 공식 결과/정산된 보존 프로토 결과를 우선하고, 모호한 같은 날 팀 조합과 점수 충돌은 제외·집계한다. MLB 공식 UTC 시작 시각은 KST 경기일로 변환한다.
- 단폴 동일 금액, 월 손실/이익/주간 횟수/확률·배당 문턱 없이 모든 공통 경기 ROI를 계산한다. draw 환급은 적중률 분모에서 제외하고 손익0으로 분리한다. 운영 자금 규칙과 실매수는 변경하지 않는다.
- 각 순수 모형과 시장90:모형10, 기존9:1의90:모형10을 구분한다. 선택된 정책의 불확실성은 관측 주 단위 paired bootstrap으로 표시한다.
- 실패 분석: 시장 반대 픽, 박빙/대승(사후 설명용), 결측/낡은 상세, 추정 선발과 실제 등판자의 차이, 확률 구간별 보정, 득점 분포 적합을 분리한다. 사후 결과별 그룹을 새 추천 규칙으로 사용하지 않는다.
- 운영 코드·DB·추천·배포는 변경하지 않는다. 학습 데이터·원문·구매 가능 배당의 사전 관측 인증 부족과 반복 연구 표본임을 밝힌다.

실행 중 감사 후 수정한 항목(사전 등록 실험으로 표현하지 않음):

- 처음에는 KBO/MLB5일·NPB6일을 가정했다. 2023 이력에서 KBO·MLB 실제 등판 간격 최빈값은 6일이었다. 고정 로테이션 수와 달력 간격을 혼동하지 않도록 **해당 시점 이전** 리그의 최근 500개 재등판 간격(3~14일)의 중앙값으로 바꿨다. 20개 미만일 때만 초기 가정을 쓴다. 평가 경기의 실제 선발로 간격을 맞추지 않는다.
- MLB 중단/재개 15경기가 원래 날짜와 재개 날짜에 같은 gamePk·최종 점수로 나왔다. 해당 ID는 두 날짜 모두 제외한다. 처음 날짜에 미래의 최종 결과를 붙이거나 중복 집계하지 않는다.
- NPB 2023 선발 이름이 전부 비어 있었다. rotation 12개 후보는 계산은 공개하되 선택 자격을 주지 않는다. 학습에서 관측하지 못한 변수를 2024로 검증했다고 주장하지 않는다.
- 위 수정과 후보 탐색 자체도 이미 결과를 살펴본 회고 연구다. 이후 새 기간의 사전 동결 검증이 필요하다.
