# 픽스터 과거 복원 시뮬레이션 (2026-10-25)

사용자 요청에 따라 엄격한 전향 검증과 별개로 가정을 명시한 과거 모의 계산을 실행했다.
기준 결과는 `results-v2.json`이다. 운영 DB·원장·모델·월 손실 정책은 변경하지 않았다.

## 범위와 복원 가정

- 로컬 TailSlips 로그 58,995행. 후보 경기일 2026-08-29~09-04,
  마지막 결과 관측 2026-09-05 07:04:06 UTC. 완전한 한 달이나 여러 시즌이 아니다.
- 사전 최초 미판정/미시작, 단폴, 표기상 MLB 팀 코드, 정규 ML, 원래 배당,
  원문 ET 시작 시각 기준 T-30 이전이라는 조건으로 458개 후보를 얻었다.
- 끝의 투자 단위 `5u` 같은 표시만 없애고 날짜·대진·작성자·선택·배당이 같은
  사후 기록을 연결했다. 과거 배당을 결과 화면에서 보충하지 않았다.
- 380개 후보에 게시자 결과가 연결됐다. 72개 미연결, 6개 과거 결과 혼재는
  미판정으로 유지했다. 공식 결과 독립 확인은 하지 않았다.
- 단폴 기술통계에서는 같은 날짜/대진에 시작 시각이 여러 개인 16개를 추가 제외:
  71개 대진에 대한 364개 작성자 픽, 170개 적중, 적중률 46.70%, 단위 투자 ROI -9.43%.
  같은 경기에 여러 픽이 있으므로 364개 독립 경기가 아니다.
- 2폴 선택에서는 미래에 발견된 시각 충돌로 과거 선택을 바꾸지 않는다.
  당시까지 알려진 일정 충돌만 제외하고 미판정 후보도 선택 대상에 남겼다.

## 비교 정책 (우리 운영 모델 비교가 아님)

매일 미국 동부 정오에 그 시점까지 관측한 같은 날의 경기 중 2개를 선택한다.
같은 경기/작성자 의견은 가장 먼저 관측한 하나만 사용한다.

1. 낮은 배당 우선 대조군: 공개 픽 후보에서 낮은 배당 쪽을 선택하고 낮은 배당순으로
   서로 다른 2경기를 묶는다. 전체 북메이커 시장의 최저 배당 전략이 아니다.
2. 픽스터 다수결: 한 경기에서 3명 이상, 동률 제외. 지지 비율→지지자 수→낮은 배당
   순으로 2경기를 묶는다. 지지 비율을 적중 확률이라고 간주하지 않았다.

선택한 팀의 배당은 당시 최초 관측 인용값이며 사후 최고 배당을 고르지 않는다.
해외 배당을 원화 모의 운용에 적용한 가정이며 국내 프로토 구매 가능 여부/회차는 미확인이다.
배당 하한·55% 기준은 이 외부 의견 실험에 적용하지 않았다(보정 확률이 없기 때문).

## 2폴 모의 결과

회당 10,000원, 주 최대 2회/3회, 하루 최대 한 장, 같은 대진 재사용 금지.
월 손실 한도 50,000원. 월/주는 KST 매수 시점으로 분류한다.
미정산 모든 투자금을 먼저 예약하고 +50,000원 수익 도달 중단은 적용하지 않았다.
양쪽 적중이면 기존 계산 규칙(곱을 소수 둘째 자리 버림 후 첫째 자리 올림),
실패 하나면 반환 0, 무효 leg는 1배 처리한다. 게시자 결과를 처음 관측한 시각에 정산한다.

- 낮은 배당 우선·주 2회: 3장, 30,000원 투자, 순손익 **-7,000원**, ROI **-23.33%**.
- 낮은 배당 우선·주 3회: 4장, 40,000원 투자, 순손익 **-17,000원**, ROI **-42.50%**.
- 다수결·주 2회: 3장, 순손익 **-30,000원**, ROI **-100%**.
- 다수결·주 3회: 4장, 순손익 **-40,000원**, ROI **-100%**.

기본 조건에서 미정산 조합은 0장이다. 8월·9월 모두 일부 날짜만 포함하므로
월간 수익 추정으로 읽으면 안 된다. 단위 투자 단폴 수익과 월 한도 2폴 수익은 다르다.

## 선택 시각 민감도 (주 3회)

결과를 보고 최적 시간을 운영에 선택하지 않았다. 정오와 별도로 10시/14시를 비교했다.

- 10시 ET 낮은 배당: 5장, +2,000원, ROI +4.0%.
- 10시 ET 다수결: 1장, -10,000원, ROI -100%.
- 14시 ET 낮은 배당: 4장 중 3장 정산, 정산 손익 -6,000원,
  미정산 10,000원. 정산분 ROI -20.0%, 미정산 전액 손실이면 총 -16,000원.
- 14시 ET 다수결: 4장, +31,000원, ROI +77.5%.

특정 조건 +77.5%는 4장뿐이며, 같은 전략이 정오에는 -100%였다.
시간마다 정보량/선택 경기/가능한 베팅 횟수도 달라져 순수 시간 효과는 아니다.
이 수치를 미래 기대수익률 또는 모델 개선 증거로 승격하지 않는다.

## 결론과 남은 검증

시뮬레이션 자체는 가능했고 실행했다. 다만 이 표본에서 단순 다수결이 안정적으로
우월하다는 근거는 없다. 실제 기존 모델·근거 추가·픽스터 추가의 동일 경기 비교는
아직 아니다. 세 모델의 사전 확률과 공식 결과/실행 가능 배당이 없어 그 차이는 null이다.
복원 가정, 짧은 기간, 상관된 픽, 표본 누락, 공식 경기 매핑 부재를 감안해야 한다.
모든 티켓의 선택 시각·팀·배당·손익은 results-v2.json에 보존했다.

재현:
```powershell
python scripts/replay_tipster_opinions.py --input data/raw/picksters/tailslips_pick_events.jsonl --output new-results.json
python -m pytest tests/test_tipster_replay.py -q
```

회귀 검증은 원래 배당 유지, 결과 미상 후보 유지, 미래 의견/일정 영향 차단,
작성자 중복, 월 손실 및 미정산 예산, 주간 횟수, 무효/실패/배당 올림을 포함한다.

실행 검증: 신규 회귀 10개 통과. 전체 Python 1,349 passed / 2 skipped /
67 subtests passed. 8개 시나리오의 티켓 손익 합계·서로 다른 경기·예약 예산을
출력 JSON으로 다시 검사했다. 운영 및 웹 소스 변경은 없어 웹 빌드는 실행하지 않았다.
