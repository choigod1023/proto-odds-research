# 픽스터 단독과 시장 9:1: 다른 출처·기간 비교

목표는 흑자 보장이 아니라 손실 감소와 안정성이다. 후보 비중이나 배당 필터는 이번 결과에 맞춰 튜닝하지 않았다. 운영 모델을 변경하지 않았다.

## 현재 결과의 해석

한 후보가 출처·기간을 가리지 않고 더 안정적이라고 확정할 수 없다. 기존 표본에서는 거의 동률이었고, 다른 출처에서는 순위가 반대로 나왔다. 기존 표본의 1,500원 차이만으로 픽스터 단독을 운영 기본값으로 선택할 근거는 부족하다.

## 고정한 모의 운용 규칙

- 장당 1만 원 단폴. 전체 종목 합산 월 순손실 하한 −5만 원.
- 같은 날의 미정산 베팅은 전액 손실 가능액을 먼저 예약. 다음 날 정산 가정.
- 경기 시작 시각, 동일 시각이면 경기 식별자 순서. 주간 횟수 제한·흑자 중단 없음.
- 픽스터 단독은 명시 추천 방향. 시장 9:1은 Shin 마진 제거 시장 확률 90% + 픽스터 one-hot 10%, 소수 넷째 자리 반올림 후 가장 높은 확률 선택.
- 사이트별 비교는 각각 별도의 가상 운용이다. 여러 사이트를 동시에 운용하며 각자 5만 원씩 손실을 허용한 것이 아니다.
- 총손익/월손익/일말 최대 낙폭을 구분한다. 월 순손실 하한이 5만 원이어도 여러 달 누적 손실이나 수익 최고점 대비 낙폭은 5만 원을 넘을 수 있다.

## 다른 사이트 추가 기간 및 최종 합산

초기 비교 후 결과에 맞춘 비중 변경 없이 8월 1~14일과 9월 1~14일을 추가 대상 기간으로 고정했다. 공개 사이트맵 순서로 원문 200건을 검사했고 상한에서 종료했다. 실제 확보는 **9월 1~14일 MLB 80경기**이며, 8월은 미수집이다. 전체 기간 전수조사가 아니다.

9월 80경기의 월 한도 손익은 픽스터 단독 −47,600원, 시장 9:1 −45,300원이다. 앞서 중간 관측 79경기는 9월 1일 경기가 빠져 있어 −41,600원/−44,600원이었으나, 최종 원장에는 뒤늦게 확보한 1일 경기를 포함해 시작부터 다시 계산했다. 최종 결과는 80경기 기준이다. 이는 월 한도 재생이 초기 베팅과 자료 누락에 민감하다는 사례다.

- 시장 9:1이 **47,600원, 약 81.6% 손실을 줄였다**. 낙폭도 28,000원 작았다. 하지만 월손익 표준편차는 31,703원 대 36,159원으로 시장 9:1 쪽이 더 컸다. 모든 안정성 지표가 좋아진 것은 아니다.

## 연결과 품질 검사

날짜·리그·팀·가능한 경우 원문 시작 시각으로 공식 경기를 먼저 식별했다. 이후 게시 시각과 명시 추천, 과거 승패 배당의 유일성, 공식 최종 점수 일치를 확인했다. 점수로 경기 정체성을 고르지 않았다. 잘못된 원문 해시, 모호한 승패/핸디캡/언더오버, 경기 후 게시 또는 확인되는 경기 후 수정은 제외한다.

2024 KBL/KOVO 공식 결과 550건, EPL 372건을 확보했다. KOVO 8건은 시간·세트 점수 등이 유효하지 않아 원문 증거를 보존하고 제외했다. 공식 API의 최종 세트 스코어와 개별 세트 스코어가 다른 사례도 있었으므로 임의 보정하지 않았다.

PickDawgz와 WSTV 본문의 동일 날짜 문자 12-gram Jaccard 0.5 이상 복제 후보는 초기 67건에서 0이다. 영어와 한국어의 번역 복제 여부는 이 검사로 알 수 없고, 작성자 계정의 독립성도 증명하지 못했다.

일반 수집 요청 기준 Goli/ATTV/named/liveman은 연결 실패, 일부 다른 사이트는 403이었다. 제한을 우회하지 않았다. Goli는 별도 웹 도구로 2026년 원문 2건을 열었으나, 비교할 과거 날짜 표본을 확보하지 못했다. 이것을 사이트 전체 접근 불가로 표현하지 않는다.

## 한계와 운영 판단

표시 게시일·수정일은 라이브 페이지의 자기 신고이고, 경기 전에 보관한 수정 불가 원본이 아니다. 엄격한 사전 시점 인증 표본은 0이다. 배당은 실제 과거 프로토 기록이지만 정확한 호가 관측 시각·구매 가능 시점·실제 정산 순서는 미검증이다. 따라서 실현 가능한 미래 기대수익이나 사용자의 실제 수익을 보장하는 결과가 아니다.

출처 간 종목과 시기가 다르므로 WSTV 농구·배구와 PickDawgz 야구의 차이를 오직 사이트 효과로 해석해서도 안 된다. 이번 실험은 픽스터 단독 채택의 확증이 아니라 출처·기간에 따라 후보 순위가 바뀐다는 반증이다. 결과를 보고 종목별 승자를 조합한 정책은 별도 미검증 정책이 된다.

## 실행 검증

Python 전체 테스트 **1,496개 통과, 2개 건너뜀, 74 subtests 통과**. 별도 검산에서 최종 147경기의 원문/해시/추천 방향/혼합 벡터/선택/월 한도 원장 불일치 0건, 입력 해시 7/7 일치, 중복 플래그 오류 0건이었다. 신뢰구간은 관측 월 6개 미만이면 산출하지 않는다. 결과는 연구 기록이며 병합이나 운영 배포를 수행하지 않았다.

입력 파일의 SHA256은 각 결과 JSON의 `input_hashes`에서 확인한다. `--games`, `--aliases`, `--previous`, `--articles`, `--official`, 선택 `--reference-articles`, `--output` 인자로 재실행한다. 기본 원본 배당은 `accuracy-formula-lab/data/processed/games.csv`다.
