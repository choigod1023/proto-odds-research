# 다른 출처·기간 손실 안정성 비교

후보는 픽스터 단독과 시장 90%·픽스터 10%로 고정한다. 비중·배당 필터·픽 선정 기준을 결과에 맞춰 변경하지 않는다. 시장확률은 기존 Shin 마진 제거 방식이고 혼합 확률은 소수 넷째 자리 반올림 후 argmax다.

장당 1만 원 단폴, 전체 종목 합산 월 순손실 5만 원 제한. 같은 날 미정산 베팅의 최대 손실을 먼저 예약하고 다음 날 정산한다고 가정한다. 주간 횟수 제한과 수익 목표 중단은 적용하지 않는다. 실제 구매 시각·정산 시각이 확인되지 않아 가상 재생이다.

다른 출처에서 신규 수집한 원문, 2024년 기간, 기존 2025년 표본의 상·하반기 민감도를 분리한다. 같은 경기의 다른 출처는 신규 경기라고 세지 않는다. 원문 복제·동일 작성자·시각 증명 부족을 따로 기록한다. 다른 사이트라도 같은 글이면 독립 검증이 아니다.

공식 경기 날짜·팀으로 먼저 연결하고, 추천 방향을 명시적으로 파싱하며, 당시 배당과 공식 점수의 일치를 확인한다. 누락·모호·게시일 미확인은 제외하고 사유를 보존한다. 결과를 보고 경기를 고르지 않는다. 과거 게시일은 표시 날짜이지 수정 불가 사전 관측 증명이 아니다.

주요 비교: 총손익, 월 평균/중앙값/표준편차, 손실 월 수, 최악 월, 월 손실 4만 원 이상 빈도, 일별 누적 최대 낙폭. 월 손실 한도 없는 동일 경기 비교도 병기해 한도 때문에 베팅 대상이 달라지는 효과를 분리한다. 월 단위 paired bootstrap은 기술적 불확실성 지표일 뿐 독립 검증 성공의 기준으로 사용하지 않는다. 표본이 짧으면 승자를 확정하지 않는다.

운영 모델·서버·자동 베팅은 변경하지 않는다. 원문은 로컬 캐시에만 저장하고 결과에는 출처·해시·추천과 조인 근거를 남긴다.
