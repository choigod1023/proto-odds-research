# NBA 득점 구성 모델과 슛 위치 검증

사용자 요청은 득점 구성 모델을 실제 구현하고 슛 위치 검증을 별도 워커로 병렬 수행한 뒤, 기존 모델·시장 기준을 같은 경기·배당으로 여러 기간에서 비교하는 것이다. 이번 실행 범위는 보존 ESPN 자료를 이용한 **NBA 양방향 승패**다. KBL이나 다른 종목, 언더오버·핸디캡으로 확대 검증했다고 주장하지 않는다.

실제 모델 구현·학습·평가를 실행했으며 전체 1,260행을 총괄이 독립 검산했다. 결론은 **시장 대비 두 기간의 ROI 손실은 줄었지만, 2026년 적중률과 확률 점수는 악화했고 기존 전적 모델보다도 나빴다**는 것이다. 적중률·ROI가 함께 안정적으로 좋아진 모델이라는 근거는 없다. 운영 교체·병합·배포는 하지 않았다.

## 작업과 근거

- 득점 구성 모델: [PR #670](https://github.com/choigod1023/proto-odds-research/pull/670), `codex/nba-score-components-20261108`. 사전 규약 `9820e1f2`를 후보 성적 계산 전에 커밋했다.
- 슛 위치 원문 검증: [PR #669](https://github.com/choigod1023/proto-odds-research/pull/669), `codex/nba-shot-location-audit-20261108`.
- 총괄 독립 검산: `codex/score-components-orchestrator-20261108`. `scripts/audit_nba_components_comparison.py`, `scripts/check_nba_components_pgf.py`.
- 원문은 기존 [PR #668](https://github.com/choigod1023/proto-odds-research/pull/668)의 2026-11-08 수신 보존본을 읽기 전용으로 사용했다. 이번 연구에서 새 HTTP 수집은 하지 않았다. 400개 날짜별 일정, 2,357개의 상세 HTTP 200 응답과 8개의 HTTP 404 응답이다. 404 본문도 실제로 보존돼 있으며 8개 모두 해시가 일치했다.
- 가격은 `experiments/all-sports-underdog-20261031/inputs/domestic.jsonl.gz`의 기존 NBA 행이다. 한국어 팀명 원본을 손상으로 오인하거나 결과로 별칭을 추측하지 않았다.

비교자는 시장의 정규화된 양방향 확률, PR #668의 동결 순효율 확률, 같은 연구의 동결 `outcome_form` 전적 확률이다. 기존 운영 픽스터 투표·운영 M0 원장을 재생한 비교가 아니다. 총괄 감사는 기존 확률·팀·경기 ID·점수·가격 벡터·최근 10경기 ID가 바뀌지 않았는지 확인했다. 비교 표본은 A 487행, B 773행 모두 유지돼 추가 제외는 0이다.

## 실제 만든 모델

팀 순효율 한 수치를 시장 승률에 더하는 대신, 2점·3점·자유투 시도율과 성공률을 분리했다. 상대 수비의 허용률도 함께 사용한다. 표본이 작은 팀별 성공률은 학습 구간 리그 평균으로 수축했다.

- 과거 노출량 대리값은 `P = FGA − ORB + TOV + 0.44 × FTA`다. 정확한 공식 포제션이라고 부르지 않는다.
- 양 팀의 실제 최근 10경기에서 공격·상대 공격의 평균 노출량을 계산하고 두 팀 값의 기하평균을 공유 노출량으로 사용했다. 공격 리바운드·턴오버는 이 노출량에 이미 들어가므로 별도로 득점에 가산하지 않는다.
- 시도율은 500 노출, 성공률은 200 시도의 고정 사전 강도로 리그 평균에 수축했다. 공격률×상대 허용률÷리그 평균으로 결합하고 사전 지정 범위로 제한했다. 이 상수는 평가 결과로 고르지 않았다.
- 성공 2점슛·3점슛·자유투 수를 각각 평균 `λ2`, `λ3`, `λ1`의 독립 포아송으로 두고 점수 `S = 2M2 + 3M3 + M1`을 생성했다. 시도 수의 포아송 분포와 성공의 이항 분포를 합친 근사다.
- 점수 분포를 수치 합성해 `P(홈 점수 > 원정 점수) + 0.5 × P(동점)`을 계산했다. 동점의 절반 배분은 실제 연장 전력을 추정한 모형이 아니라 사전에 정한 대칭 근사다. 대상 경기에서 실제 연장이 있었는지는 입력에 쓰지 않았다.
- 이번 후보는 G 하나이며 시장 혼합·배당별 필터·사후 최적화는 추가하지 않았다. 공격 기회·슛 종류의 물리적 전이를 완전히 식별한 모형도 아니다. 득점 구성별 기대값을 갖춘 근사 확률모형이다.

실제 슈팅 결과의 확률 분포를 사용하므로 몬테카를로 시뮬레이션 잡음은 없다. 관측 경기의 점수와 `2×2PM+3×3PM+FTM` 관계도 검사했다. 새 예측의 선택·확률 필드는 기존 순효율 모델의 보존 선택과 구분했다. 압축 예측은 결정적 방식으로 저장한다.

## 시간 분할과 비교 규칙

모든 특징은 대상 경기보다 최소 4일 이전의 실제 최근 10경기다. 최근 경기의 박스가 없으면 해당 예측을 제외하며 11번째 과거 경기로 메우지 않는다. 학습용 리그 평균도 구간별 마감일까지만 계산했다.

- A: 2025-01-01~08-28 자료로 사전 평균을 계산하고, 평가 계획 2025-09-01~12-31 중 실제 가격이 연결된 **2025-10-22~12-31, 487경기**를 평가했다.
- B: 2025-12-28까지 다시 계산한 평균을 고정하고, 평가 계획 2026-01-01~10-27 중 실제 연결된 **2026-01-01~05-04, 773경기**를 평가했다.
- 기존 2026 가격은 804행이며 6월 14일까지 있었다. 최근 상세 이력 부족 31행을 제외한 기존 773행에 새 후보도 전부 계산됐다. 없는 후반기 가격을 채우지 않았다.

각 모델은 정확히 같은 경기의 같은 홈·원정 가격 벡터에서 더 높은 확률의 쪽을 선택했다. 확률 동률은 홈이다. 서로 다른 쪽을 고르면 선택 배당도 달라진다. 모든 경기에 1단위를 가정했으며 월 지갑이나 실제 구매 금액은 바꾸지 않았다. 취소·무효 규칙이 확인되지 않은 다른 상품은 섞지 않았다.

2025·2026 자료는 이전 연구에서 이미 열람했다. 학습 기간 밖에서 계산한 회고 성적이며, 새로운 블라인드·전향 검증이라고 부르지 않는다.

## A 결과: 2025년 후반 487경기

- 시장: **316/487, 64.89%**, ROI **−17.09%**, 평균 선택 배당 1.318, 로그손실 0.61327, 일 마감 MDD 84.00단위.
- 기존 순효율: **316/487, 64.89%**, ROI **−17.07%**, 평균 배당 1.319, 로그손실 0.61307, MDD 83.91단위.
- 기존 전적: **310/487, 63.66%**, ROI **−13.17%**, 평균 배당 1.443, 로그손실 0.65369, MDD 64.81단위.
- 새 득점 구성 G: **316/487, 64.89%**, ROI **−7.32%**, 평균 배당 1.523, 로그손실 0.63903, MDD 35.65단위.

G는 시장 대비 적중률 변화 없이 ROI가 **+9.77%p** 나아졌다. 날짜 단위 paired bootstrap 2,000회(seed 20261108)의 명목 95% 구간은 ROI **+2.08~+17.71%p**, 적중률 **−4.27~+4.29%p**다. 전체 연구의 다중 비교·반복 열람을 보정한 확증 결과는 아니다. 로그손실은 시장보다 나빴다.

시장과 다른 112경기에서 G와 시장은 각각 56경기씩 맞혔다. 이 변경 구간에서 G의 평균 배당은 2.340, 시장은 1.448이었다. 따라서 같은 적중 개수라도 손익이 달랐다. **변경 구간만 골라 운용하자는 규칙을 검증한 것은 아니다.** 전체 성적이 기준이다.

## B 결과: 2026년 773경기

- 시장: **547/773, 70.76%**, ROI **−11.60%**, 평균 배당 1.293, 로그손실 0.55766, 일 마감 MDD 89.82단위.
- 기존 순효율: **546/773, 70.63%**, ROI **−11.81%**, 평균 배당 1.293, 로그손실 0.55658, MDD 91.48단위.
- 기존 전적: **537/773, 69.47%**, ROI **−6.86%**, 평균 배당 1.450, 로그손실 0.59679, MDD 59.33단위.
- 새 G: **508/773, 65.72%**, ROI **−8.88%**, 평균 배당 1.569, 로그손실 0.62935, MDD 71.56단위.

G는 시장 대비 ROI 손실이 **2.71%p** 줄었지만 적중률은 **5.05%p** 낮아졌다. ROI 차이의 명목 95% 구간은 **−4.73~+10.24%p**, 적중률 차이는 **−8.90~−1.19%p**다. 기존 전적 모델에 대해서도 적중률 **−3.75%p**, ROI **−2.02%p**로 나빴다. 로그손실·Brier 역시 시장과 기존 두 모델보다 나빴다.

시장과 다른 방향을 고른 201경기에서 G는 81/201(40.30%), 시장은 120/201(59.70%)을 맞혔다. G의 평균 선택 배당은 2.481로 시장 1.421보다 높았다. 다른 선택이 손실을 줄이는 경우는 있었지만 적중률을 높이는 데에는 실패했다. 원인이 홈 이점 누락, 득점 분산 가정, 슛 성공률 추정 중 어디인지 이 비교만으로 확정하지 않는다. 결과를 본 뒤 계수나 기간을 바꾸지 않았다.

두 기간의 월별 성적은 `independent-audit.json`에 전부 있다. 유리한 달만 남기거나 두 기간을 합산해 기간별 악화를 가리지 않았다. 모델 간 차이 구간은 `paired-comparisons.json`에 원 결과 해시와 함께 보존했다.

## 슛 위치 검증 결과

이 검증은 박스 통계만 쓰는 G와 독립적인 병렬 작업이다. 아래의 PBP 부적격 표본을 G의 박스가 부적격이라고 바꾸어 해석하면 안 된다. 슛 위치 모델 자체를 새로 학습하거나 ROI를 계산한 작업도 아니다.

- NBA 30개 팀의 경기 ID·홈/원정·시각을 대조한 상세 박스는 2,343경기다. 비NBA 팀 등의 14건은 제외했다.
- 야투 좌표는 418,021개, 명시적 피트 거리 문구는 306,042개에서 확인했다. 실패 슛의 `scoreValue=0`을 시도 점수로 쓰지 않도록 `pointsAttempted`와 성공 여부·설명을 구분했다.
- 좌표 `(x,y)`, 단위 배율 1, 골대 `(25,0)` 가설의 텍스트 거리 절대오차 중앙값은 **0.649ft**, 평균 **0.667ft**, 5ft 초과는 **0개**였다. 처음의 `(25,5.25)` 가설에서는 중앙값이 2.963ft였다. 공급자 좌표 원점과 NBA 코트의 물리적 바닥 원점을 혼동하지 않아야 한다.
- 이 결과는 공급자 내부 좌표와 설명 거리의 일치 증거다. ESPN 공식 좌표 정의·단위·방향을 인증한 것이 아니다. 원문 거리 없는 슛까지 같은 수준으로 검증한 것도 아니다. 코너3·림·중거리라는 확정 구역 입력은 보류하며, 가설별 거리와 예시는 별도 워커 자료에 남겼다.
- 4,686팀-경기 중 전체 FGA/FGM/3PA/3PM/FTA/FTM이 최종 팀 박스와 모두 일치한 것은 **3,505개**, 불일치는 **1,181개**다. 대부분 시도 수만 차이 나는 3점슛이며, 종료 시각 슛을 임의로 지워 숫자를 맞추지 않았다.
- 마지막 PBP 점수 불일치는 25경기, 기간별 점수 대조는 **4,675팀-경기 일치 / 11개 불일치·미확인**이었다. 점수 감소·개별 증분 충돌은 수정이나 순서 오류의 신호이며 원인 전체를 확정하지 않았다.
- 슛 분류·중복·최종/기간별 점수·팀 박스 등 모든 적격 조건을 통과한 것은 **3,044팀-경기**이며, **양 팀이 모두 통과한 실제 경기는 1,185경기**다. 두 분모를 혼동하지 않는다.
- 처음 404 본문을 없다고 표시했던 감사 경로를 `.unavailable.body`로 고쳐, 보존된 **8개 모두 해시 일치**를 확인했다. 이는 원본 손상이 아니라 감사 코드의 경로 오류였다.

최종 검증 요약과 원 결과 SHA는 `shot-location-summary.json`에 있다. 좌표 파일·실제 사후 출전시간을 대상 경기 사전 입력으로 소급하지 않는다. 슛 위치 정보를 더하면 적중률이 얼마나 올라가는지는 아직 측정하지 않았다.

## 독립 검산과 재현

총괄은 모델 코드를 불러오거나 적합하지 않고 다음을 실행했다.

1. `audit_nba_components_comparison.py`: 1,260행의 공통 표본·기존 확률·원래 가격·경기/이력 ID·점수를 대조한 뒤 Decimal 단위 손익·적중률·자연로그 손실·이항 Brier·일 마감 MDD·월별 결과를 다시 계산했다.
2. `check_nba_components_pgf.py`: 모든 상세 영수증 해시와 원문 박스를 직접 읽고 두 학습 구간의 사전 평균을 다시 계산했다. 원 구현의 포아송 합성 대신 확률생성함수 재귀 `p[k] = Σ(j×λj×p[k−j])/k`로 점수 분포를 만들었다. 1,260개 확률의 최대 오차는 **1.73×10⁻¹⁴ 미만**이었다. 25,200개 과거 경기 참조의 D−4 조건도 확인했다.

계산 일치는 이 근사모형을 구현대로 계산했다는 뜻이다. 모형의 현실 적합성이나 우월성을 입증하지 않는다. 과거 배당의 실제 수신·구매 가능 시각, 상품번호와 연장 포함 정산 규칙은 인증되지 않아 모든 ROI는 조건부 회고 1단위 손익이다. 이 가격을 미래 기대수익이나 실제 운용 지갑 성과로 표시하지 않는다.

```powershell
python -m pytest tests/test_nba_components_independent_audit.py tests/test_nba_components_pgf.py -q
python scripts/audit_nba_components_comparison.py --predictions <G예측gz> --baseline <PR668예측gz> --prices experiments/all-sports-underdog-20261031/inputs/domestic.jsonl.gz --output <독립감사.json>
```
