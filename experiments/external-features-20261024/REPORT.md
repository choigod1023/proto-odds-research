# 외부 경기 통계 추가 검증

2026-10-24 실행. 외부 자료는 실제 수집했지만, 이번 피처 구성에서는 개선되지 않았다. 운영 모델·추천·배포는 변경하지 않는다.

## 자료와 비교 기준

- EPL·분데스리가 2019/20~2025/26의 4,802경기. 결과와 점수 불일치 및 중복 제외 건수는 각각 0건.
- 2023/24, 2024/25, 2025/26을 각각 이전 시즌만 학습해 평가했다. 평가 표본은 시즌당 686경기, 총 2,058경기로 모든 모델에서 같다.
- 기존 모델의 시장 확률·Elo·pi·득점 차·최근 성적 구조를 외부 데이터에서 재학습한 기준선이다. 실제 웹에 저장된 사전 추천의 재현이나 운영 적중률 측정은 아니다.
- 추가 정보는 팀별 과거 10경기의 슈팅·유효슈팅·코너킥·퇴장 순차 통계다. 상대 팀과의 순 통계 차이를 계산했다. 현재 경기 및 하루 전 경기 통계는 사용하지 않는다.
- 팀별 유효 과거 기록이 3개 미만이면 결측으로 두고 학습 구간에서만 보정했다. 전체 4,802경기 중 추가 피처 일부가 결측인 행은 113개다.
- 시장 확률 offset을 둔 다항 로지스틱 모델, ridge 0.01, 시장 혼합비 75%를 결과 확인 전에 고정했다. 제공처의 Elo·Form·군집 지표는 사용하지 않았다.

## 실제 결과

동일 경기마다 가장 높은 확률의 승·무·패를 하나 고른 결과다. ROI는 제공된 배당으로 동일 금액을 걸었다고 가정한 단폴 회고 계산이다.

- 시장 확률만: 적중률 **53.89%**, ROI **-4.51%**.
- 기존 구조: 적중률 **54.18%**, ROI **-3.71%**.
- 시장+외부 통계: 적중률 **53.84%**, ROI **-4.58%**.
- 기존 구조+외부 통계: 적중률 **53.60%**, ROI **-5.11%**.
- 시장 75%+전체 모델 25%: 적중률 **53.94%**, ROI **-4.38%**.

기존 구조에 외부 통계를 더하면 적중률은 **0.58%p 하락**했다. 7관측일 단위 paired block bootstrap 2,000회의 차이 95% 구간은 **-1.23~0.00%p**다. 개선 근거가 없다. Brier도 0.573354에서 0.573662로 나빠졌다(낮을수록 좋음).

리그별 기존→추가 모델 적중률은 EPL **54.04→53.51%**, 분데스리가 **54.36→53.70%**다. 시즌별로는 2023/24 **57.29→56.85%**, 2024/25 **53.21→51.90%**, 2025/26 **52.04→52.04%**였다. 특정 리그의 개선을 전체 평균이 가린 결과도 아니다.

2폴 모의 운용에서도 양의 수익은 확인하지 못했다. 예상 EV가 양수인 서로 다른 경기 중 상위 2개, 하루 최대 1장·장당 1만원, 주 최대 2/3회, 미정산 최악 손실까지 예약해 월 -5만원을 제한했다. 다음 날 정산을 가정하며 실제 정산시각은 재현하지 않는다.

- 기존 구조: 주 최대 2회와 3회 모두 130장, 총 **-356,275원**, ROI **-27.41%**.
- 추가 모델: 주 최대 2회 168장, 총 **-392,010원**, ROI **-23.33%**. 주 최대 3회 179장, 총 **-330,921원**, ROI **-18.49%**.
- 위 금액은 **3개 평가 시즌 전체 합계**다. 각 경우 최악 월 손익은 -5만원이었다. 베팅 횟수·대상이 달라 ROI의 상대 개선만으로 정책을 승격하지 않는다. 시장 혼합 모델은 조건 충족 조합이 없어 0장이며 ROI는 계산 불가다.

## 수집 출처와 한계

통계 정의는 [Football-Data 공식 설명](https://football-data.co.uk/notes.txt)을 확인했다. 원본 다운로드가 TLS 연결 종료로 실패해, Football-Data 재배포라고 명시한 [Adam Gábor의 공개 자료](https://github.com/xgabora/Club-Football-Match-Data)를 사용했다.

- 고정 커밋: `25882a58a736daf7ece3781940eac17ae1117a66`.
- [수집 파일](https://raw.githubusercontent.com/xgabora/Club-Football-Match-Data/25882a58a736daf7ece3781940eac17ae1117a66/data/Matches.csv): 45,370,018바이트, 전체 238,858행에서 위 범위를 선택.
- 수집시각: `2026-10-24T00:48:36.335584+00:00`.
- SHA256: `ef224cf2c252f07a842b3bcfd4ba5c718c25cedd8937ffa174a74b86b5ba4221`.

원본과 재배포 파일의 바이트 일치는 검증하지 못했다. 배당은 Bet365로 설명되지만 개별 관측시각을 검증하지 못했으므로 경기 전 구매 가능한 수익률이라고 단정하지 않는다. 세금·구매 제한·실제 배당 반올림을 반영하지 않았다. 과거 통계도 수정 이력이 없는 당시 스냅샷은 아니므로 2일 지연 처리는 완전한 시점 증명이 아니다. 날짜는 원천의 경기일이며 정확한 UTC 킥오프라고 주장하지 않는다.

이번 결과는 두 유럽 축구 리그에 한정된다. 야구·배구·국내 프로토 추천이나 기존의 다른 표본 적중률과 직접 비교하지 않는다.
