# 외부 경기 통계 추가 실험

결과 확인 전 고정: Football-Data EPL(E0), Bundesliga(D1), 2019/20~2025/26.
과거 경기 슈팅, 유효슈팅, 코너킥, 퇴장 순차 통계 10경기 평균의 홈/원정 차이.
현재 경기 통계 및 C가 붙은 마감배당은 예측 입력에서 제외한다.
이전 경기 통계는 현재 날짜보다 최소 2일 앞선 경기만 사용한다.
동일 경기집합에서 시장, 시장+기존 팀 피처, 시장+외부 통계,
시장+기존+외부 통계, 시장/전체 모델 혼합(시장 75%)을 모두 비교한다.
기존 피처는 repo SPORT_FEATURES(sc)+Elo, 기존 고정 pi 설정.
모델은 다항 logistic, 시장 log probability offset, train-only 표준화,
ridge .01. 혼합비·윈도우는 test에서 고르지 않는다.
2023/24, 2024/25, 2025/26 각각 이전 시즌만 학습하는 expanding 평가.
리그별, 시즌별 적중률/Brier/logloss/ROI 및 paired 7관측일 block CI 2000회.
ROI는 동일 B365 pre-closing 배당 기준, 세금·구매 가능성 미검증.
2폴은 주 2/3회, 1만원, 월 최악 손실 예약 -5만원 유지, 회고적 모의.
현재 운영의 저장 픽을 재현한 것이 아닌 기존 모델 구조의 외부 표본 재학습이다.
자료 부족/수집 실패/누락은 명시하고 임의 대체하지 않는다.
원본은 로컬 캐시만, URL/시각/SHA256/누락량을 보고서에 남긴다.
배포/자동 승격 없음. 다른 종목에 이번 결과를 일반화하지 않는다.
