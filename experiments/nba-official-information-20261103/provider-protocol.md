# NBA provider 대체 수집 사전 규칙 (2026-11-03)

PR #521의 2025-26 기간과 27개 지정일을 유지한다. NBA 공식 games/calendar/team schedule의 공개 HTML에 식별 가능한 경기 목록이 있는지 먼저 확인한다. 기존 403 CDN, 부상 PDF 호스트 및 503 공식 API를 반복 요청하거나 우회하지 않는다.

공식 식별 목록이 복구되지 않으면 ESPN 공개 scoreboard 및 summary를 별도 `espn` provider로 사용한다. 지정일별 scoreboard 결과의 `season.type=2` 및 provider 정규시즌 ID/일자·팀을 확인한다. 각 월의 중복 제거 경기들을 날짜와 ESPN event ID 오름차순 정렬해 앞 18개까지 선택하며, 월별 18개 미만은 모두 선택한다. 선택은 경기 결과·선수·가격과 무관하게 scoreboard event identity에만 의존한다. 경기일과 유형이 불명확하거나 날짜별 응답이 한 달이라도 실패하면 그 달은 선택하지 않고 결측으로 기록한다. 이미 공식 3경기는 접근 탐색 사례로만 비교한다. 목표 100개 이상, 최대 126개다. 2025-10-22~2026-04-12의 6개월 이상을 포함하며 전체 시즌 전수로 표시하지 않는다.

각 선택 경기는 ESPN summary를 한 번 요청하고 원본 바이트와 요청 URL·파라미터·HTTP 상태·실제 현재 UTC 수신완료·원본 및 보관 SHA-256을 보존한다. 압축을 사용해도 원문을 복원해 해시를 검사한다. ESPN game/team/player ID는 ESPN 네임스페이스로만 보존한다. 최종 boxscore starter 및 DNP는 postgame으로만 표시한다. 부상 확정이나 과거 수신을 추론하지 않는다. 결과·개인 기록은 postgame 분리, 대상경기 feature 생성 금지. NBA 공식 3개와 날짜·팀·점수·선발만 개별 일치 검증하고 연결 성공 수를 구한다. 동명이인·이적 주의, ID 임의 생성 금지.

기존 가격 캐시는 같은 물리 경기·팀·시작·동일 상품·모든 방향 가격·연장 포함 정산을 검증하는 경우만 연결한다. 새 모델 적합·성과·ROI는 계산하지 않는다. 실패를 대체 경기로 채우지 않는다. 새 네트워크 최대 200, 호스트별 1초 이상, timeout 15초, 403/429시 해당 호스트 중단, 중복 수집기 잠금, 저장된 원문 해시 확인 후 캐시·재시작을 지원한다. 잠금은 프로세스의 정상 종료에만 해제하며 기존 잠금을 덮어쓰지 않는다. 줄바꿈 설정과 무관한 바이트 검사를 한다.
