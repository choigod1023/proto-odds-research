# NBA 공식 원천 및 ESPN 대체 자료 후속 수집

2025-26년 지정일 27일에서 ESPN 공개 scoreboard의 정규시즌 경기 식별자 **195개**를 확인했다. 사전 고정한 월별 날짜·ESPN 경기 ID 순 선택은 **126경기**이고 미선택은 **69경기**다. 선택은 2025-10-22~2026-04-12의 7개월에 걸쳐 월별 18경기다. 이는 리그 전체 시즌 전수가 아닌 지정일 표본이며, ESPN 제공자 표본이지 NBA 공식 전수 자료가 아니다.

선정 126경기의 ESPN summary 응답 126개를 보존했다. 이 중 **125경기**에서 최종 경기와 양 팀 사후 선발 각 5명, ESPN 선수·팀 ID 및 점수를 추출했다. `401810384`는 연기 상태여서 사후 결과·선발 집계에서 제외했으며 다른 경기로 대체하지 않았다. 원본에는 당시 결과와 개인 성적, 기타 정보가 혼재하며 파생 선수 명단은 `postgame_only`로 격리했다. DNP를 부상으로 판정하거나 사후 선발을 당시 발표 명단으로 취급하지 않는다. 공식 선수 ID를 새로 만들지 않았다.

원문 160요청은 모두 HTTP 200: 공식 NBA 팀 일정 HTML 1, ESPN scoreboard 27, summary 132다. 이 summary에는 선정 대상 126개, 공식 비교용 추가 2개, 올스타전 4개가 포함된다. 첫 수집기의 초기 검사에서 ESPN이 올스타전에 정규시즌 코드를 붙인 사실을 놓쳐 올스타전 4개를 수집했다. 같은 응답의 대회 유형 `ALLSTAR`를 확인해 최종 census에서 제외하고 4개 정규경기를 추가 수집했다. 제외 응답과 요청 기록을 삭제하지 않았다. 각 월 18개 선정은 경기 결과나 선수 성과를 보지 않고 재계산했다. 알 수 없는 대회 유형이나 해당 월의 날짜별 원문 누락은 그 달 전체를 보류한다.

공식 NBA 팀 일정 HTML은 접근됐으나 2025-26 공식 경기 ID 목록은 포함하지 않았다. 이전의 공식 NBA 박스스코어 3경기와 별도 ESPN 식별자를 연결해 시작 시각·홈/원정 팀 이름·최종 점수·양 팀 사후 선발 이름을 비교한 결과 **3/3 전 항목 일치**했다. 이름 비교의 범위이며 두 제공자의 선수 ID가 동일하거나 사전 명단 수신을 증명한다는 뜻이 아니다. 공식 부상 PDF는 지난 조사 이후 재요청하지 않았고, 실제 문서 바이트와 수신 기록을 보존한 사전 부상 연결은 여전히 0건이다.

지정된 두 Betman 캐시 디렉터리의 회차 응답 275파일을 읽었다. ESPN 125경기 중 39경기는 NBA 코드 행과 시작 시각이 같은 후보가 있었으나, 동시간 경기·중복 회차·여러 상품이 섞여 있다. 팀과 상품 및 연장 포함 정산을 검증하지 않았으므로 정확한 동일 경기·가격 연결은 확인 0건이며 39건을 가격 매칭으로 해석하면 안 된다. 실제 가격·결과 비교나 ROI, 모델 학습은 하지 않았다.

원천·요청·상태·수신 시각·원문과 gzip SHA는 `provider/requests.json`, 선수 명단은 `provider/postgame.json`, 모든 날짜의 집계와 선택은 `provider/census.json`, 미완료는 `provider/summary-exclusions.json`, 공식 교차 확인은 `provider/official-crosscheck.json`, 가격 후보와 입력 해시는 `provider/price-coverage.json`에 있다. `provider/derived-manifest.json`은 파생 파일을 검증한다. 원문 바이트 수신은 지금 이루어졌으며 과거 시점 인증은 0건이다.

수집·재개 명령은 `python experiments/nba-official-information-20261103/nba_provider_collect.py`, 오프라인 파생은 `python experiments/nba-official-information-20261103/nba_provider_derive.py`다. 이미 저장한 성공 응답은 두 해시를 검증해 재사용한다. 요청 실패와 403/429는 같은 실행이나 재시작에서 자동 재시도하지 않으며, 실패를 해결하려면 새 근거를 검토한 뒤 별도로 결정해야 한다. 중복 실행 잠금과 호스트당 1.1초 간격, 15초 timeout, 200 요청 상한이 있다. 비정상 종료 후 잠금이 남으면 프로세스 종료와 원문·원장을 확인하기 전 지우지 않는다.

검증: `python -m pytest -q tests/test_nba_official_20261103.py tests/test_nba_provider_20261103.py`. 합성 미래 결과 변경이 선택에 영향을 주지 않는지, 날짜 결측·해시 불일치시 월별 선택이 보류되는지, 올스타전 제외와 실제 160개 원문 해시·125경기 명단을 확인한다. 파일 Git blob 및 autocrlf true/false 체크아웃 바이트도 대조했다. 이 검사는 예측 정확도나 당시 수신 인증이 아니다.
