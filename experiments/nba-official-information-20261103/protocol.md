# NBA 공식 원천 수집 사전 규칙

- 범위: NBA 2025-26 정규시즌 2025-10-22~2026-04-12. NBA 공식 경기 페이지를 2025년 10월 22·25·28·31일, 11월~2026년 3월 매월 1·8·15·22일, 2026년 4월 1·8·12일의 미국 현지 경기일자로 조회한다. 이 날짜의 공식 목록을 전수 census로 보존하며 전체 시즌 전수로 표현하지 않는다.
- 경기 선택: 각 월별로 위 날짜 목록의 정규시즌 고유 공식 gameId를 날짜·gameId 오름차순으로 정렬해 앞 18경기까지 선택한다. 18개 미만이면 전부 선택한다. 결과·선수·가격은 선택에 사용하지 않는다. 비정규시즌·중복·불명 ID는 제외 및 기록한다. 목록의 월간 분모, 선택·미선택·실패 건수를 기록한다. 요청 실패나 출처 제한 시 사후 대체 날짜를 택하지 않는다.
- 선택 경기는 공식 경기 박스스코어 페이지를 각 1회 요청하여 원문 바이트와 수신 시각을 보존한다. 페이지에 들어있는 사후 최종 선발·DNP·스코어·선수기록은 postgame만으로 분류한다. 경기별 보고서는 가능할 때 해당 경기일 공식 Injury Report 정오 ET 판본 한 개를 경기일당 1회 요청하고 문서 표제의 시각과 경기 시각을 비교한다. 정오 판본이 존재하지 않거나 늦으면 결측이며 대체 시각을 찾지 않는다. 발표 주장 시각·현재 수신시각은 별개다.
- 가격은 제공된 공식 캐시만 읽으며 정확한 공식 경기 ID/팀/날짜/상품/선택 전체와 정산을 확인할 수 있을 때만 연결한다. 불명확하면 미연결. 현재 모델 학습/성과/ROI는 계산하지 않는다.
- host별 1초 이상 간격, timeout 15초, 전체 요청 500회 미만, 403/429 즉시 해당 host 중단, 잠금·캐시·재개. 원문 바이트와 상태/요청/수신 시각/SHA를 보존한다. PDF 및 HTML은 재수신이 현재임을 명시하고 과거 PIT 인증으로 보지 않는다. 파일은 바이너리 취급해 checkout 줄바꿈 변환을 막는다.
