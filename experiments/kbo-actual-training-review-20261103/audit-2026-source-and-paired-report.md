# 2026 실제 선발 원천과 2023·2026 입력 재구성 감사

상태: `waiting_fixed_inputs`. 고정 소스 트리 `e6068b83e1b076f0aa24a71a33a77930d4c09f2c`의 2026 실제 선발 원천을 검사하고, 같은 트리의 구성 코드와 고정 원천을 이용해 2023·2026 입력을 재구성했다. 최종 paired 입력 파일은 아직 인계되지 않았으므로 그 파일 자체의 바이트나 최종 학습 입력을 검증한 것은 아니다. 2024·2025 자료와 모델 성능·정산은 검사하지 않았다.

기존 고정 709경기 모집단(`13291d23e855e0d500327cb39ac64a480e395837`)과 2026 선발 원천의 경기 집합이 같고 누락·추가·중복은 없다. 공식 응답 873개의 바이트 수와 SHA-256을 재계산했다. 매 경기의 요청 ID, 날짜, 리그·시즌·시리즈, 팀, 완료 상태를 대조했고 1,418개 선발은 공식 박스스코어에서 유일한 첫 `선발` 행과 일정의 같은 팀 이름 또는 ID를 일치시켰다. 일정 이름·ID와 기록이 다른 사례는 없었다. 승패투수 또는 예정 선발만으로 실제 선발을 인정하지 않았다.

2026 선발 묶음 SHA-256은 `ca1d6dbc1f301ee4681237cbf1cd864df5079a3ab9364c2f7b50129a9574a69d`, 원문 묶음은 `1203fd23f085c56937273a5a42c0780ed703369b4b715fededc0a84a82e6e786`이다. 2026 타순은 기존 고정 명단 `b24739cf52435070586f8687011fd473a16123e4`의 메타데이터와 ID를 선발 원천에 맞춰 확인했다. 이번 선발 원문 묶음에 포함되지 않는 타순 응답 원문과 프로필 전체를 이 감사에서 다시 검증한 것은 아니다.

고정 구성 코드로 재구성한 예상·실제 입력 2023년 723쌍과 2026년 709쌍에서 경기 ID, 선수 명단과 특성 프로필의 ID 및 순서, 선발 ID, 공통 특성과 불펜 값의 동일성, 사용된 원천 경기의 당일·미래 제외, 선수 특성 scalar 재계산을 검사했다. 2023년 실제 명단의 타자·선발 이력은 구성된 고정 이력 인덱스에서 유효한 과거 이력 마지막 10개와 대조했다. 2026년에는 이력의 시점과 최대 10개를 검사했다. 이력 인덱스 자체의 모든 원자료 정합성을 새로 전수 증명한 검사는 아니다. 2023 실제 타자 150슬롯과 투수 75팀, 2026 실제 투수 31팀은 사용 가능한 과거 이력이 없었다.

공식 기록은 현재 시점의 후향 자료다. 과거 경기 전 발표·수신 및 타자의 실제 출전을 증명하지 않는다. 모델 성능, 배당, 체결, 운영 반영에 관한 결론도 없다.

재현: `python -B -X utf8 experiments/kbo-actual-training-review-20261103/audit_2026_source.py` 및 `python -B -X utf8 experiments/kbo-actual-training-review-20261103/audit_paired_2023_2026.py`. 전자는 지정 Git 객체와 원문만 읽는다. 후자는 지정 코드 파일의 Git 바이트 일치 확인 후 해당 코드를 실행해 입력을 재구성하며, 이때 기존 고정 원천의 파일과 이력 인덱스를 읽는다. 기계 판독 결과는 `audit-2026-source-result.json`, `audit-paired-2023-2026-result.json`이다.
