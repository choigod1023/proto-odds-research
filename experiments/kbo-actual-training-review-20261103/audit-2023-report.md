# 2023 공식 명단 원천 독립 감사

상태: 2023년 원천 감사 완료, `waiting_fixed_inputs`. 2024·2025 원천, 모델 예측과 성능·정산은 검토하지 않았다.

- 감사 대상 Git commit: `38463a3f2eb9ac2b00c4ddf9edd6ebacf8a99b55`. 명단 묶음 SHA-256 `53ea290c9bfe40dd792ddfd6b952faae4ee2d151176e0729a00abd8d216c9ff4`, 공식 응답 묶음 SHA-256 `f8d07586349e907d5acaa16103b5648489d452f1e533652715108e9b40b4ef15`.
- 모집단 기준: 고정 원천 `13291d23e855e0d500327cb39ac64a480e395837`의 2023년 723경기. 원천 및 결과 ID 집합이 정확히 같고 중복·누락·추가가 없다. 709개는 공식 G_ID 직접 일치, 14개는 날짜·팀·경기 순번이 같은 연도 대체 별칭이다. 경기 시작 시각 충돌은 1건으로 별도 보존됐다.
- 723경기, 양 팀 13,014개 타순 슬롯이 공식 응답의 확정 표시와 순서 1~9에 일치했다. 선수별 현재 공식 프로필 이름과 같은 경기·팀·타순의 보관 ID를 대조했고 경기별 타자 ID 중복은 없었다.
- 1,446개 투수는 같은 경기 공식 박스스코어의 유일한 `선발` 표시가 첫 행에 나타난다. 일정의 예정 선발이나 승패투수만으로 실제 선발을 인정하지 않았다. 일정 이름과 박스스코어 이름이 다른 7건은 `최채흥`/`최지명`, ID `68419`이며, 현재 공식 프로필과 같은 경기 투수 ID를 대조했다.
- 공식 응답 묶음 1,902개의 바이트 수·SHA-256을 계산했고 모두 적어도 한 경기의 원천 또는 선수 프로필 근거로 참조됨을 확인했다. 요청 경로·경기 ID·시즌·리그·시리즈·팀, 확정 명단과 박스스코어 구조를 원문에서 별도로 검사했다.

확정 타순은 현재 조회한 공식 응답이므로 과거 경기 전 발표 또는 수신 시각을 증명하지 않는다. 타순 확정이 각 타자의 실제 출전을 독립적으로 증명하는 것도 아니다. 경기 후 같은 경기의 ID 연결은 선수 식별에만 이용했고, 이번 감사의 결과 명단에는 성적을 모델 특성으로 계산하지 않았다. 원문에는 경기 성적이 포함될 수 있으므로 향후 특성 생성 시 별도 누출 검증이 필요하다.
