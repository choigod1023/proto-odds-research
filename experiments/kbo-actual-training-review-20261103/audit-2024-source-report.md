# 2024 KBO 공식 명단 원천 독립 감사

상태: 2024 원천 감사 완료, `waiting_fixed_inputs`. 고정 원천 커밋 `e8ba21f970f73594848e75cc6515a1dd3a994bf1`의 자료와 기존 모집단·과거 이력 원천 `13291d23e855e0d500327cb39ac64a480e395837`을 대조했다. 2024 최종 paired 입력과 모델 성능은 검사하지 않았다.

고정 모집단 728경기와 결과 경기 ID 집합이 정확히 일치했고 제외·중복·추가가 없었다. 공식 경기 ID 직접 연결 711건, 날짜·팀·차전이 같은 합성 연도 ID 16건, 날짜·팀으로 유일하게 식별된 `score:` 1건이다. 요청 정보와 공식 일정의 경기 ID·날짜·리그·시리즈·팀, 확정 타순과 공식 기록을 대조했다. 타순 13,104슬롯과 선수 프로필·같은 경기 측의 보관 선수 ID를 확인했고 동일 경기 내 선수 ID는 중복되지 않았다. 149슬롯은 보관 명칭이 일치하지 않아 공식 프로필 이름으로 식별했다. 해당 타순의 대체 후보에 대해서도 묶음에 포함된 프로필을 확인했으며 이름이 일치하는 후보가 둘 이상인 사례는 없었다.

양 팀 실제 선발 1,456건은 공식 경기 기록에서 유일한 `선발` 표시와 일정의 선수 ID를 대조했다. 이름이 달랐던 1건은 같은 ID `68419`의 일정 이름 `최채흥`과 공식 현재 프로필·기록 이름 `최지명`으로, 같은 경기의 보관 선수 ID도 확인했다. 예정 선발이나 승패투수만으로 실제 선발을 인정하지 않았다.

공식 원문 번들에 포함된 2,304개 응답의 SHA-256을 계산했고 이 중 명단의 근거로 참조된 1,898개에 대해 길이와 요청 정보를 대조했다. 타순과 선수 ID 산출물에는 경기 성적·결과 필드가 들어 있지 않은지 검사했다. 원문에는 성적과 결과가 포함될 수 있으므로 향후 모델 특성 생성에서 별도 누출 검증이 필요하다.

10월 23일의 일정 응답에는 같은 팀의 `20241021SSHT0`(10월 21일 경기)과 `20241023SSHT0`(10월 23일 경기)이 함께 있다. 두 경기 모두 시리즈 7, 차전 번호 0이므로 팀·차전만으로 구분하지 않고 공식 G_ID와 경기 날짜를 함께 확인했다. 고정 모집단의 `77771023SSHT02024`는 23일 G_ID와 날짜 23일의 보관 타자 기록에 일치한다. 기존 고정 경기 이력에는 같은 두 팀의 21일 행은 없고 23일 행만 있으므로, 21일 중단 경기의 통계가 이 인덱스에서 23일 경기의 과거 이력으로 들어갈 수 없다. 이는 향후 최종 paired 파일의 이력 전수 검증을 대신하지 않는다.

공식 응답은 현재 수집한 후향 자료다. 과거 경기 전 발표·수신 시각이나 확정된 타자 전원의 실제 출전을 증명하지 않는다. 수집 로그 1,767건의 시작 시각을 별도로 계산한 결과 1.5초 미만 간격이 128건이고 최단 간격은 0.100573초였다. 수집 워커는 중복 실행을 중단하고 잠금을 추가했다고 기록했으나, 전체 수집이 간격 기준을 지켰다고 표현할 수 없다.
