# 고정 모델·예측·정산 독립 감사

## 고정 이력과 학습 설정

입력 `58556de08c64604276de8682373d3ccc8d535d7c`, 실행 코드 `0d7cffe4173855c1e6b2ef5ebc9af3ba10c76ae5`, 2025 개발 산출물 `0277fa14b2e7ee2f950d683cf0093f9f1b6d788d`, 2026 예측 `ff2bef35988eb5add154b4bebf8b265f42792db1`을 Git 객체에서 확인했다. 개발 산출물은 최종 예측 커밋의 선행 이력이며 개발 커밋과 SHA를 검증한 뒤 최종 학습에 진입하는 코드다. 두 시점 사이 실행 코드가 달라지지 않았다. 이 검사는 Git과 산출물의 인과적 선행 관계를 확인하며 외부 실시간 수집 시각을 증명하지는 않는다.

어댑터가 4개 paired 입력의 경기·특성·명단을 손실 없이 정규화하는지 전수 대조했다. 기존 합성 반례의 명단과 이력 선수 ID 불일치는 `validate_history_owners`가 거부했다. 독립 수식으로 개발 4개 모델의 학습 1,451경기와 최종 4개 모델의 학습 2,182경기에서 표준화·팀 및 선수 사전을 재계산했다. 7일 경계는 평가 시작일에서 7일을 뺀 날짜까지 포함하는 것을 합성 경계로 확인했다. 2026 평가 시작일에 대한 학습 마감은 2026-03-21이다.

M0의 기본 L2 10, 수정 M2의 기본 L2 10·선수 L2 100, M2의 양쪽 결측·미등록 품질 항 12개를 확인했다. 고정 계수의 목적함수와 기울기도 독립 계산했다. 기존 전체 학습 기준 모델 2개는 이전 고정 모델 내용과 일치한다. 이 검사는 새 모델이나 하이퍼파라미터를 탐색한 것이 아니다.

## 예측 재생과 2025 개발 검증

고정 계수에서 2025년 4모델×2입력×731경기, 총 5,848개 예측을 독립 재생했다. 최대 확률 차이는 약 3.97×10⁻¹⁴였다. 2026년 6모델×2입력×709경기, 총 8,508개 예측과 팀별 품질 플래그 17,016개도 대조했으며 최대 확률 차이는 약 3.30×10⁻¹⁴였다. 확률은 부동소수점 허용 오차 내에서 일치했다.

2025 실제 확정 명단 평가에서 M0는 예상 명단 학습 385적중에서 실제 명단 학습 393적중, M2는 393에서 398이었다. 예상 명단 평가의 M2는 예상 학습 394, 실제 학습 383으로 방향이 달랐다. 731경기 기준 3방향 적중 수이며 검증 결과를 이용한 추가 모델·하이퍼파라미터 선택은 하지 않았다.

## 2026 결과와 가격 정산

별도 고정 결과 레이블과 가격 원장으로 Decimal 정산을 재생했다. 원래 레이블은 `archived_score_not_independently_official` 상태였으나, 기존 공식 일정 원문에서 같은 공식 경기 ID의 완료 점수를 확인한 결과 709경기 모두 레이블과 일치했고 불일치·점수 누락은 없었다. 공식 타순·선발 원문 복원과 결과 점수 대조는 별개의 검사다. 현재 보존된 공식 응답과의 비교이며 과거 수신 시각은 입증하지 않는다.

실제 확정 명단을 넣은 주 평가에서 709경기 중 무승부 16경기를 제외한 693경기 적중 수는 M0 실제 학습 418, M0 예상 학습 401, M2 실제 학습 396, M2 예상 학습 392였다. 이것은 가격이 있는 경기만의 적중 수가 아니다.

동일한 확장 가격 원장과 교집합인 667경기, 무승부 환급 15경기, 경기당 1단위 기준의 순손익·ROI는 다음과 같다.

| 평가에 넣은 명단 | M0 실제 학습 | M0 예상 학습 | M2 실제 학습 | M2 예상 학습 |
| --- | --- | --- | --- | --- |
| 실제 확정 명단 | -29.05 / -4.36% | -58.21 / -8.73% | -49.25 / -7.38% | -52.89 / -7.93% |
| 예상 명단 | -72.24 / -10.83% | -60.92 / -9.13% | -42.55 / -6.38% | -57.15 / -8.57% |

표의 순서는 순손익 단위 / 환급 포함 전체 베팅 대비 ROI다. 같은 667경기에서 실제 확정 명단 평가의 실제 학습 대 예상 학습 ROI 차이는 M0 +4.37%p, M2 +0.55%p였다. ISO 주 단위 paired 재표본 5,000회(시드 20261103)의 95% 백분위 구간은 각각 -1.12~+10.03%p, -4.11~+5.42%p로 모두 0을 포함했다. 예상 명단 평가의 ROI 차이는 각각 -1.70%p와 +2.19%p였고 해당 95% 구간도 모두 0을 포함했다.

엄격 가격 표본은 439경기다. 현재 구매거절 표시 7경기 제외 민감도는 확장 표본 660경기이며 별도로 계산했다. 엄격·확장별 적중률, 환급, 로그손실, Brier, 월별 손익, 일 마감 최대 낙폭 및 paired 구간은 `audit-independent-settlement.json`에 있다. 가격은 기존 후향 원장의 동일 가격을 사용한 1단위 가상 정산이며 과거 실제 구매 가능·체결을 증명하지 않는다. 모든 주 표의 ROI는 음수이고, 이 연구로 미래 수익이나 운영 모델 교체를 주장하지 않는다.

재현: `audit_development_frozen.py`, `audit_final_predictions.py`, `audit_independent_settlement.py`. 모델 코드는 지정 커밋의 바이트 그대로 임시 디렉터리에 추출해야 한다. 최종 예측 재생까지는 2026 결과를 열지 않으며 정산 스크립트에서만 고정 레이블과 가격을 읽는다. 2026 점수는 고정 공식 일정 원문과 별도로 대조한다. 이 보고서의 정산은 독립 재계산이며 모델 워커가 작성 중인 최종 정산 산출물의 일치 여부는 별도 검사가 필요하다.
