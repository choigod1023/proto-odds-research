# 최종 독립 감사

2023~2025 공식 명단 원천, 2026 공식 선발 원천, 최종 paired 입력과 모델 예측·정산을 고정 Git 객체 기준으로 감사했다. 학습은 실제·예상 각 2,182경기, 2026 평가는 각 709경기다. 기존 전체 학습 모델은 학습 경기 수가 다른 맥락 대조다.

선수 타순은 공식 확정 타순의 경기·팀·고유 선수 ID를, 실제 선발투수는 공식 기록의 선발 표시를 근거로 한다. 동일 경기 사후 기록과 공식 프로필은 선수 신원 구분에만 사용한다. 2025년 확정 타순이 확인되지 않은 5경기는 학습에서 제외했다. 현재 수집한 자료는 과거 경기 전 발표·수신이나 타자 전원의 실제 선발 출전을 증명하지 않는다.

고정 입력의 명단·선수 이력, 공통 비선수·불펜 특성, 최근 이력과 당일·미래 제외를 검사했다. 2024년 중단·재개 경기와 같은 일정 응답의 다른 경기를 공식 G_ID와 날짜로 구분했다. 2024년 자료 수집에서 요청 간격이 1.5초 미만인 사례 128건도 기록했다.

학습 전용 표준화·선수 사전과 고정 L2를 확인했고 2025 개발 예측 5,848건, 2026 예측 8,508건을 독립 수식으로 재생했다. 2026 결과 레이블 709경기는 이미 보존된 공식 일정의 완료 점수와 일치했다. 이 비교는 당시 수신 시각을 증명하지 않는다.

최종 정산 커밋 `54dbcfcdd9ffc3ca0ad473cf9d586a38398cde4e`의 12개 결과·모델 묶음, 48개 가격·모델 묶음, 12개 결과 paired 구간, 48개 가격 paired 구간이 독립 계산과 일치했다. 무승부 환급과 Decimal 손익을 포함한 개별 정산 26,376건도 대조했다. 엄격·확장 가격과 현재 구매거절 제외 민감도를 각각 유지했다. 자세한 수치, 월별 손익·낙폭과 신뢰구간은 아래 보고서와 기계 판독 결과에 있다.

마지막 `dataset.py` 변경은 공통 선수 이력을 홈·원정 양쪽에서 교차 확인한다. 이전 검증기가 통과한 타자·투수 교차 오류 두 사례를 새 검증기가 거부했고, 변경 전후 전체 정규화 입력과 개발 레이블의 SHA-256은 모두 `f9b1fdb58804280576b518045649843cb2e59290409d4992d08a1ce4dcab9cbf`였다. 고정 입력 14개와 최종 모델·예측 바이트도 변하지 않았다.
