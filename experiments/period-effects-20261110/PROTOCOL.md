# 종목별 반복 달력 효과와 최근 결과 변화 검증

## 입력과 시간 순서

2025년 1월 1일~2026년 11월 2일의 #691 공통 상품 원장을 평가한다. 일반 시장의 과거 이력은 저장소의 2023~2024년 국내 아카이브를 사용한다. 그룹 키는 종목·리그·상품 유형·적용 구간·결과지 수다. 기준 확률은 원장에 기록된 마진 제거 시장확률 또는 KBL 핸디캡의 동결 후보 확률이다. 동일 경기의 여러 상품은 별도 평가하고, 고유 경기 수로 해석하지 않는다.

각 경기 주의 월요일 7일 전까지의 날짜만 학습에 사용한다. 같은 주의 정산은 그 주의 예측에 들어가지 않는다. 결과 공개의 실제 시각이 없는 회고 자료에 적용하는 지연 가정이다. 2025년과 2026년은 결과를 따로 보고하고 규칙·계수 문턱은 평가 성적을 보기 전에 고정한다.

## 대조군과 후보

각 그룹의 결과지별 보정값은 `log((실제 건수 + 80 × 평균 기준확률) / (기대 건수 + 80 × 평균 기준확률))`이다. 이를 기준 로그확률에 더하고 전체 합이 1이 되도록 정규화한다. 최소 유효 이력 30건을 충족하지 못하면 보정값은 0이다. 유효 건수는 사용한 관측 가중치의 합으로 센다.

- **기준**은 원래 확률을 그대로 사용한다.
- **전체 이력 보정**은 시간 가중치 없이 해당 그룹의 사용 가능한 모든 이력으로 보정한다. 기간 정보를 추가하는 후보는 이 대조군과 짝지어 비교한다.
- **달력 반복**은 이전 연도의 같은 달과 전후 한 달만 사용한다. 연말 경계는 달력상 순환한다. 같은 연도 결과는 달력 보정값에 들어가지 않는다.
- **최근 변화**는 최근 180일 안에서 반감기 45일의 가중치를 적용한다.
- 달력·최근 후보의 보정값은 전체 이력 보정값과 섞는다. 기간별 가중치는 유효 건수 / (유효 건수 + 80)이다. **둘 다**는 사용 가능한 두 기간 보정값을 각각 적용한 결과의 로그확률 보정값을 평균한다. 둘 중 하나만 가능하면 그 후보와 같다.

동률이면 원본에서 먼저 나오는 결과를 고른다. 상품별 적중률·로그손실·가상 ROI, 바뀐 픽 수와 보정 가능 건수를 기록한다. 적중률·로그손실·ROI 차이는 동일 평가 행을 날짜 단위로 묶은 7관측일 블록 부트스트랩 95% 구간으로 보고한다. 세 후보의 탐색적 비교이며 다중 비교를 통제한 운영 승격 검정으로 해석하지 않는다. 동일한 코드와 문턱을 축구·야구·농구·배구에서 독립 병렬 실행한다.

달력 월은 실제 시즌 단계의 대용으로만 사용한다. 개막·정규시즌·플레이오프·휴식기 등 공식 일정으로 식별한 단계와 사전 부상·로테이션 정보는 별도 데이터 확보가 필요하다. 배당의 실제 사전 수신·구매 가능성이 확인되지 않아 ROI는 저장 가격의 1단위 회고 모의치다.
