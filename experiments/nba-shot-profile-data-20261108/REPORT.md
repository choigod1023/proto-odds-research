# ESPN NBA 슛 프로필 데이터 (연구 전용)

PR #669의 기존 경기별 감사에서 양 팀이 모두 적격인 1,185경기, 2,370팀-경기를 고정 원천 풀로 사용했다. 이는 이력 풀의 크기이며 예측 평가 경기 수가 아니다. KST 날짜 범위는 2025-01-01~2026-10-28이다. 2026-11-08에 사후 수신한 보존본이며 당시 실제 가용성을 증명하지 않는다. 경기 전 목표 날짜 D를 예측할 때 원천은 KST 날짜 D-4 이전까지만 사용해야 한다. 목표 경기의 슛, 박스, 점수와 대상 경기의 PBP 적격 여부를 예측 입력·표본 선정에 쓰지 않는다. D-4는 가용 시각 검증을 대체하지 않는 보수적 대리 규칙이다.

`games.jsonl.gz`는 경기당 한 행, home/away 순서다. `manifest.json`에 레이블·순서·시도 점수·해시·경계 인접 횟수가 있다. 각 팀의 9개 시도/성공 배열, 자유투 시도/성공, 공격리바운드, 팀 전체 턴오버, 야투 시도/성공, 득점과 추정 포제션(FGA−ORB+totalTurnovers+0.44×FTA)을 기록한다. 점수와 박스는 원천 경기의 사후 집계이며 반드시 과거 조건을 적용해야 한다. 미래 접근 차단은 소비 모델이 별도로 검증해야 한다.

거리 r=hypot(x−25,y), 2점 [0,4), [4,10), [10,16), [16,∞), unknown; 3점 [0,24), [24,27), [27,∞), unknown으로 사전에 고정했다. 위치 구역은 `internally_consistent_unofficial`인 ESPN 내부 거리 가설이며 공식 NBA 위치 구역이 아니다. 누락, 비유한 값, 센티넬은 unknown에 보존하며 이번 적격 풀에는 해당 시도가 없었다. 좌표와 시도 점수로만 구역을 정하고 성공 여부는 구역 선택에 관여하지 않는다. 경기 결과나 예측 성적으로 경계를 고르지 않았다. 원문 좌표 오차 및 경계 근처 슛의 분류 민감도가 남는다. 경계에서 1ft 미만인 시도는 2점 4/10/16 경계 각각 18,028/7,597/4,650, 3점 24/27 경계 각각 22,971/30,314건이다. 서로 다른 경계의 집계는 독립적인 근접 횟수다.

고정 원본 감사 풀 및 영수증 목록 해시를 확인하고 scoreboard 200 400건, summary 200 2,357건과 summary 404 본문 8건의 SHA-256을 각 영수증 및 기존 감사 목록에 대조했다. 404는 `.unavailable.body`를 읽는다. 각 대상의 경기 ID, 팀, 홈/원정, UTC 날짜와 과거 감사 값을 확인했으며 각 팀의 FGA/FGM/3PA/3PM/FTA/FTM, 전체 점수, 기간별 시도·성공 및 linescores를 재대조했다. 불일치 시 전체 내보내기를 중단한다. 블록된 실패는 원문 슈터 팀의 시도로 계산했다. 2점과 3점 unknown 각 0회다. 결과·예측 적중률·ROI 개선은 이 작업에서 측정하지 않았다.

재현:

```powershell
python scripts/export_nba_shot_profile.py --archive <보존본> --audit <PR669_실험_디렉터리> --out <출력_디렉터리>
python -m pytest tests/test_nba_shot_profile_data.py -v
```

압축 파일은 gzip mtime과 파일명을 고정한다. 원천의 개별 영수증은 그대로 두고, 원문 대량 재배포 없이 요약만 보존한다. 운영 추천, 원장, DB, 지갑, 스케줄, 배포를 변경하지 않는다.
