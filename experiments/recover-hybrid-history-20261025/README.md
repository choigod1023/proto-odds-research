# Git 과거 생성본 복구 및 하이브리드 비교

2026-10-25 로컬 실행. 운영 코드와 원본 사전 원장은 수정하지 않았다.

## 새로 확보한 자료

Git의 과거 웹 생성본 변경 306개를 읽어 사전 시각 조건에 맞는 MLB 스냅샷 2,056개를
추출했다. 기록 시각은 생성본 generated_at과 Git commit 시각 중 늦은 것으로 보수적으로
정했다. Git 시각은 저장소 증거이지 제3자 시각 인증은 아니다.
정오 ET 이전 저장, 경기 T-30 이전 의사결정, 팀/경기 날짜 일치와 시작 시각 10분 이내,
사전 관측 작성자 3명 이상을 요구했다. 최신 적격 스냅샷의 당시 최종 확률과 양쪽 배당을
사용했으며 현재 모델 확률로 재계산하지 않았다.

첫 실행 `results.json`은 기존 PR354 비교기의 별도 score_model_probability 필수 조건으로
30경기가 제외되었다. 이 보조 확률은 요청한 세 가지 비교에 필요하지 않다.
최종 실행 `results-primary.json`에서는 생산 최종 확률과 배당만 검증하는 전용 연결 함수를
사용했다. 이로써 28경기를 확보했다. 나머지 64경기는 작성자 부족, 2경기는 결과 불명/충돌이다.
정오 조건에 맞는 모델 경기는 총 94개다. 다른 3경기는 정오 조건 이전 단계에서 제외됐다.

## 결과: 동일 28경기, 단폴 동일 금액

- 기존 모델: 14/28 적중(50.00%), ROI -21.54%, Brier 0.24008.
- 픽스터 단독: 12/28(42.86%), ROI -25.86%, Brier 0.35228.
- 고정 50:50 산술 혼합: 15/28(53.57%), ROI -8.64%, Brier 0.27633.
- 230개 후보 중 사후 ROI 최고값: 18/28(64.29%), ROI +7.39%.
  단순 모델 75%·픽스터 25%가 이 최고값 동률 후보 중 하나다(Brier 0.25324).
  같은 픽을 내는 여러 후보가 동률이므로 유일한 최적 비율이 아니다.

75:25 후보의 이 표본 ROI 차이는 기존 모델 대비 +28.93%p지만, 같은 자료에서 후보를
탐색한 사후 결과다. 미래 기대수익률이나 통계적으로 검증된 개선폭이 아니다.
확률 오차(Brier)는 후보 전체 중 기존 모델이 가장 작았다. 수익률과 확률 정확도의
최적 후보가 같지 않다는 점을 반드시 구분한다.

날짜는 2026-08-30(7경기), 08-31(6), 09-01(8), 09-03(6), 09-04(1), 총 5일이다.
날짜 순 60/20/20 분할은 21/6/1경기로 최종 평가가 한 경기밖에 안 된다.
따라서 최소 표본 차단을 유지했고, 공식 선택 후보는 null이다. 모델 교체/배포하지 않았다.
모델 스냅샷은 정오보다 약 0.45~18.57분 앞서 저장됐으나 실제 정오 체결 가능성은 미확인이다.
결과는 기존에 연결된 게시자 판정이며 공식 결과와 독립 대조하지 않았다.
해결된 표본만의 비교라 누락 편향도 남는다. 다른 종목과 시즌에 일반화하지 않는다.

## 두 경기 조합: 고정된 세 기준만 비교

월 손실 5만원, 1장 1만원, 서로 다른 경기, 사전 선택한 편의 낮은 배당 우선 정책을
PR353 재생기로 실행했다. 계좌별 미정산 노출도 예산에 포함한다.
기존 모델·픽스터·고정 50:50은 이 작은 표본에서 같은 조합을 선택했다.
주 2회는 2장 +1,000원(ROI +5%), 주 3회는 3장 -9,000원(ROI -30%)이었다.
따라서 이 표본에서는 두폴 개선이 없었다. 사후 최고 75:25를 두폴 검증 완료로 주장하지 않는다.
기간은 8월/9월에 걸쳐 있으며 완전한 한 달의 운용이 아니다.

## 외부 자료 조사

- [Betshoot 공개 JSON](https://www.betshoot.com/archives/tipsters.php?export=json):
  개별 경기·작성자·배당·판정·날짜를 공개한다. 확인한 레코드에는 정확한 게시 시각과
  당시 수정 이력이 없어 현재 비교 입력으로 넣지 않았다. 사이트 집계 수익을 자체 검증으로
  인용하지 않는다.
- [Sports4Play 결과](https://sports4play.com/picks-results/): 게시 날짜/시각과 경기 시각,
  선택 및 분석 근거를 공개하는 형식이다. 사이트가 표시한 시각만으로 독립적인 사전 증명이
  되지 않으며, 이번 MLB 공통 표본으로 연결하지 않았다. 분석 근거 효과는 미검증이다.
