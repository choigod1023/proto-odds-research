# Machine-learning candidate module: pre-registration

This module implements a bounded subset of the coordinating search. It receives already time-split arrays and training labels only. It does not load data, build outcome-derived target features, choose a model, score any real period, deploy, or claim an optimum. The caller must independently enforce feature availability, time separation, nested validation and final untouched evaluation; no API can establish chronology from anonymous arrays.

Exactly three feature sets are accepted: base (6 columns), disagreement (11), form (23). Three estimators produce 26 settings per feature set: logistic C in {0.01,0.1,1,10} × class_weight {None,balanced}; random forest max_depth {2,4,None} × min_samples_leaf {5,15}, n_estimators 64/max_features 1.0/n_jobs 1/seed 20261102; histogram gradient boosting max_leaf_nodes {3,7,15} × l2_regularization {0,10} × learning_rate {0.05,0.1}, max_iter 100/min_samples_leaf 15/early_stopping false/seed 20261102. Logistic uses a scaler fit only on the training fold, lbfgs and max_iter 1000; each fitted model is cached per base setting and feature set. Six fixed market blends {0,0.1,0.25,0.5,0.75,1} mean `(1-blend)*market + blend*model`, for 78 fits and 468 labeled configurations; blend zero duplicates the market and is deliberately retained.

Labels are 0/1/2 (home/draw/away); probability columns are aligned to that order even if a training class is missing. For a single-class fold, all families use the fixed Dirichlet(1,1,1) empirical prior `(class_counts+1)/(n+3)` instead of fitting. For fitted multi-class models, absent classes receive zero initially; all probabilities then get a 1e-12 floor and renormalization. Market input is required finite, nonnegative and normalized. Random seeds and threadpoolctl limit of 1 make runs repeatable within the installed numerical stack, but different library versions may differ.

Synthetic tests cover 468 IDs, caching, scaling isolation, missing and single classes, invalid inputs, determinism, shape and finite normalized probabilities. No real target scores are read. API: `configurations()` returns JSON-compatible dicts; `predict_all(train_features, train_y, target_features, target_market, configs=None)` returns id → n×3 float array; no target label argument.
