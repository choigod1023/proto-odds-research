# 최근 경기 확률 보정 실험 — 2026-09-07

## 결론

리그·마켓별 보정에 작은 오차 감소 신호가 있으나 **유의미한 개선은 입증되지 않았다**.
운영 적용, 새 픽 선택, 적중률·수익률 개선을 주장하지 않는다.

- 학습: 9월 4~5일 공식 마켓 결과 연결 76건 (3건 + 73건).
- 평가: 9월 6~7일 오전 공식 마켓 결과 연결 103건 (79건 + 24건).
- 평가 픽은 운영 DB 사전 저장 값과 대조된 표본이다. 모든 경기별 픽이며 ‘오늘의 추천’만의 성과가 아니다.
- 기존 확률: Brier 0.244640, 로그손실 0.682360.
- 전체 공통 보정: Brier 0.244906, 로그손실 0.682920 — 소폭 악화.
- 종목별 보정: Brier 0.242675, 로그손실 0.678361.
- 종목·리그·마켓 보정: Brier 0.241281, 로그손실 0.675505 — Brier 상대 1.37% 감소.
- 최근 비중 추가: Brier 0.241269, 로그손실 0.675480 — Brier 상대 1.38% 감소.

최근 비중 추가의 Brier 감소는 비가중 리그·마켓 보정보다 약 0.00001275에 불과하다.
학습 표본 76건 중 73건이 같은 날이라 최근성의 효과를 식별할 시간적 다양성이 거의 없다.

## 유의미성 판정

경기별 손실 차이를 KST 경기일로 묶어 양측 정확 부호 반전 검정을 진단용으로 계산했다.
날짜 간 독립성과 귀무가설 아래 대칭성 가정이 필요하다. 날짜가 2개뿐이면 이 검정의
최소 가능한 양측 p값은 0.5다. 4후보 × 2지표의 8비교를 Holm 보정한 p값은 모두 1.0이다.
이는 ‘효과가 없다’는 증명이 아니라, 이 표본으로 신뢰할 개선을 입증할 수 없다는 뜻이다.
경기 103개를 독립적인 103번의 일별 검증처럼 취급하지 않았다.

최근 가중 후보의 날짜별 Brier 감소량(양수=개선):

- 9/6: +0.0043053.
- 9/7 오전: +0.0002957.

리그마다 방향도 다르다. 같은 후보의 MLB 27건은 Brier 0.236377→0.227560으로
개선했지만, NPB 5건은 0.286188→0.326417로 악화했다. 표본이 작은 리그의 결과를
따로 골라 운영 승격 근거로 사용하지 않는다. 전체 리그/종목/마켓별 결과는 report.json에 있다.

## 실험의 범위와 제한

1. 앞선 분석에서 평가 결과를 이미 보았다. 프로토콜은 이번 후보 수치 계산 전에 고정했지만,
   경기 전 사전등록이나 완전히 새로운 미래 검증이 아니다.
2. 학습/평가 분리는 경기 시작일 기준이다. 당시 시점의 정산 공개 시각은 증명하지 못했다.
   특히 평가 픽의 저장 시각보다 학습 결과가 늦게 알려졌을 수 있다. 따라서 이 결과를
   실제 사전 운용 가능한 시간순 replay나 백테스트 수익으로 주장하지 않는다.
3. 수집된 결과에서 정확히 연결된 공식 마켓 hit/miss만 사용했다. 점수 기반 잠정 판정,
   보류, 무효, 미래 경기 및 원장 없는 경기는 제외했다. 결측이 무작위라고 가정하지 않는다.
4. 기존 선택 하나의 ‘적중 확률’만 보정했다. 전체 선택지의 확률 분포, xG/선발 특징의
   효과, 새 픽 선택이나 추천 정책은 실험하지 않았다. 3-way도 선택된 사건의 이진 확률만 평가한다.
5. 픽·배당을 바꾸지 않았으므로 모든 후보의 적중은 57/103(55.3%), 동일 금액 모의 ROI는
   -10.8%로 같다. Brier 1.38% 감소를 적중률 +1.38%p로 해석하면 안 된다.
6. ridge 값과 3일 반감기는 탐색용 설정이며 최적값이 아니다. 후보 결과를 본 뒤 재튜닝하지 않았다.
7. 출력은 운영 probability artifact와 다른 연구용 schema다. 코드에는 DB·수집기 import,
   네트워크 호출, 모델 승인 목록 수정 또는 운영 반영 경로가 없다.

## 방법

기존 저장 확률의 logit을 offset으로 둔 ridge logistic calibration이다.
전체→종목→리그→마켓 항을 공동 최적화하고 각 항에 양의 L2 벌점을 준다.
최근 후보는 3일 반감기의 학습 가중치를 사용하며, 평균 가중치를 1로 정규화해
벌점 강도의 상대적 변화를 막는다. 미관측 리그는 학습된 상위 항만 사용한다.
학습에는 평가 행을 전달하지 않는다. 후보별 확률과 계수, 손실, 날짜별 대조,
프로토콜/자료 해시가 report.json에 저장된다.

## 재현

저장소 루트에서 실행한다. 외부 패키지나 운영 DB는 필요 없다.
출력은 기존 파일을 덮어쓰지 않는다.

```powershell
python src/recent_calibration_experiment.py --input experiments/recent-calibration-20260907/dataset.json --protocol experiments/recent-calibration-20260907/protocol.json --output experiments/recent-calibration-20260907/report-reproduced.json
python -m pytest -q tests/test_recent_calibration_experiment.py
```

dataset.json은 앞선 읽기 전용 감사의 필요한 경기별 필드만 추린 재현 fixture다.
전체 원본 예측/선수정보/이미지를 포함하지 않는다. 원본 감사 JSON과 각 스냅샷 SHA-256,
관측 시각은 provenance에 있다. 데이터 기준은 2026-09-07 10:02:36 KST이며
결과 피드는 10:03:33, DB 대조는 10:10 시점이다. 이후 결과는 섞지 않았다.
