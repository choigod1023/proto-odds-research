# 2026 KBO 기존 가격의 공식 회차 대조

모델 phase2의 시험 경기 726건 중 원본 CSV 유래 시장가격이 있는 **354건 전부**를 대상으로 했다. 결과나 성적에 따른 표본 선택은 없었다. `rows.jsonl`과 `labels.jsonl`의 기존 SHA-256을 검증하고, 모델 예측 6개와 시험 라벨의 경기 ID 집합이 동일한지, 대상 354건의 시장값이 모델 입력과 같은지 확인한 다음 감사 입력을 별도로 동결했다.

| 공식 상세 대조 결과 | 경기 수 |
| --- | ---: |
| 홈·원정 원본 가격과 공식 `winAllot`·`loseAllot` 일치 | 354 |
| 가격 변경 | 0 |
| 경기번호를 찾지 못함 | 0 |
| 상품 또는 경기 식별 불일치 | 0 |
| 결과 불일치 또는 경기 거부·환급값 | 0 |

공식 응답에서 7건의 `buyReject`가 1 또는 4로 표시돼 있다. 이 7건도 가격 숫자는 일치하지만, 해당 상태 코드를 별도로 보존했으며 판매 가능성을 주장하지 않는다. 원래 가격을 바꾸거나 더 유리한 가격을 선택하지 않았다. 공식 상세의 `gameReject`, `buyReject`, `gameResult`, 점수 및 원래 `winAllot`·`loseAllot` 필드를 별도로 저장했다.

## 방법과 한계

- 원본 `market_id`의 연도·회차·경기번호를 공식 응답 `gmTs`·`matchSeq`와 대조했다. 경기번호의 선행 0은 정수 표기 차이로 처리한다. KBO 리그, 홈·원정 팀 ID, 시작 시각, 일반 2-way 상품, 결과와 두 배당을 확인했다. 상품·식별·가격·결과·미조회 사유는 코드에서 별도 분류한다.
- 필요한 공식 회차 38개를 모두 확인했다. KBO·K리그 작업에 저장된 응답은 원문 해시를 검증하고 각 회차에서 **수신 시각이 가장 늦은 것**을 가격과 무관하게 재사용했다. 없는 회차만 공식 `POST /buyPsblGame/gameInfoInq.do`로 조회했다. 신규 요청 19회에는 최초 연결 오류 1회와 그 뒤 성공한 재시도 1회가 포함된다. 상한 30회, 15초 timeout, 요청 간 1초, 403/429 즉시 중단을 적용했다.
- `responses/*.gz`에는 공식 응답의 압축 원문, `request-ledger.json`에는 요청·응답·수신 시각과 압축 해제 원문 해시가 있다. `audit-original-2026-prices.jsonl.gz`에는 원래 가격과 현재 공식 응답 가격을 나란히 보존한다. `audit-manifest.json`은 파일 해시와 분모·분류를 기록한다.
- 이번 공식 응답의 수신 시각은 2026년 조회 시각이다. 원래 CSV 가격이나 현재 공식 필드가 경기 시작 30분 전의 가격이었다는 증거는 없다. 공식 배당이 일치한다는 결과는 과거 구매 가능성, 예측 성능이나 수익률을 증명하지 않는다. 2023~2025년 기존 가격은 조사 범위에 포함하지 않았다.

원본 `restored-prices.jsonl`의 SHA-256 `d9fc2f04fabec1fa41d29521aeafdb96e676747e59723396f36ba5c88a9b8117`, 기존 manifest와 공식 응답 원본은 변경하지 않았다. `python -X utf8 audit.py`로 새 원문에서 오프라인으로 결과를 재생성하며, `python -X utf8 -m unittest discover -s . -p 'test_audit.py' -v`로 전체 354건의 원문과 입력을 다시 대조할 수 있다.
