# 비축구 적중률·ROI 후속 실험

이번에는 실제 동결 후보의 **최종 선택 규칙**과 리그별 **입력·확률 모델**을 나눠 계산했다. 운영 코드·추천 기준·동결 원장·모의 지갑·스케줄을 바꾸지 않았다. 새 모델의 운영 승격이나 미래 수익 개선을 입증한 연구가 아니다.

## 1픽 선택 규칙: 동결 가격과 정산 75경기

기존 읽기 전용 추출 SHA256 `5667e855f7696798fea7411bee9b1f286f2204517bec775b8e175781371e171e`의 사전 1픽 114개를 재현했다. 현재 1.50 이상 우선 규칙은 선택 ID·상품·기준점·배당·규칙까지 **114/114 일치**했다. 모든 대안의 결과가 연결된 공통 75개를 비교했으며 나머지 39개는 미정산으로 분리했다. 경기일은 KST 11월 6~8일, 3개 날짜에 불과하다. 전체 운영 원장/해시 체인 인증이 아니며 이전 진단에서 이 기간의 요약을 이미 확인한 탐색적 회고다.

후보는 해당 snapshot에 원래 저장된 승패 선택과 자동 추천 H/UO뿐이다. 새 방향이나 기준점은 만들지 않았다. `probability_first`는 시장 역배당 정규화 확률이 큰 후보를 고르며 새 선수 모델 확률이 아니다. `primary_only`는 저장된 승패 선택이다. 바뀐 시장의 각 배당은 같은 사전 snapshot 값이며, 같은 상품의 확률 모델 A/B 비교와 다르다.

- 전체 75경기: 현재 36/75(48.00%), ROI -22.07%; 시장확률 우선 47/75(62.67%), -14.20%; 기존 승패만 선택 44/75(58.67%), -6.56%.
- **농구 23경기:** 현재 11/23(47.83%), -20.39%; 시장확률 우선 17/23(73.91%), -1.87%; 기존 승패만 선택도 17/23, -1.87%. 평균 선택 배당은 현재 1.671, 확률 우선 1.360, 승패만 1.431이다. 확률 우선에서 17경기의 선택이 바뀌었고 승패 22·핸디캡 1개가 됐다. 가상 누적 최대 낙폭은 현재 7.29→3.92단위지만 실제 지갑 낙폭이 아니다.
- 농구를 다시 리그별로 나누면 NBA 16경기는 8/16·-15.88%→13/16·+3.63%, KBL 4경기는 2/4·-21.00%→3/4·+13.25%다. 반면 WKBL 3경기는 1/3으로 같고 ROI는 -43.67%→-51.33%로 악화했다. 양의 결과만 골라 전체 농구에 승격하지 않는다. 각 리그 표본은 매우 작다.
- KBO 2경기: 현재와 확률 우선 모두 1/2 적중이지만 ROI는 -19.50%→-31.50%로 악화했다. 적중률이 같아도 당첨 배당이 낮아지면 수익은 나빠질 수 있다. 승패만 선택하면 0/2, -100%다. 이 수를 KBO 전체 성적으로 보지 않는다.
- 배구 4경기: 세 규칙 모두 0/4, -100%다. 검증된 다른 시장 후보가 없어 선택을 바꾸지 못했다. 작은 표본의 극단값을 장기 성능으로 일반화하지 않는다.
- 축구 46경기: 현재 24/46(52.17%), -16.24%; 확률 우선 29/46(63.04%), -12.15%; 승패만 27/46(58.70%), +3.28%. 축구는 요청의 주요 개선 대상이 아니지만 결과를 숨기지 않았다.

농구 ROI 차이는 +18.52%p이지만 날짜 블록 paired 95% 구간은 **-14.14~+37.50%p**다. 적중률 차이 +26.09%p의 구간은 0~+35.71%p이며, 단 3개 날짜로 추정한 구간은 매우 불안정하다. 전체 ROI 차이 구간도 -32.20~+19.86%p다. 농구에서 관측된 개선은 연구 후보로 삼을 신호이지 지속 개선이나 흑자의 증거가 아니다. 추가 모델 튜닝으로 생긴 이익도 아니다. 현재 ROI와 확률 우선 ROI는 모두 음수다.

## 리그 워커의 새 입력·모델 실험

- [KBO #658](https://github.com/choigod1023/proto-odds-research/pull/658): 이전 축소/혼합 연구를 반복하지 않고 선발 ID별 최근 10일 투구수·등판 간격을 연결했다. 2025년 43경기에서 고정한 잔차 후보를 2026년 공통 26경기에 적용한 M0+선발 이력은 M0와 같은 15/26(57.69%), 참고 ROI -8.77%다. 시장+선발 이력도 시장 자체와 픽이 같아 새 정보의 효과는 입증되지 않았다. 사후 박스에서 대상 선발을 복원한 회고이며 실제 명단·배당 수신 시점은 미증명이다. 확인 일정 97개 중 공통 26개, 개막기 일부 기간이고 포스트시즌 검증이 아니다. 실제 경기 전 capture 3건에서는 선수 ID↔원문 투구수의 완전 연결이 0건이었다. 이 누락의 어댑터 경로를 별도 점검했다.
- [농구 #657](https://github.com/choigod1023/proto-odds-research/pull/657): 2025년 KBL 공식 점수를 학습한 정규분포/Student-t 후보는 2026년 공통 152경기에서 모두 86/152(56.58%), 조건부 참고 ROI -13.93%로 동일했다. 분포가 같은 평균을 중심으로 대칭이므로 승패 방향은 구조적으로 같았다. 시장은 99/152(65.13%), -8.64%였다. 개별 상품·연장 규칙·실제 가격 수신이 없어 이 손익은 실제 상품 ROI로 인증되지 않았다. NBA/WKBL·부상·핸디캡 개선은 미검증이다.
- [배구 #656](https://github.com/choigod1023/proto-odds-research/pull/656): 세트 승률 기반 수축과 시장 잔차 후보를 계산했다. 2025/26 연속 세트 이력이 없어 결과 전에 대체 범위를 고정한 2023 학습·2024 평가다. 남녀 각 90경기(가격 127개 중 37개 점수 미연결)에서 남자는 62.22%로 같고 ROI -13.00%→-12.29%, 여자는 75.56%→72.22%, -0.81%→-6.03%였다. 둘째 후보는 시장과 픽이 같았다. 평가 경기의 공식 ID·실제 배당 수신과 픽스터 원문 공통 연결은 미완료다. 두 공식 결과 사례의 직접 대조는 평가 표본 밖이므로 평가 전체의 인증으로 사용하지 않았다.

## 판단

운영에 올릴 만큼 검증된 새 확률 모델은 없다. 농구에서는 가격 우선 규칙을 제거한 **픽 선정 후보**가 소표본에서 적중률과 손실을 동시에 개선했다. 다만 저배당 승패 비중이 늘어난 효과이며 다른 기간의 같은 조건으로 확인해야 한다. KBO·배구는 이번 특징과 규칙으로 두 지표가 함께 개선되지 않았다. 기존 M0를 시장으로 바꿨을 때의 차이를 선발 정보의 성과라고 부르지 않는다. 같은 경기 결과를 보며 새로운 임계값을 추가 탐색하지 않는다.

다음 검증은 이미 고정한 세 선택 규칙과 후보를 독립된 기간에 적용하는 것이다. 농구는 정확한 과거 H/UO 가격·상품·연장 규칙을 연결해야 하고, KBO는 실제 선수 ID·투구수 원문 연결을 완성해야 하며, 배구는 공식 세트 이력과 정확한 기준점 원문 투표 커버리지가 필요하다. 이번 연구는 그 미완료 상태를 숨기지 않는다. 새 상시 AI 점검이나 Windows 예약 작업은 만들지 않았다.
