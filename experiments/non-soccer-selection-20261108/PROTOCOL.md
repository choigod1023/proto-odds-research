# 경기 추천 1픽 선정 규칙 비교 — 실행 전 고정

2026-11-08. 운영 예측 모델과 원장은 변경하지 않는다. 현재 운영의 1.50 이상 배당 우선 규칙이 실제 1픽 적중률·ROI에 미친 구성을 조사한다. 같은 경기의 다른 상품을 고르는 선택 규칙 비교이며, 같은 상품에 대한 새 모델의 확률 개선 검증이 아니다.

입력은 2026-11-08 06:41 UTC 공개 API에 노출된 snapshot ID에 대해 06:50 UTC 운영 DB를 읽기 전용 추출한 484예측+419정산 revision이다. SHA256 `5667e855f7696798fea7411bee9b1f286f2204517bec775b8e175781371e171e`. 전체 원장이나 해시 체인 검증을 대체하지 않는다. 원본은 커밋하지 않는다. 1픽 기록 114개·75정산의 요약은 이전 진단에서 이미 봤으므로 이번 비교는 탐색적 회고 민감도이며 블라인드 최종 평가라고 부르지 않는다.

대상은 현재 정책의 저장된 1픽이 있고 as_of·captured_at·market_observed_at이 모두 경기 시작 30분 전보다 이른 이벤트다. 같은 이벤트를 중복 집계하지 않는다. 각 snapshot에 저장된 승패 선택과 자동 추천 H/UO 상품만 후보로 사용한다. 다른 방향, 새로운 기준점, 현재 가격, 결과를 보고 만든 픽은 추가하지 않는다. 양방향/3방향 원장 가격 벡터의 역배당을 정규화한다. Shin 확률이나 모델 확률과 혼동하지 않는다.

세 규칙을 고정한다. 추가 임계값 탐색은 하지 않는다.

1. `price_first`: 현재 구현대로 배당 1.50 이상을 먼저 고르고, 정규화 시장확률·기대 단위 손익·selection ID 순서로 비교. 저장된 1픽과 전수 재현 일치해야 한다.
2. `probability_first`: 같은 후보에서 배당 우선 조건만 제거. 확률·기대 단위 손익·selection ID 순서 유지.
3. `primary_only`: 같은 snapshot의 저장된 승패 선택만 사용. 운영 투표/시장 대체 선택 자체는 바꾸지 않는다.

각 선택의 원래 offer/selection ID·기준점·배당·정산 규칙과 정산 결과를 확인한다. 모든 선택이 정산된 공통 이벤트를 주 비교에 사용한다. 미정산/불완전 연결은 수와 사유를 별도 공개한다. 미정산을 손실로 처리하지 않으며 결과가 없는 상품의 결과를 다른 상품에서 추정하지 않는다. 환불은 ROI의 정산 단위 수에 포함하고 적중률 분모에서 제외한다. 매 이벤트 가상 1단위 기준, 월 손실 5만원 모의 원장은 수정하지 않는다.

종목·시장 구성·평균 배당·커버리지·정산 수·적중률·단위 ROI·최대 낙폭과 동일 이벤트의 차이를 기록한다. 날짜 단위 paired bootstrap 2,000회, seed=20261108, 95% 구간을 사용하되 날짜 블록이 적으면 불안정함을 명시한다. 선택 상품이 달라지는 비교라 교차 상품 로그손실을 같은 목표의 성능 향상으로 해석하지 않는다. 농구가 주요 진단 대상이며 KBO·배구·축구도 전체 결과를 빠짐없이 보고한다. 개선된 종목만 골라 운영에 채택하지 않는다.

과거의 실제 수익, 미래 기대수익이나 독립 검증의 성공으로 표현하지 않는다. 새 선수·라인업/세트 모델은 리그 워커의 별도 자료 연결과 시간 분할 검증 대상이다. 유의미한 신규 데이터가 없는 동일 예측을 재실행해 새 실험으로 세지 않는다. 이 규칙 비교는 이전 PR #655의 집계 구분과 별개이며, 원장에 저장된 시장 가격 선택을 실제로 재현·비교한다.
