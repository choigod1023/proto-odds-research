# KBO M0 적중률 개선: 두 후보의 회고 비교

2026-11-03. 결론: 이번 두 후보를 채택하지 않는다. 목표는 예측 적중률 개선이다. 자료를 쌓는 작업 자체를 성과로 대신하지 않고, 같은 경기에서 예측이 실제로 더 맞았는지를 확인했다. 새 후보를 두 개로 제한했으며 실패한 결과도 보존한다.

## 이번에 실행한 모델

기준 M0는 실제 선발·타순에 연결된 기존 팀 전력, 휴식, 구장, 타격 출루 대리값, 상대 선발 및 불펜 부담을 이용하는 Poisson 득점 모형이다. 두 팀 득점 차이의 Skellam 분포로 승·무·패 및 무승부를 제외한 조건부 승패 확률을 구한다. 이번 비교에 새 픽스터 자료·시장 확률·선수 ID 효과는 추가하지 않았다. 따라서 픽스터 단독 대 혼합 비율의 새 검증이 아니다.

1. **승패 직접 보정안**: `expit(logit(M0 조건부 홈승 확률) + Xβ)`. 팀 및 기존 다섯 특성의 홈·원정 차이, 결측 여부를 사용한다. L2=10, 절편 무벌점. M0 무승부 확률은 유지한다. 득점 오차를 최적화하는 M0에 승패 목표를 추가하면 선택이 좋아질지 검사했다. 보정 학습은 같은 과거 학습 구간의 M0 내표본 예측을 사용한다. 교차 적합한 스태킹이 아니므로 학습 낙관 가능성이 있다.
2. **홈런 전력 추가안**: 기존 M0에 실제 타순의 과거 HR/AB와 결측 표시를 추가하고 Poisson 회귀를 다시 적합한다. 타자별 20타수의 학습 구간 사전값으로 평활화하고, 사전값·표준화·계수는 학습 구간에서만 구한다. 전원 정보 부족이면 결측을 유지한다. 상대 투수 피홈런은 2026 평가 원자료에 없어 넣지 않았다. L2=10, 절편 무벌점. 배당·적중 결과를 보고 특성이나 계수를 탐색하지 않았다.

홈런 사전값은 학습 기간 전체에서 추정하는 고정 모수다. 학습 초기 행 당시 알 수 있었던 값이라고 주장하지 않는다. 이는 연간 정적 배치 학습 비교이며, 각 학습 행 시점에 모델까지 재학습하는 순차 재현 실험이 아니다. 평가 연도 자료는 이 사전값에 포함하지 않았다.

## 표본과 평가 방법

- 2023 실제 명단 723경기 학습 → 2024년 728경기 평가.
- 2023–2024년 1,451경기 학습 → 2025년 731경기 평가.
- 2023–2025년 2,182경기 학습 → 2026년 709경기 평가.
- 각 평가 시작 전 최소 7일 간격. 전 모델이 같은 전체 평가 경기와 같은 배당 부분집합을 사용한다. 유리한 경기만 골라 적중률을 높이지 않았다.
- 1차 지표는 승패가 난 경기의 조건부 승패 적중률이다. 무승부는 이 적중률 분모에서 제외하지만 전체 3방향 적중률과 ROI에서는 별도로 처리한다.
- 2024 개발 조건은 적중 수 증가와 조건부 logloss 비악화다. 승패 보정안은 이 조건을 통과했고 홈런안은 실패했다. 그래도 두 안의 2025·2026 원결과를 전부 공개한다.
- 모든 기간은 앞선 연구에서 이미 살펴본 회고자료다. 새로운 블라인드 홀드아웃이나 실전 수익 증명이 아니다. 이번 결과의 주별 5,000회 bootstrap 95% 구간도 다중 연구 전체를 보정한 확증 검정이 아니다.

## 실제 결과

각 연도에서 적중률은 모든 결정 경기, ROI는 실제 연결된 배당 부분집합에서 계산했다. 연간 ROI를 합쳐 대표 수익률로 제시하지 않는다.

**2024년**: 전체 728경기 중 결정 719경기, 배당 연결 714경기.

- M0: 385/719, **53.55%**, ROI **−11.83%**, 순손익 −84.49단위, 일 마감 최대 낙폭 85.54단위.
- 승패 보정: 390/719, **54.24%**, ROI **−11.12%**, 순손익 −79.40단위, 최대 낙폭 82.07단위.
- 홈런 추가: 382/719, **53.13%**, ROI **−12.51%**, 순손익 −89.32단위, 최대 낙폭 90.37단위.

**2025년**: 전체 731경기 중 결정 709경기, 배당 연결 676경기.

- M0: 393/709, **55.43%**, ROI **−9.29%**, 순손익 −62.82단위, 최대 낙폭 65.71단위.
- 승패 보정: 394/709, **55.57%**, ROI **−8.43%**, 순손익 −56.97단위, 최대 낙폭 63.81단위.
- 홈런 추가: 389/709, **54.87%**, ROI **−10.58%**, 순손익 −71.52단위, 최대 낙폭 74.83단위.

**2026년**: 전체 709경기 중 결정 693경기, 배당 연결 667경기(그중 환급 15경기).

- M0: 418/693, **60.32%**, ROI **−4.36%**, 순손익 −29.05단위, 최대 낙폭 40.98단위.
- 승패 보정: 395/693, **57.00%**, ROI **−9.08%**, 순손익 −60.57단위, 최대 낙폭 64.45단위.
- 홈런 추가: 389/693, **56.13%**, ROI **−10.02%**, 순손익 −66.82단위, 최대 낙폭 66.82단위.

2026년에서 승패 보정은 틀렸던 47경기를 바로잡았지만 맞았던 70경기를 새로 틀렸다. 홈런 추가는 35경기를 바로잡고 64경기를 새로 틀렸다. 단순히 예측이 많이 바뀌었다는 것을 개선으로 볼 수 없다.

2026 ROI 차이의 주별 nominal 95% 구간은 승패 보정 −9.53~+0.13%p, 홈런 추가 −11.54~+0.18%p다. 두 안 모두 수익 개선을 지지하지 않는다. 더 엄격한 원시각 일치 배당 439경기에서도 M0 ROI −6.53%, 승패 보정 −10.79%, 홈런 추가 −8.22%였다.

전체 3방향 적중률은 2026년 M0 418/709=58.96%, 승패 보정 395/709=55.71%, 홈런 추가 389/709=54.87%다. 조건부 60.32%와 혼동하면 안 된다.

## 자료와 수익률의 한계

실제 명단 원자료는 [기존 M0 패키지](../kbo-m0-followup-20261103/vendor/evolution/common/inputs/)의 `train-actual.jsonl.gz`, `test-actual.jsonl.gz`다. 과거 선수 기록의 날짜는 해당 대상 경기보다 이전이어야 하고, 같은 경기 ID도 거부한다. 자료 내용의 과거 날짜와 실제 경기 전 수신 증명은 다르다. 이 자료는 `retrospective_unproven`이며 경기 전에 확정 명단을 실제 수신했다는 증거는 없다.

2023 라벨은 [전용 학습 파일](../kbo-m0-followup-20261103/inputs/fit2023-labels.jsonl.gz), 2024·2025 라벨과 가격은 [기존 data](../kbo-m0-followup-20261103/data/), 2026 라벨과 가격은 Git 커밋 `d08ccb708033fb6b067e84e80eae81ea3c9b4cfa`의 `experiments/kbo-player-effects-20261103/inputs/test-labels.jsonl.gz`, `price-ledgers.json`에서 읽었다. [audit.json](audit.json)에 추가 입력 및 산출물 해시를 기록했다. 기존 vendor와 원자료의 고정 해시도 검사한다.

2024·2025는 1,459경기 중 1,390경기에만 가격이 연결됐고, 미연결 69경기에 무승부 31경기가 모두 포함된다. 원래 가격 표본 생성에 결과 기반 제외가 있어 표본 편향이 있다. 따라서 이 ROI는 보관된 가격 코호트에 한정한 값이며 전체 기회 집합이나 실전 수익률을 대표하지 않는다. 2026 확장 가격의 실제 체결 가능성과 수신 시각도 전부 입증된 것은 아니다.

경기당 동일 1단위, 단폴로 정산했다. 무승부는 순손익 0이며 환급 경기도 ROI 투입 분모에 포함한다. 조합 배당 반올림이나 월 손실 한도에 따른 베팅 중단을 적용한 운용 재현이 아니다. 기존 월 손실 5만 원 원장은 변경하지 않았다.

## 이제 할 일

이번 비교에서는 M0를 유지한다. 이는 M0가 최적이거나 수익성이 입증됐다는 뜻이 아니다. 기존 예측에 승패 목적을 덧붙이거나 HR/AB 하나를 넣는 방식으로는 일관된 개선을 확인하지 못했다는 뜻이다.

다음 비교의 우선순위는 **M0가 놓친 정보를 실제로 추가할 수 있는지**다. 경기 전 확정 선발·타순이 직전 예상과 어떻게 바뀌었는지, 해당 변화에 따른 상대 선발과의 타자 구성 및 불펜 가용 전력 차이를 독립된 특성으로 연결하는 가설을 먼저 확인해야 한다. 이것은 아직 효과를 측정한 결론도, 기존 연구와 중복이 없음을 확인한 새 모델도 아니다. 기존 연구 목록과 입력 수준을 대조하고 사전 시점을 입증할 자료가 있을 때 한 개 가설을 고정해서 비교해야 한다. 같은 과거 점수를 보고 무한히 계수를 바꾸거나 맞은 경기만 남기는 방식은 채택 근거가 되지 않는다.

Windows Python 자동 수집과 기존에 고정한 M0·혼합안은 그대로 유지했다. 정기 AI 점검 두 개는 계속 정지 상태이며, 이번 연구 PR은 운영 모델 교체·병합·배포를 수행하지 않는다.
