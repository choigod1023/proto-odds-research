# 초기 실행의 자격 정정

`results.json`과 루트의 `domestic-ledger.jsonl`/`overseas-ledger.jsonl`은 등록 commit
`50fdae5514188a62d283722d2824f913e35b9008`으로 최초 계산한 기록이다. 삭제하거나
좋은 성적으로 바꾸지 않고 보존한다. 이 계산 직후 독립 검토에서 해외 원자료의
상품 및 홈/무/원정 배당 순서가 보존 원문으로 검증되지 않는 결함을 확인했다.
단지 배당 세 값이 있다는 이유로 전체 경기 1X2로 자격을 부여한 것은 잘못이다.

따라서 **초기 해외 120행의 성능 수치는 유효한 모델 검증 결과가 아니다**.
세 모델의 설정은 바꾸지 않고 해외 전 행을 `unverified_market_and_selection_order`로
제외하도록 자료 준비를 수정했다. 이후 등록된 `verified-inputs/`와
`verified-results/`만 최종 자격/성적에 사용한다. 국내 77경기의 예측·정산은
초기 기록과 최종 기록의 동일성을 검사한다. 수정 뒤 새 표본이나 새로운 튜닝
성공으로 재포장하지 않는다.

국내·해외의 경기 ID 교집합은 77, 합집합은 120이었다. 초기 77+120을 독립
197경기로 합산하지 않는다. 해외 원문 증거를 확보하기 전에는 가격 순서를
추정해 뒤집거나 현재 사이트의 표로 과거 원문을 인증하지 않는다.
