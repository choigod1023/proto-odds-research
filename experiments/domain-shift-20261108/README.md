# 2026-11-08 입력 분포 이동에 따른 가중 학습

의료·뇌신호 분류에서 쓰는 입력 분포 이동 보정을 실제 스포츠 회고 자료에 적용했다. 두 후보 모두 모든 종목의 전체 ROI가 음수이며, 현재 운영 정책으로 승격하지 않는다.

## 기존 연구와 다른 점

`rg`로 experiments, research, scripts, docs/research의 `density ratio`, `covariate shift`, `KLIEP`, `uLSIF`, `domain adapt`, `importance weight`를 검색했고 동일 구현은 찾지 못했다. 기존 최근 경기 가중·시장 잔차 회귀와 목적 일부는 겹친다. 이번에는 경기의 나이가 아니라 **2025년 말의 배당·확률 특성 분포와 얼마나 비슷한가**로 훈련 가중치를 바꾼다. 새 선수·픽스터 정보를 추가한 실험이 아니다.

원문: [Sugiyama et al., 2007, Covariate Shift Adaptation by Importance Weighted Cross Validation](https://www.jmlr.org/beta/papers/v8/sugiyama07a.html). 원 논문의 IWCV 알고리즘 전체를 재현한 것이 아니라, 입력 밀도비 가중 원리를 응용했다. 조건부 결과 분포가 유지된다는 가정은 여기서 입증하지 못했다.

## 고정한 방법과 시점

- 입력: `experiments/all-sports-underdog-20261031/results/{bs,sc,bk,vl}/domestic_archive/ledger.jsonl.gz`의 시장 확률, 당시 기록 가격, 보존된 outcome-form 확률과 실제 결과. 파일 해시는 summary에 있다. 운영 M0나 투표 모델을 재현한 것이 아니다.
- 학습: 2025-01-01~12-27. 결과 가용성을 경기일+4일로 가정하여 2026년 이전에 학습을 닫았다. 보존된 상위 form 예측의 원래 월별 시점 계약도 함께 따른다.
- 목표 입력 분포: 2025-10-01~12-27. **2026년 입력이나 결과로 밀도비를 학습하지 않았다.** 평가용 결과는 지표 계산에만 썼다.
- 평가: 2026-01-01~08-26. 사전에 정한 정규 리그와 form 비폴백 행을 사용했다. 같은 경기·상품·배당·결과를 네 모델에 모두 적용했다. 전체 서비스 기회 목록의 100%라는 뜻은 아니다.
- 시장 대조군: 주어진 전체 선택지의 정규화 역배당 확률과 최유력 방향.
- 동일 정보 대조군: 시장 log-probability를 offset으로 두고, 시장/form log-ratio·시장 entropy·overround를 선형 다항 로짓으로 보정한다. L2=0.01, L-BFGS-B, 최대300회로 고정했다.
- 후보1: LogisticRegression(C=0.1)으로 2025년 말 표본 소속 확률을 추정하고, `P(late|x)/P(late)`로 전체 2025년 표본을 재가중한다. 밀도비는 [0.25,4]로 제한한다.
- 후보2: 최대 시장확률을 고정 0.1 너비 구간에 나눠 말기/전체 빈도비를 계산한다. 각 구간 Jeffreys 0.5 평활과 같은 가중치 상한을 적용한다.
- 두 후보와 선형 대조군은 같은 변수·규제·선택 규칙을 쓴다. 당일 선택은 argmax 확률, 동일 확률은 기존 index 순서다. 가격별 정상 정산의 가상 1단위 손익이며 월 손실 한도 지갑은 바꾸지 않았다.

## 실제 실행 결과

야구 2,959경기에서 직접 시장은 적중률56.88%, ROI−12.18%, 로그손실0.680002다. 동일 정보 선형 대조군은57.38%, −11.24%, 0.680019다. 후보1은57.52%, −10.93%, **0.680693으로 로그손실이 악화**했고, 후보2는57.35%, −11.29%, 0.680023이다.

농구 1,016경기에서 직접 시장은69.69%, ROI−11.00%다. 선형 대조군70.08%, −10.28%; 후보1 70.08%, −10.24%; 후보2 70.08%, −10.28%다. 후보1의 로그손실은 시장보다 악화했다.

축구 2,304경기에서 시장은49.31%, ROI−14.77%다. 후보1은49.44%, −14.36%; 후보2는49.35%, −14.61%다. 축구는 홈·무승부·원정 **세 방향을 모두 보존**했다. 두 후보의 로그손실은 시장보다 악화했다.

배구 KOVO 139경기에서 시장은61.15%, ROI−17.96%다. 후보1은63.31%, −13.37%; 후보2는62.59%, −15.23%다. 이 작은 표본의 적중률 증가와 달리 두 후보의 로그손실은 악화했다.

일부 개별 리그의 ROI가 양수일 수 있으나 해당 리그를 사후 선택하거나 새 정책으로 채택하지 않는다. 리그·분기 결과와 MDD는 summary에 모두 보존했다. 가상 낙폭은 경기일/id 순이며 실제 정산 시각의 미정산 노출을 재현한 값은 아니다.

## 불확실성과 독립 검산

같은 ISO 주를 묶어 1,000회 쌍체 bootstrap과 주별 차이 합의 양측 부호 순열 검정을 계산했다. 표본 간 독립성이나 교환가능성을 입증한 것은 아니다. 후보1 야구의 ROI 차이 명목 구간은 양수지만, 2후보×4종목×3지표의 **24개 비교에 Holm 보정 후 유의한 결과는 0개**다. 이 보정 범위는 이번 분포 이동 가족에 한정되며 다른 워커의 모든 연구를 보정했다고 주장하지 않는다.

`audit.py`는 표준 라이브러리로 확률합·선택·Decimal 손익·동일 상품 정렬·중복 여부를 별도로 검산한다. 실제 6,418경기와 25,672개 모델별 예측 행을 확인했다. 테스트와 계산 명령:

```text
python experiments/domain-shift-20261108/run.py
python experiments/domain-shift-20261108/audit.py
python -m pytest experiments/domain-shift-20261108/test_domain_shift_research.py -q
```

## 해석 한계

원본 HTTP 수신·당시 실제 구매 가능성·공식 결과의 최초 가용 시각을 입증한 전향 자료가 아니다. 야구·농구의 원래 보존 2-way 자료는 무승부를 제외한 조건부 표본이므로 환불을 포함한 운영 원장 성과와 다르다. 과거 여러 번 검사한 기간이고, late-2025 분포가2026년에도 유지된다는 보장도 없다. 적중률 몇 건 증가를 양의 미래 기대수익이나 확률 보정 성공으로 해석하지 않는다. 운영 변경·상시 작업·자동 베팅은 추가하지 않았다.
