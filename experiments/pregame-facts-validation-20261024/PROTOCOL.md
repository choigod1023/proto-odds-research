# 선발·결장·로테이션 증분 검증

운영 모델·DB·웹에는 연결하지 않는 로컬 연구. 픽스터의 최종 선택이나 추천 방향은 입력에서 제외한다.

## 비교 계약

- 기존 모델과 정보 추가 모델은 같은 경기, 같은 예측 마감 시각, 같은 당시 구매 가능 배당으로 비교한다.
- 글 게시 시각과 실제 최초 수집 시각을 분리한다. 지금 수집한 과거 글을 당시 수집한 것으로 간주하지 않는다. 별도 신뢰 가능한 사전 아카이브가 있으면 회고 재구성 자료로 분리한다.
- 공식 경기 ID, 타임존이 있는 시작 시각, T-30 이전 예측 시각, 정보 관측 시각, 독립된 공식 확인을 요구한다. 예상 선발과 확정 선발, 의심 결장과 확정 결장을 혼합하지 않는다.
- 사후 결과지의 실제 선발은 사전에 알려진 선발과 다를 수 있다. 선발 이름만으로 임의 확률 가산점을 만들지 않는다.
- 선수 영향 계수는 이전 기간 학습 자료로 추정하고 이후 기간을 평가한다. 동일 사실의 여러 재게시 글을 독립 정보로 중복 가산하지 않는다.
- 정보 부족을 정상 출전·무결장이라는 0 값으로 바꾸지 않는다. 비교 가능 경기 수와 제외 이유를 보고한다.

## 모의 운용 조건

- 기존 사용자 조건: 2폴, 회당 1만원, 주 2회와 3회를 별도 비교한다.
- 월 순손실 한도 5만원은 각 모델의 전체 종목 합산 계정에 적용한다. 종목별로 한도를 복제하지 않는다.
- 아직 정산되지 않은 베팅의 최대 손실까지 예약해서 한도 초과 주문을 막는다. 결과를 나중에 안 시점의 이익으로 이전 베팅을 허용하지 않는다.
- 두 모델 모두 사전 정보만으로 조합을 선택한다. 개별 경기 확률 품질 비교와 조합 선택 정책 효과를 분리한다. 실제 배당 지급 규칙을 확인하기 전에는 올림 규칙을 추측하지 않는다.
- 실제 ROI, 적중률, 베팅/보류 수, 월별 순익, 수익 월 비율, 최대 낙폭, 한도 도달 월 수를 함께 보고한다. 시간 블록 단위 불확실성도 제시한다.
- 이 문서와 감사 프로그램은 모의 운용이 실행됐다는 증거가 아니다. 적합한 자료와 학습된 추가 모델이 없으면 해당 결과는 null로 남긴다.

## 이번 실행 범위

실제 공개 분석 자료 수집과 독립 확인 가능성을 점검하고, 기존 과거 선발 파일의 관측 시각을 Python으로 감사한다. 적합한 추가 학습·검증 표본이 없으면 이전의 form/rest 연구 결과를 이번 픽스터 효과로 대체하지 않는다. 검증 가능한 실제 자료가 없다는 사실과 모델이 효과가 없다는 결론은 다르다.
