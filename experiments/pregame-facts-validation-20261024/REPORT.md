# 실제 수집 결과와 모델 비교 가능성

2026-10-24 KST. 운영 변경·병합·배포·실베팅 없음.

## 결론

공개 분석 글을 실제 조회해 4종목 각 2개 기사, 총 15개 주장을 구조화했다. 그러나 이번에 확보한 자료 중 경기 전 관측·공식 경기 매칭·당시 예측 마감 시각·독립 확인을 갖춘 모델 비교 표본은 0개다. **기존 모델 대비 적중률·ROI·수익 안정성 개선 여부는 아직 계산하지 못했다.** 개선이 0이라는 결론이 아니다.

- 야구: 기사 2개 / 주장 4개 / 사전 적격 0개 / 성능 차이 계산 불가.
- 축구: 기사 2개 / 주장 4개 / 사전 적격 0개 / 성능 차이 계산 불가.
- 농구: 기사 2개 / 주장 4개 / 사전 적격 0개 / 성능 차이 계산 불가.
- 배구: 기사 2개 / 주장 3개 / 사전 적격 0개 / 성능 차이 계산 불가.

기사 조회 9회 중 8개를 읽었다. 검색 서비스의 캐시일 수 있어 전체 원본 최신성까지 증명한 것은 아니다. 결장 복귀·직전 경기 결장·출전 불확실을 현재 결장 확정으로 바꾸지 않았고, 픽스터 최종 추천은 제외했다. 일부 팀 로테이션 언급은 구체적인 명단·시각이 없어 정보 추가 모델의 변수로 쓸 수 없다.

## 공식 대조와 과거 자료 검사

[NC–LG 분석](https://www.attv24.com/sports_analysis/19403)의 로건 앨런·손주영 선발 언급은 [KBO 공식 사이트 프리뷰](https://www.koreabaseball.com/MediaNews/News/Preview/View.aspx?bdSe=59980)와 내용이 일치했다. 다만 지금 과거 프리뷰를 읽은 것으로, 당시 수집 스냅샷이나 실제 선발 확정 명단을 검증한 것은 아니다.

기존 로컬 `mlb_starters.json`도 Python으로 검사했다. 2023-03-31~2026-08-10의 9,201개 경기 중 양 팀 선발 이름이 있는 것은 9,152개, 타임존이 있는 observed_at은 0개였다. 이 자료는 실제 선발을 이용한 회고 탐색에는 활용 가능하지만 당시 예고 선발로 실전 베팅했을 때의 증거는 아니다. 이번 연구에서 사후 실제 선발을 사전 정보로 취급하지 않았다.

## 월 손실 한도와 미수행 범위

월 순손실 5만원 한도는 유지한다. 예정된 비교 조건은 회당 1만원·2폴·주 2회 및 3회이며, 각 모델의 모든 종목을 합산한 한도다. 미정산 주문의 위험까지 포함해야 한다. 상세 조건은 PROTOCOL.md에 고정했다.

이번 실행은 자료 수집과 적격성 감사까지다. **추가 모델 학습, 과거 모델 대조 추론, 월 모의 운용은 실행하지 못했다.** 따라서 월 수익·수익 월 비율·최대 낙폭·손실 한도 도달 빈도는 모두 미측정이며 results.json에 null로 남겼다. 이전 form/rest 실험의 수익률을 픽스터 추가 효과로 재사용하지 않았다.

추가 모델에 검증되지 않은 가산점을 붙여 숫자를 만들지 않았다. 다음 실행에는 경기 ID와 T-30 이전 수집 시각이 있는 사실, 그 사실의 독립 검증 기록, 같은 시각의 배당·기준 모델 확률, 공식 결과가 함께 필요하다. 신규 사전 수집 또는 신뢰 가능한 과거 아카이브를 확보한 후 시간순 학습·검증으로 평가한다. 과거 아카이브가 충분하면 반드시 운영 배포 이후 자료만 기다릴 필요는 없다.
