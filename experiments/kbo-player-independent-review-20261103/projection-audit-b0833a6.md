# KBO 과거 경기 기반 예상 구성 독립 감사 — stage 3

상태: `ready_for_model_results`. 고정 대상은 데이터 PR #511의 commit `b0833a6`이며 원본은 `git show`로 읽었다. 모델 워커의 진행 중 파일과 성적은 검토하지 않았다. 총괄 보완 계약 `1770f8b3`의 prior-only 주 시나리오와 hindsight 분리를 기준으로 했다.

## 결론과 직접 실행한 검사

- 고정 projection gzip SHA-256 `eca78a16ca59ccc1de6eca47713acded513541c59cddbbb4d8dd193e7c5b27ae` 및 입력 rows·labels와 원천 4종의 SHA가 manifest와 일치했다. fixture 2,913행은 모두 유일하고 원본 fixture ID 집합과 일치한다. 이 해시는 보존 바이트의 무결성이며 공식 인증이나 과거 수신 증명이 아니다.
- 원본 경기와 타자·투수 박스의 날짜·홈·원정·점수를 검사해 불일치 0건을 확인했다. 타자·투수 원천은 각각 261경기 부재했고 이를 0의 실제 기록으로 세지 않았다. 유일한 원본 선발 행의 날짜·팀·점수 불일치도 0건이었다.
- 저장된 2,913행을 immutable `build_prior_projection.py`에서 재생해 전부 일치시켰다. 이는 같은 구현의 재현이지 독립 알고리즘 검증은 아니다. 별도 Python 검사로 2,913행의 대상·과거 fixture 날짜, 5,276개 예상 타순의 출처·선수 ID 순서, 28,964개 로테이션 후보의 소속과 첫 투수 ID, 464,404개 타자 기록과 49,907개 투수 기록의 숫자·원천 행을 대조했다.
- 별도 계산으로 가장 최근 유일한 이전 팀 경기 및 최근 5명 중 가장 오래 쉬었던 선발 선택을 2,913경기 전부 확인했다. 바로 이전 경기 날짜가 중복되는 팀 사례 28개는 타순을 null로 남겼고 manifest의 타순·선발·팀·불펜·구장 건수와 같았다. 원본의 동일 팀·경기 내 선수 ID 중복은 타자·투수 각각 0건이다. 이 확인은 공식 ID 인증이 아니다.
- 실제 원자료에서 2025-06-01 포함 이후 1,178경기의 타깃 타순 ID, 투수 ID, 선수 수치, 점수 및 저장 선발명을 동시에 변조했다. 그 날짜까지의 1,740개 예상 결과(변조 당일 5경기 포함)는 바뀌지 않았다. 이는 실제 입력 대상일 한 구간의 실행 검사이며 모든 가능한 변조에 대한 증명은 아니다.
- 이닝 독립 변환으로 `5.2`와 `5 ⅔`는 17아웃, `0 ⅓`은 1아웃, `5.3`과 단독 `⅓`은 미해석임을 확인했다. 보존된 원본 투수 이닝 28,468개에는 미해석 값이 없었다. 숫자 null과 실제 0은 구분해야 한다.

## 모델 인계에 남는 검증 조건

- 이 projection은 **과거 출전 정보로 만든 가정 기반 시나리오**다. 실제 발표 타순·선발 또는 경기 전 실제 수신을 증명하지 않는다. `completed_at`·`received_at`은 null이며 이전 날짜 완료는 가정이다. 투구 수와 시간 기준 24/48시간 불펜 사용량은 없고, 경기 일정의 완전성·`bf` 단위도 인증되지 않았다. 결측·불완전 정보를 0으로 채워 확정 관측으로 표시하면 안 된다.
- 기존 1차 데이터 감사의 조건은 그대로다. 60무승부 전부 가격 미연결, 그중 날짜·팀·시각이 맞는 46경기는 사후 무효 1.00/1.00만 확인됐다. 임의의 선행 가격·실제 체결·공식 상품 정산을 추정해서는 안 된다. 원배당이 없는 환급 손익 0을 추가해 전체 ROI가 좋아진 것처럼 표시하지 않는다. 원래 시장 가격 2,459경기는 결과에 따라 무승부가 제외된 조건부 표본이며 검증된 실거래 ROI가 아니다.
- 최종 모델에서는 `home/away_lineup_prior` 및 `home/away_starter_prior`의 사후 타깃 선수 의존성을 제거해야 한다. stage 3 projection만 존재한다는 사실이 모델이 실제로 그 projection을 사용한다는 증거는 아니다. 고정 모델 및 입력을 확보한 후 타깃 선수/라벨 poison 불변성, projected·hindsight 분리, 결과 및 가격 매칭, 무효 환급·미정산과 선택/정산 분모, Decimal 공통 표본 정산을 검증한다.

운영 원장·모델·스케줄·서버 변경, 병합·배포, 성능 평가나 네트워크 접근은 하지 않았다.
