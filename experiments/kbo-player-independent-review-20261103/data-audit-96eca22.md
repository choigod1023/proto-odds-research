# KBO 1차 데이터 독립 감사 — 2026-11-03

검토 대상은 PR #511의 immutable commit `96eca22`에서 `git show`로 읽은 `experiments/kbo-player-data-20261103/{build.py,rows.jsonl,labels.jsonl,inventory.json,handoff.json}`이다. 진행 중인 워커 작업 파일이나 모델은 수정·검증하지 않았다. 총괄 보완 계약 `1770f8b3`을 함께 읽었다. 본 감사는 데이터·표기 감사이며 새 모델 학습·성능 검증이 아니다.

## 확인된 문제와 경계

1. **사후 선수 identity가 prior 필드로 전파된다.** `build.py` 108–111행은 사후 타깃 박스스코어에서 얻은 `b`와 `pitcher_id`로 각각 `*_lineup_prior`와 `*_starter_prior`의 선수별 과거 기록을 고른다. 두 prior의 `availability_basis`는 `retrospective_prior_calendar_day_assumption`이지만, 그 선수가 타깃에 출전했는지를 사후 데이터로 선택하는 의존성은 표현하지 않는다. 홈 `lineup_prior`가 존재하는 2,652행에서 ID 순서가 타깃 `actual_lineup_assumed`와 정확히 같다. 예: `20230407KTLT02023` 원정 선발·타순 prior는 2023-04-02 이전 이력이라도 그 대상 선수는 타깃 실제 출전 정보에서 선택됐다. **주 분석의 projected 모델에 이 두 필드나 이를 집계한 값을 그대로 쓰면 누출이다.** 1770f8b3처럼 과거 날짜 출전 기록만으로 타깃 선수를 추정해 별도 재구성하고, 타깃 선수 ID를 변조해도 주 예측이 불변인지 실행 확인해야 한다. 실제 선수 구성 기반은 hindsight 층으로만 둔다.
2. **가격 집합은 무승부 환급을 결과에 따라 빠뜨린 선택 표본이다.** 라벨 2,913개 중 무승부 60개이며 이 60개는 전부 `market=null`; 가격 2,459개에는 무승부가 없다. 보존 CSV와 날짜·팀·시각 기준으로 무승부 46경기에서 매칭 가격 행을 찾았으나 각 행은 `is_void=True`, `result=무승부`, 가격 1.00/1.00으로 사후 환급 표시였다(48행, 중복 포함). 선행 가격을 알 수 없으므로 1.00을 경기 전 원배당으로 쓰거나 ROI에 복원하면 안 된다. 나머지 14건은 7건 kickoff 부재, 7건 해당 시각 행 미발견이다. 다만 빠진 환급/무효 기회를 분자·분모와 별도로 밝혀야 하며, 2,459를 무작위 전체 경기 표본이나 모든 환급을 포함한 2-way 수익률로 소개하면 안 된다. 가격 없는 무승부도 득점 진단에는 활용 가능하다.
3. **정산 규칙/결과의 근거를 별도 표기해야 한다.** `build.py` 97행은 가격 2,459행 전부에 `settlement_rule=draw_void_refund`를 넣지만 문서상 실제 상품별 공식 규칙은 아직 독립 인증되지 않았다. 이는 회고 가정이지 검증된 정산 근거가 아니다. 라벨의 `official_result` 역시 별도 `result_source_status`에 독립 공식 인증 미확인이라 표시돼 있으므로 그 이름만 보고 인증된 공식 결과로 승격하면 안 된다. 원문·시각·규칙 근거가 없으면 verified ROI는 미산출, archived-price scenario만 명시적 가정으로 분리한다.

## 독립 실행 결과

Python stdlib로 commit blob 자체의 SHA-256을 inventory와 대조했다. `rows.jsonl` `66433dd4706e602befd75f8084ee43eb2e84a54b2657438c37733e3d80531c8c`, `labels.jsonl` `ef32ffe806b41521f5bd53c12d0eea1362bd44293181fc3ebb7c24c6fcb249ca`가 일치한다. inventory에 기록된 로컬 원본 6종의 현재 바이트 해시도 모두 일치했다. 2,913행/라벨 2,913개, fixture ID 2,913개, 시장 ID 2,459개는 각각 유일하고 fixture·market 키 집합이 같다. 연도별 723/728/736/726, 가격 2,459·무가격 454, 전부 `retrospective_unproven`이다.

원본 아카이브의 대상 날짜와 `latest_source_date`를 비교했을 때 같은 날짜 이후로 표시된 이력은 없었다. 이는 **시간 태그 검사만 통과**한 것이며 위 타깃 선수 선택 누출을 해소하지 않는다. 실제 historical receipt 및 가격 receipt의 독립 인증, 선발/타순 실제 사전 가용성, 선수 ID·최종 결과의 공식 인증은 수행하지 않았다. 로그·해시만으로 독립 수신을 증명하지 않는다. 표본 외 자료나 운영 전체에 동일 결론을 확대하지 않는다.

## 보완 계약의 의미

`1770f8b3`은 PIT의 실제 수신·완료 요건을 완화하지 않고, 과거 공식 선수 구성 및 실제 기록 시각 없이도 별도 회고 진단을 허용한다. 가정 가격 ROI를 검증된 ROI와 나누는 것도 가능하다. 단 이 분리는 구현이 검증되기 전까지 계약상의 요구일 뿐이다. 이전 가용 시각 null과 대상 실제 선수 미사용을 지키고, 제공된 원천의 부재를 운영 전체 부재로 확대하지 않는다. 선수·모델의 성능·실제 베팅 성과·운영 정책 변경을 주장하지 않는다.
