# KBO 동결 예측의 공식 가격 overlay 독립 감사

상태: `overlay_audited_reproducibility_correction_required`. 대상 모델 PR #512 commit `5c797509a9305674307ecce83df99ea8f9a2b0c1`, 공식 가격 PR #513 `9bcbd53bf95ce6c6961b5b88fd43877152d602b6`, 원자료 PR #511 `b0833a6`이다. 모델·가격 워커 작업 폴더와 운영 원장·서버는 변경하지 않았다. 별도 수집 중인 공식 타순은 이번 결과에 포함하지 않았다.

## 확인된 재현성 결함과 앞선 감사 정정

공식 가격 파일 `restored-prices.jsonl`의 **Git blob은 LF 줄바꿈**이며 SHA-256은 `cb556b0fb182eb13de6d22a513b8a04952e5e22d6b31a6b6ca44f543edb647aa`다. 373개 줄바꿈을 CRLF로 바꾼 Windows 체크아웃 바이트의 SHA는 manifest 및 overlay가 요구하는 `d9fc2f04fabec1fa41d29521aeafdb96e676747e59723396f36ba5c88a9b8117`이다. JSON 내용은 같다. 사용자 환경의 `core.autocrlf=true`에서 이전 단계 `git archive`로 얻은 파일도 CRLF로 변환되었는데, 이전 `official-price-audit-9bcbd53.md`에서 이를 Git blob 원래 바이트처럼 소개한 것은 잘못이다. **실제 저장 blob과 변환된 체크아웃 바이트를 이 문서의 두 해시로 정정한다.** 373건의 원문 행·가격 대조 결론은 변하지 않는다.

`phase3_overlay.py`의 `SOURCE_HASH` 및 `verify_sources()`는 Windows CRLF 해시를 `checked()`에 전달한다. immutable Git blob LF를 임시 파일에 그대로 저장해 `checked()`를 호출하면 `ValueError: SHA mismatch`가 발생했고, 같은 내용을 CRLF로 변환했을 때만 통과했다. 따라서 Linux 또는 LF 체크아웃에서 결과를 그대로 재현하기 어렵다. 이는 실제 실행 가능한 재현성 문제이며, 가격이나 손익 오류를 뜻하지 않는다. PR 작성자는 LF/CRLF 정책과 해시 대상을 명시적으로 고정하고 양쪽 체크아웃을 테스트해야 한다. 기존 고정 결과는 덮지 않고 보존한다.

기존 phase2 `comparison_note`가 가정 가격의 과거 시각이 독립 인증됐다고 잘못 기재한 문제는 `phase3/overlay-results.json`의 `phase2_comparison_note_erratum`과 `phase3-report.md`에서 명시적으로 정정했다. 원래 오류가 들어 있는 phase2 파일은 보존돼 있으므로 원본만 단독 소비할 경우 여전히 오해할 수 있다.

## 해석과 한계

두 표본은 중첩되므로 독립 성적으로 합산하면 안 된다. `strict_original_time_match`의 strict는 원본 경기시각 대조만 뜻하며 과거 T-30 수신·체결을 증명하지 않는다. 2026-11-03 수신한 과거 공식 가격 필드이며 예측 시점의 최초 배당도 증명되지 않았다. 경기 점수를 가격 연결에 쓰므로 결과 조건부 선택 편향이 남고 보관 점수의 별도 KBO 공식 인증도 없다. 2026년은 반복 열람된 기간이다. 모든 ROI는 가정 단폴 기준 음수이며, 확장 표본에서는 시장 적중률·ROI가 선수 모델보다 높았다. 차이 구간이 0을 포함하므로 새 후보의 우세나 유의한 열세를 확정하지 않는다. 검증된 실제 가격 ROI·모의 지갑 재생·운영 모델 채택 근거는 없다.
