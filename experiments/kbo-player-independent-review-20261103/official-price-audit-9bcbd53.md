## 결과

`restored-prices.jsonl` SHA-256은 `d9fc2f04fabec1fa41d29521aeafdb96e676747e59723396f36ba5c88a9b8117`로 일치한다. 원본 가격 누락 454경기 중 373경기이고, 그중 무승부 56·승패 317이다. 나머지 81경기는 이 복원 결과에 없다. 이 숫자는 원래 확보한 파일 범위만 뜻한다.

기록된 모든 응답 104건(마감 목록·페이지 2건, 회차 상세 102건)의 압축 해제 바이트 SHA와 HTTP 200을 확인했다. 상세 102건의 POST 경로, `gmId=G101`, 요청·응답 회차 ID/연도, 원문 표의 컬럼·값 대응과 발매 날짜 범위를 확인했다. 기존 행·라벨 및 경기 아카이브의 SHA와 fixture ID, 시장 ID는 고유하고 원행의 가격은 null이다.

373건 각각을 독립 코드로 보존된 상세의 일반 전체 승패 항목과 다시 연결해 원문의 `winAllot`·`loseAllot`, 홈·원정 팀 코드, KBO 리그, 날짜, 보관 점수, 회차·경기번호, 2-way 및 거부 상태를 대조했다. 328건은 `betId=2 / betTypId=2 / handi=21 / 야구 승패 / 일반 승패`, 45건은 구 형식 ID null·`handi=0`; 양쪽 핸디캡 수치 0, 무승부 배당 0, 경기·구매 거부 0이다. 각 케이스의 대응 원문 값과 결과 값이 일치했다. 예를 들어 2023년 43회 28번 KT–한화 7:7은 1.36/2.49, 2024년 39회 1번 LG–삼성 2:2는 1.57/2.05, 2026년 40회 192번 삼성–두산 5:5는 1.61/1.89다. 이 숫자는 사후 환급 표시 1.00/1.00을 원배당으로 역산한 값이 아니다.

## 시작 시각과 identity의 한계

기존 시작 시각과 공식 상세 시각이 같은 건은 124건, 기존 시각이 없어 비교하지 못한 건은 249건이다. 249건 모두 보존된 원본 아카이브에서 같은 날짜·홈·원정의 원행이 하나이고, 조회한 발매 기간 회차 원문에서 팀 방향·보관 점수·상품 조건을 만족한 후보가 하나임을 확인했다. 복수 후보를 임의로 고른 사례는 발견하지 못했다. 다만 249건은 **시각 미대조 회고 연결**로 별도 집계해야 하며, 아카이브 밖의 누락 경기나 독립 공식 fixture ID 검증까지 증명하지 않는다. 양 팀의 source 이름→코드는 소스 매핑을 확인했으며 공식 ID 독립 인증이라고 부르지 않는다.

공식 상세 점수와 기존 보관 라벨의 일치는 교차 점검이다. 이 감사가 KBO 공식 결과·수정 이력을 별도로 인증했다는 뜻은 아니다. 경기 취소·판매 거부·잘못된 상품·배당 1.00·후보 중복은 독립 테스트에서 거부 조건을 검사했다. 캡처된 자료 외의 가능한 회차가 없다는 주장은 하지 않는다.

## 시점·정산 경계

373건 전부 `source_observed_at=null`, `execution_price_verified=false`이고 응답 `received_at`은 2026-11-03의 실제 사후 수신 기록으로 보존돼 있다. 첫 응답 수신은 2026-11-03 01:34:08 UTC이며 모두 대상 경기 시각보다 뒤다. 이 자료는 **공식 마감 상세에 보존된 과거 가격 필드**이지 최초 개시가, T-30 가격, 실제 매수 가능 가격 또는 과거 실수신 증명이 아니다. 실행 전 고정 예측을 이용한 별도 `archived_price_scenario`로만 비교하며 원래 354경기 결과를 덮지 않는다. 무승부 환급은 해당 상품의 공식 정산 근거를 별도 확인해야 하며, 현시점의 사후 가격을 과거 체결가격으로 취급하지 않는다.
