## 데이터/모델 완성 후 필수 검사 사례

1. **기회와 identity**: fixture ID·공식 ID·날짜·수정 전후 kickoff·홈/원정·리그·시즌과 회차/상품 ID를 대조한다. 더블헤더·연기·시간 변경·팀 방향 역전·동일 경기 다른 회차의 가격 재발행을 합성해 실제 비교 단위와 중복 제거를 검사한다. 일치 근거가 부족하면 제외 사유와 원본 행을 보존한다. 동일 경기 다른 상품·다른 회차를 독립 경기로 부풀리지 않는다.
2. **시점 경계**: timezone-aware 판정시각 정확히 T-30, 1초 전/후; source/feature의 실제 수신·공식 발표 각각 결정 직전·동일·직후; 결측/naive 시각; 연기와 수정 전후 시각을 검사한다. 실제 pregame 증거가 없는 과거 자료는 `retrospective_unproven`로 진단하되 회고 수신을 소급 생성하지 않는다. 과거 공식 발표가 독립 보존된 경우 그 증거와 실제 수신 증명은 별도로 기술한다. SHA는 바이트 무결성만 나타낸다.
3. **선수와 이력 누출**: 예상·공식 확정 선발과 실제 경기 후 투입 선수를 구분한다. 발표/수신이 늦은 타순·타깃 박스스코어·동일 날짜 이전 경기의 불명확한 종료시각·미완료/늦은 수신 불펜 투구 기록·부분 누락 명단을 주입해 PIT 거부, 회고 가정 표기, null과 실제 0의 구분을 확인한다. 현재/미래 라벨·선수 통계 변조가 해당 시점의 특징·예측·학습 선택을 바꾸지 않아야 한다.
4. **시장과 환급**: 2-way와 3-way를 별도 상품으로 검증하고 전체 경기·정확한 선택지 순서와 ID·완전한 원 배당 벡터·시점을 모든 비교군에 동일하게 적용한다. 승/패 2-way에서 실제 규칙이 무승부 환급이면 원금 반환, 손익 0이며 적중·실패와 분리한다. 3-way 무승부는 독립 선택지다. 임의의 상품 규칙을 가정하지 말고 불명확하면 정산을 보류한다. 이진 확률 점수에는 실제 환급 경기의 조건부 표본/분모를 명시한다.
5. **가격 없는 자료**: `market=null`인 경기는 득점 모델 학습/진단에 사용할 수 있으나 시장 비교나 ROI의 분모에 넣지 않는다. 불완전 벡터, 실제 관측 시각 불명, 같은 경기 다른 회차의 가격, 전반·핸디캡·합계 혼입은 제외한다. 회고 가격의 과거 수신/체결 미증명과 파일 제공 범위는 따로 보고한다.
6. **결과 연결과 분모**: 라벨 파일을 예측과 분리하고 정확한 fixture·market·정산 규칙·revision으로 연결한다. 미정산·취소·무효·환급·중복·운영 보류 및 미연결을 구분하고 전체 기회→연결→적격→선택→정산 각 수와 모델별 공통 분모를 확인한다. 보류를 임의의 시장 선택으로 메우지 않는다. 빈 분모는 0%가 아니라 미산출이다. 예측 확률 합, 유한성 및 정산 전 예측 고정 해시를 확인한다.
7. **시간 분할과 모델 비교**: 고정된 구조·튜닝 범위와 결과를 보기 전 확정한 시간 분할을 확인한다. 변환·축소·보정은 학습 구간만 사용하고 테스트 라벨 변조 시 예측 및 설정이 불변인지 검사한다. 선수군·팀만 기준·동일 시점 시장, 그리고 실제 운영/픽스터 입력이 있는 공통 부분만 각각 비교한다. 선수·불펜 부재 층의 성능을 그 특징의 효과로 주장하지 않는다. 기존 2026 노출은 독립 맹검으로 부르지 않는다.
