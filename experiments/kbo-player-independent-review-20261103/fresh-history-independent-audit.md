# KBO 보완 선수 이력과 고정 결과 독립 감사

상태: `independently_verified_retrospective` — 고정된 네 입력과 예측 및 기존·보완 이력 8설정의 결과를 독립 재계산한 범위에서 불일치를 발견하지 못했다. 과거 실제 수신·체결을 인증한 결과는 아니며, 2026 성적을 이미 본 뒤 수행한 후향적 자료 품질 비교다.

## 동결 증거

부모 계약 `497cf651`, 공식 기록 PR 520 `d11367b7`, 데이터 PR 511 입력 `0d980b4`와 최종 인계 `13291d23`, 예측 PR 512 동결 `c91cc13d`, 별도 결과 커밋 `b160d3d1`을 검사했다. 네 입력과 불완전 타자 파일, V1/V2 정규화·원본 응답 묶음, 기존 예측·가격·계수·라벨 및 새 예측·결과의 Git blob과 해시를 확인했다. 새 예측 커밋이 결과 커밋의 조상이며 예측 SHA-256은 `9bcb16da33843f3e60b869c62d4b2cb67f65e346b87c1be215e49a2b9b5c1f0e`, 결과 SHA-256은 `0e4cfa3398a5cf07d99fb17fab6e533cb52b55be6a1b8293e5c92b92a3f94391`이다.

데이터의 예측 동결 당시 manifest와 최종 인계 manifest는 별도 바이트다. 비교한 결과 최종본은 `batter_zero_pa=518` 진단만 추가했고 네 입력과 불완전 파일의 해시는 동일하다. 예측이 앞선 manifest를 참조한 사실을 최종 manifest로 소급 변경하지 않았다.

공식 응답 묶음의 개별 원문 바이트와 해시를 검사하고 V1/V2의 경기·선수·일별 기록 연결 및 개인 투수 중복 ID 처리를 다시 구성했다. 독립 스크립트는 정규화된 선수 기록을 원천으로 사용하며 원본 HTML을 별도 파서로 다시 해석하지 않는다. 선수별 마지막 10개 완전 이력과 예상 타순·최근 5명 선발 선택을 재구성해 네 입력과 비교했고, 보완 경기 이력·불펜을 참조할 때의 횟수는 **91,576회**다. 네 설정과 대상 경기에서 같은 기록을 반복해서 세는 참조 횟수이며 고유 행 수가 아니다. 투수별 기록에는 같은 경기 중복 ID 8행이 제외되고, 팀 불펜은 공식 팀 아웃과 합계가 맞을 때만 사용한다.

타자 완전 관측은 3,939행이다. 이 중 **AB+BB=0이 537행**이고 실제 PA는 0이 518행, 1이 19행이다. 확인된 0은 관측으로 남기되 분모가 0이면 비율은 null이다. 볼넷이 확인되지 않은 3,026행은 `bb=null`인 별도 파일에 보존돼 있고 0으로 채우지 않았다. 그중 2,799행은 일별 자료 미수집, 227행은 선수 ID 미확보다. 투수 1,805행은 완전 관측이고 764행은 ID 또는 수치 미확보로 제외됐다. 보완은 부분적이다.

## 동일 경기 성적

기존 선수 이력과 보완 이력 모두 709경기이며 기존 193·신규 516과 7월 26일 이전 470·이후 239로 나뉜다. 두 분할 방식은 서로 겹친다. 이력과 선택 근거는 대상보다 이전 달력 날짜만 사용하며 비선수 특징은 기존 입력과 같다. 모델의 계수·평균·scale·alpha=100은 고정됐다. 2,836개 새 예측의 선수 scalar와 득점률 및 Poisson 확률을 다시 계산했으며 최대 오차는 `4.28e-11`이다.

## 가격·환급과 제한

각 표본에서 기존과 보완 설정은 같은 경기·가격·상품을 사용한다. 전체 strict는 439경기·환급 10건, extended는 667경기·환급 15건이다. `Decimal`로 8설정과 팀·시장 기준의 픽, 순손익, 월별 손익, 일일 마감 낙폭, 환급을 대조했으며 ROI 분모에는 환급 경기를 포함한다. 가격층별 보완 전후 주 단위 paired 구간도 일치했다. 7월 26일 이후 strict 가격은 **0건**이므로 해당 ROI는 0이 아니라 미정의다. 이후 extended는 228경기·환급 5건이다.

기존 공식 가격 감사에서 현재 `buyReject`가 1 또는 4였던 원본 가격 7경기를 모든 설정에서 공통 제외하면 전체 extended는 660경기·환급 15건이다. 이 별도 민감도의 기존 이력 ROI는 위 네 설정 순서대로 -9.65%, -8.90%, -9.77%, -7.89%, 보완 이력은 -10.05%, -9.01%, -9.78%, -8.94%다. 이후 228경기는 모두 이 공통 0 표본에 남는다. 현재 상태 코드의 과거 의미는 미확정이므로 당시 판매 불가 또는 실제 체결 가능으로 해석하지 않는다.

명단과 일정 선발은 후향적으로 알려진 것으로 가정한다. 공식 기록은 현재 재수신 자료이며 과거 발표·완료·수신 시각과 가격 실행 가능성은 증명되지 않았다. 2026은 이전 결과를 본 표본이고 모델은 보완된 공식 입력으로 새로 최적화한 모델이 아니다. 이 결과는 실전 ROI, 운영 9:1 대조 또는 월 5만원 지갑 재생이 아니다.
