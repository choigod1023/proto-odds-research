# K리그1·2 공식 명단 비교 독립 감사

고정된 입력·모델·예측·정산을 독립 재계산한 범위에서 수치 불일치는 발견하지 못했다. 공식 명단은 현재 재조회한 실제 선발을 당시 알고 있었다고 가정한 후향 자료다. 과거 발표·수신과 실제 가격 체결은 확인되지 않았고, 2026년 결과도 이미 열람한 표본이므로 독립 블라인드 검증이 아니다.

## 원천과 분할

K리그1 모델 PR 519 `b8f5117d2ec60f37562007dcd050c62d35e25d23`, K리그2 모델 PR 518 `32c690e55df246db5e122a037fd4eda0cd2c6be2`를 검사했다. K리그1 명단·manifest·일정은 공식 PR 516 `1f5ecca8`, K리그2 명단·census는 PR 515 `99dc30bd`의 Git blob 및 manifest와 바이트 단위로 일치했다. 두 모델의 가격과 manifest는 PR 517 `4f3ee6b2`에 고정된 동일 파일과 일치한다. 매칭된 시험 가격은 공식 회차 원문에서도 경기번호·양 팀 ID·시각·스코어·배당·상품·현재 상태를 대조했다. 공식 명단 원본 HTML을 별도 파서로 다시 해석한 것은 아니며, 공식 원천 PR의 정규화된 명단과 manifest를 기준으로 검사했다.

K리그1은 2025 학습 228경기, 2026 검증 90경기, 7일 경계에서 제외된 경기 0건, 7월 이후 시험 114경기다. K리그2는 학습 273·검증 120·시험 128경기다. K리그2 계약은 K리그1처럼 명시적인 7일 embargo를 두지 않지만, 실제 마지막 검증 경기는 6월 7일이므로 7월 이후 시험과 달력상 간격이 있다. K리그2 2025 플레이오프 274·275번은 연장전 등 정규시간 점수를 분리할 근거가 없어 두 경기 모두 제외했다. 각 2026 공식 일정 228·272경기에는 미종료 24경기씩이 포함되며 이들은 종료 경기 평가 분모에 넣지 않았다.

두 모델 모두 이력은 대상 경기보다 **앞선 날짜**의 같은 팀 선발명단만 사용하고, 같은 팀의 같은 날짜 경기가 여럿이면 그 날짜를 이력에 넣지 않는다. 실제 첫 시험 경기에서 당일·미래 점수를 극단값으로 바꾸고 다른 당일·미래 선발명단을 오염시켜도 독립 계산한 이력 특징은 그대로였다. 현재 경기 선발 ID 자체는 후향적으로 알려진 것으로 가정하며, 그 사실은 과거 사전 입수의 증거가 아니다. 경기 당일 결과·선수 득점·출전시간·교체 기록을 수치 특징으로 사용하는지와 선발명단 사전 확보 여부는 별개의 문제다.

이전 선발명단이 없으면 연속성을 0으로 넣되 결측 표시도 함께 넣는다. 3경기가 부족하면 관측된 횟수만 합하고 부족 표시를 넣는다. 이는 결측을 실제 로테이션 부재라고 단정하지 않는 처리지만, 0 대체가 추정 결과에 미치는 영향은 별도로 식별되지 않았다. 시험 표본에서 이전 이력 없음·3경기 부족은 양 리그 모두 0팀 슬롯이다. 훈련 초기 결측은 존재한다. 다른 대회·국가대표·리그 간 이동 이력은 포함되지 않는다.

## 고정 확률과 같은 가격 표본

동결된 팀별 계수와 선발 특징에서 홈·원정 득점률을 직접 구성하고, 독립 Poisson 격자와 K리그2 Dixon–Coles 0–0·0–1·1–0·1–1 보정을 계산했다. 동결 예측과의 최대 절대 오차는 `8.33e-16`이다. 예측·계수의 동결 커밋은 각 결과 커밋의 조상이며 예측 파일에 결과 점수는 없다. 검증용 재학습이나 새 후보 탐색은 하지 않았다. K리그2 DC는 Poisson 시험 결과를 본 뒤 등록된 추가 분석이다.

각 리그의 팀·선발·시장 비교는 동일한 113 또는 127경기에서 이루어졌다. 확률을 이용한 3-way 적중률·log loss·Brier, 시장의 역배당 정규화, 1단위 `Decimal` 손익, 월별 합과 일일 마감 최대 낙폭을 원래 결과와 비교했다. 두 리그 모두 시험 1경기는 공통 가격 표본에서 빠졌다. 원천 가격 제외 원장에는 K1 `kleague:2026:1:144`의 현재 `buyReject=1`, K2 `kleague:2026:2:163`의 현재 `buyReject=4`가 기록돼 있다. 이 현재 코드만으로 과거 실제 판매 불가를 단정하지 않는다.

정산은 무승부를 제3의 선택지로 취급하는 일반 승무패 상품이며, 취소·환급 또는 선택지 배당 1.00 상품은 이 동일 가격 표본에서 제외했다. 저장된 결과 점수·정산 코드와 일치하는지 확인했다. 연구 계약은 정규 90분과 추가시간을 기준으로 하며, 공식 회차 행의 가격·코드 대조만으로 경기별 점수가 연장전을 포함하지 않는다는 별도의 시각별 기록을 증명하지는 못한다. 플레이오프 두 경기를 제외한 이유도 이 구분이 미확인인 점이다.
