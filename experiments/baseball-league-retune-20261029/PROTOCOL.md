# MLB·KBO 에이전트별 재설계와 통합 검증

사용자의 두 모델은 직전 비교에서 개선을 재현하지 못한MLB·KBO로 해석한다. NPB는 기존 후보와 결과를 보존하고 이번 재탐색에 섞지 않는다. 각 리그 작업은 별도 codex 브랜치·worktree에서 수행한 뒤 부모 브랜치로 통합한다. 운영 코드·추천 정책·DB·배포는 변경하지 않는다.

공통 선택 규칙:

- 리그마다 최대32개 구체적 후보와 추가 효과 없는 시장 기준. 식·변수·범위는 평가 전에 각 에이전트의 protocol에 적는다.
- 2023학습→2024검증 선택→2023+2024재학습→2026평가. 임의 섞기 대신 날짜 순서를 유지한다.
- primary는 검증에서 시장 기준보다 적중률과ROI가 모두 나쁘지 않은 후보 중 logloss 최소, 이후Brier·이름 순으로 고른다. 시장 기준 자체도 포함한다.
- hit_leader는 검증 적중률 최대, 이후Brier·이름; profit_leader는 검증ROI 최대, 이후logloss·이름으로 따로 동결할 수 있다. 평가 수익을 보고 이들 중 운영용을 다시 고르지 않는다.
- 선별된 쉬운 경기만의 성과와 전체 성과를 혼동하지 않도록 원칙적으로100% 참여율을 유지한다. 원천 무결성 제외는 기준과 원래/유효 건수를 공개하고 동일 경기 기준선을 다시 계산한다.
- 월 손실 한도 없는 동일금액 단폴1만원. 무승부는 환불, 적중률에서는 제외하되ROI 투입금 분모에는 포함한다. 평가 기간별·선택 변경 수·일말 최대낙폭·paired 주단위 bootstrap을 공개한다.

MLB는 기존230경기의 실제 가격 관측 시각까지 완료된 과거 정보만 쓰는 검사를 우선한다. 해당 새 경기에는 픽스터가 없으므로 기준은시장 단독이며9:1로 부르지 않는다. 기존116경기의9:1은 별도 보조 검사다. KBO는 유효198경기의9:1을 같은 경기에서 다시 계산한다. 미확인 현재 선발·라인업을 사후 박스에서 가져오지 않는다.

부모 작업은 소스·기준선·후보 선택·정산·시점 가드를 독립적으로 검토하고 통합 테스트를 수행한다. 두 에이전트의 식이 달라지는 부분과 보존된 기준선을 구분한다. 현재평가 자료는 이미 본 회고 집합이며 미열람 홀드아웃이 아니다. 제한된 후보 중 검증에서 선택한 값을 수학적 전역 최적해나 미래 수익 보장이라고 표현하지 않는다.

참고: Bailey 외의 [백테스트 과최적화 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)는 다수 후보를 반복 비교할 때의 선택 문제를 설명한다. 이번 자료의PBO를 계산했다고 주장하지 않는다. [scikit-learn의 시계열 교차검증 설명](https://scikit-learn.org/stable/modules/cross_validation.html#time-series-split)은 미래 관측을 앞선 시점의 학습에 넣지 않는 설계의 참고다.
