상태 `prepared_waiting_for_model_freeze`: 계약 `7ceda125`와 고정 데이터만 검사했다. 모델 작업 중 파일은 평가 근거로 쓰지 않았으며 아직 실제 모델 예측·성적을 검산하지 않았다. 모델 예측 및 정산이 각자의 고정 커밋으로 인계되면 별도 증거와 결과를 이 브랜치에 추가한다.

계약 SHA-256은 `6ffdf7947559df052c248a1f9fb5e7ad871321f52e7920126934bf21771465ed`다. 2023·2024·2025·2026 고정 자료는 각각 723·728·736·726경기다. 후향 2026 선수 시나리오 두 개는 같은 709경기이며 타순·선발 이외의 입력은 같다. 선수 이력·예상 선택 근거의 경기 ID와 날짜는 타깃보다 이전 달력 날짜임을 검증했다. 경기 전 수신·완료를 인증한 것은 아니다.

검토 전제: 2023~2025 학습 명단은 과거 경기로 예상한 선택자다. 2023년 공식 연결 169건은 사후 조사이며 전체 학습 명단을 공식 확정 명단으로 바꾸지 않는다. 2026 보완 이력과 학습 연도의 원천 범위 차이는 비교의 해석 한계다. 원본 투수 `bf`는 실제 투구 수일 가능성이 있어 타자 수 분모로 쓰지 않는다. 선수 ID 효과는 팀·기용에 영향을 받는 예측상 연관이지 인과 효과가 아니다.

`audit_math.py`는 모델 코드를 가져오지 않고 타순별 고정 가중치, 타자와 상대 선발 역할, 미등록 ID와 결측 표시, 3-way Poisson 꼬리와 softmax, 2-way 무승부 환급 Decimal 정산, 월 합·일일 마감 낙폭 및 사전 등록된 동률 규칙을 독립 계산한다. 합성 검사는 검토기 자체의 경계 검증이며 실제 모델 구현이 통과했다는 뜻이 아니다. 정규화는 학습 집합에서만 추정됐는지, 미등록 선수의 ID 계수는 0인지, 별도의 미등록·결측 표시가 유지되는지를 모델 고정 이후 각각 확인해야 한다. 미등록 표시의 모델 계수가 실제로 0이어야 한다는 뜻은 아니다.
