# KBO M2 결측 표시 수정본 독립 감사

상태 `verified_retrospective_correction`: 고정된 수정 설계·선택·예측·정산을 독립 재계산했다. 원본 M2의 결측 표시 상쇄는 **구현 결함**이었고, 등록된 두 상쇄 사례는 수정 설계에서 구분된다. 수정은 원본 2026년 결과를 본 뒤 등록됐으므로 블라인드 검증이 아니다.

## 수정 범위와 회귀 검사

수정 계약 `ebe25eb7`에 따라 M2의 기존 방향 차이와 선수 ID 노출을 유지하고, 기존 수치 결측 8개와 선수 명단 품질 4개의 양 팀 합계 **12열**만 추가했다. 추가 열은 기존 기본 변수와 같은 L2=10을 쓴다. 선수 페널티 후보 1·10·100, 시간 분할과 계열 선택 규칙은 바뀌지 않았다.

고정 수정 코드 `849e43a5`의 실제 설계행을 별도 구현과 비교해 최대 오차 `2.23e-16`으로 일치했다. 양 타순·선발이 모두 결측인 경우와 모두 미등록인 경우, 양측 수치가 null인 경우와 관측된 학습 평균·0인 경우는 원본에서 각각 같은 행이었고 수정본에서는 달랐다. 한쪽 및 양쪽 상태, 홈·원정 교환 시 방향 차이의 부호 반전과 합계의 보존도 검사했다. 원본 M0·M1 및 기존 계약·선택·모델·예측·정산 바이트는 보존됐다. 기존 [원본 감사](final-audit.md)의 상쇄 발생 건수와 원래 결과는 수정하지 않았다.

## 동결·선택·예측

수정 선택은 `d28b4101`, 예측은 `18c2e84d6962f9016b20996e543e5b4bb6c70975`, 정산은 별도 `d08ccb708033fb6b067e84e80eae81ea3c9b4cfa`에 고정됐다. 예측 커밋은 정산 커밋의 조상이다. 수정 예측 SHA-256은 `6d3dd2cc15d4a4681335e1984c76e8526bf94aae9f46fe372d5b4c10b1abced5`, 결과 SHA-256은 `1b120334063c0ff535d3ff74c3ab0f55dc01a3c4bb878204b745b05f2c0d1b55`다. 수정 계약·선택·모델·예측·결과를 별도 임시 clone의 `core.autocrlf=true/false` 양쪽에서 정확히 재현했다.

2023년 723경기로 수정 M2의 등록된 세 페널티를 독립 재적합해 2024년 728경기에 평가했을 때 **100**이 선택됐다. 가장 큰 독립 재최적화 log loss 차이는 약 `1.52e-7`이며 선택은 동일하다. 원래 M0·M1의 2025 점수를 그대로 쓰는 고정 규칙에서 2025년 736경기 선택도 **M2**였다. 2023~2025년 학습 전용 선수 사전·평균·scale을 다시 구성했고, 수정 M2의 두 2026 시나리오 1,418개 확률은 최대 `2.23e-16` 차이로 재현됐다. 독립 선택·예측 재계산에는 2026 결과를 사용하지 않았다.

## 동일 2026 경기의 원본·수정 비교

두 시나리오는 동일 709경기다. 선수 명단은 예상 명단이 주 시나리오이며, 공식 타순·일정 선발은 경기 전 가용했다고 가정한 후향 보조 시나리오다.

| 시나리오 | M2 원본 적중 | M2 수정 적중 | 원본 log loss | 수정 log loss | 3-way 픽 변경 |
|---|---:|---:|---:|---:|---:|
| 예상 타순·선발 | 390/709 | 395/709 | 0.771886 | 0.772314 | 47 |
| 공식 타순·선발 가정 | 389/709 | 390/709 | 0.771351 | 0.772346 | 37 |

전체 무승부는 16/709경기다. 예상 시나리오의 평균 예측 무승부 확률은 원본 1.93%, 수정 1.95%이며, 비무승부 693경기의 조건부 log loss는 0.679601→0.680218, Brier는 0.486632→0.487249다. 적중은 390→395다. 공식 가정의 조건부 log loss는 0.678889→0.679976, 적중은 389→390이다. 확률 점수와 픽 적중은 서로 다른 지표이며 이 결과로 사후 선택하거나 운영에 채택하지 않는다.

## 동일 가격과 환급

| 시나리오·가격층 | 경기·환급 | 원본 M2 ROI | 수정 M2 ROI |
|---|---:|---:|---:|
| 예상 · strict | 439·10 | -12.19% | -10.29% |
| 예상 · extended | 667·15 | -9.02% | -7.93% |
| 예상 · extended, 현재 reject 7건 제외 | 660·15 | -9.17% | -8.07% |
| 공식 가정 · strict | 439·10 | -12.55% | -12.98% |
| 공식 가정 · extended | 667·15 | -8.73% | -8.51% |
| 공식 가정 · extended, 현재 reject 7건 제외 | 660·15 | -8.88% | -8.66% |

전체 원장에는 M0·M1·원본 M2·수정 M2·이전 고정 기준선·팀·시장이 동일 경기와 가격으로 들어간다. 독립 검사에서 2개 시나리오와 4개 가격층의 Decimal 손익·환급·월별 합·일일 마감 최대 낙폭 및 주 단위 paired 구간이 고정 결과와 일치했고, M0·M1과 기존 기준선 원장도 원본과 같았다. 무승부는 원금을 환급하고 ROI 분모에 포함한다. strict는 시작 시각 일치일 뿐 가격의 과거 수신이나 실제 체결을 인증하지 않는다. 현재 reject 코드 7건을 뺀 값도 별도 민감도일 뿐 과거 판매 가능 여부를 나타내지 않는다.

## 한계와 재현

이전 결과를 본 후 오류를 고친 진단으로, 2026 성능으로 가족·페널티를 다시 고르지 않았다. 명단과 가격의 실제 사전 수신 및 실행 시각은 입증되지 않았다. 학습 명단은 이전 경기 기반 예상이며 2023년 사후 공식 연결 169건을 전 기간 확정 명단으로 취급하지 않았다. 원본 투수 `bf`를 타자 수 분모로 사용하지 않는다. 실제 ROI·운영 9:1·월 5만원 지갑 재생이나 인과 선수 가치로 해석하지 않는다.

`audit_v2_code.py`, `audit_v2_frozen.py`, `audit_v2_results.py`, `audit_v2_bytes.py`를 이 디렉터리에서 Python으로 실행하면 각각 고정 코드 설계, 내부 선택과 예측, 정산·보조 진단, 줄바꿈 설정별 바이트를 확인한다. `python -B -X utf8 -m unittest discover -s experiments/kbo-player-effects-review-20261103 -p 'test_audit*.py' -v`의 16개 검사는 원본 상쇄 재현과 수정된 양측 상태 구분을 포함한다. 고정 원천 Git 객체가 필요하며 원본 worktree나 산출물은 수정하지 않는다.
