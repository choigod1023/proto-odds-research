# 리그별 독립 장기 실험 — 2026-09-07

## 결론

요청에 따라 리그를 공동 학습하지 않고, **종목+리그+마켓+선택지 수별로 완전히 독립된
확률 보정 모델**을 학습했다. 2025-01-01~2026-08-25에 분기별 재학습·평가한 결과,
이번 두 후보에서 다중 비교를 고려한 개선 기준을 통과한 리그는 없었다.

이는 리그별 모델 전체가 쓸모없다는 결론이 아니다. **배당 기반 확률 보정과 최근성 가중만으로
지속적인 개선이 확인되지 않았다**는 결론이다. xG·선발·라인업 특징의 가중치는 이 실험 범위가 아니다.

## 자료와 기간

- 기존 완성 아카이브: 2023~2026년 184,473개 마켓 행. 입력 파일은 수정하지 않았다.
- 승패·승무패·풀타임 언더오버·핸디캡을 대상으로 정규화한 141,246개 고유 마켓,
  45,852개 경기. 배당/결과가 충돌하는 재발매 445개 offer 그룹은 모두 제외했다.
- 학습 시작: 2023-01-01. 분기마다 해당 분기 시작 7일 전보다 이른 경기만 사용한다.
  예를 들어 2025 Q1은 2024-12-25 미만, Q2는 2025-03-25 미만이다.
- 평가: **2025-01-01~2026-08-25**, 약 20개월. 이후의 최근 운영 기록을 섞지 않았다.
- 133개 리그/대회 중 같은 리그·마켓 학습 200건 조건을 충족한 30개에서
  **56,807개 마켓 / 18,770개 경기**를 평가했다. 동일 경기의 여러 마켓을 여러 독립 경기로 세지 않았다.
- 30개 중 28개는 평가 최소 300마켓·150경기·26주 요건까지 충족했다.
  WKBL(297마켓)과 U네이션(10마켓)은 평가 부족이다. 나머지 103개 대회는
  다른 리그 자료를 빌려 모델을 만들지 않고 학습 부족으로 명시했다.
- 이 수치는 서비스가 당시 저장한 실제 추천픽의 적중률이 아니다.
  아카이브의 모든 평가 대상 마켓에서 최대 예측 확률의 선택지를 고르는 재구성 실험이다.

## 독립성·모델

Shin 시장 확률을 비교 기준으로 쓰고, 각 리그·마켓의 다항 확률 분포를 별도 보정한다.
모델은 softmax((1+a) log(q) + class_bias)이고 클래스 확률 합계는 1이다.
각 모델의 계수와 학습 표본·날짜·해시가 report.json의 folds에 남는다.

- independent: 그 리그·마켓의 앞선 전체 기록만으로 학습.
- independent_recent180: 같은 범위에 180일 반감기를 적용. 가중치 평균은 1로 정규화.

두 후보는 고정된 ridge=10을 사용한다. 리그 간 계수·평가 데이터·학습 데이터 공유나
표본 부족을 이유로 한 상위 종목 모델 대체는 없다. 설정은 탐색값이지 최적 가중치가 아니다.
평가 결과로 후보를 선택해 다시 보고하지 않고 두 후보 모두 공개한다.

## 대표 리그 결과

아래 오차 감소율은 Brier 상대 감소율이다. 양수는 개선, 음수는 악화이며 적중률 변화가 아니다.

- MLB 11,790마켓: 독립 보정 **+0.037%**, 최근 가중 **-0.029%**.
- NPB 4,255마켓: **+0.091%**, **+0.077%**.
- KBO 3,675마켓: **-0.148%**, **-0.269%**.
- EPL 2,203마켓: **-0.124%**, **-0.301%**.
- K리그1 1,246마켓: **-0.193%**, **-0.464%**.
- 세리에A 1,846마켓: **+0.272%**, **+0.291%**.
- KOVO여 613마켓: **+0.937%**, **+0.635%**.

독립 보정의 마켓 선택 적중률 예:

- MLB 58.65%→58.82%, NPB 59.11%→59.01%, KBO 59.32%→59.10%.
- 세리에A 52.65%→54.01%, KOVO여 56.28%→57.26%.

확률 오차와 적중률의 방향은 항상 같지 않다. 모든 평가 리그에서 두 후보의
아카이브 배당 기준 동일 금액 모의 ROI는 음수였다. 당시 실제 체결 가능 가격이나
서비스 추천 정책의 성과로 간주하지 않는다.

## 유의미성 판정

같은 마켓의 기준/후보 손실을 대조하고, 동일 경기 마켓의 상관관계와 단기 추세를
고려해 4개 달력 주 단위 원형 이동 블록 부트스트랩을 10,000번 실행했다.
빈 주도 달력 축에 보존한다. Brier·로그손실 95% 구간과 중심화 부트스트랩의
양측 근사 p값을 제공한다. 이는 정확 무작위배정 검정이 아니며 긴 기간의 비정상성과
수집 누락을 완전히 제거하지 못한다.

30개 평가 리그 × 2후보 × 2지표 = **120개 비교에 Holm 보정**을 적용했다.
개선 판정에는 표본 요건, 두 지표의 양의 개선 구간과 보정 p<0.05,
2025년과 2026년 모두의 두 지표 개선을 함께 요구했다.

KOVO여의 독립 보정은 개별 비교만 보면 Brier p≈0.0076, 로그손실 p≈0.0064였다.
하지만 120개를 탐색한 다중 비교를 고려하면 각각 약 0.889, 0.755여서 통과하지 못한다.
이처럼 좋아 보이는 일부 리그만 골라 ‘성공’이라고 보고하지 않았다.

## 중요한 한계

1. 과거 아카이브에는 배당 관측/판매 시각과 결과 공개 시각이 없다. 7일 간격은 보수적
   장치일 뿐 당시 정보 이용 가능성을 증명하지 않는다. 실제 T-30 검증이 아니다.
2. 기존 과거 연구에서도 사용된 자료이므로, 새 미래 표본의 사전등록 검증이 아니다.
3. 주 단위 추론은 시장 행을 독립 경기로 오인하는 문제를 줄일 뿐, 누락·가격 충돌
   제외와 모형 선택의 모든 편향을 없애지 못한다.
4. 서로 다른 리그/대회 이름을 임의로 합치지 않았다. 이름이 바뀐 대회나 신규 대회는
   표본이 부족할 수 있다. 결과가 없는 대회를 실패율 0%로 표시하지 않는다.
5. 이번 Brier는 **선택지 전체의 제곱 오차 합**이다. 이전 이틀 실험의 선택된 픽 하나에
   대한 이진 Brier 수치와 절댓값을 직접 비교하면 안 된다.
6. 조합 베팅·개인 베팅 기록·특징 수집 확대·운영 DB 마이그레이션은 수행하지 않았다.
