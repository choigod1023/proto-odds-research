# KBO 최근 타격 부진: 로컬 시간순 검증

2026-10-20. 운영 정책 변경·모델 승격·배포 없음.
결론: 최근 타격 부진 변수를 운영 확률에 추가할 근거는 아직 부족하다.
일부 소표본 수익은 양수지만, 확률 정확도와 수익 안정성이 함께 개선됐다고
확인할 수 없다. 아래 수치는 실제 사용자 손익이나 앞으로의 기대수익이 아니다.

## 재현과 데이터

```powershell
python src/batting_slump_validation.py --games <기존 processed_games CSV> --output experiments/batting-slump-20261020/report.json
python -m unittest discover -s tests -p test_batting_slump_validation.py -v
```

누락된 games.csv는 기존 로컬 accuracy-formula-lab 작업 폴더의 읽기 전용
원본으로 복구했다. 다른 작업 폴더나 운영 DB는 수정하지 않았다.
원본 SHA256: `dfe95c2ace14ee42142ea0c86912b68359bc8ebee9ad3cb566812815bdec0eb0`.
타격·선수·투수 원본은 이 저장소의 `data/raw/detail/kbo_*_2023_2026.json`.
전체 수치와 월별 손익은 [report.json](report.json)에 있다.

- 2023년부터 누적 학습. 2024년 검증은 2023년만 학습하고, 2025년 검증은
  2024년까지, 2026년 검증은 2025년까지 학습한다.
- 검증 경기: 2024-03-23~2026-07-26. 승패 1,810경기, 언더오버 1,847경기.
- 시즌별 승패 표본: 2024년 705 / 2025년 673 / 2026년 432.
  언더오버: 712 / 692 / 443. 2026년은 완전한 시즌이 아니다.
- 최대 40경기 타격 수준 대비 최근 5·10·20경기 wOBA 변화량을 각각 비교.
  볼넷·단타·2루타·3루타·홈런 기반 근사 지표이며 HBP/SF는 포함되지 않는다.
- 기본 비교 모델(context)은 시장 확률에 최근 득점, 라인업 wOBA,
  선발 xFIP, 구장 과거 총득점을 추가한 로컬 모델이다. **운영 모델 자체가 아니다.**
  시장 단독 및 시장 절편 보정 모델도 함께 기록한다.
- 모든 배당 확률은 운영과 같은 Shin 방식. 첫 파이프라인 점검에서 사용한
  비례 마진 제거법을 Shin으로 맞춘 뒤 최종 결과를 산출했다.
- 같은 날짜 전체가 끝난 뒤에만 누적 통계를 갱신한다. 더블헤더 등 날짜 키가
  모호한 경기, 결과 충돌, 복수 총점 기준선은 제외한다. 동일 경기 재발매는
  고정된 회차·게임번호 순서로 한 건만 남긴다.
- 점수와 시장 결과를 교차 검산했으며 최종 결합 자료에서 충돌은 0건.
- 선발 xFIP 결측은 승패 378건, 언더오버 383건. 각 학습 구간의 중앙값으로
  대체하며, 이를 완전한 선발 정보 검증이라고 해석하지 않는다.
- 정규화·결측 대체·계수 학습은 과거 학습 구간만 이용한다.
  창 길이별 결과 중 최댓값을 찾아 운영에 승격하는 절차는 없다.

## 확률 정확도

Brier는 낮을수록 좋다.

- 승패: 시장 단독 0.239208, 기본 비교 모델 0.238502.
  5경기 부진 추가 0.238549, 10경기 0.238592, 20경기 0.238433.
  20경기 지표의 개선은 약 0.000069이며 날짜 단위 부트스트랩의
  기본 모델 대비 오차 차이 95% 구간은 -0.000247~+0.000064로 0을 포함한다.
- 승패 10경기 지표는 2024·2025·2026년 모두 기본 모델보다 Brier가 나빴다.
  특정 베팅 정책의 손익 개선과 확률 예측 개선을 혼동하면 안 된다.
- 언더오버: 시장 단독 0.248275, 기본 비교 모델 0.249551.
  5경기 추가 0.249812, 10경기 0.249375, 20경기 0.249516.
  세 모델 모두 시장 단독보다 오차가 크다.
- 날짜 단위 신뢰구간은 날짜별 평균 오차 차이를 재표집한다.
  경기별 전체 Brier와 가중 방식이 다르다. 다중 비교 보정은 하지 않았으므로
  탐색 결과이며, 유의성·인과관계 또는 시장 효율성의 증명이 아니다.

## 월 손실 5만원 제한 모의 운용

고정 규칙: 하루 최대 한 장, 서로 다른 두 경기, 한 장 1만원, 주 최대 2회 또는
3회. 해당 주에서 조건을 충족하는 날짜부터 선택하고 예상 이익 순으로 고른다.
음수 예상 이익도 순위로 고르는 경우와 양수만 허용하는 경우를 구분했다.
월 +5만원 도달 후 중단하는 경우도 별도로 기록했다.

다음 한 장이 전패해도 월 누적 손익이 -5만원 아래로 내려가지 않을 때만
진입한다. 손익은 베팅일의 월에 귀속하고 하루의 베팅은 다음 날짜 전에
정산된다고 가정한다. 실제 정산 시각·연기 경기는 재현하지 못한다.
배당은 두 배당의 곱을 그대로 사용하며 별도 올림·세금·수수료를 가정하지 않는다.
배당 곱은 지급액 계산이지 두 경기의 독립성이 입증됐다는 뜻이 아니다.

### 주 최대 2회, 예상 이익 순위로 선택, 목표 수익 중단 없음

승패:
- 기본 비교 모델: 145장, -100,866원, ROI -6.96%.
- 최근 5경기 추가: 142장, -125,350원, -8.83%.
- 최근 10경기 추가: 145장, -13,707원, -0.95%.
- 최근 20경기 추가: 145장, -58,902원, -4.06%.

10경기 모델은 손실을 줄였지만 주 최대 3회로 바꾸면 -7.35%로,
기본 모델 -7.12%보다 조금 나빴다. 정책 변화에도 일관된 개선이 아니다.

언더오버:
- 기본 비교 모델: 134장, -171,232원, -12.78%.
- 최근 5경기: 134장, -153,525원, -11.46%.
- 최근 10경기: 126장, -471,772원, -37.44%.
- 최근 20경기: 137장, -99,824원, -7.29%.

### 양수 예상 이익만 허용

승패의 주 최대 2회:
- 기본 비교 모델: 15장, +3,549원, +2.37%.
- 최근 5경기: 17장, -2,405원, -1.41%.
- 최근 10경기: 15장, +27,860원, +18.57%.
- 최근 20경기: 14장, +39,729원, +28.38%.

**양수 ROI가 나온 경우도 숨기지 않지만, 여러 시즌 합계 14~15장에 불과하다.**
최근 20경기 모델의 최대 누적 낙폭은 4만원이며, 경기 자료가 있는 21개월 중
흑자 6개월, 월 +5만원 달성 0개월이다. 이것으로 월 5만원 수익 목표를
뒷받침하지 못한다. 활동 가능한 날짜만 세므로 매주 2회가 보장되는 것도 아니다.
언더오버의 양수 예상 이익 필터는 모든 추가 모델에서 손실이었다.
월 단위 블록 부트스트랩 ROI 구간은 JSON에 전부 저장했다.
최근 10경기 모델의 ROI 95% 구간은 약 -33.3%~+96.0%,
20경기 모델은 -42.6%~+115.5%로 모두 0을 포함한다.
거래가 드문 자료의 신뢰구간 자체도 불안정하다.

## 기존 실험 재실행

누락 CSV 경로를 명시해서 기존 `lineup_batting.main()`도 재실행했다.
타선 wOBA 차이와 득점 차이 상관 +0.1202, 합과 총득점 상관 +0.0873을 재현.
이번 CSV로 결합된 승패 검증 1,125경기에서 기존 시장 기준
Brier 0.23768 → 타선 추가 0.23824로 악화했다.
이는 옛 문서와 데이터 결합 표본이 다른 재실행이며, 위 새 실험과도
학습 구간·배당 정리 방식이 다르므로 서로 같은 실험으로 합산하지 않는다.
스크립트의 “시장이 이미 안다” 출력은 통계적 결론으로 채택하지 않는다.

## 남아 있는 검증 장애와 결정

1. 보관 배당이 추천 당시 실제로 구매 가능한 가격이었는지 시각 증거가 없다.
   첫 발매 순으로 고르는 것만으로 이 문제가 해결되지는 않는다.
2. 선발·라인업은 경기 후 박스스코어에서 복원했다. 발표 시각과 그때의 배당을
   함께 입증하지 못하므로 실제 베팅 가능 ROI가 아니라 회고적 대리 실험이다.
   같은 날 전체 후보 중 상위 둘을 선택할 때 그 정보가 첫 경기 시작 전에
   모두 공개됐는지도 보장하지 못한다.
3. xFIP 결측, 상대 투수·구장 보정의 근사, 역사적 일정 강도 미보정 등
   잔여 교란이 있다. “타격 부진이 승패에 직접 영향을 주지 않는다”는
   인과 결론을 내릴 수 없다.
4. 데이터는 2026년 7월까지다. 오늘 LG가 부진한지 또는 오늘 픽이 유리한지를
   이 결과로 단정하지 않는다.
5. 경기 전 시각이 확인된 배당·라인업·선발·공식 결과 결합 자료에서
   사전 고정한 조건으로 재검증하기 전까지 운영 확률·추천 정책을 변경하지 않는다.

이번 변경은 독립적인 오프라인 검증 도구와 회귀 테스트뿐이다.
월 손실 한도는 모든 모의 조건에서 유지한다. 테스트는 같은 날짜 누수,
검증 결과를 바꿔도 예측이 바뀌지 않는지, 동일 경기 중복 조합 방지,
전패 위험 예약, 주간 상한, 이익 목표 중단, 후보 부족을 확인한다.
