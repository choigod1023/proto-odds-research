# 연속 경기 자료 연결과 연구 결과 독립 검산

이 작업은 원천 사이트 발견이나 소수 표본 수집에서 끝났던 이전 작업을 보완한다. 종목별 격리 워커가 연속 이력 수집·식별·시계열 특징·학습·평가를 수행하고, 총괄은 저장된 예측의 손익과 확률 점수를 별도 코드로 다시 계산한다. 연구 PR은 운영 모델 채택이나 배포가 아니다.

실행 범위는 KBO·KBL·NBA·KOVO/VNL의 **양방향 승패 연구 후보**다. 픽스터 원문·대상 경기의 확정 명단을 새로 넣은 운영 투표/M0 전체 재현이나 언더오버·핸디캡 비교를 완료했다고 주장하지 않는다. 비교자의 실제 정의와 누락 자료를 종목별로 구분한다.

## 완료를 막았던 부분과 수정

- **NBA 팀명 오진:** PowerShell 출력의 인코딩 문제를 원본 데이터 손상으로 잘못 판단했다. gzip 원본을 UTF-8로 직접 읽자 NBA 4,713행의 팀명은 30개이며 U+FFFD 손상은 0개였다. `audit_research_archive_text.py`는 원본 바이트·해시·명시적 별칭을 검사하며 결과를 보고 이름을 추측하지 않는다. 별칭 30개로 원천 연결을 복구했다.
- **상세 기록 미연결:** 일정·결과와 달리 KBL 효율 계산에는 선수별 야투 시도, 공격 리바운드, 턴오버가 필요하다. 연속 박스를 수집해 팀 합계를 검증했다. NBA도 일정 응답에 빠진 공격 리바운드·턴오버를 경기별 상세 응답에서 수집한다.
- **배구 원천 경로 누락:** DB Bank 루트만 보고 연속 수집이 불가능하다고 판단한 것은 성급했다. 일반 팬용 공식 사이트에서 공개 일정을 확인했고, 알려진 252개 경기의 공개 결과 페이지와 연결했다. API 호스트의 robots 제한을 확인한 뒤 그 호스트에는 추가 요청하지 않았다. VNL 대체 자료를 KOVO 자료라고 표시하지 않는다.
- **KBO 이용조건 확인 부족:** 이전에 제안한 MyKBO는 [약관](https://mykbostats.com/tos/)이 스포츠 베팅 지원 용도를 금지한다. 이 목적의 신규 수집과 사용을 중단했다. 기존에 별도로 보존한 이력으로 실행한 연구와, 새 장기 원천 확보 실패를 구분한다.
- **검증과 수집 복구:** KBL 429가 반복되면 다음 경기로 넘어가지 않고 배치를 중단·기한 저장하도록 수정했다. NBA의 손상 캐시는 재조회로 덮어쓰지 않고 보존·중단한다. 빠진 최근 기록을 더 오래된 경기로 대체하지 않는다. KBO의 미래 행에서만 등장하는 과거 기록과 나중에 알려진 충돌이 과거 특징을 바꾸지 않도록 차단했다.

## KBL: 526개 박스에서 152경기 평가

워커 [PR #666](https://github.com/choigod1023/proto-odds-research/pull/666), `codex/kbl-history-20261108e`. 공식 일정의 526경기 상세 응답 중 점수·출전 시간 합계가 일치하는 525경기를 사용했다. 최근 10경기, 대상일 최소 4일 전 정보로 계산한 순효율 차이를 시장 로그오즈에 계수 하나로 더했다. 2025년 학습·검증 후 계수를 고정해 2026-01-01~05-13의 공통 152경기를 비교했다.

- 시장: 99/152 적중, 65.13%, 조건부 ROI −8.64%, 로그손실 0.63125, 일 마감 MDD 16.62단위.
- 새 효율 모델: 100/152 적중, 65.79%, ROI −7.48%, 로그손실 0.63016, MDD 15.55단위.
- 이전 득실차 연구 비교자: 86/152 적중, 56.58%, ROI −13.93%.

새 후보가 시장 대비 바꾼 선택은 **1개**다. 그 한 경기의 적중으로 ROI가 1.16%p 나아졌으므로 안정적인 개선이나 운영 교체를 입증하지 못한다. 2025년 최초 이력 부족과 공식 일정 누락은 워커 보고서에 별도 기록했다.

## KBO: 보존 구원 이력의 443경기 평가

워커 [PR #665](https://github.com/choigod1023/proto-odds-research/pull/665), `codex/kbo-history-20261108e`. 2025년 공통 603경기로 학습·검증하고 2026-04-07~10-10의 공통 443경기에서 평가했다. D−18~D−4 구간의 구원투수 ID별 재등판 집중도를 사용했다. 실제 피로·부상·당일 선발 명단을 측정한 모델은 아니다.

- 시장: 252/433 적중, 58.20%, 조건부 ROI −10.58%, 로그손실 0.67697, 일 마감 MDD 51.14단위.
- 보존 M0_projected 연구 예측: 245/433 적중, 56.58%, ROI −10.59%, 로그손실 0.68618, MDD 56.11단위.
- 새 구원 재등판 모델: 248/433 적중, 57.27%, ROI −11.95%, 로그손실 0.67907, MDD 57.24단위.

무승부 환불 10건은 적중률 분모에서 제외하고 ROI 분모에는 포함했다. 새 후보는 시장 대비 적중률·ROI·확률 점수가 모두 나빠졌다. M0_projected는 현재 운영 모델의 재현이 아니며 두 모델의 이력 지연도 다르다. 2025년 가격 교집합의 무승부 사후 제외, 후반기 이력 누락과 원천 수신 시각 미인증 때문에 전체 모집단 성과라고 주장하지 않는다. 새 KBO 원천의 대량 수집은 이용 가능한 권한을 확보하지 못해 완료하지 못했다.

## KOVO: 252개 공식 결과와 125경기 가격 연결

워커 [PR #664](https://github.com/choigod1023/proto-odds-research/pull/664), `codex/volleyball-history-20261108e`. 2025–26 정규리그 252경기의 날짜·팀·시작 시각·세트 승수를 공식 일정과 대조했다. 리시브 효율의 최근 최대 10경기 평균(최소 5경기, 4일 지연)을 시장 로그오즈에 더했다. 학습 구간의 표준편차만 사용해 단위를 맞추는 규약을 성과 확인 전에 고정했다.

- 남자: 2026년 공통 63경기, 시장과 후보 모두 39/63(61.90%), 조건부 ROI −17.05%. 로그손실은 0.65268 → 0.65090.
- 여자: 공통 62경기, 모두 36/62(58.06%), ROI −24.55%. 로그손실은 0.67976 → 0.68813으로 악화.

남녀 모두 선택 변화는 0개이며 확률 점수 차이의 날짜 단위 95% 구간도 0을 포함한다. 첫 결과를 본 뒤 학습 정답에도 4일 지연을 적용하는 시간 경계 수정을 했으므로 원래 규약 그대로 실행한 블라인드 결과라고 부르지 않는다. 수정 후에도 선택 변화는 0개다. 사전 수신·정산 규칙·실제 구매 가능성은 인증하지 못했다.

## VNL 대체 실험: KOVO와 분리

공개 제3자 VNL CSV의 2025년 기록으로 리시브 성공률 변수를 학습하고 2026년 남자 48경기·여자 81경기를 비교했다. 남자는 시장과 후보 모두 38/48(79.17%), ROI −0.31%; 여자는 모두 62/81(76.54%), ROI −3.26%였다. 선택 변화는 0개다. 작은 비율 단위에 강한 정규화를 적용해 계수가 거의 0이 된 한계가 있으며, 이 결과만으로 리시브 정보가 쓸모없다고 결론 내리지 않는다. 원문은 공식 인증 자료가 아니며 로컬에만 남긴다.

## 독립 검산 방법

`scripts/audit_history_forecasts.py`는 학습 코드나 워커 지표 함수를 호출하지 않는다. 저장된 확률·승자·같은 경기의 배당으로 선택과 Decimal 단위 손익을 재계산한다. 중복 ID·모델별 표본 불일치·잘못된 확률·가격은 거부한다. KBO에 보존된 선택·배당도 확률과 대조한다. 로그손실은 자연로그, Brier는 이항 정의, MDD는 날짜별 손익을 합친 **일 마감 기준**이다. 워커가 표시한 경기별 MDD와 같다고 가정하지 않는다.

같은 경기·가격을 사용한다는 것은 각 모델이 고른 쪽의 배당이 같다는 뜻이 아니다. 공통 가격 벡터에서 각 모델의 선택에 해당하는 배당을 사용한다. 모든 ROI는 경기당 1단위를 가정한 조건부 회고 손익이며 실제 구매, 월 지갑, 실전 기대수익이 아니다. 결과를 보고 월 손실 한도나 배팅 수를 바꾸지 않는다.

원천 수집 시각은 2026-11-08의 실제 수신 시각이다. 과거 경기 전에 수신했다는 증거로 소급하지 않는다. 해당 경기보다 과거에 끝난 경기의 기록만 특징으로 써도 현재 응답의 수정 이력, 당시 상품번호·기준점·정산 규칙·구매 가능 시각까지 입증되는 것은 아니다. 2026년 일부 기간은 이전 연구에서도 이미 열람했으므로 새로운 블라인드 검증이 아니다.

## 재현

부모 작업 브랜치는 `codex/history-connect-orchestrator-20261108`이다. 각 워커 PR의 저장 예측을 내려받은 뒤 해당 경로를 CLI에 지정한다.

```powershell
python -m pytest tests/test_history_forecast_audit.py tests/test_research_archive_text.py -q
python scripts/audit_history_forecasts.py <worker-predictions.jsonl.gz> --kind kbl --output <audit.json>
python scripts/audit_history_forecasts.py <worker-predictions.jsonl.gz> --kind kbo --output <audit.json>
```

NBA는 `--kind nba`, VNL은 `--kind vnl`, KOVO는 `--kind kovo`와 `--league`의 정확한 리그명을 사용한다. 입력 예측 파일 SHA-256을 모든 감사 결과에 기록한다. 원천 수집·선수 원본을 재배포하지 않으며, 감사 결과만으로 원천의 이용 허가나 과거 사전 시점을 인증하지 않는다.

운영 코드·모델·DB·원장·지갑·스케줄·배포는 바꾸지 않았다. Windows 예약 작업이나 반복 AI 점검도 만들지 않았다.

검증: 부모 신규 테스트 16개 통과. 부모 브랜치 전체 `python -m pytest -q`는 **2,771 passed, 6 skipped, 123 subtests passed**. 워커의 KBO 관련 5개, KBL 관련 17개도 부모가 각각 다시 실행해 통과를 확인했다. 배구 모듈 충돌 수정 전 단독 8개 통과와 전체 CI 실패를 구분했으며, 충돌 수정의 전체 CI는 별도 확인한다.
