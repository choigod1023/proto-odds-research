# 다종목 픽스터 9:1 실제 재계산 — 2026-10-26

결론: 이 작은 사후 표본에서 9:1은 합산 ROI를 개선하지 않았다. 신규 기사 확보 0건이며 이전에 구조화한 기사 16경기를 원본 배당·정산 CSV와 다시 연결해 재계산했다. 경기 전 자료임을 입증한 표본은 0건이다. 운영 확대의 검증 완료가 아니다.

## 계산한 결과

순서는 재구성 기준 모델 / 픽스터 단독 / 기준 모델 90% + 픽스터 투표 10%다.

- 야구 10경기: ROI -53.30% / -51.10% / -51.10%, 적중 3 / 3 / 3. 혼합 시 선택 2건 변경.
- 농구 3경기: ROI -1.33% / -56.67% / -56.67%, 적중 2 / 1 / 1. 혼합 시 선택 1건 변경.
- 축구 2경기: 세 방식 모두 ROI -30.50%, 적중 1. 선택 변경 없음.
- 배구 1경기: 세 방식 모두 ROI +54.00%, 적중 1. 선택 변경 없음. 우수성 증거로 해석 불가.
- 전체 16경기: 기준 -34.00%, 픽스터와 9:1 각각 -43.00%. ROI 차이 -9.00%p.

별도로 Shin 시장확률 기준 및 시장 90% + 픽스터 10%도 계산했다. 이 표본에서는 각각 위 기준 모델 및 혼합과 최종 선택·손익이 같았다. 확률 벡터까지 같다는 뜻은 아니다. MLB 173경기 비교와 서로 다른 종목·기간·출처이므로 합쳐 비교하지 않았다.

## 입력과 방법

- 기사: 기존 `public-tipsters-20261024`의 아톰티비 선택 및 `multisport-fixed-hybrid-20261025`의 올스티비 배구 선택. 각 URL·날짜·팀·배당·확률·정산은 results.json ledger에 보존했다. 현재 일부 기사 URL의 직접 재조회는 실패했다. 오늘 새 원문 검증을 마쳤다고 주장하지 않는다.
- 기준 확률: 2023~2024년 학습 후 2025년 경기용으로 계산해 보관했던 연구 모델. 당시 동결된 운영 모델의 예측이 아니다. 이번에는 다시 학습하지 않고 보관 확률을 재사용했다.
- 원본 `accuracy-formula-lab/data/processed/games.csv` SHA256을 기존 보고서와 비교한 후 전체 시장행을 재정제했다. 종목·날짜·팀·일반 승패 시장을 정확히 연결하고, 단일 경기 일치·배당·정산 결과가 모두 같은지 검사했다. 충돌 시 계산을 중단한다.
- 픽스터는 경기별 한 작성자의 명시적 선택을 one-hot 투표로 표현했다. 100% 적중확률을 뜻하지 않는다. 축구는 무승부를 포함한 3-way, 나머지는 2-way다.
- 9:1을 고정하고 결과를 보고 비중을 탐색하지 않았다. 각 벡터의 최대값을 선택하고 동률은 선택지 순서로 결정한다.
- 동일 경기·동일 배당에 단폴 1단위: `ROI = sum(적중 시 배당 - 1, 실패 시 -1) / 경기 수`.

## 월 손실 5만 원 제한

별도 보조 계산에서 장당 1만 원, 월 손실 5만 원, 당일 미정산 베팅 전액을 먼저 예약하고 다음 날 정산한다고 가정했다. 주간 횟수 제한은 적용하지 않았다. 제한으로 제외된 경기는 없으며 16경기 누적 순손익은 기준 -54,400원, 픽스터·9:1 -68,800원이다. 여러 달의 합산이지 한 달 손실이 아니다. 최악의 월 손익은 모두 -20,000원이었다.

실제 정산 시각이 없으므로 실제 계좌 재현이나 월 수익 예측이 아니다. 운영의 월 손실 한도는 변경하지 않았다.
