# NBA 선수별 슛 위치와 예상 로테이션 회고 연구

## 확정 선발과 예상 로테이션 구분

원래 요청한 경기 전 확정 라인업 모델은 **검증 보류**다. 조사한 1,260경기에서 경기 전 게시·수신 시각을 입증할 수 있는 확정 선발 자료는 0건이었다. 사후 박스의 선발·출전 선수·출전시간을 대상 경기 입력으로 사용하지 않았다. 이는 다른 곳에 그런 자료가 절대 없다는 뜻은 아니다.

아래 결과는 별도 회고 proxy다. 대상일 D-4까지의 최근 실제 팀 10경기를 먼저 고르고 각 선수의 표시 출전시간을 합산해 팀당 240분으로 정규화했다. 결측 경기를 더 오래된 경기로 대체하지 않았고, 대상의 실제 선발·출전·현역 여부로 선수를 걸러내지 않았다. 따라서 이 수치는 실제 라인업 효과가 아니다. 표시 분은 초 단위의 정확한 기록이 아닐 수 있다.

선수별 슛 성공·위치는 D-365~D-4 이력에서만 구했고, 선수 이력이 5경기 미만이면 리그 사전값으로 수축했다. 구역과 계열 성공률 사전 강도는 같게 배분했다. 비공간 PN과 공간 PS는 같은 예상 로테이션·상대 허용·Q의 계열별 시도량·자유투와 포제션 추정을 썼다. 포제션 추정은 NBA 공식 기록이 아니다. 수식과 평가 전 고정 규칙은 [PROTOCOL.md](PROTOCOL.md)에 있다.

원천 1,185경기 중 양 팀 선수 슛 기록 및 표시 출전시간이 대조된 1069경기를 선수·수비 이력에 사용했다. 나머지는 팀 분 표시 검증·미귀속 슛·선수 박스 불일치 등을 이유로 제외했다. Q 자체는 기존 1,185경기 원천을 그대로 쓴다. 평균 예상 출전시간의 3.64%는 선수 이력이 부족해 리그 사전값을 적용했다. ESPN 좌표는 공식 NBA 구역이 아닌 거리 proxy다.

원래 공통 표본 1,260경기 중 633경기는 최근 10경기 안에 검증되지 않은 선수 박스가 있어 제외했다. 결과는 선택된 627경기에서 모든 모델이 같은 경기와 배당을 사용한 비교다. 2026년 원본 가격 804건 중 기존 공통 표본은 773건이었으며, 선수 모델은 그중 362건만 평가했다. 1,185는 평가 경기 수가 아니다.

최초 실행 후 최근 이력의 기간 정보가 없는 경기를 누락하고 11번째 경기로 대체할 가능성이 코드에 있음을 발견했다. 결과 수치를 확인하기 전에 고쳤고, 수정 전 생성 파일을 [별도 폴더](pre-fix-no-line-score-guard/)에 보존했다. 수정 전후 예측·집계·원천 manifest·제외 파일 네 개의 SHA-256이 각각 같아 이 자료에서 결과 차이는 없었다. 이 수정은 기존 사전 규약의 결측 처리 규칙을 구현한 것이다.

두 기간은 기존 연구에서 이미 검토한 회고 자료다. 과거 ESPN 원천의 당시 수신·가격 구매 가능성·상품 식별·연장 정산 규칙은 검증되지 않았다. ROI는 조건부 1단위 가상 정산으로, 실제 수익이나 운영 M0·픽스터 투표 성능이 아니다. 2026년 기존 공통 평가 경기는 5월 4일까지이며 가격은 6월 14일까지다.

[manifest.json](manifest.json)에 원천 해시·제외 사유·확정 선발 증거 현황, [results.json](results.json)에 월별 coverage·모든 지표·paired 구간, [predictions.jsonl.gz](predictions.jsonl.gz)에 경기별 예측·출전시간·이력 ID, [exclusions.jsonl.gz](exclusions.jsonl.gz)에 제외 경기 사유가 있다. 원문 대량 파일은 포함하지 않았다. 재현 시 `NBA_ESPN_CACHE`, `NBA_SHOT_PREVIOUS`, `NBA_SHOT_HARD`, `NBA_PLAYER_INPUT`, `NBA_PLAYER_OUTPUT`을 지정하고 `python scripts/nba_player_spatial_model.py`를 실행한다.
