# 야구·축구 반복 실험 원장 — 2026-09-09

## 실행 규칙

2시간 간격의 이 대화 후속 실행이 설정되어 있다. 매번 한 단계만 실행한다.
운영 예측·DB·서비스에는 쓰지 않는다. 자동 병합·배포·유료 수집은 하지 않는다.
각 코드 변경은 최신 원격 main의 독립 작업트리에서 테스트·커밋·푸시·PR로 제출한다.
보고서는 Markdown이며 원본과 상세 결과는 private SQLite에 저장한다.

1. 아래 후보 목록과 이전 PR 기록을 읽고 이미 실패한 가설인지 확인한다.
2. 데이터 해시, 모델/설정, 코드 해시, 관측 가능 시각을 고정한다. 동일 실행을 중복하지 않는다.
3. 리그를 합쳐 학습하지 않는다. 같은 날 결과는 그날 다른 경기의 입력으로 쓰지 않는다.
4. 최근 결과를 반복해서 본 구간은 **탐색용**이다. 좋은 숫자를 발견해도 독립 검증으로 부르지 않는다.
5. 중간 사건 예측이 기준을 넘은 후보만 승패·언오버와 실제 추천 정책까지 연결한다.
   2단계 모델의 학습 입력도 과거만 사용한 out-of-fold 예측이어야 한다.
6. 최종 비교는 같은 날짜·배당대·추천 수, 적중률과 Brier·보정·ROI·날짜별 불확실성을 함께 평가한다.
   추천 수를 줄이거나 저배당만 고른 효과를 모델 개선으로 세지 않는다.
7. 실패와 표본 부족을 구분한다. 표본 부족이면 데이터 확보 또는 다른 실행 가능한 후보로 전환한다.
8. 한 후보의 가중치를 끝없이 탐색하지 않는다. 새 가설·근거·데이터 요구를 기록하고 다음 후보로 이동한다.
9. 실행 가능한 새 후보나 데이터가 없으면 조용히 기다린다. 개선·완료·실패·필요한 결정만 알린다.
10. 독립 검증을 통과한 후보가 나오면 사용자에게 보고하고 자동화를 일시중지한다.

## 첫 후보와 다음 분기

  단순 최근 평균과 상대 허용 슈팅 평균 결합을 모두 기준으로 둔다.
  고정 ridge 후보의 과정 예측을 먼저 확인한다. 실제 이번 경기 슈팅으로 승패를 예측하는 누수는 금지한다.
  SOG의 수집 정의·시즌 변화가 의심되면 이를 먼저 감사하고 확대하지 않는다.
- MLB: 타석 결과를 리그 prior와 타자·투수 부분 풀링으로 예측한다.
  현재 30경기 캐시는 조건부 타석 진단용이다. 타석 수를 독립 경기 수로 바꾸지 않는다.
  실제 출전자를 사전 발표 라인업으로 간주하지 않는다.
- 과정 모델이 불충분하면 다음 순서는 데이터 정의/관측시각 감사 → 다른 공개 장기 데이터에서
  리그별 과정 모델 검증 → 오류 유형별 사전 고정 선택/보정 가설이다.
  단순 가중치 탐색이나 이미 실패한 CatBoost·팀 평균 조합을 새 방법으로 재포장하지 않는다.
