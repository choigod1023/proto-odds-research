# Dual-objective protocol (frozen before execution)

Offline, exploratory; no live recommendation changes. Reuse archived primary-market data from PR339, not an independent holdout or replay of the live policy.

- Four sports; evaluate 2025 and partial 2026. Probability model: existing features + market offset, log-loss fit. For test year Y, train probability model through Y-2, predict Y-1 out of sample to train a separate return residual ridge model; refit probability model through Y-1 for Y. The refit introduces a distribution shift, disclosed rather than using in-sample probabilities to train returns.
- Value model: observed unit return minus probability-implied EV. Features: probability, market probability, log odds, difference, probability squared, outcome indicators. Ridge penalty 10, weights inverse squared odds, no hyperparameter tuning. Return prediction shrunk by 50% towards probability EV and clipped to [-.95, odds-1]. This is a fixed heuristic shrinkage, not a confidence bound.
- Four policies: baseline market-probability rank; probability rank; value rank; hybrid equal-weight log(probability) and log(1+predicted return). All select the globally best admissible pair over all outcome options, excluding same event and shared teams within sport/league. No upper odds cap. Independence is a scoring assumption only, not established fact.
- Forced-selection evaluation: one pair per eligible date for every policy, compare common dates; no risk cap here so equal counts remain equal. Unit ticket return and pair/leg hit rates, 7-observed-date block bootstrap 10,000; Holm across 4 sports + pooled, 3 comparisons, 2 endpoints =30.
- Separate realistic simulation: value requires positive predicted leg return, probability requires positive probability EV; hybrid requires both, and leg p>=.55. Baseline uses positive market EV. One ticket/day, KRW10,000, weekly2/3, total monthly loss reserve KRW50,000; next-day settlement proxy. Also run forced-selection schedules with the same loss cap to expose abstention effects. Pooled simulation has one shared cap across all sports. Sport scenarios are alternatives, not additive budgets.
- Raw product decimal odds, no unverified rounding/payout rule. All ROI retrospective, quoted-price availability unverified. Report losses, zero-ticket ROI as unavailable, month stability, best-ticket removal. Do not change thresholds after viewing test results.
