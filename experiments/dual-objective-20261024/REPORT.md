# 확률 예측과 수익성 평가를 분리한 2폴 실험

2026-10-24 로컬 실행. 운영 예측·웹·DB·서버는 변경하지 않았다.

## 결과

분리 학습과 결합을 실제로 구현했다. 이번 고정 설정에서는 결합 모델이 시장 기준보다 소폭 좋아졌지만 확률 모델 단독보다 일관되게 좋지 않았고, 수익성도 입증하지 못했다. 결합 구조 자체가 불가능하다는 뜻은 아니며 이 구현을 바로 운영에 채택할 근거가 없다는 뜻이다.

네 종목 20,621경기를 평가했다. 모든 종목에서 고를 수 있는 통합 평가의 공통 591일에 하루 2폴 한 장씩 선택했다. 여기서 적중률은 **두 경기를 모두 맞힌 티켓 적중률**이다. 이전 보고서의 개별 경기 적중률과 직접 비교하면 안 된다.

- 시장 기준: 적중률 71.07%, 실현 ROI -12.60%, 평균 조합 배당 1.26.
- 확률 중심: 적중률 72.42%, ROI -10.90%, 평균 조합 배당 1.26.
- 수익성 중심: 적중률 32.83%, ROI -6.94%, 평균 조합 배당 4.22.
- 결합: 적중률 71.91%, ROI -10.59%, 평균 조합 배당 1.28.

결합은 시장 기준보다 +0.85%p 적중률, +2.01%p ROI였지만 확률 중심보다 적중률은 낮고 ROI 개선은 작았다. 30개 비교의 Holm 보정 후 양의 개선을 입증한 항목은 없다. 수익성 중심의 적중률 하락은 통합·농구·야구·축구에서 보정 p=0.003으로 유의했다. 즉 두 목표 사이의 상충은 확인됐지만 동시에 개선하는 효과는 확인되지 않았다.

연도 안정성도 부족했다. 통합 수익성 중심의 동일 건수 ROI는 2025년 +5.52%에서 2026년 부분 기간 -26.36%로 뒤집혔다. 결합은 각각 -11.30%, -9.48%였고, 2026년에는 확률 중심 -8.48%보다 나빴다. 좋은 해만 골라 보고하면 결론이 왜곡된다.

## 종목별 같은 날짜·같은 건수 비교

각 문장의 순서는 시장 기준 → 확률 중심 → 수익성 중심 → 결합이다. 배당 분포는 통제하지 않았다. 모델이 배당이 다른 픽을 고르는 것은 이 실험의 선택 정책 차이에 포함된다.

- 농구 353장: 적중률 63.46% → 64.59% → 27.20% → 64.02%. ROI -23.31% → -21.63% → -16.49% → -21.59%. 결합은 확률 중심을 뚜렷하게 앞서지 못했다.
- 야구 366장: 적중률 49.45% → 50.27% → 27.05% → 48.09%. ROI -15.37% → -13.92% → -19.61% → -17.37%. 결합이 두 지표 모두 나빠져 이 설정은 채택하지 않는다.
- 축구 545장: 적중률 52.84% → 53.39% → 30.83% → 54.31%. ROI -18.09% → -16.41% → -3.13% → -14.14%. 결합의 관측 개선은 있지만 보정 후 유의하지 않으며 수익성 중심은 적중률을 크게 포기했다.
- 배구 293장: 적중률 47.78% → 48.46% → 46.42% → 48.81%. ROI -25.22% → -23.16% → -19.86% → -22.03%. 소폭 개선만 관측됐다.

각 종목 시나리오는 독립 대안이고 통합 평가와 서로 합산할 수 없다. 통합은 같은 날 서로 다른 종목의 경기도 묶을 수 있다.

## 월 손실 5만원 제한

통합 시나리오에는 네 종목을 합쳐 하나의 월 한도를 적용했다. 회당 1만원, 하루 최대 한 장, 주 2회 또는 3회다. 다음 베팅이 전액 손실이어도 해당 월 -5만원을 넘지 않도록 중단한다. 아래는 평가 기간 약 20개월의 **누적** 손익이지 월 손익이 아니다.

양의 기대수익 조건 없이 일정에 맞춰 선택하는 경우:

- 주 2회: 시장 -192,088원 / 확률 -160,940원 / 수익성 -246,761원 / 결합 -171,049원.
- 주 3회: 시장 -372,853원 / 확률 -254,166원 / 수익성 -189,898원 / 결합 -291,217원.

결합은 주 2회 173장, ROI -9.89%, 수익 월 7/20개월이었다. 주 3회는 251장, ROI -11.60%, 수익 월 5/20개월이었다. 확률 중심의 수익 월은 각각 9/20, 8/20개월로 오히려 더 많았다. 손실 중단 때문에 실행 건수는 모델마다 달라지므로 이 결과는 동일 건수 통계 검정과 분리한다.

긍정적인 추정 EV를 요구해 베팅하지 않는 선택을 허용하면:

- 확률 중심과 결합은 티켓 0장으로 ROI 계산 불가.
- 수익성 중심은 축구 1장만 선택했고 실패해 -1만원. 표본 1건으로 성능을 판단할 수 없다.
- 시장 EV 기준은 마진이 있는 배당에서 원칙적으로 양수가 되기 어려워 티켓 0장이다.

축구만 주 3회 수익성 중심으로 강제 선택하면 +27,157원(+1.28%)인 조합도 나왔지만, 가장 크게 번 티켓 한 장을 제외하면 -88,768원이다. 이는 선택된 표본의 민감도 점검이며 그 티켓이 없을 때 이후 중단 경로까지 재계산한 반사실 시뮬레이션은 아니다. 이 부분 결과를 근거로 수익 모델이 성공했다고 판단하지 않는다.

## 설계

확률 모델은 종목별 기존 특징과 시장 확률 오프셋을 사용하는 다항 로지스틱 모델이다. 적중률을 직접 미분해 최적화하지 않고 log loss로 확률을 학습한 뒤 최대 확률 기준으로 선택한다.

수익성 모델은 별도의 ridge 회귀다. 먼저 과거 연도로 학습한 확률 모델이 다음 연도를 예측하게 하고, 그 **미학습 연도 예측**과 실제 단위 수익률의 차이로 수익 보정을 학습한다. 특징은 예측 확률·시장 확률·로그 배당·확률 차이·확률 제곱·선택 방향이다. 역배당제곱 가중치와 고정 ridge 10으로 높은 배당의 분산을 줄이고, 예측 보정의 50%만 반영한다. 이 50%는 고정 규칙이지 검증된 신뢰구간이나 최적 가중치가 아니다.

2025년 평가: 2023년까지 확률 학습 → 2024년 외부 예측으로 수익 모델 학습 → 확률 모델을 2024년까지 재학습 → 2025년 평가. 2026년에는 한 해씩 이동한다. 확률 모델 재학습으로 수익 모델 입력 분포가 바뀌는 한계가 있다. 하이퍼파라미터나 결합 가중치는 결과를 보고 조정하지 않았다.

수익성 중심은 두 선택의 예측 총수익 배수를 곱해 점수를 낸다. 결합은 각 선택의 `0.5*log(p) + 0.5*log(1+예측수익률)` 합을 최대화한다. 베팅 보류를 허용하는 결합 정책은 각 선택 p≥55%, 확률 EV>0, 수익 모델 EV>0을 모두 요구한다. 배당 상한은 없다. 동일 경기·동일 팀이 겹치는 조합은 제외한다. 확률과 수익 배수의 곱은 독립성 근사이며, 남은 경기 간 의존성을 입증하거나 제거한 것은 아니다.

수익률만 따로 학습하더라도 확률 오차와 데이터 부족을 피할 수 없다는 결과다. 이번 모델은 선수·선발·라인업·실제 구매 시점 배당이라는 새로운 정보를 추가한 모델이 아니다.
