# 실제 입력 연결 전 보완 계약

2026-11-03. 모델 성능을 계산하기 전의 입력 감사에 따른 명시적 보완이다. 원 사전 계획과 원자료를 덮어쓰지 않는다. 이번 보완 뒤 추가 입력 규칙과 변환식을 커밋하고 나서 훈련한다.

## 현재 확보 범위

데이터 PR #511은 2023~2026 KBO 2,913경기와 과거 2-way 가격 2,459경기를 연결했다. 실제 경기 전 선수/가격 수신이 증명된 행은 없다. raw rows와 labels는 immutable 입력으로 유지하고 어댑터 결과를 별도 파일로 만든다. 원시 행은 객체형 선수 이력이며 모델 입력은 숫자형 특징이므로 별도 변환과 근거 추적이 필요하다.

## 주 분석과 사후 시나리오 구분

- 주 진단의 선수 구성은 타깃 경기 실제 출전자/선발 ID를 사용하지 않는다. 이전 날짜까지의 팀 출전 이력에서 예상 타순과 선발 로테이션 시나리오를 구성한다. 이는 공식 확정 명단이 아니라 `projected_from_prior_games`이며 실제 발표 명단을 반영하는 요청의 완료를 뜻하지 않는다.
- 타깃 경기 박스스코어에서 얻은 실제 선수 구성은 선택적 `hindsight_actual_participants` 시나리오에서만 사용할 수 있다. 해당 ROI/적중률을 사전 예측이나 주 분석으로 승격하지 않는다. 두 경우의 선수 ID 출처와 개수를 별도로 보고한다.
- 파생 특징/소스 값과 타깃 행이 같은 날짜이면 이력에서 제외한다. 투수 이닝은 야구 아웃카운트로 변환한다. 5.2이닝은 17아웃이며 5.2개의 십진 이닝이 아니다.
- 투구 수·종료 시각이 없으면 24/48시간 연투 부하라고 표시하지 않는다. 과거 날짜별 구원 등판/이닝·상대 타자 수로 만든 지표는 별도 이름의 proxy다. 데이터에 없는 공식 ERA/FIP/OPS/xwOBA를 임의로 만들지 않는다.

## 시각이 없는 회고 라벨

`point_in_time_verified` 검사는 기존의 실제 수신·완료 시각 조건을 그대로 유지한다. 회고 진단에서만 실제 완료/수신 시각 미확인을 null로 유지한 채 명시적인 이전 날짜 완료 가정과 시간 분할을 사용할 수 있다. 가정상 완료일과 실제 완료시각은 다른 필드로 저장하고, 현재 시각·자정·경기 시작 시각을 실제 received_at/completed_at으로 채우지 않는다. 마지막 날짜 기준 7일 간격은 라벨 날짜에서도 보수적으로 확인한다.

## 두 종류의 손익

- 검증된 가격 ROI: 완전한 동일 상품 배당, 실제 사전 관측과 정산 근거가 모두 있는 행. 현재는 0건이며 미산출이다.
- 별도 가정 가격 시나리오: 저장된 과거 가격이 당시 선택 가능했다고 **가정**하는 `archived_price_scenario`. 실제 관측 시각/체결과 공식 정산 규칙은 미확인으로 유지하고 실행기가 가정 플래그를 명시적으로 요구해야 한다. 이 결과는 성능 탐색을 위한 가상 비교이며 검증된 운영 ROI·실매수 수익률이 아니다. 원 프로토콜의 검증 ROI와 별도로 출력한다.
- 가격 벡터 불완전·매칭 충돌·무효 상품은 가정 시나리오에서도 제외한다. 같은 경기·상품·가격·고정 선택 규칙(확률 최댓값, 동률 고정 순서)을 모든 팔에 적용하고 무승부 환급 원금/분모를 분리한다. 테스트 결과를 보고 선택 규칙을 바꾸지 않는다.

## 통합 승인과 검사

숫자형 특징명/공식·투구 수 부재/시각 가정과 선택 규칙을 모델 워커가 훈련 전에 추가 커밋한다. 원본/변환/학습/검증/진단 해시와 상태를 인계한다. 독립 검토는 실제 타깃 선수/라벨 변조 불변성, 날짜 경계, 가정 시나리오와 검증 결과의 혼합 여부를 확인한다. 이번 보완은 운영 권한이나 월 손실 5만원 제한을 변경하지 않는다.
