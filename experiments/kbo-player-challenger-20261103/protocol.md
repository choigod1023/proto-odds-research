## 가설과 중복 방지

동일한 KBO 경기·상품·시점·배당에서 선수 구성, 선발투수, 이전 경기 불펜 사용을 반영한 득점 분포가 팀 정보만 사용하는 같은 구조 및 시장 기준보다 더 정확한 확률을 제공하는지 검증한다.

기존 e0/잔차·시장 혼합의 재튜닝, 반복 노출된 51경기 재실행, 445/122경기의 새 이름 재포장으로 이 요청을 완료하지 않는다. 기존 파일은 출처·모델 정의·기간과 함께 대조 기록으로만 사용한다.

## 입력 층과 정직한 결과 범위

1. `point_in_time_verified`: 실제 사전 수신/발표 증거가 있고 모든 사용 입력이 decision_at 이하이며 decision_at <= kickoff-30분인 행. 운영 우세 비교는 이 층에서만 주장한다.
2. `retrospective_unproven`: 과거 결과·박스스코어·가격이 있지만 당시 선수 발표/가격 가용 시점의 독립 증명이 없는 행. 시간 순서로 과거 특징을 만들고 한계를 표시해 진단할 수 있으나 실제 사전 예측 또는 운영 수익률로 소개하지 않는다.
3. 합성 자료는 누출·정산·누락·확률 합·소프트웨어 검사에만 쓴다. 합성 ROI는 성능 결과가 아니다.

시점 증명 표본이 0이어도 학습표/어댑터/후보 구현과 가능한 회고 진단을 실제로 진행한다. 이를 이유로 회고 자료를 시점 증명으로 승격하거나 필요한 입력이 없는 모델을 실행했다고 보고하지 않는다. 부족한 입력은 필드별로 집계하고 차단 사유를 남긴다.

## 고정 입력 계약

`contract.json`을 읽는다. JSONL 한 행은 고유 경기와 고유 전체 경기 상품 1개다. 각 특징은 값뿐 아니라 원천·가용 시각·가용 근거를 가진다. 비어 있는 특징을 0인 실제 관측으로 간주하지 않는다.

공식 경기/선수 ID, 일정 변경·더블헤더, 상대 팀·홈/원정, 시장 2-way/3-way와 무승부/환불 규칙을 명시한다. 가격이 없는 과거 경기도 득점 모형의 학습/예측 진단에는 쓸 수 있지만 `market=null`로 표시하고 ROI·시장 비교에서 뺀다. 전체 배당 벡터와 실제 관측 시각이 없으면 ROI 비교 대상에서 뺀다. 현재 시각으로 과거 관측 시각을 채우지 않는다.

현재 경기의 최종 점수·경기 후 선수 성적을 설명변수에 넣지 않는다. 이전 경기의 선수/불펜 통계는 해당 경기 이전에 완료된 경기만 사용한다. 종료 시각이 없는 같은 날 이전 경기의 정보를 임의로 사용하지 않는다. 타깃 경기의 실제 출전자를 사후 박스스코어에서 알아낸 경우 별도의 가정 기반 선수 구성으로 표시하고 검증 층에 섞지 않는다.

## 후보와 대조군

- 후보군은 새로운 득점 분포 구조 1개로 제한한다. 홈/원정 득점 강도에 팀 전력·선발투수·타자 구성·불펜·구장/휴식을 연결하고 훈련 자료에서만 축소 추정한다. 과분산과 두 팀 득점 의존성을 진단하고 선택한 분포·가정을 명시한다.
- 최소 대조: 같은 구조의 팀 정보만 모델, 동일 시점 마진 제거 시장 확률. 보존된 현행 예측이 있으면 그 정확한 revision도 비교한다.
- 픽스터 자료가 실제로 연결된 공통 부분에서만 픽스터 단독 및 기존 시장90:투표10 정의와 비교한다. 유효 표 부재를 가상 투표로 메우지 않고 모델별 보류·선택 차이를 보고한다.
- 선발/타순, 불펜 정보의 추가 효과를 분리한다. 입력이 없는 층에서는 해당 변수를 사용한 후보의 우세를 주장하지 않는다.
- 구조/튜닝 범위는 훈련 전에 모델 워커가 사전 커밋한다. 개발 구간에서만 정규화·보정·가중치를 선택하며 같은 테스트에서 최적값을 계속 찾지 않는다.

## 평가와 산출물

- 확보된 최대 기간·시즌을 먼저 감사한다. 시간 순 학습/선정/진단 분리와 별도 기간을 사용한다. 이미 여러 연구에서 본 2026년 자료는 새 독립 맹검으로 부르지 않는다. 새 미래 자료가 없으면 전향 검증 미완료로 남긴다.
- 예측 파일을 정산 전 고정하고 feature/입력/모델/예측/결과 해시를 남긴다. 학습기 입력에서 타깃/공식 결과 필드를 분리하고 라벨 변조 검사로 테스트 예측의 불변성을 확인한다.
- 보고: 시점 층별 전체 기회·연결·제외·정산·무효·미정산·보류 수, 적중률, log loss, Brier, 동일 금액 단폴 ROI, 리그/시즌/월별 손익, 최대 낙폭, 불확실성, 대조군과 다른 선택 수.
- 무효 환불 원금과 미정산 노출은 따로 표기한다. 순수 모델 비교의 균등 단위 ROI와 월 손실 5만원 제한 모의 재생은 별도 결과이며, 실제 원장 한도는 변경하지 않는다.
- 워커는 자신의 handoff.json에 status, 실제 입력 경로/해시, 모델 정의, 실제 실행 명령, 분할·건수·지표, 한계, commit/PR을 남긴다. 숫자가 없으면 이유를 쓴다. 계획만을 완료로 보고하지 않는다.
- 데이터 워커는 결측 공개 자료의 합법적인 제한 수집을 허용한다. 우선 기존 로컬 자료를 재사용하고, 이 작업의 외부 요청은 최대 40회·연결/읽기 timeout 명시·단일 실행으로 제한한다. paywall/로그인/캡차/접근 제한 우회 및 운영 서버 수집은 금지한다.
- KBO 결과·검토가 모이면 K리그 단계의 동일 계약을 확정한다. 다른 종목은 그 뒤 각 득점·세트·정산 구조에 맞게 별도 실행하며 지금 전 리그 재학습을 동시에 시작하지 않는다.
