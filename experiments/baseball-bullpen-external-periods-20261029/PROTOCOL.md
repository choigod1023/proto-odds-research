# 불펜 후보의 다른 기간·리그 검증

2026-10-29 모형 결과 확인 전 고정한다. 연구만 수행하며 운영 추천·자금 정책·배포는 바꾸지 않는다. ROI는 월 손실 한도 없는 동일 금액 단폴이다.

1. MLB 우선 검사는 #408의 `bullpen:l1` 최종 계수·스케일을 그대로 동결한다. 기존116경기를 제외하고, 보존한 2026-07-26~08-23 시계열의 새로운 MLB 승패 가격을 공식 결과에 연결한다. 최근24시간 안의 마지막 경기전 관측이며 예정 시작10분 전보다 빨라야 한다. 같은 시각 서로 다른 가격은 제외하고 공식 일정의 팀·예정 시각±15분을 확인한다. 당시 실제 가격 관측 시각까지 끝난 과거 기록만 사용한다.
2. 새 경기에는 당시 픽스터 자료가 없을 수 있다. 그런 경우 **시장 단독 대비 검사**라고 표시하며9:1 독립 검증으로 부르지 않는다. 기간은8월10일 이전/이후로 고정하고 평가에서 계수를 고르지 않는다.
3. KBO/NPB에는 원래 MLB의 세이브·홀드·BF 등을 동일하게 확보하지 못한 항목이 있다. 따라서 ‘같은 모델’로 위장하지 않고 공통 불펜 모형을 별도로 만든다. 최근28일 구원 등판을 사용해 전일/3일 아웃 수, 이틀 연속 등판 인원, 과거28일 구원 아웃 수 상위3명의 전일 사용, `(K-BB)`의 아웃 수당 지표를 만든다. 이름이 아닌 원천 선수 id를 우선한다. KBO의 bf는 진짜 상대 타자 수로 간주하지 않는다.
4. KBO는 보유 과거 투수 기록을 검증된 경기 결과와 연결하고, NPB는 공식2024·2026 박스스코어를 추가 수집하며 이전2023 공식 복원본을 재사용한다. 구원투수 허용 실점 합계를 양 팀 공식 점수와 대조한다. 현재 경기의 박스·선발·결과는 특징에 쓰지 않는다. 과거 날짜만 사용한다. KBO/NPB 검사는 **일자 기준 회고 검증**으로, 기록 공개·당시 매수의 정확한 시각까지 인증한 검증이 아니다.
5. 공통 모형 후보는 업무량4변수 / 업무량+K-BB 품질5변수의2묶음×ridge0.01/0.1/1 + market_null이다. 리그별2023 가격 경기로 학습하고2024 가격 경기에서 적중률→Brier→이름 순으로 하나를 선택한다. 2023+2024로 재학습한 뒤2026년 기존 KBO203·NPB115경기에서 같은9:1과 비교한다. 7월1일 전/후 결과도 같은 모형으로 공개한다. 원천 누락·검증 부재는 건수로 밝히고 미래 성적으로 기간·계수를 다시 고르지 않는다.
6. 기존 평가 집합은 과거 연구에도 사용됐으므로 새 미열람 검증이라고 하지 않는다. 아카이브 가격·공식 점수 연결만으로 실거래 가능성을 인증하지 않는다. 적중률·ROI·참여율·픽 변경 수·같은 경기 paired bootstrap 구간을 함께 기록한다. 운영 채택은 이번 작업에 포함하지 않는다.

자료 무결성 보완(아시아 모형 결과를 보기 전): KBO 보유 투수 기록이2026-07-26에 끝남을 확인했다. 과거28일의 알려진 공식 경기 중 투수 기록이 하나라도 빠진 경우 학습·검증·평가에서 같은 규칙으로 제외하며, 해당 동일 경기의9:1과 비교한다. 날짜별 제외 사유·최초318경기 대비 참여율을 공개하고, 누락을 실제 ‘불펜 휴식’으로 코딩하지 않는다. 더블헤더의 과거 등판은 원천 gameId로 구별해 합산하되 현재 경기 날짜의 기록은 모두 제외한다.
