# M2 양팀 결측·미등록 상쇄 수정

상태: `ready_for_independent_review`. 독립 검토에서 원래 M2의 홈−원정 결측 표시가 양쪽에서 상쇄됨을 확인했다. 양쪽 타순·선발이 모두 없는 경우와 양쪽이 모두 학습에 없던 선수인 경우, 양쪽 수치가 null인 경우와 훈련 평균인 경우가 각각 같은 설계 행이 됐다. 이는 원래 계약의 결측·미등록 구별 의도를 충족하지 못한 구현 결함이다.

기존 방향 차이와 선수 역할 노출은 유지하고, 기존 수치 결측 표시 8개와 선수 명단 품질 표시 4개의 양팀 합만 M2에 추가했다. 추가 열의 L2는 기존 팀·스칼라와 같은 10이다. 새로운 선수·통계 변수, 모델 가족, penalty 격자는 없다. M0·M1과 원본 M2의 코드·계수·선택·예측·정산 파일은 보존했다. 이 수정은 2026년 원본 결과를 본 뒤 이뤄졌으므로 블라인드 실험이 아니다.

## 검증

회귀 테스트에서 양쪽 명단 결측과 양쪽 미등록, 양쪽 수치 null과 관측 0/훈련 평균, 한쪽만 결측·미등록을 구별했다. 홈·원정 교환 시 기존 방향 차이는 반전하고 새 품질 합은 유지된다. 원래 선수 노출과 나머지 설계 열은 바뀌지 않는다. 수정 M2의 두 시나리오 예측 1,418개를 독립 밀집 수식으로 재계산한 최대 확률 차이는 2.23e-16이며 원본·수정 Decimal 정산 8,792건, 월별 손익과 낙폭을 독립 대조했다. 관련 테스트 51개가 통과했다.

원본 계약·모델·예측·결과는 이전 커밋 그대로다. 선수 이력은 일부 결측이며 경기 전 발표·수신과 가격 체결은 검증되지 않았다. 결과는 현재 9:1이나 지갑의 재생이 아니고 운영 모델의 우월성·실전 수익·채택을 입증하지 않는다. 병합·배포·운영 변경은 없다.
