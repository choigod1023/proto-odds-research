## 자료 및 방법

`../m1-service-20261104/replay/replayed-709.json.gz`의 2023–25 학습 M0_actual 예측을 그대로 사용하고 재학습·재조정하지 않았다. `../m1-service-20261104/replay/service-replay.json`의 667경기 승패 표본 및 M0 선택을 이용한다. 예측은 실시간 당시 발행된 예측이 아니라 보존 입력으로 소급 재현한 것이다. 사전 수신 여부는 검증되지 않았고, 당시 실제 타순 입력과 가격의 가용 시점도 입증되지 않았다. 이미 살펴본 2026년 기간이라 독립 블라인드 검증이 아니다.

`../pregame-proto-prices-20261104/manifest-v2.json`의 기존 베트맨 원본 2026 회차 76개를 해시 검증하여 읽었다. `BS001`, 날짜·홈/원정 원천 ID와 유일한 동결 경기 ID를 대조했고, 기존 667경기 중 총점 원본 후보는 311경기였다. 각 원본 회차에서 일반 승패 행과 언더오버 행이 각각 한 개이고, 승패 가격이 기존 원장과 정확히 일치하며 점수로 계산한 원래 승패와 기존 원장이 일치하고, 총점 방향이 원본 결과 코드와 일치하는 half-line, 정상 가격·완료 표시만 포함했다. 같은 경기에서 여러 적격 회차가 있으면 전부 제외한다. 44경기이며 선별된 표본이다. 홈/원정 ID·회차·상품번호·기준점·가격·결과 및 선택은 [cohort.json](cohort.json)에 있다. 76개 원본에는 기존 가격 정규화에서 제외된 조건부 상품이 남아 있었다. 311개는 원본 총점 후보가 있는 고유 경기 수로, 적격 성적 표본이 아니다. 전체 원본 상품과 점수·식별 누락의 사유별 완전 census는 아니다.

`python scripts/validate_m0_multimarket.py`는 위 보존 원본 경로가 접근 가능한 환경에서 [audit.json](audit.json) 및 cohort를 재생한다. 외부 원본 경로가 없으면 누락 수를 보고하고 동일 결과를 재현할 수 없다. 산출물은 원본 시각이 경기 전이었거나 가격이 실제 구매 가능했다는 증거가 아니다. 모델의 합계 분포는 독립 Poisson 가정이며 연장전과 점수 분포를 별도로 보정하지 않아 확률 보정이나 향후 수익을 보장하지 않는다.

## 공통 API 및 공식 규칙

`normalize_market(options, sport, league)`는 각 선택지의 `market`, `게임번호` 또는 `game_no`, `line`, `period`, `settlement_rule`, `unit`, `선택` 또는 `selection`을 요구하며 동일 상품의 완전한 선택지만 받는다. 기준점은 홈팀 점수에 더하는 부호로 통일한다. `probabilities(terms, home_mean, away_mean)`는 한국어 선택지별 `p_win`, `p_push`, `p_loss`, 무조건부 `probability`를 제공한다. `settle`에는 공식 결과 상태와 정확한 `result_period`를 전달해야 하며 기간 미확인, 미완료, 미확인 취소는 보류한다. 공식 무효는 1.0배 환불이다. `total_half`, `total_push`, `handicap_3way`, `winner_2way_draw_refund`, `winner_3way`는 명시적으로 지정하는 규칙이며, 특히 `total_push`는 수학적 일반 규칙으로 특정 프로토 정수 상품에 승인됐다는 뜻이 아니다. 2-way 핸디캡과 quarter-line은 지원하지 않는다. 사용자는 각 상품의 원문 정산·기간·단위를 확인해야 한다.

[스포츠토토 공식 현행 세부규칙](https://www.sportstoto.co.kr/terms_allocation.php)은 홈 기준 조건부 승무패, 총점의 기준 미만/초과, 공식 무효 1.0배, 일반 야구·농구 무승부 1.0배 및 축구 정규시간과 야구·농구 연장 포함을 규정한다. [공식 이전 세부규칙](https://www.sportstoto.co.kr/proto_rules.php)은 조건이 주어지면 조건 반영 결과를 적용한다는 예외와 홈팀에 -1.0 조건을 적용하는 예시를 제시한다. [공식 게임 안내](https://www.sportstoto.co.kr/proto_intro)는 구매 시점의 기준점을 사용한다고 명시한다. 베트맨 홈페이지는 확인했으나 해당 페이지의 상세 규칙은 동적 화면에서 직접 추출하지 못해 발행 수탁자의 공식 원문을 인용한다. 각 시기별 상품별 별도 공지와 KBO 2-way 핸디캡 규칙까지 검증한 것은 아니다.
