# KBL 공식 경기·선수 기록 수집 — 2026-11-03

## 범위와 상태

공식 2025–26 KBL 정규시즌 270경기 중 경기 결과와 무관하게 날짜·시간·ID순으로 균등 간격 120경기를 선정했다. 선행 규칙은 `a7d4598`, 일정 원문과 선택 ID 동결은 `a0fca933f39a38e14cc10f247f66023be89c3898`다. 선택 표본의 경기일은 2025-10-03~2026-04-08이다. 이 표본은 정규시즌 전체 270경기가 아니다. 나머지 150경기는 경기별 기록을 수집하지 않았다.

120경기 모두 공식 헤더와 선수별 경기기록을 받았다. 날짜·시각·양 팀 ID·시즌 키, 선수 ID 중복, 양 팀 선발 각 5명, 팀별 개인 득점 합과 일정 점수를 검사한 결과 **119경기 통과, 1경기 불일치**다. `S47G01N52`는 홈 수원 KT의 일정상 60점과 기록된 개인 점수 합 45점이 달라 원문을 보존하고 정합 집계에서 제외했다. 원인이나 어느 값이 맞는지는 확정하지 않는다. 통과 119경기에는 선수 경기행 2,856개, 선발 1,190개, 선발 외 명단 1,666개가 있으며, 출전시간 양수 2,588개, 0초 268개다. 0초는 이 경기기록의 미출전 표시일 뿐 부상이나 출장 제한의 증거가 아니다. 선발 외 명단 전체가 실제로 뛰었다는 뜻도 아니다.

기존 두 베트맨 원문 캐시의 고유 상세 응답 173개를 조회 없이 검사했다. 선정된 120경기 중 날짜·시각·홈/원정 코드와 이름·일반 승패 양쪽 가격·결과가 일치하고 판매 제한이 표시되지 않은 경기는 **39개**다. 이 중 공식 선수기록 정합성까지 통과한 공통 집합은 **38개**다. 나머지 81경기는 제공된 캐시에 정확한 일반 승패 후보가 없는 80건과 판매 제한 표시 1건이다. 제공 캐시가 전체 회차라는 뜻은 아니다. 사후에 받은 과거 가격이며 당시 관측 시각·T-30 배당·실제 구매 가능성은 미확인이다. 5점 이내 중간 선택은 일반 무승부가 아니다. 승5패, 핸디캡, 총점은 구분만 했고 가격 연결을 검증하지 않아 계산하지 않았다. 적중률·ROI·모델 적합은 수행하지 않았다.

## 공식 원천과 시점

[KBL 공식 일정](https://www.kbl.or.kr/match/schedule)의 실제 JavaScript `evidence/official-frontend-js.body.gz`는 `/match/list`, `/match/{gmkey}`, `/match/{gmkey}/player-stat`, `/players`를 호출한다. 공식 웹의 공개 `Channel: WEB`, `TeamCode: XX` 헤더를 사용했고 로그인이나 우회는 하지 않았다. 정규시즌 `S47G01`, 예시 게임 `S47G01N1`, `S47G01N136`, `S47G01N270`의 서로 다른 시기 자료를 먼저 직접 검사했다. 선수 기록의 `startFlag`, 선수 `pcode`, `tcode`, `playerFlag`, `playMin`, `playSec`은 공식 응답 원문에 있다. `playerFlag`와 등록 상태는 경기 당일 확정 출전 가능성이나 부상 명단을 증명하지 않는다.

별도 최근 일정 응답에서 2026–27 시즌 `seasonCode=49`, 정규시즌 `S49G01` 52행과 EASL `S49G07` 2행을 확인했다. 현재 수신한 `/players?searchOption=active` 응답은 188행이다. 이는 현재 활동 선수 조회이지 특정 과거 경기의 출전 대상자나 경기 전 확정 선발 명단이 아니다. 경기 전 출전 제한·부상에 관한 독립적 공개 원천과 과거 확정 명단 스냅샷은 이번에 찾거나 인증하지 못했다. 해당 원천 부재를 증명하는 뜻은 아니다.

`evidence/postgame-*`는 경기 최종 결과 또는 선수 개인 경기 수치를 포함한다. `postgame-index.json` 또한 경기 후 자료다. 경기 당일의 현재 입력으로 쓸 수 없으며, 이후 경기의 과거 이력에 활용할 때도 해당 시점 이전에 실제 수신했다는 별도 증거가 필요하다. `received_at`은 이번 실제 수신 시각이며 당시 발표시각으로 소급하지 않는다. 엄격한 경기 전 수신 인증은 **0건**이다. 원문 바이트와 SHA는 내부 무결성 확인이지 독립 수신 인증이 아니다.

[KBL 2024–25 경기규칙서](https://kbl.or.kr/upfiles/ebook/2025_rules.pdf)는 10분 4쿼터, 동점이면 5분씩 연장으로 설명한다. [프로토 공식 안내](https://www.sportstoto.co.kr/proto_intro)는 농구 최종 종료까지 연장을 포함하며, 핸디캡과 언더오버는 구매 당시 기준값을 사용한다. 일반 승패·승5패·핸디캡·합계의 선택지와 회차별 적중특례는 각각 독립적으로 해석해야 한다. 실제 회차 원문과 해당 시즌 규정은 평가 전에 추가 확인한다.

## 다음 가설과 제한

후속 가설 한 개: 경기 전 공식 확인된 결장으로 이전 경기 출전시간이 많은 선수의 역할을 대체해야 하는 팀은, 동일 시점 시장 기준에 비해 선발·벤치 구성의 연속성이 달라질 수 있다. 실제 공식 경기기록의 선수 ID·선발 표시·출전시간으로 **이전 완료 경기**의 연속성을 구성하되, 대상 경기 박스스코어·최종 결과는 입력에서 제외한다. 경기 전 공식 상태와 실제 수신, 같은 시장의 완전한 당시 배당 및 정확한 정산 조건이 확보되고 별도 시간 분할·검증 규칙이 동결되기 전에는 효과를 주장하지 않는다. 기존 픽스터 방향 잔차 실험과 입력 자체가 다르며 이를 반복 학습하지 않았다.

## 재현

`python -X utf8 experiments/kbl-official-information-20261103/analyze.py`는 공식 원문·SHA·선수·득점 정합성을 재검사한다. `python -X utf8 -m unittest discover -s experiments/kbl-official-information-20261103 -p 'test_*.py' -v`는 실제 원문과 오류 사례를 검증한다. 9개 테스트가 통과했다. `collect.py boxes`는 성공 캐시를 재사용하고 잠금, 재개, 15초 timeout, 1.1초 간격, 480개 로컬 API 예산을 적용한다. 오류·403·429는 반복하지 않고 중단하며, 실패 메타데이터를 사람이 살펴본 뒤 새 작업을 정해야 한다. 이 수집에서 보존한 공식 사이트/API 응답은 245개, 사전 원천 조사 요청은 별도이며 모두 합쳐 500회 미만이다. 원문과 파생 JSON은 `.gitattributes`에서 줄바꿈 처리를 지정한다.

`join_prices.py`는 명시된 두 외부 원문 캐시가 있어야 전체 매칭을 재실행할 수 있다. 연결된 15개 회차의 압축 원문은 `evidence/odds/`에 보존했고 요청·수신·원문과 압축 해시를 `price-join.json`에 기록했다. 저장 원문만 사용하는 테스트는 39개 연결 결과의 가격·게임 식별자를 다시 검사한다. 운영 모델·원장·DB·자동화·배포는 변경하지 않았다.
