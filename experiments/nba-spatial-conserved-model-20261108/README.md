# NBA 공간 모델의 시도량 보존 실험

이전 S는 2점·3점 계열 안에서 구역별 시도율을 각각 결합하므로 합계가 비공간 Q의 시도율과 달라질 수 있다. 기존 진단에서 전체 평균 비율은 2점 0.99970, 3점 0.99977로 1에 가까웠지만 경기별 편차가 있었다. 이는 가능한 혼합 요인이지, 기존 성능 저하의 원인이 입증됐다는 뜻은 아니다.

각 계열의 전체 시도율을 Q와 같게 고정하고, 구역별 상대 시도율의 합이 1이 되도록 정규화했다. H는 기존 경계, F는 경계에서 ±1ft 선형 혼합을 사용했다. H_anchor/F_anchor는 시장에 각 후보와 Q의 확률 잔차를 L2로 수축한 모델이다. 네 후보, 산식, 학습 기간, 자료와 비교 기준은 성적 계산 전에 [PROTOCOL.md](PROTOCOL.md)에 고정했다.

동일한 가격·결과·이전 예측의 2025년 487경기와 2026년 773경기를 사용했다. 과거 경기 이력은 D-365~D-4, 팀별 최소 5건이다. 검증된 원천 1,185건은 이력 풀이고 타깃 자체의 원천 품질로 주 표본을 고르지 않았다. 타깃도 풀에 속하는 378건은 결과 JSON에 사후 선택된 설명용 집계로만 남겼다.

두 앵커는 두 기간 모두 시장과 픽이 같았다. 네 후보 가운데 두 기간 모두 Q보다 적중률과 ROI를 함께 개선한 후보는 없다. 2026년 H는 기존 S에 비해 적중과 ROI가 함께 개선됐지만 2025년에는 그렇지 않았다.

2026년 원본 가격 804건 중 31건은 기존 공통 표본에서 상세 이력 결측으로 제외됐다. 가격은 6월 14일까지이나 평가 경기는 5월 4일까지다. 7~10월 가격은 없다. 두 기간 모두 이미 검토한 회고 자료다. ESPN 위치는 공식 NBA 구역이 아닌 내부 거리 proxy이며, 가격 수신 시점·상품 식별·연장 정산 규칙이 미인증이므로 ROI는 조건부 1단위 가상 정산이다. 운영 추천, 픽스터 투표, M0, 실제 구매나 미래 수익을 재현하지 않는다.

[manifest.json](manifest.json)에 원천 해시, 동결 학습 ID 및 계수가 있고 [predictions.jsonl.gz](predictions.jsonl.gz)와 [train_features.jsonl.gz](train_features.jsonl.gz)에 경기별 확률·이력·구역 가중치가 있다. 원시 자료는 커밋하지 않는다. `NBA_SHOT_PREVIOUS`, `NBA_SHOT_HARD`, `NBA_SHOT_SOFT`, `NBA_CONSERVED_OUT`으로 경로를 지정한 뒤 `python scripts/nba_spatial_conserved_model.py`로 재현한다.
