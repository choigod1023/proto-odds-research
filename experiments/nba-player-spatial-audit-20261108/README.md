# 선수별 슛 위치·출전 시간 모델의 독립 검산

선수별 슛 위치와 과거 실제 출전 시간을 연결해 예상 로테이션 모델을 실행했다. 그러나 조사한 과거 1,260경기에는 당시 발표·수신 시각이 입증된 확정 선발 원문이 없어 **실제 경기 전 확정 라인업 모델의 비교는 미완료**다. 아래 성적을 확정 라인업 효과나 당시 서비스 예측으로 보고하지 않는다.

## 실제 연결한 자료

ESPN의 기존 검증 원천 1,185경기에서 선수별 이력 31,948행을 추출했다. 선수 ID·팀·설명문의 슈터를 보수적으로 대조해 블로커·어시스트 선수를 슈터로 쓰지 않도록 했다. 미귀속 395개 슛·자유투와 선수 박스 불일치가 있는 경우를 보존하고 품질 통과 자료와 구분했다. 두 팀 선수 슛·박스·표시 출전 시간이 맞는 1,069경기가 선수 슛 특성의 이력이 됐다. 표시 정수 분을 초로 환산해도 실제 초 단위 출전 기록이 되는 것은 아니다.

예측 대상 날짜 D에서 D−4까지의 최근 실제 팀 10경기를 먼저 고른다. 그 안에 선수 박스 누락·불일치가 있으면 더 오래된 경기로 채우지 않고 제외한다. 출전 선수 ID별 표시 시간을 합산해 팀당 240분으로 정규화한다. 대상 경기의 실제 명단·트레이드 반영 명단·출전·선발·출전 시간을 보고 거르지 않는다. 따라서 로테이션은 당시 확정 명단이 아니라 과거 기록에 기반한 단순 추정이다.

선수별 슛 특성은 D−365~D−4의 과거 기록만 사용한다. 개인 이력이 5경기 미만이면 리그 사전값을 사용하며, 개인 시도율·성공률을 수축 추정한다. 2점·3점 총 시도량과 자유투·기회량은 기존 Q와 맞춘다. 평균 예상 시간의 3.64%가 선수 이력 부족으로 리그 사전값을 썼다. 대상 경기의 결과는 정산에만 사용한다.

두 후보를 구분했다.

- PN: 같은 선수·예상 출전 시간에 선수별 2점/3점 성공률만 사용.
- PS: PN과 같은 조건에 선수별 슛 위치까지 사용.

대조군은 동결한 위치 없는 팀 득점 Q, 시장확률, 기존 전적 대조군이다. 운영 픽스터 투표나 운영 M0의 성적을 재현한 것이 아니다. 기존 RAPM 선수 조합 연구도 확인했으며, 이번 실험은 선수 조합의 stint 효과가 아니라 선수별 위치 성공률을 예상 시간으로 혼합한 별도 가설이다.

## 표본과 같은 조건의 결과

기존 평가 1,260경기 중 최근 10경기 안의 박스를 검증하지 못한 633경기를 제외했다. **627경기 공통 표본**에서 모든 대조군의 성적을 다시 계산했으며, 이전의 전체 1,260경기 성적과 직접 비교하지 않았다. 선수 이력의 1,069경기는 평가 표본 수가 아니다.

### A: 2025-10-23~12-31, 265경기

- 시장: 169적중, **63.77%, ROI −19.77%, 로그손실 0.621458**.
- 기존 전적: 170적중, **64.15%, ROI −14.94%, 로그손실 0.645652**.
- 기존 Q: 155적중, **58.49%, ROI −20.02%, 로그손실 0.657577**.
- 선수별 PN: 160적중, **60.38%, ROI −18.20%, 로그손실 0.658373**.
- 선수별 위치 PS: 162적중, **61.13%, ROI −13.46%, 로그손실 0.659567**.

PS는 Q보다 적중률 +2.64%p, ROI +6.57%p였지만, 시장과 전적 모델보다 적중률이 낮고 로그손실도 개선하지 못했다. PS−Q ROI 차이의 날짜 단위 bootstrap 95% 구간은 **[−2.46,+15.42]%p**로 0을 포함한다.

### B: 2026-01-01~05-04, 362경기

- 시장: 249적중, **68.78%, ROI −12.49%, 로그손실 0.579006**.
- 기존 전적: 246적중, **67.96%, ROI −6.27%, 로그손실 0.608322**.
- 기존 Q: 229적중, **63.26%, ROI −8.39%, 로그손실 0.645581**.
- 선수별 PN: 232적중, **64.09%, ROI −8.37%, 로그손실 0.656504**.
- 선수별 위치 PS: 223적중, **61.60%, ROI −13.39%, 로그손실 0.657118**.

PS는 Q보다 적중률 −1.66%p, ROI −5.01%p였다. ROI 차이 95% 구간은 **[−13.23,+2.77]%p**다. PN은 Q보다 3개 더 적중했지만 ROI 차이는 약 +0.02%p에 그쳤고, 시장보다 적중률이 낮고 전적 모델보다 ROI가 나빴다.

이번에는 어느 후보도 두 기간 모두에서 시장·전적·Q를 넘지 못했다. 한 기간의 개선을 근거로 교체하지 않는다. 개인별 분할이 항상 예측력을 높인다는 증거도 없다. 정확한 값·Brier·일별 마감 최대 낙폭은 [audit.json](audit.json)에 있다.

## 별도 코드로 확인한 내용

- 400개 보존 scoreboard의 원문 영수증을 확인하고 완료 경기·팀·KST 날짜를 다시 색인했다. 각 예상 로테이션이 D−4 이전의 실제 최근 10경기를 사용했는지 검산했다.
- 참조된 경기들의 선수 박스 원문·영수증에서 분을 다시 합산했다. 627경기 양 팀의 예상 출전 시간과 저장값 차이는 **0**이었다. 대상 경기의 실제 출전 여부로 선수를 빼거나 추가하지 않았다.
- 선수별 계열·위치 추정은 별도 스칼라 식으로 재계산하고, 모델 코드의 SciPy 합성곱 대신 확률생성함수 재귀식으로 승률을 계산했다. 최대 확률 차이는 **1.55e−14**였다.
- 같은 경기 ID·홈/원정·날짜·결과·원래 가격·대조군 확률을 대조했다. 조건부 1단위 손익을 Decimal로 다시 정산해 적중률·ROI·일별 낙폭을 검산했다.
- 원래 1,260개 대상은 평가 627개와 사유가 기록된 제외 633개로 빠짐없이 분리됐다.
- 회귀 테스트 3개가 통과했다. 입력 원천의 테스트 6개와 모델 워커의 검증 결과·CI 상태는 각 PR에서 별도로 확인한다.

## 해석과 남은 연결

기간은 이미 살펴본 과거 자료라 새 블라인드 검증이 아니다. 자료는 사후 수집했으므로 날짜를 지켜 만든 특성이라도 당시 실제 수신을 입증하지 않는다. 과거 가격의 구매 가능성·관측 시각·정확한 상품·연장 정산 규칙도 인증되지 않았다. 따라서 ROI는 **조건부 과거 가상 ROI**이며 실제 미래 기대수익이나 사용자의 지갑 수익이 아니다.

확정 라인업 모델을 평가하려면 각 경기의 실제 경기 전 원문, 발표·수신 시각과 해시, 선수 ID·팀·경기 연결이 필요하다. 부상 보고서와 제출 규칙이 존재한다는 사실만으로 그 경기의 확정 선발 원문을 대신하지 않는다. 이번 어댑터는 구조·시점·금지 필드를 검사하지만 원문의 권위와 의미를 자동 인증하는 것은 아니다. 실제 타깃 출전 시간은 경기 전에 알 수 없으므로 발표 명단과 과거 실출전 이력으로 예상 시간을 만들어야 한다.
