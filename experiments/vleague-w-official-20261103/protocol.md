# KOVO 여자부 공식 원천 수집 사전 계획

대상은 2025–26 V리그 여자 정규리그의 공식 일정 전체다. 경기 결과·승패·점수와 무관하게 공식 일정에 있는 여자 정규리그 완료 경기의 공식 ID 순서로 모두 요청하며, 고유 공식 경기 수 최소 100개를 목표로 한다. 처음·중간·끝의 서로 다른 시기 세 경기를 선행 확인한다. 요청은 공식 공개 프런트엔드에 나타나는 경로와 인자만 사용하며 호스트당 1초 이상 간격, 15초 timeout, 최대 500회, 403/429 또는 반복 오류 시 즉시 중단한다. 재수집 방지·잠금·resume을 적용하고 수집한 각 HTTP 원문 바이트와 현재 수신시각, 요청 인자·상태·SHA를 남긴다.

2025–26 정규리그 여자부를 남자부·포스트시즌·다른 시즌과 혼합하지 않는다. 최종 결과와 경기 후 개인·세트 기록은 labels/postgame에 두고 1세트 선발과 이후 세트 출전·교대는 원문 구조에 근거해 구분한다. 공식 라인업이라도 이번 수신시각은 2026년 현재이며 과거 T-30 수신 증명이 아니다. 발표 시각이나 독립 수신 증거 없으면 strict PIT 0. 결장·미출장을 부상으로 해석하지 않는다. 경기단위 동일 상품·날짜·팀·방향·라인·완전가격·정산을 입증할 수 있을 때만 Betman과 연결한다. 경기 승패, 세트 핸디, 총점은 서로 다른 상품으로 구분한다.

수집 단계에서는 모델 적합, ROI, 사후 후보 선택, 운영 반영을 하지 않는다. 원문 스냅샷 자체는 과거 경기 전 가용성을 증명하지 않는다. 수집 이후 단계에서 독립적인 확정선발 수신과 배당 관측 시각을 갖춘 전향 표본이 생긴 경우에만 기존에 고정한 후보와 분리 검증한다.
