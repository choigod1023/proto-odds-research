# 여러 작성자의 NBA·KBL 연간 아카이브 수집

목표 기간은 **2025-10-28~2026-10-27**다. 실제 확보한 경기 날짜는 2025-10-29~2026-10-27이며, 두 사이트의 공개 핸들 14개에서 **583픽**을 확보했다. 원문 날짜와 팀명으로 묶은 식별자는 349개이고, 명시적인 팀 별칭으로 식별한 단일 경기 후보는 **347개**다. NBA 일정·공식 결과로 확인한 경기 수라는 뜻은 아니다.

- NBA: 553픽, 원문 식별자 321개, 정규화한 단일 경기 후보 319개, 공개 핸들 11개. 공식 점수 연결은 이 작업에서 확보하지 못했다.
- KBL: 30픽, **공식 최종 점수와 연결한 28경기**, 공개 핸들 5개. 18픽은 연장 포함 승패 정산 범위까지 확인했다. 나머지 12픽은 공식 점수만 연결했으며, 연장·전반 등 시장 규칙이 충분하지 않아 승패를 재정산하지 않았다.
- Miky938: 174픽·40개 경기 식별자. Betblog: 409픽·320개 경기 식별자. 출처별 경기 수는 중복되므로 합산하지 않는다.
- 패배 232픽, 승리 337픽, 0손익·무효 추정 13픽, 결과 미확인 1픽을 함께 보존했다. 출처의 손익을 기준으로 표시한 결과는 독립적으로 검증한 정산 결과가 아니다.

## 수집 방법과 출처

[Miky938 결과 인덱스](https://miky938-oddsparser.com/results/)에서 실제 연결된 2026-02~2026-10 월별 페이지 9개를 수집했다. 리그 첫 화면의 최근 100행 제한을 전체 아카이브로 오인하지 않았다. 월별 전체 행에서 NBA·KBL만 골랐고 결과·배당·시장에 따른 선택은 하지 않았다. 이 사이트 자체의 기록 시작 주장은 2026-02-24이며, 2025년 자료를 갖고 있다고 주장하지 않는다.

[Betblog NBA](https://www.betblog.com/basketball/nba/)와 [KBL](https://www.betblog.com/basketball/south-korea-kbl/)에 실제 나타난 작성자들의 리그별 프로필을 따라가고, 다음 페이지가 연결되며 목표 기간의 단일 경기 픽이 있는 동안 순서대로 확장했다. 광역 리그 화면은 최근 90일만 표시하므로, 과거 자료는 작성자별 아카이브에서 확보했다. 검색에서 찾은 Kentukyo·faster와 KBL 연간 목록의 나머지 핸들(str1ke·THUNDER·Haris333), 전체 기간 목록의 Nelaime도 확인했다. 목표 기간보다 오래된 기록만 있던 프로필도 요청·제외 로그에 남겼다. 작성자 모집단을 무작위로 표집한 자료는 아니며, 목록의 노출 편향이 있다. 양수 수익 작성자만 고르지 않았다.

[KBL 공식 경기 API](https://api.kbl.or.kr/match/list?fromDate=20251028&toDate=20261027&tcodeList=all)는 공개 웹 클라이언트의 `Channel: WEB`, `TeamCode: XX`, `lang: ko`, `X-Requested-With: XMLHttpRequest` 헤더를 사용했다. 인증·쿠키·우회는 사용하지 않았다. 383개 경기 중 종료 표시가 있는 370개만 최종 점수를 보존하고, 미종료 경기의 점수는 null로 뒀다. 날짜와 명시적 홈·원정 팀 코드를 정확히 연결했으며 점수가 비슷한 경기를 찾는 방식은 쓰지 않았다.

NBA 공식 CDN 일정과 nba.com 일정·경기 페이지는 이 실행에서 403을 반환했고, stats.nba.com은 시간 초과로 끝났다. 요청을 우회하거나 픽 사이트 점수를 공식 점수로 대신하지 않았다. 다른 작업에서 확보하는 NBA 공식 결과는 별도로 검증·연결해야 한다.

## 확인한 이상과 한계

- **2026-04-26 안양–KCC**: Miky938은 84:67, KBL 공식 API(`S47G03N14`)는 91:83이다. 승패는 같지만 점수가 다르다. `disagreements.json`에 양쪽 값과 출처를 남겼다.
- Betblog가 NBA로 분류한 `Portland Trail Blazers - London Lions` 1건은 상대 팀을 NBA 팀으로 식별하지 못했다. 원문 후보는 유지하되 `team_identity_status=unresolved_source_team_label`로 표시하고 정규화한 단일 경기 수에서 제외했다.
- 경기 제목이 있는 시리즈 승자 픽 1개는 `market=series_winner`로 남기고 단일 경기 수에서 제외했다. 경기 제목 자체가 없는 시즌 우승·개인상 픽은 제외 사유와 수를 기록했다.
- NBA 시장은 승패 74, 핸디캡 22, 경기 득점 164, 팀 득점 7, 전반 득점 2, 전반 핸디캡 1, 시리즈 승자 1, 미분류 282다. 미분류에는 선수 득점·리바운드·어시스트·3점·더블더블·트리플더블 등이 많다. 원문을 보존했으며 경기 점수만으로 이들을 정산하지 않는다.
- Betblog의 게시 시각 주장 409개는 공개 페이지의 `validFrom`을 읽은 값이다. Miky938 게시 시각은 null이다. 모든 `cutoff_proven`은 false다. 현재 읽은 과거 페이지는 경기 전에 실제 공개됐다는 독립 증거가 아니다.
- 작성자 핸들 뒤의 실제 사람·자동 시스템 여부와 작성자 사이의 독립성은 확인하지 않았다. 한 경기의 여러 작성자 픽은 독립 경기 표본이 아니다.
- Miky938은 WAT(UTC+01) 날짜, Betblog는 UTC 시각 주장이다. NBA 공식 일정 없이 자정 부근의 날짜 경계를 완전히 대조하지 못했으므로, NBA 경기 수는 후보 식별 수다.
- 자체 모델·하이브리드·ROI 비교, 채택·병합·배포는 수행하지 않았다. 통합 검증은 상위 작업에서 진행한다.

## 파일과 필드

- `candidates.jsonl`: 중복 제거한 583개 후보. `kbl-candidates.jsonl`, `nba-candidates.jsonl`은 같은 자료의 리그별 분할이다.
- `source-observations.jsonl`: 페이지별 개별 관측. 중복 제거 전의 증거를 보존한다.
- `official-kbl-results.jsonl`: 383개 공식 경기. `is_ended`와 null 점수를 반드시 구분한다.
- `summary.json`: 전체·월·리그·출처·작성자별 픽 수, 경기 수, 시장·결과·공식 검증 상태, 페이지별 제외 사유, 네트워크 실패.
- `requests.json`, `discovery.json`: URL·수집 시각·원본 해시·응답 상태·추가 작성자 선택 근거. Python HTTP 시도는 63회이며 재시도는 없다.
- `raw/`: 원본 응답의 무손실 gzip 스냅샷. SHA-256은 압축 전 HTTP 응답을 대상으로 한다.

각 후보는 `published_at_claim`, `observed_at`, `source_url`, `reported_decimal_odds`, `market_raw`, `side_raw`, `market`, `side`, `line`, `market_scope`, `team_side`, `canonical_teams`, `fixture_group_key`를 포함한다. 팀 득점 픽은 `side=over/under`, `team_side=home/away`다. 홈·원정 코드와 원문 팀명을 함께 남겨 연결 규칙을 확인할 수 있다.

## 실행과 검증

```powershell
python scripts/research_collect_year_basketball.py --collect --build
python scripts/research_collect_year_basketball.py --build
python -m unittest discover -s tests -p test_tipster_year_basketball.py -v
```

`--build`와 테스트는 저장된 원본으로 오프라인 실행한다. 날짜 경계·패배 보존·게시 시각 부재·선수/전반 시장 오분류 방지·팀 별칭·홈원정·중복 및 모호한 공식 연결·미종료 경기·쿼터 라인 정산 보류·원본 해시·실제 후보 무결성을 확인하는 테스트 9개를 통과했다. 파서 변경 뒤 픽 수는 동일한 583개이고 NBA 미분류는 316개에서 282개로 줄었다. KBL은 별칭 정리 뒤 30개 모두 공식 점수를 연결했다.
