# 종목·리그·상품별 모델 선택 회고 검증

2025년 1월 1일~2026년 11월 2일의 173개 종목·리그 조합에서 33,086개 상품 표본을 평가했다. 한 경기의 서로 다른 시장은 별도 상품이므로 이 수는 고유 경기 수가 아니다. 월별 선택에는 월초 7일 전까지의 결과만 제공했다. 같은 경기·상품·기준점의 결과와 배당은 모든 모델에 공통으로 적용했다. [사전 규칙](PROTOCOL.md)

## 결과

- **전체 33,086건.** 기준 모델 18,633건 적중(56.32%), 가상 ROI −11.85%. 과거 적중률만으로 고르면 18,598건(56.21%), −11.84%. 모델이 달라진 6,661건 중 실제 픽이 달라진 것은 691건이다. 적중률 차이의 7관측일 블록 95% 구간은 −0.280~+0.069%p, ROI 차이는 −0.357~+0.370%p였다. 로그손실은 0.79618에서 0.79891로 늘었다.
- **축구 16,837건.** 8,844 → 8,825건 적중, ROI −10.93% → −10.85%. 승무패 11,014건, 핸디캡 2,928건, 언더오버 2,895건을 비교했다.
- **야구 11,991건.** 6,975 → 6,959건 적중, ROI −13.05% → −13.15%. 승패 6,885건, 핸디캡 2,592건, 언더오버 2,514건을 비교했다. 감소한 적중은 주로 언더오버에서 발생했다.
- **농구 3,356건.** 2,204 → 2,206건 적중, ROI −12.08% → −11.93%. 승패 2,760건, 핸디캡 302건, 언더오버 294건이다. 한국 KBL 핸디캡 95건에서 기존 동결 모델과 월별 선택이 모두 56건 적중했다. 가상 ROI는 +2.87% → +2.82%였다.
- **배구 902건.** 610 → 608건 적중, ROI −12.40% → −12.54%. 승패만 비교했다. 세트·점수 단위와 공식 정산을 확인할 수 있는 핸디캡·언더오버 공통 표본은 이 자료에서 확보하지 못했다.

적중률만 본 선택은 2025년에 19건 더 맞혔고 2026년에는 54건 덜 맞혔다. 바뀐 픽의 순증 적중과 로그손실까지 요구하는 선택은 전 구간에서 모델을 바꾸지 않았다. 두 해 모두를 종합하면 현재 후보들로 자동 교체할 근거는 부족하다.

## 비교 범위

기준 모델은 시장확률이며 KBL 핸디캡에는 동결 후보를 기준으로 썼다. 일반 승패 아카이브는 월별 팀 전력·최근 성적, 시장확률 보정, 두 방식의 혼합 예측을 보존한다. 해당 원장은 일반 승패 정규화 ID를 사용하며 공식 상품번호와 과거 수신시각이 남아 있지 않다. 모델 원천의 기존 학습·피처 시차는 4일이다. 베트맨 별도 상품에는 공식 상품번호·기준점·결과가 남아 있고, 새 후보는 같은 리그·시장 유형에서 7일 이상 지난 점수 분포를 현재 기준점으로 재정산한 뒤 시장확률에 섞는다. 한국 KBL에는 #689의 득점 구성·로테이션·슛 위치·선수 효과 원장을 별도로 연결했다. [베트맨 회고 원장 #595](https://github.com/choigod1023/proto-odds-research/pull/595) · [KBL 원장 #689](https://github.com/choigod1023/proto-odds-research/pull/689)

실제 당시 구매 가격은 확인되지 않았다. 가상 ROI는 보존된 가격에 1단위를 걸었다고 가정한 상품별 비교다. 운영 투표·9:1·M0의 동시 예측, 픽스터 원문, 경기당 최종 한 상품 선택, 복수 경기 조합은 이번 표본의 비교 범위 밖이다. 축구 정규시간과 야구·농구 연장 포함 상품은 구분했다. [프로토 상품 규칙](https://www.sportstoto.co.kr/proto_intro)

## 재현

원장·월별 상태 해시는 [summary.json](summary.json), 상품별 선택과 결과는 [ledger.jsonl.gz](ledger.jsonl.gz)에 있다. #595의 고정 커밋 `12729dc3`과 #689의 `68bdbc7e` Git 객체가 로컬에 필요하다. 두 원천 PR을 가져올 때는 아래와 같이 실행한다. 어댑터는 현재 브랜치의 원천 파일로 대체하지 않고 고정 커밋의 원장을 읽는다.

```text
git fetch origin refs/pull/595/head refs/pull/689/head
python -X utf8 experiments/market-model-routing-20261110/run.py --out .local-test/router
python -m pytest -q experiments/market-model-routing-20261110
```

테스트 12개를 통과했다. 전체 평가를 두 번 실행해 두 산출물이 바이트 단위로 같음을 확인했다. 33,086개 상품의 고유 ID와 네 정책의 132,344건 손익을 별도로 검산했다.
