# 종목·리그·상품별 적중률 기준 모델 선택

회차와 상품번호는 평가와 정산을 연결하는 식별자로 보존한다. 새 번호의 모델은 종목·리그·상품 종류·적용 구간·결과지 수를 기준으로 고른다. 핸디캡과 언더오버는 동일 기준점 표본으로 먼저 판단하고, 자료가 부족하면 같은 리그·상품 유형으로 범위를 넓힌다. 예측은 각 모델의 가장 높은 확률을 고르는 방식으로 통일하며, 동률이면 원본 순서의 첫 결과를 고른다.

## 데이터와 기준

- 축구·야구·농구·배구의 기존 시간순 일반 승패 원장, 확대 베트맨 회고 원장의 공식 상품 정보, #689의 KBL 승패와 별도 상품 예측을 사용한다. 자료 원천과 기간이 서로 다른 표본은 별도로 표시한다. 동결 KBL 핸디캡 후보가 있는 경우 해당 상품의 기존 모델도 대조군으로 기록한다.
- 동일 평가 행에서 모든 후보가 같은 결과·기준점·양쪽 또는 세 방향의 가격을 사용한다. 회차·상품번호가 있는 원천에서는 이를 보존한다. 일반 승패 원장의 정규화된 경기 식별자는 공식 상품번호로 표시하지 않는다. 푸시·무효·점수 불일치·정산 기준 불명 자료는 제외한다.
- 거래 가격의 당시 관측시각이 입증되지 않은 자료는 회고 표본이다. 1단위 ROI는 모델 선택에 사용하지 않고 별도로 보고한다.

## 시간순 모델 선택

- 평가 구간은 2025년과 2026년이다. 월 1일에 모델 순위를 정하고 그달 내내 동일한 과거 범위를 사용한다. 과거 기록은 월 1일보다 최소 7일 앞선 날까지로 제한한다. 후보와 기준 모델의 같은 상품을 비교한다.
- 단순 선택은 최소 40건에서 기준 모델보다 적중률이 높은 후보를 고른다. 같은 기준점 표본을 우선하고 없으면 같은 리그·상품 유형의 표본을 사용한다. 순위는 적중률 차이, 로그손실 차이, 후보 이름 순이다.
- 보수적 선택은 40건 외에도 픽이 바뀐 5건 이상, 순증 적중 2건 이상, 기준 모델 이하의 로그손실을 요구한다. 날짜별 순증 적중의 단측 부호검정에서 가족별 유의수준 10%를 두 범위와 검사 후보 수로 나눈 문턱을 사용한다. 근거가 부족하면 기준 모델을 유지한다. 반복 월 검정까지 통제한 승격 검정으로 해석하지 않는다.
- 기본 기준은 마진 제거 시장확률이다. 기존 동결 KBL 핸디캡이 있는 경우 해당 그룹의 기준은 동결 모델로 두고, 시장확률 결과도 같이 남긴다. 변경 픽 수, 적중률, 로그손실, 가상 ROI와 날짜 단위 짝지은 차이 구간을 보고한다.

이 연구는 종목·상품별로 어느 모델을 쓸지 검증한다. 여러 상품 중 실제 구매할 한 상품을 고르는 정책과 복수 경기 조합은 별도 검증 대상이다.
