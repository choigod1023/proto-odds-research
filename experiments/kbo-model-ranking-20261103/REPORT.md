# 기존 KBO 모델 중 M0의 위치

2026-11-03. 기존 동결 예측을 재정산한 비교 감사다. 새로운 학습·튜닝·예측·수집·운영 모델 변경은 없다. 여기서 M0는 현재 서비스 모델을 가리키는 이름이 아니라, 2023~2025년 실제 선발·확정 타순으로 학습한 연구용 집계 Poisson 모델이다.

## 판단

현재 동일 조건으로 비교할 수 있는 KBO 자료에서는 **실제 명단 학습 M0를 승패 선택의 기준 모델·최우선 후보로 두는 것이 타당하다.** 넓은 2026 표본에서 적중률·단위 ROI·일 마감 최대 낙폭이 모두 가장 좋았고, 픽스터와 공통인 197경기, 이전 e0 후보와 공통인 196경기에서도 손실이 가장 적었다.

다만 모든 기간·평가 척도에서 최고는 아니다. 엄격한 가격 표본의 ROI는 이전 M1 예상 명단 설정이 더 좋았으며, 3분류 확률 점수는 M2가 우세했다. 전부 손실이고 과거 열람 자료이며 주요 ROI 차이의 주간 구간도 0을 포함하므로 흑자나 미래 우월성이 증명된 모델이라고 부르지 않는다. K리그·NPB·MLB 등 다른 리그까지의 통합 최고라는 결론도 아니다.

## 비교한 범위와 분모

1. 최종 paired 재학습 M0/M2 및 예전 전체 학습 대조군 6개 × 실제/예상 평가 명단 2개, 이전 M1/M2 v1의 두 평가 명단, 기존 고정 선수 모델의 네 입력 상황: 총 20개 설정은 같은 709경기 전체 확률이 있다.
2. 시장·팀·선발·타순·불펜·기존 선수·선발+타순 등 과거 원장의 7개 설정을 더해, 총 27개 설정을 공통 확장 가격 667경기에서 비교했다. 이들은 27개의 독립 모델 가족이 아니며 같은 모형의 입력·학습 상황을 포함한다. 과거 원장 7개는 과거 특성 갱신 상황이 달라 명단만의 통제 실험은 아니다.
3. 엄격한 원래 경기 시각 일치 가격 439경기와 현재 구매거절 7건 공통 제외(확장660/엄격432)를 각각 유지했다. 가격이나 기간을 성적에 맞춰 선택하지 않았다.
4. 별도로 실제 픽스터 의견이 있는 같은 197경기에서 시장·9:1·순수 투표 및 공수 Poisson/승부 상태 모델의 고정/순차 8개 설정을 비교했다. e0 후보와는 같은 196경기로 비교했다. 이 작은 표본 수익률을 667경기 수익률과 직접 순위 비교하지 않는다.

모든 ROI는 경기당 단폴 1단위, 두 방향 전체 승패, 무승부 환급이며 환급액도 투자 분모에 포함한다. 709경기 적중률은 무승부 포함 3분류, 가격 표본 적중률은 환급 제외 승패 결정 경기 기준이다. 원래 2025 검증·2026 예측은 PR #535에서 고정돼 있고 이번 감사에서 새로 최적값을 찾지 않았다. 가격의 과거 체결 가능성·최초 수신 시각은 전수 입증되지 않았다.

## 넓은 공통 표본

평가 기간은 2026-03-28~10-27. 전체709경기 3분류 적중은 실제 명단 학습 M0가 **418/709=58.96%**로 20개 확률 설정 중 가장 많았다. 다음은 예전 전체 학습 M0와 고정 선수 모델의 확정 타순 설정들이 403경기였다.

공통 확장 가격667경기(승부 결정652, 환급15)의 결과:

- 실제 명단 학습 M0: 395/652 적중(60.58%), 순손익 -29.05단위, **ROI -4.36%**, 일 마감 최대 낙폭40.98단위. 27설정 중 적중·ROI·최소 낙폭 모두 1위.
- 실제 명단 학습 M2를 예상 명단으로 평가: 376/652, ROI -6.38%, 낙폭59.03. 입력 상황이 다른 문맥 비교다.
- 실제 명단 학습 M2를 실제 명단으로 평가: 374/652, ROI -7.38%, 낙폭67.74.
- 이전 고정 선수 모델의 실제 명단 평가: ROI -8.26%.
- 시장 기준: 387/652(59.36%), ROI -9.03%.
- 이전 선수 ID Poisson M1의 실제 명단 평가: ROI -13.16%.

현재 구매거절 7건을 공통 제외한660경기에서도 M0는 ROI -4.36%와 최소 낙폭41.73단위로 첫 순위를 유지했다. 현재 플래그를 과거 판매 상태의 증거로 해석하지 않는다.

엄격 가격439경기(승부 결정429/환급10)는 예외다. **예전 M1 예상 명단 설정은 ROI -3.91%·낙폭30.15, M0 실제 명단 학습은 -6.53%·낙폭30.89**였다. 적중은 M0 254/429로 M1 252/429보다 높았다. 이 결과를 보고 엄격 표본에서만 M1을 고르는 새 정책을 만들지 않았다.

확장667에서 M0−M2 실제 명단 학습의 ROI 차이 95% 구간은 -2.87~+8.54%p, M0−시장은 -1.12~+10.56%p였다. 엄격439에서 M0−M1 예상 명단의 구간은 -11.62~+5.14%p였다. 주 단위 paired bootstrap5,000회(seed20261103)이며 다중 비교 보정을 하지 않았고 동일 자료의 반복 개발·열람 불확실성은 포함하지 않는다.

## 픽스터와 같은 197경기

2026-03-29~09-08, 전 경기 승부 결정·환급0. 공식 경기ID·KST날짜·홈/원정 팀·양방향 배당을 대조했다. 원래199경기 중 기존 M0 확장 가격 원장에 없는 2경기를 제외했다. 의견 없는 경기를 시장으로 대신하지 않았다. 투표의 방향 값을 보정 확률로 사용하지 않았다.

- M0 실제 명단 학습: **119/197=60.41%, ROI -5.95%, 순손익 -11.72, 낙폭11.72**.
- 공수 상태 Poisson 고정 설정(score-static): 116/197, ROI -6.40%, 순손익 -12.60, 낙폭13.72. 8개 상태 설정 중 이 표본 ROI가 가장 좋았으나 2025년에 사전 선택된 상태 모델은 outcome-static이었다.
- 시장90%+픽스터투표10%: 116/197=58.88%, ROI -9.36%, 순손익 -18.43, 낙폭18.78.
- 순수 픽스터 투표: 110/197=55.84%, ROI -10.32%, 순손익 -20.33, 낙폭24.25.
- 시장 기준: 115/197=58.38%, ROI -11.58%.
- 사전 선택 고정 상태 모델(outcome-static): 107/197, ROI -12.15%.
- M2 실제 명단 학습: 104/197, ROI -16.40%.

M0−9:1 ROI 차이는 +3.41%p이지만 95% 구간 -4.54~+11.46%p, M0−순수투표는 +4.37%p/구간 -14.59~+20.87%p다. 두 비교 모두 우월성을 확정하지 못한다. 전체 14개 설정과 월별 손익·낙폭·픽 변화·구간은 tipster-results.json에 보존했다.

## 이전 e0 후보와 같은 196경기

2026-03-29~07-23, 전 경기 승부 결정·환급0.

- M0 실제 명단 학습: 118/196=60.20%, ROI -6.38%, 순손익 -12.50, 낙폭13.92.
- e0 후보: 118/196=60.20%, ROI -7.23%, 순손익 -14.17, 낙폭16.67.
- 해당 연구 9:1: 117/196=59.69%, ROI -8.31%, 순손익 -16.29, 낙폭17.15.

M0와 e0는 같은 수를 맞혔지만 선택이46경기 달라 배당과 손익이 달랐다. ROI 차이의 구간은 넓어 이 차이로 전향 우위를 확정하지 않는다. 두 비교 그룹에서 제외된 원래 경기2건은 20260702KTHH02026와20260709LGSS02026이며, 이들의 다른 보관 배당으로 M0 가격 원장의 빈자리를 채우지 않았다.

## 해석과 후속 판단

'M0가 최고'는 **실제 선발·확정 타순으로 학습하고 실제 명단을 넣은 KBO 연구 후보**라는 조건에서 해석해야 한다. M0라는 가족 이름만 유지한 예상 명단 학습/평가 설정은 더 나빴다. 현재 운영 투표 모델의 실시간 동결픽 성능이나 야구 외 다른 리그까지 검증했다는 뜻이 아니다.

M0는 선수 ID별 효과보다 타격·선발의 최근 수치 집계를 사용하므로 다른 시즌 선수에도 입력을 적용할 수 있다. M2 실제 명단 평가에는 학습에 없는 선발 슬롯447/1,418와 타자 슬롯988/12,762가 있어 중립 선수 효과를 사용했다. 이 점은 M2가 더 복잡해도 반드시 좋아지지 않는 가능한 설명이며 원인 분해 실험으로 입증한 결과는 아니다.

3분류 log loss/Brier는 M2가 더 좋았다(M0 0.84040/0.52259, M2 0.77062/0.50705). M0 평균 무승부 확률 약12.58%가 실제2.26%보다 높았던 영향이 크다. 무승부 제외 승패 log loss는 M0 0.67776, M2 0.67762로 거의 같다. 따라서 승패 선택 기준 후보와 보정된 확률·베팅 금액 산정 용도를 구별한다.

당장 할 일은 모델 계열을 다시 바꾸는 것이 아니라, 이 M0와 입력 정의를 고정해 새로운 경기의 사전 명단·배당·공식 결과를 같은 원장에 연결해 평가하는 것이다. 이번 요청에서는 그 운영 연결·모델 전환·병합·배포를 실행하지 않았다. 기존 월 손실5만원 모의 원장도 변경하지 않았다.

## 재현·검증

- compare.py는 고정 Git 객체의27설정/4가격tier를 재정산해 results.json을 만든다.
- compare_tipsters.py는 고정 원천과 공식 경기ID를 연결해197/196 공통표본을 tipster-results.json에 보존한다. 추가8상태설정도 같은197에서만 비교했다.
- source_hashes에는 읽은 각 원문 blob의 커밋·경로·SHA-256이 있다. 동결된 비교 원천 커밋은 ff2bef35988eb5add154b4bebf8b265f42792db1, d08ccb708033fb6b067e84e80eae81ea3c9b4cfa, dc9dffc82ae1f2081a3af113b08a8e22e3ef3b37, 66f1c255b41714dabc6dc0638bbd8f1e12e13006, 공식 ID는 c4e6bdb67784ceaf76e39707e1b8083f222c0a7d다.
- 재현에는 해당 Git 객체가 필요하다. 연구용 리모트 브랜치 codex/kbo-actual-training-model-20261103와 codex/kbo-player-effects-20261103를 fetch해 확보한다. 공식 ID blob은 compare_tipsters.py에 명시한 읽기 전용 데이터 저장소에서 가져온다.
- 전체709 모델 지표·4가격tier의 기존12조합48결과는 독립 감사된54dbcfcdd9ffc3ca0ad473cf9d586a38398cde4e와 대조했다. 197/196의 주요 수치도 별도 워커가 메모리 정산한 수치와 일치했다.
- 단위 검사는 환급 분모·Decimal·날짜 마감 낙폭·중복·불일치·비정상 확률 거부를 포함한다.

실행:

```text
python -B -X utf8 experiments/kbo-model-ranking-20261103/compare.py

```

비교 자료의 결과·예측과 학습 자료는 과거 연구에서 이미 열람했다. 순위는 후향 진단이며 새로운 블라인드 테스트가 아니다. 같은199/198의 과거 전수 지표를 이번197/196 결과인 것처럼 재사용하지 않았다.
