# NBA ESPN 회고 실험 보고서

## 결과

2026년 평가에 사용할 수 있었던 773경기에서 공격·수비 효율 후보의 적중률은 70.63%, 조건부 ROI는 **-11.81%**였다. 같은 경기에서 시장 기준은 적중률 70.76%, ROI -11.60%였다. 후보의 로그손실과 Brier 점수는 소폭 낮았으나 날짜별 paired bootstrap 95% 구간은 두 지표 모두 0을 포함한다. 이 결과는 운영 채택이나 미래 수익을 뒷받침하지 않는다.

가격 행 804건 중 773건을 평가해 coverage는 96.14%다. **가격 자료의 실제 날짜는 2026-01-01~2026-06-14이고, 평가 경기는 2026-01-01~2026-05-04에만 있다.** 5월 26건과 6월 5건은 최근 10경기의 필요한 상세 박스가 없어 제외됐다. 7~10월 가격 행은 이 입력에 없으므로 해당 기간에 대한 성적은 없다. 사전 지정한 평가 상한 10월 27일이 해당 날짜까지 관측을 확보했다는 뜻은 아니다.

## 자료와 방법

ESPN 공개 [scoreboard](https://site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard?dates=20250101&limit=100)의 경기 달력을 이용해 400일을 수집했다. 점수판 응답 400건은 모두 200이었고, 완료 경기 상세 2,365건 중 2,357건이 200, 8건이 404였다. 404는 해당 상세의 실제 오류 응답·수신 완료 시각·상태·해시를 로컬에 보존하고 재실행 시 재요청하지 않는다. 최초 404에서 수집기가 중단된 뒤 영수증을 보존하도록 수정했고, 해당 첫 경기만 404를 한 번 다시 확인해 보존한 다음 나머지를 계속 수집했다. 403 또는 429는 즉시 중단하며 우회하지 않는다. 원문과 개별 영수증은 로컬 `.local-test/nba-espn-history-20261108/`에 있고 Git에 올리지 않는다. 수신 범위·상태·해시 요약은 [source_receipts.json](source_receipts.json)이다.

전체 점수판 이벤트 2,374건 중 완료 상태와 NBA 30개 팀, 점수 등을 갖춘 경기는 2,351건이며 이 중 2,343건은 필요한 팀 상세 박스를 확보했다. 슈팅 통계가 불완전한 경기는 0건, 상세와 점수판의 통계·점수 충돌은 0건이다. NBA 팀 가격 2,133행은 KST 날짜와 명시한 30개 팀 별칭으로 각각 유일하게 연결됐고, 홈/원정 원점수와 가격 라벨이 모두 일치했다. ESPN 쪽 가격 미연결 경기는 218건, 중복 가격 경기 ID는 0건이다. 최근 이력 부족 등으로 209행은 모델 입력에서 제외했다. 동일 경기 ID의 상충하는 점수판 기록은 임의 선택하지 않고 중단한다.

첫 표본 [ESPN 상세](https://site.api.espn.com/apis/site/v2/sports/basketball/nba/summary?event=401705021)에서 공격 리바운드와 팀 턴오버를 확인했다. 수집 완료 후, 사전 고정한 가용성 검사에서 포제션 추정에 필요한 직전 10경기가 있는 표본이 학습 664건, 검증 487건, 평가 773건으로 최소 기준을 넘었다. 자세한 결정과 입력 해시는 [availability.json](availability.json)에 기록하고 성적 계산 전에 커밋했다. 이력 창에서 결측된 경기는 더 오래된 경기로 대체하지 않았다.

포제션 추정은 `FGA - 공격 리바운드 + 턴오버 + 0.44 × FTA`, 경기별 공격 효율은 `100 × 득점 / 추정 포제션`이다. 상대의 같은 계산을 수비 효율로 쓰고 팀별 직전 10경기의 공격 효율에서 상대 공격 효율을 뺀 평균을 구한다. 홈과 원정의 차이 하나를 표준화해 무마진 시장확률의 logit에 더한다. 절편 없이 L2=10으로 수축한다. 각 이력 경기는 대상 경기의 KST 날짜보다 적어도 4일 전이어야 하며 대상 경기 점수와 박스는 입력하지 않는다. 학습 라벨도 2025-08-28 및 2025-12-28 이후를 각각 제외한다.

`outcome_form`은 저장소의 기존 연구 코드를 당시 가격 파일로 재학습한 별도 비교군이다. 실제 운영 픽스터 투표나 M0를 재현하지 않는다. 후보와 시장, 비교군은 같은 평가 경기·가격·결과를 사용했다. [예측 파일](predictions.jsonl.gz)에는 선택 방향·확률·가격·원점수·두 팀 각 10개 이력 이벤트 ID를 남겼다.

기존 보관 [NBA 공식 박스 원문](https://www.nba.com/game/0022500274/box-score)과 ESPN 이벤트 401810129를 로컬 원문 해시 확인 후 직접 대조했다. 2025-11-23 03:00 UTC 덴버 123–새크라멘토 128의 팀·시각·점수가 일치했다. 이는 한 경기만 확인한 것이며 ESPN 전체 데이터의 공식 인증은 아니다. [대조 기록](official_crosscheck.json)을 참고한다.

## 한계와 검증

ESPN은 NBA 공식 데이터가 아닌 발행처 자료다. 현재 받은 과거 박스의 과거 경기 전 실제 수신을 증명할 수 없고, 원천이 뒤에 수정됐을 가능성도 있다. 4일 간격은 회고 실험의 보수적 대용 기준이다. 과거에 이미 연구된 기간이므로 독립적인 블라인드 실전 검증이 아니다. 가격의 실제 수신 시각·구매 가능성·상품 식별자·연장 포함 정산 규칙은 인증되지 않았으며 ROI는 그 조건을 가정한 참고치다. HTTP 200이나 robots 응답만으로 재배포 또는 상시 자동 수집 허가를 보장할 수 없다.

저장 예측 1,260행을 별도 검산해 각 행의 최근 이력 20개, 원점수·가격 라벨, 후보 확률과 기간별 손익·적중률·로그손실·Brier·평균 배당·최대 낙폭을 대조했다([audit.json](audit.json)). 모의 HTTP·캐시 해시·404 재실행·403/429 중단·통계 결측·경기 ID 충돌·누출 및 산식 테스트를 실행했다. 수집과 실험은 로컬 전용 작업 공간에서 수행했고 운영 원장이나 배포를 변경하지 않았다.

재현: `python scripts/nba_espn_collect.py --phase scoreboard`, `python scripts/nba_espn_collect.py --phase summary`, `python scripts/nba_espn_research.py --availability`, `python scripts/nba_espn_research.py`, `python scripts/nba_espn_audit.py`. 원천은 변할 수 있으므로 원래 로컬 캐시가 있어야 수신 당시 응답을 정확히 재현한다. 공식 단일 경기 대조는 `python scripts/nba_espn_crosscheck.py`이며 기록된 Git 객체가 필요하다.
