# 한국어 픽스터 원문 수집 결과

수집·검토: 2026-10-28. 이 하위 작업은 신규 후보 7개 중 **픽스티비·해피토토·스포츠분석전문블로그 3개 출처**의 실제 추천 확보를 맡았다. 7개 전체 성과 집계, 프로토 가격 연결, 운영 채택은 부모 작업의 범위다.

## 확보한 표본

- `candidates.jsonl`: **45경기, 추천 48개**. 일반 승패 44개, 합계점 3개, 핸디캡 1개다. 한 경기의 다른 시장을 독립 경기로 세지 않는다.
- 해피토토: 2026-08-29·09-01·09-02, 31경기·31개 추천. 작성자 덕배·한강을 글별로 보존했다.
- 픽스티비: 2026-10-15 NPB·10-24 K1, 2경기·4개 추천. 작성자 픽스티비.
- 스포츠분석전문블로그: 2025-07-08~07-18, 12경기·13개 추천. 9개 글에서 만물안박사라는 본문 바깥 작성자 표시를 확인했다. 나머지 3개 글의 작성자는 추론하지 않고 null로 두었다.
- 리그별 추천 수: K1 5개, KBO 15개, NPB 28개. K1 5개는 3경기에 해당한다. MLB·KBL·NBA 추천은 이 하위 작업에 포함하지 않았다.
- `excluded_picks.jsonl`: 2026-08-29 니혼햄–지바 롯데 1건. 본문이 작성 당시 이미 3회초였다고 명시하므로 사전 추천 집계에서 제외했다. 게시 표시 06:12와 본문의 진행 중 설명은 서로 어긋나며, 시각을 임의로 정정하지 않았다.

원문 팀 순서는 그대로 보존했다. 해피토토의 팀 순서는 실제 홈·원정 순서와 다를 수 있다. `selected_team`은 같은 글의 대진 제목에 나온 팀명으로 연결했고, 원문의 짧은 선택 표현은 별도로 기록했다. 예측 점수·선수 성적·순위·시뮬레이션은 실제 결과로 사용하지 않았다.

## 가격과 시점

모든 행에서 `cutoff_proven=false`다. 최초 관측은 이번 수집이며 과거 경기 전 관측을 복원하지 않았다. 게시 시각은 제공자 주장이다. 픽스티비·해피토토는 표시 시간대가 명확하지 않아 `source_timezone=null`; 블로그는 HTML 게시 메타데이터의 `+09:00`을 보존했다.

`observed_at`은 Python 응답 수신 시각 또는 웹 본문을 검토한 뒤 사실 레코드를 만든 현재 시각이다. 각 행의 `observation_semantics`로 구분했다. 웹 도구의 과거 응답 수신 시각을 새로 만들어 넣지 않았다.

- 소수 배당이 있는 추천은 5개다. 픽스티비 4개는 **실시간 스냅샷**이며 당시 최초 추천 가격이나 실제 구매 가능 프로토 가격으로 확정하지 않았다. 원문 국내/해외 가격을 구분해 보존했다.
- 수원FC–광주FC 글의 광주 승 약 2.45는 원문이 제시한 대략적인 시장 가격이다. 업체와 가격 관측 시각은 미확인이다.
- 요미우리–주니치 2025-07-09 글에는 해외 가격 약 **-135**가 있다. `reported_american_odds=-135`, `reported_decimal_odds=null`로 기록했다. 원문이 소수 배당을 보고한 것처럼 바꾸지 않았다.
- 그 밖의 가격은 null이다. 울산–대구 글의 승무패 배당을 대구 +1.0 또는 언더 2.5의 가격으로 재사용하지 않았다.
- 대구 +1.0은 아시안 핸디캡이다. 1골 차 패배는 푸시이며, 원문의 승/무 설명만 따라 승패 정산하지 않는다.

이번 파일만으로 **실제 구매 배당 ROI를 계산할 수 없다**. 부모가 정확한 경기·시장·기준점·가격 시점을 연결한 뒤 계산해야 한다. 원문 가격이나 게시 날짜의 존재는 사전 검증을 뜻하지 않는다.

## 결과 연결 자료

`outcome_facts.json`의 점수는 `home_score`, `away_score`에 정수로 저장했다. 추천 방향·제공자 예상 점수와 분리했으며 정산은 적용하지 않았다.

- **공식 NPB 원문 5경기**: [2026-09-02 결과](https://npb.jp/bis/2026/games/gm20260902.html). 요미우리 1–2 DeNA, 야쿠르트 5–3 한신, 주니치 5–4 히로시마, 니혼햄 1–1 소프트뱅크, 라쿠텐 4–0 오릭스. `is_official_result_source=true`. 페이지 제목·날짜와 결과 구역을 확인했고, 상단의 현재 경기 배너는 제외했다. 원문 한국어 팀명과 공식 일본어 팀명 연결도 보존했다. 무승부의 적특/패배 처리는 부모의 해당 시장 규칙으로 결정해야 한다.
- **로컬 K1 상세 2경기**: 2025-07-18 수원FC 2–1 광주, 2025-07-12 울산 2–2 대구. 정확한 날짜·양 팀명으로 1건씩 연결했다. 파일 경로·SHA256·경기 ID를 보존했다. 원래 URL·관측 시각이 없는 기존 로컬 상세이므로 `is_official_result_source=false`이고, 독립적인 공식 재검증으로 부르지 않았다. 부모가 확보한 공식 K1 결과를 우선하면 된다.

사용자가 알려준 `accuracy-formula-lab/data/processed/games.csv`는 실제 존재하지 않았다. 사용하지 않았다. `official-international.json`과 별칭 JSON은 존재하며 읽기 전용으로 형식만 확인했다. 전자의 리그는 EPL·MLB·K리그1·K리그2이며 KBO·NPB 결과는 없었다. `games.csv.tmp`는 읽지 않았다.

## 접근·제외 기록

명시적 요청 시도는 **51회**다: Python 36회와 웹 도구 페이지 명령 15회. 약 50회라는 한도에서 수집을 멈춘 뒤, 제목에 날짜가 없는 한신–히로시마 글의 본문에 **2025년 7월 10일**이 명시되어 있는지 확인하는 1회만 추가했다. 표본은 늘리지 않았다. 웹 도구 내부 요청 횟수는 관측할 수 없다.

픽스티비·해피토토의 초기 Python 요청은 ConnectionResetError 10054로 실패했다. 공개 웹 도구로 대체했으며 로그인·접근 제한 우회는 하지 않았다. 해피토토 2페이지는 일반 열기 2회가 실패하고 목록 링크 클릭 1회가 성공했다. 실패는 해당 전송 경로의 관측이며 사이트 전체의 영구 장애로 단정하지 않는다.

블로그는 7개 목록 페이지를 확인했다. `discovered.json`에는 1·2·3·6·7페이지의 링크 메타데이터 40개를 보존했다. 4·5페이지는 초기 탐색 성공 기록만 남겼다. J1/J2·국제대회는 관심 리그 밖이어서 제외했고, K2 링크는 발견했지만 한정 요청을 K1/NPB 본문에 배정했다. 픽스티비의 현재 목록은 미래 경기 위주이며 반환된 페이지에서 과거 탐색 링크를 확보하지 못했다. 비공개 API나 추측한 페이지 엔드포인트는 사용하지 않았다.

원문 전체를 보존하지 않았다. `observations.json`은 검토한 경기·시장·선택·가격 사실과 짧은 근거이고, `documents.json`은 메타데이터·해시·짧은 검사 문구다. 해시만으로 원문 전체 파서를 재현할 수 있다고 주장하지 않는다. 3개 사이트의 복제 관계·독립성도 검증하지 않았다.

## 재실행과 검증

저장한 검토 사실로 후보 생성과 검증을 다시 실행하며, 다음 명령은 네트워크 요청을 하지 않는다.

```powershell
python -X utf8 scripts/research_collect_korean_tipsters.py --build --self-test
```

검증 항목: 필수 필드·시각 오프셋·팀 연결·시장·중복, 경기 중 작성 1건 제외, 핸디캡/합계점 분리, -135를 원문 소수 배당으로 오인하지 않음, 로컬 결과 2건의 날짜·팀·점수·해시. 중복·다른 팀·증거 없는 cutoff·품질 표시 없는 가격·임의 확률·오프셋 없는 관측 시각 6가지 잘못된 입력이 실제로 거부되는지도 검사했다.

개별 요청은 `transport.jsonl`, 초기 7개 Python 탐색과 웹 15개 명령은 `prior_transport_attempts.json`, 합산은 `request_budget.json`에 남겼다. 초기 탐색 일부는 정확한 응답 시각을 보존하지 못해 세션 시간 범위와 그 한계를 기록했다. `source_attempts.json`은 출처별 시도·제외·미확인을 요약한다.
