## 이미 실행한 픽스터 단독 실험과의 관계

[PR353](https://github.com/choigod1023/proto-odds-research/pull/353)의
`experiments/tipster-replay-20261025/results-v2.json`은 별도의 픽스터 단독 재생이다.
364개 작성자 픽(71경기)의 적중률 46.70%, 단폴 ROI -9.43%였다.
정오 ET 고정, 낮은 배당 우선 두 경기 조합은 주 2회 3장 -7,000원(-23.33%),
주 3회 4장 -17,000원(-42.5%)이었다. 월 손실 한도 5만원과 미정산 노출을 포함했다.
중복 경기에 여러 작성자가 있으므로 364개의 독립 경기가 아니며, 결과는 게시자 판정으로
연결한 것이어서 공식 결과와의 독립 검증이 남아 있다. 이 결과는 모델보다 열등하다는
증거도, 미래 수익률 예측도 아니다. 같은 경기·시점의 모델 비교가 없기 때문이다.

## 픽스터에게 배울 근거

현재 TailSlips 기록은 선택·배당·작성자·게시자 판정 중심이다. 선발·결장·로테이션 등의
분석 근거가 동일 표본에 연결되어 있지 않다. 아직 픽스터 우월성도 확인하지 못했으므로
특정 분석 요소가 성능 향상의 원인이라고 해석하지 않는다. 근거별 평가에는 경기 전
관측된 기사/라인업 근거와 원래 확률을 함께 보존하고, 해당 요소만 제거한 비교가 필요하다.

## 재현

PR353의 `scripts/replay_tipster_opinions.py`를 `--replay-module`로 명시한다.
출력 JSON에 사용한 파일들의 SHA256과 원장 커밋을 기록했다. 입력 원본을 수정하지 않는다.

```powershell
python -X utf8 scripts/compare_saved_tipster_models.py --replay-module <PR353-checkout>/scripts/replay_tipster_opinions.py --decision-mode noon --output <new-result-path.json>
python -X utf8 -m unittest tests.test_saved_tipster_models
```

실험의 혼합 비율은 고정 25/50/75%이며 사후 최적 비율 탐색을 하지 않았다. 계산 가능한
표본이 없어 혼합 모델을 학습하거나 승격하지 않았다. JSON의 `expected_gross_edge_NOT_verified`는
저장된 미보정 확률과 독립시행 가정으로 계산한 참고치이며 실현 손익이나 보장 수익이 아니다.
