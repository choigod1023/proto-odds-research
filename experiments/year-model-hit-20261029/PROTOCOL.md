# 모델별 1년 범위 적중률 비교 규칙

- 요청 구간: 2025-10-29~2026-10-28, KST 경기일 기준 365일. 실제 확보된 월/리그/날짜 범위를 별도로 제시한다. 이전 2026-10-28 수집 자료를 재사용하며 10월 28일 경기까지 모두 확보했다고 주장하지 않는다.
- 비교 모델은 고정한다: 시장 마진 제거 확률, 시장90:투표10, 시장75:투표25, 시장50:투표50, 픽스터 최다 득표. 앞 숫자는 시장 비중이다. 평가 결과를 보고 소수점 가중치나 작성자/리그/배당 문턱을 최적화하지 않는다.
- 같은 공식 경기·결과·프로토 전체 가격 벡터를 공통 입력으로 쓴다. 승패/승무패만 포함한다. 핸디·합계·조합·선수 props는 섞지 않는다. 시장 확률은 기존 Shin 함수다. 시장/혼합 동률은 홈→무→원정 순서, 픽스터 동률은 보류한다.
- 작성자/발행처별 한 표. 같은 작성자가 같은 경기에서 방향이 충돌하면 제외한다. 과거 글의 진짜 최초 버전과 독립 정보원 여부는 입증하지 못했다. 원문 전체의 분석 해시가 없어 최신 수집기의 복제 제외를 과거 자료에 그대로 적용했다고 주장하지 않는다.
- 모델마다 자체 선택 표본의 적중률·선택률을 표시하고, 모든 모델이 선택한 공통 표본을 별도로 비교한다. 적중률 분모는 적중+실패, 무효/환급은 분리한다. 보류나 결과 누락을 패배로 넣지 않는다.
- 주 분석은 기존 정산 범위가 확인된 moneyline 자료, 보충 분석은 NBA/KBL의 전체 경기 연장 포함을 가정한 자료다. 둘을 합산하지 않는다.
- 회고 자료의 실제 경기 전 독립 관측 증거가 없음을 명시한다. 과거 동결 운영 모델의 1년 실적 재생이 아니며, 새 Q-EDGE 실시간 어댑터를 과거 전체에 적용한 결과도 아니다.
- 단위 ROI는 동일한 보존 가격에서의 회고 계산이며 구매 가능 가격 인증/미래 기대수익이 아니다. 1회 1만원 단폴·전 종목 합산 월 순손실 5만원의 별도 모의 장부를 모델별로 만든다. 당일 노출을 모두 예약하고 다음 날 정산하는 보수적 대용 규칙을 고정한다.
- 적중률 구간과 모델 차이는 관측 주 단위 클러스터 부트스트랩 2,000회, 고정 시드로 계산한다. 공통 경기에서의 적중 차이도 함께 제시한다. 이미 검토한 회고 표본이므로 독립 홀드아웃이나 최적 모델 채택 근거로 부르지 않는다.
- 운영 코드·모델·DB·실제 베팅은 변경하지 않는다.
