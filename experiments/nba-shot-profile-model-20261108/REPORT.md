# NBA 슛 위치 구성 회고 연구

사전 등록한 공간 구간 모델 S, 동일 원천의 비공간 대조군 Q, 시장 확률에 공간 잔차를 더하는 A를 평가했다. 기존 전적 outcome_form과 시장은 PR #668 확률을 같은 경기·배당에서 그대로 사용했다. 운영 투표나 M0 재현은 아니다.

ESPN 원천에서 검증된 1,185경기는 과거 학습 원천 풀이다. 평가 대상의 슛 기록 존재 여부로 주 표본을 고르지 않았다. 각 대상일 D에 D-365부터 D-4까지의 검증된 과거 경기만 사용했고 팀별 최소 5경기를 요구했다. 1,260경기가 모두 통과했고 팀별 사용 이력은 19~77경기다. 타깃 자체도 원천 풀에 포함된 378건(A 135, B 243)은 사후 선택된 설명용 부분집합으로 결과 JSON에 별도 수록했다.

공급자 좌표 기반 거리는 공식 NBA 구역이 아닌 proxy다. 원천 풀 1,185경기에서 2점·3점 위치 미상 시도는 0건이다. 400개 점수판 응답, 상세 200 응답 2,357건과 404 8건에서 출발했다. 원천 해시, 팀별 경기 수와 계수는 [manifest.json](manifest.json)에 있다. 원천 바이트는 Git에 포함하지 않았다.

[사전 규약](PROTOCOL.md)에 모형과 수축을 고정했다. 처음 기재한 달력 경계는 후보 성적을 생성하거나 확인하기 전에 D-365~D-4로 바로잡아 별도 커밋했다. [경기별 예측](predictions.jsonl.gz)과 [계수 학습행](train_features.jsonl.gz)에 배당·확률·이력 ID를 보존했다. gzip은 결정적이다. 월별 모든 지표와 날짜별 paired bootstrap 95% 구간(2,000회, seed 20261108)은 [results.json](results.json)에 있다.

2026년 원래 가격 804행 중 기존 공통 표본에서 31행은 필요한 상세 이력 결측으로 제외됐다. 실제 가격은 6월 14일까지, 평가 가능한 공통 경기는 5월 4일까지다. 7~10월 가격은 없다. 2025년 평가 표본은 10월 22일부터 시작한다.

두 기간은 이전 연구에서 이미 살펴본 회고 자료다. ESPN 원천은 NBA 공식 데이터가 아니고 과거 실제 수신 시점은 확인되지 않았다. 가격 수신 시점·판매 가능성·상품 식별·연장 정산 규칙도 미인증이므로 ROI는 가정에 따른 1단위 회고 수치다. 미래 수익, 운영 채택 또는 승패 외 상품의 검증을 의미하지 않는다.
