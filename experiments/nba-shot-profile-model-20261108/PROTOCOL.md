# NBA shot-profile experiment — preregistered before candidate results

Retrospective research, not a new blind test or operating-vote/M0 replay. ESPN publisher coordinates are proxies, not official NBA zones. Use only the frozen validated source pool (source events 1,185 expected), and the prior ESPN research's 1,260 uniquely matched price/evaluation records, retaining original market and outcome_form probabilities. The source pool is historical input, not an eligibility test on target PBP. Separately report the post-hoc descriptive subset whose target is itself in the source pool, without using target membership to select the primary sample. Validate exact identities, scores, dates, teams, odds and receipts; abort on ambiguity. Target PBP, boxes, score, players and subsequent source events cannot be features; target outcome is used only to fit training labels and evaluate.

Per target use all verified pool games in [D-369, D-4] inclusive (365 calendar days ending four days before the target), at least five games per team, no replacement fiction. League priors are computed from all verified pool games in the same as-of 365-day window, never from future games. If a prior denominator is zero or no valid opportunity prior, abstain; no external constant imputation. Source includes overtime if recorded; D-4 is a conservative historical proxy, not verified receipt timing.

Nine two/three-point categories use provider coordinate r=hypot(x-25,y): 2-point [0,4), [4,10), [10,16), [16,infinity), unknown; 3-point [0,24), [24,27), [27,infinity), unknown. Coordinate values and finite boundary rules are independent of made/missed outcome. Reconcile valid source aggregate counts and team identity with source manifest. ORB/TOV enter estimated opportunities P=FGA-ORB+TOV+0.44*FTA, not official possessions; ORB is not added again. Own and opponent estimated P are averaged per historical team game, shared target P is geometric mean of both teams' averages.

For each 9-zone attempt rate and FT rate per estimated opportunity, use exposure shrinkage: r_off=(team attempts+500*league rate)/(team P+500), r_def=(opponent attempts allowed+500*league rate)/(opponent P+500). Combine as r_off*r_def/league rate; if a league zone has zero attempts, set that zone's expected makes to zero, without dividing. Zone shooting probability shrinks with strength 200 times its share of league attempts within its 2P or 3P family: p_off=(team makes+strength*league accuracy)/(team attempts+strength), similarly p_def for opponent allowed. Combine on odds scale: odds(p_off)*odds(p_def)/odds(league accuracy), logistic transform. Clip all accuracy inputs and combined accuracy to [0.000001,0.999999] for both models. FT shooting uses strength 200. Clip attempt rates to [0,1.5]. The pair of predictions uses P times combined attempts times combined accuracy. S uses nine zones, Q pools the exact same zone counts into 2P and 3P families before applying the same formulas, each family having aggregate accuracy prior strength 200. FT identical in both. This pooling changes only spatial granularity, not source, window, exposures, clipping or shared opportunity assumption.

S and Q are independent score-generating models: 2*Poisson(expected 2-point makes)+3*Poisson(expected 3-point makes)+Poisson(expected free throws). Compute exact numerical convolution over k=0..250 for each component and fail if omitted Poisson tail exceeds 1e-12. Home win probability is P(home score>away score)+0.5*P(tie), a symmetric overtime approximation; home wins exact 0.5 selection ties. No new home intercept or grid search.

A uses logit(p_A)=logit(p_market)+beta*(logit(p_S)-logit(p_Q)), clipped probabilities [1e-6,1-1e-6], no intercept, with sum binary log loss + 10*beta²/2 minimized using bounded scalar search beta in [-10,10], tolerance 1e-12. Training rows are priced games with prequential features computed from each row's own D-4 365-day history/prior, at least five source games per team, matching unique ESPN event identity and outcome. First fit on 2025-01-01 through 2025-08-28 for A (2025-09-01–12-31), refit 2025-01-01 through 2025-12-28 for B (2026-01-01–10-27). Never fit using target dates inside evaluation period. If no eligible training rows, fail rather than silently impute. Other evaluation observations never affect beta or each other's prior except through source games D-4 already in the historical pool.

Compare Q, S, A, market and original outcome_form on identical valid events, exact same odds, one unit per match and argmax pick, including all months; no post-hoc parameter or market filter. Report full per-period and monthly counts, hits, ROI, log loss, Brier, mean chosen odds, daily aggregate max drawdown and coverage, changed picks; paired date-bootstrap 2,000 seed 20261108 percentile 95% intervals for S−Q and each candidate−market and candidate−outcome_form. Preserve per-event prediction, source history IDs, model choices, fitted beta, training cutoff and source hashes. The target-source intersection is a descriptive subset, not independent or causal validation. Price receipt timing, product identity, ability to buy, and overtime settlement rules are unverified, so all one-unit ROI is conditional. No claim about other markets, future profit, deployment or prospective validation.
