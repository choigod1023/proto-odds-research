# 최종픽 제외: 사실형 주장과 기존 컨텍스트 분리 검증

2026-10-24 실행. 운영 코드·모델·DB·수집 작업을 바꾸지 않는 로컬 연구다.

## 결론

픽스터 최종 선택은 입력·실험에서 완전히 제외했다. 기존 공개 글에서 사실형 주장 11개를 구조화했지만, **사전 관측 시각과 독립적인 공식 대조 증거를 갖춘 주장은 0개**다. 따라서 픽스터 사실 추가 모델의 적중률·ROI는 계산 불가이며 results.json의 `tipster_incremental_roi`는 null이다. 0%라는 뜻이 아니다.

대신 기존 historical games에서 재구성할 수 있는 최근 경기력·휴식 변수를 활용하는 대조 실험을 실행했다. 일부 연도 개선은 있지만 모든 경우의 단폴 ROI가 음수이고 연도 간 일관성도 없다. 운영 승격 근거로 쓰지 않는다.

## 정보 분리

- 팀 최근 성적: 기존 form_diff·margin_diff·trend_diff·streak_diff와 같은 정보 계열. 글의 문장을 팀 통계와 정확히 동등하다고 단정하지 않는다.
- 휴식·연전: rest_diff·b2b_home/away로 일부 이미 표현된다. 원정 거리·시차·연장전 시간까지 표현하는 것은 아니다.
- 투수 최근 성적: 팀 최근 성적과 구분한 pitcher_form. 기존 팀 form의 중복으로 처리하지 않는다.
- 선발·부상·불펜 사용량: 이번 games 파일에 대응하는 검증된 사전 기록이 없어 추가 입력으로 만들지 않았다.
- 최종 승패 선택, 핸디캡·언더오버 추천, 우세·필승 같은 의견: 지원하는 사실 타입이 아니다. 자유 본문/추천/배당/결과 필드를 입력에 붙여도 gate 출력에는 전달하지 않는다.

`assess`는 확인된 경기 ID, 관측시각 ≤ 예측시각 < 시작시각, 별도 출처의 확인 기록과 그 기록의 사전 관측시각을 요구한다. URL과 confirmed=true 자체가 진실을 보증하지는 않으므로 신뢰할 수 있는 검증자가 증거를 확인해야 한다. 텍스트 자동 진위 판별기나 운영 인코더를 구현했다고 주장하지 않는다. 숫자와 home/away만 출력하며 자유 텍스트는 모델에 보내지 않는다.

## 재구성 변수 대조 실험

공통 load_data와 fit/predict를 재사용했다. 입력 184,473행에서 유효한 중복 제거 시장 174,620행, invalid 3,448행, 충돌 재발매 584건 제외, 최종 primary event 45,184개다. 입력 SHA256은 results.json에 기록했다.

기준선은 기존 연구의 시장확률 offset 다항 로지스틱 + Elo + 종목별 SPORT_FEATURES이며 **운영에 저장된 사전 추천 재현은 아니다**. 추가 모델은 form·margin·trend·streak·rest·b2b 기존 변수의 합집합이다. 새 글의 사실이나 픽스터 선택을 사용하지 않는다. ridge 0.01과 변수 집합을 첫 실행 전에 고정했고 이번 결과를 보고 튜닝하지 않았다.

2025 평가는 2023~24 학습, 2026 평가는 2023~25 학습이다. 2026은 8월까지의 일부 연도다. 같은 경기/같은 배당에서 가장 높은 확률의 선택 1개에 동일 금액을 건 단폴 회고 ROI이며, 후보 선택에 실제 결과를 쓰지 않는다. 현재 경기 결과는 예측 변수 갱신 뒤 반영하는 기존 features 구현을 재사용한다. 단, 원천 배당 관측시각과 과거 결과의 수정 이력을 입증한 것은 아니다.

각 줄은 기준선 → 추가 모델, 괄호는 평가 경기 수다.

- 야구 2025 (3,890): 적중률 56.25% → 56.38%, ROI -14.65% → -14.40%.
- 야구 2026 (2,993): 적중률 56.97% → 57.70%, ROI -12.31% → -10.90%.
- 축구 2025 (6,499): 적중률 52.81% → 53.01%, ROI -10.49% → -9.89%.
- 축구 2026 (3,268): 적중률 51.22% → 51.19%, ROI -12.76% → -12.81%.
- 농구 2025 (1,921): 적중률 67.46% → 67.00%, ROI -11.68% → -12.34%.
- 농구 2026 (1,148): 적중률 71.08% → 70.91%, ROI -9.40% → -9.60%.
- 배구 2025 (546): 적중률 66.85% → 68.68%, ROI -12.78% → -9.26%.
- 배구 2026 (356): 적중률 70.22% → 69.66%, ROI -9.19% → -10.03%.

총 평가 20,621경기. 7개 연속 관측일 블록 paired bootstrap 1,000회, seed=20261024의 차이 95% 구간을 JSON에 저장했다. 야구 2026 적중률 차이 +0.735%p (구간 +0.125~+1.278%p), ROI 차이 +1.412%p (+0.412~+2.328%p); 배구 2025 적중률 차이 +1.832%p (+0.368~+3.202%p), ROI 차이 +3.515%p (+0.813~+6.092%p)다. 나머지 종목/연도 차이 구간은 0을 포함한다.

이 구간은 다중 비교를 보정하지 않았으며 같은 역사 자료는 이전 연구에서도 여러 번 평가했다. 시간순 분리는 했지만 완전히 새롭고 손대지 않은 최종 홀드아웃은 아니다. 야구 2026은 Brier가 0.48540→0.48830으로 악화했다. 적중률 상승만으로 확률 품질·수익 안정성이 좋아졌다고 결론 내릴 수 없다. 월 -5만원 정책을 변경하지 않았고 이번 단폴 실험으로 2폴 월 모의 손익을 산출하지 않았다.
