# 신규 과거 픽스터 12경기 연결·비교 — 2026-10-26

기존 16경기를 다시 평가한 결과가 아니다. 이번에 새로 찾은 12경기만 계산했으며 이전 원장의 날짜·종목·홈·원정 키와 겹치면 실행을 실패시킨다. 기존 16경기와 합치면 식별한 경기는 28경기지만, 기존 경기의 공식 결과 재검증 상태가 다르므로 ROI를 합치지 않았다.

## 실제 결과

신규 표본에서 연구 대조군·픽스터 단독·고정 9:1 혼합의 선택이 모두 일치했다. 따라서 아래 결과는 세 방식에 동일하다.

- 야구 MLB 1경기: 1적중, ROI +51.00%, 경기당 1만 원이면 +5,100원.
- 농구 NBA 3경기: 0적중, ROI -100.00%, -30,000원.
- 축구 EPL 1경기: 1적중, ROI +63.00%, +6,300원.
- 배구 KOVO여 7경기: 4적중, ROI -25.71%, -18,000원.
- 전체 12경기: 6적중, 총 투입 120,000원, 순손익 -36,600원, ROI -30.50%.

이번 자료에서는 9:1 혼합이 선택을 바꾸지 않았으므로 수익 개선을 확인하지 못했다. NBA 3연패나 야구·축구 각 1승으로 종목 전체의 실력을 판단할 수도 없다.

## 입력과 정의

`sources.json`에 새 분석 URL, 추천 방향, 표시 게시 시각(확인 가능한 경우), 공식 결과 URL, 공식 점수를 기록했다. `results.json`에는 각 경기의 실제 아카이브 배당, 회차·게임 번호, 확률, 선택, 정산 결과를 저장했다. 본문 전체를 재배포하지 않고 사실 필드와 출처만 보관했다.

- 기존 모델 대조군: 2023–2024년 자료로 학습한 시장확률 오프셋 로지스틱 연구 모델. 현재 운영 모델의 동결된 과거 예측은 아니다. 따라서 운영 모델 자체의 과거 수익이라고 해석하면 안 된다.
- 픽스터: 해당 글의 일반 승패/승무패 방향을 단일 작성자의 투표로 표현한다. 100% 적중 확률이라는 의미가 아니다. 핸디캡·언더오버를 섞지 않는다.
- 혼합: `0.9 × 연구확률 + 0.1 × 픽스터 투표`, 최대값 선택. 결과를 보고 가중치나 배당 조건을 튜닝하지 않았다. 로그오즈 혼합과도 다르다.
- 단폴, 동일 경기·동일 배당, 동일 1만 원 투입. 배당 반올림이나 2폴 규칙은 사용하지 않았다.
- 정확한 공식 점수와 로컬 점수가 일치하고 주시장 배당이 유일하게 연결된 경기만 포함했다. NBA·MLB의 미국 경기일과 한국 날짜의 차이를 반영했다.

## 증거 수준과 한계

12건 모두 공식 리그/구단 자료로 결과를 따로 확인했다. NBA는 NBA.com, MLB는 MLB.com, EPL은 AFC Bournemouth 공식 자료, 배구는 흥국생명 구단 경기결과를 사용했다. 세부 출처는 원장에 있다.

픽스터 원문은 검색 색인으로 확인한 글 6건과 와이즈티비 게시판에 표시된 추천 6건으로 나뉜다. 게시판 자료는 본문의 일관성·작성자를 검증하지 못했으며 별도 `listing_pick` 등급이다. 배구 3월 20일 글은 승리 예상과 달리 대표 추천이 총점이고 선수 명단도 오래된 정보라 경고를 남겼다. 이 글과 게시판 자료를 제외한 5경기 민감도 결과도 JSON에 따로 기록했다. 이를 숨긴 채 모두 완전한 원문 수집이라고 부르지 않는다.

사후 수집이므로 글 수정 가능성을 배제하지 못한다. 배당도 실제 아카이브 값이지만 관측 시각·당시 구매 가능성은 입증하지 못했다. 경기 전 증거까지 검증된 표본은 **0건**이다. 여기서 산출한 것은 사후 가상 실현 ROI이지 미래 기대수익률이 아니다.

검색으로 발견하고 연결 가능한 자료를 모은 편의표본이다. 배구는 흥국생명 경기, 특히 같은 챔피언결정전 시리즈에 집중되어 독립적인 7개 사례로 보기 어렵다. 전체 시즌이나 모든 픽스터의 대표 표본이 아니다. 이번 확대는 신규 자료 연결과 실제 계산까지 수행한 중간 결과이며, 대규모·균형 표본 검증 완료를 뜻하지 않는다.

## 월 손실 한도

월 -5만 원 제한을 유지한 단폴 모의 계산도 실행했다. 같은 날 미정산 베팅 전액을 위험금액으로 예약하고 다음 날 정산했다고 가정했다. 해당 12경기에서는 한도 때문에 제외된 경기가 없었다. 월 손익은 3월 -8,600원, 4월 -16,300원, 5월 -24,900원, 8월 +6,300원, 10월 +6,900원이다. 실제 종료 시각은 복원하지 않았고 주간 횟수 제한은 적용하지 않았으므로 사용자의 실제 월 수익 시뮬레이션과 동일하지 않다.
