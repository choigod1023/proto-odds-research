# 사전 신호 조건부 하이브리드 모의 실험

2026-10-25 로컬 실행. 운영 모델·DB·자동 실행 설정은 바꾸지 않았다.
기존에 여러 번 살펴본 MLB 28경기/5일을 재사용한 개발 진단이다.
새 검증 표본이나 조건부 모델 전체에 대한 최적화 결과가 아니다.

## 비교 규칙

- model / tipster / fixed25: 기존 모델, 픽스터 단독, 모델75%·픽스터25%.
- disagreement50: 양쪽이 서로 다른 승자를 지지하고 점수 차이가 0.20 이상이면
  픽스터 비중50%, 아니면25%.
- consensus50: 사전 작성자5명 이상, 한쪽 선택 비율75% 이상이면 픽스터50%, 아니면25%.
- past_brier: 이전 날짜이며 의사결정 전에 결과까지 관측된 경기가10개 이상일 때만
  0/25/50% 중 과거 Brier가 가장 작은 비중을 비교한다. 고정25%보다 Brier가
  0.01 이상 좋아야 전환한다. 그 외25% 유지. 현재/미관측 결과는 선택에 쓰지 않는다.

이 임계값은 이번 개발용 가설이다. 이전 결과를 이미 본 상태에서 정했으므로
사전 등록 또는 독립 검증으로 표현하지 않는다. 추가 임계값 탐색은 하지 않았다.
픽스터 투표 비율은 보정된 승률이 아니며 작성자 수는 정보의 독립성을 보장하지 않는다.
현재 입력에는 작성자별 과거 실력, 선발 변경, 결장, 배당 이동이 없어 실험하지 않았다.

## 단폴 동일 금액 결과

- 기존 모델:14/28, ROI -21.5357%, Brier0.240076.
- 픽스터:12/28, ROI -25.8571%, Brier0.352277.
- 고정75:25:18/28, ROI +7.3929%, Brier0.253241.
- 불일치 전환:15/28, ROI -8.6429%, Brier0.249338.
- 강한 합의 전환:18/28, ROI +7.3929%, Brier0.256078.
- 과거 Brier 전환:12/28, ROI -33.3214%, Brier0.254702.

고정75:25 대비 날짜별 ROI 승/무/패는 불일치0/3/2,
강한 합의0/5/0, 과거 Brier0/3/2다. 확률 오차 개선과 수익 개선은 일치하지 않았다.
이 세 전환 규칙 중 고정75:25보다 나은 후보는 없었다.

## 두폴·월 손실 한도

기존 PR353 재생기를 그대로 사용했다. 정오ET, T-30, 서로 다른 경기,
각 모델이 선택한 편 중 낮은 배당 우선2개, 한 장1만원, 주2회/3회,
KST 주·월 기준, 월 순손실5만원 및 미정산 최대 노출을 반영했다.
이는 운영 관심픽55%/1.50 필터가 아니라 기존 연구용 조합 규칙이며 1.50미만도 포함한다.
각 전략은 별도 가상계좌이며 실매수하지 않는다.

모든 전략의 최종 손익은 같았다. 주2회는2장/+1,000원/ROI+5%/최대낙폭10,000원,
주3회는3장/-9,000원/ROI-30%/최대낙폭20,000원이다.
**일부 선택 경기와 배당은 서로 다르다. 같은 티켓이었다는 뜻이 아니다.**
8월·9월 일부 날짜만 포함하며 완전한 월 수익률이나 손실한도 효과를 검증하지 못했다.
선택에 적합한 다음 경기일이 부족하고 주간 한도 때문에 티켓 수가 극히 적다.

## 한계와 결정

결과는 publisher_not_official이다. 공식 결과 독립 대조와 정오 체결 가능 가격 확인이
남는다. 결과가 연결된 공통 부분집합만 평가해 누락 편향도 있다.
조건부 전환을 운영에 채택하지 않는다. 고정75:25도 미래 수익 보장이나 실전 승인으로
해석하지 않는다. 월 손실 한도와 기존 운영 모델은 변경하지 않았다.
