# NBA·K리그 선수 출전 부담 검증

K리그1·2는 기존 팀 전력 Poisson 모델과 출전 부담을 반영한 모델을 비교했다. 기존 동결 예측과 공식 경기 결과를 같은 프로토 G101 90분 승무패 배당에 연결했다. 두 모델 모두 경기당 최고 확률 선택에 1단위를 걸었다고 가정했다. ROI는 모의 정산 손익을 총 투입액으로 나눴다. 실제 운영 픽스터 투표나 다른 상품의 성과는 이 비교 범위 밖이다.

## K리그 결과

2026년 7월 4일~11월 1일을 평가했다. K1 432경기와 K2 521경기의 규정시간 출전 분수를 복원했다. 평가 기간에 동결 예측이 있었던 K1 114경기와 K2 128경기 중 각 1경기는 적격 배당이 없어서 제외했다.

- **K리그1 113경기**에서 기존 모델은 42건 적중(37.17%), ROI −23.73%였다. 최근 출전 시간·휴식·이전 선발 변경을 넣으면 37건 적중(32.74%), ROI −32.30%였다. 실제 당일 선발을 회고적으로 넣으면 35건 적중(30.97%), ROI −35.36%였다.
- **K리그2 127경기**에서 기존 모델은 57건 적중(44.88%), ROI −17.99%였다. 최근 출전 시간·휴식·이전 선발 변경을 넣으면 51건 적중(40.16%), ROI −22.96%였다. 실제 당일 선발을 회고적으로 넣으면 52건 적중(40.94%), ROI −21.28%였다.
- 주 분석에서 바뀐 선택은 K1 30건, K2 36건이었다. 주 단위로 묶어 5,000회 다시 뽑은 ROI 차이의 95% 구간은 K1 −25.64~+7.92%p, K2 −26.76~+16.06%p였다. 두 리그 모두 관측 성과가 낮았고 구간은 0을 포함했다. 이 보정안을 채택할 근거는 확인하지 못했다. 집계는 `kleague-results.json`에, 경기별 선택과 배당, 확률은 `kleague-results.picks.jsonl`에 저장했다.

## 원천과 평가 시점

- K리그 공식 선발과 경기 타임라인을 사용했다. K1 타임라인은 보관 Git 원본에서, K2는 연맹의 경기 상세 API에서 읽었다. 교체·직접 퇴장·경고 누적을 반영해 90분 기준으로 합산했다. 휴식은 리그 경기 날짜 기준이고 컵·국제대회 및 훈련 부하는 반영하지 않았다. [K리그 공식 기록 안내](https://www.kleague.com/news_view.do?orderBy=seq&page=2&seq=2918&viewOption=list)
- 2025년 기록으로 학습용 팀 전력을 만들고, 2026년 6월 24일까지의 결과로 보정 계수를 학습했다. 평가는 7월 1일 이후 기존 연구의 동결 예측을 사용했다. 주 분석은 완료된 과거 경기만 본다. 평가 경기의 실제 선발은 공식 경기 후 기록으로 확보했으므로 따로 회고 분석했다. 가격도 당시 수신 시각을 입증하지 못한 보관 배당이므로 결과는 모의 회고 비교다.
- K리그 2부 초기 검산에서 명단 페이지의 교체 요약으로 연쇄 교체를 잘못 해석하거나 제외하는 사례를 확인했다. 최종 계산에는 공식 타임라인을 사용했다. 팀·경기 ID와 공식 점수를 확인했고, 원본 SHA-256과 정규화 이벤트는 `k2-official-timelines.jsonl.gz`에 있다.

## NBA

공식 일정 27경기, 그 일정 자료에 포함된 종료 결과 13경기, 다른 세 날짜의 공식 최종 박스스코어 3경기를 확인했다. 2026년 11월 4일(미국 날짜)의 부상 PDF는 원본 해시를 대조했고, 경기 전 수신한 14경기에서 선수 상태 119행을 확인했다. 보고서의 선수명은 공식 선수 ID로 확인되지 않았고, 명단에 없다는 이유로 출전을 확정하지 않았다. [NBA 공식 부상 보고서](https://official.nba.com/nba-injury-report-2026-27-season/) · [공식 박스스코어 예시](https://www.nba.com/game/0022500274/box-score)

보관된 NBA 프로토 배당 676행 중 정산 규칙이 확인된 행은 0건이다. 공식 일정·박스스코어와 시작 시각·홈 및 원정 코드로 유일하게 연결되는 배당은 1경기였고, 위 14경기에는 0경기였다. 부상 자료가 있는 14경기 중 양 팀 모두의 지난 7일 내 공식 박스스코어가 있는 경기도 0경기였다. 과거 공식 부상 PDF 조회에서 HTTP 403을, 공식 통계 박스스코어 API 조회에서 읽기 시간 초과를 확인했다. 이 교집합에서는 연전·최근 주전 출전 시간·부상 상태를 함께 넣어 학습하거나 동일 배당으로 정산할 수 없다. `nba-audit.json`에 미산출 상태와 확인한 원본 범위를 기록했다.

## 재현

저장소 루트에서 아래 명령을 실행한다. 세 Git 입력 커밋은 `kleague.py`, NBA 박스스코어 커밋은 `nba_audit.py`에 고정했다. 해당 개체가 없는 새 클론에서는 기존 K1·K2 라인업 비교 브랜치와 K1·NBA 공식 근거 브랜치를 가져와야 한다. K2 최종 타임라인은 함께 저장했으므로 재생 중에는 네트워크 호출이 없다. NBA 부상 PDF 원본을 보유하면 `--injury-pdf`로 gzip 파일을 지정해 원본 해시를 재확인할 수 있다.

```powershell
$research = 'experiments/nba-kleague-workload-20261106'
python -X utf8 "$research/kleague.py" --state .local-test/nba-kleague-replay --output .local-test/kleague-results.json
python -X utf8 "$research/nba_audit.py" --state .local-test/nba-kleague-replay --output .local-test/nba-audit.json
python -m pytest -q tests/test_league_workload_replay.py
```
