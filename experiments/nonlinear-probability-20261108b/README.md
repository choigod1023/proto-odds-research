# 비선형 확률 회귀: 회고 연구

2023~2024 자료로 적합하고 2025 전체를 검증 기록으로 남긴 후 설정을 바꾸지 않고 2026-01-01~08-26을 평가했다. 사전 외부 등록은 없으며 여러 연구에 반복 사용된 회고 자료다. 독립 미공개 검증이 아니다. 실제 원가격 수신 시점, 구매 가능성, 공식 결과 최초 가용 시각을 확인하지 못했다. 픽스터·선수·운영 모델 입력은 없다. 운영·추천·모의 지갑을 재현하거나 변경하지 않는다.

## 결과

종목 순서는 야구, 축구, 농구, 배구다. 평가 경기는 각각 2,995, 3,634, 1,148, 356경기다. 시장 / 선형 / RFF / 스플라인의 적중률(%)은 각각 야구 57.06/57.53/57.13/56.89, 축구 50.47/50.63/50.72/50.83, 농구 70.38/70.64/70.73/70.91, 배구 69.94/71.07/70.79/70.22다. 같은 순서 ROI(%)는 야구 -12.19/-11.36/-12.06/-12.44, 축구 -13.42/-12.86/-12.68/-12.37, 농구 -10.66/-10.20/-10.03/-9.74, 배구 -9.70/-7.71/-8.21/-9.20다. **모든 후보와 대조군의 절대 ROI가 음수다.** LL, Brier, 일별 MDD, 리그·분기·월별 전체 결과와 2025 검증은 summary.json에 있다.

동일 입력 선형 대비 RFF 적중률 차이와 95% 주별 쌍체 구간(%p)은 야구 -0.40 [-0.87, 0.07], 축구 +0.08 [-0.14, 0.29], 농구 +0.09 [-0.31, 0.45], 배구 -0.28 [-0.94, 0.00]이다. 스플라인은 -0.63 [-1.21, 0.00], +0.19 [-0.13, 0.49], +0.26 [0.00, 0.54], -0.84 [-2.06, 0.00]이다. 반올림한 끝점은 정확한 0이 아닐 수 있으며, 차이는 작고 여러 비교에 대한 보정이 없다. 신뢰구간이 경계에 걸리는 결과를 포함해 비선형 표현력의 안정적 개선을 주장하기 어렵다. 구간·방향별 변경 픽·LL/ROI 차이와 두 방향 부호 꼬리 비율은 summary.json을 따른다. 부호 꼬리 비율은 귀무분포를 강제한 검정이 아니며 다중검정 보정도 하지 않았다.

## 설계와 신규성

동일 종목·경기 ID·상품·배당·결과로 모델을 나란히 비교한다. 기존 `all-sports-underdog-20261031/common.py`의 day+4 팀 Elo/최근 전적/리그 사전율을 재구성하고, 시장 중심 로그확률을 입력으로 추가한다. 직접 시장은 역배당 정규화 확률, 선형은 동일 피처에 시장 로그확률 offset을 둔 L2 다항 로짓이다. 두 후보는 동일 offset과 선형 피처를 공유하고 각각 고정 시드 RFF 64개 또는 고정 절점 선형 스플라인과 시장·전적 상호작용을 추가한다. 벌점 0.03, RFF 폭 0.5, 절점 -1/0/1은 고정이며 평가 결과를 보고 선택하지 않았다. 연속 입력 표준화는 학습 구간에서만 구하고 변환값은 ±5로 제한한다. 2025를 검증으로만 쓰고 재적합하지 않았다. 무승부는 축구에서 별도 선택지이며 비축구 무승부·기권·결측은 원천에서 빠진다.

기존 `scripts/sport_model_tournament.py`는 부스팅과 확률 보정·혼합을, `all-sports-underdog-20261031`은 선형 시장 잔차 및 팀 전력을, KL 후속은 K리그 교차상품의 점수분포 투영을 실험했다. 여기서는 같은 전력·가격 입력의 비선형 표현을 선형 대조군과 비교한다. 시장 잔차, 전적 입력, 회고 자료 자체의 신규성을 주장하지 않는다. [Rahimi–Recht 원문](https://proceedings.neurips.cc/paper/2007/hash/013a006f03dbc5392effeb8f18fda755-Abstract.html)의 무작위 유한 차원 특징을 응용했으며 커널 전체 행렬은 만들지 않는다. [NGBoost 원문](https://proceedings.mlr.press/v119/duan20a.html)의 자연기울기 분포 부스팅은 구현하지 않았다. 설치된 ngboost가 없고 점수 분포 입력도 검증되지 않아 일반 부스팅으로 대체하지 않았다.

입력 원장은 종목별 `experiments/all-sports-underdog-20261031/results/{bs,sc,bk,vl}/domestic_archive/ledger.jsonl.gz`다. 원천은 이미 걸러진 확정 결과·가격이며 상품 정합성과 중복 제거는 해당 원장에 의존한다. 입력 ID 중복은 중단한다. 팀·리그명 인코딩 오염과 동명 충돌, 날짜 기준 가격 및 결측·기권의 원천상 누락은 완전히 복구하거나 검증하지 못했다. 팀 상태는 결과의 최초 가용이 경기일+4일이라는 가정이며 실제 보장은 아니다. 같은 날 결과와 미래 시즌 요약은 쓰지 않는다. 2024-12-28~31 결과는 학습 계수에서 제외하고, 2025 및 2026 팀 상태는 day+4에 갱신된다. 2025 결과를 보관한 뒤 모델을 고르는 절차는 적용하지 않았다.

경기당 1단위 가상 선택이며 최고 확률 동률은 배열 앞쪽이다. 승리 손익은 Decimal 배당-1, 실패는 -1, 원천의 미정산·환불은 분석에서 제외한다. 낙폭은 일별 합산 누적 손익의 고점 대비 최대 하락이며 손익 단위다. ISO 주 단위 쌍체 1,000회 부트스트랩, 후보−대조군이다. 적중률/ROI는 양수가 좋고 LL은 음수가 좋다. 행별 파일은 event_id, day, sport, league, y, odds, market_p, model, p, pick, hit, net을 보관한다. 배열 순서는 원천 승/무/패(축구), 승/패(그 외)다.

재현: `python -X utf8 experiments/nonlinear-probability-20261108b/run.py`; 검증: `python -m pytest -q experiments/nonlinear-probability-20261108b/test_nonlinear_probability.py`. 테스트는 월말 토요일부터 day+4 수요일까지 결과 누출, 평가 라벨 변경 시 동결 예측 불변, 정렬·확률합·Decimal 정산을 검사한다. 가격 관측 시점 검증은 이 테스트가 해결하지 못한다.
