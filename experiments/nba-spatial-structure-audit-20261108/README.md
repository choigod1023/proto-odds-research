# NBA 슛 위치 모델: 성능 저하 진단과 구조 개선 재검증

결론: 시도 횟수를 보존하고 위치 경계를 평활화하는 구조 개선을 실제 실행했으나, 위치를 쓰지 않은 동형 득점 모델 Q보다 적중률과 ROI가 두 기간에서 함께 좋아진 후보는 없었다. 기존 위치 모델 S에 비해 확률 오차 일부를 줄였다는 사실과 운영 채택 근거는 구별한다. 네 후보 모두 운영에 적용하지 않았다.

## 사용한 자료와 비교 범위

- 입력: ESPN 원문에서 양 팀 박스 기록과 플레이 집계가 일치한 1,185경기, 야투 210,663개. 이는 학습 특성을 만드는 이력 풀의 크기이며 평가 경기 수가 아니다.
- 평가: 동결된 NBA 1,260경기. A는 2025-10-22~12-31의 487경기, B는 2026-01-01~05-04의 773경기. 이번 작업에서 유리한 월이나 경기만 선택하지 않았다.
- 모든 모델이 같은 경기 ID, 홈/원정 순서, 승패, 가격 벡터를 사용한다. 1경기 1단위, 확률 0.5 이상이면 홈 선택. 월 손실 제한을 적용한 운영 지갑 성과가 아니다.
- 각 대상 날짜 D의 특성에는 D−365~D−4의 이력만 사용한다. 팀당 최소 5경기를 요구하고, 리그 사전분포도 해당 시점 이력만 사용한다.
- 시장 앵커 계수의 학습 종료는 A 2025-08-28, B 2025-12-28이며 각각 721/1,187행이다. 두 재학습 집합에 같은 경기가 들어갈 수 있으므로 1,908행을 서로 다른 경기 수로 해석하지 않는다.
- Q는 위치를 쓰지 않는 2점·3점·자유투 득점 분포 모델, S는 기존 위치 모델이다. Q와 기존 전적 대조군은 서로 다르며, 둘 다 운영 픽스터 투표나 운영 M0의 재현이라고 주장하지 않는다.
- 과거 가격의 정확한 상품·관측 시각·구매 가능성·연장전 정산 규칙은 인증되지 않았다. ROI는 **조건부 과거 가상 ROI**다. ESPN 자료는 리그 공식 인증 원문이 아니며, 사후 확보한 이력이 당시 사전 수집 성공을 증명하지 않는다.
- 두 기간은 이미 검토했던 과거 자료다. 이번 후보의 규약을 평가 전에 커밋했어도 새 블라인드 검증은 아니다.

## 왜 더 나빠졌는가

### 위치 정보와 슛 기회량이 함께 바뀌었다

기존 Q는 2점/3점 계열을 먼저 합산해 공격 시도율과 상대 허용률을 결합한다. S는 각 구역별 비율을 곱한 뒤 더한다. 일반적으로 다음 두 값은 같지 않다.

`R_Q = r_off,family × r_def,family / r_league,family`

`R_S = Σ_z (r_off,z × r_def,z / r_league,z)`

따라서 위치 효과만 추가한 비교가 아니었다. 실제 2점 S/Q 비율 범위는 약 0.956~1.047, 3점은 0.939~1.055였다. 평균이 1에 가까워도 서로 다른 팀의 변화가 상쇄되므로 문제가 없다는 근거가 되지 않는다. 반대로 모든 경기의 시도 횟수가 체계적으로 부풀었다고 주장해서도 안 된다.

계열 기대 성공 수 R×A의 차이를 다음처럼 정확히 분해했다.

`S−Q = (R_S−R_Q)(A_S+A_Q)/2 + (A_S−A_Q)(R_S+R_Q)/2`

여기에 공통 기회량과 2/3점 가치를 곱했다. 팀별 두 계열을 합친 기여의 평균 절댓값은 다음과 같다.

- A: 시도율 0.533점, 성공률 0.242점. 시도율 기여의 팀별 최대 절댓값은 3.090점.
- B: 시도율 0.583점, 성공률 0.250점. 최대 절댓값은 3.173점.

이는 대수적 귀속이다. 시도율 변화가 실제 패배를 인과적으로 일으켰다는 증명은 아니다. 아래의 보존 실험도 실패했으므로 이 항만 고치면 수익이 회복된다고 결론내릴 수 없다.

### 바꾼 픽에서 잃은 적중이 더 많았다

- A: Q→S에서 20경기 선택 변경. 원래 적중을 실패로 바꾼 11경기, 반대 9경기. 적중 2개 감소, 손익 2.60단위 감소.
- B: 30경기 변경. 원래 적중을 실패로 바꾼 16경기, 반대 14경기. 적중 2개 감소, 손익 9.49단위 감소.
- 전체 손익 차이 −12.09단위, 전체 ROI 차이 약 −0.96%p. 바꾸지 않은 경기는 같은 가격·방향이므로 손익 차이가 없다.

### 위치 구간의 민감도와 추가 정보의 약한 효과

기존 좌표는 `hypot(x−25,y)`라는 비공식 제공자 거리다. 이전 원문 감사에서 경계 1피트 이내에 3점 시도의 60.61%, 2점 시도의 24.66%가 있었다. 따라서 경계 민감도를 검사할 이유는 있지만, 이 수치 자체가 측정 오차나 성능 저하의 원인이라는 뜻은 아니다. 아래 F는 반경 1피트의 균일 질량이라는 고정 가정이며 실제 측정 오차 분포를 인증한 것이 아니다.

## 실제로 만든 네 후보

1. H: Q의 계열 전체 시도율을 유지한다. S의 구역별 결합 시도율은 계열 내 합이 1이 되도록 정규화하고, 구역별 성공률을 가중 평균한다. 자유투·기회량·기존 사전분포는 유지한다.
2. F: H에 거리 경계 평활을 추가한다. 각 야투를 `[max(0,r−1), r+1]`와 구역의 겹침 비율로 나눈다. 2점과 3점 사이에는 이동시키지 않는다.
3. H_A: `logit(market) + β × [logit(H)−logit(Q)]`.
4. F_A: 같은 식에 F를 사용한다.

β는 학습 구간에서만 추정하고 L2=10, 절편 없음으로 고정했다. 평가 성적을 보고 폭·사전분포·정규화·배당 필터를 다시 고르지 않았다. 규약 커밋은 `c854390e`다.

## 같은 경기·배당의 결과

### A: 487경기

- 위치 없는 Q: **288적중, 59.14%, ROI −16.93%, 로그손실 0.6594794**.
- 기존 위치 S: 286적중, 58.73%, ROI −17.46%, 로그손실 0.6631685.
- H: 285적중, 58.52%, ROI −17.97%, 로그손실 0.6606006.
- F: 286적중, 58.73%, ROI −17.47%, 로그손실 0.6606236.
- H_A/F_A: 모두 시장과 같은 316적중, 64.89%, ROI −17.09%. 확률은 약간 달라도 선택은 모두 시장과 같다.
- 별도 기존 전적 대조군: 310적중, 63.66%, ROI −13.17%.

### B: 773경기

- 위치 없는 Q: **499적중, 64.55%, ROI −9.86%, 로그손실 0.6418084**.
- 기존 위치 S: 497적중, 64.29%, ROI −11.09%, 로그손실 0.6429956.
- H: 498적중, 64.42%, ROI −10.27%, 로그손실 0.6420713.
- F: 497적중, 64.29%, ROI −10.42%, 로그손실 0.6421707.
- H_A/F_A: 모두 시장과 같은 547적중, 70.76%, ROI −11.60%.
- 별도 기존 전적 대조군: 537적중, 69.47%, ROI −6.86%.

H는 S보다 B에서 1개 더 적중하고 ROI가 약 0.82%p 나아졌으나 A에서는 더 나빠졌다. Q와 비교하면 두 기간 모두 적중·ROI가 나빠졌다. H의 Q 대비 ROI 차이의 날짜 단위 paired bootstrap 95% 구간은 A [−2.55,+0.31]%p, B [−2.52,+1.40]%p였다. 위치 정보의 안정적인 이득이라는 근거가 없다.

시장 앵커의 β는 H/F 각각 A 약 0.02970/0.03646, B 약 −0.00119/−0.00199다. B에서는 학습기가 추가 공간 신호를 거의 0으로 축소했다. 이것은 이 설정과 자료에서의 추가 정보가 약하다는 근거이며 모든 위치 모델의 가능성을 부정하지 않는다.

전체 1,260경기의 참고 집계도 보존한다: Q 62.46%/−12.59%, H 62.14%/−13.25%, F 62.14%/−13.15%, S 62.14%/−13.55%. 통합 수치로 기간별 실패를 가리지 않는다. 모든 대조군·후보의 Brier·일별 마감 최대 낙폭·정확한 수치는 `independent-model-audit.json` 및 모델 PR 결과에 있다. 자기 경기의 사후 원문 품질로 고른 378경기 하위집합은 주 검증이나 경기 전 선택 기준으로 쓰지 않았다.

## 독립 검산과 재현

부모 작업의 검산기는 모델 워커의 SciPy 합성곱과 최적화 코드를 가져다 실행하지 않는다. 별도 스칼라 수식, 확률생성함수 재귀식, 정규화 로지스틱 기울기 이분법, Decimal 손익 계산으로 대조했다.

- soft 프로필의 야투 210,663개를 원문에서 다시 집계했다. 원문 SHA와 1,185개 ID, 2/3점 시도·성공, 자유투·기회량을 보존했고 최대 구역 집계 차이는 0이었다.
- 학습 1,908행, 평가 1,260행, 고유 특성 키 1,981개를 대조했다.
- 확률 재계산 최대 오차 2.08e−14, 구조 상세 최대 오차 3.45e−15, 예상 득점 최대 오차 5.55e−13.
- β 오차 최대 2.55e−8. 원래 가격·이력·대조군 확률·선택 및 보고된 기간별 지표도 일치했다.

실행 명령과 원천 작업의 커밋·해시는 `provenance.json`에 기록했다. 독립 감사 회귀 테스트 6개, 로컬 전체 테스트 2,761개와 123 subtests가 통과했고 6개는 skip이었다. 전체 테스트 실행 시간은 274.23초다. 원격 CI 상태는 PR에서 별도로 확인한다.

## 이번 결론과 다음 실험의 조건

확인된 것은 시도량과 위치 효과의 혼재, 변경 픽의 순손실, 구조 보존 후에도 남는 약한 추가 정보다. 이번 후보로 교체할 근거는 없다. 같은 구간에서 수치를 계속 맞추기보다는, 실제 경기 전 출전 선수·라인업과 선수별 위치 능력을 연결한 뒤 기회량/위치선택/성공률을 분리하는 다음 가설이 필요하다. 현재 자료만으로 그 가설의 적중률이나 ROI를 지어내지 않는다. 새 자료와 새 검증 기간을 확보하기 전에는 이번 후보를 운영에 승격하지 않는다.
