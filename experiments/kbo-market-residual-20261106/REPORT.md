# KBO M0와 시장 배당을 결합한 모델 비교

접전과 뚜렷한 우세 경기에 다른 혼합 비중을 주는 모델을 구현했다. 두 평가 연도 모두 새 모델과 시장 기준의 선택이 전 경기에서 같았다. 2026년에는 M0 단독이 적중률과 모의 ROI 모두 높았다.

| 평가 | 같은 상품 경기 | 시장 | M0 | 학습형 고정 혼합 | 새 모델 |
| --- | ---: | --- | --- | --- | --- |
| 2025 | 676 | 59.62% / -10.30% | 55.92% / -9.29% | 59.62% / -10.30% | 59.62% / -10.30% |
| 2026 | 354 | 58.76% / -10.29% | 60.73% / -3.96% | 58.76% / -10.29% | 58.76% / -10.29% |

각 칸은 적중률 / 단폴 1단위 모의 ROI다. 2025년은 2024년 714경기, 2026년은 2024~2025년 1,390경기로 가중치를 학습했다. M0 확률은 기존 실제 타순 연구가 해당 평가 시즌보다 앞선 경기들로 적합한 보관 결과다. 모델 구조와 가중치 범위는 PROTOCOL.md에 있다.

2025년 접전·뚜렷한 우세 경기의 끝점 가중치는 각각 0과 0.0437이었다. 픽은 하나도 바뀌지 않았고 로그손실은 시장 0.66398에서 0.66423으로 올랐다. 2026년 두 가중치는 모두 0이었다. M0 단독 대비 새 모델의 ROI 차이는 2025년 -1.01%p, 2026년 -6.33%p였다. 주 단위 짝지은 95% 구간은 각각 [-6.97,+4.88]%p, [-15.08,+2.41]%p로 0을 포함한다. 기존 M0를 이 모델로 교체할 근거는 없다.

2026년 기존 교집합 667경기 중 결과 쪽 상품 ID나 정산 규칙이 비어 있는 313경기를 제외했다. 엄격 가격 자료의 439경기에도 같은 조건을 적용하면 동일한 354경기가 남으므로 별도 검증 표본으로 합산할 수 없다. 평가에 포함된 무승부는 0건이며 과거 자료의 결측과 원본 보관 정책에 따른 선택 편향이 있다. 배당과 명단의 당시 수신이 인증된 전향 평가가 아니며, 픽스터나 운영 동결 추천은 이번 실험의 대조군에 포함하지 않았다.

재현 명령은 저장소 루트에서 실행한다.

```powershell
python -X utf8 experiments/kbo-market-residual-20261106/run.py --output experiments/kbo-market-residual-20261106/results.json
python -m pytest -q experiments/kbo-market-residual-20261106/test_model.py experiments/kbo-m0-followup-20261103/test_study.py
```

입력 원본 해시, 제외 경기 ID, Brier 점수, 월별 손익, 최대 낙폭 및 부트스트랩 구간은 results.json에 저장했다.
