# KBO M0 발전 실험 최종 독립 감사

세 후보의 개발 선택·최종 적합·예측과 통합 예측을 고정 Git 객체에서 검토하고, 이후 고정 정산을 별도 수식과 Decimal로 재계산했다. 학습·평가는 기존에 여러 차례 열람한 후향 자료이며 새로운 블라인드 검증이 아니다. 현재 수집한 공식 타순은 과거 의사결정 전 수신이나 타자 전원의 실제 선발 출전을 증명하지 않는다.

## 선택과 고정

공통 입력은 개발 학습 1,451경기, 2025 검증 731경기, 최종 학습 2,182경기, 2026 실제·예상 명단 평가 각각 709경기다. 개발 단계에 2026 레이블·배당은 포함되지 않았다. 최초에 발견한 선택 함수의 731경기 부분집합 허용 공백은 공통 수정 `c43d386e`·`7f29ae1b`로 차단됐고, 가드 반영 전후 후보 파일은 변하지 않았다.

2025 검증의 가족별 선택은 recency `shrink`, 상대 상호작용 `baseline`, 분포 `negative_binomial_alpha03`이며, 사전 규칙에 따른 전역 주 선택은 recency다. 고정 1/3 앙상블은 선택 후보가 아닌 진단이다. 가족별 개발 선택은 해당 최종 적합보다 먼저 별도 커밋됐다. 전역 선택과 통합 예측은 `627cadca9096acae18a30f72484c342edab7acd3`에서 함께 고정됐으므로 전역 선택이 모든 가족의 최종 적합보다 먼저 별도 커밋됐다고 주장하지 않는다.

recency의 가상 prior·결측과 0 구분·과거 이력, 상대 모델의 훈련 마지막 날짜 기준 365일 가중치와 평균 1 정규화·상호작용, NB 목적함수와 수치 미분·점수 꼬리, 훈련 정답만을 쓴 무승부 절편과 조건부 승패 불변을 검사했다. 기존 M0와 후보 개발·최종 예측은 각각 독립 수식으로 재생했고 차이는 부동소수점 오차 범위였다. 통합 앙상블 1,418건은 3방향 확률을 1/3씩 평균한 뒤 승패 조건부 확률을 계산한 값과 일치했다.

## 2026 결과·동일 가격 정산

최종 정산 `9495a91512d19e80d158a545d21d7311023ac36c`은 예측 `627cadca9096acae18a30f72484c342edab7acd3`의 후손이다. 평가 코드는 예측 Git blob과 SHA, 선택과 입력을 검증한 뒤에만 결과·가격 로더를 호출한다. 잘못된 예측 SHA에서 로더가 호출되지 않는 회귀 검사를 실행했다. 이전 독립 감사에서 동일 레이블의 709경기 점수를 보존된 공식 일정의 완료 점수와 대조해 전부 일치했으며, 레이블 원래의 후향 출처와 현재 공식 응답 대조는 구분한다.

실제 확정 명단 평가의 709경기는 무승부 16경기를 포함한다. 아래 ROI·손익은 동일 확장 가격 원장과 교집합인 667경기의 1단위 가상 정산으로, 무승부 15건은 환급하고 ROI 분모에 포함한다. `적중/709`는 가격 여부와 무관한 전체 결과 표본이므로 가격 표본의 적중 수와 혼동하지 않는다.

| 고정 설정 | 적중/709 | 667경기 순손익 | ROI | 일 마감 최대 낙폭 |
| --- | ---: | ---: | ---: | ---: |
| baseline | 418 | -29.05 | -4.36% | 40.98 |
| 2025 주 선택 recency | 414 | -33.58 | -5.03% | 40.60 |
| 분포 NB 0.3 | 418 | -28.91 | -4.33% | 36.17 |
| 고정 1/3 앙상블 | 421 | -21.46 | -3.22% | 29.74 |

상대 후보는 개발에서 baseline을 선택했고 무승부 진단은 조건부 승패 선택이 변하지 않아 이 둘의 가격 정산은 baseline과 같다. 앙상블−baseline의 667경기 ROI 차이는 +1.14%p, ISO 달력주 paired 재표본 5,000회·시드 20261103의 95% 백분위 구간은 **-2.16~+4.55%p**로 0을 포함한다. 반복적으로 열람한 자료의 여러 후보 비교이며 다중비교 보정은 하지 않았다.

예상 명단을 넣은 보조 평가에서는 709경기 적중이 baseline 392, recency 385, NB 393, 앙상블 390이었다. 같은 667경기 ROI는 각각 -10.83%, -12.26%, -10.84%, -11.29%였다. 따라서 실제 명단 평가의 개선 양상을 예상 명단에서도 일관된 우위로 해석할 수 없다. 2025 주 선택 recency는 2026 결과를 보고 다시 바꾸지 않는다.

엄격 가격 439경기, 현재 구매거절 제외 확장 660·엄격 432경기, 월별 손익과 일 마감 낙폭도 독립 대조했다. 확장 실제 명단의 모든 표기 ROI는 음수다. 이 손익은 과거 고정 가격으로 계산한 가상 정산이며 실제 과거 구매·체결이나 미래 수익을 증명하지 않는다.
