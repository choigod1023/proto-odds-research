상태: 나머지 후보 고정 산출물 감사 중. 공통 계약 `0e8ecbb27f4800481dd8a8630c1388cda4b9e2ba`을 격리 브랜치에 가져와 검사했다. 2026 결과·배당은 공통 입력에 포함되지 않았고 개발 레이블은 2023~2025년에 한정된다. 고정 입력의 SHA와 기존 paired Git 바이트를 대조했으며 분할은 개발 학습 1,451·검증 731, 최종 학습 2,182, 2026 실제·예상 각 709경기다. 과거 실제 수신·타자 실제 출전을 증명하지 않으며 전향 블라인드 자료가 아니다.

기존 M0 actual 모델과 2025 예측 731건을 기존 고정 개발 결과 `0277fa14b2e7ee2f950d683cf0093f9f1b6d788d`와 대조했다. 고정 모델을 다시 적합했을 때 계수·목적함수·학습 전용 선수 사전과 스케일이 일치했고, 독립 예측 공식과 최대 확률 차이는 `3.36e-14` 미만이었다. 2026 기존 M0 모델과 예측 참조도 이전 고정 Git 객체 값과 일치한다. 이 작업에서는 2026 성과를 사용하지 않았다.

## 공통 선택 함수에서 확인한 검증 공백

`common/core.py`의 `choose`는 기준과 후보가 **서로 같은 경기 집합**이고 각 레이블 날짜가 2025년인지 확인하지만, 그 집합이 사전 고정된 검증 731경기 전체인지 확인하지 않는다. 재현한 두 경기 합성 사례에서 전체를 넣으면 후보가 선택되지만 첫 경기만 양쪽에 넣으면 기준 모델이 선택되고 함수가 오류 없이 반환한다. 따라서 누락 경기나 선택적 부분집합이 들어오면 계약의 전체 731경기 선택 규칙을 보장하지 못한다. 이 반례는 공통 API의 방어 공백이며 아직 후보 워커가 실제로 잘못 선택했거나 입력이 누락됐다는 증거는 아니다.

이후 총괄의 공통 수정 `c43d386e`, `7f29ae1b`를 순서대로 반영했다. 고정 731경기 중 하나를 뺀 예측, 후보 간 불일치, 중복·NaN·비정규화·조건부 불일치를 새 함수가 거부하고 전체 731경기는 받아들이는 것을 확인했다. 공통 파일은 별도로 수정하지 않았다.

기준 우선·문자순 동률 처리, 후보 간 서로 다른 경기 집합 거부 및 2026 레이블을 이용한 선택 거부는 합성 검사에서 작동했다. 검토 스크립트 `audit_common.py`와 회귀 검사 `test_review.py`는 `review/`에만 작성했다. recency 후보 고정 산출물의 별도 감사는 아래에 기록했다. 상대·분포 후보와 앙상블·정산은 별도 감사한다.

```text
python -B -X utf8 experiments/kbo-m0-evolution-20261103/review/audit_common.py
python -B -X utf8 -m unittest discover -s experiments/kbo-m0-evolution-20261103/review -p 'test_*.py' -v
```

## recency 후보 고정 산출물

구현 `ff94372a`, 개발 `7cc6b0b4`, 최종 예측 `1110b13e`의 선행 관계와 코드 불변을 확인했다. 네 설정의 2025 개발 예측 2,924건과 두 2026 명단의 최종 예측 1,418건을 독립 수식으로 재생했으며 최대 확률 차이는 `3.52e-14`였다. 새 공통 선택 검사가 고정 731경기 전체와 확률을 수용하고 선택 `shrink`를 재현했다. 개발 1,451경기 및 최종 2,182경기의 학습 전용 스케일·사전과 목적함수·기울기를 대조했다.

타자 prior는 선수당 OBP 0.33·20PA, 투수 prior는 ERA 4.5·27아웃이며 관측 사실이 아닌 가상 prior다. 전부 미관측인 타순은 null을 유지하고, 실제 0 성적은 관측값으로 축소한다. 당일 이력을 거부하고 투수의 불명확한 `BF`를 사용하지 않는 합성 검사도 통과했다. 2026 실제 결과·가격은 읽지 않았다. 전체 검사 결과는 `recency-audit-result.json`이다.
