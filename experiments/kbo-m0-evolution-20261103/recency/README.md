# M0 선수 이력 후보

공통 고정 계약에 따라 2023~24년 1,451경기로 네 후보를 학습하고 2025년 731경기에서 선택했다. 승부가 난 709경기의 적중 수는 shrink 405, ordered_decay30_shrink 403, baseline 393, decay90 392, decay30 390이다. 선택은 승부 결정 적중률 최대, 동률이면 conditional log loss 최소, 완전 동률이면 baseline 우선, 이후 설정 ID 순이다. 선택된 shrink만 2023~25년 2,182경기로 재학습해 2026년 실제/예상 명단 각각 709경기의 예측을 고정했다. 2026년 결과와 가격은 읽지 않았다.

shrink는 선수별 타격 관측에 OBP 0.33과 20 PA, 선발투수 관측에 ERA 4.5와 27 outs의 고정 가정 prior를 사용한다. 관측이 없는 선수가 포함된 라인업에서는 해당 선수의 prior를 더한다. 이는 관측 리그 평균이 아니다. 전체 타격 이력 또는 선발 이력이 없어 기존 값이 null이면 null을 유지한다. decay 후보는 AB/H/BB와 ER/outs에 경기일까지의 달력일 반감기를 적용한다. ordered 후보는 개인별 수축 OBP에 계약의 고정 타순 기대 타석을 적용한다. BF는 쓰지 않는다.

선택 후보 기준 입력 결측: 학습 2,182경기에서 팀 단위 타순 null 10, 선발 null 135, 노출 관측 없는 개별 타자 슬롯 224. 실제 명단 709경기에서 각각 0, 32, 19; 예상 명단 709경기에서 각각 22, 0, 0이다. 타순 null인 팀의 타자 슬롯은 마지막 수치에 포함하지 않는다. 원천 이력과 확정 명단은 회고 자료로, 경기 전 수신이나 각 선수의 실제 출전을 보증하지 않는다. 과거에 이미 결과가 알려진 자료이므로 블라인드 실험이 아니다.

`python -m unittest discover -s experiments/kbo-m0-evolution-20261103/recency -p test_*.py -v`로 단위 테스트를 실행한다. `run.py development`는 개발 산출물을 쓰고, 이를 커밋한 뒤 `run.py final`을 실행한다. 공통 입력 SHA를 검증하며, 예측 및 모델 SHA는 `final/manifest.json`에 있다. 최종 예측은 연구용 고정 산출물일 뿐 운영 채택이나 배포가 아니다.
