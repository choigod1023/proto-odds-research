# M0 상대·불펜 상호작용: 사전 고정 구현

공통 계약 `0e8ecbb27f4800481dd8a8630c1388cda4b9e2ba` 및 `COMMON_API.md`를 따른다. 선수 ID 계수 없이 기존 M0의 훈련 전용 척도·팀 고정효과·결측 표시를 유지한다. 세 상호작용은 훈련 척도의 홈/원정별 z 값으로 계산하고 어느 쪽이 결측이면 0이다. `interaction10`, `interaction100`, `training_decay365`, `training_decay365_interaction100`만 허용한다. 일자 가중은 훈련 마지막 날짜를 기준으로 반감기 365일, 평균 1로 고정한다. 공통 모델 또는 원천 입력을 수정하지 않는다.

`test_candidate.py`는 상호작용과 결측 표시, 훈련 전용 표준화, 가중치, 분석 기울기 유한차분, 타깃 raw 성적 오염을 검증한다. `development.py`는 기존 기준 예측을 재현하고 2025년만으로 네 후보와 기준 중 선택한다. 세 개발 출력의 커밋을 검증한 후 `final.py`가 선택된 후보만 전체 학습하고 2026 실제/예상 두 709행 예측을 저장한다. 2026 라벨·가격과 수익률을 읽지 않는다.
