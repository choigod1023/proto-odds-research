# M0 득점 분포 후보

사전 고정 후보는 NB2 분산 계수 0.1, 0.3과 무승부 허들이다. NB2는 기존 M0의
설계·훈련 구간 정규화·절편 0 및 나머지 계수 L2 10을 유지하면서 로그 연결
`mu=exp(X beta)` 아래 음이항 로그우도 자체를 최적화한다. 분포는 `n=1/alpha`,
`p=1/(1+alpha*mu)`이며 분산은 `mu+alpha*mu²`다. 두 팀 득점은 독립으로 두고
지원 범위를 꼬리 합계 `1e-13` 이하까지 확장한 뒤 승·무·패를 합산한다.
매개변수와 꼬리 계산 기준은 [SciPy 공식 nbinom 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nbinom.html)를 따른다.

허들은 기존 M0를 그대로 학습하고 훈련 경기들의 무승부 확률에 같은 로짓 절편을
더한다. 절편은 보정된 평균이 `(훈련 무승부 수+0.5)/(훈련 경기 수+1)`이 되게
구한다. 이후 `P(H)=(1-d)q(H)`, `P(A)=(1-d)q(A)`를 사용한다. 기존 조건부 승패
확률과 선택은 정확히 같으므로 확률 개선을 수익 개선으로 해석하지 않는다.

코드·설정을 먼저 커밋하고 `run.py development`로 2023–24 학습 및 2025 선택을
기록한 다음 개발 결과를 커밋한다. 그 후 `run.py final`은 커밋된 개발 결과를
확인하고 2023–25 전체로 선택 모형과 사전 선언 허들 진단을 다시 학습해 실제·
예상 명단 각각 709개 예측을 기록한다. 2026 결과와 배당은 읽거나 정산하지 않는다.
이전에도 본 연도이므로 블라인드 테스트가 아니다. `source_bf`를 사용하지 않는다.

검증: `python -m unittest discover -s experiments/kbo-m0-evolution-20261103/distribution -p test_candidate.py -v`.
기울기 유한차분, NB 로그우도 및 주변분포 대조, alpha→0 포아송 회귀 극한,
꼬리질량, 허들 훈련 무승부 평균과 조건부 확률 보존을 확인한다.
