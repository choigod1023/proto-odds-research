# 득점 분포 후보 고정 결과

사전 선언된 2023–24 학습 1,451경기와 2025 검증 731경기에서 공통 선택 규칙을
적용했다. 승패가 난 709경기 기준 순서는 다음과 같다.

| 후보 | 적중 | 승패 조건부 log loss |
| --- | ---: | ---: |
| NB2 alpha 0.3 | 395/709 | 0.6869651469 |
| NB2 alpha 0.1 | 395/709 | 0.6881742347 |
| 기존 M0 | 393/709 | 0.6911346317 |
| 무승부 허들 진단 | 393/709 | 0.6911346317 |

따라서 조건부 정확도가 같은 두 NB2 후보 중 log loss가 작은 alpha 0.3을
선택했다. 허들의 조건부 확률과 선택은 기존 M0와 같으며, 허들은 선정 모형과
별개의 사전 선언 진단이다. 위 수치는 이미 관찰된 과거 구간의 개발 결과이며
블라인드 성능이나 수익 개선을 입증하지 않는다.

개발 선택을 커밋한 뒤 학습 2,182경기로 선택 모형과 허들을 다시 적합해 2026년
실제·예상 명단 시나리오 각각 709개 예측을 고정했다. 2026 결과·배당은 읽지
않았고 정산하지 않았다. 훈련 허들의 보정 평균은 목표 `0.019926706367384334`와
일치했다. 두 시나리오의 최대 NB 꼬리 상계는 각각 `4.9706391004746106e-14`,
`4.6033243279954666e-14`였다. 최종 M0 기준 재현 오차는 0이고 허들의 모든
조건부 승패 확률이 기준과 정확히 같았다. `source_bf`를 변조해도 예측이 같았다.
