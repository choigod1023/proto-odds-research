# M0 병렬 개선: 구현·사전 선택·실제 정산

2026-11-03. M0를 발전시키기 위해 세 모델 워커와 독립 검토 워커를 병렬로 운용했다. 원천을 다시 수집하거나 운영 모델을 바꾸지 않고, 같은 실제 선발·확정 타순 입력에서 11개 변경 후보를 구현했다. 고정 연구 모델과 재현 가능한 코드·예측을 보존한다.

## 결과와 판단

2025년으로 미리 선택한 전역 주 후보는 선수 이력 수축형(shrink)이었지만 2026년 실제 명단 평가에서는 기존 M0보다 나빴다. 따라서 **이 후보로 기존 M0를 자동 교체할 근거는 나오지 않았다.**

사전에 정한 세 후보의 1/3 확률 합성은 실제 명단 평가에서 적중·손실·낙폭이 함께 개선됐다. 그러나 이는 사전 주 후보가 아닌 보조 진단이며, 신뢰구간도 0을 포함하고 예상 명단에서는 악화됐다. 결과를 보고 주 후보를 합성형으로 바꾸거나 새 비중을 탐색하지 않았다. 운영 M0의 유지/교체를 이 실험만으로 확정하지 않는다. 이 M0는 현재 웹 투표 정책과 별개의 연구 기준 모델이다.

## 고정 입력과 대조군

- 원래 입력: 58556de08c64604276de8682373d3ccc8d535d7c의 실제 명단 2,182경기(2023=723/2024=728/2025=731), 2026 실제/예상 각709경기. 2025년 타순 미확정5경기는 모든 후보에서 같은 방식으로 제외했다.
- M0는 팀·상대 효과, 팀 성적·휴식·구장·타순·상대 선발·불펜 수치를 사용한 독립 Poisson 모델이며 절편 패널티0/나머지 L2=10이다. 학습의 평균·척도는 학습 구간에서만 산출했다.
- 2023~24년1,451경기로 학습→2025년731경기로 후보를 선택했다. 승부 결정709경기에서 적중률 최대, 동률이면 조건부 로그손실 최소, 완전 동률이면 baseline 우선, 그 뒤 설정 ID 순이다. ROI로 후보를 선택하지 않았다.
- 선택 후2023~25년2,182경기로 재학습→2026-03-28~10-27의 실제 명단709경기를 주 평가로, 같은709경기 예상 명단을 보조 평가로 사용했다. 7일 경계 간격을 유지했다.
- 기존 M0 개발/최종 재학습의 계수와 예측이 앞선 고정 M0와 정확히 일치함을 확인했다. 기존 M0의 성적을 새 후보의 개선처럼 보고하지 않았다.

공통 데이터에는 개발 결과만 있다. 2026 레이블과 가격 원장은 통합 예측 동결 후 정산 콜백에서만 읽었다. 이 연도들은 이미 과거 연구에서 본 자료이므로 블라인드 검증이 아니다. 공식 타순의 사후 복원은 경기 전 수신 시각·타자 전원의 실제 출전을 증명하지 않는다. 현재 공식 점수와709레이블의 일치는 이전 독립 감사에서 확인한 동일 원장을 재사용했다.

## 실제 구현한 변경

### 1. 선수 성적·타순 (4후보)

- decay30/decay90: 최근10개 유효 관측의 AB/H/BB와 ER/outs에 같은 달력일 반감기를 적용한다. 행별 비율을 단순 평균하지 않고 노출 분자·분모를 함께 가중한다.
- shrink: 타자마다20PA·OBP0.33, 투수에는27outs·ERA4.5의 고정 가정 prior를 더해 작은 표본의 극단값을 줄인다. 라인업은 prior가 더해진 분자·분모를 풀링한다.
- ordered_decay30_shrink: 선수별 수축 OBP를 타순 기대 타석 가중4.7~3.9/4.3으로 합성하고 투수에도30일 감쇠·수축을 적용한다.

여기서 OBP는 정식 출루율 전체가 아니라 (H+BB)/(AB+BB) 대용치다. HBP·희생플라이를 포함한 정식 출루율이나 OPS를 계산했다고 주장하지 않는다. prior는 관측한 KBO 평균이 아니라 사전 고정한 가정이다. 개인 관측이 없으면 prior 추정임을 표시하며 라인업 또는 선발 수치 전체가 null이면 원래 null 표시를 남긴다. BF를 타자 수로 쓰거나 결측을0으로 채우지 않는다.

### 2. 상대·불펜 상호작용 (4후보)

훈련 척도로 표준화한 자기 타순×상대 선발, 상대 선발×상대 불펜, 자기 휴식×상대 불펜의 세 곱을 추가했다. 추가열 패널티10/100, 별도365일 훈련 표본 감쇠, 감쇠+패널티100 상호작용의 네 구성을 비교했다. 표본 감쇠는 훈련 마지막 날짜를 기준으로 계산하고 평균1로 정규화해 패널티 크기를 유지한다. 결측 곱은0이되 기존 결측 플래그는 유지한다.

### 3. 득점 분산·최종 무승부 (3후보)

NB2 분산 Var(Y)=mu+alpha*mu²에서 alpha0.1/0.3의 두 후보는 분포만 바꾸지 않고 로그우도로 M0 평균 계수를 실제 재학습했다. 기존 척도·설계·패널티는 그대로다. n=1/alpha,p=1/(1+alpha*mu)를 사용하고 꼬리질량1e-13 이하까지 확장했다. [SciPy 공식 nbinom 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nbinom.html)의 매개변수와 대조하고 유한차분 기울기 및 Poisson 극한을 검사했다.

무승부 허들은 원래 M0의 조건부 승패 확률을 보존하면서 훈련 레이블만으로 무승부 로짓 절편을 맞춘다. 목표 평균은 (훈련 무승부 수+0.5)/(n+1)이다. 이 진단은 승패 선택과 ROI가 원래 M0와 같아야 하며 확률 개선을 이익 개선으로 부르지 않는다.
