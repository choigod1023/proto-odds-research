This is retrospective research on previously inspected datasets, not a pristine holdout. Scope is this sidecar only. No production model, DB, stake selection, deployment, push or PR.

## Chronology, model and finite candidates
- Training = accepted 2024 rows (expected296). Validation = accepted2025 validation rows (expected300), excluding every evaluation gamePk; log overlap count/IDs. Evaluation2025 uses2024 fit only. Evaluation2026 uses refit2024+eligible2025, excluding all evaluation/external gamePk. Check disjoint IDs and training years < evaluation year.
- No validation prices exist: select on pure-model proper scoring/hit only, never ROI. Validation score uses all valid games without prices. Intercept/home bias learned from training.
- EB prior-season player rates shrink to that prior season's PA/BF-weighted league means: batting150 PA, pitching300 BF; xwOBA/xSLG and xERA use Savant PA with the same constants. Current replay K/BB, OBP/SLG and ERA are optional past-only rates, shrunk with150 PA/100 BF/30 IP toward the player's EB previous-season estimates. Missing flags for no prior player, no current sample, no Savant.
- Ordered lineup exposure weights fixed [1.12,1.09,1.06,1.03,1,.97,.94,.91,.88], normalized. Aggregate actual nine players; also top3, bottom3, weighted spread and weak-batter share (xwOBA<.300). Starter features xwOBA allowed, xERA, K%,BB%,K-BB%, current ERA and sample reliability; opponent lineup×starter interactions.
- Exactly12 candidates + fixed baselines: family linear / matchup / hinge crossed with L2 lambda [.01,.1,1,10]. Logistic objective mean logloss + lambda/2 * sum(nonintercept beta^2), train-only z scaling, clipped z [-6,6]. linear uses signed home-away lineup and starter differences and missingness/reliability differences. matchup adds signed lineup×opponent pitcher products (centered xwOBA, K/BB mismatch, slugging×xwOBA allowed), top/bottom/dispersion matchup and tanh fixed advantage. hinge adds fixed positive/negative-part squares of each standardized linear feature, plus matchup terms. No learned trees, no new sklearn dependency. Numpy Newton optimizer, deterministic.
- PRIMARY = minimum validation logloss, then Brier, then candidate name. HIT = maximum validation correct count, then logloss, then name. Freeze selected names/model coefficients and save validation probabilities before computing evaluation metrics. Do not reselect after evaluation.
- Evaluate baseline, primary and hit heads; fixed auxiliary blend baseline90%+selected pure10% shown separately, never a replacement head. Baseline = archived market-only on external230 and research market90_vote10 on old116; report old116 market-only as separate reference. None is a replay of the operating model. All12 evaluation probabilities retained for diagnostics, no evaluation winner declared.
