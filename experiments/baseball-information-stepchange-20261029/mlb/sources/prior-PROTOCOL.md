# 경기 전 선발·타순 보강 비교 — 실행 규칙

- 이전 #405 공통 평가434경기를 출발점으로 삼되, 경기 전 증거가 없는 경기는 보강 모형 성과에 포함하지 않는다. 해당 공통 부분집합에서 시장·고정 시장90:투표10·보강 모형·고정9:1의90%+보강10%를 비교한다. 평가 집합 자체는 이미 여러 번 살펴본 회고 표본이다.
- MLB 공식 feed/live의 경기 예정 시각 10분 전 timecode를 조회한다. 반환 metaData.timeStamp가 요청 시각 이하이고 경기 시작 전이어야 한다. scheduled/warmup 상태, 실제 투구 없음, 양 팀 probablePitchers ID와 중복 없는9인 타순을 모두 요구한다. 단순 최종 박스스코어의 선발·타순을 당일 입력으로 쓰지 않는다.
- MLB 2024·2025년 각각9월30일까지 결과를 보지 않고 시간순으로300경기를 균등 추출해 수집한다. 2024로 적합, 2025로 후보 선택한다. 2025-11-01 평가에는2024 계수, 2026 평가에는2024+2025 재적합 계수를 쓴다. 원래 평가116경기 중 수집 실패·시점 부적합은 사유와 함께 제외하고 동일 표본의9:1을 다시 계산한다.
- 후보9개: announced starter(실제 선발의 경기 전 개인 ERA·진짜 BF 기준 K−BB) / +announced lineup(선발9인의 출루율·장타율) / +Statcast(이전 완료 연도 타자 xwOBA, 투수 피허용 xwOBA·xERA), 각각 ridge0.1/1/10의 logistic 모형. 학습 통계로만 표준화한다. 모형은 적중률 최대→동률 Brier 최소→이름 순으로2025에서 선택한다. 평가 ROI로 후보·임계값을 바꾸지 않는다.
- 당일 seasonStats는 공식 과거 timecode 응답의 선수 기록만 사용한다. Statcast는 평가연도−1의 완료 시즌 자료만 사용한다(2024입력은2023,2025는2024,2026은2025). 현재연도 최종 리더보드로 과거를 예측하지 않는다. 후일 정정 가능성은 남아 있으므로 당시 직접 보존한 불변 원본이라고 부르지 않는다.
- NPB2023 공식 박스스코어로 누락된 과거 선발·BF·투구 지표를 복원한다. 이는 **경기 후 학습 이력**이다. 발표 시각 증거를 갖춘 현재 경기 입력과 구분한다. 과거 결과표로 경기 전 발표를 인증하지 않는다.
- KBO/NPB 보존 발표 로그는 실제 observed_at<시작 시각을 확인하고 변경 로그도 함께 조사한다. 시각이 있는 원보도에서 발표된 선발·9인 타순도 수집하되, 최종 수정 시각이 경기 후이면 제외한다. 두 팀 타순·개인 기록의 시점이 모두 검증된 표본이 없으면 전체 입력 비교는 미완료로 보고하고 다른 결과로 대체하지 않는다.
- 단폴 동일금액·전 공통 경기·월 손실 제한 없이 회고 ROI를 계산한다. 운영 모형·자금 정책·DB·배포는 변경하지 않는다. 원문 해시·URL·반환시각·배제사유와 경기별 계산을 보존한다.
