# KBO 자료 원천 조사와 불펜 대체 가용성 가설

공식 보존 원문과 공개 보조 사이트의 선수·경기 한 건을 실제로 연결했다. MyKBO Stats 선수 `1990`은 자체 선수 페이지의 공식 프로필 링크가 가리키는 KBO ID `50030`이며, 2026-10-12 KT 원정·삼성 홈 경기는 MyKBO `14037`, 보존 공식 ID `20261012KTSS02026`으로 날짜·팀·홈/원정·선수 정보가 맞는다. 두 박스에서 해당 투수의 투구수는 **84구**, 이닝 6, 탈삼진 8이다. 보조 경기 상세에는 KT 투수 4행·삼성 7행이 있다. 이는 한 경기의 원문 연결 검증으로, 이 선수가 같은 식별자라는 것을 다른 시즌·경기의 자동 매핑에 일반화하지 않는다.

## 실제 조사한 원천

- [KBO 공식 원본](https://www.koreabaseball.com/robots.txt): 2026-11-08 07:40 UTC에 받은 `robots.txt`는 사전 승인 없는 자동 수집·복제 금지 및 `User-agent: * / Disallow: /`를 명시한다. 따라서 새 공식 경기 API 자동 호출을 하지 않았다. 기존 보존 원문에서는 일정 POST `/ws/Main.asmx/GetKboGameList`의 `date=YYYYMMDD`, `leId=1`, `srId`와 박스 POST `/ws/Schedule.asmx/GetBoxScore`의 `gameId`, `seasonId`, `leId`, `srId`를 확인했다. 이는 보존된 기존 접근 방식의 기록이지 신규 자동 수집 허가가 아니다. 공식 일정에는 `G_ID`, 날짜·팀 ID·홈/원정·선발 ID, 박스에는 투수명·등판 구분·이닝·투구수·실점·삼진 등이 있다. 원문에 모든 투수 행의 공식 ID가 직접 있지는 않아 저장된 공식 선수검색·식별 근거를 재생해야 한다.

- [MyKBO Stats 경기 14037](https://mykbostats.com/games/14037): 같은 날 07:39:59 UTC 수신 HTTP 200, SHA `38c3eb0806dd4476d39d8d6a2d37c441c1cb19df85469b23e88aeba9f2ecf413`. 실제 경기 ID·날짜·팀, 타순 결과·선수 링크와 투수별 이닝·투구수·피안타·홈런·삼진 등을 확인했다. 선수 상세의 경기 로그에선 이 경기 `NP`가 빈 값인 반면 경기 상세에는 84로 표시된다. 사이트 자체 경기 ID와 KBO ID는 다르므로 공식 링크와 경기·팀·날짜를 대조한다. 이 자료도 경기 후 페이지다.
- [MyKBO robots](https://mykbostats.com/robots.txt)는 조사한 두 공개 경로를 허용하고 5초 crawl-delay를 표기했다. 요청은 5초 이상 간격으로 제한했으며, robots 허용이나 HTTP 200을 데이터의 자유 재배포·장기 안정성 허가로 취급하지 않는다. 이 사이트는 비공식 팬 사이트라고 명시한다. 수신 영수증에는 본문 완료 시각을 로컬 시계 기준으로 기록했으며 독립 시각 인증은 아니다.

## 사전 고정한 새로운 모델 가설 — 적합하지 않음

[사전 규약](PROTOCOL.md)은 결과를 열람하기 전 커밋 `7114016a`에 고정했다(논문 저자명 정정 `5b05a925`). 선발 예상 조기 교체량과 **실제 사전 명단으로 확인된 대체 불펜의 직전 부하**를 곱해 팀 간 차이 하나를 만든다. 이 변수를 `logit(P_home) = logit(P_home_M0) + β × (S_away B_away − S_home B_home)`에 강하게 수축해 더하는 후보다. 선발 휴식 단독인 PR #658이나 이전 상위 3명 불펜 부하 연구와 달리, 선발이 맡지 못할 것으로 예상되는 아웃과 이용 가능한 구원 대체자들의 상태가 상호작용한다는 가설이다. 시장이 이미 알고 있는 정보를 초과하는지는 검증 대상이지 전제가 아니다.

[Bradbury·Forman의 MLB 선발 연구](https://pubmed.ncbi.nlm.nih.gov/22344048/)는 과거 부하와 다음 성적의 작은 연관을 보고했고, [Burris·Coleman의 MLB 구원투수 연구](https://www.degruyterbrill.com/de/document/doi/10.1515/jqas-2018-0007/html)는 투구량과 이후 구속 감소의 관계를 모델링했다. 두 연구가 KBO 경기 결과나 ROI를 증명하는 것은 아니다. 기존 xFIP 실험의 미래 리그 평균 누수 지적을 확인했으며 현재 가설에 FIP/xFIP를 재사용하지 않는다. PR #656·#657은 배구·KBL 분포 연구, #659는 1픽 선택 규칙 비교로 구분했다.

**학습·평가는 하지 않았다.** 이번 실제 교차 연결은 1경기·1선수이나 당시 수신된 구원투수 가용 명단, 부상·제외 여부, 전원 선수 ID와 D-1까지 완전한 등판·투구수, 같은 시점 M0·완전 배당·공식 결과를 함께 보유한 표본은 이 조사 범위에서 0건이다. 전체 데이터베이스의 0이라는 뜻은 아니다. 보조 사이트 현재 페이지와 과거 최종 엔트리는 경기 전 가용 명단이 아니다. 따라서 2025 학습·검증, 2026 평가, 적중률·ROI·LL·Brier·coverage·paired CI는 모두 **미산출**이다. 새로운 예측·정책 변경도 없다.

다음에는 KBO의 자동 수집에 필요한 사전 승인 또는 이용 가능한 허가된 제공 경로와, 경기 전 시각이 보존된 실제 엔트리·선수 제외·발표 선발 원문을 확보해야 한다. 이후에야 동일 선수 ID의 이전 완료 경기 투구수와 미정산/연장·무승부 규칙, 동시점 가격 및 M0를 연결할 수 있다.
