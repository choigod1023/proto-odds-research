# KBO 동결 예측의 공식 회차 배당 복원 진단

2026년 KBO 동결 예측 726경기에 원래 기록 배당과 공식 회차에서 복원한 배당을 연결했다. **원본 경기 시각까지 대조한 439경기**에서는 선수 모델이 245/429 적중, 가정 ROI -9.78%, 시장이 250/429 적중, -10.67%였다. **원본 시각이 없는 날짜·팀·점수 일치 경기까지 포함한 683경기**에서는 선수 모델이 380/667 적중, -9.91%, 시장은 398/667 적중, -8.59%였다. 적중률 분모는 무승부 환급을 제외하고 ROI 분모는 환급 원금을 포함한다.

공식 회차 자료가 원배당 필드를 보존한다는 것과 **당시 T-30에 그 가격을 실제 관측하거나 체결할 수 있었다는 것은 다르다.** 실제 사전 수신·체결이 검증된 가격은 0건이고 검증 ROI는 미산출이다. 선수 구성은 이전 경기로 추정한 시나리오이며 실제 확정 명단이 아니다. 저장 점수도 독립 공식 결과로 인증되지 않았다. 이번 진단과 2026년 자료는 이미 살펴본 자료로, 블라인드 운영 성과가 아니다.

## 입력과 보존 범위

모델·선택 규칙은 바꾸지 않았다. 기존 2026 예측 SHA256 `d841cd9549a9dab4f3c9612e2fbdea84b9f914b390da4f9c80c0d9e2b3e5d317`과 기존 phase2 결과 SHA256 `8c8776c43dc0013056026c83c3b5afaf2d462a7de3e346438b2e71e536408562`을 재검증했다. 보완 비교 규칙 `b9b4a88a`, overlay 코드·테스트 `1de3d926`를 새 계산 전에 고정했다. 계산 뒤 공식 회차 목록과 evidence manifest의 커밋 일치·해시 검사 `28ee50d4` 및 원본 시장 ID 누락 차단 `8795652b`를 보강하고 다시 실행해 결과 바이트가 동일함을 확인했다. 부모 데이터 워커의 `9bcbd53bf95ce6c6961b5b88fd43877152d602b6`와 `restored-prices.jsonl` 원본 SHA256 `d9fc2f04fabec1fa41d29521aeafdb96e676747e59723396f36ba5c88a9b8117`을 검증했다. 원래 rows·labels SHA도 이전 값과 일치했다.

2023~26년 가격 누락 454경기 중 공식 자료로 373건을 연결했고 그중 무승부가 56건이다. 373건 중 249건은 기존 원본 경기 시각이 없어 공식 시각과 맞춰볼 수 없었다. 공식 응답의 날짜·정방향 팀·결과 점수·일반 승패 상품·유일 후보를 확인했으나, **결과 점수를 결합 조건으로 사용한 선택 편향**이 남는다. 공식 원문 각 응답 SHA와 실제 2026-11-03 수신 시각을 보존했고 과거 수신시각은 null이다.

기존 기록 배당 354경기는 원래 출처로 유지하고 공식 복원 배당은 별도 회차·경기번호·원문 해시로 보존한다. 기존 354경기 선수·팀 등 6개 모델과 시장의 확률·픽·정산이 phase2와 같음을 독립 재계산으로 확인했다. 354경기 성과를 전체 2026년 모델 우세로 소개하지 않는다.

## 두 가지 고정 표본

|---|---:|---:|

| 원본 경기 시각 없는 공식 복원 | 0 | 244 |

시각 대조 표본의 원래 354개 가격은 기존 데이터 워커의 경기시각·팀·결과 결합을 물려받았고, 복원 85개는 원본 경기시각과 공식 회차 시각이 일치했다. 확장 244개는 원본 경기시각이 없어 같은 날짜·정방향 팀·점수·유일 후보만 확인했다. 날짜만으로 더블헤더가 모호하거나 상품·가격·상태·점수가 맞지 않는 경우를 넣지 않았다. 이 구분 자체는 실제 사전 가격 증명이 아니다.

726경기 중 43경기는 여전히 미연결이다. 기존 배당이 없는 경기의 공식 회차 후보를 별도로 감사한 결과, 27경기는 발매기간 기준 후보 회차가 없었고 16경기는 해당 경기의 판매 거부가 표시됐다. 이는 2026년 표본만의 점검이다. 별도로 전체 2023~26 복원 대상에서 데이터 워커가 보고한 제외 81건은 회차 후보 없음 47, 유효 일치 없음 34다. 상품 불일치·0 또는 1 배당·시각/점수 충돌·원본 시각 없는 동일 날짜 중복은 계산기의 차단 조건이며, 상세 [제외 감사](phase3/exclusion-audit.json)의 표식은 중복될 수 있다.

ROI 차이 구간은 각각 **-9.02~+11.06%p**, **-10.19~+7.38%p**다. 모든 구간이 0을 포함하며 실제 사용 가능성·표본 편향까지 해결하지 않는다. 선수 모델은 두 표본 모두 시장보다 로그손실과 Brier가 높았다.

선수 모델의 일 마감 최대 낙폭은 시각 대조 51.77단위, 확장 76.53단위다. 확장 표본의 월별 단위 손익은 3월 -4.42, 4월 -4.88, 5월 -6.29, 6월 -2.62, 7월 -25.19, 8월 -4.00, 9월 -3.95, 10월 -16.36이다. 이는 고정 단위 가상 계산이며 월 5만원 제한이나 미정산 노출을 반영한 지갑 재생이 아니다.

## 복원 가격만 따로 본 참고 결과

출처별로 분리하면 공식 복원 329경기에는 무승부 환급 16건이 포함된다. 이 중 확장 표본의 선수 모델은 168/313 적중, 가정 ROI -15.05%, 시장은 190/313 적중, -6.77%였다. 선수-시장 적중률 차이의 95% 구간은 -15.60~+0.85%p다. 원본 경기시각까지 일치한 복원 85경기만 보면 환급 10건을 제외해 선수 33/75, 시장 42/75 적중이며 ROI는 각각 -29.11%, -12.24%다. 원본 354경기와 복원군은 누락 사유·시기·무승부 구성이 달라 서로 독립된 무작위 표본이 아니다. 무환급 2026-03~06 기존 가격만 본 결과와 대비해 해석해야 한다. [출처별 상세](phase3/source-strata.json)에 모든 모델과 월별 결과를 남겼다.

## 정정과 검증

원래 `phase2/results.json`의 `comparison_note`에서 가정 가격 시나리오를 ‘independently evidenced historical price timing’으로 표현한 부분은 잘못됐다. 과거 수신시각과 실제 체결은 증명되지 않았다. 원본 파일은 보존하고 이번 결과의 erratum으로 바로잡는다. 픽스터·현행 동결 운영 선택·9:1, 공식 확정 선수 명단은 연결하지 않았으므로 비교하지 않았다.

[상세 결과와 원천별 경기 원장](phase3/overlay-results.json), [독립 검산](phase3/verification.json), [제외 감사](phase3/exclusion-audit.json)를 참조한다. 독립 Brent 알고리즘과 Decimal 계산으로 두 표본의 7,854건 정산을 재생해 최대 확률 차이 4.81e-13으로 일치했고, 기존 354경기는 6개 모델과 시장에서 유지됐다. 가격·상품·점수·원본 시각 불일치, 날짜만 있는 더블헤더, 중복 후보, 무승부 환급 및 예측 불변 회귀 검사도 실행했다.

```text
python -X utf8 experiments/kbo-player-model-20261103/phase3_overlay.py --output 새_결과_경로.json
python -X utf8 experiments/kbo-player-model-20261103/verify_phase3.py
python -X utf8 experiments/kbo-player-model-20261103/phase3_source_strata.py
python -m pytest -q tests/test_kbo_price_overlay_20261103.py tests/test_kbo_player_model_20261103.py tests/test_devig.py tests/test_market_residual_experiment.py
```

계산기는 덮어쓰지 않으므로 새 경로를 지정한다. 별도 독립 검토 전이며 운영·원장·모델·월 손실 5만원 규칙은 변경하지 않았다.

전체 Python 테스트는 2,265개 통과·6개 건너뜀·93개 하위 테스트 통과였다. 전체 테스트 수집 뒤 추가한 공식 목록 변조 차단 검사는 최종 관련 테스트 42개로 별도 통과했다.
