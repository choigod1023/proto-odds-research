# KBO 이전 경기 기반 선수 구성의 회고 진단

작성일 2026-11-03. **선수 포함 모델은 2026년 기록 가격이 남은 354경기에서 212경기를 맞혔고, 같은 경기의 시장 기준은 208경기를 맞혔다.** 단위 베팅 가정 ROI는 각각 -5.14%, -10.29%였다. 두 자료 모두 과거 관측·실행 가능성이 입증되지 않았고, 354경기에 무승부가 하나도 없어 선택 편향이 있다. 이 차이는 실전·운영 우세의 증거가 아니다.

## 입력과 고정 절차

데이터 PR #511 `b0833a6`의 2023~2026 KBO 2,913경기. 훈련 2023~24년 1,451경기, 검증 2025년 736경기, 이후 진단 2026-03-28~10-27 726경기. 2026 자료는 과거 연구에서 이미 본 기간이다. raw rows/labels 및 prior-projected SHA는 [사전 등록](integration-protocol.md)에 기록했다. 파생 features와 2023~25 라벨, 모델·실행기는 실제 훈련 전에 `5cb48043`으로 고정했다. 2026 라벨을 정산에 쓰기 전 726경기 예측을 `9b920679`에 고정했고 예측 SHA256은 `d841cd9549a9dab4f3c9612e2fbdea84b9f914b390da4f9c80c0d9e2b3e5d317`이다.

이전 날짜 팀 타순과 최근 5명의 선발 순환으로 추정한 선수 구성만 사용했다. 이는 실제 사전 발표 명단이 아니다. 홈·원정 득점은 독립 Poisson 회귀로 추정하고 같은 구조의 팀 모델과 선발·타순·불펜 제거 실험을 비교했다. 사용한 과거 라벨은 공식적으로 독립 인증되지 않은 저장 점수다. 2025 득점 로그손실 기준 L2 {1,10,100} 중 모든 모드가 100을 선택했다. 같은 날짜 이력은 배제하고 이전 달력 날짜 경기는 끝났다고 가정했다. 실제 종료·수신 시각은 null로 보존했다.

## 2026년 회고 결과

전체 726경기의 선수 포함 모델 3-way 로그손실은 0.85020, Brier는 0.53037이다. 같은 726경기에서 팀 대조는 0.84899, 0.52967이다. 선수 모델의 Pearson 점수 잔차 분산 지표는 2.45, 홈·원정 잔차 상관은 -0.025다. 독립 Poisson 가정에서 과분산을 의심할 근거이며 별도의 분포 검증이 필요하다. 이 3-way 확률 지표는 아래 2-way 시장의 조건부 로그손실과 직접 비교하지 않는다.

실제 사전 가격 관측과 체결을 입증한 경기는 **0/726**이므로 검증 가격 ROI는 미산출이다. 원본 기록 가격을 당시 이용할 수 있었다고 가정한 `archived_price_scenario`는 2026-03-28~06-30의 354/726경기다. 각 모델은 같은 경기·가격, 확률 최댓값과 동률 홈 우선, 단위금액 단폴을 사용한다. 무승부는 원금 환급 규칙이나 이 가격 부분집합에는 무승부가 0건이다.

이는 사전 고정된 제거 실험 결과이지 이후 진단 점수를 보고 채택한 모델이 아니다. 선수 전체와 시장은 88경기에서 선택이 달랐다. 14개 관측 주를 5,000회 재표집한 선수-시장 적중률 차이의 95% 구간은 **-5.04~+7.52%p**, ROI 차이는 **-5.80~+16.83%p**다. 선수-팀의 적중률 차이 구간은 **-1.81~+3.93%p**다. 모두 0을 포함하며, 반복 열람 및 선택된 표본의 편향이 남는다.

선수 전체의 단위 손익은 -18.21, 월별은 3월 -4.42, 4월 -4.88, 5월 -6.29, 6월 -2.62단위다. 무승부를 포함한 전체 2026년 726경기 중 무승부 17경기에는 모두 기록 가격이 없다. 전체 2023~26년 무승부 60경기도 모두 가격이 없다. 354경기 외 372경기는 가격 시나리오에서 제외됐다. 따라서 ROI 분모에서 무승부가 빠진 것은 전략의 환불 성과가 아니다.

2026 진단의 예상 타순 지표는 홈·원정 각각 475/726경기에 있고 불펜 proxy는 홈 459, 원정 457경기에 있다. 구장 수치 지표는 전부 결측이며, 시작 시간이 없는 경기 256개는 null 그대로다. 불펜 아웃은 최근 두 **달력 날짜** 자료이며 24/48시간 실제 투구 수가 아니다. 동일 경기의 원본 target 선수 ID는 주 분석에 사용하지 않았다. 점수·팀·선수 ID, 실제 명단 발표, 가격 수신/체결 및 정산 규칙도 독립 인증되지 않았다.

## 검증과 산출물

[결과와 경기별 정산](phase2/results.json), [독립 검산](phase2/verification.json), [입력 인계](handoff.json)를 참조한다. 독립 스칼라 코드가 예측 726개와 각 모드·시장 4,248건의 Decimal 정산을 재생했고 최대 확률 차이는 3.66e-13이다. 2026년 라벨 726개를 변조해 점수화해도 고정 예측 객체가 바뀌지 않았다. strict 시점 검증, 같은 날·미래 이력, 타깃 ID 유입, 원천 가정과 검증 ROI 분리, 2-way 환불을 합성 회귀 테스트로 확인했다.

픽스터·현행 운영 동결픽·9:1은 연결된 입력이 없어 비교하지 않았다. 월 손실 5만원 한도와 미정산 노출을 포함한 지갑 재생은 구현하지 않았다. 위 숫자는 균등 단위 시나리오이며 실제 모의 지갑 손익이나 운영 추천이 아니다. 명단·수신시각과 분포 가정의 독립 검증이 끝나기 전 채택·배포하지 않는다.

원래 예측 실행 시 코드 해시는 Windows CRLF 원본 바이트다. 독립 검산기는 학습 전 커밋 `5cb48043`에서 해당 바이트를 복원해 해시를 검증한다. 다른 줄바꿈 환경에서 실행기를 그대로 다시 돌리면 해시 불일치로 안전하게 중단되므로 동일 코드 바이트를 복원해야 한다. 모델 확률이나 규제를 재선정해서는 안 된다.

전체 Python 테스트는 2,261개 통과·6개 건너뜀·93개 하위 테스트 통과였다. 전체 수집 후 추가한 가정 가격 opt-in 검사는 최종 관련 테스트 37개에 포함해 별도 통과했다.
