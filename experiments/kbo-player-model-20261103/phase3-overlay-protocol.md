계산 전 등록. 기존 모델·규제·특징·이전 예측·기존 결과는 변경하지 않는다. phase2 예측 SHA256 `d841cd9549a9dab4f3c9612e2fbdea84b9f914b390da4f9c80c0d9e2b3e5d317`, feature gzip `346edd84d4388f99cc9ad23f7ad530560445b4bc06b6f841b745dabffa1a8b42`, test labels gzip `885b5dc0d182fa91d29ea4d74a078fb8835acf817095604106564864d0e19dc9`, 학습·예측 코드 커밋 `5cb48043`, 예측 고정 `9b920679`. 공식 가격 PR #511과 별개인 데이터 워커 커밋 `9bcbd53bf95ce6c6961b5b88fd43877152d602b6`, overlay SHA `d9fc2f04fabec1fa41d29521aeafdb96e676747e59723396f36ba5c88a9b8117`, 원본 rows `66433dd4706e602befd75f8084ee43eb2e84a54b2657438c37733e3d80531c8c`, labels `ef32ffe806b41521f5bd53c12d0eea1362bd44293181fc3ebb7c24c6fcb249ca`를 검증한다. 모델은 재학습하지 않는다.

대상은 동결된 2026년 KBO 예측 726경기다. 원래 비어 있는 시장에만 소급 공식 회차 가격을 별도 ID·원본 응답 해시와 함께 붙인다. 기존 원자료와 phase2 결과를 덮어쓰지 않는다. 원래 354개 가격도 출처를 `original_archived`로 따로 기록하며 소급 복원은 `official_restored`로 구분한다. 정확히 같은 경기 ID·홈/원정 순서·상품·최종 점수가 맞고 명확히 유일한 가격만 사용한다. 성과를 보고 경기를 추가·삭제하거나 모델/파라미터/선택 규칙을 바꾸지 않는다.

사전 정의된 두 표본을 독립 보고한다. `strict_original_time_match`는 기존 2-way 가격의 원본 경기 시각이 있는 행과, 공식 복원 가격 중 원본·공식 시각이 모두 있고 정확히 일치한 행을 포함한다. `extended_day_team_source_confirmed`는 위에 원본 경기 시각은 없지만 복원 자료에서 명시한 날짜·정방향 팀·점수가 일치하고 중복 경기가 없으며 공식 후보가 유일한 행을 더한다. 누락·모호·더블헤더 식별 불가·배당 비정상·취소/판매 거부·점수 불일치 등 제외 사유를 남긴다. 원천의 공식 선수/팀과 결과 인증 범위는 가격 워커의 응답·매칭 감사에 의존하며 추가 독립 검토가 필요하다. 결과 일치를 결합에 사용한 선택 편향을 기록한다.

양쪽 공통 표본에서 기존 동결 모델 6개 및 같은 가격의 Shin 시장 2-way 기준을 계산한다. 선택은 조건부 홈·원정 확률 최댓값이며 동률 홈. 무승부는 원금 환급, ROI 분모에 원금을 포함하고 적중률·2-way logloss/Brier 분모에서는 제외한다. 가격이 없는 경기에 환급을 만들어 넣지 않는다. 각 표본의 전체 기회·연결·무효·적중·가상 ROI, logloss/Brier, 월별·일 마감 낙폭, 원천 유형별 건수, 시장 및 팀과 다른 선택, 주 단위 5,000회(seed 20261103) 쌍체 차이구간을 저장한다. 엄격 표본은 출처 시각의 대조 수준을 뜻하고 가격의 실제 T-30 수신·체결 증명이 아니다. 별도의 verified-execution 표본과 ROI는 계속 0/미산출이다.

기록 시점은 공식 응답의 2026-11-03 실제 수신시각 그대로이고 과거 `source_observed_at=null`, `execution_price_verified=false`를 유지한다. 데이터 워커의 제외 81건(회차 후보 없음 47·유일 일치 미확인 34)은 전체 2023~26 복원 대상 454건의 사유이며 2026 실험 분모와 혼동하지 않는다. score/팀/시간/배당 충돌·중복은 overlay에서 다시 차단·집계한다. 현재 픽스터/운영/9:1과 공식 확정 선수 명단은 연결하지 않으며 월 손실 5만원 지갑 재생도 하지 않는다.

추가 계산은 이 파일 커밋 후 독립된 overlay 스크립트에서만 실행한다. 독립 Decimal 재계산과 합성 시간 미상·중복·스코어 불일치·상품 오류·환불·가격 변화 비침투 테스트를 실행하고 파일 해시와 명령을 남긴다. phase2 `comparison_note`의 ‘independently evidenced historical price timing’은 별도의 가정 시나리오에 부적절한 문구이며 원본을 덮어쓰지 않고 결과와 errata에 바로잡는다.
