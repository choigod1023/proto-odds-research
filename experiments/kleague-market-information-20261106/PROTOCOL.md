# K리그 배당 시장 간 추가 정보 검증 계획

승무패 배당만으로 만든 확률에 같은 응답의 90분 언더오버·정수 3방향 핸디캡을 추가하면, 결과에 부여하는 확률이 좋아지는지 검증한다. 입력 계약과 표본은 PR #621의 893개 공식 결과 연결 경기 및 신규 14경기에서 그대로 가져온다. 시장별 역배당을 합계 1로 맞춘 뒤 독립 Poisson 점수 분포에 맞춘다. 1X2 단독 분포와 세 시장 분포에는 동일한 수치 최적화 조건을 쓰고 시장별 가중치를 같게 둔다. 경기 결과로 모델을 적합하거나 시장 가중치를 고르지 않는다.

- 사후 분석의 주 비교는 기존 2026년 7월 4일~11월 1일 공통 239경기의 경기별 로그점수 차이, 즉 세 시장 분포의 실제 결과 로그확률에서 정규화 승무패 배당의 실제 결과 로그확률을 뺀 값이다. 평균이 양수면 세 시장 분포가 좋다.
- 같은 Poisson 점수 분포를 승무패만으로 맞춘 비교군을 두어 점수 분포 제약과 추가 시장 입력의 차이를 구분한다. 기존 팀 전력 Poisson과 이전 회귀 모델은 결과를 해석하는 참고 비교군이다.
- 두 리그를 합쳐 날짜 순서를 유지한다. 같은 주의 모든 경기를 함께 묶고, 달력상 연속 2주를 원형 블록으로 10,000번 재표집한다. 1주·4주 블록은 민감도 확인에만 쓴다. 리그별 결과, 공통 239경기 외 별도 654경기, Brier 점수, 적중률과 단위 베팅 ROI는 보조 지표다.
- 2025~2026년 893경기의 가격은 마감 후 확보했다. 앞선 연구에서 일부 표본의 결과를 이미 본 상태로 분석 방법을 정했다. 두 사후 표본 모두 탐색 자료로 표시한다.
- 11월 6일에 받은 14경기에는 최초 경기 전에 같은 세 확률 분포와 동일 승무패 배당을 파일로 동결한다. 시작 시각과 팀 식별자가 맞는 공식 90분 최종 결과만 연결한다. 취소나 무효는 이유를 별도 기록한다. 이 단일 회차는 실제 경기 전 배당으로 검증 절차를 확인하는 예비 표본으로 사용한다.
