# 특징 수와 정규화 강도의 시간 분리 검증

PR #211의 팀 특징을 그대로 재사용하고, 특징 조합과 ridge를 학습 자료 안에서
선택하는 절차를 추가했다. #211 위에 쌓는 후속 연구 PR이다. 운영 서비스의 예측,
DB, 추천 가중치, 수집기, 서버 상태를 수정하지 않는다.

## 무엇을 확인하는가

앞선 full/ridge=100 모델의 성능 악화가 특징을 과도하게 넣은 것과 관련 있는지,
계수를 더 강하게 축소하거나 특징군을 줄이면 이후 경기 오차가 줄어드는지 확인한다.
개선하더라도 두 가지 질문을 구분한다.

1. 이전의 과적합 가능성이 있는 full 모델보다 좋아졌는가?
2. 배당 기준선보다도 좋아졌는가?

첫 번째만 만족하면 새 정보로 시장을 이겼다고 말할 수 없다.

## 학습과 선택 순서

- 원자료: 2023년부터의 같은 보관 games.csv. CSV와 운영 DB를 섞지 않는다.
- 내부 검증: 2024년 4개 분기. 각 분기 시작 7일 전 미만 경기로 학습하고 그 분기 예측.
- 내부 검증의 마지막 종료일은 **2024-12-25 미만**이다. 2025년 첫 분기의 학습 embargo를
  특징/정규화 선택에도 적용한다.
- 리그·종목·시장·선택지 수별로 독립 선택한다. 내부 자료 부족 시 그 범위는 배당 기준으로
  돌아간다. 다른 리그의 계수나 선택 결과를 빌리지 않는다.
- 선택된 특징 조합과 ridge는 2025-01-01~2026-08-25 평가에서 바꾸지 않는다.
  모델 계수와 정규화 중앙값/표준편차만 각 분기에 다시 학습한다.
- 앞서 끝난 평가 경기는 다음 날 팀 특징과 다음 분기 계수 학습에 쓸 수 있다.
  하지만 2025년 이후 어떤 결과도 특징/정규화 선택에는 사용하지 않는다.

이는 지금 실행한 회고 연구에서 **2025년 전 자료만으로 선택했다**는 뜻이다.
실제로 2024년에 모델을 동결해 두었다거나 새 holdout을 확보했다는 뜻은 아니다.

## 후보와 선택 규칙

총 33개 후보를 사전에 지정했다.

- 배당 기준선 1개.
- 8개 특징 조합 × ridge 100/1,000/10,000/100,000.
- 특징 조합: compact(원특징 10개), 절편만, 득실 수준/Elo,
  모든 특징, 변동성 제거, 강약 성과 제거, 일정·상호작용 제거, 득실 수준/Elo 제거.
- 기존 full은 원특징 50개다. 결측 표시 50개와 절편을 포함하면 설계 열은 101개이고,
  2-way/3-way에서 추정 계수는 101개/202개다. 특징 수는 유효 자유도의 추정값은 아니다.
- ridge는 기존처럼 **합산 음의 로그우도 + lambda × 계수 제곱합 / 2**이며 절편도 축소한다.
  표본 수가 n일 때 평균 손실 기준으로는 lambda/n이다. 분기별 값을 결과에 남겼다.

동일한 내부 검증 시장행의 평균 log loss가 가장 작은 후보를 먼저 찾는다.
그 후보의 평균 손실 표준오차(SE)를 4개 달력 주 블록 bootstrap 10,000회로 계산한다.
후보 자신의 SE가 아니라 **최소 손실 후보의 SE 하나**를 공통 허용 폭으로 쓴다.

- tuned_minimum: 내부 검증 평균 손실이 가장 작은 후보.
- tuned_simple: 최소 손실+1SE 안에서 추정 계수가 적은 후보. 같은 크기면 더 강한 ridge,
  그래도 같으면 후보 ID 사전순. 배당 기준선은 추정 계수가 없어 절편 모델보다 단순하다.
- ridge_only: 모든 특징을 고정하고 4개 ridge 안에서 같은 1SE 규칙으로 선택한다.
- fixed_full: 앞선 실험의 모든 특징/ridge=100.
- baseline: 배당에서 마진을 제거한 확률.

1SE 규칙은 단순성 선호 규칙이지 통계적 우월성·동등성 검정이 아니다.
불확실성 폭이 크면 배당 기준선이 선택될 수 있다. 이를 특징이 불필요하다는 증명으로
해석하지 않도록 최소 손실 선택 결과도 별도로 평가한다.
내부 SE의 2주/8주 블록 민감도는 선택 ID만 기록하며, 원하는 결과를 골라 적용하지 않는다.

## 표본과 비교의 일관성

내부 각 분기의 학습 300시장 이상, 검증 20시장 이상을 요구한다.
합산 검증 300시장·150실경기·26실제 관측주·3사용 가능 분기 이상이어야 선택한다.
이 문턱은 보수적인 실험 조건이지 검정력 보장이 아니다.
부족하면 세 선택 전략 모두 배당 기준으로 고정한다. 그래도 외부 학습 300시장 조건을
통과하는 평가 행은 삭제하지 않는다. 모든 전략은 동일한 행에서 평가한다.
후보 학습 실패는 실험을 실패시키며 성능이 나쁜 행을 조용히 누락하지 않는다.

외부 평가는 baseline/fixed_full 대 세 선택 전략, ridge_only 대 tuned_simple,
tuned_minimum 대 tuned_simple의 8개 쌍 비교다. 모든 리그의 Brier/log loss 비교를 합쳐
Holm 보정한다. 기존과 동일한 최소 표본·두 연도 개선·양의 개선 CI·보정 p<0.05 조건을
모두 통과해야 과거 개선 신호로 표시한다. **운영 적용 허용은 항상 false**다.

bootstrap은 기존 실험과 비교 가능하도록 원형 달력 주 블록을 사용한다. 빈 주는 남기고,
평균은 재표집 손실 합/시장 수 합으로 계산한다. 같은 경기의 시장은 같은 블록에 있다.
연말과 연초를 연결하는 경계 및 비정상적인 시간 변화는 이 방법의 한계다.

## 해석 제한

2025~2026년은 앞선 실험에서 이미 본 자료다. 내부 검증을 추가해도 연구자가 그 결과를
이미 알고 설계를 고른 영향은 없앨 수 없다. 특히 no_scoring은 앞선 실험 중에 추가됐다.
이번 grid와 규칙은 이번 실행 결과를 확인하기 전에 고정했지만 완전히 새로운 holdout은 아니다.

배당 관측 시각, 결과 공개 시각, 완전한 리그 일정, 과거 xG·선발·불펜·부상·라인업은
없다. 같은 날짜 결과는 다음 날부터 사용한다는 가정이며 실제 T-30 시점 재현은 아니다.
수익률은 모든 시장의 최확률 선택에 같은 단위를 가상 구매한 값이다.
실제 서비스의 오늘 추천픽이나 실현 수익률이 아니다.

## 수치 계산 검증

고강도 정규화 후보 중 L-BFGS-B 선 탐색이 수치 오류로 종료되는 경우가 첫 실행에서
발견됐다. 실패 후보를 제외하지 않고, 동일한 볼록 목적함수를 정확한 Hessian의
trust-exact 방식으로 다시 푸는 처리를 추가했다. 두 번째 풀이도 실패하면 전체 실행을
실패시킨다. 첫 실패 실행은 결과 보고서를 저장하지 않았다.
성공하던 기존 L-BFGS-B 경로와 후보/시간 분할/정규화 grid는 변경하지 않았다.
일부 후보를 제거해서 좋은 비교만 남기는 동작은 하지 않는다.

신규 테스트는 1SE 경계·최소 손실 후보의 SE 사용·단순성 동점 처리·달력 공백·
2025년 이후 정보 제거/변조에 대한 설정 불변·리그 분리·부족한 내부 검증의
외부 평가 행 보존·첫 외부 분기 학습 불변·동일 목적함수 재풀이 등을 확인한다.
프론트에는 변경이 없으며, 테스트 중 기존 HMR 포트 점유 및 종료 시 dependency scan
경고는 있었지만 다른 서버나 프로세스를 종료하지 않았다.

## 최종 실행 결과

평가 구간은 2025-01-01~2026-08-25, 29개 리그의 17,881실경기·53,979시장행이다.
실제 외부 평가에 포함된 종목·리그·시장·선택지 수 조합은 **88개**다.
이 중 12개 리그의 **32개**만 내부 선택 표본 조건을 만족했고, **56개**는 표본 부족으로
기준선에 돌아갔다. 원자료에 존재하지만 외부 평가에 등장하지 않은 범위를 분모에 넣지 않았다.

- 32개 선택 가능 범위 모두에서 보수적 1SE가 배당 기준선을 선택했다.
  2주/8주 블록 SE 민감도에서도 이 선택은 같았다.
- 같은 32개 범위에서 특징을 전부 유지한 ridge-only는 모두 100,000을 선택했다.
  매우 강한 축소로 배당 기준선에 가까워지는 결과이지 추가 예측력의 확인은 아니다.
- 내부 최소 오차 선택은 29개 범위에서 비기준선 모델을 선택했다.
  리그 합산 Brier/log loss 평균은 NPB, EPL, 라리가, 세리에A, 프리그1에서 작아졌지만,
  배당 대비 Brier 개선 신뢰구간은 모두 0을 포함했다. NBA·KBO·MLB 등에서는 악화됐다.
- 배당 대비 세 선택 전략 중 지정된 과거 개선 조건을 통과한 비교는 **0개**다.
  기준선과 동률인 표본 부족 리그를 특징의 성공 또는 실패로 집계하지 않는다.

주요 리그의 Brier(낮을수록 좋음), 배당 → 기존 full → 내부 최소 오차 선택:

- NPB: 0.466910 → 0.469734 → 0.466694.
- MLB: 0.469518 → 0.473770 → 0.470820.
- KBO: 0.476038 → 0.483949 → 0.479738.
- NBA: 0.465995 → 0.471656 → 0.466602.

NPB의 전체 최확률 적중률은 58.95% → 59.28%로 올랐지만 팀 특징 효과라고 볼 수 없다.
승패는 control@1000, 핸디캡은 control@100으로 **팀 특징 없는 절편 보정**을 선택했다.
팀 특징을 사용한 언더오버(no_matchup@10000)는 Brier 0.499291 → 0.499574로 악화됐다.
리그 합산 Brier 개선량 0.000215의 95% 구간은 [-0.000333, 0.000730], Holm p=1이다.
MLB처럼 적중률이 조금 올라가도 확률 오차는 나빠질 수 있으므로 적중률만으로 채택하지 않는다.

NBA와 프리그1의 fixed_full → tuned_minimum 비교만 과거 개선 조건을 통과했다.
이것은 기존 약한 비교 모델에서의 회복이지 시장 우위가 아니다. 두 손실의 보정 p는
0.046395로, 10,000회 bootstrap의 Monte Carlo 해상도 하한(1/10001)과 464개 보정에
영향받는 경계 수치다. 강건한 확정적 유의성으로 확대 해석하지 않는다.

- 원본 CSV, 프로토콜, 코드 해시를 전후 확인했다. DB 쓰기·서비스 재시작·운영 가중치
  변경·배포는 수행하지 않았다.

현재 판단은 **운영 가중치 변경 보류**다. 다음 검증은 이미 본 평가 구간에 후보를 계속
맞추기보다, 완전한 팀 일정과 경기 전 시각이 있는 추가 특징을 확보한 뒤 미관측 기간에
모의 운영하는 방향이다. 이번 결과는 팀 성향이 존재하지 않는다는 증거가 아니라,
현재 보관 기록과 이 모델·선택 절차로 그 추가 예측력을 확인하지 못했다는 결과다.
