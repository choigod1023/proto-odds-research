# 토너먼트·외부 픽스터 연구 연결부

## 확인한 현재 상태

- `context_features.match_context`는 knockout/playoff/final을 위험 플래그로 분류한다. 시리즈 전적이나 탈락 조건을 이용한 별도 학습은 아니다.
- `pickster_watch` / `pickster_eval`에는 공개 픽 수집과 전향 성적 판정이 이미 있다. `recommendation_context`에서는 검증 전 인기 신호로만 설명하고 확률에 가산하지 않는다.
- #341 병합 커밋 63c913af에서 재실행한 results.json/tickets.json은 기존 산출물과 JSON 기준 완전히 일치했다. 이는 재현성 확인이며 독립 검증이나 수익성 개선이 아니다.

## 이번 구현 범위

`src/tournament_evidence.py`는 로컬 연구용 입력 연결부다. 운영 수집, 학습기, 웹에는 아직 연결하지 않았다. 실제 신규 자료로 학습하거나 ROI를 다시 계산한 결과가 아니다.

대회 정보는 경기 ID, 관측 시각, 대회/시즌, 규칙 버전, 출처, 단계가 필요하다. 승수 목표형 시리즈만 지원한다. 홈/원정 팀 기준 전적과 각각의 필요 승수를 명시해 비대칭 어드밴티지도 표현한다. 종료된 시리즈나 미래 자료는 거부한다. 축구 합산 스코어, 조별리그 순위 시나리오, 무승부에 따른 진출은 지원하지 않으며 임의로 시리즈 승수로 환산하지 않는다. 포맷별 공식 규칙 어댑터가 추가로 필요하다.

픽스터 입력은 공개 시각과 실제 관측 시각을 모두 요구한다. 동일한 경기·시장·라인·정산 범위의 의견만 집계하고 사이트 간 동일 인물은 하나로 센다. 같은 시각 상충 의견은 제외한다. 집계 수치는 독립 표본 수나 승률이 아니다. 작성자 식별과 출처 진위는 상위 수집기가 검증해야 한다. 사후 수정본의 시각을 최초 게시 시각으로 둔갑시키면 안 된다. 결과/현재 순위는 특징으로 사용하지 않는다.

## 외부 자료 점검 (2026-10-24)

- [TailSlips](https://tailslips.com/): 공개 MLB/NFL/NBA 픽과 성적, 원문 링크를 제공한다. 사이트가 제시하는 성적은 자체 집계이며 이 작업에서 독립 검산하지 않았다. 기존 수집기가 사이트의 모든 종목을 지원한다고 가정하지 않는다.
- [Bet Football 기록](https://betfootball.com/track-record): 경기별 정산 기록과 CSV 내보내기를 제공한다. 경기 전 게시 배당으로 정산한다고 설명하지만, 이 작업에서는 CSV나 원문 수정 이력을 수집·검증하지 않았다.

공개 접근 가능하다는 사실이 대량 수집 허가를 뜻하지 않는다. 이용 조건·빈도 제한을 확인한 뒤 허용된 범위만 수집한다. 현재 순위 상위 작성자만 고르면 생존자/선택 편향이 생기므로 수집 대상은 테스트 기간 전에 고정해야 한다. 국내 KBO/배구를 충분히 덮는 자료는 아직 확보하지 못했다.

## 다음 검증의 고정 조건

1. 기존 경기와 경기 전 스냅샷을 연결하고 종목·대회·단계별 연결률과 누락률을 먼저 보고한다. 관측 시각이 없는 과거 자료를 경기 전 자료라고 추정하지 않는다.
2. 대회별 공식 규칙, 시리즈 상태, 선발/확정 라인업, 불펜 사용량, 휴식·이동, 중립 구장, 축구 1·2차전 합산과 정산 범위를 각각 시간 기준으로 연결한다. 모든 변수를 확보했다는 주장은 하지 않는다.
3. 동일한 경기 집합에서 기존 모델 / 대회 맥락 추가 / 픽스터 추가 / 둘 다 추가를 비교한다. 누락 자료가 있는 실제 전체 경기 집합에서도 별도 비교해 선택 편향을 확인한다.
4. 시즌 순서대로 학습·보정·최종 평가를 분리한다. 작성자별 신뢰도는 그 시점 이전 정산 자료로만 학습한다. 표본 적은 포스트시즌은 정규시즌 모델 쪽으로 수축하고 대회별 결과도 공개한다.
5. 적중률, Brier/log loss, 실제 배당 ROI, 추천 건수, 월 손익·최대 낙폭을 함께 평가한다. 대회/시리즈 단위 재표집과 다중 비교 보정을 적용한다. 기존에 반복 튜닝한 데이터는 탐색 결과로 표시한다.
6. 월 손실 5만 원과 미정산 베팅의 손실 예약을 유지한다. 전체 성적뿐 아니라 종목·포스트시즌별 안정성이 확인되기 전에는 운영 가중치를 변경하지 않는다.

외부 픽스터는 필수 정답지가 아니라 추가 정보 후보다. 배당에 이미 반영된 의견이나 복제된 픽은 성능을 높이지 못할 수 있다. 현재 자료만으로 대회 맥락/픽스터의 적중률 또는 ROI 개선 폭을 산정할 수 없다.
