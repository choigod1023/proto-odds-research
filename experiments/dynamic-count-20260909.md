# 연속 실행 결과 — 2026-09-09

예약 없이 현재 대화에서 결과를 보고 다음 실험을 실행했다. 이전 PR217의 첫 실험을
재사용했으며, 이번 변경은 그 위에 동적 슈팅 예측·승패 연결·최근 기간 재학습·추천 대상
직접 학습과 MLB 타석 완전성 수정을 추가한다. 운영 모델·서비스·DB는 변경하지 않았다.

## 결론

**슈팅 예측 자체는 개선됐지만, 추천 적중률의 개선 근거는 아직 없다.**
아래 세 승패 연결 방식을 실제로 실행했고, 좋은 일부 수치만 선택하지 않았다.
비교 기준은 보관된 배당의 Shin 확률이다. 현재 서비스에 저장된 모든 실제 추천 픽의
성과를 재현한 것이 아니다. 승무패 마켓만 공급한 실제 프런트엔드 추천 함수의 부분 재현이다.

## 1. 동적 공격·수비 Poisson: 첫 관문 통과

사전 고정한 365일 학습창·90일 반감기·공격/수비 L2=0.1·날짜 D−2일 제한을 사용했다.
팀 공격력과 상대 허용 능력, 홈 효과를 각 예측 날짜마다 다시 추정한다.
K1 승강전 12개를 제외한 원본 804경기, 공통 평가 338경기/128날짜다.

- 총 슈팅 MSE: 최근 평균 19.7086, 상대 포함 평균 18.3262, 동적 모델 **16.6525**.
- 상대 포함 기준 대비 오차 감소 **9.13%**. 날짜 bootstrap 99% 감소 구간 0.6980~2.6636.
- 2025년: 기준 19.5311 → 17.7438. 2026년: 15.9896 → 14.5364.
- 128개 예측 날짜에서 최적화 실패 없음. 승패 적중률이 아니라 슈팅 수 예측 오차다.

## 2. 과거만 사용한 슈팅 예측을 승패에 연결: 실패

학습 구간의 입력도 당시 날짜 이전 기록으로 생성한 슈팅 예측이다. 실제 대상 경기의
슈팅을 학습 피처로 사용하지 않았다. 팀 이름은 명시적인 별칭표, 홈/원정과 KST 날짜로
결합하고 승무패 정산 방향을 대조했다. 초기 이력 부족 54경기와 배당 미결합 23경기를
제외한 727경기 중 397경기로 학습, 2025~2026년 330경기로 평가했다.

고정 L2=32의 배당-offset 3분류 모델로 2024년까지 학습한 결과를 유지했다.

- 전체 승무패: 배당 기준 **145/330 = 43.94%**, 과정 모델 **142/330 = 43.03%**.
- Brier: 0.64475 → 0.65481로 악화. 기준 대비 감소 구간도 −0.01733~−0.00256.
- 추천 함수 적용: 기준 **24/47 = 51.06%**, 후보 **23/58 = 39.66%**.
- 같은 날짜·0.1 배당 구간·추천 수 비교: **21/43 → 20/43**.

슈팅 예측을 더 잘한다는 결과만으로 추천에 연결하면 안 되는 사례다.

## 3. 오래된 승패 학습을 고정한 영향인가: 최근 365일 재학습

앞선 실패를 본 뒤 학습 기간 적응을 별도 가설로 평가했다. 매 날짜 D−2일까지 직전
365일의 150경기 이상으로 같은 모형을 다시 학습했다. 파라미터 탐색은 하지 않았다.

- 전체 승무패: **148/330 = 44.85%**로 기준보다 3건 증가.
- 그러나 Brier는 **0.64706**으로 기준 0.64475보다 나쁘다.
- 추천: **28/53 = 52.83%**. 배당 기준 24/47보다 비율이 높지만 표본·배당이 다르다.
- 같은 날짜·배당대·추천 수에서는 **양쪽 모두 19/35 = 54.29%**.
- 따라서 ‘재학습으로 추천 적중률을 개선했다’고 채택하지 않는다.

## 4. 실제 추천할 픽의 적중 여부를 직접 학습

다음 가설은 목표의 차이다. 전체 3분류 대신 배당 최유력 선택의 적중 여부를
배당 확률 offset 이진 로지스틱으로 학습했다. 최유력 팀 방향으로 정렬한 슈팅 예상 차와
합계를 사용하고, 최근 365일 재학습·L2=32를 고정했다. 나머지 두 선택의 확률은
시장 비율대로 재분배하여 합계 1을 유지했다.

- 전체 승무패 최댓값 선택: **148/330 = 44.85%**.
- 추천: **26/50 = 52.00%**. 같은 조건 매칭 후 **양쪽 모두 18/33 = 54.55%**.
- 목표였던 최유력 픽의 이진 Brier도 **0.24572 → 0.24841**로 악화.
- 2026년 추천만 보면 **10/14 = 71.43%, 단위 베팅 ROI +9.14%**.
  하지만 같은 조건 비교는 **양쪽 모두 8/11 = 72.73%**다. 14픽과 재사용 기간의
  좋은 숫자를 성공 사례로 선택할 수 없다. 2025년 결과도 일관되게 좋지 않다.

## 5. MLB: 모델보다 입력 완전성부터 수정하고 재실행

이전 5분류에서 빠졌던 실책 13타석과 포수방해 2타석을 별도 잔여 출루 유형으로 복원했다.
야수선택도 이 유형으로 분리했다. 원본은 읽기 전용으로 유지했다.

- 수용 타석 **2,232 → 2,247**. 30경기/60개 팀의 박스스코어 타석 합계와 전부 일치.
- 선수별 타석 대조도 수행하고, 불일치는 강제 재배정하지 않고 원본 증거와 보존한다.
- 평가: **15경기/2날짜/1,177타석**. 리그 기준 → 선수 풀링 로그손실
  **1.365917 → 1.365729**, Brier **0.692778 → 0.692821**. 혼합 결과다.
- 평가 타석 중 **994개(84.5%)에 해당 투수의 과거 이력이 없다**.
  이 표본으로 타자–투수 모델의 장기 성능이나 경기 승리 적중률을 판정할 수 없다.

## 해석과 제한

현재 확보한 슈팅 예상치가 배당을 넘어서는 승패 정보를 제공한다는 증거를 얻지 못했다.
이것이 모든 과정 모델이 불가능하다는 증명은 아니다. 이번 세 연결 방식과 표본에서
실패했으며, 단순히 오래된 가중치나 학습 목표 하나만 바꾸면 해결되는 문제도 아니었다.

모든 구간은 반복 사용한 과거 탐색 데이터다. 부트스트랩 구간은 다중 시도 보정이나
독립 미래 평가를 대체하지 않는다. 원본 슈팅은 일부 선수 통계 누락을 0으로 합산한
수집 한계가 있고, 보관 배당의 관측시각도 증명되지 않았다. 라이브 개선·수익 보장은 없다.

실패한 같은 설정을 다시 돌려 성공 횟수를 늘리지 않는다. 이번 가설의 채택은 보류한다.
다음 단계의 핵심 제약은 축구의 추가 예측 정보와 검증 가능한 공개시각,
야구의 실제 선수별 장기 이력이다. 예약은 재활성화하지 않았다.
