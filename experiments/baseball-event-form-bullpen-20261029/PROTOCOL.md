# 선발·타순 변경, 최근 성적, 불펜 사용량 사전 규칙

2026-10-29: 수집 시작 후 모형 결과를 보기 전에 기록한다. 운영 변경은 하지 않는다. 월 손실 제한 없이 동일 금액 단폴 ROI를 계산한다.

1. 이전 연구의 발표 선발·타순/가격 연결 MLB 2024년274경기와 2025-11~2026년116경기에 대해 공식 선수별 경기 로그와 경기 종료 정보, T-120/T-30/T-10의 공식 시간대 재생 상태를 실제로 수집한다. 실패/누락은 조용히 대체하지 않고 집계한다.
2. fullSeason roster는 로그를 찾는 색인일 뿐이다. 미래 로스터 소속·미래 투수 등판을 가용 불펜 선정에 사용하지 않는다. 해당 시점까지 실제 팀에서 던진 과거 등판으로만 풀을 만든다. 트레이드 시 로그의 team id를 확인한다.
3. 최근 14/30일 발표 타자들의 출루·장타·삼진, 발표 선발의 최근30일 ERA/K-BB와 직전 등판 이후 휴식, 팀 최근 득실을 만든다. 불펜은 과거 비선발 등판만 사용해 1/3일 투구 수, 이틀 연속 등판 인원, 최근28일 세이브+홀드 기준 상위3명의 전일 사용을 만든다. 현재 경기·아직 끝나지 않은 경기는 제외한다.
4. 완료 시각은 MLB 공식 schedule의 실제 firstPitch + gameDurationMinutes + delayDurationMinutes + 안전 여유60분으로 보수적으로 계산한다. 중단·재개 표시, 완료 여부/시간이 없는 기록은 제외한다. 이는 최종 타석의 실제 종료시각을 수집한 것과 구분하며, 원천의 날짜 오류/소급 정정 가능성까지 제거한 것은 아니다.
5. T-120와 T-30/T-10에서 둘 다 완성된9인 명단일 때만 ‘발표 타순 변경’으로 부른다. probablePitchers 변경은 예상 선발 변경으로 따로 부른다. 앞 시점에 명단이 없던 것은 발표 확보이며 교체로 부르지 않는다. 발표 순서와 배당 관측의 선후가 입증되지 않으면 ‘미반영 배당’ 효과를 검증했다고 부르지 않는다.
6. 기존 보존 시계열을 해당 경기·경기 전 관측으로 다시 연결한다. 명단 관측 전·후 가격이 있어야 발표 반응을 분리한다. 가격이 없거나 발표 전후 순서를 확인하지 못한 경기는 수익 비교에서 제외한다. ‘확률 변화1%p 미만’은 관측 기간 내 가격 이동이 작다는 진단일 뿐 미반영의 증명은 아니다.
7. 후보는 recent / bullpen / combined / combined_changes 네 묶음 × ridge 0.01/0.1/1의12개와 추가 효과 없는 market_null이다. 시장에 logit 잔차를 학습하며, 평가에서 동일 계수를 기존9:1로 이식하는 효과도 구분한다. 2024 픽스터가 없으므로 픽스터 계수까지 학습했다고 부르지 않는다. 미래 평가에서 좋은 묶음/계수를 고르지 않는다. 2024-03-20~08-03의190경기로 학습, 08-04~09-30의84경기로 적중률→Brier→이름 순 선택하고274경기로 재학습한다. 입력 연결 실패로 감소하면 실제 건수와 날짜를 보고하고 날짜 경계를 바꾸지 않는다.
8. 비교용9:1은 시장90%+픽스터10%이며 운영 투표 모형 전체의 동결 재생이 아니다. 2026-07-01 전/후를 사전에 정한 다른 기간으로 각각 공개하고2025-11도 별도 표시한다. 이는 이미 다른 연구에서 사용한 회고 집합이며 새 독립 미래 검증이 아니다. 구간에서 좋은 후보로 교체하지 않는다.
9. 동일 경기·동일 가격·동일 환불 기준으로 적중률/ROI/참여율/선택 변경 수, 주 단위 paired bootstrap 차이95%구간을 공개한다. 다중 탐색 보정 없는 서술적 구간이다. 현재 자료에서 구현 가능한 비교와 자료 부족으로 검증하지 못한 항목을 분리한다.

원자료 검증 중 추가한 무결성 수정: fullSeason 색인의 로그 합계와 공식 득실점이 다른 83경기를 발견해 공식 박스스코어로 전체 선수 기록을 대체했다. 모형 선택 규칙·기간·정규화 강도는 바꾸지 않고 모두 재실행한다. 최신 시점의 선발은 probablePitchers만으로 인정하지 않고, T-10 공식 사전 박스의 투수 목록에 단독 등록되고 예상 선발과 일치해야 한다. 이는 구단이 별도 발표한 게시물의 발표 시각까지 확보했다는 뜻은 아니다.
