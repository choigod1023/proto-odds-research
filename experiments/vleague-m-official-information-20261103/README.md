# 남자 V리그 공식 기록 연결 — 2025–26 정규리그

공식 [KOVO 프런트엔드](https://kovo.co.kr/)의 공개 일정·상세 API에서 2025–26 남자 정규리그 일정 126경기와 상세 126경기를 확보했다. 공식 시즌 목록의 대회 `001`·시즌 `022`·정규 `201`·남자 `1`을 사용했고, `023`은 2026–27이다. 일정의 날짜 범위는 2025-10-20~2026-03-19이며 약 5개월이다. 최근 완료 정규 시즌 전체를 택한 결과 요청한 6개월에 미치지 못한다. 플레이오프와 컵은 분모 밖이다. 일정 페이지가 `totalElements=126`을 반환했고 126개 ID가 유일하다.

상세 126/126경기에서 양 팀 각각 제1세트 비리베로 선발 6명, 리베로 명단, 선발 세터를 확인했다. 공식 프런트의 `ynS1`~`ynS5`에서 `-1`은 시작 표시, `-2`는 공란으로 렌더링한다. 선수별 세트 표시는 `postgame.jsonl`에 그대로 따로 두었다. 리베로는 6명에 포함하지 않는다. 각 선수의 ID·소속 팀·포지션도 보존했으나, 결장자의 공식 사전 명단이나 코트 로테이션 순서는 이 응답만으로 확인하지 못했다. 팀·선수 경기 통계와 최종 점수는 원문 상세에 포함된 사후 자료이며 타깃 경기의 사전 특징으로 사용하지 않는다.

동일 날짜·시작시각·홈/원정 공식 팀 ID와 이름·세트 스코어·결과가 일치하고, 핸디캡이 0이며 양방향 가격이 1보다 큰 일반 경기승 상품만 베트맨 원문 캐시 147개 회차에서 찾아 27/126경기를 연결했다. 캐시 99/126경기에는 이 조건에 부합하는 고유 가격이 없었다. KBO 캐시의 해당 76개 회차는 압축 해제 SHA 기준 모두 위 147개에 포함된다. 일부 과거 형식은 상품 ID가 비어 있어 두 선택지·기준점 등 명시한 필드로 제한했다. 추가 회차, 실제 판매 여부, 경기 전 관측·실행 가능 가격은 확인하지 못했다. `price-intersection.jsonl`에 원문 경로·SHA·수신시각과 두 가격을 보존했다. 세트 핸디캡·포인트 합계 상품은 연결 검사를 하지 않았으며 경기승의 27건과 합치지 않는다.

수신은 2026-11-03에 이뤄진 회고 자료다. 과거 발표시각, 당시 T-30 가용성, 경기 전 독립 수신을 증명하지 않으므로 엄격 PIT 선수·가격 연결은 0건이다. 해시는 저장한 바이트의 일치 검사이며 출처의 독립 인증이 아니다. 상세의 경기 결과 `3:2`는 세트 수이며 개별 세트 득점이나 포인트 합계 상품과 다르다. `schedule.body`와 상세 원문에도 최종값이 있으므로 사전 feature 경로로 직접 쓰지 않는다.

## 가설과 후속 계약

후속 가설 하나: 실제 판정 전에 공식 확인된 제1세트 세터 변경이 상대 전력·동시점 시장에 추가 정보를 주는지, 이전 경기까지의 공식 서브·리시브 누적치를 함께 고려해 경기승과 세트 시장을 각각 평가한다. 실제 사전 수신된 명단, 공식 선수 ID 매칭, 이전 경기의 실제 가용시각, 동일 상품·기준점·완전 가격과 정확한 결과 및 사전 동결 예측이 필요하다. 이후 세트의 명단, 대상 경기 개인 성적과 최종 점수는 타깃 전 입력에서 제외한다. 이 단계에서는 모델 적합·ROI·성과·채택을 주장하지 않는다.

## 수집·재개·검증

선택 규칙은 결과 확인 전 커밋 `332b93a`에서 고정했다. `collect.py`는 기존 바이트와 SHA를 확인해 재사용하며 전용 잠금, 최소 1.1초 간격, 15초 timeout, HTTP 403/429 즉시 중단을 적용한다. 재개는 `python -X utf8 experiments/vleague-m-official-information-20261103/collect.py`. 잠금이 남은 경우 소유 프로세스 종료 여부를 확인하기 전 제거하지 않는다. 최초의 상세 요청 3건은 추가 파라미터 때문에 HTTP 200이지만 응답 내부 404였으며, 원문과 메타를 그대로 보존하고 올바른 공개 프런트 요청 파라미터로 별도 재시도했다.

`audit.py`는 저장한 공식 원문과 지정된 기존 가격 캐시를 오프라인으로 대조한다. 외부 캐시는 별도 작업 경로이므로 재생에는 같은 SHA의 캐시와 원장 파일이 필요하다. 공식 웹 JS는 공개 배포본에 제3자 인증 문자열이 포함되어 원문을 저장소에 추가하지 않았으며, URL·수신시각·SHA 메타만 남겼다. 따라서 이 PR의 Git 바이트 검증 대상은 보존한 API 원문·파생물이며 JS 바이트는 제외한다. 원문·파생물의 `.gitattributes`는 줄바꿈 변환을 끈다.

Python으로 126경기 ID 유일성, 공식 상세와 일정의 ID·팀·날짜 일치, 252개 팀의 선발 6명 중복·리베로 분리, 세트별 점수와 경기 세트 결과 일치, 원문 SHA, 27건의 양방향 가격을 검사했다. 단위 테스트는 팀·날짜·점수·상품·판매 제한 불일치와 리베로 분리를 다룬다. 미래 라벨 오염에 대한 모델 예측 불변성 검사는 아직 학습·예측 코드가 없어 수행하지 않았다. 운영 모델·추천·DB·지갑·자동화·배포는 변경하지 않았다.
