## 확인한 현상

별도 경기 추천 1픽은 모든 종목 합계 36/75, ROI -22.07%다. 농구 11/23(-20.39%), KBO 1/2(-19.50%), 배구 0/4(-100%), 축구 24/46(-16.24%)이며 미래/미정산 39건은 손실로 세지 않았다. 이 작은 표본을 일반 승패와 같은 모델의 성적으로 해석하지 않는다. 같은 1픽 안에서도 승패·핸디캡·언더오버 구성이 다르다.

핸디캡·언더오버 추천 468개 중 449개는 정확한 기준점의 유효 투표가 없는 `market-baseline-v1`이다. 나머지 19개는 K리그1·KBL의 동결 핸디캡 모형이다. 배구 일반 승패 11개는 모두 유효 투표 0명의 시장 대체다. 따라서 현재 숫자를 선수·라인업 모델이나 실제 다수 픽스터 투표의 성적이라고 부르면 안 된다.

1픽 선택 코드는 배당 1.50 이상을 우선한 뒤 정규화 역배당 확률을 비교한다. 이 규칙은 저배당 승패보다 균형 잡힌 핸디캡·합계를 선택할 수 있다. 농구 워커는 1픽 H/UO 28개 중 26개의 같은 snapshot 승패 배당이 1.50 미만임을 확인했다. 관측된 구성 차이이며 인과적 성능 저하의 증명은 아니다. 정규화 역배당은 시장 정보를 변환한 값으로, 검증된 초과 수익 신호가 아니다.

무투표 시장 대체는 10/30 커밋 `13d9c5df`의 명시적 구현이며, 오래된 10/28 무투표 보류 문구만 보고 이를 새 버그로 판정하거나 정책을 되돌리지 않았다.

## 이번 구현

- 기존 동결 원장에 저장된 fixture·정책·선택 근거를 1픽 조회 시 읽어 종목·리그·시장·근거·정책별 집계를 만든다. 선택 ID·상품·기준점·배당·정산 규칙이 일치한 저장 추천만 모델 출처로 연결한다.
- 기존 전체 분모와 손익을 유지한다. 미분류 과거 기록도 버리지 않고 별도 그룹으로 남기며, 환불은 적중률에서 제외하고 정산 단위 ROI에는 포함한다.
- 실제 투표는 현재 투표 정책과 유효 작성자 수를 확인한다. `status=applied`나 정책 이름만으로 시장 대체를 투표로 분류하지 않는다.
- 웹 1픽 성적에 종목별·시장별 실현 성적, 펼쳐 보는 리그·근거·정책별 성적, 1.50 우선 규칙과 확률 해석 안내를 추가한다. 이전 API 응답도 표시할 수 있다.

예측식·추천 기준·동결 픽·운영 DB·스케줄·모의 지갑은 이번 구현에서 변경하지 않았다. 이 수정은 성능을 확인하고 잘못 해석하지 않도록 하는 개선이며 적중률 상승을 입증하는 모델 교체가 아니다.
