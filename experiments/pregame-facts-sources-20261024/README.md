# 선발·결장·로테이션 새 조회 증거 묶음

2026-10-24 11:25:48~11:26:32 UTC에 공개 웹 도구로 다시 조회했다. 독립 작업의 수집 증거 담당이며 운영·모델·월 손실 정책을 변경하지 않았다.

## 결과 및 인계

야구 2개, 축구 2개, 농구 2개, 배구 2개 분석글 본문을 읽고 15개 주장을 짧게 구조화했다. 축구 추가 1개 글은 Bot Verification으로 실패했다. 총 기사 직접 조회 시도는 9개이며 읽힌 것은 8개다. 모든 종목의 선발·결장·로테이션 후보를 확보했지만 검증된 현재 선발 명단을 확보한 것은 아니다.

records.json은 메인 담당이 요청한 리스트이며 id/sport/kind/source_url/published_at/observed_at/event_id/kickoff_at/summary/verification 필드를 포함한다. 미확인 값은 null이다. 추가 claim_status, claim_scope를 반드시 함께 읽어야 한다. absence는 수집 주제일 뿐 현재 결장 확정값이 아니다. 부상 복귀(returned), 직전 경기 결장(previous_event), 출전 불확실(questionable)을 current out으로 매핑하면 안 된다. 김천의 일반적인 선수단 재편 주장은 구체적인 교체 명단·날짜가 없어 제외 대상이다.

독립 대조로 [KBO 공식 사이트 프리뷰](https://www.koreabaseball.com/MediaNews/News/Preview/View.aspx?bdSe=59980)에서 NC 로건·LG 손주영 선발을 확인했다. 해당 [아톰티비 글](https://www.attv24.com/sports_analysis/19403)의 두 주장과 내용이 일치한다. 이는 공식 사이트에 실린 프리뷰의 **사후 조회 일치**이며 당시 관측·원문 불변성 증거가 아니다. verification.confirmed=true는 이 제한된 내용 일치만 뜻한다. 실제 경기 투구 결과/선발 확정 라인업을 검증한 것으로 확대하지 않는다.

공식 대조가 된 주장 2개를 포함해 **사전검증 적격 0개**다. event_id와 kickoff_at 모두 미매칭이다. 분석글 날짜/시간을 공식 경기 식별자나 예측시각으로 꾸며 넣지 않았다. 모델효과 ROI는 null이며 월 손실 5만원 계산은 메인 담당의 별도 작업이다.

## 시간·접근 한계

- observed_at은 이 배치의 실제 도구 조회가 끝난 UTC 상한시각이다. 첫 조회 시각이나 서버 원본 갱신 시각은 아니다.
- 새 도구 조회라도 검색 서비스가 오래된 캐시를 반환할 수 있다. 일부 아톰티비 페이지의 crawl 메타데이터가 오래됐으며 원본 최신성은 검증하지 못했다.
- 게시화면 문자열은 published_display_raw에 보존했다. 아톰티비는 연도·시간대가 없고 경기 시각과 동일한 표시가 나온다. 킹콩티비도 시간대·수정이력은 확인하지 못해 published_at은 null이다.
- 과거 기사 조회를 과거 경기 전 관측으로 바꾸지 않는다. 같은 날 킹콩티비 기사도 이번 확인이 한국시간 20:26경이고 공식 시작시각 미매칭이므로 사전 관측이라고 주장하지 않는다.
- KBL/KOVO 공식 홈페이지는 읽을 본문이 없었고 관련 한정 검색도 결과가 없었다. 해당 부상·로테이션 주장의 공식 확인에 실패했다는 의미이며 실제 정보가 없다는 증거가 아니다.
- 네임드 후보 경로는 도구 접근 실패, 한글 도메인은 iframe만 반환했다. 정확한 네임드 분석 게시판 경로도 확인하지 못했다. 우회하지 않았다.

세부 URL과 실패/검색 기록은 access_log.json, 기사별 짧은 주장과 URL은 records.json에 있다. 원문 전체, 최종 승패·핸디·언더오버 선택은 저장하지 않았다. validation.json 해시는 로컬 구조화 파일 해시이지 원문이나 과거 스냅샷의 해시가 아니다.
