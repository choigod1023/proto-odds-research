# 보정 전이 검증

PR335의 로더/보정기를 재사용한다. 새 독립 자료 검증이 아닌 기존 자료의 강건성 분석이다.
농구·축구·배구, 2025~2026년 분기별 평가. 평가 직전까지 학습하고 해당 분기 결과는
학습에서 제외한다. 시장, 전체 절편 보정, 최근 365일 절편 보정, 리그 보정의 고정
네 후보를 모두 보고한다. 리그는 학습 200경기 이상일 때 전체 보정과 50:50 혼합,
그 미만은 전체 보정으로 후퇴한다. 평가 결과에 따른 운영 승격이나 최고값 선택 금지.
적중률, Brier, ROI, 월별 및 리그별 차이와 7관측일 블록 CI를 보고한다.
동일 자료 재사용과 다중 비교로 확증으로 해석하지 않는다. 최신 운영 결과는 별도
읽기 전용 API 확인으로 분리하며 당시 사전 예측 없이는 소급 성능이라 부르지 않는다.
