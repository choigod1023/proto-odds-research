# 분기별 보정 전이와 최근 성과 점검

## 결론

농구의 작은 적중률 개선이 분기별 재학습에서도 나타났고 축구에도 리그 보정이
후보로 남았다. 배구는 불확실하다. 세 종목 모두 양수 수익을 입증하지 못했다.
운영 추천이나 확률을 변경하지 않는다.

## 설계

프로토콜 814fca85 고정 후 실행. PR335의 로더와 모델 함수를 동일하게 재사용했다.
입력은 accuracy-formula-lab/data/processed/games.csv,
SHA256 dfe95c2ace14ee42142ea0c86912b68359bc8ebee9ad3cb566812815bdec0eb0.
2025Q1~2026Q3(부분 분기), 매 분기 이전 기록만 학습했다.
시장, 전체 절편 보정, 최근 365일 보정, 리그/전체 보정 50:50의 고정 후보 비교다.
리그 학습 200경기 미만은 전체 보정으로 후퇴한다. 2폴 계산은 재사용한
paper 함수의 월 손실 5만원 제한을 유지한다.
기존에 본 데이터이므로 새로운 독립 확인이 아니며 다중 비교 보정 전 탐색이다.
이전 보고서와 동일한 8월까지 자료로 10월의 성능을 소급 입증하지 않는다.

- 농구 3,069경기: 시장 68.20%, 전체 보정 68.78%, 최근 보정 68.65%,
  리그 혼합 68.78%. 전체 보정의 차이 CI +0.12~+1.09%p.
  단폴 ROI -11.99%→-10.92%. 전체 보정은 7분기 중 4개 개선, 1개 동일,
  2개 악화. 특히 2026Q2 -0.49%p, 부분 Q3 -2.22%p로 일관된 개선이 아니다.
- 축구 9,767경기: 시장 52.17%, 전체 보정 52.27%, 최근 보정 52.43%,
  리그 혼합 52.50%. 리그 혼합 차이 CI +0.11~+0.56%p.
  단폴 ROI -11.55%→-10.65%. 리그 혼합은 5분기 개선, 1개 동일, 마지막
  부분 Q3 -0.39%p 악화. 축구에도 적용 후보는 있지만 운영 승격 근거는 부족하다.
- 배구 902경기: 시장 67.63%, 전체 보정 67.85%, 최근 보정 67.74%,

  단폴 ROI -12.40%→-11.81%. 리그 혼합 3분기 개선, 2개 동일, 2개 악화.
  과거 적중률 최대값을 근거로 바꾸지 않는다.

CI는 7개 관측일 블록 bootstrap 2,000회다. 모든 후보의 Brier, 확률 구간,
리그/월별 결과, 월 손실 제한 2폴 결과는 report.json에 기록했다.
같은 시장 기록을 반복 분석한 결과이므로 유의한 구간도 새 데이터 확인이 필요하다.

공개 성과 API만으로 검증할 수 없다.

## 개선 우선순위

1. 과거 추천 자격·모델 버전·종목·시장·사전 입력 시각을 보존한 표본부터 평가한다.
   현재 공개 전체 예측 통계와 추천픽 성적을 혼용하지 않는다.
2. 농구 전체 보정과 축구 리그 혼합을 고정 후보로 최신 사전 기록에 병행 산출한다.
   최근 분기 악화가 있어 자동 교체하지 않는다.
3. 배구는 표본 확보 및 남녀/리그별 보정 확인을 우선한다.
4. 선발·결장·라인업·최근 팀 폼 추가는 경기 전 관측시각이 있는 자료로
   해당 변수 포함/제외 비교를 해야 한다. 없던 과거 정보를 소급 주입하지 않는다.
5. 적중률뿐 아니라 확률 오차와 배당 대비 손익을 함께 통과해야 승격한다.
