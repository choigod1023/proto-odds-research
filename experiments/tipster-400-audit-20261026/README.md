## 왜 이전에는 픽이 같았나, 이번에는 어떻게 달랐나

이전 12경기는 연구 모델과 픽스터가 모두 같은 쪽을 골랐다. 같은 쪽에 투표를 더하면 최고확률 선택은 바뀌지 않고 확신만 올라간다. 이번에는 실제 불일치가 충분히 발생했다.

- 야구: 모델–픽스터 불일치 76경기. 9:1에서 40경기 변경, 기존 실패를 적중으로 바꾼 20건·기존 적중을 실패로 바꾼 20건.
- 농구: 불일치 30경기. 16경기 변경, 개선 6건·악화 10건.
- 축구: 불일치 89경기. 23경기 변경, 개선 9건·악화 9건·양쪽 모두 실패 5건.
- 배구: 불일치 21경기. 6경기 변경, 개선 3건·악화 3건.

기존 선택 b와 픽스터 선택 t가 다를 때, 10% 투표가 선택을 바꾸려면 대략 `p(b)-p(t) < 1/9`여야 한다. 이진 시장에서는 기존 우세 확률이 55.56%를 넘으면 반대편 한 표 10%만으로는 뒤집히지 않는다. 경계에서는 반올림과 동률 처리도 영향을 준다.

같은 쪽을 고른 경기에서 9:1은 선택 확률을 평균 야구 4.10%p·농구 3.62%p·축구 4.85%p·배구 2.93%p 높였다. **확률 상승 자체는 성능 개선이 아니다.** 전체 Brier 점수는 연구→연구 9:1에서 야구 0.48932→0.49157, 농구 0.43683→0.44045, 축구 0.61491→0.61435, 배구 0.41119→0.41804였다. 낮을수록 좋으므로 축구만 아주 조금 개선됐고 나머지는 악화됐다. 축구도 log loss는 소폭 악화됐다.
