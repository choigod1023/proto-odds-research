# 신규 픽스터 표본 확대 검증 규칙

목표는 야구·농구·축구·배구 각각 신규 100경기 이상이다. 종목과 리그는 다르다. 농구 KBL 결과를 NBA까지 일반화하지 않는다. 기존 16경기 원장과 후속 12경기 원장의 경기 식별자를 제외한다. URL 수나 공식 결과 수를 최종 연결 경기 수로 보고하지 않는다.

## 수집과 연결

- 무료 공개 분석 글의 본문을 로컬에 수집한다. 원문 HTML·본문은 Git에 올리지 않고, 공개 URL·본문 해시·추천 방향·분석 결과를 남긴다.
- 게시판 분류 대신 제목의 리그, 경기 날짜, 두 팀을 사용한다. 공식 경기 하나로 식별되지 않으면 제외한다. MLB 더블헤더를 점수나 유리한 결과로 골라 연결하지 않는다.
- 공식 결과는 MLB StatsAPI, EPL 공식 사이트 데이터 API, K리그 공식 사이트, KBL·KOVO 공식 API에서 가져온다. 경기별 공식 식별자와 원문 응답 캐시를 보존한다.
- 게시 시각을 KST로 가정했을 때 경기 시작 전이어야 한다. 현재 수집한 수정 가능한 게시 시각은 당시 공개 사실의 독립적 증명이 아니다. `strict_pregame_eligible=0`을 유지한다.
- 실제 과거 배당은 기존 `games.csv`에서 연결한다. 경기·시장·결과가 고유하게 연결되고 공식 최종 점수까지 일치해야 한다. 배당이 제시된 정확한 시각과 실제 구매 가능 여부는 미확인이다.
- 승·패·무승부를 명시적으로 구별한다. `팀 패`는 상대 승으로 해석하고, 핸디캡·이중기회·부정문·팀명만 있는 문구는 제외한다. 같은 경기의 여러 글은 한 경기로 세며 서로 다른 추천이면 제외한다.

## 고정 비교군

1. 시장확률: 실제 배당을 Shin 방식으로 마진 제거.
2. 기존 연구 모델: 2025년 이전 자료로 학습한 시장확률 offset 모델. 종목별 Elo·Pi·기존 지정 피처 사용. 저장된 운영 사전 예측과 동일하지 않다.
3. 픽스터 단독: 원문의 일반 승패/승무패 추천. 보정된 확률 모델로 간주하지 않는다.
4. 시장 90% + 픽스터 투표 10%: 운영 계산식의 연구용 유사 비교군. 운영 작성자·사전 관측 자격을 충족하는 재현은 아니다. 운영과 같이 선택 시 소수점 넷째 자리 반올림.
5. 연구 모델 90% + 픽스터 투표 10%: 이전 연구와 비교할 별도 혼합군.

모든 군은 최고확률 단폴 한 개를 고른다. 평가 결과를 보고 혼합 비율·피처·필터·배당 조건을 튜닝하지 않는다. 적격 경기 전체를 평가하며 이긴 경기만 100개 채우지 않는다.

## 지표와 손실 제한

- 동일 경기의 적중률, 실현 ROI, 1만 원 균등 단폴 손익, Brier·log loss(확률 비교군만).
- 연구 모델과 픽스터의 불일치 수, 혼합 후 선택 변경 수, 변경으로 맞거나 틀린 수, 경기별 모델 피처 기여도.
- ROI 차이는 날짜별 paired bootstrap 2,000회, 고정 시드로 구간을 계산한다. 반복 연구에 따른 선택 편향을 해결한 독립 검증 구간이라고 주장하지 않는다.
- 월 순손실 한도 −50,000원. 하루 중 미정산 후보의 전액 손실을 미리 예약하고 다음 날 정산한다고 가정한다. 네 종목을 합친 하나의 한도는 `overall_monthly_cap`이다. 종목별 결과는 서로 다른 가상 전략이지 동시에 사용할 별도 지갑 네 개가 아니다.
- 경기 선택은 결과와 무관하게 시작 시각·식별자 순서다. 주 2~3회·2폴·실제 구매 시각을 재현한 계산이 아니다.

## 해석 제한

원문에 선발·결장·전술이 언급돼도 그 정보가 정확하거나 모델에 인과적으로 기여했다고 보지 않는다. 이번 9:1 혼합의 입력은 최종 추천 방향이며 본문 사실을 직접 모델 피처로 넣은 것이 아니다. 본문의 요인 태그와 모델 피처 기여도는 불일치를 설명하는 감사 자료다. 원문의 사실 검증과 별도 피처 제거 실험 없이 ‘선발 정보 때문에 수익률 개선’이라고 결론내리지 않는다.

수집 경로와 연결 성공 여부에 따른 선택 편향, 단일 게시 계정 의존, 사후 수정 가능성, 배당 시각 미확인, 동시 경기의 상관관계가 남는다. 100경기는 최소 수집 목표일 뿐 수익 보장이나 운영 채택 기준이 아니다. 이 작업은 운영 모델·DB·수집 서버를 변경하거나 배포하지 않는다.
