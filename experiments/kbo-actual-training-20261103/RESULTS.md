# KBO 실제 타순·선발 학습 비교

2026-11-03. 실제 재학습 및 동결 예측의 독립 정산 결과다. 최종 모델 워커 결과와 독립 검토의 고정 커밋은 dispatch.json에 인계한다. 연구 자료·결과를 보존하며 운영 모델 변경, 병합, 배포는 하지 않는다.

## 비교 범위

기존 모델 M0는 PR #531에서 사용한 선수 성적 집계 기반 독립 Poisson 연구 대조군이다. 현재 웹 서비스의 픽스터 투표/9:1 모델을 재생한 결과가 아니다. M2는 같은 연구의 교정 v2 다항 모델로 선수 ID 효과와 양 팀 결측·미등록 합계 12개를 포함한다. M0 base L2=10, M2 base L2=10/player L2=100을 유지했고 이번 결과로 새로운 모델·특성·하이퍼파라미터를 선택하지 않았다.

원래 보유 모집단 2023년 723, 2024년 728, 2025년 736경기에서 공식 타순·실제 투수 선발을 연결했다. 2025-09-30의 타순 확정 근거가 없는 5경기를 예상/실제 양쪽에서 제외해 2,182경기(723/728/731)를 맞췄다. 각 시즌 전체 KBO 경기의 완전 수집이라고 주장하지 않는다.

공식 확정 타순은 순서가 확인된 9명이다. 발표 후 타순 변경 여부·각 타자의 물리적 출전·당시 경기 전 수신 시각까지 증명한 것은 아니다. 실제 투수 선발은 공식 경기기록의 선발 표시를 대조했다. 동명이인 투수 5건과 이름이 바뀐 동일 선수 ID는 공식 신원 근거로 해결했다. 대상 경기 기록을 신원 식별에만 쓰고 해당 경기 성적을 숫자 특성에 넣지 않았다.

예상/실제 양쪽은 같은 경기·같은 비선수 및 불펜 특성·같은 과거 원천을 사용한다. 공통 선수의 이력도 같으며 이전 날짜의 유효 관측 최근 10개를 사용한다. 결측은 0으로 채우지 않았다. 학습 사전과 표준화는 학습 구간에서만 산출하고 7일 경계 간격을 적용했다.

## 주 평가: 2026 실제 명단으로 평가

적중률은 무승부를 포함한 709경기 3분류 정확도다. ROI는 동일한 두 방향 승패 배당을 연결한 667경기에서 매 경기 1단위씩, 15무승부는 환급하며 투자액 분모에 포함해 산출했다. 두 지표의 분모가 다르다.

- M0 예상 명단 학습: 401/709, 56.56%; ROI -8.73%, 순손익 -58.21단위.
- M0 실제 명단 학습: 418/709, 58.96%; ROI -4.36%, 순손익 -29.05단위.
- M2 예상 명단 학습: 392/709, 55.29%; ROI -7.93%, 순손익 -52.89단위.
- M2 실제 명단 학습: 396/709, 55.85%; ROI -7.38%, 순손익 -49.25단위.

M0에서 명단을 바로잡아 학습한 차이는 적중 +17경기/+2.40%p, ROI +4.37%p였다. M2의 차이는 +4경기/+0.56%p, ROI +0.55%p였다. 실제 명단 학습 후 M2는 M0보다 22경기 덜 맞혔고 ROI도 3.03%p 낮았다. M2가 확률 점수에서는 우세했다(M0 log loss 0.84040/Brier 0.52259, M2 0.77062/0.50705). 확률 점수의 개선을 픽 적중이나 이익 개선과 혼동하면 안 된다.

30개 달력 주를 묶어 5,000회 재표집한 paired ROI 차이의 95% 구간은 M0 실제-예상 학습 -1.12~+10.03%p, M2 -4.11~+5.42%p였다. 모두 0을 포함한다. 기간별 우월성·미래 수익성을 확정하지 않는다.

## 민감도와 이전 모델 문맥

엄격한 원래 경기 시각 일치 배당 439경기에서도 M0 실제 학습 ROI -6.53%가 M2 실제 학습 -10.31%보다 높았다. 같은 각 모델의 예상 명단 학습은 M0 -7.95%, M2 -11.69%였다. 확장 배당과 엄격 배당을 섞어 유리한 값만 선택하지 않았다.

실제 학습 M0의 확장 배당 일별 마감 누적 최대 낙폭은 40.98단위, M2는 67.74단위였다. 양쪽 모두 4개 월에서 순이익, 4개 월에서 손실이며 3월·10월은 부분 기간이다. 전 기간 수익 또는 흑자 모델은 아니다.

예상 명단으로 평가하면 결론이 달라졌다. M0 실제 학습은 392/709(55.29%), ROI -10.83%로 예상 학습 398/709(56.14%), -9.13%보다 나빴다. M2 실제 학습은 400/709(56.42%), -6.38%로 예상 학습 392/709(55.29%), -8.57%보다 나았다. 실제 명단 학습 모델을 불확실한 예상 명단에 넣어도 같은 개선이 난다고 주장하지 않는다.

이전 full-training 동결 M0/M2를 새 실제 명단에 재생하면 각각 403/709·ROI -8.30%, 390/709·-8.51%다. 이 모델들은 원래 2,187경기 학습이므로 5경기를 제외한 paired 재학습과의 차이를 명단만의 인과 효과로 설명하지 않는다.

2025년 실제 명단 평가에서는 M0 예상 학습385/731→실제 학습393/731, M2 393/731→398/731이었다. 그러나 예상 명단 평가에서 M2 실제 학습383/731은 예상 학습394/731보다 낮았다. 검증 구간에서도 시나리오 차이가 존재한다.

## 판단과 한계

실제 명단을 학습 자료에 연결하는 방향은 이번 표본에서 M0의 손실과 낙폭을 줄였다. 현 연구에서 후속 검증 후보는 실제 명단 학습 M0이며, M2로 교체할 근거는 나오지 않았다. 두 모델 모두 ROI가 음수이고 우월성 구간도 0을 포함하므로 수익 모델로 채택하거나 운영에 자동 교체하지 않는다. 다음 비교에서는 동일 정의의 경기 전 명단 입력을 축적하고 고정 모델로 추가 평가해야 한다.

원래 가격·결과는 d08ccb708033fb6b067e84e80eae81ea3c9b4cfa의 고정 원장을 재사용했다. 배당 일부는 날짜·팀 기준 복원이며 당시 구매 가능성·경기 전 실제 관측을 전수 입증한 것은 아니다. 현재 buyReject 플래그 제외는 민감도일 뿐 과거 판매 여부 증거가 아니다. 결과 원본의 archive 표시는 보존했다. 독립 검토자는 추가 네트워크 수집 없이 고정된 공식 일정 원문의 최종 점수와 평가 레이블 709건을 대조해 전부 일치함을 확인했다(불일치 0, 누락 0). 이는 현재 확보한 공식 결과와의 일치이며 당시 수신·베팅 체결 증거는 아니다.

2024년 수집 중 요청 간격 1.5초 미만 128건이 있었고, 겹친 프로세스를 중단한 후 잠금을 적용했다. 수집 규칙을 전부 지켰다고 주장하지 않는다. 당시 수신 시각이 입증된 표본은 0건이다.

기존 월 손실 5만원 모의 원장은 변경하지 않았다. 이 계산은 월 한도·2폴·사용자 베팅 내역 재현이 아닌 단폴 1단위 비교다. 운영 코드·DB·스케줄·자동화·배포도 변경하지 않았다.
