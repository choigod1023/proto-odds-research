# NBA 슛 위치 모델 구조 진단

기존 1,185경기 이력 풀과 동결된 1,260경기 Q(계열 합산)·S(구역별) 예측을 그대로 사용한 사후 진단이다. A는 2025-10-22~12-31 487경기, B는 2026-01-01~05-04 773경기다. 기존 대상 경기·배당·승패와 D-365~D-4 이력 창을 유지했고 이력 ID 및 기존 예상 득점과 재계산을 모두 대조했다. 1,185는 평가 경기 수가 아니라 원천 이력 풀이다. 추가 모델의 예측 성능을 측정하거나 평가 결과로 평활 폭을 고르지 않았다.

## 기회량과 성공률의 혼재

Q는 2점과 3점을 각각 먼저 합친 후 공격 시도율과 상대 허용 시도율을 결합한다. S는 구역별 결합 시도율 `ro × rd / r0`을 계산해 더한다. 따라서 구역의 성공률이 같아도 두 모델의 2점·3점 전체 시도율은 일반적으로 같지 않다. 각 경기의 양 팀 2,520개 예측에서 S/Q 시도율의 5·50·95백분위는 2점 0.9829 / 0.9998 / 1.0164, 3점 0.9808 / 0.9998 / 1.0195였다. 평균은 각각 0.9997, 0.9998이다. 평균이 1에 가까워도 팀별 차이는 상쇄될 수 있다.

계열별 Q/S 시도율을 R, 그 계열의 기대 성공 수를 시도율로 나눈 성공률을 A라 하면, 점수 차이를 정확히 `점수×포제션×[(Rs−Rq)(As+Aq)/2 + (As−Aq)(Rs+Rq)/2]`로 분해했다. 첫 항은 시도율, 둘째 항은 성공률의 대칭 기여다. 이 분해는 수학적 귀속이며 반사실적 인과 효과는 아니다. 자유투 항은 두 모델에서 같아 차이가 0이다. 최대 분해 잔차는 부동소수점 수준이다.

Q와 S의 선택이 바뀐 50경기에서 홈과 원정의 시도율 기여 차이 절댓값은 평균 0.926점, 성공률 기여 차이 절댓값은 평균 0.501점이었다. 두 항은 같은 경기에서 서로 상쇄되거나 같은 방향으로 작용할 수 있고, 확률은 점수 분포로 계산되므로 이 숫자만으로 특정 선택의 인과 원인을 확정할 수 없다. 변경 경기의 평균 절대 확률 이동은 2.40%p였다.

A에서는 20경기 방향이 바뀌어 Q 11승, S 9승이었다. 1단위 가상 손익 합은 Q -0.78, S -3.38이었다. B에서는 30경기, Q 16승과 S 14승이었고 합계는 Q +1.22, S -8.27이었다. 전체 50경기의 차이는 S−Q -12.09단위다. 바뀌지 않은 경기는 같은 방향·배당이므로 전체 1,260경기 기준 ROI 차이는 약 -0.96%p다. 이 과거 집계는 결과를 보고 원인을 진단한 것이며 미래 수익성이나 원인 확정을 뜻하지 않는다. 개별 확률·배당·양 팀 분해 결과는 `diagnostic_games.jsonl.gz`, 기간별 분포는 `diagnostics.json`에 있다.

## 1피트 평활 거리 자료

`soft_games.jsonl.gz`는 원문 야투 210,663개에 대해 r=hypot(x−25,y)로 두고 `[max(0,r−1), r+1]`에 균일한 거리 질량을 배분한다. 기존 2점 경계 4/10/16, 3점 경계 24/27은 유지하며 각 구간과 겹치는 길이의 비율을 시도와 성공에 똑같이 적용한다. 2점·3점 간 이동은 없고 좌표 누락·비유한·센티넬은 기존 unknown에 남긴다. 폭 1피트는 기존 거리 오차에 근거해 고정했으며 새 평가 성적으로 선택하지 않았다. 이는 ESPN 내부 기하의 비공식 가설이고 실제 좌표 측정 오차의 확률분포를 입증한 것이 아니다. 공식 NBA 슛 존으로 해석하지 않는다.

각 경기 원문과 영수증 해시, 팀 및 날짜를 검사하고, 원문에서 다시 센 기존 hard 9개 구역과 기존 파일이 일치하는지 확인했다. 각 팀의 2점·3점·전체 시도/성공과 자유투가 hard 자료와 보존된다. 최대 차이는 1.42e-14로 부동소수점 합산 오차다. 대상 1,185개 경기 ID 및 원문 SHA를 유지하며 행별 영수증 SHA도 기록했다. 고정 hard 파일, 예측 파일 및 학습 특성 파일의 해시는 `diagnostics.json`에 있다. 결과에는 soft 프로필을 이용한 새 예측이나 성능 평가가 없다.

## 재현

```powershell
python scripts/nba_spatial_structure_diagnostics.py --pool <기존_프로필_실험폴더> --model <기존_모델_실험폴더> --archive <ESPN_보존폴더> --out <출력폴더>
python -m pytest tests/test_nba_spatial_structure_diagnostics.py -v
```

이력 풀의 사후 수신은 당시 경기 전 가용성을 증명하지 않는다. 실제 구매 가능성·수익성은 미검증이며 운영 추천, 원장, DB, 배포를 변경하지 않았다.
