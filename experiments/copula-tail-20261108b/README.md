# K리그 득점 의존성과 꼬리 분포: 회고 연구

## 범위와 결과

K리그1·2의 세 상품이 모두 연결된 자료에서 2023~2024년 928경기로 계수를 추정하고 2025년 437경기로 검증한 뒤, 계수를 바꾸지 않고 2026년 126경기를 평가했다. 요청한 2026-01-01~08-26 중 실제 자료는 06-07까지만 있다. 이미 반복 사용한 회고 자료로, 독립 미공개 검증이 아니며 사전 등록도 하지 않았다. 다른 종목과 전체 승패 공통 아카이브 평가를 완료한 것은 아니다.

2026년 같은 126경기 기준, 승무패 적중률/ROI/로그손실은 직접 시장 48.41%/-10.94%/1.0390, Gaussian copula 49.21%/-8.87%/1.0362, 공통 충격 혼합 48.41%/-10.94%/1.0383이다. 핸디캡은 각각 52.38%/-11.16%/1.0095, 50.79%/-14.76%/1.0055, 50.79%/-14.76%/1.0054다. 언더오버는 49.21%/-21.83%/0.6976, 45.24%/-26.10%/0.7249, 46.03%/-24.66%/0.7264다. 모든 후보의 절대 ROI는 음수다. 승무패 copula의 선택 차이는 한 경기뿐이다. 언더오버 시장 대비 ROI 차이 95% 주 단위 쌍체 구간은 copula -17.46~+8.08%p, 충격 혼합 -16.71~+10.46%p로 모두 0을 포함한다. 다중 비교를 보정하지 않았다.

`summary.json`에 검증·평가 구간의 전체, 리그, 분기, 월별 적중률·ROI·로그손실·다중분류 Brier·일별 최대낙폭과 평가기의 모든 대조군 쌍체 비교 및 선택 변경 방향이 있다. 후보−대조군 방향으로 적중률·ROI는 양수, 로그손실·Brier는 음수가 후보에 유리하다. 주별 블록을 1,000번 복원 추출한 백분위 95% 구간이며, p값은 표본 차이의 부호가 0 이하/이상인 비율 중 작은 값의 두 배(최대 1)인 기술적 부호 재표집 값으로 정식 중심화 영가설 검정이 아니다. 0은 1/1000 미만을 뜻하며 정확히 0의 확률을 뜻하지 않는다.

## 모델과 신규성

승무패의 역배당을 정규화하고 이에 맞춘 두 Poisson 평균을 공통 입력으로 한다. Gaussian copula는 Poisson 누적분포를 정규 copula로 결합하고 격자 차분으로 셀 확률을 얻는다. 2023~2024 실제 점수의 우도로 단일 rho=0.10359를 추정했다. 다른 후보는 같은 평균의 양 팀 강도에 1±0.18272를 같은 확률로 곱한 두 독립 Poisson 분포의 공통 충격 혼합이다. 이는 명시적인 2성분 혼합이지 최대엔트로피 최적화로 증명된 모델이 아니다. 두 후보는 결과를 검증·평가기에 반영하지 않고 2024년 이후 동결한다. 보정 자체나 승무패 가격의 사전 수신은 입증되지 않았다.

동일 정보의 승무패 Poisson, 승무패 Poisson과 copula의 50:50 고정 확률 혼합을 비교했다. 직접 상품 시장은 해당 상품의 추가 가격을 사용한다. 기존 세 상품 입력 Poisson·Dixon–Coles·KL도 강한 참조군이지만, 추가 정보를 사용하므로 차이를 분포 형태의 순수 효과로 해석할 수 없다. 3-way 무승부를 따로 보존한다. 승무패/핸디캡의 인덱스는 홈/무/원정, 언더오버는 언더/오버다. 프로토 정수 3-way 핸디캡과 반점 총점만 사용하며 축구 정규시간 기준이다. 다른 종목 연장 규칙에는 적용하지 않았다.

기존 `docs/research/2026-10-01-dc-report.md`, `2026-10-01-score-tournament-report.md`, KL 실험 README와 `src/cross_market_edge.py`를 점검했다. 기본 Poisson/DC와 시장 적합, KL 투영은 기존 연구다. 여기는 공통 상관 copula와 평균 보존 공통 강도 혼합의 제한된 비교이며 copula나 혼합 분포 자체의 독창성을 주장하지 않는다. [van der Wurp 등 원문](https://arxiv.org/abs/1908.00823)은 이산 카운트의 copula 결합 회귀를 다룬다. 여기서는 그 결합 아이디어만 적용하고 논문의 공동 회귀·추정 알고리즘은 재현하지 않는다. [McHale와 Scarf의 논문 초록](https://www.statmod.org/smij/Vol11/Iss3/McHale/Abstract.html)도 득점의 주변분포와 copula 결합을 설명한다. 공통 충격 혼합은 본 실험의 간단한 구성으로 특정 논문의 재현이나 최대엔트로피 모델이 아니다. CMP와 농구 Student-t는 자료·정산 검증 및 적절한 대조군 구축을 마치지 못해 구현하거나 효과를 주장하지 않는다.

## 자료, 시점 및 한계

KL 연구 작업공간의 `experiments/kl-projection-20261108/predictions.json`을 입력으로 사용한다. 원시 `games.csv.tmp`의 SHA-256은 KL 기록 기준 `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`이며 입력 파생 파일 해시는 summary에 기록한다. KL 입력 로더는 충돌 재발행 316건과 원본 유효하지 않은 1,524행을 제외했고, 세 상품 부족·중복 127경기를 제외했다. 정확한 상품과 점수 일치 여부는 그 선행 로더에 의존하며 이 실험에서 원시 자료부터 재검증하지 않았다. 대조군별 경기 ID·상품·배당·결과 일치와 Decimal 정산은 별도 검사했다. 점수·가격·선수·픽스터 입력을 갖춘 운영 모델의 재현이 아니다. 가격은 날짜 수준의 회고 자료이고 실제 수신·경기 전 판매·구매 가능성은 미확인이다. 기권/결측의 전체 원천 분모와 리그명 오염 규모는 독립 재감사하지 못했다. 두 리그만 선행 로더가 선택했으며 일반 승패의 무승부 제외를 적용하지 않고 3-way 무승부를 보존한다.

공식 결과 최초 가용 시각이 미확인이므로 업데이트가 있다면 결과일+4일 이후만 허용한다는 가정을 사용한다. 실제 본 실행은 2024년 말 학습 후 검증·평가 동안 업데이트가 없어 같은 날·주말·월말 결과와 미래 시즌 통계를 사용하지 않는다. 경계 테스트는 이 날짜 규칙 자체를 확인하며 실시간 데이터 도착을 입증하지 않는다. 두 모델은 0~13 점수 격자로 계산한다. copula는 마지막 셀에 잔여 꼬리를 모으고 혼합은 절단 후 정규화한다. 0~19 확대 비교는 대표 평균에서 확인했으며 모든 경기 및 극단 평균에 대한 완전한 오차 상한은 아니다. 16점 구적 및 부동소수점 보정으로 근사한다.

`predictions.jsonl.gz`는 event_id/day/sport/league/y/odds/market_p/model/p/pick/hit/net과 홈·원정·상품·기준점을 보존한다. 손익은 1단위, 적중 시 배당−1, 실패 시 −1이다. 이 데이터는 환불 상품을 포함하지 않으며 실제 베팅, 모의 지갑, 수익성 또는 운영 추천을 뜻하지 않는다.

## 재현

```powershell
$env:OPENBLAS_NUM_THREADS='1'; $env:OMP_NUM_THREADS='1'
python -X utf8 experiments/copula-tail-20261108b/run.py --input <KL-predictions.json> --out experiments/copula-tail-20261108b
python -m pytest -q experiments/copula-tail-20261108b/test_copula_tail.py
```

입력 파생 파일은 별도 KL 작업공간에 있으며 원천 대용량을 이 PR에 추가하지 않았다. 코드와 결과는 연구용이며 배포·운영 채택을 요청하지 않는다.
