# 적중률 개선 작업 — 2026-09-08

이 작업은 두 부분을 분리한다. 운영의 확인된 확률 검증/원장 누락은 수정하지만,
새 예측 모델의 성능은 과거 데이터를 통해 검증한다. 낮은 하루 적중률만으로
운영 가중치나 추천 문턱을 바꾸지 않는다.

## 운영 코드 수정

- 최종 확률이 유효하지 않으면 유효한 시장 확률에만 되돌아간다.
  모든 확률이 잘못된 후보는 추천에서 제외하며, 누락을 0%로 위장하지 않는다.
- 사전 추천을 저장할 때 원본 관측 시각, 시장 기준 확률, 확률 출처,
  모델/판단 식별자, 검증 여부, 불확실성 근거 등 이미 있는 정보를 함께 보존한다.
- T-30 이후 원장과 기존 레거시 기록은 새 정보로 덮어쓰지 않는다.
  원자료 시각을 발행 시각에서 추정하거나 모델 승인 표식을 만들지 않는다.
- 추천 문턱 55%/60%, 리그 상위 3개 규칙, 1.50 우선/2.20 미만 조건,
  시장 최유력 선택 규칙 및 모델 승격 차단은 유지한다.

오늘 추천 5/11=45.5%는 유효한 확률을 가진 실제 사전 추천의 결과다.
위 검증 누락 때문에 오늘 패배했다고 입증된 것은 아니며, 이 수정으로 과거 적중률이
올랐다고 주장하지 않는다. 오래된 소스가 새 발행 시각으로 포장될 수 있는 경로도
관찰했지만, 오늘 11픽의 입력 노후화는 입증하지 못했다. 이번에는 근거 보존을 보강한다.

## 새 모델

- CatBoost 1.2.10의 얕은 비선형 잔차 모델. 학습 기준값은 시장 확률 logit이다.
- 시장 정보만 쓴 대조 모델과, 최근 팀 정보 23개를 추가한 모델을 구분한다.
- 팀별 최근 최대 20경기, 180일 이내 득점/실점 평균·표준편차, 승률,
  휴식일, 표본 수, 상대와의 차이 및 누락 지표를 사용한다.
- 종목·리그·시장·선택지 수별로 독립 학습한다. 3-way도 최유력 후보의 적중 여부를
  학습하는 이진 모델이지 모든 방향의 다중분류 확률이 아니다.
- 분기마다 과거 최대 730일로 다시 학습한다. 7일 embargo와 180일 반감기,
  깊이 3, 200 trees, learning rate 0.03, leaf L2 30을 실행 전에 고정했다.
- 2024년 순차 외부 예측으로 혼합 비중 0/0.25/0.5/1을 고른다.
  최저 log loss 모델의 4주 달력 블록 표준오차 이내에서는 더 작은 비중을 택한다.
  이 혼합 비중은 2025~2026 평가 결과로 바꾸지 않는다.
- 시장 기준, 시장 비선형 보정, 팀 정보 추가, 내부 검증 혼합의 네 방법을 비교한다.
  같은 실제 프론트 추천 함수를 호출하고 정답은 선택 후에만 평가에 연결한다.

## 검증과 제한

평가 기간은 2025-01-01~2026-08-25다. 원본은 앞선 실험과 동일한 184,473행,
SHA-256 `dfe95c2ace14ee42142ea0c86912b68359bc8ebee9ad3cb566812815bdec0eb0`이다.

추천 적중률뿐 아니라 추천 수·일수, 평균 배당, 저배당 비중, 확률 오차와
동일 금액 단식 ROI를 함께 공개한다. 동일 날짜·종목·리그·마켓·선택지 수·
0.10 배당 구간에서 추천 수를 맞춘 대조도 수행한다.
달력의 빈 주를 보존한 4주 원형 블록 bootstrap 10,000회와 전체 Holm 보정을 사용한다.
현재 프로토콜의 표본 수·추천 유지율·가격·두 연도 개선 조건을 모두 통과해야
과거 개선 신호로 표시하지만, 그래도 운영 승격은 허용하지 않는다.

이미 여러 차례 본 2025~2026년 자료이므로 새로운 미관측 검증이라고 부르지 않는다.
입력의 배당 관측 시각, 발매 가능 여부, 완전한 일별 후보가 없어 과거의 실제
T-30 추천 원장을 재현한 것도 아니다. 확인된 같은 날 결과는 다음 KST 날짜부터
사용한다는 가정이 있으며, 결과 공개 시각까지 확인된 것은 아니다.
선발·불펜·라인업·xG·부상 정보는 없는 값을 만들지 않는다.
배당 가격이 지워진 취소 경기는 당시 후보 여부를 복원할 수 없다.
동일 시장의 동률 최유력은 원래 선택 순서의 첫 방향을 사용하므로,
이전 전체 선택지 실험과 완전히 동일한 모집단/타이브레이크가 아니다.

## 재현

전용 가상환경에서 선택 의존성 `requirements-research.txt`를 설치한다.
운영 수집기의 `requirements.txt`에는 CatBoost를 추가하지 않았다.

```powershell
python -m venv --system-site-packages .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-research.txt
$env:PYTHONIOENCODING='utf-8'
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
.\.venv\Scripts\python.exe src/nonlinear_accuracy_lab.py --games <보관-games.csv> --protocol experiments/nonlinear-accuracy-20260908/protocol.json --output <새-report.json> --workers 4
.\.venv\Scripts\python.exe -m pytest -q
npm test --prefix web
```

JSON과 같은 이름의 Markdown 보고서가 함께 생성된다. 출력이 이미 있으면 덮어쓰지 않는다.
입력·프로토콜·관련 코드 해시를 실행 전후에 비교하고 변경되었으면 저장하지 않는다.
전체 학습은 로컬의 격리된 데이터/가상환경에서만 실행하며 DB나 서버에 쓰지 않는다.

## 실행에서 확인한 내용

- 첫 실행은 20,037실경기 / 61,678시장 후보를 평가했다.
  현재 정책 기준은 4,122/7,250 = 56.86%, 시장 비선형 보정 4,749/8,516 = 55.77%,
  팀 정보 추가 4,933/9,133 = 54.01%였다. 새 모델 적용을 지지하지 않는다.
- 팀 정보 모델의 추천 평균 예측은 64.19%인데 실제는 54.01%였다.
  같은 수/배당 구간 대조에서도 3,891/7,071 대 기준 3,950/7,071로 개선되지 않았다.
- 내부 혼합 선택이 가능한 범위는 32개였고 모두 시장 기준(혼합 비중 0)을 선택했다.
  나머지 277개는 내부 표본 부족으로 돌아간 것이며 모델 실패로 세지 않는다.
- 추천 정책/모집단/동률 처리가 완전히 같지 않으므로 #213의 4,124/7,251와
  이번 기준을 섞어서 개선량을 계산하지 않는다. 모든 비교는 이번 동일 입력 안에서 수행한다.
- 리뷰에서 취소만 있는 주가 최소 평가 기간을 채울 수 있는 검증기 결함을 발견해,
  별도 `settled_weeks`를 사용하도록 수정하고 회귀 테스트를 추가했다.
  bootstrap에는 빈 달력 주를 계속 유지한다. 실제 이번 평가의 취소 후보는 0개지만,
  향후 자료에서는 잘못된 운영 후보 판정을 막기 위해 필요한 수정이다.
- 첫 결과는 격리 빌드 폴더의 `initial-report.json/md`로 보존했고,
  수정된 최종 코드와 2 worker로 같은 실험을 재실행했다. 모델 설정과 평가 문턱은 바꾸지 않았다.

## 최종 검증

  연구용 의존성은 운영 배포 의존성과 별도로 관리한다.

통계 해상도에도 제한이 있다. 679개 계획 비교 중 유한 p값은 623개다.
10,000회 재표집의 최소 p=1/10,001에 전체 Holm 보정을 적용하면 최소 0.06229여서
이번 해상도로는 5% 유의성 문턱을 통과할 수 없다. 향후 미리 정한 프로토콜에서는
재표집 수를 더 크게 잡아야 한다. 따라서 “통과 0개”를 모든 리그에서 효과가 없다는
증명으로 읽으면 안 된다. 이번 비채택 판단은 전체 원시 적중률 감소, 내부 혼합 비중 0,
추천 수·가격대 대조 결과도 함께 근거로 삼는다. 양의 개별 CI가 나온 여섯 비교의
가장 작은 p값도 약 0.008이어서 이번 재표집 하한에 잘린 유리한 결과는 아니었다.

실험 산출물은 검토용이다. 과거 배당 관측 시점과 실제 미관측 사전 후보가 없는 상태에서
