# K리그1 선수합과 선수쌍의 경기 단위 축소 모형

실제 선수 ID를 연결해 새 변수를 만든 회고 연구다. 득점/교체 시각과 출전 구간이 없으므로 possession RAPM이라고 부르지 않는다. 기존 `src/lineup_soccer.py`의 인원 교체/비주전 집계와 `src/lineup_edge.py`의 비주전 인원 필터와 달리 선수 ID별 공격·수비 효과와 같은 팀 선수쌍을 직접 적합했다. 계수는 인과적 개인 기여도가 아니다.

## 입력과 연결

원자료는 기존 `kbo-player-model-20261103/data/raw/detail/kleague_soccer_2023_2026.json`이다. 이름과 달리 K리그 축구 자료로 816경기의 선발11명 ID/위치 순서·팀·점수가 있다. `src/game_detail.py`에서 확인한 Naver Sports `/schedule/games/{gameId}/lineup` 파생 캐시이며 **공식 리그 HTTP 원문이나 당시 수신 시각을 이번에 증명한 자료가 아니다**. `changed`, 득점, 카드, 사후 교체 선수 필드는 입력에 쓰지 않았다. 해시는 summary에 있다.

같은 날짜·고정 별칭의 홈/원정으로 보존 프로토 K리그1 일반 승무패 가격 archive와 유일하게 연결하고 결과 방향을 대조했다. source fixture ID가 두 원천에서 같다는 뜻은 아니며 실제 원가격 수신·구매 가능성은 미증명이다. 홈/무/원 세 방향을 모두 보존했다. 가격 없는 취소를 포함한 완전 기회 모집단은 아니다.

2023년228, 2024년228, 2025년227, 2026년106경기, 합계789경기가 연결됐다. 2026년 가격26건은 명단 원천과 연결하지 못했다. 학습은2025-12-27까지683경기이고, 2026년106경기 중 이전 명단이 없는1경기를 모든 대조군에서 함께 제외해 **105경기(2026-02-28~07-26)**로 평가했다. 학습·평가의 실제 선수11명 검증과 원점수 방향을 확인했으나 공식 원점수 HTTP 전체를 독립 검증한 것은 아니다.

두 입력 조건을 구분했다. projected는 경기일+4일 전에 끝났다고 가정한 가장 최근 같은 팀 명단이다. 같은 날·직전3일 또는 평가 경기의 실제 XI를 넣지 않는다. oracle은 사후 기록에 남은 당일 실제 선발을 알았다고 가정한 별도 진단이다. 과거 경기 전 수신이 증명된 실제 XI와 가격의 공통 표본은0이다.

## 모형과 고정 설정

팀 공수·홈 효과를 대조군으로 두고, 선수별 공격·수비 합, 이어서 같은 편 55쌍의 효과를 추가했다. 팀/선수/선수쌍의 L2는각각0.01/0.03/0.1이며 선수와 쌍 입력은각각sqrt(11), sqrt(55)로 나눴다. 계수는683개 과거 경기에서만 적합했다. 원래 득점 Poisson 모형의 성적이 약한 것을 본 뒤, 시장 log-probability offset의 다항 로짓 ablation도 추가했다. **이 설계 반복을 사전등록한 독립 확인 실험으로 소개하지 않는다.** 평가 구간으로 규제 강도를 고르거나 다시 튜닝하지 않았고 처음 실패한 결과도 보존했다.

Poisson 모형은0~40점 격자에서 홈/무/원 확률을 합산한다. 시장 결합형은 동일 경기의 원시장 세 확률을 offset으로 두고 같은 입력 블록을 추가한다. 원가격 기준 argmax 방향 가상1단위로 정산하며 모의 지갑과 실제 추천은 바꾸지 않는다.

## 결과

같은105경기에서 직접 시장은48/105적중(45.71%), ROI−12.49%, 로그손실1.05100이었다.

시장 offset에 팀 정보만 더한 대조군은42.86%, ROI−18.15%다. 이전 명단의 선수합 모형과 선수쌍 모형은 모두45/105적중(42.86%), ROI−18.00%였다. 두 모형의 픽은 한 건도 다르지 않았고, 선수쌍의 로그손실도1.08080에서1.08118로 약간 악화했다.

사후 실제 XI를 안다는 시장 결합 oracle도 개선되지 않았다. 선수합40/105(38.10%), ROI−28.98%; 선수쌍39/105(37.14%), ROI−31.10%였다. 원래 시장을 쓰지 않는 점수 모형은 선수합/쌍 projected 모두33.33%, ROI각각−33.08/−33.16%로 더 나빴다. 전체11개 후보·대조군 결과를 summary와 경기별 예측에 보존했다.

선수쌍의 projected-vs-additive 비교에서 시장 결합형은 같은 픽이어서 적중률·ROI 차이가0이다. 비시장 점수 모형은2픽이 바뀌고 ROI차이는−0.09%p, 주별95%구간은−6.76~+5.84%p였다. 명목 구간이며 다중비교·반복 사용 자료를 보정한 미래 성능 보장이 아니다.

## 왜 차이를 만들기 어려웠나

학습 선수는626명, 같은 팀 선수쌍은10,655쌍이다. 평가의 실제 선수 출현 중19.44%는 학습에 없었고, 실제 선수쌍 출현 중54.03%는 처음 보는 쌍이었다(이 출현들의 학습 빈도 중앙값0). 실제 XI와 이전 명단의 차이는팀당평균3.31명이다. 관측된 지원 부족이며 이것만으로 성능 악화의 인과 원인을 입증한 것은 아니다. 출전 구간 없는 경기 단위 점수로 팀·선수·상대·조합의 효과를 분리하기 어렵다는 모형 한계도 있다. 이번 모형의 실패가 실제 선발 정보가 무의미하다는 뜻은 아니다.
