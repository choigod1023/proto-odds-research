# KBO 실제 명단 기반 paired 연구 입력

상태: `ready_for_model_worker`. 상위 계약 `c5407e9b`, SHA-256 `512c6172eb792ed6e5f7afe7b90d4cfaa0e4087b05e0a497ec7cf9a997cb2480`에 따라 2023~2025년 학습·검증용 입력과 2026년 평가용 입력을 고정했다. 모델 적합·예측·성과 계산·운영 변경·병합·배포는 수행하지 않았다.

- `paired-train-projected.jsonl.gz` / `paired-train-actual.jsonl.gz`: 동일 2,182경기. 2023년 723, 2024년 728, 2025년 731경기다. 2025년은 검증용이며 7일 embargo와 최종 분할은 모델 단계에서 적용한다.
- `paired-test-projected.jsonl.gz` / `paired-test-actual.jsonl.gz`: 2026년 기존 709경기 전부에서 실제 선발을 공식 경기 기록과 대조한 동일 평가 집합이다.
- `paired-inputs-manifest.json`: 정확한 파일 해시와 원천 커밋·원문 해시, 다섯 제외 경기의 ID와 사유, 연도별 선택자 일치 집계, 검증 범위를 포함한다.
- `paired-inputs-handoff.json`: 모델 워커용 파일 경로·해시·스키마·재생성 및 감사 명령이다.

예상과 실제 양쪽은 같은 경기, 과거 원천, 대상 이전 달력일, 최근 10개 완전 관측과 팀·휴식·구장 등 비선수 특징을 사용한다. 두 선택자에 같은 선수가 있으면 선수 이력의 정규화된 JSON 바이트가 일치한다. 0은 관측으로 남기고 결측은 0으로 대체하지 않는다. 명단 미확정으로 학습 행에서 제외한 2025년 5경기도 검증된 선수 성적은 이후 날짜의 과거 이력으로 남긴다. 공식 타순은 확인된 명단이며 발표 후 실제 타순 변경 여부는 입증되지 않았다. 실제 투수 선발은 공식 경기기록의 선발 표시를 대조했다.

전수 독립 감사 `audit_paired_inputs.py`에서 학습 2,182쌍, 평가 709쌍, 두 선택자 공통 타자 이력 41,152개, 누락 경기 5개를 확인했다. 제외 경기의 이후 이력 참조는 중복 참조를 포함해 1,843건이다. 2023~2026년 대상일·미래 선수 성적 변조 검사와 원문·프로필·선발 표시 감사도 통과했다.

2024년 원천 수집 중 두 프로세스가 겹쳐 요청 간격 1.5초 미만이 128건 발생했다. 생산자 측은 중복 요청을 중단하고 잠금을 적용했으며, 원문 및 Git 바이트를 검증해 이 사실을 manifest에 보존했다. 전체 자료는 현재 공식 자료를 이용한 회고 복원으로, 당시 발표·수신이 검증된 PIT 표본은 0건이다. 2025년 결과를 본 적이 있으므로 독립 블라인드 표본으로 주장하지 않는다.
