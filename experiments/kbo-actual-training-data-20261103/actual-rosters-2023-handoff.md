# 2023 공식 실제 명단 소스 handoff

상태: 2023 소스 한정 고정 완료. 전체 paired 입력 및 2026 검증은 아직 진행 중이다.

PR511 `13291d23e855e0d500327cb39ac64a480e395837`의 2023년 고정 723경기 모두에서 양 팀 공식 확정 타순(선수 13,014슬롯)과 실제 선발(1,446팀)을 검증했다. 공식 원문 1,902개를 함께 보존했다. 기존 아카이브의 14개 연도 대체 별칭은 원래 경기 날짜·팀·더블헤더 순번을 공식 G_ID와 일대일로 대조했다. 한 경기의 시작 시각 차이는 별도로 보존했다. 7개 팀 선발은 일정의 과거 이름과 공식 경기 기록의 현재 이름이 달랐지만 공식 투수 프로필과 동일 경기 ID 대조로 같은 선수 ID를 확인했으며 두 이름과 원래 보류 사유를 남겼다.

- 명단 `actual-rosters-2023.jsonl.gz`: SHA-256 `53ea290c9bfe40dd792ddfd6b952faae4ee2d151176e0729a00abd8d216c9ff4`
- 공식 원문 `actual-rosters-2023-raw.jsonl.gz`: SHA-256 `f8d07586349e907d5acaa16103b5648489d452f1e533652715108e9b40b4ef15`
- 상세 분모 및 정책: `actual-rosters-2023-manifest.json`

공식 현재 응답의 수신 시각과 원문 SHA를 유지하되 과거 발표·수신을 증명하지 않는다. 같은 경기 사후 기록은 타순 이름과 선수 ID의 식별 연결에만 사용했으며 경기 성적과 점수는 입력 특징이 아니다. 최종 명단의 `status`는 complete 또는 excluded이며 complete가 아니면 대체 추정을 하지 않는다.

검증: `python experiments/kbo-actual-training-data-20261103/audit_rosters_2023.py`는 원문 1,902개, 타자 ID 13,014개, 실제 선발 1,446개를 다시 대조했다. `audit_lineups_2023.py`는 대상 723경기, 14개 별칭, 시각 불일치 1개를 검증했다. 모델 학습과 성능 평가는 수행하지 않았다.

독립 paired 입력 재구성 검증에서는 723쌍 모두 같은 경기와 동일한 비선수 특징을 유지했다. 실제 타순 선수 13,014슬롯 중 150슬롯과 선발 1,446팀 중 75팀은 이전 선수 이력이 없어 결측으로 유지한다. 대상일의 5경기와 미래 경기의 타자·투수 성적을 메모리에서 변조해도 양쪽 입력은 변하지 않았다. 검증 명령은 `test_2023_pairs.py`와 `test_2023_poison.py`다.
