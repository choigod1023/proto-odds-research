픽스터 점수는 작성자 투표 비율이며 보정된 확률이 아니다. 새로운 최적화는 실행하지 않는다.

- PR356에서 혼합 비율 선택에 사용한 28경기의 이벤트 키와 ID 모두 제외한다.
- 기존 표본 마지막 날짜인 2026-09-04 이후 경기만 허용한다.

- 동일 이벤트가 중복되면 전체를 제외한다. 먼저 나온 유리한 결과만 선택하지 않는다.
- 고정 전에 저장된 과거 기록은 retrospective_unseen으로, 고정 후에 저장된 기록은
  prospective로 나눠 보고한다. 과거 표본이 개발 파일에 없다는 것만으로 누구도 결과를
  보지 않았음을 증명하지는 않는다. 입력은 PR356에서 감사한 MLB 양방향 승패 형식이다.
- 기존 모델, 픽스터 단독, 고정 75:25만 비교한다. 결과를 보고 비율을 바꾸지 않는다.
