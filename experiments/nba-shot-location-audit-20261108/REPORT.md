# ESPN NBA 보존 PBP 슛 위치 검증 (연구 전용)

## 범위와 결과

2026-11-08 수신된 ESPN scoreboard 400건과 summary 2,365건을 로컬 보존본에서 읽었다. 신규 수집과 예측·수익률 평가는 하지 않았다. 정상 200 본문은 scoreboard 400/400, summary 2,357/2,357의 SHA-256이 영수증과 일치했다. summary 404 8건은 영수증으로 보존되어 있고 응답 본문이 없어 본문 해시는 검증 대상이 아니다. 개별 영수증과 원문 해시 및 검증 결과는 `receipt_hashes.json`에 있다.

ESPN의 NBA 30개 팀 약칭, 경기 ID, 양 팀 홈/원정, scoreboard와 summary의 UTC 시각을 대조했다. 통과한 경기는 2343경기, 비NBA 팀 등의 제외는 14건이다. 대상 기간은 2024-12-31T20:00Z ~ 2026-10-28T03:00Z다. 한국어 원본 팀명은 변경하거나 재해석하지 않았다. 경기별 플레이 ID 중복 및 누락은 각각 0, 0건이었다. 다만 단일 스냅샷만 있어 동일 ID의 이전 버전 수정 여부는 확인하지 못한다.

슛 플래그 526,860개 중 보수적인 설명/점수 필터를 통과한 1점 108,830, 2점 242,578, 3점 175,443개다. 2·3점 좌표는 418,021개에 있었고 명시적 거리 문구는 306,042개에 있었다. 블록된 슛 22,689개를 슈터 팀의 실패로 센다. 3점 12,196개는 설명문에 3점이라는 문구가 없어서 `pointsAttempted`와 득점 플래그를 사용했다. 성공 여부는 `scoringPlay`, 시도 점수는 `pointsAttempted`이며 실패 슛의 `scoreValue=0`을 시도 점수로 사용하지 않는다. 모호한 슛 이벤트 9개는 제외했다.

4,686 팀-경기 중 FGA/FGM/3PA/3PM/FTA/FTM 모두 팀 최종 박스와 일치한 경우 3,505개, 불일치는 1,181개다. 가장 흔한 차이는 PBP 3PA가 박스보다 1개 많은 945팀-경기, FGA가 1개 많은 934팀-경기다. 이 두 수는 서로 중복된다. 원인 전체는 아직 식별하지 못했으며 강제로 보정하지 않았다. 예를 들어 401705040의 이벤트 191은 자유투 유형·득점 값과 설명문이 충돌하고, 192는 실패 점수 값과 성공 설명이 충돌한다. 해당 이벤트를 추측해 복원하지 않았다. 마지막 PBP 점수는 2,318경기에서 최종 점수와 같고 25경기에서 다르다. 전 이벤트의 점수 감소 480건과 직전 점수차·scoreValue 불일치 1036건은 수정 또는 순서/기록 불일치의 신호이지 확정 원인 분류가 아니다.

분모를 좁혀 팀 박스 일치, 게임의 모든 슛 명확, ID 중복/누락 없음, 최종 점수 및 개별 점수차 일치를 모두 만족한 팀-경기는 3,044개이며 1,642개는 제외했다. `game_team_audit.jsonl.gz`에는 양쪽 모두와 제외 사유, 기간별 PBP 집계와 최종 팀 박스 차이를 남겼다. 기간별 공식 박스 대조는 자료를 확인하지 못해 수행하지 않았다. 어느 행도 좌표 존을 인증한 것이 아니며 `zones`는 null이다. 5인 라인업은 검증하지 않았다.

## 좌표 기하 교차 검사

[공식 NBA 코트 규칙](https://official.nba.com/rule-no-1-court-dimensions-equipment/)을 기준 맥락으로 삼되 ESPN 좌표 문서나 단위를 확인하지 못했다. 서로 다른 축, 1과 0.1 배율, 반코트/풀코트, 골대 y=0과 y=5.25 가설 각각에 대해 텍스트의 명시된 정수 피트 거리와 오차를 계산했다. 가설은 예측 적중률에 의해 선택하지 않았다. 코트상의 골대 위치 가설과 공급자 내부 원점을 분리해야 한다.

306,042개에서 `(x,y)` 배율 1, 골대 (25,0), 반코트 가설의 절대오차 중앙값 0.649ft, 평균 0.667ft, 5ft 초과 0.000%였다. 골대 (25,5.25)의 같은 가설은 중앙값 2.963ft, 5ft 초과 3.145%였다. 모든 16개 가설과 예시는 `results.json`에 있다. 낮은 오차는 제공자 내부 거리와 일치하는 후보가 있다는 증거이나 공식 단위·방향·원점 또는 개별 좌표의 정확성 인증이 아니다. 거리 문구가 없는 슛에는 이 검사를 적용하지 못했다. 코너 3·림·중거리 구역은 모두 보류한다.

## 재현 및 사용 경계

```
python scripts/audit_nba_shots.py --archive <보존본_디렉터리> --out <출력_디렉터리>
python -m unittest scripts.test_audit_nba_shots -v
```

원문 대량 배포 없이 경기별 파생 집계만 보존했다. 원문은 별도 보존본에서 읽으며 404 본문을 생성하지 않는다. 결과는 사후 ESPN 수신본이며 당시 경기 전 가용성을 증명하지 않는다. 사전 예측에는 목표 경기의 슛을 사용할 수 없고, 과거 경기 D-4 이력만 후보로 사용할 수 있다. D-4는 보수적인 대리 기준일 뿐 실제 가용 시각의 증거가 아니다. 존 입력, 예측 적중률, ROI 향상, 실전 수익성은 검증하지 않았다.
