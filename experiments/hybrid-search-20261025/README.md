# 하이브리드 후보 탐색 — 2026-10-25

로컬 연구용 코드이며 운영 추천·배포·모의 계좌를 변경하지 않았다.

## 구현

- 기존 모델 단독, 픽스터 단독을 기준으로 둔다.
- 픽스터 비중 5~95%, 5% 간격의 19개 가중치.
- 확률 점수의 산술 혼합 / 로그오즈 혼합 2종.
- 작성자 수에 따라 픽스터 점수를 50%로 축소하는 강도 0/5/20.
- 서로 반대편을 선택할 때 픽스터 가중치를 절반으로 줄이는 처리 켜기/끄기.
- 총 228개 하이브리드 + 단독 모델 2개 = 230개 후보.

무작위성을 추가하지 않는다. 작성자 득표 비율은 보정된 승률이 아니며, 혼합 결과도
검증 전에는 확률로 신뢰하면 안 된다. 종목별 가중치 학습은 구현/평가하지 않았다.

## 선택 규칙과 범위

경기 날짜 순으로 60/20/20%를 나눈다. 고정 후보는 학습을 하지 않으며 첫 구간은 향후
학습용으로 예약한다. 검증 구간 Brier 오차 최소, 동점이면 ROI 최대를 선택 기준으로
고정했다. 최종 평가 구간은 선택된 후보와 단독 기준 두 개만 비교한다.
이는 수익률을 최대화하는 전역 최적해가 아니라 확률 점수 정확도를 우선한 후보 선별이다.
최소 30일, 각 구간 100경기를 충족하지 않으면 승자를 반환하지 않는다. 이 최소치는
통계적 유의성의 보장이 아니다. 충분한 자료 확보 후 시계열 재검증과 독립 모의 운용이 필요하다.

현 구현의 ROI는 단폴 동일 금액 진단용이다. 2폴·월별 낙폭·손실 중단의 성과 검증은
아직 완료하지 않았다. 월 손실 5만원이라는 기존 정책은 변경하지 않았다.

## 실제 실행 결과

PR354의 고정 정오 대조 결과를 입력으로 사용했다. `results.json`에 입력 SHA256을 남겼다.
공통 유효 경기 0개여서 `blocked_insufficient_paired_data`, 최적 후보 및 평가값은 null이다.
230개 후보의 실제 성능을 평가했다는 뜻이 아니다. 합성 데이터는 코드 테스트에만 사용했다.
따라서 적중률·ROI 개선폭과 최적 혼합 비율은 아직 알 수 없다.
