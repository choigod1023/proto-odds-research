# 공개 픽스터 1차 수집·로컬 비교 (2026-10-24)

## 판정

**채택 근거 없음. 탐색 실험이며 운영 모델 개선 검증은 미완료.**

22개 공개 분석글의 승패 선택을 수작업 구조화했다. 20개는 아톰티비의
2025년 경기, 2개는 킹콩티비의 2026-10-24 경기다. 검색으로 발견한 편의표본이며
전체 게시판, 전체 픽스터 또는 모든 기간을 대표하지 않는다. 본문 복제 대신
URL 식별자, 경기 날짜, 팀, 선택, 화면 시각 및 모순 여부만 보관한다.

15경기에서 기존 로컬 정산 데이터와 연결했다. 제외 7건: 카드/본문 모순 3건,
정제된 승패 데이터와 연결되지 않은 과거 경기 2건, 기간 밖 10월 경기 2건.
모든 글은 경기 후 수집했으므로 **경기 전 원문이 검증된 표본은 0건**이다.
글 옆 시각은 실제 최초 공개 시각인지 검증하지 않았으며, 아톰의 수집 글에서는
경기 일정과 같은 시각이 표시된다. 이를 경기 전 게시 시각으로 간주하지 않는다.

## 동일 표본 결과

주 비교는 결과 확인 전 정한 logit +0.25 가산이다. 별도 학습한 픽스터 모델이
아니라 기존 연구 모델에 명시적 승패 의견을 가산한 최소 실험이다.

- 야구 10경기: 기준 3/10(30%), ROI -53.30%; 의견 추가 3/10(30%), -51.10%.
  적중률 차이 0%p, ROI 차이 +2.20%p. 선택 2건 변경.
- 농구 3경기: 기준 2/3(66.67%), ROI -1.33%; 의견 추가 1/3(33.33%), -56.67%.
  적중률 차이 -33.33%p, ROI 차이 -55.33%p. 선택 1건 변경.
- 축구 2경기: 기준과 의견 추가 모두 1/2(50%), ROI -30.50%. 선택 변경 없음.
- 배구: 연결 가능한 완료 경기 0건. 적중률/ROI 미산출(0%가 아님).

약한 가산 +0.1과 강한 가산 +0.5도 모두 results.json에 공개했다.
+0.1에서 야구는 변화가 없고, 농구 악화와 축구 무변화는 동일하다.
좋게 나온 가산 강도만 고르거나 이 표본에 맞춰 튜닝하지 않았다.

ROI는 선택한 승패 시장에 동일 1단위를 걸었을 때 `mean(배당×적중 - 1)`이다.
대조군과 실험군에 같은 경기·같은 데이터의 배당을 사용했다. 단폴 단위수익률이며
2폴 수익, 실제 구매 가능한 배당, 월 수익, 월 손실 제한 모의계좌의 결과가 아니다.
운영 및 월 손실 5만 원 한도는 변경하지 않았다.

## 기준 모델과 한계

기준은 PR #341에서도 사용한 `sport_hybrid_validation.fit(..., offset=True)`의
시장확률 + 종목별 과거 경기 피처 연구 모델이다. 2023~2024년 자료로 학습하고
2025년 수집 경기만 평가했다. 당시에 동결해 저장한 운영 추천을 재현한 것은 아니다.
따라서 **현재 사이트 추천 vs 새 모델의 실전 비교라고 부르면 안 된다.**

피처는 elo_diff 및 model_v2.SPORT_FEATURES이고, 외부 글의 선택에 고정 logit 신호를
더했다. 본문의 부상·선발·최근 부진을 공식 기록과 검증해 추가하는 텍스트/사실
피처 실험은 아직 하지 않았다. 이 실험의 실패가 그러한 정보의 무용함을 뜻하지 않는다.

기존 games.csv의 정산 결과를 사용했으며 이번 작업에서 15경기 공식 리그 원장을
독립적으로 재조회하지는 않았다. 입력 해시, 학습 종료일, 원문 URL, 경기별 배당,
정산 선택지, 기준 확률, 각 정책의 선택은 results.json에 남겼다.

작은 검색 표본/사후 수정 가능성/삭제 및 검색 노출 편향/배당 관측 시각 미검증으로
유의미한 개선이나 미래 수익을 입증할 수 없다. 수치가 나왔다는 사실과
누수 없는 성능 검증에 성공했다는 주장을 분리한다.

## 품질 문제의 직접 근거

- https://www.attv24.com/sports_analysis/16051 : 상단 NC, 본문 SSG 우위. 제외.
- https://www.attv24.com/sports_analysis/14759 : 상단 서울, 본문 포항 승리. 제외.
- https://www.attv24.com/sports_analysis/19147 : 상단 김포, 본문 무승부. 제외.
- 과거 원문 예: https://www.attv24.com/sports_analysis/19024
- 현재 원문 예: https://www.goli.tv/board/analysis/297857?page=1

전체 출처는 picks.csv의 source/id에서 생성한 results.json audit.url에 있다.
픽스터 작성자는 아톰티비 `분석관리자`, 킹콩티비 `호나우두`로 표시됐다.
실제 독립 저자 수는 알 수 없고, 이번 동일 표본은 아톰티비 한 출처뿐이다.

## 수집 경로

사용자가 지정한 세 사이트를 조사했다. 로컬 requests의 goli HTTPS는 연결 리셋,
이전 브라우저 확인에서도 첫 번째 한글 도메인과 attv24는 연결 리셋이었다.
공개 웹 검색/페이지 열기 결과에서 읽힌 분석을 수작업 구조화했다.
킹콩의 최신 글과 아톰의 과거 분석은 읽혔지만, 아톰 배구 과거 글 검색은
결과/뉴스 페이지가 주로 반환되어 추천 선택을 확보하지 못했다.
접근 제한을 우회하거나 무단 대량 크롤링하지 않았다. 자동 수집기는 구현하지 않았다.

   반영한 2폴 모의운용으로 확장한다. 그 전까지 운영 추천은 변경하지 않는다.
