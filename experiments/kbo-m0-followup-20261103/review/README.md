상태: `independent_review_complete`. 공통 계약 `0fe05367fc85e71f2df2784c6ddf50fb017bcba2`과 원천 `ed11ca0561e485319f2b951409287f42167f42b5`을 검사했다. 지정 원천 파일 15개의 Git blob과 복사본 SHA-256이 같고, `fit2023-labels.jsonl.gz`의 723개는 기존 고정 개발 레이블의 2023 부분과 정확히 같다. 2024 평가 대상은 728경기이며 2024 첫 경기 2024-03-23 기준 7일 경계는 2024-03-16, 적격 2023 학습은 723경기다.

## 레이블·기존 계수 노출

별도의 2023 전용 레이블이 있어도 복사된 `vendor/evolution/common/inputs/development-labels.jsonl.gz`에는 2023 723개뿐 아니라 **2024 결과 728개와 2025 결과 731개도 들어 있다**. 실제로 해당 `core.load()`를 실행하면 세 연도 레이블 2,182개가 반환된다. 같은 공통 폴더의 `baseline-reference.json`에는 2023~24 학습 1,451경기 모델과 2023~25 학습 2,182경기 모델도 보존돼 있다.

이는 공통 패키지의 접근 경계 문제이며 아직 2024 예측 코드가 2024 결과나 그 결과로 학습한 모델을 사용했다는 뜻은 아니다. 2024 예측 생성에서는 전용 2023 레이블과 2023 학습 행만 전달하고 기존 1,451·2,182경기 적합 모델을 예측에 사용하지 않아야 한다. 특히 `core.load()`는 2024 결과까지 읽으므로, 2024 결과를 예측 동결 전에 **읽지 않았다**고 주장하려면 해당 호출도 피하거나 접근 경로를 별도로 차단한 증거가 필요하다. 평가 레이블과 기준 참조 모델이 물리적으로 존재한다는 사실을 단순 가용성 테스트만으로는 제거할 수 없다. 공통 파일은 변경하지 않았다.

고정된 2024 예측 구현 인계 후에는 2023 전용 레이블 사용 경로, 학습 행·7일 경계·fit 전용 스케일러를 확인하고, 2024·2025 레이블과 기존 미래 학습 모델을 독립적으로 변조하거나 접근을 차단했을 때 예측이 불변인지 검사해야 한다. 접근하지 않았다는 증거와 변조해도 출력에 영향을 주지 않는다는 증거는 구분한다.

2024는 2025에서 이미 선택한 레시피를 앞선 연도에 적용하는 기열람 후향 진단이다. 2025는 레시피 선택에 재사용된 구간이고, 2026 역시 기열람 반기 진단이다. 어느 기간도 새로운 전향 holdout으로 표현하지 않는다. 2024·2025 가격 행은 보존된 원본 market과 대조했다. 과거 가격의 수신·체결 시각은 입증되지 않았다.

전향 기록 구현 전 검증해야 할 사례와 시점 조건은 `prospective-review-checklist.md`에 적었다. 이 문서는 확인 항목이며 아직 새 CLI가 통과했다는 뜻이 아니다. 과거 자료의 피처·공식 명단 감사는 반복 수집하지 않았다.
