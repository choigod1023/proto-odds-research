# KBO M0 고정 혼합안 후속 검증

운영 전환을 뒷받침할 일관된 개선은 확인하지 못했다. 고정 혼합안은 2024년에 기존 M0보다 악화했고 2025·2026년에는 일부 개선했지만, 모든 연도 ROI가 음수이며 차이의 주 단위 95% 구간은 0을 포함했다. 운영 모델은 변경하지 않았다.

## 비교한 모델과 입력

- 기존 M0: 경기 전 이전 날짜의 팀·선수 최근 기록을 입력으로 하는 독립 Poisson 득점 모델, L2=10. 동결된 운영 추천을 재생한 모델이라고 주장하지 않는다.
- shrink: 타자 (H+BB)/(AB+BB) 대리값에 .33/20PA, 투수 ERA에 4.5/27outs 사전값. HBP/SF가 없어 공식 OBP 전체와 같지 않다.
- NB03: 같은 입력과 L2에 NB2 분산 mu+0.3mu², 평균 계수 재적합.
- 혼합안: 기존 M0·shrink·NB03의 무조건부 홈/무/원정 확률을 각각 1/3로 평균한 뒤 무승부 제외 홈/원정 확률을 산출했다. 가중치를 새로 탐색하지 않았다.
- 확정 타순 9명과 실제 선발 기록을 연결한 보관 자료를 썼다. 과거 경기 전 명단 수신 증명이 있는 전향 자료는 아니다. 픽스터 투표·시장 9:1·실제 운영 추천과의 새 비교가 아니다.

## 시계열 분리와 결과

2024년은 2023년 723경기로만 새 계수를 적합해 728경기를 예측했다. 7일 경계 배제와 학습 구간 전용 표준화를 적용하고 평가 라벨·미래 적합 모델 접근을 막았다. 2025년은 2023–24년 1,451경기 학습 후 보관 예측, 2026년은 2023–25년 2,182경기 학습 후 보관 예측을 재사용했다. 모든 연도는 이전 연구에서 이미 본 자료다. 2025년은 후보 선택에 재사용됐고, 2024년 추가 적용도 2025·2026 연구 뒤 정한 레시피의 회고 진단이므로 새 블라인드 검증이 아니다.

적중률 분모는 명단이 연결된 전체 평가 경기(무승부 포함), ROI 분모는 동일 보관 양방향 배당이 있는 경기(환급도 포함)다. 전 경기 단폴 1단위 고정이며 월 손실 제한을 적용한 베팅 정책이나 실제 체결 수익이 아니다. 기존 월 5만 원 모의 원장은 수정하지 않았다.

## 반기 안정성: 사전 지정한 구간 전부

기간별 유리한 모델을 사후 선택하거나 교체하지 않았다. 아래 ROI는 같은 해·같은 반기의 두 모델에 공통으로 존재하는 가격만 비교한다.

- 2024년 상반기: 전체 397 / 가격 386경기, ROI 기존 -9.96% → 혼합 -10.17%.
- 2024년 하반기: 전체 331 / 가격 328경기, ROI 기존 -14.04% → 혼합 -14.99%.
- 2025년 상반기: 전체 395 / 가격 364경기, ROI 기존 -8.28% → 혼합 -5.62%.
- 2025년 하반기: 전체 336 / 가격 312경기, ROI 기존 -10.48% → 혼합 -12.85%.
- 2026년 상반기: 전체 388 / 가격 360경기, ROI 기존 -3.89% → 혼합 -1.12%.
- 2026년 하반기: 전체 321 / 가격 307경기, ROI 기존 -4.90% → 혼합 -5.67%.

2025·2026년 모두 상반기 개선이 하반기에는 역전됐다. 2026년 엄격 가격 연결 439경기 민감도에서도 기존 −6.53%, 혼합 −4.26%로 손실이었다. 연도별 가격 모집단과 선택 조건이 달라 연도 합산 ROI는 제시하지 않는다. 월별 손익·모든 성분·구간별 확률 지표·제외 ID는 results.json에 보존했다.

## 가격 선택 편향과 해석 제한

2024년 무승부 9경기, 2025년 무승부 22경기 전부가 가격 결측 69경기에 포함됐다. 기존 가격 생성기가 void 행을 빼고 사후 최종 점수 일치도 요구했기 때문이다. 1,390개 가격의 과거 관측 시각은 null이며 당시 실제 구매 가능성과 원배당 프로토 상품 동일성·체결 가격을 증명하지 못했다. 현재 공식 일정 점수 재대조와 과거 명단 연결은 이러한 문제를 없애지 않는다. 이 ROI는 사후 선택의 영향을 받은 보관 가격 표본의 조건부 재현이다. 전체 기회의 손실률·미래 기대수익·사용자의 실제 수익으로 해석하면 안 된다.

2026년은 이전 실험의 가격 667경기(무승부 환급 15경기)를 그대로 재사용했다. 이번에 새로 더 수집한 평가 경기로 합산하지 않는다. 신뢰구간은 달력 주를 재표집한 명목 구간이며 반복 연구·다중 비교에 따른 선택을 보정하지 않았다. 0 포함은 동등함의 증명도 아니다.

## 다음에 진행할 실제 후속 검증

1. 확정 선발·확정 타순·이전 날짜의 기록·동일 양방향 상품 배당을 원문에서 검증하는 어댑터를 연결한다. 단순 URL·원문 해시·수신 시각만으로 내용이 공식 사실이라고 인증하지 않는다. 현재 이 어댑터와 자동 실행 스케줄은 연결되지 않았다.
2. 기존 2023–25 계수와 1:1:1 비중을 고정해, 결과를 모르는 새 경기에서 경기 시작 최소 30분 전 첫 완전 입력과 두 예측을 함께 저장한다. 같은 경기·상품의 사후 재가격·예측 덮어쓰기, 당일/미래 기록, 캡처 이후 받은 이력을 거부한다. 30분 정각은 사전 계약의 at least 기준으로 허용한다.
3. 공식 종료·취소 결과는 별도 기록으로 연결하고, 무승부·취소 환급과 결측·실패·배제 사유도 남긴다. 재시작 후에도 처음 기록을 보존한다. 정정은 기존 정산 덮어쓰기로 처리하지 않으며, 별도 정정 절차는 후속 연결 전에 설계해야 한다.
4. 새 적격 정산 200경기와 8주를 모두 채운 첫 시점에서 검토한다. 이 수치는 검토 시작 조건이며 개선을 보장하는 충분 표본 수가 아니다. ROI 차이·적중률·확률 보정·낙폭·기간별 방향을 같은 경기로 비교한다.
5. 우위가 불명확하면 현행을 유지하고 원장을 더 쌓는다. 검토 결과로 자동 모델 채택이나 생산 추천을 변경하지 않는다.

forward.py는 이 계약을 검사하는 로컬 staging CLI다. 원문 내용 인증이 미연결인 동안 모든 예측과 정산을 성과 검증 비적격으로 표시한다. 실제 인증된 전향 정산은 0경기이며 자동 수집을 시작했다고 주장하지 않는다. 테스트용 합성 입력은 임시 경로에서만 사용했고 운영·기존 모의 원장에 넣지 않았다.

이번 공식 공개 조회는 11월 3일 17:16:56–17:17:26 KST의 20요청으로 한정했다. 그 스냅샷에서는 예정 6경기 모두 타순 미확정이었다. 이후 현재 상태를 뜻하지 않는다. sources/README.md와 원문 압축본·요청 기록에 상세 증거가 있다. 배당 연결·실제 전향 예측 실행은 이 조회에 포함되지 않았다.
