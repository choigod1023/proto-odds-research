# 고정 레시피의 2024년 시점 안정성 진단

2025~26 연구 이후 고정한 M0 base L2 10, 선수별 shrink(.33/20 PA와 4.5/27 outs), NB2 alpha 0.3 세 모델을 2023년 실제 명단 723경기로만 학습하고 2024년 실제 명단 728경기를 예측했다. 2024년은 이미 살펴본 과거이므로 독립적인 새 holdout이 아니다. 결과 또는 수익률을 여기서 평가하지 않는다.

선택이나 재튜닝 없이 세 모델의 무조건부 승/무/패 확률을 각각 1/3로 평균하고 그 결과에서 조건부 승패 확률을 계산했다. 사전 계약과 원래 evolution 계약의 해시를 별도 검증한다. 2023년 fit 라벨 파일만 열며 2024년 라벨·가격은 읽지 않는다. 원자료 이력이 각 경기보다 이른지 점검하고 2023년 훈련과 2024년 첫 경기 사이 7일 경계를 검사한다.

미래 또는 미등록 라벨 접근 시 예외를 내는 래퍼를 학습에 사용하며, 각 모델의 표준화와 선수·팀 목록이 학습 행에서만 계산됐는지 독립적으로 비교했다. 예측의 경기 ID, 중복, 확률 범위·합계와 조건부 확률 일관성을 확인했다. 원천 명단 및 경기별 이력은 회고 자료로, 경기 전 실제 수신을 입증하지 않는다.

- `models2023.json`: baseline, shrink, nb03 모델
- `predictions2024.json`: baseline, shrink, nb03, equal_ensemble별 728개 예측
- `manifest.json`: 계약·산출물 SHA-256과 실행 경계
- 재현: `python historical/run.py`; 이미 산출물이 있으면 덮어쓰지 않고 실패한다.
- 테스트: `python -m unittest discover -s experiments/kbo-m0-followup-20261103/historical -p test_*.py -v`

운영 채택, 데이터 수집, 정산, 병합 및 배포는 수행하지 않았다.
