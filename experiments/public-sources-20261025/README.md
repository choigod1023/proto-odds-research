# 공개 분석 원천 연결 실측 (2026-10-25)

`manifest.json`의 실제 기사/목록 2개에 로컬 수집기를 실행했다.
`capture-v2.json`은 최종 파서 실행 결과, `capture.json`은 라인업 이름 문단을
연결하기 전 기록이다. 기존 관측은 덮어쓰지 않았다.

- Sports Mole: robots 확인 후 기사 HTTP 200, 주장 4개 추출.
  부상/출전 가능성 문장 2개, 두 팀 예상 선발 명단 2개다.
  이전 경기의 출전 정지 후 복귀를 다루는 문장도 있으므로 absence 태그는 검색 분류일 뿐
  현재 결장 확정이 아니다. 선수별 정규화 및 공식 확인은 아직 하지 않았다.
- SportsGambler: 로컬 연결 오류로 실패. 파서의 존재와 실서비스 수집 성공을 구분한다.
- 읽은 기사는 과거 게시물이며 실제 관측 시각은 2026-10-25다.
  리뷰된 공식 경기 매핑을 제공하지 않았으므로 연결 records 0건이다.
- 적격 사전 표본 0건, ROI 및 적중률 개선은 미측정(null). 승률 개선을 주장하지 않는다.
- 운영 스케줄, 수집 서버, 운영 DB, 예측 확률, 월 손실 한도는 변경하지 않았다.

다음 단계는 최신 경기 기사에 정확한 공식 일정 매핑을 검토해서 제공하고,
실제 동결 시각 이전에 관측한 자료를 공식 확인 및 사전 배당/예측과 결합하는 것이다.
와이즈토토·OLBG·라이브스코어는 자동 수집 비활성 상태다.
