# 검증된 1,185경기로 만든 NBA 슛 위치 모델

사용자 요청에 따라 슛 위치를 포함한 모델을 실제 구현·학습하고 기존 전적 모델·시장 기준과 두 기간에서 비교했다. **공간 정보가 적중률과 ROI를 두 기간 모두 개선한다는 결과는 얻지 못했다.** 시장 보정안이 2026년에는 두 지표를 조금 높였지만 2025년에는 나빴고, 2026년 기존 전적 모델의 ROI도 넘지 못했다. 운영 추천을 바꾸지 않았다.

## 작업과 실제 표본

- 자료 어댑터: [PR #672](https://github.com/choigod1023/proto-odds-research/pull/672), `codex/nba-shot-profile-data-20261108`, 코드 `scripts/export_nba_shot_profile.py`.
- 모델: [PR #673](https://github.com/choigod1023/proto-odds-research/pull/673), `codex/nba-shot-profile-model-20261108`, 코드 `scripts/nba_shot_profile_model.py`.
- 총괄 독립 검산: `codex/shot-profile-orchestrator-20261108`, 코드 `scripts/audit_nba_spatial_research.py`.
- 기존 자료: [PR #669](https://github.com/choigod1023/proto-odds-research/pull/669)의 PBP 감사와 [PR #668](https://github.com/choigod1023/proto-odds-research/pull/668)의 동결 연구 예측·원문 보존본이다. 새 원천 HTTP 수집은 하지 않았다.

1,185경기는 양 팀의 PBP 품질 검사를 통과한 **과거 입력 자료 풀**이다. 여기서 야투 시도 **210,663개**를 재계수해 거리 구간별 시도·성공 수를 만들었다. 경기별 최종·기간별 득점, FGA/FGM/3PA/3PM/FTA/FTM과 영수증 해시를 검증했다. 404 본문 8개도 보존 원문 해시와 일치한다.

두 평가와 학습에 실제 참조된 고유 과거 경기는 1,138개이며 마지막 참조일은 2026-04-30이다. 풀의 나머지 47개를 더 썼다고 부풀리지 않았다. 원천 날짜가 예측 이후이면 풀에 있어도 쓰지 않는다. 학습행 1,908개는 A 721행과 B 1,187행의 합이며, 재학습 사이에 겹치는 경기들이 포함된다.

자료 풀 중 어떤 경기가 예측 대상 자신인지를 미리 보고 평가 대상을 고르면 사후 선택이 된다. 따라서 주 평가는 기존의 가격 연결 1,260경기에 고정하고, **그 대상보다 과거인 검증 자료만** 입력에 사용했다. 기존 487+773경기 모두 양 팀의 과거 자료를 5경기 이상 갖고 있어 유지됐으며, 새 모델 때문에 제외한 대상은 0개다.

대상 자신도 1,185경기 풀에 속하면서 가격·기존 예측까지 연결된 것은 **378경기(A 135 / B 243)**다. 이 집합의 성적도 별도로 남겼지만, 사후 품질을 기준으로 선택된 집합이므로 주 평가나 운영 선정 조건으로 쓰지 않았다.

## 위치 구간과 모델식

공급자 좌표의 내부 거리 가설은 `r = hypot(x−25, y)`다. 설명문 거리와 일치하는 근거는 있지만 공식 NBA 코트 구역 인증은 아니다. 모든 산출물에 `internally_consistent_unofficial` 상태를 유지했다.

- 2점: `[0,4)`, `[4,10)`, `[10,16)`, `[16,∞)`, 좌표 미상.
- 3점: `[0,24)`, `[24,27)`, `[27,∞)`, 좌표 미상.
- 미상 좌표를 임의 위치로 채우거나 그 슛을 삭제하지 않는다. 이번 자료의 미상 구간 시도는 0개였다.
- 시도·성공을 먼저 구분하므로 실패 슛의 `scoreValue=0`을 0점 시도로 오해하지 않는다.

공간 모형 S는 팀 공격·상대 허용의 구간별 시도율과 성공률을 조합해 2점·3점·자유투 성공 수의 기대값을 계산한다. 비공간 대조군 Q는 **같은 과거 경기·동일 수축 강도·동일 시간 경계**에서 구간을 2점·3점으로 합친다. 따라서 이번 S−Q는 이전 실험 G와 비교하는 것보다 위치 정보의 추가 효과를 명확히 구분한다.

시도율은 500 추정 노출의 사전 강도로 리그 평균에 수축한다. 성공률의 총 사전 강도 200은 2점·3점 각각의 구간별 시도 비중에 나눠 준다. 구간마다 200을 더해 정규화 강도가 달라지는 혼동을 피했다. 공격·수비 성공률은 사전 확률에 대한 오즈 비율로 결합한다. 관측 시도 0인 구간은 득점 기여 0이며, 희귀 구간을 수치상 처리하는 epsilon은 사전에 고정했다.

추정 공격 기회 `P = FGA−ORB+TOV+0.44×FTA`는 공식 포제션이 아니다. 공격 리바운드를 별도로 다시 가산하지 않는다. 2점·3점·자유투 성공 수를 독립 포아송으로 두고 `점수=2×M2+3×M3+MFT`의 합성 분포를 계산했다. 동점은 양 팀에 절반씩 배분하는 사전 지정 근사이며 실제 연장 전력의 완전한 모델이 아니다.

시장 보정안 R은 다음 공간 추가분만 시장 확률에 반영한다.

`logit(p_R) = logit(p_market) + β × [logit(p_S) − logit(p_Q)]`

β 하나만 `합산 로그손실 + 10×β²/2`로 학습하며 절편·배당 필터·사후 후보 선택은 없다. 학습 결과 β는 A **−0.0197739**, B **−0.1230179**였다. 공간 모형의 신호를 단순히 강하게 더하도록 만든 것이 아니라, 훈련 자료가 정한 방향과 크기를 그대로 사용했다.

## 과거 정보 경계와 기간

대상 날짜 D마다 **D−365부터 D−4까지(양 끝 포함)**의 검증된 과거 경기 전체를 쓴다. 최근 3일과 대상 경기는 제외한다. 이는 365일 lookback에서 최근 3일을 뺀 범위이며 362개 달력 날짜다. 이전 실험의 '실제 최근 10경기' 규칙을 몰래 느슨하게 바꾼 것이 아니라 이번 모델에 새로 고정한 달력 창이다. 자료가 빠지면 이전 경기를 대신 끼워 넣는 방식이 아니다.

팀별 과거 자료는 최소 5경기다. 리그 사전 평균도 **각 행 자신의 D−4까지만** 계산한다. 학습 기간 전체 평균을 과거 1월 행의 특징에 사용하는 누출을 막았다. 대상 경기의 PBP·슈팅·출전시간·점수는 특징에서 읽지 않으며, 결과는 학습 정답·정산 검증에만 쓴다.

- A: β 학습 **2025-01-01~08-28**, 적격 학습 721행. 평가 계획 2025-09-01~12-31 중 실제 연결된 **2025-10-22~12-31, 487경기**.
- B: β 재학습 **2025-01-01~12-28**, 적격 학습 1,187행. 평가 계획 2026-01-01~10-27 중 실제 연결된 **2026-01-01~05-04, 773경기**.
- 2026년 원래 가격은 6월 14일까지 804행이었고, 이전의 상세 이력 부족 31행 제외를 유지한 773행이다. 새 모델에 유리한 날짜나 경기로 바꾸지 않았다.

최초 모델 규약은 `ddd4d4b8`, 달력 경계 오기 수정은 첫 후보 결과 이전의 `afcae2fe`에 보존했다. 처음 적었던 `[D−369,D−4]`는 365일이 아니라 366개 날짜이므로 위 명시적 경계로 정정했다. 성과를 보고 창을 고른 것이 아니다.

두 기간은 이전 연구에서 이미 열람했다. 학습 기간 밖에 대한 회고 평가이며 새로운 블라인드·전향 검증은 아니다. 비교자의 `prior_outcome_form`은 기존 연구 전적 모델의 동결 확률이고 현재 운영 투표나 M0 원장 재생은 아니다.

## A: 2025년 후반 487경기

- 시장: **316/487, 64.89%**, 조건부 ROI **−17.09%**, 로그손실 0.61327, 일 마감 MDD 84.00단위.
- 기존 전적 모델: **310/487, 63.66%**, ROI **−13.17%**, 로그손실 0.65369, MDD 64.81단위.
- 비공간 Q: **288/487, 59.14%**, ROI **−16.93%**, 로그손실 0.65948, MDD 86.23단위.
- 공간 S: **286/487, 58.73%**, ROI **−17.46%**, 로그손실 0.66317, MDD 88.83단위.
- 시장 보정 R: **315/487, 64.68%**, ROI **−17.44%**, 로그손실 0.61322, MDD 85.74단위.

S는 같은 이력의 Q보다 적중 2건·ROI **0.53%p**가 나빴다. R은 시장보다 적중 1건·ROI **0.36%p**가 나빴다. R의 유일한 선택 변경은 2025-11-21 SA–ATL의 양쪽 1.74배당 동률 경기였으며, 시장의 홈 동률 선택을 원정으로 바꿔 실패했다.

## B: 2026년 773경기

- 시장: **547/773, 70.76%**, ROI **−11.60%**, 로그손실 0.55766, 일 마감 MDD 89.82단위.
- 기존 전적: **537/773, 69.47%**, ROI **−6.86%**, 로그손실 0.59679, MDD 59.33단위.
- 비공간 Q: **499/773, 64.55%**, ROI **−9.86%**, 로그손실 0.64181, MDD 78.16단위.
- 공간 S: **497/773, 64.29%**, ROI **−11.09%**, 로그손실 0.64300, MDD 89.52단위.
- 시장 보정 R: **549/773, 71.02%**, ROI **−11.14%**, 로그손실 0.55757, MDD 86.32단위.

S는 Q보다 적중 2건·ROI **1.23%p**가 나빴다. 시장 보정 R은 시장보다 적중률 **+0.26%p**, ROI **+0.45%p**였으나 다음 두 변경에만 의존했다.

- 2026-01-17 BKN–CHI, 배당 1.75/1.73: 시장 원정 → R 홈, 적중.
- 2026-01-19 SAC–POR, 배당 1.73/1.75: 시장 홈 → R 원정, 적중.

두 경기는 정확한 동률은 아니며 박빙 배당이었다. 날짜 단위 paired bootstrap 2,000회(seed 20261108)에서 R−시장 차이의 명목 95% 구간은 적중률 **0~+0.66%p**, ROI **0~+1.16%p**로 0을 포함했다. 한 기간의 2건 증가를 안정적 우위로 볼 수 없다. 기존 전적 모델과 비교하면 R의 적중률은 높지만 ROI는 **4.28%p 더 낮았다**.

S−Q의 ROI 차이 구간도 A **−4.10~+3.37%p**, B **−3.90~+1.26%p**로 0을 포함했다. 이 반복 열람·여러 후보의 명목 구간을 확증적인 통계 검정으로 표시하지 않는다. 모든 월과 모든 후보의 결과를 남기며 유리한 기간만 합산하지 않는다.

## 검증된 대상 자체에 한정한 378경기

이 절은 사후 PBP 품질로 골라진 **서술용 하위 집합**이다. 주 평가를 대체하지 않는다.

- A 135경기: 시장 **65.19% / −17.10%**, 전적 **68.15% / −7.68%**, S **56.30% / −22.98%**, R **65.19% / −17.10%**.
- B 243경기: 시장 **68.72% / −14.23%**, 전적 **65.02% / −12.26%**, S **65.02% / −7.81%**, R **68.72% / −14.23%**.

R은 이 집합에서는 시장과 선택이 전부 같았다. B의 S가 시장보다 손실을 줄였다는 부분만 떼어 내도 적중률은 낮고 A에서는 나빴다. 두 기간에서 두 지표가 함께 나아진다는 결론은 동일하게 성립하지 않는다.

## 독립 검산과 한계

총괄은 모델 구현을 불러오지 않는 `audit_nba_spatial_research.py`를 실행했다.

- 원문과 1,185개 파생 프로필의 9구간 시도·성공, 자유투, 추정 노출량과 최종 점수를 전수 대조했다. 야투 210,663개를 독립 재계수했고 전체 풀·해시가 일치했다.
- 평가 1,260행과 학습 1,908행에서 각 행의 D−365~D−4 이력과 리그 평균을 직접 다시 구성했다. 데이터 풀에 있는 미래·대상 경기의 정보는 들어가지 않았다.
- 원 구현의 포아송 합성 대신 확률생성함수 재귀로 Q/S 확률과 공간 추가분을 다시 계산했다. 최대 오차는 **1.32×10⁻¹³ 미만**이었다.
- 정규화 로그손실의 기울기 `Σ delta×(sigmoid(logit(market)+β×delta)−y)+10β=0`를 별도 이분법으로 풀었다. β 차이는 **1.2×10⁻⁸ 미만**이었다.
- 원래 가격·결과 라벨과 전적/시장 확률을 고정한 뒤 Decimal 단위 손익, 적중률, 로그손실, Brier, 일 마감 MDD와 월별 성적을 다시 계산했다.

`independent-audit.json`에 전수 결과와 월별·하위 집합 성적이 있다. `independent-source-check.json`은 원문 대조, `paired-comparisons.json`은 워커의 구간 추정 원 결과와 SHA, `worker-provenance.json`은 코드와 입력 파일 버전을 기록한다.

검증 범위는 이 비공식 거리 구간·달력 이력·팀 단위 결합 모형에 한정한다. 위치만으로 슈터 능력·수비 압박·실제 다음 경기 출전 조합을 알 수 없다. 자료의 3점 시도 약 60.6%, 2점 시도 약 24.7%가 구간 경계 1ft 안에 있어 좌표 근사와 구간화 오차에 대한 민감도도 남는다. 이 수치가 성능 악화의 원인이라고 확정하지 않는다.

4일 지연은 논리적인 과거 경계이며 실제 역사적 수신 시각의 증거가 아니다. 당시 가격 수신·구매 가능성·상품번호·연장 정산 규칙이 인증되지 않아 ROI는 같은 보존 배당의 **조건부 회고 1단위 손익**이다. 미래 기대수익·현재 운영 픽 적중률·월 지갑 수익으로 바꾸어 표시하지 않는다.
