# 예약 작업 설치 전 최종 반례 재검토

고정 커밋 `b0c439d9ef1d6f9a8813939a0e6875e2f0330cc4`를 대상으로 합성 데이터와 임시 원장을 사용했다. 실제 보관 상태는 수정하지 않았고 공식 원천 재요청·예측·정산·예약 작업 등록을 수행하지 않았다.

## 설치 전 보완할 결함

1. **오래된 상충 정산이 최신 공식 관측을 덮을 수 있다.** 같은 결과가 더 늦게 관측되면 그 수신 사실을 저장하지 않으므로, 이어서 들어온 더 오래된 상충 결과가 정정으로 허용된다. 합성 10:00 결과 A → 10:20 동일 A → 10:10 결과 B 순서로 이를 재현했다. 이전 결과 관측의 최신 수신 watermark를 보존하고 이를 기준으로 상충 정정의 순서를 검사해야 한다. `audit_ledger_latest.py`.
2. **원천 일정 장애가 계속되면 마감된 기회가 미분류로 남는다.** 선행 관측한 경기가 마감을 지났더라도 `schedule()`이 실패하면 미예측 분류 함수에 도달하지 못한다. 합성 시험에서 원장에는 기회 1건만 남았고 미예측 기록은 생성되지 않았다. 다음 정상 실행에서 복구될 수 있으나, 장애 기간 집계에 미분류 만료 건수를 별도로 표시하거나 실패 경로에서 안전하게 마감을 분류해야 한다. `audit_integrated_recheck.py`.
3. **미배당 예측의 모델 쌍·확률 형식 미검증.** 잘못된 단일 모델을 반환하는 합성 infer 결과가 저장됐다. 미배당 예측은 ROI 비적격이지만 이후 두 모델 적중률 집계는 별도로 수행하므로, 정산 전에 같은 두 모델과 확률·경기 식별자·시간 역행을 검증해야 한다. `audit_ledger_latest.py`.

원장 API 단독으로 호출한 합성 원문이 직접 수집 검증 표식을 얻는 사례도 그대로다. 실제 자동 경로가 이 API에 신뢰된 adapter 결과만 전달하는지를 별도로 보장해야 한다. 이는 임의 외부 명령줄 입력이 존재한다는 주장이 아니다.

## 확인 범위

압축 근거 내용 변조 거부를 재확인했고, 가격 마감·상품 표기 변조 및 판매 마감 후 캡처는 앞선 통합 커밋 `d6e8581f`에서 차단됐다. 공식 팀 코드 사용과 선수 식별 범위 보강을 포함하는 코드 상태에서 원장·runner·피처·가격·공식 원천 테스트 47개와 하위 검사 5개가 통과했다. 실제 진행 중인 source 사전 수집의 결과, 실시간 원문에서 최종 예측까지의 완전한 통합, 예약 작업 등록 후 권한과 절전·실패 알림은 이 검토에서 확인하지 않았다. 또한 고정 runtime 파일의 매 실행 시 해시와 Python 환경 재검증이 필요하다는 이전 점검은 여전히 남는다.
