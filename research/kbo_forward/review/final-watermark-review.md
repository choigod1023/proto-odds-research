# 최종 반례 재검증

대상 커밋 `a755f36c2d639bb1b499ef39854a2961b7ee765e`. 실제 원천 요청이나 예측·예약 작업 실행 없이 합성 입력과 임시 원장으로 검토했다.

이전에 발견한 두 결함의 수정은 독립 재현에서 확인했다. 더 늦은 동일 결과 수신이 별도 확인 기록으로 남고, 그보다 오래된 상충 결과는 거부된다. 일정 조회가 실패한 경우에도 이미 관측한 마감 경과 기회를 미예측으로 분류한다. 압축 근거 내용 변조도 거부됐다. 전체 기존 테스트 51개와 하위 검사 5개가 통과했다.

설치 전에 남은 필수 확인은 미배당 예측이다. `capture_unpriced()`에 잘못된 단일 모델을 반환하는 합성 추론 함수를 넣었을 때 검증 없이 원장에 저장됐다. 정상 고정 추론 함수가 항상 잘못된 결과를 낸다는 뜻은 아니지만, 미배당 결과는 두 모델의 적중률로 별도 집계되므로 priced 경로와 같은 모델 쌍·확률·경기 식별자 검사 및 시계 역행 차단이 필요하다. `audit_ledger_watermark.py`에서 재현한다.

원장 API는 직접 수집 경로가 아닌 호출에도 source verification을 스스로 붙일 수 있어, 외부 입력을 허용하지 않는 실제 runner/adapter 경계가 전제다. 실제 사전 수집 결과·전체 공식 원문→모델→정산 경로와 설치 후 Windows 작업 및 runtime 무결성은 독립 확인하지 않았다. `audit_outage_recheck.py`는 일정 실패 후 미예측 분류와 압축 근거 변조 차단을 재현한다.
