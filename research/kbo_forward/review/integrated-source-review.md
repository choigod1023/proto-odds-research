# 통합 수집 경로 독립 점검

대상은 통합 커밋 `d6e8581fb882328cb9ecdf1ac3fa3b4b5622e87b`과 원천 선수 식별자 보강 `48ab8adef67306ea4e546c838ab86e735490aabb`다. 실제 원천 요청이나 Windows 예약 작업 등록·실행은 하지 않았다.

## 수정 확인

- 이전 가격 반례를 동일한 합성 원문으로 다시 실행했다. 마감 시각·상품 표시 변조와 판매 마감 후 캡처가 모두 거부됐다. 미배당 정산은 가격 ROI 표본에 들어가지 않았다. `audit_quote_close_recheck.py`에 고정 커밋과 재현 사례를 남겼다.
- 원천 응답을 담은 압축 근거의 내용이 해시와 달라지면 검증이 실패하는 것을 합성 파일로 확인했다. 이 해시 검사는 보관된 내용의 무결성을 확인하며, 실제 외부 원천의 진위나 외부 인증 수신 시각을 독립적으로 증명하지는 않는다.
- 현재 공식 snapshot은 공식 팀 코드를 사용하고, 이력 검증에서 고정 seed와 원천 응답으로 재구성한 이력이 일치해야 한다. 필요한 팀의 선수 식별자만 해석하도록 한 수정도 포함됐다. 실제 공식 경기의 완전한 원문→예측·정산 전체 경로를 독립 실행한 것은 아니다.
- 최신 작업 공간의 `research/kbo_forward` 전체 테스트 47개와 하위 검사 5개가 통과했다.

## 남은 사항

- 최초 관측 기회는 보존되지만, 마감 후 일정 조회 자체가 실패하면 `close_missed_opportunities`에 도달하지 못한다. 합성 시험에서 관측 기회가 원장에 남은 채 마감 미예측 기록 없이 실행이 실패했다. 이후 성공 실행이 있으면 다시 분류할 기회가 있지만, 장애가 계속되는 동안 미예측 수가 실제보다 적게 보인다. 실패 경로에서도 기존 원장만으로 마감 경과 기회를 분류하거나 미분류 경과 건수를 별도 표시해야 한다. `audit_integrated_initial.py`로 재현했다.
- 원장 정정은 동일한 결과를 더 늦게 관측해도 watermark를 갱신하지 않아 그보다 오래된 상충 정정을 수용한다는 이전 반례가 이 통합본의 `settle` 로직에 남아 있다. 미배당 캡처의 모델 쌍·확률 형식 검증과 예약 실행 직전 파일·환경 해시 확인도 아직 확인되지 않았다.
- 실제 공식 경기 snapshot 및 과거 박스 원문과 정규화 값 전수 대조, 압축 근거의 재열람 가능성, 운영체제 예약 작업의 권한·실패 알림·절전 후 동작은 설치 전 또는 별도로 수행할 통합 검증이다. 현재 테스트 결과만으로 실제 원천 어댑터가 사용 가능한 상태라고 단정하지 않는다.
