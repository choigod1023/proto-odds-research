# 가격 원문·팀 코드·이력 경계 재검증

고정 커밋 `190b1c8bdab0ab342924c97bf13d81a8403349be`. 공식 snapshot 생산기는 아직 인계되지 않았으며 공식 원천 실시간 요청이나 예약 작업 설치 없이 합성 자료와 고정 학습 행으로 검토했다.

## 확인한 수정

- 고정 학습 원본에서 10개 팀을 빠짐없이 포함하는 5개 행을 골랐다. 원래 팀 이름을 공식 코드로 변환해 `infer_frozen()`에 전달한 결과, 원래 행을 고정 모델에 직접 전달한 결과와 두 모델의 모든 확률 및 모델 해시가 완전히 일치했다. 입력 행의 공식 코드는 보존됐다. 전제는 공식 코드와 팀 이름 매핑 자체가 현재 공식 ID 체계와 일치한다는 것이며, 실제 source adapter의 ID 출처는 별도 검증해야 한다.
- 공식 판매 목록 및 상세 원문을 보존하는 테스트 자료로 가격 packet을 정상 통과시킨 뒤 정규화된 홈 배당만 바꿨더니 거부했다. 양 팀 가운데 한쪽 이력 상태가 불완전인 packet도 거부됐다. runner의 `q.market` 우회 경로가 제거됐다. 이는 직접 원천 수신의 진위나 공식 무승부 정산 규칙을 증명하는 시험은 아니다.
- 팀 이력 coverage가 불완전하면 타자·투수 피처도 `None`으로 만든다. 원천 일정·선수 이력의 실제 완전성은 최종 공식 생산기와 함께 재검증해야 한다.
- `test_ledger.py`, `test_runner.py`, `test_features.py`, `test_prices.py` 총 27개와 하위 검사 5개가 통과했다. 독립 재현은 `audit_source_recheck.py`다.

## 남은 차단·확인 사항

- 원장 단독 API는 호출자 합성 원문을 검증된 출처로 표시한다. 현재 공개 수동 import CLI가 없다는 설명은 이 반례와 양립하며, 실제 공식 생산기와 runner가 원장으로 이어지는 유일한 경로인지, 원문 바이트→일정·선발·피처·결과를 실제로 대조하는지 인계 후 확인해야 한다.
- 동일한 결과를 더 늦게 수신했을 때 기록을 남기지 않아 그보다 오래된 상충 결과가 정정으로 수용된다. 부정확한 정산이 될 수 있으므로 최신 공식 관측 수신 watermark를 보존해야 한다. 미배당 경로의 두 모델·확률 검증 누락도 그대로 재현됐으며 ROI 비적격과는 별도 문제다. `audit_ledger_recheck.py`로 이 버전에서 다시 확인했다.
- 경기별 예외가 전체 `ok`로 표시되는 문제와 예약 실행 시 runtime 해시·환경 재검증 부재는 이 검토 범위에서 해결이 확인되지 않았다. 6개 이상 후보 순회와 강제 종료 뒤 원장 잠금 회복은 `4860d514`에서 독립 재검증을 통과했다.
- 고정 seed의 팀 식별자를 공식 코드와 일치시키는 별도 구현과 실시간 공식 snapshot 생산기는 작업 중이므로, 실제 전향 수집을 승인할 정도의 통합 증거는 아직 없다.
