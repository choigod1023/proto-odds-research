# 경기 별칭 점수·실행 경로 최종 재검증

고정 커밋 `a721357271677ecab373e7cb0fdce5e58bd61b56`을 합성 입력으로 검토했다. 이전의 점수 없는 seed 별칭과 득점·실점 중 하나만 있는 별칭 세 가지는 모두 거부됐다. 대상 홈 팀에 완전한 정수 점수가 있고 공식 점수와 같은 경우는 허용됐다. 기존 점수 불일치·동일 팀 더블헤더 거부 시험도 전체 테스트에 포함된다.

별도 임시 작업 디렉터리에서 Python 격리 모드 `-I`로 runner의 상태 조회를 실행한 뒤 `research.kbo_forward.official`을 불러왔다. 작업 디렉터리나 `PYTHONPATH`에 기대지 않는 import를 확인했다. 이 검사는 별도 압축 runtime의 파일 무결성이나 실제 예약 작업 실행을 확인한 것은 아니다.

전체 테스트 57개와 하위 검사 5개가 통과했다. 독립 검증 코드는 `audit_alias_final.py`다. 실제 원천 재요청, 예측·정산, 예약 작업 설치는 수행하지 않았다. 사용자가 전달한 별도 사전 수집 성공은 이 독립 검토에서 재실행하지 않았다.
