# KBL 핸디캡 경기 전 모의 비교

이 작업은 공식 KBL 경기와 베트맨에서 판매 중인 KBL 반점 핸디캡을 팀 ID와 시작시각으로 연결한다. 경기 24시간 전부터 T-30까지 첫 적격 상품의 번호·기준점·양쪽 배당을 기록한다. 상품 마감과 회차 마감 전에 원문을 받은 후 10분 이내에 세 모델의 확률을 함께 고정한다. 같은 경기의 기록은 다음 수집 주기에 덮어쓰지 않는다. 원문과 응답 완료 시각, SHA-256은 별도 연구 디렉터리에 남는다.

- 기존 KBL 동결 팀 점수차 모델은 배포 코드와 같은 계수와 공식 팀 ID를 사용한다.
- 전체 이력 보정과 시즌 단계·휴식일 보정은 [#693](https://github.com/choigod1023/proto-odds-research/pull/693)의 KBL 2024-25 및 2025-26시즌 575건으로 한 번 적합한 계수를 사용한다. 새 결과는 비교 원장에만 들어간다.
- 공식 최종 점수와 베트맨의 동일 상품 정산이 일치한 뒤 세 모델을 고정 배당으로 정산한다. 기준점이 바뀐 경우 최신 상품 정산과 원점수를 먼저 대조하고 고정한 기준점으로 계산한다. 공식 무효는 1단위를 환급한다. 판정 근거가 불충분하면 대기한다. [프로토 정산 규칙](https://www.sportstoto.co.kr/proto_intro)

비교는 세 모델마다 상품당 가상 1단위로 진행한다. 적중률 분모에는 확정 승패만 포함하며, ROI 분모에는 공식 환불도 포함한다. 실제 체결과 기존 모의 지갑은 이 비교에 포함하지 않는다.

## 실행

수집 서버 실행 설정은 한국 시간 09~23시, 기존 supervisor의 30분 주기다. 운영에 반영되면 상태는 /data/research/kbl-handicap-forward-v1에 남는다. 로컬이나 격리 서버에서는 상태 경로를 따로 지정해 1회 실행할 수 있다.

~~~text
python -m research.kbl_handicap_forward.cycle --state STATE
python -m research.kbl_handicap_forward.cycle --state STATE --status-only
python -m pytest -q research/kbl_handicap_forward
~~~
