# M1 서비스 입력 재현 경로

이 모듈은 동결 M1과 M0_actual·M0_projected를 같은 경기 전 입력으로 계산하는 **별도 연구 기록 경로**다. 운영 추천·확률, T-30 동결 픽, 기존 월 손실 5만원 모의원장은 변경하지 않는다. M1의 운영 승격은 허용되지 않은 상태다.

## 실제로 구현한 부분

- `model.forecast(row)`: 기존 가중치만 로드한다. 재학습·수치 탐색·네트워크 호출이 없다. 2023~2025 학습 모델을 2025년 표적에 적용하지 않는다. 타순은 9명 또는 명시적 결측이고 빈 목록은 거부한다. 알려지지 않은 선수는 원래 계약의 중립 효과와 unknown 지표를 유지한다. 결측과 관측값 0을 구분하고, 원래 변환에서 항상 결측인 구장 특성에 새 숫자를 넣지 않는다.
- `observer.Recorder`: 기존 수집기의 엄격한 snapshot 검증기를 재사용한다. 별도로 보관 HTTP 바이트와 캐시를 대조하고, 공식 명단과 선수 ID, 이력 통계, 원시·스칼라 특성, 공식 판매 목록 및 가격 응답을 다시 구성해 입력과 비교한다. 이 검증은 오프라인이며 추가 HTTP를 하지 않는다. 로컬 수신 시각과 보존 원본의 검증이지 독립 외부 타임스탬프 인증은 아니다.
- 추론이 T-30이나 시장 마감 이후 끝나면 기록하지 않는다. 계수의 보존 시점보다 과거로 캡처 시각을 소급하지 않는다. 첫 캡처를 지우거나 수정하지 않으며, 공식 결과 정정은 팀·날짜·시즌과 수신 순서를 확인해 추가 기록한다.
- 가격이 없는 예측은 적중 여부만 별도로 정산하며 ROI에 넣지 않는다. 2방향 승패와 3방향 승무패의 성과를 `by_product`로 분리하고 독립 경기 수도 별도로 표시한다. 합계 `methods`는 상품별 원장 항목의 합계이지 독립 경기 성과가 아니다.
- M1 초기화·추론·정산·원장 오류는 기존 수집 경로와 분리해 보고한다. `m1_status`는 `waiting_for_eligible_inputs`, `recorded`, `blocked`를 구분한다. 이 상태만으로 성능 검증 통과를 뜻하지 않는다.

## 연결과 활성화 상태

기존 `research/kbo_forward/runner.py`에 아래 **선택 실행 옵션**을 연결했다.

```powershell
python research/kbo_forward/runner.py --state experiments/m1-local-source --m1-state experiments/m1-local-candidate
```

이미 검증한 같은 payload를 사용해 M1·두 M0를 별도 `predictions.jsonl`에 기록한다. 과거 캡처를 읽어 새 사전 예측으로 소급 생성하지 않는다. 다른 원장에 이미 있는 경기라도 새로운 M1 입력은 현재 실제 시각에 다시 검증하고, 적격 기록이 생긴 뒤에는 중복 수집·기록을 피한다.

`bootstrap_runtime.py`의 고정 코드 패키지에도 이 모듈과 가중치를 포함했다. 별도 상태 경로를 넘기는 `--m1-state`와 PowerShell의 `-M1StateRoot`는 선택 옵션이다. 옵션이 없으면 기존 실행을 유지하며, 설치 스크립트는 기존 예약 작업을 덮어쓰지 않는다. 이 변경에서 설치 명령은 실행하지 않았다.

이 옵션을 만들었다고 설치된 예약 작업이나 Fly 운영 프로세스에 적용된 것은 아니다. 이번 작업은 기존 예약 작업·설치본·스케줄·서버·웹사이트를 변경하지 않았다. 상시 AI 점검을 켜지 않았다. 운영 활성화·장기 부하 검증·실제 경기 전 양성 캡처는 미완료다. 특히 원천 이력 재검증의 운영 메모리 상한은 아직 측정하지 않았다.

## 1.20 이하 배당

`low_odds.review`는 **1.20 포함** 여부를 검사하고 같은 경기·전체 경기 상품의 후보를 비교한다. 단순히 더 높은 배당이나 역배로 교체하지 않는다. 양의 추정 EV 후보 중 적중 확률과 추정 EV에서 다른 후보에 모두 뒤처지는 것을 제거해 Pareto 후보 목록을 남긴다. 두 목표를 동시에 최대화하는 단일 선택이 항상 존재하는 것은 아니다.

승리·환급·실패 확률을 구분한 세전 단폴 1단위 추정 손익은 다음과 같다.

`EV = p_win × (배당 − 1) − p_loss`

무승부 환급을 제외한 승패 확정 조건부 손익분기 확률은 `1 / 배당`이다. 1.20이면 83.33%다. 이는 추정 확률이 실제 적중 확률이라는 보증이 아니다. 야구 일반 승패의 무승부에 배당 1.0을 적용하는 근거는 [공식 배당률 산정 약관](https://www.sportstoto.co.kr/terms_allocation.php)에 있다.

전체 경기 핸디캡·언더오버는 승패 확률을 복사하지 않고 동결된 득점 분포에서 별도로 계산한다. 정수·반정수와 명시적 환급 규칙만 지원하며, 전반/이닝 상품·0.25 기준점·방향이 불명확한 핸디캡은 거부한다. 이 분포 역시 상품별로 보정·검증되지 않았으므로 **추정 연구값**이다. 현재 연결한 가격 수집 경로는 2방향/3방향 전체 경기 승패를 지원한다. 핸디캡·언더오버의 검증된 경기 전 가격 스트림까지 연결 완료했다고 주장하지 않는다.

현재 M1의 확률 보정과 양의 기대값 우위가 입증되지 않아 `automatic_replacement`는 항상 `null`이다. 저배당일 때의 보류 상태는 **미검증 대안의 자동 교체를 보류**한다는 뜻이며, 현재 운영 픽을 일괄 삭제하거나 모든 저배당 베팅을 중단시킨 변경이 아니다.

## 재현 결과와 판단

[결과 보고서](../../experiments/m1-service-20261104/REPORT.md)에 전체 667경기와 선택된 103경기를 함께 제시했다. M1은 선택된 103경기에서 +7.64%지만 전체 667경기에서는 -13.16%였다. 현재 근거로 전면 교체하지 않는다. 확률 평가에는 적중률만이 아니라 로그손실·Brier 점수도 함께 확인한다. 확률 예측 평가의 배경은 [Gneiting & Raftery (2007)](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)를 참고했다.
