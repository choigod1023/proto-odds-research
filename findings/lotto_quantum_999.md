# 고정한 6큐비트 모델: 가짜 이력 999개 재검증

주 평가 구간의 상측 몬테카를로 p값은 99개 실험의 0.15에서 999개 실험의 0.093으로 바뀌었다. 실제 예측 점수는 전혀 바뀌지 않았다. 가짜 이력 999개 중 92개가 실제 이상 점수를 얻었다. 통상적인 5% 기준에서 균등 무작위보다 우월하다는 근거는 여전히 부족하다.

## 그대로 유지한 조건

이전 PR #303의 `src/lotto_small_quantum.py`를 수정하지 않았다. 저장된 LF 기준 소스 SHA-256과 데이터 해시를 확인하고, 실제 자료 전체 평가와 기존 가짜 이력 99개를 다시 학습했다. 각 기록의 학습 각도·최적화 상태·점수가 이전 결과와 정확히 일치했다. 새로운 시드는 기존 순서를 이어 900개만 추가했으며, 최종 가짜 이력 수는 999개다.

- 큐비트 6개, 2층 RY/CNOT 회로, 매개변수 12개.
- 인코딩: `8 × 1~22 번호 개수 + 홀수 개수`.
- 균등 로또의 정확한 범주별 경우의 수로 보정한 Born 확률과 5% 균등 혼합.
- 학습 1~740회, 균등 분포 의사 관측 740회, 고정 초기 각도.
- L-BFGS-B 최대 반복 40회, 함수 평가 예산 800, ftol=1e-9.
- 학습 후 회로 고정. 주 평가 991~1238회, 부 평가 741~990회 및 1239~1245회.
- 가짜 이력 시드 `2026101700 + i`, `i=0..998`. 정확한 균등 로또 범주 분포에서 1,245회씩 생성하고 학습부터 평가까지 반복.

모델은 범주만 사용하므로 범주 분포에서 직접 추출하는 것은 이 실험 통계에 대해 균등 로또 조합을 추출하는 것과 같다. 같은 범주 안에서는 개별 조합에 동일한 확률을 부여한다. 새 실제 회차 수집이나 모델·학습 조건의 재선택은 없었다.

## 결과

- 741~990회: 실제 평균 로그점수 차이 −0.002535766. 실제 이상의 가짜 이력 591/999개, p=0.592. 이전 p=0.63.
- **991~1238회:** 실제 평균 로그점수 차이 +0.002956079. 실제 이상의 가짜 이력 **92/999개, p=0.093**. 이전 p=0.15.
- 1239~1245회: 실제 평균 로그점수 차이 +0.001453065. 실제 이상의 가짜 이력 437/999개, p=0.438. 이전 p=0.44.

각 p값은 `(1 + 실제 이상인 가짜 이력 수) / 1000`으로 계산했다. 주 평가에서 귀무 모형의 꼬리 확률에 대한 Clopper–Pearson 95% 구간은 약 **0.0749~0.1117**이다. 이는 가짜 이력 표본 수로 인한 몬테카를로 불확실성 구간이며, 로또 예측 효과의 신뢰구간이 아니다.

실제 당첨 조합에 부여한 확률은 주 평가에서 기하평균으로 균등보다 약 0.296% 높았지만, 앞선 검증 구간에서는 약 0.253% 낮았다. 이 수치는 구매 복권의 당첨률이나 적중 횟수의 개선이 아니다. p값 감소는 모델 성능 향상이 아니라 귀무 분포 추정의 변화다.

주 평가 지표와 구간은 이전 실험에서 고정했다. 부 평가 p값은 설명용이다. 여러 모델을 시도해 온 전체 연구 과정의 선택 편향까지 보정한 검정은 아니다. 99개 결과를 본 뒤 사용자의 요청으로 표본을 늘렸으므로 독립적인 확증 재현이나 새로운 미공개 회차 검증으로 해석할 수 없다.

## 컴퓨터 부하와 저장

단일 프로세스를 논리 CPU 하나에 고정하고 Windows BELOW_NORMAL 우선순위를 유지했다. 수치 라이브러리 스레드는 1개, 각 이력 뒤 25ms 휴식, 50개마다 임시 파일·flush/fsync·교체 방식으로 중간 결과를 저장했다. 120초 시간 예산과 256MiB 메모리 감시 기준도 유지했다. 이 기준은 목적함수 평가와 반복 사이에서 확인하는 감시 장치로, OS 수준의 강제 메모리 제한은 아니다.

실제 실행 시간은 **69.32초**, CPU 시간 **40.33초**, 실험 프로세스의 최대 작업 집합은 **118.62MiB**였다. 999개 학습 모두 정상 수렴했다. 별도 검산은 약 1.70초, 최대 작업 집합 93.68MiB였다. 컴퓨터 전체의 부하·온도·전력은 측정하지 않았다.

## 검산과 재현

독립적인 64×64 밀집 행렬로 999개 학습된 회로를 모두 계산했다. 재생성한 평가 자료 504,495회에 대한 구간별 평균 로그점수를 저장값과 비교했으며 최대 오차는 약 5.9×10⁻¹⁶이었다. 기존 실제 자료 505회도 별도로 확인했다. 데이터와 고정 소스 해시, 기존 99개와의 정확한 일치, 꼬리 확률 집계도 확인했다. 관련 테스트 14개가 통과했다.

실행: `python src/lotto_quantum_999.py`

검산: `python scripts/verify_lotto_quantum_999.py`

테스트: `python -m pytest tests/test_lotto_quantum_999.py tests/test_lotto_small_quantum.py tests/test_lotto645.py -q`

결과는 `data/lotto/reports/quantum-999/`의 protocol, actual, nulls, summary, verification JSON에 저장했다. 이전 결과는 `data/lotto/reports/small-quantum/`에 보존했다.

실제 양자 하드웨어를 사용하지 않은 작은 CPU 모의실험이다. 기존 과거 자료를 재사용한 결과이며, 양자 우위나 운영 번호 생성 방식 변경을 뒷받침하지 않는다.
