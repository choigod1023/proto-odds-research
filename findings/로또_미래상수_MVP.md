# 로또 6/45 미래상수 MVP

## 결론

현재 운영 판정은 **균등 복귀**다. 동행복권 공식 1~1238회 결과를 사용했을 때
번호 빈도, 990개 번호쌍, 번호별 1회차 자기상관은 전체 탐색 효과를 보정한 뒤
균등 비복원 추첨과 구별되지 않았다. 베이지안 번호 편향과 미래상수 지속상태
후보도 301~1238회 워크포워드에서 균등 기준보다 나빴다.

따라서 지금 적용되는 것은 다음 세 가지뿐이다.

1. 같은 회차의 구매 후보를 모두 고유 조합으로 만든다.
2. 생일형·연속수·끝수·등간격·용지 직선 등 인기 패턴을 별도 점수로 회피한다.
3. 조합 사이의 번호 중첩을 줄인다.

2와 3은 1등 당첨확률을 높이지 않는다. 인기 회피는 공동당첨 위험을 줄이려는
휴리스틱이고, 조합 거리는 하위 등수 적중의 상관을 줄이는 장치다.

## 정확한 부분집합 확률

균등 기준선은 다음과 같다.

```text
P(i 포함) = 6/45
P(S) = 1 / C(45, 6) = 1 / 8,145,060
P(i,j 함께 포함) = 1/66
```

번호 점수 `eta`를 사용할 때도 6개의 독립 Bernoulli로 계산하지 않는다.

```text
P(S | eta) = exp(sum(i in S) eta_i) / e6(exp(eta_1), ..., exp(eta_45))
```

`e6`는 45개 가중치의 6차 기본대칭다항식이다. 번호별 포함확률도
`w_i e5(w_-i) / e6(w)`로 정확히 계산한다. 조합 생성 역시 같은 분포에서 동적
계획법으로 가중 비복원 표본을 뽑는다.

## 무작위성 감사

다음 세 개의 최대통계량을 측정한다.

- 45개 번호 중 최대 절대 빈도 z값
- 990개 번호쌍 중 최대 절대 동반출현 z값
- 45개 번호 중 최대 절대 lag-1 자기상관

한 항목만 사후 선택하는 효과를 막기 위해 동일 길이의 균등 비복원 전체 원장을
반복 생성하고 매번 최대값을 다시 계산한다. 운영 기본은 250회이며 정밀 감사에는
1,000회 이상을 권한다.

1~1238회, 시드 645, 250회 모의실험 결과:

```text
번호 빈도 최대편차  family-wise p = 0.446
번호쌍 최대편차     family-wise p = 0.538
lag-1 자기상관      family-wise p = 0.179
판정                 균등모델과 구별되는 증거 없음
```

## 베이지안 축소와 미래상수

번호별 포함확률은 평균 `6/45`인 Beta 사전분포로 축소한다. 표본이 부족하거나
우연히 많이 나온 번호가 과대평가되지 않도록 사전 강도 180을 사용한다.

미래상수는 다음처럼 분리한다.

```text
F(i,t) = R(i,t) + U(i,t) + C(i,t)
C(i,t) = rho * C(i,t-1) + epsilon(i,t)
```

- `C`: 과거에서 추정 가능한 지속상태 후보
- `R`: 다음 회차의 독립 충격. 평균 0, 예측점수 사용 금지
- `U`: 미관측 장비·환경. 공식 값이 없으면 예측점수 사용 금지

`rho`는 45개 번호의 잔차에서 pooled lag-1 값으로 추정하고, 95% 잡음 범위 안의
크기는 정확히 0으로 축소한다. 1~1238회 결과는 축소 후 `rho=0`이었다.

## 워크포워드 관문

```text
1~300회 학습 → 301회 평가
1~301회 학습 → 302회 평가
...
1~1237회 학습 → 1238회 평가
```

각 회차에는 직전 회차까지의 데이터만 사용한다. 균등 대비 번호별 Brier score
개선과 전체 6개 조합 로그점수 개선을 함께 본다. 확장창 점수의 시계열 의존은
Newey-West HAC 표준오차로 보정한다.

채택 조건:

1. Brier 개선 평균의 95% 하한이 0보다 크다.
2. 조합 로그점수 개선 평균의 95% 하한이 0보다 크다.
3. 평가기간 후반부에서도 두 개선값이 모두 양수다.

현재 결과:

```text
베이지안 축소  Brier 개선 -0.0001126 · 로그점수 개선 -0.02132 · 탈락
미래상수 통합  Brier 개선 -0.0001126 · 로그점수 개선 -0.02132 · 탈락
운영 선택       uniform · edge weight 0
```

## 조합 최적화

검증 관문을 통과하면 posterior와 미래상수 불확실성에서 여러 `eta`를 샘플링해
각 후보의 10% 하위 조합 로그점수를 강건 점수로 쓴다. 통과하지 못하면 이 점수는
모든 조합에서 0이다.

그 다음 후보별 인기 위험을 계산하고, 이미 선택한 조합과의 최소 거리
`6 - |A ∩ B|`를 키우는 탐욕 선택을 한다. 모델점수가 같은 경우 공개 고정 시드로
동률을 해소해 낮은 번호나 사전식 순서가 체계적으로 앞서지 않게 한다.

## 사전등록과 재현

```powershell
python src/lotto_pipeline.py --data data/lotto/draws.jsonl all `
  --refresh --budget 10000 --simulations 250
```

산출물:

- `data/lotto/draws.jsonl`: 공식 원장
- `data/lotto/reports/audit.json`: 균등 감사
- `data/lotto/reports/backtest.json`: 워크포워드 결과
- `data/lotto/preregistrations/draw-*.json`: 회차별 사전등록
- `docs/data/lotto_latest.json`: 공개 화면용 스냅샷

공개 시드는 모델 버전, 대상 회차, 데이터 마감 회차, 데이터 해시에서 결정한다.
같은 대상 회차의 기존 사전등록은 다른 조합으로 덮어쓰지 않는다. Git 커밋과 별개로
실제 실행한 세 모델 파일의 SHA-256도 함께 고정한다.
