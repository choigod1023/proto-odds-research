# 전체 8,145,060개 조합의 6개 모델 계열 합의

기존 후보 표본 대신 C(45,6)=8,145,060개 조합을 전부 열거했다. 각 모델의 순위 백분위도 전체 조합을 기준으로 다시 계산했다. 모델을 추가 학습하거나 예측력이 새로 검증된 것은 아니다. 1245회까지의 기존 자료로 만든 1246회용 탐색적 선택이다.

## 최종 5세트

1. 13 · 20 · 21 · 22 · 32 · 42
2. 15 · 19 · 20 · 22 · 32 · 42
3. 18 · 19 · 21 · 22 · 28 · 42
4. 16 · 19 · 20 · 21 · 32 · 42
5. 18 · 19 · 20 · 21 · 32 · 42

6개 계열 중 최저 백분위는 모두 67.219816이다. 동률을 푸는 평균 백분위는 순서대로 74.349911, 74.333913, 73.953345, 73.912093, 72.742139다. 평균 점수만 최대화하는 기준이 아니라, 가장 낮게 평가한 계열의 백분위를 먼저 최대화한다. 모델들이 선호하는 조합이 비슷해 번호가 많이 겹친다. 다양성이나 당첨금 분산을 최적화하지 않았다.

이 점수들은 당첨 확률이 아니다. 공정한 추첨에서는 모든 개별 조합의 1등 확률이 같다. 기존 검증에서 무작위보다 우수하다는 근거를 찾지 못했고, 전체를 검색한 사실도 그 결론을 바꾸지 않는다.

## 유지한 모델과 합의 기준

양자, 고전 범주 빈도, 축소(반감기50·사전강도4500), 시간 의존성2개, 비선형24개, 엔트로피 상태6개를 여섯 계열로 묶었다. 각 모델 점수의 동률 중간 백분위는 `(더 낮은 점수 개수 + 동일 점수 개수/2) / 8145060`이다. 계열 내 모델 백분위를 평균하고 여섯 계열의 최저값, 그다음 평균값으로 정렬했다. 그래도 같으면 번호 사전식 순서를 따른다. 시드 생성기와 혼잡도 전략은 이 조합 점수에 포함하지 않는다. 모델 간 상관은 크며 서로 독립적인 증거 여섯 개가 아니다.

양자·범주 빈도·조건부 모형은 기존 학습 규칙을 유지하고, 축소 모델과 다음 회차 조건 입력은 기존 순차 계산 방식대로 1245회까지 반영했다. 참고 실험 파일은 data/lotto/entropy-regime/에 복사해 보존했다. 기존 데이터나 결과를 덮어쓰지 않았다.

## 전수 처리와 검산

첫 순회에서는 사전식으로 전체 조합을 한 번씩 생성해 범주별·특징별 점수 빈도를 계산했다. 축소 모델의 연속 점수는 float64 디스크 배열에 저장하고 별도 디스크 배열에서 정렬했다. 범주형 점수는 정확한 개수에 기반한 가중 중간 순위로 계산했다. 두 번째 순회에서 같은 전체 조합의 6개 계열 순위를 비교하고 상위5개만 유지했다. 총 두 순회 각각 8,145,060개를 처리했다.

모든 계열의 중간 순위 평균은 1/(48*8145060)의 정수배로 표현할 수 있다. 비교 키를 정수로 변환해 부동소수점 반올림 오차가 수학적 동률을 깨지 않도록 했다. 첫 실행 후 이 동점 처리를 보강해 다시 전수 실행했고 선택한 5세트는 바뀌지 않았다.

전체 범주 개수와 직전 회차 겹침 개수의 히스토그램이 정확한 조합 공식과 일치했다. 별도 감사에서 각 선택 조합의 사전식 인덱스를 조합 공식으로 재계산했고, 전체 원본 점수를 직접 세어 선택 조합의 축소 모델 백분위5개를 검산했다. 결과·프로토콜·감사는 data/lotto/full-consensus/에 보존했다. 큰 중간 점수 파일은 .local-build/의 재생성 가능한 파일로 Git에서 제외했다.

## 자원과 테스트

논리 CPU 하나, BelowNormal, 수치 라이브러리 스레드1, 배치25,000개, 배치 계산 시간의 50% 이상 휴식을 적용했다. 프로세스 최대 작업 집합384MiB 감시와 30분 시간 예산을 설정했다. 이는 OS 강제 메모리 제한이나 온도 제어가 아니다.

최종 전수 실행은 **17.420초**, 프로세스 CPU **9.922초**, 최대 작업 집합 **246.992MiB**였다. 초기 전수 실행은 16.876초였으므로 최종 실행 시간을 두 실행 전체 시간으로 해석하면 안 된다. 테스트·감사·파일 준비 시간도 별도다. 실행기 부모 프로세스나 다른 프로그램의 메모리는 이 최대값에 포함하지 않는다. 온도와 컴퓨터 전체 최대 부하는 측정하지 않았다. 두 실행과 감사는 정상 종료했다.

테스트5개 통과: 작은 공간 전수 열거의 누락·중복·순서, 범주별 가중 순위와 펼친 배열 순위 일치, 연속 점수 순위와 직접 정렬 일치, 정수 동점 비교, 배치별 상위5 유지와 전체 정렬 일치.


이 결과는 정의한 합의 기준의 전체 조합 상위5개이며, 실제로 가장 당첨 확률이 높은 조합을 발견했다는 결과는 아니다. 구매·병합·배포·자동 감시는 실행하지 않았다.
