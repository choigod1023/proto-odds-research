# 겹침을 제한한 전체 조합 합의 5세트

기존 6개 모델과 전체 8,145,060개 조합의 순위 기준을 유지하면서 다양성 제약을 추가했다. 모든 계열의 백분위가 60 이상인 조합만 허용하고, 세트끼리 공유하는 번호는 최대2개, 한 번호의 전체 사용 횟수는 최대2회로 제한했다.

## 결과

1. 13 · 20 · 21 · 22 · 32 · 42
2. 04 · 05 · 06 · 13 · 16 · 18
3. 03 · 04 · 15 · 16 · 28 · 32
4. 02 · 05 · 06 · 15 · 28 · 38
5. 18 · 19 · 21 · 25 · 31 · 42

서로 다른 번호19개를 사용한다. 각 번호는 최대2회, 세트 간 겹침도 최대2개다. 10개 세트 쌍의 겹침 개수는 사전식 쌍 순서로 1,1,0,2,2,2,1,2,0,0이다. 이전 중복 제한 없는 결과는 서로 다른 번호11개였고 같은 번호가 최대5회 사용됐다.

세트별 최저 모델 계열 백분위는 67.219816, 63.680579, 63.680579, 63.680579, 63.053150이다. 기존 결과는 모두 67.219816이었으므로 다양성을 확보하면서 최저 선호 순위가 최대 약 4.17백분위 포인트 내려갔다. 평균 백분위는 74.349911, 87.745593, 77.682135, 75.412209, 78.815187이다. 먼저 최저 계열 백분위를 최대화하므로 평균만 높은 순서와는 다르다. 이 값은 당첨 확률이나 신뢰도가 아니다.

## 방법과 해석

양자·고전 범주 빈도·축소·시간 의존성·비선형·엔트로피 상태 여섯 계열의 모델, 기존 학습 규칙과 1245회까지의 자료를 유지했다. 1246회용 선택이며 새로운 회차 결과를 수집하지 않았다. 각 모델의 전체 조합 내 동률 중간 백분위를 계산하고 계열 내에서 평균했다. 24개 비선형 후보가 다른 계열보다 많은 표를 받지 않는다.

첫 순회로 전체 점수 분포를 구한 뒤, 5차례 각각 전체 조합을 순회해 이미 선택한 세트와 겹침 제약을 지키는 최고 후보를 하나씩 선택했다. 정렬 기준은 최저 계열 백분위, 평균 계열 백분위, 번호 사전식 순서다. 동점 비교는 공통 분모를 가진 정수로 처리했다. 전체 조합을 단계마다 검사한 순차 탐욕 선택이며, 가능한 모든 5세트 묶음의 조합 최적화는 아니다.

총6순회, 순회마다 8,145,060개 조합을 열거했다. 범주와 겹침 히스토그램이 정확한 조합 공식과 일치했다. 독립 감사로 모든 결과의 제약과 소스 해시를 확인했다. protocol.json, results.json, audit.json은 data/lotto/full-consensus/에 보존했다. 과거 모형 입력은 data/lotto/entropy-regime/에 보존했다.

이 모델들은 기존 연구에서 무작위보다 예측력이 높다는 근거를 얻지 못했다. 다양성 제약은 번호가 한쪽에 몰리는 것을 줄이는 선택 기준이며, 공정한 추첨에서 서로 다른5게임의 1등 당첨 확률을 높이지 않는다. 기존5게임도 서로 다른 조합이었다. 번호 중복을 줄인다고 항상 모든 등수의 당첨 확률이 좋아지는 것도 아니다.

## 자원·검증

CPU 하나, BelowNormal, 수치 라이브러리 스레드1, 배치25,000개, 배치 계산 시간의 50% 이상 휴식을 적용했다. 디스크 기반 점수 배열을 사용했다. 최대 작업 집합384MiB 감시와 30분 예산은 소프트웨어 감시이며 강제 OS 제한은 아니다.

경과 **61.257초**, 프로세스 CPU **39.250초**, 계산 프로세스 최대 작업 집합 **254.281MiB**였다. 부모 실행기와 다른 프로그램의 메모리 및 온도는 측정 범위 밖이다. 실행은 정상 종료했다.

관련 테스트6개 통과: 전수 열거, 가중 중간 순위, 연속 순위, 정수 동점 처리, 배치 상위값 유지, 겹침·사용 횟수 필터. 결과 전체의 다양성과 품질 조건은 별도 감사에서도 통과했다.

```text
python scripts/lotto_full_consensus.py
python -m pytest tests/test_lotto_full_consensus.py -q
```

구매·병합·배포·자동 감시는 실행하지 않았다.
