# 무료 동적 경기정보·픽스터 수집과 판정 수식

작성 2026-08-19. 목표는 “정배를 설명할 정보를 더 붙이는 것”이 아니라, **프로토
가격이 굳은 뒤 새로 생긴 정보가 시장확률을 실제로 개선하는지** 판정하는 것이다.

## 1. 무엇을 우선 수집하나

고정된 팀 전력·구장·요일은 이미 시장이 알 가능성이 높다. 우선순위는 공개시점이
늦고 값이 바뀌는 순서다.

1. 선발 발표와 교체/scratch
2. 확인된 타순, 좌우타 구성, 핵심 선수 제외
3. 최근 1–3일 불펜 투구수·연투·휴식
4. 경기 시각 날씨 자체보다 T-24→T-6→T-1 예보 수정폭, 개폐식 지붕 상태
5. 공개 픽스터 군중의 방향·분산과 픽 공개 뒤 시장가격 변화(CLV)

MLB의 공식 [probable pitchers](https://www.mlb.com/probable-pitchers/)와
[starting lineups](https://www.mlb.com/starting-lineups)는 무료 확인 경로다.
[Baseball Savant Statcast](https://baseballsavant.mlb.com/en/statcast_search)는
xwOBA, 타구속도, 구속·회전 같은 선수 과정지표를 제공한다. NPB는 공식
[선수/성적 페이지](https://npb.jp/bis/2026/stats/)가 무료지만, 현재 확인한 공개
경로에서는 경기 전 구조화 라인업이 안정적으로 나오지 않았다.

## 2. 현재 자동화된 무료 경로

| 정보 | 리그 | 비용/키 | 코드 | 현재 한계 |
|---|---|---|---|---|
| 일정·선발 발표/교체 | KBO·NPB·MLB | 무료, 키 없음 | `info_watch.py` | 공개 웹 응답이라 계약형 API가 아님 |
| 선발 시즌/상대 성적, K-BB/9, 최근 팀 득실, 라인업 상태 | KBO·MLB 중심 | 무료, 키 없음 | `baseball_context_watch.py` | NPB 상세 preview가 현재 비어 있음 |
| 경기장 시간별 예보·수정 이력 | KBO·NPB·MLB·K리그 | Open-Meteo 무료 비상업, 키 없음 | `weather_watch.py` | 개폐식 지붕 실제 상태는 별도 필요 |
| 공개 X MLB 픽·30일 기록·당일 군중 | MLB | 공개 HTML, 키 없음 | `pickster_watch.py` | open data licence가 아니므로 저빈도·비공개 API 미사용 |
| 픽스터 전향 적중률/ROI | MLB | 위 수집분 | `pickster_eval.py` | 첫 관측 이후 표본을 기다려야 함 |

현재 필요한 새 API 키는 **0개**다. 무료 키를 만들기 위해 외부 계정을 추가할 이유가
없다. 계정 생성은 이메일·약관 동의가 필요한 외부 행위이고, 지금 구현보다 더 나은
coverage를 주지도 않는다.

유료/체험 경로는 당장은 제외했다.

- [The Odds API](https://theoddsapi.com/pricing): 무료는 MLB/NBA moneyline 25회/일,
  $29/월부터 20,000회. 현재 15분 관측에는 무료량이 부족하다.
- [SportsDataIO](https://sportsdata.io/developers): 무료 trial은 구조 시험용 scrambled
  data라 실분석에 쓸 수 없고, 실데이터 hobby 상품도 지연 또는 유료다.
- [Sportradar](https://developer.sportradar.com/getting-started/docs/your-account): trial은
  30일·1,000회이고 production/MLB Statcast 등은 고객 계약 영역이다.

## 3. 픽스터를 어떻게 보나

[TailSlips](https://tailslips.com/)는 추적한 공개 X 계정의 MLB 픽을 동일 규칙으로
등급화하고, 삭제 표시와 posted odds/stake 기반 ROI를 함께 보여준다. 2026-08-19
우리 관측 단면은 다음과 같다.

- 최근 30일 활성/상위 50명, 표시 픽 4,231건
- 픽스터 중앙값: 48.5픽, 적중률 54.0%, ROI 2.2%
- 양(+) ROI 66.0%, 표시 순익/ROI를 합친 단면 ROI 3.48%
- 현재 슬레이트 476픽 중 직선 픽 325개; 가격이 읽힌 직선 픽의 정배 비중 66.82%
- 삭제 표시가 있는 계정 7/50

이것은 **전체 픽스터의 성공률이 아니다.** 최근 활동 계정과 상위 화면을 본 단면이라
survivorship, ranking selection, 작은 표본의 극단 ROI가 섞인다. 예를 들어 13–34픽
표본에서 ROI 31–95%가 나타났다. 원 적중률의 Wilson 구간도 매우 넓다.

따라서 두 표본을 완전히 분리한다.

```text
화면 단면 = 픽스터 성향을 탐색하는 설명 자료
전향 표본 = 우리 수집기가 결과 미정일 때 처음 본 픽만 성공률/ROI 판정
```

첫 실행에서 이미 끝난 477픽은 baseline이라 성과 계산에서 제외했다. parlay leg도
한 티켓이 여러 경기에서 중복 손익으로 잡히므로 제외한다. 직선 픽의 risk는 결과와
American odds로 복원한다.

\[
R_i=\begin{cases}
|u_i|,& L\\
u_i\frac{|o_i|}{100},&W,\ o_i<0\\
u_i\frac{100}{o_i},&W,\ o_i>0
\end{cases},\qquad
ROI=\frac{\sum_i u_i}{\sum_i R_i}.
\]

픽스터별로 볼 특성은 raw 적중률 순위가 아니다.

- 직선/파라레이 비중, ML/total/runline/prop 구성
- 정배/역배 비중과 중앙 American odds
- 한 경기 중복 포스팅, 평균 stake, 픽 수
- 삭제 표시와 결과가 나쁜 픽의 소실 여부
- 전체 군중과 고표본군 방향 일치
- 픽 공개 뒤 해외시장 무마진 확률 변화(CLV)
- 월별/시즌별 성과 부호 안정성

## 4. 경기 내부 수식

### 4.1 시장을 기준점으로 둔다

2-way decimal odds가 \(o_i\)일 때 기본 무마진 확률은

\[
q_i=1/o_i,\qquad p_{m,i}=q_i/\sum_j q_j.
\]

경기정보 모델이 시장을 대체하지 않는다. 시장 log-odds에 **잔차만** 더한다.

\[
\operatorname{logit}(p_{adj})=
\operatorname{logit}(p_m)+\beta^T x_{game}+\gamma^T x_{crowd}.
\]

### 4.2 현재 산출한 야구 원시 feature

모든 edge는 양수면 홈에 유리하도록 부호를 맞춘다.

\[
\begin{aligned}
x_{KBB9}&=(K\!-\!BB)/9_H-(K\!-\!BB)/9_A\\
x_{ERA}&=ERA_A-ERA_H\\
x_{WHIP}&=WHIP_A-WHIP_H\\
x_{HR9}&=HR/9_A-HR/9_H\\
x_{form}&=(RF-RA)_{H,5}/G_H-(RF-RA)_{A,5}/G_A.
\end{aligned}
\]

선발 이닝이 작을 때는 리그 평균으로 수축해야 한다.

\[
\tilde r=w r+(1-w)\bar r_{league},\qquad w=IP/(IP+k).
\]

\(k\)는 임의로 정하지 않고 과거 walk-forward에서 학습한다. 상대전적도 상대 선발
표본이 20이닝 미만이면 설명 문구로만 두고 모델 입력에서는 막는다.

확정 타선이 쌓이면 타순 가중 선수 품질을 추가한다.

\[
L_{team}=\sum_{j=1}^{9} PAshare_j\,Quality_j,\qquad
x_{lineup}=L_H-L_A.
\]

MLB는 xwOBA, KBO/NPB는 리그별 가용한 wOBA 또는 OBP/SLG 성분으로 `Quality`를
정의하되, **예상 라인업이 아니라 해당 시점에 확인된 타선**만 쓴다.

불펜 피로는 단순 “최근 경기 수”보다 투구수 지수감쇠가 낫다.

\[
Load_t=\sum_a pitches_a\exp(-\Delta day_a/\tau),\qquad
x_{pen}=Load_A-Load_H.
\]

### 4.3 날씨는 수준보다 수정폭

\[
x_{weather}=
Forecast(T\!-\!1h)-Forecast(T\!-\!24h).
\]

기온·바람·강수 변화와 open-roof indicator를 상호작용시킨다. dome은 0, retractable은
실제 지붕 상태가 없으면 missing이다. 날씨 자체가 정배를 지지해도 이미 시장에
반영됐다면 계수는 0이어야 한다.

## 5. 군중 수식과 “다들 왜 이렇게 쏠렸지?”

홈/원정 픽스터 수가 \(n_H,n_A\)일 때 0/1 무한대 방지를 위해

\[
s_H=\frac{n_H+0.5}{n_H+n_A+1},\qquad
H=-\frac{\sum s_i\log s_i}{\log 2}.
\]

`s_H`가 크고 `H`가 작으면 의견이 한쪽으로 모였다. 그러나 시장확률도 이미 같은
방향이면 중복 계산이다. crowd가 시장에서 예측되는 부분을 먼저 제거한다.

\[
r_{crowd}=\operatorname{logit}(s_H)-
(\alpha_0+\alpha_1\operatorname{logit}(p_m)).
\]

분석 글은 확률 하나 대신 기여도를 보여준다.

```text
시장 기준                 63.0%
확인된 선발 변경          -2.1%p
확정 타선/좌우 매치업      +0.8%p
불펜 최근 부하             -0.4%p
예보 수정                  +0.2%p
픽스터 군중의 시장초과 잔차 +0.0%p  (아직 전향 검증 미통과)
──────────────────────────────
조정 확률                  61.5%
판정: 정배 지지는 있으나 기존 가격보다 약함
```

각 줄에는 `observed_at`, 표본 크기, 결측/소표본 경고를 붙인다. 그래서 “다들 정배를
골랐다”가 원인이 아니라, 선발·타선·날씨 중 무엇이 공개된 뒤 쏠렸고 그 정보가 해외
시장에도 같이 움직였는지를 설명할 수 있다.

## 6. 통과 조건

시간 순서대로 expanding/walk-forward 학습하고 다음을 모두 통과해야 계수를 0에서
풀어 준다.

1. 시장 단독보다 out-of-sample Brier와 log-loss 모두 개선
2. calibration intercept≈0, slope≈1이 악화되지 않음
3. KBO·NPB·MLB 또는 시즌별 효과 방향이 뒤집히지 않음
4. 픽스터 군중은 최소 전향 100픽 후 1차, 500픽 후 재판정
5. crowd 추가모델이 경기정보+시장 모델보다 다시 개선

통과하지 못하면 정보는 버리지 않는다. 확률 보정에는 쓰지 않고 “정배를 설명하지만
가격에 이미 반영된 정보” 또는 “설명되지 않는 군중 쏠림”으로만 글에 표시한다.
