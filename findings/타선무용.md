# 타선 지표는 통째로 죽었다 — 그리고 그게 '과정 지표' 가설을 다시 쓰게 한다

- 측정일 2026-07-28 · KBO 타자 박스스코어 2,896경기 (안타 검산 100% 일치)
- 프로토 결합 2,559 · 학습 1,430(~2024) / 검증 1,129(2025~)
- 재현: `python src/game_detail.py batters kbo 2023 2026 && python src/batter_process.py`

## 왜 쟀나

투수는 정교했다. ERA(결과) → FIP(과정) → xFIP(과정+잡음축소) 로 가며
Brier 개선이 +0.00257 → +0.00432 → +0.00597 로 2.3배가 됐다.
**타선은 '팀 득점 평균'뿐**이었다 — ERA 를 쓰던 것과 같은 실수라고 봤다.

## [사실] 전부 무의미하다

기준 (Elo 단독) 검증 Brier 0.24681

| 피처 | 계수 | z | 개선 |
|---|---:|---:|---:|
| 팀 득점 차 (결과) | **−0.0526** | −1.05 | +0.00079 |
| wOBA 차 (과정) | −0.3966 | −0.22 | +0.00020 |
| 삼진율 차 (과정) | 1.5383 | 0.94 | +0.00020 |
| 볼넷율 차 (과정) | −1.7238 | −0.70 | +0.00013 |
| 순장타율 차 (과정) | −0.5152 | −0.32 | +0.00018 |
| BABIP 차 (운) | −0.6210 | −0.40 | +0.00032 |

**z 가 전부 |1.6| 미만이고 개선은 투수 효과(+0.006)의 10분의 1이다.**
팀 득점 차의 계수는 **음수** 다 — 최근 많이 득점한 팀이 덜 이긴다는 뜻이니
명백한 잡음이다.

조합해도 마찬가지다. `Elo + 팀득점 + wOBA` 는 `Elo + 팀득점` 보다 **나쁘다**
(0.24659 vs 0.24602). 축구 xG 처럼 "같이 쓰면 살아나는" 일도 없다.

## [사실] Elo 가 흡수한 게 아니다

"Elo 가 이미 타선 실력을 담고 있어서 겹치는 것 아닌가" 를 확인했다.
**Elo 를 빼고** 재도 결과는 같다 (기준선 0.24979):

| 모델 | 개선 | z |
|---|---:|---|
| Elo 단독 | +0.00299 | 2.16 |
| 팀 득점 단독 | +0.00003 | 0.27 |
| wOBA 단독 | −0.00000 | 0.91 |
| 과정 지표 전부 | +0.00128 | K% 만 1.46 |

**타선 최근 폼 자체에 신호가 없다.** 겹침의 문제가 아니다.

## ⭐ [의견] 그러면 투수는 왜 통했나 — 가설을 다시 쓴다

지금까지의 가설: *"결과 지표보다 과정 지표가 낫다."*
그 틀로는 이 결과가 설명되지 않는다. 타선의 과정 지표(wOBA)도 똑같이 죽었으니까.

더 맞는 설명은 이것이다:

> **경기마다 바뀌는 정보인가, 아니면 팀 레이팅이 이미 아는 것인가.**

| | 경기 간 변동 | 결과 |
|---|---|---|
| **선발투수** | 매 경기 다른 사람이 던진다. 에이스와 5선발은 딴판 | **+0.006** |
| **타선** | 매일 거의 같은 라인업. 팀 실력 근처에서 진동 | **≈0** |

선발은 Elo 가 알 수 없는 **그날의 정보**다. 타선 최근 폼은 팀의 고유 수준 주변
잡음이고, 그 수준은 이미 Elo 가 담고 있다(그마저 +0.00299 로 크지 않다).

FIP > ERA 였던 것도 "과정이라서"가 아니라, **선발을 잰다는 올바른 대상을 잡은
뒤 측정 정밀도를 올린 것**으로 읽는 게 맞다.

축구 결과도 이 틀에 맞는다 — xG 가 득실차를 밀어낸 건(`xG관문.md`) 둘 다
팀 단위 정보이고, xG 는 **같은 것을 더 정확히 재는 자**였다. 그래서 얻은 게
+0.004 로 작았다.

## [해석] 그래서 어디에 시간을 쓸 것인가

**타선에는 쓰지 마라.** 이 결과는 그 방향을 닫는다.

**경기마다 바뀌는 것**을 찾아야 한다:
- 구장(파크팩터) — 경기마다 바뀌고 Elo 가 모른다. 언더오버 격차에 직결. **수집 완료**
- 불펜 가용성 — 단, `박빙과xFIP.md` 에서 직접 재보니 z=0.51 로 죽었다
- 라인업 결장(주전 이탈) — 축구에서 시도했으나 표본 부족으로 판정 불가였다
- 날씨·기온 — 미수집
