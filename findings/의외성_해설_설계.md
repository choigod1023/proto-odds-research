# 의외성 해설 설계

## 목적

정배를 무조건 추천하거나 역배를 억지로 만드는 것이 아니다. 시장의 기본 판단과
득점분포를 다른 마켓에 투영한 결과가 충돌할 때, 역배가 성립하는 경기 경로를
조건부로 설명한다.

## 현재 진단식

- `pM_f`: 마진을 제거한 시장의 정배 승률
- `pS_f`: 득점분포 모델의 정배 승률
- `G_win = pM_f - pS_f`
- `G_handicap = pS(역배팀 핸디캡 커버) - pM(역배팀 핸디캡 커버)`
- `G_close = pS(접전 밴드) - pM(접전 밴드)`

현재의 임시 의외성 조건은 다음과 같다.

```text
surprise = (G_win >= 0.08)
           AND (G_handicap >= 0.08 OR G_close >= 0.08)
```

8%p는 적중확률 보정값이 아니라 설명을 여는 보수적 임시 문턱이다. 승패 모델 하나만
시장과 다르면 모델 오류로 보고 문장을 열지 않는다. 핸디캡과 접전 밴드도 같은
득점분포에서 나온 값이므로 독립 증거라고 부르지 않고 `교차 마켓 진단`이라고 부른다.

총득점 추정은 다음과 같다.

```text
E(home) = (홈 최근 평균득점 + 원정 최근 평균실점) / 2
E(away) = (원정 최근 평균득점 + 홈 최근 평균실점) / 2
E(total) = E(home) + E(away)
```

`E(total)`은 반드시 실제 발매 U/O 라인과 비교한다. 종목별 고정값을 실제 기준선처럼
표시하지 않는다. 기대 득점 차이 역시 다득점 차 승리의 확률로 해석하지 않는다.

## 문장 구조

1. `시장 기본값`: 배당에서 읽은 정배 확률과 배당. 서비스의 적중확률이라고 부르지 않는다.
2. `어라 포인트`: 승패 확신과 핸디캡·접전 밴드가 어느 방향으로 얼마나 엇갈리는지 쓴다.
3. `역배 시나리오`: 역배가 나온다면 어떤 경기 흐름이어야 하는지 조건부로 쓴다.
4. `쏠림 의심`: 실제 베팅 비율·금액 데이터가 없으므로 쏠림을 사실로 단정하지 않는다.

## LA다저스 예시

- 시장 기본값: LA다저스 승 65%, 배당 1.39
- 득점분포 승률: LA다저스 53% (`G_win = 12%p`)
- 콜로라도 `+2.5` 커버: 시장 59%, 모델 76% (`G_handicap = 17%p`)
- 1점 차: 시장 23%, 모델 36% (`G_close = 13%p`)
- 실제 U/O 11.5, 단순 합계 추정 10.2: 언더 방향

따라서 역배의 설명은 `콜로라도가 더 강하다`가 아니다. 시장이 다저스 압승에 준
가격보다 접전 경로가 넓고, 저득점 접전이 길어지면 한 번의 득점으로 뒤집힐 수 있다는
내용이어야 한다.

## 검증 계획

이 진단을 추천 수식으로 승격하려면 시계열 누수를 막은 워크포워드 검증이 먼저다.

- 각 경기에서 구매 시각에 실제로 알 수 있던 배당·라인만 저장한다.
- `surprise=1`과 나머지를 분리해 역배 승률, 핸디캡 적중률, ROI를 비교한다.
- 배당 구간·홈/원정·리그별 최소 표본과 신뢰구간을 같이 낸다.
- Brier score와 log loss로 확률 품질, ROI로 가격 품질을 따로 본다.
- 종료 배당을 저장해 CLV를 보조 지표로 보되, CLV가 적중을 뜻한다고 쓰지 않는다.
- 8%p 문턱은 과거 학습 구간에서만 선택하고 다음 기간에서 고정 검증한다.

실제 투표 비율이나 베팅 금액을 확보하면 `인기팀 여부`, `티켓 비율-금액 비율 차이`,
`시작 배당 대비 현재 배당`을 별도 변수로 추가한다. 그 전에는 시장-모델 괴리를
대중 쏠림의 증거로 사용하지 않는다.
