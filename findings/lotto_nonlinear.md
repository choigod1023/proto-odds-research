# 여러 회차·비선형 로또 의존성 탐색

24개 제한된 비선형 모델을 검증했다. 실제 자료에서 2개 모델의 평가 점수가 기준보다 조금 높았지만, 전체 모델 탐색을 반영한 순열 p값은 **0.933**, 균등 독립 이력 비교 p값은 **0.936**이었다. 무작위보다 예측이 잘된다는 근거를 찾지 못했다. 미래 예측·자동 감시는 시작하지 않았다.

## 고정한 후보와 평가

입력은 기존 실제 자료 1~1245회다. 처음 10회는 지연 입력 준비에 쓰고 11~740회로 학습, 741~1245회 505회로 평가했다. 이전에 이미 살펴본 자료여서 새로운 확증 검증은 아니다. source/data SHA256, 시드, 검사 목록은 실제 평가 전에 protocol.json으로 저장했다.

예측 대상 네 가지:

- 홀수 개수의 짝홀.
- 22 이하 번호 개수의 짝홀.
- 번호 합계의 5개 구간: 100 미만, 100~119, 120~149, 150~169, 170 이상.
- 연속한 번호가 하나 이상 포함됐는지.

각 대상에 다음 여섯 조건을 적용했다(총 24개): 같은 대상의 1·2회 전 상태 조합, 1·2·3회 전 상태 조합, 1·2회 전 상태 코드 짝홀의 XOR, 직전 5회 중 상태 코드가 상위 절반에 해당하는 횟수, 직전 회차의 홀수·낮은 번호 개수 짝홀 조합, 같은 대상의 5·10회 전 상태 조합. 이진 대상의 상위 절반은 값 1, 합계 구간 대상은 코드 2 이상이다. 합계 구간 코드의 XOR는 수치 패턴 후보 하나일 뿐 물리적 의미를 부여하지 않는다.

조건별 범주 확률을 학습 구간 빈도로 추정하되, 시간 독립 기준 분포 쪽으로 가상 관측 20개만큼 축소한다. 기준 분포에는 각 범주당 1개의 가상 관측을 사용한다. 평가 자료로 매개변수를 다시 학습하거나 후보를 추가하지 않았다. 학습되지 않은 조건은 기준 분포로 돌아간다.

평가 점수는 시간 독립 모델 대비 총 로그 확률 이득이다. 실제 회차 순서를 999번 섞고 매번 24개를 모두 재학습·평가했다. 각 순열의 최고 점수를 실제 최고 점수와 비교해 이번 탐색 내 다중 비교를 반영했다. 별도로 균등 6개 조합 이력 999개에서도 같은 검사를 했다. p=(1+실제 이상 최고 점수 수)/1000이며 동률을 포함한다. 순열은 한 회차의 번호 집합과 특징 간 관계를 보존한다.

## 실제 결과

가장 높은 점수는 5·10회 전 상태로 낮은 번호 개수의 짝홀을 예측한 모델이었다.

- 총 로그 이득: +0.398010220 nats.
- 회차당 +0.001137044비트.
- 평가 앞 250회 +0.311255272 nats, 뒤 255회 +0.086754948 nats.
- 해당 후보만 비교한 보정 전 순열 p=0.154.
- 24개 탐색을 반영한 순열 p=0.933.

두 번째 양수 모델은 직전 두 상태 코드 XOR로 연속 번호 포함 여부를 예측한 모델이다. 총 이득 +0.020365202 nats, 보정 p=0.995였고 평가 후반 점수는 음수였다. 나머지 22개는 전체 평가 점수가 기준 이하였다. 모든 후보의 점수와 p값은 results.json에 기록했다.

이 점수는 번호 조합 전체의 당첨 확률 증가나 참 엔트로피 감소가 아니다. 각 모델은 조합의 일부 특징만 예측한다. 양수인 후보가 있다는 이유만으로 규칙을 채택하지 않는다.

## 비선형 탐지 능력과 오탐

모의 이력도 매 회차 서로 다른 1~45의 번호 6개를 유지한다. 선택된 회차에서 홀수 개수의 짝홀이 직전 두 회차 짝홀의 XOR가 되도록 강제한다. 원하는 짝홀이 나올 때까지 균등 6개 조합을 재추출하므로 해당 짝홀 조건 안에서는 균등하다. 주입 확률 25%는 모든 회차의 25%를 일정 규칙으로 강제하는 확률이며, 당첨률이나 예측 정확도가 25%포인트 증가한다는 뜻이 아니다.

조건마다 이력 100개, 이력당 순열 99개를 사용했고 각 순열에서 24개 탐색을 반복했다. 양수 점수이면서 가족 단위 p<=0.05를 탐지로 판정했다.

- 주입 없음: 9/100 탐지. 95% 이항 구간 4.20~16.40%.
- 주입 확률 25%: 100/100 탐지. 95% 구간 96.38~100%.
- 주입 확률 50%: 100/100 탐지. 동일 구간.

선택한 XOR 형태에는 탐지 능력이 있었지만 관측 오탐률은 9%였다. 명목 5%가 구간에 포함된다고 해서 오탐률 5%를 정밀하게 실증한 것은 아니다. 이 정도의 강한 주입만으로 미세한 효과나 모든 비선형 관계를 탐지할 수 있다고 주장하지 않는다. 예측 개선은 실제 자료에서 재현되지 않았다.

## 자원·검증·재현

단일 논리 CPU, BelowNormal 우선순위, 수치 라이브러리 스레드 1개를 적용했다. 모의 이력 또는 평가 반복마다 계산 시간의 25% 이상 쉬었고 전체 실행 예산은 600초였다. 실제 본 실행은 **32.986초**, 프로세스 CPU 시간 **25.188초**, 해당 계산 프로세스 최대 작업 집합 메모리 **98.441MiB**였다. 실행 도중에도 CPU affinity=1 및 BelowNormal을 확인했다. 실행기 부모 프로세스와 다른 프로그램의 메모리는 이 최대값에 포함하지 않는다. 온도·전체 컴퓨터 평균 부하는 측정하지 않았다. 오류 로그는 비어 있고 실행은 정상 종료했다.

관련 테스트 6개 통과: 번호 정렬 불변성, 강제 XOR와 고유 번호 보존, 평가 데이터 변경 시 학습 확률 불변, 과거만 사용하는 조건, 직접 확률비 합산과 점수 일치, 최고 점수 기반 비교 및 동률 처리. 저장한 배열에서 두 통합 p값과 소스·자료 해시를 별도로 재검산했다.

```text
python scripts/lotto_nonlinear.py
python -m pytest tests/test_lotto_nonlinear.py -q
```

결과는 data/lotto/nonlinear-study/의 protocol.json, results.json, scores.npz 및 두 입력 JSONL에 보존했다. 이번 24개 검사 보정은 이전 대화에서 시도한 전체 모델 선택 이력을 보정하지 않는다. 순열 비교는 시간 교환가능성을 기준으로 하므로, 유의한 결과가 있었더라도 추첨 환경 변화와 실제 예측 가능한 의존성을 별도로 구분해야 한다. 이번 음성 결과는 모든 비선형 패턴의 부재를 증명하지 않는다.
