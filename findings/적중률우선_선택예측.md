# 적중률 우선 선택예측 재감사

## 결론

실전에서 알 수 없는 미래 순위를 제거하고, 운영과 같은 Shin 마진 제거법·인과적 xFIP·
고정 절대 문턱으로 다시 계산했다. 2026년 선택 경기의 적중률은 높아 보이지만 **같은
경기에서 시장과 다른 승자를 더 잘 고른 증거가 없고 수익도 나지 않았다.** 2026년은
이미 프로젝트 개발 중 반복해서 확인한 자료이고 과거 배당의 구매 가능 시점도 확인되지
않으므로, 이 결과는 깨끗한 홀드아웃 검증이 아닌 `research_only` 역사 감사다.

- 규칙 선택: 2025년만 사용
- 역사 감사: 2026년 8월 25일까지
- 모델: 최근 730일 팀 컨텍스트+xFIP 비선형 잔차모델
- 시장 결합비: 모델 75%, 시장 25% (2024년 확률오차로 선택)
- 마진 제거: 운영과 같은 Shin
- 고정 규칙: 선택 배당 1.30 이상, 모델 신뢰도 **0.621231 이상**
- 2025년 목표 커버리지: 30%

## 2026 역사 감사

- 전체 결합 가능 KBO 519경기, xFIP 사용 가능 418경기
- 86경기 선택, 59승: 적중률 **68.60%**
- 전체 KBO 기준 커버리지 **16.57%**, xFIP 사용 가능 경기 기준 **20.57%**
- 평균 배당 **1.407**
- ROI **-2.94%**
- 적중률 Wilson 95% 구간 **58.18~77.44%**

2025년에 고정한 시장 신뢰도 문턱 0.607423은 2026년에 104경기 65승,
62.50%였다. 다만 선택 수가 달라 직접 비교하기 어렵다. 시장 신뢰도 상위 86경기로
수를 사후 일치시킨 진단에서는 시장이 54승, 62.79%였고 모델 선택기와의 차이는
+5.81%p였다. 날짜 블록 부트스트랩 95% 구간은 **-1.50~+13.38%p**로 0을
포함한다. 이 비교 자체도 전체 기간 순위를 사용한 회고적 진단이라 운영 규칙이 아니다.

더 중요한 사실은 모델이 선택한 86경기에서 모델과 시장의 승자 방향 불일치가 **0건**
이었다는 점이다. 같은 경기의 시장 방향도 59승으로 적중률이 똑같아 승자 예측 edge는
0%p다. 모델 Brier는 0.21969, 시장은 0.22359로 확률 크기가 0.00391
좋았지만, 이는 승자 방향을 뒤집어 맞힌 증거가 아니다. 전체 시장 방향 56.94%보다
선택 적중률이 11.67%p 높다는 수치 역시 **시장과 같은 방향 중 쉬운 경기를 거른 효과**다.

## 데이터 시점과 누수 감사

- 리그 HR/9와 FIP 상수, 투수 최근 기록은 각 경기보다 이전에 끝난 경기만 사용한다.
- 시작시각/gameId가 보존되지 않은 더블헤더 중복 키는 전부 제외한다.
- 과거 전 구간에는 예고 선발 스냅샷이 없어 박스스코어의 실제 선발을 대용했다.
- 스냅샷이 있는 2026-07-28~08-25의 89경기·178개 선발 측면 중 177개가
  일치했다. 일치율 99.44%지만 이전 기간을 확인할 수 없어 여전히 상한 추정이다.
- 정산 archive 배당에는 `collected_at`이 없어 개장·마감·구매 가능 시점을 인증할 수
  없다. 따라서 archive 배당으로 계산한 적중률과 ROI는 운영 성과가 아니라 연구용이다.
- KBO 스냅샷 감사에서 최신 경기 전 배당과 비교 가능한 것은 69경기뿐이었고 4경기
  (5.80%)의 가격이 달랐다. T-30은 60경기 중 11경기(18.33%)가 달랐으며 선호
  방향 반전도 1건 있었다.
- 519개 archive 시장 중 같은 가격이 스냅샷에서 처음 확인된 시점이 경기 시작 이후인
  사례가 24개였고, 430개는 같은 가격이 한 번도 관측되지 않았다. 시작 후 최초 관측은
  그때 가격이 바뀌었다는 뜻이 아니라 **경기 전 가격이었다는 증거가 없다는 뜻**이다.
- 2026년은 프로젝트에서 이미 여러 차례 확인했으므로 깨끗한 최종 홀드아웃이 아니다.

## 운영 결정

1. 기존 추천을 이 규칙으로 교체하지 않는다.
2. 문턱은 해시가 붙은 `findings/accuracy_rule.json` 한 파일에서만 읽는다.
3. 실제 예고 선발·판매 상태·T-30 배당·모델 버전을 경기 전에 고정해 shadow 기록한다.
4. 신규 300픽에서 Wilson 하한 60% 이상, 같은 경기 시장 대비 확률오차 개선,
   ROI 0 이상을 모두 충족해야 승격한다.
5. 시장과 같은 방향을 고르는 동안에는 “시장을 이겼다”가 아니라 “시장 내 선별이
   좋아졌을 가능성”으로만 표현한다.
