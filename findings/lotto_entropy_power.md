# 로또 엔트로피·시간 의존성 탐색과 탐지 능력

실제 1~1245회 자료에서 두 시간 의존 모델의 이후 구간 예측 개선을 확인하지 못했다. 균등 독립 이력 비교의 두 모델 통합 p값은 0.956, 실제 이력의 회차 순서를 섞어 재학습한 비교 p값은 0.963이다. 조건부로 승인된 미래 회차 순차 검정 단계에는 진입하지 않았다.

## 설계

학습 1~740회, 평가 741~1245회(505회). 이 실제 자료는 이전 연구에서 이미 확인했으므로 독립 확증 검증이 아니다. 보너스 번호는 제외했다. 데이터 원본과 SHA256은 입력 파일 및 protocol.json에 저장했다.

1. 직전 회차와 겹치는 개수 K를 쓰는 지수 기울기 모델: P(K=k)는 C(6,k)C(39,6-k)/C(45,6)에 exp(theta*k)를 곱하고 정규화한다. 같은 겹침 개수를 가진 조합에는 균등 확률을 부여한다. 학습 평균을 이론값 0.8 방향으로 가상 관측 100개만큼 축소하고 theta는 [-2,2]로 제한한다. 평가 기준은 균등 6개 조합이다.
2. 미리 지정한 1번 번호의 직전 출현 여부를 쓰는 이진 Markov 모델. 비교 기준은 학습 구간에서 얻은 시간 독립 출현 확률이다. 조건별 관측을 가상 관측 100개로 축소한다. 포함/미포함 집합 내부에 균등 확률을 주면 정규화된 전체 조합 모델이 되고, 두 모델의 확률비는 이진 확률비와 같다. 45개 중 가장 좋아 보이는 번호를 고르지 않았다.

평가 통계량은 두 모델의 총 로그 예측 이득을 별도 균등 이력 200개에서 구한 평균·표준편차로 표준화한 뒤 최댓값을 취한 것이다. 독립 균등 이력 999개로 통합 귀무분포를 만든다. 실제 자료의 순서 섞기 999번도 매번 모델을 재학습하며 동일한 통계량을 사용한다. p=(1+실제 이상 통계량 개수)/(비교 이력 수+1). 한 회차의 6개 숫자 집합은 그대로 유지한다. 이 방식은 이번 두 모델의 선택을 반영하지만 이전 전체 모델 탐색을 보정하지 않는다.

미래 단계 진입 조건: 통합 균등 p와 순서 섞기 p가 모두 0.05 이하, 선택 모델 평가 이득 양수, 강한 반복 주입에서 탐지율 80% 이상. 실제 자료 조건에서 탈락했다. 새로운 미래 예측 규칙·자동 감시는 시작하지 않았다.

## 탐지 능력

각 가짜 이력은 1245회이며 매 회차 서로 다른 6개 숫자를 보존한다. 균등 추첨 후 주입 확률에 따라 목표 번호가 없을 때 기존 번호 하나를 균등하게 골라 교체한다.

- 정적 편향: 목표 번호는 항상 1번. 첫 회차부터 동일하게 적용해 시간 독립성을 유지한다.
- 반복 편향: 직전 회차의 6개 번호 중 하나를 균등하게 고른다. 첫 회차는 균등이다.

주입 확률 10%는 당첨 확률이나 반복률이 10%포인트 올라간다는 뜻이 아니다. 반복 주입 시 목표 번호가 이미 있으면 바꾸지 않는다. 반복 개수 기댓값은 대략 0.8+주입확률*0.8667*(34/39)이다. 따라서 10% 주입은 약 0.876, 25% 주입은 약 0.989다. 매우 미세한 물리적 편향의 검출력을 입증한 실험은 아니다.

각 조건 200회 반복한 균등 기준 통합 검사의 탐지율:

- 정적 주입 0·10·25·50·100%: 6.5·15·55·99·100%.
- 반복 주입 0·10·25·50·100%: 8·66.5·99.5·100·100%.
- 별도 균등 검증 200개 중 14개 탐지: 7%, 95% 이항 구간 3.88~11.47%. 명목 5%를 포함하지만 정밀한 오탐률 검증에는 부족하다.

이 검사는 정적 편향도 탐지하므로 균등 기준에서 유의하다는 사실만으로 시간 의존성을 말할 수 없다. 이를 구분하는 순서 섞기 검사도 추가 시험했다(조건당 100개 이력, 각각 199회 순열, 독립 시드 2026101702):

- 정적 주입 50%: 9/100 탐지, 95% 구간 4.20~16.40%.
- 반복 주입 25%: 98/100 탐지, 95% 구간 92.96~99.76%.

정적 조건의 관측 오탐률 9%를 숨기거나 5%가 실증됐다고 주장하지 않는다. 반복 편향에 대한 탐지 능력은 높지만, 표본 100개의 오탐률 추정은 거칠다. 추가 시험은 실제 결과를 본 뒤 설계한 진단이며 실제 p값이나 진입 기준을 변경하지 않았다.

## 실제 결과와 엔트로피 해석

- 겹침 모델: 평가 총 로그 이득 -0.715445834 nats, 회차당 -0.002043901 비트.
- 1번 번호 Markov 모델: -0.673575884 nats, 회차당 -0.001924286 비트.

둘 다 기준 모델보다 더 긴 부호 길이, 즉 더 나쁜 예측 점수를 냈다. 이는 참 조건부 엔트로피가 증가했다는 추정이 아니라, 제한된 모델의 외부 평가 교차 엔트로피 차이다. 모든 비선형 의존성이 없음을 증명하지 않는다. 두 특징으로 탐지할 수 없는 패턴이나 더 작은 효과는 남는다.

공정한 전체 조합 엔트로피는 log2(C(45,6))=22.95749비트다. 1245개 관측 빈도로 구한 경험적 조합 엔트로피의 상한 log2(1245)=10.28193비트와 직접 비교해 예측 가능한 구조를 주장하면 안 된다. 관측되지 않은 조합이 대부분이기 때문이다.

## 실행·재현·수정 이력

CPU 하나에 고정, BelowNormal 우선순위, 수치 라이브러리 스레드 1개, 배치 20개, 계산 시간의 25% 이상 휴식을 적용했다. 30분 시간 예산을 두었다. 최종 본 실행은 15.289초(프로세스 CPU 10.391초), 추가 순열 탐지 시험은 10.551초였다. 이는 최종 실행 두 개의 시간으로, 초기 실행·수정 후 재실행·테스트까지 포함한 전체 작업 시간이 아니다. 최대 메모리·온도는 측정하지 않았다. 결과를 얻은 프로세스는 종료했고 백그라운드 작업을 남기지 않았다.

초기 실행 후 두 가지 검증상 수정을 했다. 통계량 표준화에 쓰는 이력을 귀무분포 보정 이력과 분리했고, 정적 편향을 첫 회차부터 적용하도록 수정했다. 수정 전 실제 p값은 균등 0.962/순열 0.959였고, 최종값은 0.956/0.963이다. 실제 두 모델 점수와 결론은 바뀌지 않았다. 결과를 본 뒤 구현을 점검·수정했으므로 엄격한 사전등록 실험이라고 주장하지 않는다.
