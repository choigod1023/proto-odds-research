# 고정 시드 선별 규칙: 가짜 이력 999개 및 추가 7회 검증

기존 선별 규칙과 실제 선별군을 유지했습니다. 가짜 이력을 99개에서 999개로 늘린 비교와 기존 실험에 없던 1239~1245회 평가를 수행했습니다. 과거 평가 구간은 이미 여러 번 확인한 후향 자료이며, 추가 7회도 이미 발표된 결과입니다. 새 회차 평가는 이 실험에서 미사용했던 구간의 평가이지, 앞으로 발표될 결과를 기다린 전향 실험이 아닙니다.

## 고정한 것과 늘린 것

- 생성기: 기존 splitmix64-paired128-v1. 상위 64비트는 홀수, 하위 64비트는 짝수 회차에 사용합니다.
- 학습: 1~740회. 부분 후보 각각 100만 개. 첫 홀수·짝수 회차를 맞히도록 역산하고, 부분별 2회 이상 적중한 후보를 모두 짝짓습니다. 첫 두 적중은 구성한 결과입니다.
- 실제 선별군: 홀수 부분 35개 × 짝수 부분 40개 = 완성 시드 1,400개. 이번에도 같은 시드이며 재선별하지 않았습니다.
- 과거 구간: 검증 741~990회, 최종 991~1238회. 비교군 199개와 난수 시드, 표준화 점수, 두 구간 Bonferroni 보정을 그대로 유지했습니다.
- 가짜 이력만 99개에서 999개로 늘렸습니다. 기존 실제·가짜 이력 100개를 보존하고 새 가짜 이력 900개를 계산했습니다. 실제 이력은 한 번 재실행해 이전 결과와 완전히 같음을 확인했습니다.
- 새 가짜 이력 계산에 사용한 부분 후보는 18억 개입니다. 기존 이력까지 포함한 고유 이력 1,000개의 누적 부분 후보는 20억 개이며, 실제 이력 동일성 확인용 재실행 200만 개는 별도입니다.
- 중간 결과에 따라 멈추거나 후보 수·평가 지표를 바꾸지 않았습니다. 추가 계산 시간은 419.76초입니다.

## 가짜 이력 확대 결과

가짜 이력 999개 중 생존 조합이 있는 이력은 999개입니다. 각 가짜 이력의 최고 학습 적중 횟수 분포는 {'4': 996, '5': 3}입니다. 가짜 이력에서 나온 완성 시드 수의 95% 경험적 구간은 1301.7~3000.4개입니다.

실제 선별군의 성과 자체는 바뀌지 않았습니다. 달라지는 것은 이를 비교할 가짜 이력의 수와 Monte Carlo 오차입니다.

### 검증 구간

- 실제 선별군 평균 일치 수: 0.81140000. 무선별 대조군: 0.79970632.
- 실제 표준화 점수 이상인 가짜 이력: 67/999.
- Monte Carlo 단측 p=0.0680; 두 구간 보정 p=0.1360.
- 비교 꼬리확률의 Monte Carlo 오차에 대한 95% 이항 구간: [0.0524, 0.0844]. 이는 전략 효과 크기의 신뢰구간이 아닙니다.

### 최종 구간

- 실제 선별군 평균 일치 수: 0.81026786. 무선별 대조군: 0.80005746.
- 실제 표준화 점수 이상인 가짜 이력: 105/999.
- Monte Carlo 단측 p=0.1060; 두 구간 보정 p=0.2120.
- 비교 꼬리확률의 Monte Carlo 오차에 대한 95% 이항 구간: [0.0868, 0.1258]. 이는 전략 효과 크기의 신뢰구간이 아닙니다.

기존 99개 비교의 보정 p값은 검증 0.12, 최종 0.28이었습니다. 이력을 더 늘리는 것은 과거 선별 성과를 높이는 작업이 아니며 비교의 정밀도를 높이는 작업입니다. Monte Carlo 값은 `(1+초과 개수)/(1+반복 수)`로 계산했습니다. 999개의 가짜 이력에서도 임계값 0.05 아래의 보정 결과를 얻지 못했습니다.

## 기존 실험에서 쓰지 않은 1239~1245회

기존 원장은 1238회까지였습니다. 2026-10-16에 동행복권 공식 API에서 1239회(2026-08-29)부터 1245회(2026-10-10)까지 7개 회차를 수집했습니다. 응답에 함께 포함된 1236~1238회가 기존 원장과 일치함도 확인했습니다. 기존 학습 원장은 갱신하지 않고 추가 원장을 별도로 보관했습니다.

고정된 1,400개 시드를 이 7개 회차에 그대로 적용했습니다. 추가 구간의 비교군 수는 결과 계산 전에 9,999개로 정했고, 각각 홀수 부분 35개·짝수 부분 40개와 동일한 공유 구조를 유지했습니다. 이는 후보나 선별 규칙의 변경이 아닙니다.

- 선별군 평균 일치 수: **0.76326531**.
- 무작위 대조군 평균: **0.79964879**.
- 차이: **-0.03638349**.
- 무작위 대조군 평균 일치 수의 95% 참고 범위: [0.70561, 0.89643].
- 선별군 이상인 대조군은 9,999개 중 7,713개, 보정된 Monte Carlo 단측 p=0.7714입니다. 여기의 ‘보정’은 +1 Monte Carlo 계산을 뜻하며 여러 검정에 대한 보정은 아닙니다. 신규 구간 전체의 한 가지 사전 고정 지표로 평가했습니다.
- 선별군 1등 적중: 0회.

완성 시드별 게임 수를 합하면 9,800건이지만 서로 독립인 9,800번의 추첨이 아닙니다. 실제 추첨은 7회이고, 중복되는 부분 수열을 제외한 시드·회차 조합은 260건입니다. 위 무작위 대조군도 이 중복 구조를 동일하게 반영했습니다. 새 구간의 관측 평균은 더 낮았지만, 표본이 작고 무작위 참고 범위 안이므로 장기적으로 더 나쁘다고 확정할 수도 없습니다.

## 해석과 한계

이번 확장에서는 기존의 작은 평균 우위를 통계적으로 뒷받침하는 근거를 얻지 못했고, 추가 7회에서도 우위가 재현되지 않았습니다. 모든 가능한 효과가 정확히 0이라는 증명은 아닙니다. 평균 일치 수는 1등 확률이나 수익률의 대체 증거가 아닙니다.

규칙을 유지한 채 아직 발표되지 않은 회차를 평가하려면 실제로 그 결과가 나온 뒤 확인해야 합니다. 이번에 찾은 7개 회차는 이전 실험에서는 사용하지 않았지만 이미 공개된 자료입니다. 별도의 정기 실행이나 구매는 설정하지 않았습니다.

## 검증과 재현

- 관련 테스트 26개 통과.
- 원본 실제 결과 재실행 및 기존 기록 100개 동일성 확인.
- 전체 이력 1000개의 생존 부분 시드 90,746개, 학습 적중 비교 33,576,020건을 독립 스칼라 Python으로 검산.
- 새 7개 회차의 완성 시드별 게임 9,800건을 별도 스칼라 생성·조합 변환으로 검산.
- 비생존 후보 전체를 독립적으로 다시 전수 탐색한 것은 아닙니다. 작은 합성 자료에서 native/Python 선별 일치, 공유 수열 대조군 집계, 평가 자료가 선별에 영향을 주지 않는지를 테스트했습니다.

결과 폴더는 `data/lotto/reports/null-expanded/`입니다. `histories.jsonl.gz`는 기존·추가 이력 1,000개의 전체 결과를 저장한 압축 JSON Lines입니다. `protocol.json`, `prefix-manifest.json`, `seed-summary.json`, `verification.json`에 조건과 검산 결과를 보관했습니다. `new-rounds/official-response.txt`는 공식 JSON 원응답이고 `draws.jsonl`, `evaluation.json`은 추가 원장과 평가 결과입니다.

재현 순서:

1. `.local-build` 폴더를 만들고 `g++ -O3 -march=native -std=c++17 -pthread -static -DMIN_HITS=2 src/lotto_seed_scan.cpp -o .local-build/scan-two.exe`로 컴파일합니다.
2. `python src/lotto_null_extension.py --prior <PR298의 bias-null 결과 폴더> --executable .local-build/scan-two.exe --output <새 결과 폴더>`를 실행합니다. 이전 결과를 지우거나 덮어쓰지 않습니다.
3. 새 결과 폴더의 `new-rounds/official-response.txt`에 보관된 공식 원응답을 복사하고 `python src/lotto_new_rounds.py --report <새 결과 폴더>`를 실행합니다.
4. `python scripts/verify_lotto_null_extension.py --report <새 결과 폴더>`로 검산합니다.
5. `python -m pytest -q tests/test_lotto645.py tests/test_lotto_seed_expanded.py tests/test_lotto_seed_128.py tests/test_lotto_bias_null.py tests/test_lotto_null_extension.py`로 테스트합니다.
