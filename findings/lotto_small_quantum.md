# 작은 양자 회로의 로또 분포 학습 실험

6큐비트 양자 회로를 일반 CPU로 모의실험했다. 인위적으로 만든 패턴은 학습했으나 로또에서 균등 무작위보다 우월하다는 근거는 얻지 못했다. 실제 양자 하드웨어를 사용하거나 양자 계산 우위를 입증한 실험은 아니다.

## 계산 규모와 실제 자원 사용

- 큐비트 6개, 상태 64개, 실수 상태벡터 512바이트.
- RY 회전과 이웃 큐비트 사이의 고리형 CNOT을 2층 적용. 학습 매개변수 12개.
- 단일 프로세스, 논리 CPU 하나에 고정, Windows 실행 우선순위 BELOW_NORMAL, 수치 라이브러리 스레드 1개.
- 실행 상한 120초, 프로세스 메모리 감시 기준 256MiB. 목적함수 평가와 이력 반복 사이에서 검사하며 OS의 강제 메모리 할당 제한은 아니다.
- 실제 벽시계 시간 6.67초, CPU 시간 3.95초, 프로세스 최대 작업 집합 약 89.90MiB. 매 가짜 이력 뒤에 25ms 쉬었다.

이 수치는 실험 프로세스의 사용량이다. 컴퓨터 전체의 온도·전력·다른 프로세스 사용량은 측정하지 않았다.

## 로또를 회로에 표현한 방법

조합을 `8 × 1~22 번호의 개수 + 홀수 개수`로 표현했다. 실제 가능한 범주는 49개이며 64개 양자 상태의 일부를 사용한다. 같은 범주에 속한 개별 조합들은 같은 확률을 갖는다. 따라서 개별 번호의 정체성이나 모든 번호 쌍의 관계를 학습하지 못한다.

균등 로또에서도 각 범주의 빈도는 다르다. 네 집단(낮은 홀수 11개, 낮은 짝수 11개, 높은 홀수 12개, 높은 짝수 11개)에서 뽑는 경우의 수를 정확히 계산했다. 범주별 조합 수의 합은 8,145,060이며, 낮은 번호 개수와 홀수 개수의 주변분포도 초기하분포와 대조했다.

양자 회로의 Born 확률을 q(c), 균등 로또의 범주 확률을 b(c)라 하면 실제 모델은 다음과 같다.

`p(c) = 0.05 b(c) + 0.95 b(c) q(c) / sum_d b(d) q(d)`

범주 확률을 그 범주에 속한 조합 수로 나누어 개별 여섯 번호 조합의 확률로 환산한다. 이는 회로의 측정 결과를 그대로 사용하는 순수 QCBM이 아니라, 고전적인 기저 분포 보정과 균등 혼합을 추가한 모델이다. 회로가 균등 상태이면 개별 로또 조합도 정확히 균등해진다. 혼합 항은 특정 결과에 확률 0을 부여하지 않도록 한다.

## 사전에 고정한 학습과 검증

1~740회만 학습했다. 균등 로또에 해당하는 의사 관측 740회를 더한 범주 분포에 교차 엔트로피를 맞췄다. 초기 각도는 첫 층 π/2, 둘째 층 0이며 재시작·매개변수 탐색은 하지 않았다. L-BFGS-B 최대 40회 반복, 함수 평가 예산 800, ftol=1e-9로 고정했다. 실제·인공 패턴·가짜 이력의 모든 학습이 정상 수렴했다.

741회 이후에는 회로를 고정했다. 주 평가 구간은 991~1238회, 부 평가 구간은 741~990회 및 1239~1245회다. 어떤 구간도 이번 모델을 선택하거나 수정하는 데 쓰지 않았다. 다만 모두 이전 연구에서 이미 확인한 자료이므로 신규 미공개 검증은 아니다.

주 지표는 실제 당첨 조합의 로그 확률에서 균등 조합의 로그 확률을 뺀 평균이다. 양수가 개선이다. 그 지수값은 당첨 조합에 부여한 확률비의 기하평균이며, 구매 복권의 1등 당첨률 상승률이나 실제 적중 횟수가 아니다. 복권을 추출해 1등 횟수를 비교하는 실험은 하지 않았다.

## 결과

- 인위적 패턴: 별도 교사 회로에서 학습 740개, 독립 평가 5,000개 생성. 평균 로그점수 차이 +0.899514. 모형이 표현 가능한 강한 패턴은 학습했다. 모든 형태의 패턴을 학습한다는 의미는 아니다.
- 검증 741~990회: 평균 로그점수 차이 −0.002535766, 기하평균 확률비 0.997467446, 상측 p=0.63.
- 주 평가 991~1238회: +0.002956079, 확률비 1.002960452, 상측 p=0.15.
- 기존 추가 구간 1239~1245회: +0.001453065, 확률비 1.001454121, 상측 p=0.44.

주 평가에서는 실제 당첨 조합에 부여한 확률이 기하평균으로 약 0.296% 높았지만, 앞선 검증 구간에서는 약 0.253% 낮았다. 개선이 일관되지 않았고 무작위 이력에서 드문 결과도 아니었다.

균등 추첨에 해당하는 가짜 이력 99개에서 학습부터 평가까지 전부 반복했다. 이 모델은 범주만 사용하므로 조합 자체를 생성하는 대신 정확한 균등 범주 분포에서 추출했다. 이 모델의 실험 통계에 관해서는 동일한 귀무 모형이다. 주 평가에서 실제 이상의 점수를 낸 가짜 이력은 14개다. p값은 `(1+14)/(1+99)=0.15`로 계산했다. 예산을 작게 유지했으므로 p값 해상도는 0.01이고 몬테카를로 오차가 있다.

고전적인 비교 모델로 동일 범주에 의사 관측 740회를 더한 빈도 모델도 평가했다. 주 평가 로그점수 차이는 −0.006298820이었다. 이번 자료에서 회로 모델의 점수가 더 높았지만, 자유도·정규화 방식이 다르며 이 차이에 별도 유의성 검정을 하지 않았으므로 양자 모델의 일반적인 우위를 뜻하지 않는다.

## 검산·한계·재현

테스트 12개가 통과했다. 독립적인 64×64 밀집 행렬로 회전·CNOT 회로를 계산해 상태벡터와 대조했다. 조합 확률의 정규화, 정확한 균등 초기 상태, 미래 평가 자료가 학습을 바꾸지 않는 것도 검사했다. 저장된 실제 회로를 밀집 행렬로 다시 계산하고 505회 점수와 가짜 이력 p값을 별도로 확인했다.

회로 크기와 인코딩 하나만 시험한 결과다. 다른 회로에도 성능이 없다는 증명은 아니다. 반대로 반복적으로 모델을 바꾸어 온 전체 연구 과정의 선택 편향을 이번 p값이 보정하지도 않는다. 운영 번호 생성은 변경하지 않았으며 이 결과만으로 균등 무작위를 대체할 근거는 없다.
