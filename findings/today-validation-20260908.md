## 새 모델 검증 상태

**CatBoost 비교는 미완료**다. 아직 학습된 모델이 없으며, API 이력은 경기별 한 후보만
보존해 당시 모든 마켓·특징 입력을 증명하지 못한다. Fly CLI는 인증 토큰이 없어 DB의
읽기 전용 내보내기도 할 수 없었다. 현재 값이나 오늘 결과로 과거 입력을 만들어 넣지 않았다.
서버의 당시 전체 후보/특징 스냅샷을 확보한 뒤, 오늘 이전 자료로만 학습한 모델을 같은
추천 조건에서 비교해야 한다. 사후 학습 실험은 당시 실제 서비스 예측과 구분해야 한다.

11추천의 Wilson 95% 구간은 21.27~71.99%이며 경기 간 의존성은 반영하지 않았다.
하루 자료만으로 모델의 개선/악화 또는 시장별 가중치 변경을 정당화하지 않는다.
