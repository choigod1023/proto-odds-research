# 추첨 편향·가짜 추첨 대조 실험과 당첨자 수 모델

요청한 1번과 3번을 실행했으나, 이번 조건에서 미래 번호 예측력의 근거를 확인하지 못했습니다. 이에 2번도 소규모로 실행했습니다. 번호 조합 특징을 추가한 당첨자 수 모델 역시 최종 구간에서 판매액만 사용한 기준 모델을 개선하지 못했습니다. 이는 모든 가능한 예측 방법이 불가능하다는 증명이 아닙니다.

## 공통 조건

- 기존 원장 1~1238회 사용. 최신 회차를 새로 수집하지 않았습니다.
- 1번·3번: 학습 1~740회, 검증 741~990회, 최종 991~1238회.
- 이 평가 구간들은 이전 실험에서도 확인했습니다. 모델마다 학습/평가 자료를 분리했지만 연구 전체로는 후향 탐색이며, 새로운 전향적 검증이 아닙니다.
- 새 코드와 결과는 별도 worktree/브랜치에 저장했습니다. 실제 구매나 서비스 변경은 하지 않았습니다.

## 1. 추첨 편향과 이후 구간 재현성

각 회차에서 45개 중 6개를 중복 없이 균등하게 뽑는 가짜 이력 1,999개를 만들었습니다. 실제 이력과 같은 길이를 사용하고 아래의 분석 전체를 각 가짜 이력에도 다시 적용했습니다.

검사 항목은 번호별 빈도의 산포, 번호 쌍별 동시 출현 빈도의 산포, 연속 회차의 공통 번호 수, 학습/최종 구간의 번호별 빈도 상관입니다. 번호 하나나 번호 쌍 하나를 사후에 골라 검정하지 않고 전체 산포를 사용했습니다. 빈도·동시 출현 검정은 과도한 산포를 찾는 단측 검사이며 모든 형태의 비무작위성을 검사하는 것은 아닙니다.

예측 모델은 학습 마지막 100회 또는 학습 전체 740회에서 가장 많이/적게 나온 번호 6개를 고르는 네 가지로 고정했습니다. 동률은 번호 순으로 처리하고, 검증·최종 구간에 들어간 뒤 번호를 다시 고르지 않았습니다. 모델 네 개 × 평가 구간 두 개와 감사 통계 네 개, 총 12개 비교에 Holm 보정을 적용했습니다.

결과:

- 번호 빈도 산포: Monte Carlo p=0.8930.
- 번호 쌍 동시 출현 산포: p=0.7260.
- 연속 회차 공통 번호 수 편차: p=0.2730.
- 학습/최종 빈도 상관의 절댓값: 약 0.06184, p=0.6895.
- 예측 네 모델의 최종 평균 일치 수: 최근 빈도 상위 0.82661, 최근 하위 0.79839, 전체 상위 0.82258, 전체 하위 0.78629. 균등 무작위 한 게임의 기대 일치 수는 0.8입니다.
- 12개 비교의 Holm 보정 p값은 모두 1.0입니다. 선택한 검사에서 편향이나 예측 우위를 확인하지 못했습니다.

빈도 상위 모델의 최종 평균만 보면 0.8을 조금 웃돌지만, 무작위 이력에서도 생기는 변동을 넘는다는 근거는 없습니다. 기계·공 세트별 편향은 이 분석의 대상이 아닙니다.

## 3. 실제·가짜 이력에 같은 시드 선별 절차 적용

기존 `splitmix64-paired128-v1` 생성기를 유지했습니다. 첫 홀수/짝수 회차를 맞히는 역산 후보를 각 100만 개 만들고, 학습에서 각 부분이 2회 이상 적중한 후보를 모두 짝지었습니다. 따라서 완성 시드의 기준은 합계 4회 이상이며 첫 두 적중은 구성한 결과입니다.

실제 이력 1개와 독립적으로 생성한 가짜 이력 99개에 같은 후보 수, 아핀 순열 방식, 학습 구간과 기준을 적용했습니다. 총 부분 후보 2억 개를 계산했습니다. 이는 이전의 7회 적중·80억 부분 후보 실험을 동일 규모로 재현한 것이 아니라, 비교 가능한 생존 후보를 확보하기 위한 축소 실험입니다. 결과를 6~7회 적중 시드의 성능으로 확대 해석할 수 없습니다.

결과:

- 실제 이력: 4회 이상 적중 완성 시드 1,400개, 최고 4회.
- 가짜 이력: **99개 모두** 4회 이상 적중 시드 생성. 98개 이력은 최고 4회, 1개는 최고 5회.
- 가짜 이력의 생존 완성 시드 수 95% 경험적 구간: 1,425~2,856.4개. 이 구간은 이력별 개수의 분위수이며 평균 추정의 신뢰구간이 아닙니다.

시드들은 홀수/짝수 부분 수열을 공유합니다. 따라서 완성 시드들을 독립 관측으로 간주하지 않았습니다. 각 이력에서 같은 수의 부분 시드와 같은 공유 구조를 가진 무선별 대조군 199개를 만들었습니다. 선별군의 평균 일치 수를 그 대조군 평균·표준편차로 표준화하고, 실제 이력의 표준화 점수를 가짜 이력 99개의 점수와 비교했습니다. 모든 Monte Carlo 꼬리확률에 `(1+초과 개수)/(1+반복 수)`를 사용했습니다.

- 검증 구간: 실제 선별군 0.81140, 무선별 대조군 0.79971. 가짜 이력 대비 단측 p=0.06, 두 구간 보정 후 p=0.12.
- 최종 구간: 실제 선별군 0.81027, 무선별 대조군 0.80006. 가짜 이력 대비 단측 p=0.14, 보정 후 p=0.28.
- 실제 선별군의 이후 구간 1등 적중은 두 구간 모두 0회였습니다.

실제 선별군의 평균은 조금 높았지만, 이번 실험으로 우위가 재현된다고 판단할 수 없습니다. 가짜 이력에서도 다회 적중 시드가 반복적으로 만들어진다는 결과는, 과거 적중 횟수 자체를 예측력의 증거로 볼 수 없음을 보여 줍니다. 가짜 이력 99개의 비교 해상도는 제한적이며, 유의하지 않다는 결과가 정확히 효과가 0임을 증명하지는 않습니다.

## 2. 조건부 후속: 당첨자 수와 번호 선택 선호

1번·3번에서 근거를 얻지 못해 요청한 후속 방향도 시험했습니다. 기존 원장 1,238회 모두 판매액과 1등 당첨자 수를 보유했습니다. 초기 구간의 영향을 줄이기 위해 학습은 201~740회로 고정하고, 평가 구간은 동일하게 사용했습니다. 기간 효과를 모두 제거했다는 뜻은 아닙니다.

판매액에 비례하는 1등 당첨자 수를 기준 모델로 사용하고, 다음 네 특징을 추가한 모델과 비교했습니다: 31 이하 번호 개수, 인접한 연속수 쌍 개수, 5의 배수 개수, 최댓값-최솟값. 특징 표준화와 계수 추정은 학습 구간에서만 했습니다. 로그 판매액을 offset으로 둔 Poisson 평균 회귀에 ridge=1을 고정했습니다.

평가지표는 평균 Poisson deviance로, 작을수록 당첨자 수 예측이 좋습니다. 관측 수가 실제 Poisson 분포를 따른다고 가정해 유의확률을 계산하지 않았으며, 회차 간 변동을 일부 반영하도록 길이 10의 순환 블록 부트스트랩 4,999회로 고정 모델의 차이를 요약했습니다.

- 검증: 기준 모델 1.51218 → 특징 모델 1.51012. 개선량 +0.00206, 95% 참고 구간 [-0.02874, +0.03528].
- 최종: 기준 모델 2.23587 → 특징 모델 2.24666. 개선량 -0.01080, 95% 참고 구간 [-0.05865, +0.03614].
- 최종 평균 절대 오차도 기준 모델 4.05292명 → 특징 모델 4.07985명으로 약간 악화했습니다.

이 제한된 특징 모델에서는 당첨자 수 예측을 개선하지 못했습니다. 전체 구매 조합의 인기도를 관측한 것이 아니며, 이 결과로 ‘31 초과 번호를 고르면 유리하다’거나 특정 조합의 기대수익이 높다고 주장할 수 없습니다. 이 후속 분석의 구간은 같은 자료를 재사용했고, 부트스트랩 구간은 탐색적 참고치이며 재학습 불확실성까지 포함하지 않습니다.

## 재현과 검증

실험 입력과 기준은 각 `protocol.json`에 결과 계산 전에 저장했습니다. 새로 정한 기준의 시간 순서를 기록한 것이지, 이미 관찰한 자료에 대한 독립적인 사전등록은 아닙니다.

```powershell
g++ -O3 -march=native -std=c++17 -pthread -static -DMIN_HITS=2 src/lotto_seed_scan.cpp -o .local-build/scan-two.exe
python src/lotto_bias_null.py --executable .local-build/scan-two.exe --output <새 폴더>
python src/lotto_crowding.py --output <새 폴더>/crowding
python scripts/verify_lotto_bias_null.py --report <새 폴더>
python -m pytest -q tests/test_lotto645.py tests/test_lotto_seed_expanded.py tests/test_lotto_seed_128.py tests/test_lotto_bias_null.py tests/test_lotto_crowding.py
```

`.local-build` 폴더를 먼저 만들고 출력에는 아직 존재하지 않는 경로를 지정합니다. 기존 결과를 덮어쓰지 않습니다. 검산 스크립트의 `--report`를 생략하면 기본 저장 결과를 확인합니다.

관련 테스트 25개를 통과했습니다. 독립 스칼라 Python 검산으로 이력 100개의 생존 부분 시드 9,145개에 대해 학습 회차 3,383,650건의 적중 여부를 다시 확인했고, 무작위 감사 이력 1,999개와 최종 집계도 다시 계산해 일치함을 확인했습니다. 후보 2억 개 전체를 두 번째로 전수 탐색한 것은 아닙니다.

결과 폴더: `data/lotto/reports/bias-null/`. `bias.json`, 실제·가짜 이력별 100개 JSON, `seed-summary.json`, `crowding/result.json`에 원시 집계와 평가 결과를 보존했습니다. 기본 C++ 스캐너는 여전히 3회 이상을 출력하고, 이번 실험은 컴파일 옵션으로 2회 기준을 명시했습니다.
