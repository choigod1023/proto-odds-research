# 출전 불가·부상·징계 정보 반영 원칙

## 결론

결장자 수를 승률에서 일괄 차감하지 않는다. `결장 가능성 × 선수 비중 × 대체 선수와의 차이 × 출처 신뢰도`를 별도로 저장하고, 역사적 결장 데이터로 워크포워드 검증하기 전에는 경기 설명과 불확실성 표시에만 사용한다.

부상 정보가 공개될 때 시장 배당도 움직일 수 있으므로, 검증 없이 모델 확률에 다시 더하면 같은 정보를 두 번 반영하는 문제가 생긴다.

## 표준 데이터

```text
name                    선수명
reason_code             injury / suspension / cards / illness / rest / registration / personal / unknown
status                  원문 상태
availability_status     out / doubtful / questionable / probable / bench
availability_probability 출전하지 못할 확률
importance              팀 내 비중(0~1)
replacement_gap         대체 선수와의 예상 차이(0~1)
source_type             official_injury_report / official_roster / official_discipline / official_lineup / team_report / media / inferred
source_confidence        출처 신뢰도(0~1)
source_url               근거 주소
updated_at               확인 시각
impact_score             위 네 요소의 곱
```

`경기 명단 미포함`만으로 부상이나 징계라고 추정하지 않는다. 공식 징계 공지, 공식 부상 보고서 또는 구단 발표가 없으면 `unknown`으로 둔다.

## 자료원 우선순위

1. 대회·리그 공식 징계 및 부상 보고서
2. 경기 공식 엔트리와 비활성 명단
3. 구단 공식 발표
4. 신뢰할 수 있는 언론
5. 명단 비교로 만든 추정값

현재 연결 범위는 MLB 공식 40인 로스터 부상 상태와 축구 공식 경기 명단이다. NBA 공식 부상 보고서처럼 정형화된 자료는 같은 스키마에 연결할 수 있다. K리그 등에서 명단 제외 사유가 공식 확인되지 않으면 이유를 만들지 않는다.

## 연구 근거

- UEFA 11시즌 추적 연구에서는 낮은 부상 부담과 높은 선수 가용성이 리그 순위·경기당 승점·UEFA 성과와 유의하게 연결됐다: https://pubmed.ncbi.nlm.nih.gov/23645832/
- 부상과 경기 성공의 관계를 검토한 체계적 문헌고찰은 선수 가용성이 높을수록 실패 위험이 낮다는 강한 근거를 보고했다: https://pubmed.ncbi.nlm.nih.gov/28446456/
- A리그 6시즌 연구에서는 결장 경기가 승점·패배와 연관됐지만 효과 크기가 작아 부상 수 하나만으로 팀 성과를 설명할 수 없다고 결론냈다: https://doi.org/10.1016/j.jsams.2020.11.004
- NBA 25년 자료에서는 부상·질병으로 놓친 경기 수와 팀 승률 사이에 음의 상관관계가 있었다(r=-0.29): https://pubmed.ncbi.nlm.nih.gov/24908360/
- NFL 공식 정의는 Out, Doubtful, Questionable을 서로 다른 출전 가능성 상태로 구분한다. 단순 부상 여부가 아니라 경기 상태를 저장해야 하는 근거다: https://operations.nfl.com/media/2683/2017-nfl-injury-report-policy.pdf
- MLB HITS 검토는 포지션과 부상 종류에 따라 결장 기간과 복귀 성과가 크게 달라짐을 보여준다: https://pmc.ncbi.nlm.nih.gov/articles/PMC12966506/

## 확률 모델 채택 조건

회차별로 당시 공개돼 있던 상태만 저장한다. 최종 명단을 과거 예측 시점에 소급해서 넣지 않는다. 다음 비교를 워크포워드로 수행한다.

1. 현재 모델
2. 결장자 수만 반영
3. 선수 비중을 반영한 출전 부담
4. 선수 비중·대체 수준·출처 신뢰도를 모두 반영

로그손실·Brier score·보정도와 시장 종가 대비 성능이 미공개 구간에서 개선될 때만 `impact_score`를 확률 보정에 사용한다.
