# 스포츠 예측 파이프라인 v1

## 지금 운영에 들어간 것

1. **시장 기준선**
   - 최종 확률의 기본값은 Shin 방식으로 마진을 제거한 시장확률이다.
   - 확률 artifact가 없거나, 깨졌거나, 승격 근거가 부족하거나, 코드 allowlist에
     등록되지 않았으면 최종 확률은 무조건 시장값으로 돌아간다.

2. **시장-logit 잔차 계층**
   - 후보 모델은 다음 식으로 시장 기준선의 잔차만 학습한다.
   - p_candidate = sigmoid(logit(p_market) + clipped_residual)
   - identity, Platt, 단조 piecewise 보정을 지원한다.
   - 종목·마켓별 모델을 우선하고 종목 → 마켓 → 전역 fallback 순서를 쓴다.

3. **종목별 스코어 분포**
   - 야구는 득점, 축구는 골, 농구는 득점, 배구는 세트 단위 계약을 명시한다.
   - 기대 스코어, 승무패 분포, 상위 스코어 3개를 사이트 경기 분석에 표시한다.
   - 배구 세트 분포를 포인트 언더오버에 사용하는 경로는 오류로 차단한다.
   - 현재 스코어 분포는 shadow이며 추천 선택과 최종 확률을 바꾸지 않는다.

4. **경기 전 불변 예측 원장**
   - 경로: data/raw/prediction_ledger/pregame.jsonl
   - 배당, 모델 입력, 최근 흐름, 선발·결장, 설명 근거, 실제 공개 선택을 킥오프
     전에 append-only JSONL로 저장한다.
   - 해시 체인과 lock file로 변조 및 동시 갱신 충돌을 감지한다.
   - 같은 입력을 30분마다 다시 계산해도 중복 기록하지 않는다. 배당·선발·최근
     흐름·추천이 바뀔 때만 새 revision을 남긴다.
   - 킥오프 전 마지막 revision 하나를 공식 UI 기록과 적중률·ROI 집계에 쓴다.
   - 정산과 공식 correction은 예측 행을 수정하지 않고 별도 행으로 추가한다.

## 아직 운영 확률에 들어가지 않는 것

- 선수·결장·라인업은 사전 원장에 원문 시점대로 저장하지만, 미래 검증 표본이
  부족하므로 아직 확률을 움직이지 않는다.
- LLM은 수집된 경기력 근거를 문장으로 정리할 뿐 선택·확률 계산에는 참여하지 않는다.
- 임의 난수나 이름만 붙인 ‘미래상수’는 정보가 아니므로 예측 입력으로 쓰지 않는다.
  불확실성은 실제로 정의된 라인업 시나리오와 그 발생확률로만 표현한다.

## 승격 조건

잔차 모델은 다음 조건을 모두 만족해야 한다.

- 당시에는 결과를 알 수 없었던 순수 미래 예측 300건 이상
- 시장 기준 대비 Brier 개선 95% 신뢰구간 전체가 0보다 큼
- 시장 기준 대비 log-loss 개선 95% 신뢰구간 전체가 0보다 큼
- 평균 배당과 추천 coverage가 시장 기준보다 나빠지지 않음
- artifact의 canonical SHA-256이 코드 검토 allowlist에 등록됨

artifact가 스스로 좋은 평가값을 적어 넣는 것만으로는 승격되지 않는다.

## 크론 실행 순서

수집 → 입력 컷오프 고정 → 스코어 shadow 계산 → 확률 fail-closed 계산 → 설명 생성
→ 변경 revision만 사전 원장 기록 → 공식 결과 정산 → picks_v2.json 게시

이 순서 때문에 나중에 수집된 선수 정보나 경기 결과가 과거 예측에 섞이지 않는다.
