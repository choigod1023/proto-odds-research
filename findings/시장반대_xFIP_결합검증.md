# 시장 반대 + 선발 xFIP 결합 검증

## 결론

가설은 미공개 구간에서 재현되지 않았다. 현재 추천 로직으로 승격하지 않는다.

- 결합 가능 KBO 경기: 1,978경기
- 설계: 2023 적합, 2024 확인, 2023~24 재적합, 2025~26 고정 검증
- 고정 규칙: 컨텍스트 모델이 시장 선호 팀과 반대이고 선발 xFIP 방향이 모델과 같을 때
- 2024: 27경기, 16승, 적중률 59.26%, ROI +8.67%
- 2025~26: **52경기, 26승, 적중률 50.00%, ROI -9.04%**
- 검증 적중률 Wilson 95% 구간: 36.89~63.11%
- 평균 선택 배당: 1.806

2024의 양호한 수치는 표본 27건에서 생긴 변동으로 보는 것이 타당하다. 더 엄격한
배당·xFIP·EV 문턱 54개도 2024 최대 표본이 12건이라 문턱 선택에 사용하지 않았다.
결과가 좋아 보이는 2~12건짜리 조합을 채택하면 전형적인 다중검정·사후선택 오류가 된다.

## 운영 판정

`research_only`로 둔다. 자동 추천이나 베팅 금액 상향에는 반영하지 않는다. 승격 조건은
전향 표본 300건 이상, 적중률 Wilson 하한 50% 초과, 실현 ROI 0 초과를 동시에 만족하는
것이다. 현재 결론은 “xFIP가 유용하지 않다”가 아니라, **시장과 반대일 때 xFIP가 같은
방향이라는 조건만으로는 시장을 이기지 못했다**는 뜻이다.

재현 명령:

```text
python src/xfip_disagreement_gate.py
```

상세 수치는 `findings/xfip_disagreement_gate.json`에 보존한다.
