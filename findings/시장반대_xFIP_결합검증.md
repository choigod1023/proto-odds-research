# 시장 반대 + 선발 xFIP 결합 재감사

## 결론

미래 리그 평균 참조와 더블헤더 중복을 제거한 뒤에도 표본이 너무 작아 승격할 수 없다.

- 결합 가능 KBO 경기: 1,997경기
- 2024 확인: 25경기 17승, 68.00%, ROI +25.08%
- 2025~2026 역사 감사: **54경기 28승, 51.85%, ROI -5.44%**
- 감사 적중률 Wilson 95% 구간: **38.85~64.61%**
- 평균 선택 배당: 1.815

확인 구간의 플러스는 역사 감사에서 재현되지 않았다. 54경기에 불과하고 신뢰구간이
50%를 넓게 포함한다. 2026년까지 이미 반복 확인했으며 과거 예고 선발 스냅샷과
배당 수집시각도 없어 깨끗한 검증이 아니다. 따라서 `research_only`로 두고 추천·금액
상향에는 반영하지 않는다.

## 수정된 시간 규칙

- 리그 HR/9·FIP 상수는 각 경기 이전 날짜만 사용한다.
- 투수 최근 12선발과 불펜 기록도 이전 날짜까지만 사용한다.
- 같은 날짜 경기는 모두 계산한 뒤 상태를 갱신한다.
- 시간/gameId가 없는 더블헤더 중복 키는 전부 제외한다.
- 실제 선발은 과거 예고 선발의 대용값이라는 한계를 명시한다.

전향적으로 예고 선발과 당시 배당을 고정한 신규 300픽에서 Wilson 하한 50% 초과와
ROI 0 초과를 동시에 만족하기 전에는 운영하지 않는다.

재현: `python src/xfip_disagreement_gate.py`
