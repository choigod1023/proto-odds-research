# 고정 선별 규칙으로 가짜 이력 9,999개 검증

선별 규칙과 실제 선별 시드를 그대로 유지하고 가짜 이력을 999개에서 9,999개로 늘렸습니다. 기존 이력 1,000개(실제 1개와 가짜 999개)를 보존하고 새로운 가짜 이력 9,000개를 계산했습니다. 실제 성과가 변하는 실험이 아니라, 같은 성과를 무작위 이력과 비교하는 Monte Carlo 오차를 줄이는 실험입니다.

## 고정 조건

- 생성기: splitmix64-paired128-v1. 홀수·짝수 회차에 각각 고정된 64비트 부분 시드를 사용합니다.
- 학습 1~740회, 검증 741~990회, 최종 991~1238회.
- 이력마다 부분 후보 각 100만 개. 첫 홀수·짝수 적중은 역산으로 구성합니다.
- 부분별 학습 적중 2회 이상 후보의 전체 조합을 사용합니다. 합계 4회 이상 기준입니다.
- 실제 선별군: 홀수 부분 35개 × 짝수 부분 40개 = 완성 시드 1,400개. 변경하지 않았습니다.
- 이력별 대조군 199개, 난수 시드와 공유 수열 구조, 표준화 평균 일치 수, 두 평가 구간 Bonferroni 보정 모두 유지했습니다.
- 실제 결과를 재선별하거나 평가 기간을 바꾸지 않았습니다. 정해 둔 9,999개에 도달할 때까지 계산했습니다.

추가 고유 부분 후보는 180억 개, 전체 10,000개 이력의 누적 고유 부분 후보는 200억 개입니다. 계산 구현 동일성을 확인하기 위한 별도 재실행은 이 숫자에서 제외했습니다. 부분 후보 수를 독립적인 완성 시드 수나 독립적인 실제 추첨 횟수로 해석하면 안 됩니다.

## 확대 결과

가짜 이력 9,999개 중 9,999개에서 선별 기준을 통과하는 시드 조합이 나왔습니다. 최고 학습 적중 횟수별 가짜 이력 수: {'4': 9983, '5': 16}.

가짜 이력에서 선별된 완성 시드 수의 95% 경험적 구간은 1295.0~2989.0개입니다. 실제 이력은 기존과 같은 1,400개입니다.

### 검증 구간

- 실제 선별군 평균 일치 수: 0.81140000.
- 고정된 무작위 대조군 평균 일치 수: 0.79970632.
- 실제 표준화 점수 이상인 가짜 이력: 638/9,999.
- Monte Carlo 단측 p=0.06390.
- 두 구간 보정 p: 이전 999개 비교의 0.136 → 이번 0.12780.
- 비교 꼬리확률의 Monte Carlo 오차에 대한 95% 이항 구간: [0.05909, 0.06878]. 전략 효과 크기의 신뢰구간이 아닙니다.

### 최종 구간

- 실제 선별군 평균 일치 수: 0.81026786.
- 고정된 무작위 대조군 평균 일치 수: 0.80005746.
- 실제 표준화 점수 이상인 가짜 이력: 1,054/9,999.
- Monte Carlo 단측 p=0.10550.
- 두 구간 보정 p: 이전 999개 비교의 0.212 → 이번 0.21100.
- 비교 꼬리확률의 Monte Carlo 오차에 대한 95% 이항 구간: [0.09946, 0.11159]. 전략 효과 크기의 신뢰구간이 아닙니다.

이번에도 0.05 기준을 넘는 우위를 확인하지 못했습니다. 가짜 이력을 늘려 비교 정밀도를 높였지만, 실제 선별군의 작은 평균 우위를 예측력의 증거로 인정할 근거는 얻지 못했습니다.

## 추가 회차 결과는 기존 기록 유지

이번 요청에서는 추가 실제 회차를 새로 넣지 않았습니다. 이전에 평가한 1239~1245회 기록을 그대로 보존했습니다. 그 7개 회차의 평균 일치 수는 선별군 0.76326531, 무작위 대조군 0.79964879, 단측 p=0.7714, 선별군 1등 적중 0회였습니다. 이 수치를 이번에 새로 발견한 검증 결과로 계산하지 않았습니다.

## 계산과 검증

8개 프로세스로 계산했습니다. 원래 스캐너와 같은 적중 판정을 더 빠른 정수 산술로 계산하는 별도 구현을 사용했습니다. 생성기와 후보 순서, 기준은 바꾸지 않았습니다. 이진 나머지 판정의 무작위·경계값 테스트를 통과했고, 실제 이력 및 가짜 이력 1·623·999의 전체 결과가 원래 스캐너와 기존 기록에 정확히 일치함을 확인한 뒤 적용했습니다. 623번은 이전에 5회 적중 조합이 나온 이력이라 3회 적중 부분 시드도 비교에 포함됩니다.

재개 후 실행 시간은 554.64초입니다. 중단 전 전체 시간 기록은 남지 않아 총 실행 시간은 추정하지 않았습니다. 100개 이력 단위로 압축 체크포인트를 원자적으로 저장하고 각 파일의 해시와 회차 범위를 기록했습니다. 기본 생성기와 기본 C++ 스캐너 소스는 기존과 동일합니다.

관련 테스트 26개를 통과했습니다. 독립 스칼라 Python 검산으로 이력 10,000개에 대해 생존 부분 시드 905,282개, 학습 적중 비교 334,954,340건을 다시 확인했습니다. 압축 파일 91개의 범위·해시, 기존 기록 1,000개의 보존, 최종 통계 재계산도 확인했습니다. 비생존 후보 200억 개 전체를 독립적인 구현으로 다시 전수 탐색한 것은 아닙니다.

## 실행 중단과 복구

도구 세션과 계산 프로세스가 종료돼 작업이 중단됐습니다. 정확한 종료 원인은 확인하지 못했습니다. 4,799번 이력까지는 정상이었고, 4,800~4,999번 이력의 두 압축 파일 및 일부 진행 기록은 손상돼 별도 보관했습니다. 4,800번부터 같은 난수 시드와 같은 기준으로 다시 계산했습니다. 손상된 이력을 다른 임의 이력으로 바꾸지 않았습니다.

재개 시 정상 압축 파일의 범위와 원본 해시를 확인하고, 별도 프로세스로 실행했습니다. 새 체크포인트는 fsync 후 원자적 이름 변경과 재읽기 비교를 거칩니다. 선택 규칙이나 평가 조건은 바뀌지 않았습니다. 복구 정보는 recovery.json에 보관했습니다.

## 해석상의 한계

- 이미 확인한 실제 평가 결과를 반복 사용했습니다. 이번 실행 안에서는 종료 예산을 고정했지만, 연구 전체가 독립 사전등록 실험으로 바뀌는 것은 아닙니다.
- 가짜 이력을 더 만드는 것은 새로운 실제 추첨 결과를 확보하는 것과 다릅니다.
- 평균 번호 일치 수는 1등 당첨 확률이나 수익률 개선을 직접 입증하지 않습니다.
- 실제 및 각 가짜 이력의 대조군은 199개로 고정했습니다. 이번에는 가짜 이력 사이의 꼬리확률 비교를 정밀하게 했고, 기존 대조군 추정 자체를 새로 더 정밀하게 계산한 것은 아닙니다.
- 유의한 우위를 확인하지 못했다는 결과는 모든 가능한 효과가 정확히 0이라는 증명이 아닙니다.

## 재현 자료

결과 폴더: `data/lotto/reports/null-9999/`. `protocol.json`에 고정 기준과 원본·최적화 소스 해시 및 사전 동일성 검사를 저장했습니다. `histories-00000-00999.jsonl.gz`는 이전 기록을 그대로 복사한 파일입니다. 나머지 90개 압축 파일에 추가 9,000개 이력을 보관했습니다. `archive-manifest.json`, `seed-summary.json`, `verification.json`이 파일 무결성·최종 요약·독립 검산 결과입니다. `retained-new-rounds.json`은 이전 7회 평가를 그대로 보존한 기록입니다.

재현 명령:

```powershell
New-Item -ItemType Directory -Force .local-build
# 원래 스캐너와 동등한 최적화 스캐너를 각각 컴파일
g++ -O3 -march=native -std=c++17 -pthread -static -DMIN_HITS=2 src/lotto_seed_scan.cpp -o .local-build/scan-two.exe
g++ -O3 -march=native -std=c++17 -pthread -static -DMIN_HITS=2 src/lotto_seed_scan_fast.cpp -o .local-build/scan-fast.exe
python src/lotto_null_9999.py --prior <PR299의 null-expanded 결과 폴더> --executable .local-build/scan-fast.exe --reference-executable .local-build/scan-two.exe --output <새 결과 폴더>
python -m pytest -q tests/test_lotto645.py tests/test_lotto_seed_expanded.py tests/test_lotto_seed_128.py tests/test_lotto_bias_null.py tests/test_lotto_null_9999.py
```

`python scripts/verify_lotto_null_9999.py`는 기본 저장 경로의 결과를 검산하며, 계산 중에는 완성된 체크포인트를 따라가며 검산합니다. 검산 완료를 기다릴 때 기존 결과를 삭제하거나 덮어쓸 필요는 없습니다.
