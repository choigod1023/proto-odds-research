# 과거 1등 최초 도달 횟수와 빠른 시드의 다른 회차 성능

32개 시드로 실제 난수열을 생성해 1245회 번호를 처음 찾는 횟수를 측정하고 가장 빠른8개를 골랐다. 다른10회차에서 선별군은 비교군보다 평균적으로 빨랐지만, 전체 선별 과정을 반영한 단측 p=0.1992로 우연 이상의 우월성을 확인하지 못했다.

## 실제 생성 결과

1245회 목표 번호는 04·05·25·28·32·42다. 가장 빠른 시드202610171004는 **122,264번째**에 처음 맞혔다. 32개 시드의 이 목표 평균 도달 횟수는 8,542,563.531회였다. 균등 독립 생성의 이론 평균은 8,145,060회다.

선택한8개 시드와 이 목표 최초 도달 횟수:

- 202610171004: 122,264
- 202610171001: 652,344
- 202610171010: 653,915
- 202610171016: 882,081
- 202610171013: 1,299,675
- 202610171026: 1,450,533
- 202610171003: 1,903,368
- 202610171012: 2,170,940

선별에 쓰지 않은 1235~1244회 번호10개에서의 도달 횟수:

- 선택8개 산술평균: 7,223,851.225회.
- 나머지24개 산술평균: 8,629,641.875회.
- 선택8개 기하평균: 4,412,180.552회.
- 나머지24개 기하평균: 5,088,359.585회.
- 사전에 정한 주 평가인 기하평균 비율: 0.867113(선별군이 약13.3% 적은 횟수).
- 10개 목표 중8개에서 선택군 산술평균이 더 짧았다. 목표별 비교는 서로 독립이라고 가정하지 않는다.

이 개선폭은 표본에서 관측한 값이며 재현 가능한 이득으로 입증되지 않았다. 32개 중 빨리 맞힌8개를 골랐으므로 선별 회차에서 빠른 것은 당연하다.

## 생성과 평가 방법

시드는202610171000부터32개, NumPy default_rng의 PCG64를 사용했다. 매 생성은 0~8,145,059의 균등 정수이고, 이를45개 중6개 조합의 사전식 순위와 일대일로 대응시켰다. 매번6개 숫자 배열을 만들지는 않았지만 각 생성값은 정확히 하나의 유효한6개 조합을 뜻한다. 순위 변환과 역변환은 작은 공간에서 전수 검증했고 실제 목표 번호도 역변환으로 확인했다. 복원 추출이므로 같은 조합이 반복될 수 있다.

32개 시드 각각 동일한 난수열 시작점에서11개 목표의 최초 위치를 측정했다. 다른 회차 목표가 선택 회차보다 먼저 나왔어도 해당 최초 위치를 쓴다. 선별에는1245회 도달 횟수만 사용한다. 실제로 모든 시드에서 모든 목표를 찾을 때까지 생성했으며 총 생성 순위 수는 **769,500,000개**다. 100,000개씩 생성하므로 마지막 블록의 여분을 포함하고, 목표당 별도 생성한 횟수의 합은 아니다. 한 난수열에서11개 목표를 함께 확인했다.

주 평가는 다른10개 목표의 로그 도달 횟수를 시드·목표에 걸쳐 평균한 뒤, 선택군과 나머지군의 차이를 계산한다. 이를 지수화하면 기하평균 비율이다. 실제 추첨 이후의 전향 검증이 아니며 이미 확인했던 과거 회차 간 소급 비교다.

## 무작위 비교

9,999번의 가짜 실험에서도32개 시드를 만들고1245회에 해당하는 목표가 빠른8개를 고르는 절차를 반복했다. 단순히 독립 기하분포11개를 나열하지 않았다. 한 스트림에서 목표들이 서로 다른 시점에 나타나는 의존성을 유지했다.

아직 안 나온 목표가 m개이면 다음 새 목표까지의 간격은 Geometric(m/8,145,060)이고, 새 목표의 순서는 균등 무작위 순열이다. 이 간격을 누적해 각 목표의 최초 위치를 얻는다. 이는 이상적인 균등 독립 추출의 정확한 공동 첫 도달 분포이며, 가짜 실험에만 이 단축 계산을 사용했다. 실제32개 시드는 앞서 설명한 난수를 모두 생성했다.

p값은 (1+가짜 실험에서 실제 이하 로그비율을 얻은 수)/10000=0.1992다. 귀무분포의 비율 중앙95% 구간은 [0.716791,1.383636]이며, 실제 효과의 신뢰구간이 아니다. 실제 비율0.867113은 이 범위 안에 있다. 이 비교는 이상적인 균등 난수 가정에 대한 검사이며 PCG64의 모든 시드나 다른 생성기의 성질을 증명하지 않는다.

## 자원과 검산

단일 CPU·BelowNormal·수치 라이브러리 스레드1, 블록100,000개, 블록마다 계산 시간50% 이상 또는1ms 이상 휴식을 적용했다. 384MiB 최대 작업 집합 감시와600초 시간 예산을 두었다. 이는 소프트웨어 감시이며 온도 제어나 강제 OS 메모리 제한은 아니다. 시드 하나가 끝날 때마다 기록을 원자적으로 저장했다.

본 실행은 **12.101초**, 프로세스 CPU **3.094초**, 계산 프로세스 최대 작업 집합 **118.039MiB**였다. 이 수치는 테스트·별도 감사 시간을 포함하지 않는다. 감사에서는 가장 빠른 시드를 다시 실행해11개 최초 위치 전체가 일치함을 확인했고12,000,000개를 추가 생성했다. 따라서 감사까지 실제 생성한 순위는781,500,000개다. 실행기 부모 프로세스와 다른 프로그램의 메모리 및 온도는 측정하지 않았다. 모든 실행은 정상 종료했다.
