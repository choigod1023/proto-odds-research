# 고정 6큐비트 모델의 가짜 이력 999,999개 검증 — 실행 중

최종 결과는 아직 나오지 않았다. 이전 99,999개 실험의 주 평가 p값은 0.0997이며, 이번 확장 결과가 아니다.

## 고정한 조건과 변경 범위

PR #306의 모델 코드를 그대로 사용한다. 6큐비트 RY/CNOT 2층, 매개변수 12개, 낮은 번호 개수·홀수 개수 인코딩, 균등 혼합 5%, 균등 의사 관측 740회, 초기 각도와 L-BFGS-B 설정을 바꾸지 않았다. 학습은 1~740회, 주 평가는 991~1238회, 부 평가는 741~990회·1239~1245회다. 새 실제 자료 수집이나 모델 재선택은 없다.

기존 99,999개를 해시·프로토콜·연속성 확인 후 재사용하고 같은 시드 순서에서 900,000개를 추가한다. 시드는 `2026101700 + i`, `i=0..999998`이다. p값은 `(1 + 실제 이상의 가짜 이력 수) / 1000000`이다. 실제 자료의 결과를 재계산했고, 병렬 프로세스에서 기존 이력 0·998·9998·99998번을 재학습하여 결과 전체가 정확히 같음을 확인했다.

변경한 것은 실행 방식이다. 계산 프로세스 2개를 서로 다른 논리 CPU 하나씩에 고정하고 BELOW_NORMAL 우선순위·수치 라이브러리 스레드 1개를 유지한다. 각 이력 계산 후 해당 시간의 25% 이상, 최소 5ms 쉬게 한다. 검산은 단일 프로세스로 같은 낮은 우선순위를 사용한다. 모델의 수학적 계산이나 최적화 조건을 바꾸지 않았다.

## 자원과 재시작

프로세스마다 256MiB 메모리를 감시하고 계산 블록 500개당 300초의 시간 예산을 둔다. 동시에 처리 중인 블록은 최대 2개로 제한한다. 결과는 500개씩 압축·fsync·재열기 확인 후 저장한다. 순서가 뒤바뀌어 완료돼도 인덱스 구간별로 저장하고 재시작 시 완료한 구간은 다시 계산하지 않는다. 한 실행의 최대 예산은 48시간이다. OS 파일 잠금으로 같은 전용 작업의 중복 실행을 막는다. 전체 학습 객체는 메모리에 모으지 않고 점수 배열만 보관한다.

이 제한은 소프트웨어 감시이며 운영체제의 강제 메모리 제한이나 온도 제어는 아니다. 테스트 당시 컴퓨터는 논리 CPU 16개, 여유 메모리 약 14GiB였다. 새 이력 1,000개를 실제 병렬 실행한 결과 약 38.7초, 작업 프로세스당 최대 메모리 약 111.8MiB, 조정 프로세스 약 106.1MiB였다. 이 시간에는 사전 파일 점검 일부가 포함되지 않으며 장시간 평균 속도를 보장하지 않는다. 수 시간 이상 걸릴 수 있다.

## 검증과 완료 기준

본 실행의 초기 10초 측정에서 작업자 두 개의 CPU 사용량은 전체 16개 논리 CPU 기준 합계 약 9.46%였다. 작업자 두 개와 조정 프로세스의 당시 메모리는 각각 약 108.87·108.41·107.00MiB, 합계 약 324.29MiB였다. 실행용 부모 프로세스의 메모리는 이 합계에서 제외했다. 당시 컴퓨터 전체 CPU 사용률은 순간값 85%로 나타나 추가 병렬화는 하지 않았다. 다른 작업을 포함한 수치이며 온도나 전체 실행 평균은 측정하지 않았다.

관련 테스트 20개가 통과했다. 전체 계산 후에는 밀집 행렬 기반 별도 회로 구현으로 999,999개 가짜 이력과 실제 회로 1개를 모두 검산한다. 학습 미수렴 이력을 임의로 제거하지 않으며 수렴 수를 따로 기록한다. `progress.json`의 `state=verified`와 `verification.json`의 `status=passed`가 완료 기준이다.

실행: `python scripts/run_lotto_quantum_million.py`.

진행 기록과 결과: `data/lotto/reports/quantum-million/`. 로그: `.local-build/quantum-million.stdout.log`, `.local-build/quantum-million.stderr.log`.

테스트: `python -m pytest tests/test_lotto_quantum_million.py tests/test_lotto_quantum_99999.py tests/test_lotto_quantum_9999.py tests/test_lotto_quantum_999.py tests/test_lotto_small_quantum.py tests/test_lotto645.py -q`.

과거 실제 자료를 반복 사용하는 탐색이므로 신규 미공개 회차의 확증 검증이 아니다. 가짜 이력을 늘려도 실제 예측 점수는 바뀌지 않고 몬테카를로 오차만 줄어든다. 수차례 결과를 확인하며 표본을 늘렸고 여러 모델을 시도한 전체 선택 과정까지 p값이 보정하지 않는다. 실제 양자 하드웨어·양자 우위를 검증하는 실험도 아니다.
