# 수식 v3 — 시장 기준 확률, 이변 위험, 목표 배당 제약

검토일: 2026-08-19

## 왜 다시 고쳤나

당일 정산 추천은 32건 중 10건 적중, ROI -48.8%였다. 하루 결과만으로 계수를
바꾸면 과적합이므로, 결과와 무관하게 확인되는 계산 구조부터 감사했다.

1. `today.json`은 2-way에 multiplicative, 3-way에 power를 썼지만 상세 픽은
   Shin을 썼다. 같은 경기의 시장확률이 화면마다 달랐다.
2. 오늘 조합의 `hit_est`는 선택한 경기의 확률이 아니라 과거 배당구간 평균 적중률의
   곱이었다. 실제 선택이 바뀌어도 적중률은 그대로였다.
3. 같은 배당구간에서는 가장 가까운 경기부터 골랐다. 경기 시작 시각은 적중 근거가
   아니므로, 목표 배당을 유지하면서 확률을 높이는 목적과 충돌했다.

## 이번에 적용한 식

프로젝트 전역의 마진 제거법을 현재 내부 비교에서 가장 오차가 작았던 Shin으로
통일한다. 이것은 자체 모델의 승률이 아니라 **시장 기준 확률**이다.

선택한 서로 다른 경기의 확률과 배당을 각각 `p_i`, `o_i`라 하면:

```
P_ticket = product(p_i)
O_ticket = product(o_i)
upset_risk = 1 - P_ticket
market_EV = P_ticket * O_ticket - 1
```

목표 배당 `T`별 선택은 다음 제약 최적화다.

```
maximize    product(p_i)
subject to  0.95*T <= product(o_i) <= 1.15*T
            모든 다리는 서로 다른 실제 경기
            금지 배당대 5.0+ 제외
```

같은 0.05 배당 구간에서는 시장확률 상위 후보만 남겨 탐색량을 줄인다. 확률이 같으면
환급률이 높은 조합, 목표 배당에 가까운 조합 순으로 고른다. 경기 종료 후 브라우저도
남은 후보로 같은 식을 다시 계산한다.

2026-08-19 산출물을 새 식으로 다시 계산한 예:

- 목표 1.4배: 실제 1.33배, 시장 기준 적중 69.6%, 이변 위험 30.4%, 시장 기준 EV -7.3%
- 목표 2배: 실제 1.90배, 시장 기준 적중 46.8%, 이변 위험 53.2%, 시장 기준 EV -11.1%
- 목표 3배: 실제 2.86배, 시장 기준 적중 30.1%, 이변 위험 69.9%, 시장 기준 EV -14.1%

두 경기 모두 강팀이어도 2폴은 최소 한 경기 이변 확률이 빠르게 커진다. 예컨대 각
경기 80%면 2폴 적중은 64%, 한 경기 이상 이변은 36%다. 따라서 `적중 70%`와
`2배 이상`을 동시에 요구하려면 시장이 놓친 독립 신호가 반드시 필요하다.

## 다음 수식 — 검증 전에는 계수를 0으로 둔다

시장확률을 버리고 자체 모델로 대체하는 방식은 현재 홀드아웃에서 실패했다. 다음
모델은 시장을 강한 기준점으로 두고 **시장 잔차만** 학습한다.

```
logit(p_final) = alpha_g
               + beta_g * logit(p_market)
               + gamma_g * (logit(p_model) - logit(p_market))
               + delta_g * sentiment_gap
               + eta_g * line_movement
```

`g`는 종목×리그×마켓×배당대의 계층 그룹이다. expanding-window 시간순 검증에서
Brier·log loss가 시장보다 좋아지고 계수의 부트스트랩 구간이 0을 벗어날 때만
`gamma`, `delta`, `eta`를 사용한다. 현재 교차시장과 배당이동 검정은 홀드아웃에서
재현되지 않았으므로 기본값은 0이다.

대중 쏠림은 단순 배당 이동과 같지 않다. 정보 유입과 인기팀 수요가 한 가격에 섞이기
때문이다. 다음 수집에는 같은 시점의 샤프북 합의 확률, 프로토 확률, 티켓 비중과 금액
비중, 팀 인기 지표가 있어야 한다. 그 뒤에만
`sentiment_gap = logit(p_proto) - logit(p_sharp_consensus)`를 검정한다.

최종 베팅 관문은 점추정 EV가 아니라 불확실성 하한이다.

```
p_lower = bootstrap 5% quantile of p_final
robust_EV = p_lower * odds - 1
```

## 운영 판정은 매수·소액 도전·패스로 분리한다

2026-08-22까지는 `robust_EV > 0`만 자동 매수로 인정했다. 그러나 현재 보정식은
다리별 실측 ROI `r_i`를 `p_i = (1 + r_i) / o_i`로 역산한다. 따라서 조합의
점추정 기대값은 다음처럼 배당이 소거된다.

```
EV_calibrated = product(p_i * o_i) - 1
              = product(1 + r_i) - 1
```

모든 검증 배당구간의 `r_i`가 음수이므로 점추정부터 음수이고, 95% 하한은 더
낮다. 즉 이 관문 하나만 화면의 일상 판정으로 쓰면 엄격한 것이 아니라 구조적으로
거의 영구 패스다. 시장 우위의 정의는 유지하되 운영 행동을 다음 세 단계로 분리한다.

- `매수`: `robust_EV > 0`. 시장 우위가 검증된 경우에만 기존 자금 성향을 적용한다.
- `소액 도전`: 목표 1.4배 이하, 보수 기대수익률 −20% 이상, 보정 적중률 55% 이상.
  양의 기대수익 신호가 아니므로 하루 예산의 10% 수준(최소 1,000원)만 먼저 잡는다.
- `패스`: 소액 도전 기준에도 못 미치거나 적중 우선 1.4배 조합을 만들 수 없는 날.

저장된 2026-07-29~08-22의 22개 일별 산출물에 이 운영 기준을 적용하면 소액 도전
20일, 패스 2일로 주당 약 6.4회다. 구형 산출물에는 Wilson 하한이 없어 당시 저장된
적중률·기대수익률을 대체 지표로 썼으므로, 이 수치는 수익성 백테스트가 아니라
**화면에 신호가 얼마나 자주 뜨는지**에 대한 빈도 점검이다. 10%는 추천 상한이 아니라
기본값이며, 화면에서 1.4·2·3·5배 강도와 투입 금액을 서로 독립적으로 바꿀 수 있다.

## 홀짝은 계산하되 자동 추천하지 않는다

홀짝은 총득점 분포에서 확률을 계산할 수 있지만, 그것이 곧 시장보다 잘 맞는다는
뜻은 아니다. 내부 감사에서 야구 총득점 홀 비율은 검증 구간 58.0%로 구조적 편향이
확인됐지만 프로토 가격도 이를 반영했다. 같은 구간 홀 단독 ROI는 -11.27%
(95% CI -13.41%~-9.13%)였고, 축구·농구·배구도 양의 ROI를 보이지 못했다.

따라서 홀짝은 상세 화면에서 배당·시장확률·모델확률을 비교할 수 있도록 남기되,
경기별 자동 추천과 오늘의 단폴·다폴 조합 후보에서는 제외한다. 시간순 외부표본에서
시장보다 Brier와 log loss가 개선되고 `robust_EV > 0`인 규칙이 재현될 때만 다시
추천 대상으로 연다.

## 목표 배당을 역배로 끼워 맞추지 않는다

과거 353,047개 베팅에서 배당대가 높을수록 ROI가 단조 악화했다. 1.0~1.5는
-9.90%, 2.2~3.0은 -14.97%, 5.0 이상은 -33.19%였다. 따라서 총배당 목표를
맞춘다는 이유만으로 시장 반대편을 고르는 것은 검증된 가치 전략이 아니다.

자동 추천에는 다음 관문을 공통 적용한다.

- 같은 마켓에서 Shin 시장확률이 가장 높은 선택지만 허용한다. 3-way는 확률이
  50% 미만이어도 세 선택지 중 1위면 최유력으로 본다.
- 다리 하나의 배당은 2.20 미만만 허용한다.
- 홀짝은 자동 추천·조합에서 제외한다. 역배는 1.50~3.00 미만,
  시장확률 28% 이상, 검증 전 구조 모델 50~75%, 시장 대비 모델 차이 8~25%p를
  모두 만족할 때만 기존 정배를 제거하고 경기의 최종 픽 하나를 역배로 교체한다.
  이 모델값은 선택 방향 관문일 뿐 적중확률이나 기대수익으로 사용하지 않으며,
  표시 확률은 교체된 선택의 Shin 시장확률을 유지한다.
- 이 관문으로 목표 배당을 만들 수 없으면 역배로 채우지 않고 `조합 없음`을 표시한다.

5배와 8배는 기존 2폴 대신 3폴, 12배는 기존 3폴 대신 4폴의 안전 구간으로
구성한다. 다리가 늘면 마진도 누적되므로 기대값이 좋아진다는 뜻은 아니다. 이 변경은
고배당 목표를 없애지 않으면서, 한 경기의 낮은 가능성에 티켓 전체를 거는 집중 위험을
줄이기 위한 것이다.
