# 규칙을 다 쌓아도 −11.5% — 제안한 해결책이 반박됐다

실행 `src/stack_filter.py` · 2026-07-28
선택지 354,190(무효 제외) · 경기 149,234 · 학습 ≤2024 / 검증 2025~

---

## 0. 한 줄

**구조적 선택만으로 유효 마진을 4%대까지 낮출 수 있다고 제안했는데, 측정하니
2.4%p 밖에 안 줄었다(−13.89% → −11.48%).** 그리고 근거로 삼았던 좁은 슬라이스
(−3.85%)는 **2025년 한 해에만 나타난 현상**이었다.

---

## 1. 무엇을 제안했고 무엇이 틀렸나

오늘 세 갈래 스캔이 전부 닫힌 뒤 이렇게 제안했다.

> 부등식의 왼쪽(정보 2.4%p)은 상한이 막혔다. 그런데 **오른쪽(마진)은 상수가 아니다.**
> 아무거나 −12.75% / 핸디캡 홈 −18.41% / 승①패 중간·3.0-5.0 **−3.85%**.
> 같은 프로토 안에서 14.6%p 가 벌어지니, 구조적 선택만으로 −12% 를 −4% 로 만들면
> 필요한 우위가 6.8%p → 3.9%p 가 된다.

**이 추론이 틀렸다.** 14.6%p 격차는 실재하지만, 그건 **아주 좁은 슬라이스 하나**의
값이지 규칙을 쌓아서 도달하는 값이 아니다.

---

## 2. 규칙 누적 — 2.4%p 가 전부다

`anomaly_scan.py` 가 안 넣었던 축(초대면·회차 환급률·무효·단폴)까지 전부 AND 로 쌓았다.

| 누적 규칙 | 검증 n | 검증 ROI | 95%CI |
|---|---|---|---|
| ① 전체 (무효만 제외) | 173,289 | −13.89% | [−14.12%, −13.65%] |
| ② + 3-way 핸디캡 제외 | 137,307 | −13.41% | [−13.64%, −13.17%] |
| ③ + 핸디캡 '홈' 제외 | 137,307 | −13.41% | [−13.64%, −13.18%] |
| ④ + 배당 5.0 이상 제외 | 132,416 | −12.74% | [−12.94%, −12.55%] |
| ⑤ + 3-way 는 '중간'만 | 98,934 | −12.24% | [−12.64%, −11.84%] |
| ⑥ + 초대면·1~3회 제외 | 80,143 | −12.14% | [−12.56%, −11.72%] |
| ⑦ + 회차 환급률 상위 50% | 31,540 | **−11.48%** | [−12.05%, −10.88%] |

**총 개선 2.41%p.** 표본은 173,289 → 31,540 으로 5.5배 줄었는데 얻은 게 2.4%p 다.

③이 ②와 같은 이유: 핸디캡 '홈' 의 손실은 대부분 3-way 핸디캡에서 나오는데
②에서 이미 빠졌다. **규칙들이 서로 겹친다** — 이게 누적 효과가 작은 이유다.

## 3. 좁은 슬라이스는 2025년 현상이었다

−3.85% 라는 값의 정체를 연도별로 쪼개니 드러났다.

### 승①패 · '중간' 선택지 / 배당 3.0-5.0

| 연도 | n | 적중률 | 평균배당 | ROI | 기준선 초과 |
|---|---|---|---|---|---|
| 2023 | 325 | 27.7% | 3.55 | −1.78% | +10.52% |
| **2024** | 907 | 23.3% | 3.61 | **−16.52%** | **−4.12%** |
| **2025** | 3,111 | 29.2% | 3.46 | **+0.68%** | **+13.34%** |
| 2026 | 1,978 | 26.5% | 3.35 | −11.02% | +2.33% |

**부호가 해마다 뒤집힌다.** 평균배당 3.4 면 손익분기 적중률이 **29.4%** 인데,
2025년만 29.2% 로 겨우 닿았고 나머지 해는 23~28% 다.

학습(≤2024) −12.63% / 검증(2025~) −3.87% 라는 그림도 이걸로 설명된다.
**엣지가 아니라 2025년 한 해가 좋았던 것이다.**

⚠️ 이건 `HANDOFF §6` 함정 7("표본이 늘면 부호가 뒤집힐 수 있다")의 교과서적 사례다.
그리고 오늘만 세 번째다 — KBL 가짜 승리, FA컵 R1, 그리고 이것.

## 4. 그래서 부등식이 어떻게 되나

```
필요한 우위        6.8%p   (2-way booking 1.1364)
정보의 크기        2.4%p   (샤프 마켓 24h 스윙 중앙)
구조 선택의 이득   2.4%p   (규칙 7개 전부 누적, 이 문서)
                 ─────
합쳐도             4.8%p   <  6.8%p
```

**둘을 다 더해도 못 넘는다.** 그리고 이 둘은 독립적으로 더해지지도 않는다 —
구조 선택으로 좁힌 구간에서 정보 우위가 그대로 유지된다는 보장이 없다.

---

## 5. 그래도 확정된 것

**손실 축소는 진짜다.** −13.89% → −11.48% 는 검증 구간에서 CI 가 겹치지 않는다.
예측력 0 으로 얻는 2.4%p 이고, 이건 해마다 뒤집히지 않는 **구조적** 이득이다
(booking 이 규정으로 고정돼 있으므로).

| 확정 규칙 | 근거 |
|---|---|
| 3-way 핸디캡 금지 | booking 86% (2-way 88%) |
| 배당 5.0 이상 금지 | −33.19% (Q0) |
| 3-way 는 '중간' 선택지만 | 승①패 중간 초과 +4.66% |
| 초대면 매치업 회피 | 초과 −1.89% (`세갈래_스캔.md` ③) |
| 회차 환급률 상위만 | 회차별 86~89% |
| 조합 금지 · 단폴만 | 마진이 곱해진다 |

⚠️ 단 **표본이 5.5배 줄어든다.** 회차당 살 수 있는 게 크게 준다.
