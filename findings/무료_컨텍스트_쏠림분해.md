# 무료 경기정보와 쏠림 분해 — 1차 관문

실행: `python3 src/context_features.py --league K리그1` →
`python3 src/free_context_eval.py`

## 질문

선수·일정·날씨가 정배를 같은 방향으로 지지하면 그것을 좋은 신호라고 불러도 되는가?

아니다. 다음 세 값을 분리해야 한다.

- 프로토 Shin devig 확률
- 현재 배당을 보지 않은 독립 경기모델
- 프로토 확률을 offset으로 두고 무료 경기정보를 추가한 모델

독립모델은 “왜 이 가격인가”를 설명하고, offset 모델은 그 정보가 이미 가격에
들어 있는지를 검정한다. 정배를 지지하더라도 offset 모델이 시장보다 나쁘면
예측 우위가 아니라 `이미 가격 반영`이다.

## 현재 무료 데이터

| 묶음 | 내용 | 시점 품질 |
|---|---|---|
| 일정 | 휴식일, 최근 7·14일 경기 수, 연속 원정 | 경기 직전 1-pass |
| 이동 | 직전 경기장→현재 경기장 대권거리 | 기본 홈구장 좌표 기반 추정 |
| 선수 | 현재 XI의 지수감쇠 선발 workload | 90분 근사·사후 복원, 현재 모델 미투입 |
| 날씨 | Open-Meteo 12개 K리그1 경기장 시간별 예보 | `observed_at`별 append-only, 축적 중 |

시즌 휴식기가 300일짜리 `rest_diff`나 원정 10연전으로 들어가 확률이 폭주하는
결함을 발견했다. 30일 이상 공백에서 일정 상태를 리셋하고, 학습분포 1~99% 밖의
새 시즌 값을 학습 경계로 고정했다. 이 가드 전의 독립모델 결과는 폐기한다.

## 1차 결과

K리그1 3-way 승무패, 학습 2023–2024 456경기, 검증 2025–2026 336경기다.
정규화 강도는 테스트를 보지 않고 2023→2024 내부 시간검증으로 골랐다.

| 모델 | 검증 Brier |
|---|---:|
| 프로토 Shin devig | **0.64571** |
| 독립 무료 경기모델 | 0.66155 |
| 프로토 + 무료 피처 offset | 0.66690 |

시장 대비 offset 개선은 **−0.02119**, 날짜 블록 95% CI는
**[−0.03880, −0.00260]**이다. 즉 현재 일정·이동·최근폼 묶음은 시장에 추가할
새 예측정보가 아니다. 같은 방향의 근거가 나오더라도 픽 신호로 승격하지 않는다.

현재 분류는 `이미 가격 반영` 207, `시장과 경기정보 일치` 81,
`설명되지 않는 쏠림` 45, `시장 과소반영` 3경기다. 이 분류는 결과 적중률이 아니라
시장과 독립모델의 괴리 진단이다. 날씨·당시 관측 라인업이 축적되기 전에는
화면의 확정 결론으로 사용하지 않는다.

## 다음 관문

1. 무료 날씨 예보를 T-24h/T-6h/T-1h로 축적한다.
2. 실제 경기시간과 가장 가까운 과거 예보만 as-of join한다.
3. 라인업은 `observed_at`이 있는 신규 경기부터 workload 변화량을 결합한다.
4. 각 묶음을 하나씩 제거해 검증 손실이 개선되는지 잰다.
5. 개선 신뢰구간이 양수가 아니면 해설용 근거로만 남긴다.

유료 구독은 사용하지 않았다.
