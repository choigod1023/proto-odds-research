# 로또 2회 적중 시드 100만 후보 탐색

학습 구간에서 1등을 2회 맞힌 시드 98개를 찾았습니다. 그러나 이후 회차에서 무작위보다 잘 맞힌다는 근거는 나타나지 않았습니다.

## 앞선 실험과 다른 점

이전 `seed-survival-v1`의 Python Random 시드를 단순 연장한 실험이 아닙니다. 회차별 한 조합을 생성할 때 740회 중 두 번 이상 1등을 맞힐 확률은 독립 균등 모형에서 약 4.12e-9입니다. 후보 하나당 740회를 순차 생성하는 기존 방식으로는 평균 약 2억 4천만 후보가 필요합니다.

이번에는 역산 가능한 `splitmix64-combinadic-v1` 생성기를 별도로 만들었습니다. 1회차 당첨 조합으로 연결되는 시드 가운데 100만 개를 중복 없이 뽑고, 학습 구간인 2~740회에서 추가 적중을 찾았습니다. 첫 적중은 구성한 결과이며 예측 성과가 아닙니다. 100만 개 전부 1회 이상, 98개가 2회 이상, 3회 이상은 0개였습니다. 조건부 후보 100만 개를 검사한 것이므로 무작위 시드 수억 개를 실제 전수 검색했다고 해석하면 안 됩니다.

## 이후 회차 결과

- 검증 741~990회: 98개 시드 × 250회 = 24,500티켓. 1등 0회. 평균 일치 수는 생존군 0.799755개, 무작위 대조군 0.799841개였습니다. 대조군 1,000개 중 50.3%가 생존군 이상이었습니다.
- 최종 991~1238회: 98개 시드 × 248회 = 24,304티켓. 1등 0회. 평균 일치 수는 생존군 0.795713개, 무작위 대조군 0.800113개였습니다. 대조군 1,000개 중 82.1%가 생존군 이상이었습니다.
- 최종 구간의 무작위 대조군 평균 일치 수 95% 참고 범위는 0.789868~0.809229개입니다. 생존군은 이 범위 안에 있습니다.

대조군은 같은 생성기에서 학습 성적으로 선별하지 않은 무작위 64비트 시드입니다. 반복마다 생존군과 같은 98개 시드, 같은 회차, 같은 티켓 수를 평가했습니다. 개별 생존 시드의 일치 분포도 JSON에 저장했으며, 최종 성적을 보고 좋은 시드만 다시 추리지는 않았습니다.

이미 이전 실험에서 확인한 검증·최종 구간을 재사용했으므로 이는 추가 탐색이지 새 미래 자료를 사용한 확증 평가가 아닙니다. 대조군 이상 비율도 탐색적 비교 지표입니다. 이번 결과는 이 생성기와 조건에서 우위가 나타나지 않았다는 뜻이며 모든 생성기에 대한 불가능성 증명은 아닙니다.

## 재현

```powershell
python src/lotto_seed_expanded.py --output .local-build/seed-expanded-repeat
python -m pytest tests/test_lotto_seed_expanded.py tests/test_lotto645.py -q
python scripts/verify_lotto_seed_expanded.py
```

실행 전에 설정·소스 해시·원장 해시를 `protocol.json`에 저장하고, 평가 전에 생존 시드와 학습 적중 회차를 `selection.json`에 저장합니다. `--output`은 비어 있어야 하며 기존 결과를 덮어쓰지 않습니다. Python 3.14.3, NumPy 2.5.1에서 실행했습니다.

14개 테스트를 통과했습니다. 별도 스칼라 Python 구현으로 생존 시드 98개의 1~1238회 번호 121,324조합을 다시 계산해 학습 적중 회차와 검증·최종 일치 분포가 정확히 같은지 확인했습니다. 결과는 `verification.json`에 있습니다.

전체 결과: `data/lotto/reports/seed-expanded/experiment.json`. 번호 원장: `data/lotto/draws.jsonl`의 회차별 출처·수집 시각. 공식 출처: [동행복권](https://www.dhlottery.co.kr/).

이 기능은 별도 연구 CLI이며 운영 추천 번호, 기존 생성기, 배포 설정을 바꾸지 않습니다.
