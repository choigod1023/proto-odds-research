## 모델 후보: 최종 평가 후 후보 추가·파라미터 조정 금지

1. Shin 시장 기준.
2. 기존 L2=0.01 로지스틱 + 온도 보정(2023–24로만 온도 0.5~2.0 학습).
3. 후보 2와 시장 확률 50:50 고정 혼합: 모델 과신 완화 가설.
4. 시장 로그 확률을 기준으로 전력·폼·상수의 잔차만 학습하는 다항 로지스틱. 고정 L2=0.1, 절편 포함 전체 계수 정규화. 추가 온도 보정 없음.
5. Shin 로그 확률의 온도+클래스별 편향 보정. 온도 0.5~2.0, 편향 L2=0.1, 2023–24로만 학습.

모델 선택은 2024–25 전체 경기 logloss 최소, 동률이면 이름순. ROI로 모델을 고르지 않는다. 최종 평가에서는 선택된 모델의 결과가 주결과이고, 나머지는 모두 보조 비교로 공개한다. 순위를 보고 모델을 바꿔 운영하지 않는다.

## 선별 기준

- p60_range: 확률 ≥60%, 1.50≤배당<2.20.
- p60_low: 확률 ≥60%, 1<배당<2.20.
- ev03_all: 확률 하한·배당 상한 없음, 단일 선택 추정 EV ≥3%.
- ev03_nonfavorite: ev03_all이면서 해당 경기 최저 배당보다 높은 선택만 허용. 무승부 포함. 최저 배당 동률은 역배로 세지 않는다.
- nonfavorite_control: EV 제한 없이 역배 중 확률이 가장 높은 선택. 유리한 역배가 없어서 0조합이 되는 문제와 역배를 억지로 고르는 문제를 구분하기 위한 진단 대조군이며 운영 후보가 아니다.

각 경기에서 적격 선택 중 EV, 확률, H/D/A 순으로 결정. 날짜별 EV, 확률, ID 순의 서로 다른 두 경기만 조합. nonfavorite_control만 확률 우선. 모든 경기와 모든 조합을 겹쳐 베팅하지 않는다.

## 평가와 채택

- 원배당 ROI를 주결과로, 프로토 조합 절상 가정 ROI를 보조로 보고한다. 적중률·장수·총손익·현금 포함 같은 예산 수익·최대 낙폭·역배/저배당 편입 수를 함께 계산한다.
- ISO 주 단위 묶음 재표집 5,000회(seed 20260928). 원배당 ROI의 95% 구간과, 기존 온도 모델+p60_range 대비 같은 주를 재표집한 전체 예산 수익 차이 구간을 보고한다. 두 구간은 모델 추정 오차·주 간 의존성·다중 비교 전체를 해결하지 않는다.
- 주별 군집 부트스트랩 logloss 차이도 보고한다. 빈 베팅은 ROI null이며 수익 0과 구분한다.
- 최소 100조합, 원배당 ROI 구간 하한>0, 기존 정책 대비 예산 수익 차이 구간 하한>0, 확률 정확도가 시장보다 나쁘지 않을 때만 다음 독립 검증 대상으로 삼는다. 다중 후보의 최고값을 확정 수익이라고 부르지 않는다.
- 해당 조건 통과도 자동 운영 적용 근거가 아니다. 별도 리그/실제 프로토 가격 재검증 없이는 운영 정책 변경을 하지 않는다.
- 이번 요청의 병합 대상은 재현 가능한 실험 코드·회귀 테스트·전체 결과 기록이다. 운영 소스와 DB, 서버는 변경하지 않는다.
