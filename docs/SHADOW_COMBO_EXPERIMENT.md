# 전향적 2경기 조합 실험 v1

정식 추천이나 자동 베팅이 아닌 가상 기록이다. 기존 추천/화면/배당 수집 주기는 변경하지 않는다.
`today_combo` 저장 트랜잭션에서 `shadow_experiment`를 갱신한다. 별도 데몬이나 외부 요청은 없다.

## 사전 고정 규칙

- 정책 식별자: `shadow-daily-two-p60-o150-v1`. 관측 이후 임계값을 바꾸지 않는다.
- 기존 highlight 규칙을 통과한 앞으로의 경기만 사용한다. KST 경기 날짜별 비교 집단을 만든다.
- 생성 시각, 원천 생성 시각, 배당 생성 시각이 모두 현재 기준 15분 이내여야 한다. 미래/누락 시각은 거절한다.
- 해당 날짜에서 처음 관측한 후보의 가장 이른 경기 시작 30분 전을 마감으로 정한다. 이후 마감은 앞당길 수만 있다.
- 마감 전 최신 유효 스냅샷을 보관한다. 마감 후 다음 정상 저장 때 이를 고정한다. 이때 원천/기록 시각이 마감 기준 15분보다 오래됐으면 그 날은 제외한다.
- 정확히 T-30에 별도 작업을 실행하는 방식이 아니다. 실제 `recorded_at`, 예정 `cutoff_at`, 고정 처리 `frozen_at`을 구별한다. 마감 후 자료로 소급 구성하지 않는다.
- 기존 추천 단폴, 그중 확률 0.60 이상·배당 1.50 이상인 단폴, 필터 통과 상위 두 경기 조합을 같은 스냅샷으로 비교한다. 기존 highlight의 배당 상한 2.20 미만도 유지한다.
- 확률 내림차순, 배당 오름차순, 경기 식별자와 선택 키 순으로 동률을 처리한다. 동일 경기의 다른 시장은 중복 선택하지 않는다. 두 경기 미만이면 조합을 만들지 않는다.
- `probability_source`와 모델/결정 식별자를 저장한다. 출처를 알 수 없으면 unknown이며 모델 확률로 간주하지 않는다.

## 평가와 한계

각 단폴/조합당 가상 1단위. 공식 결과와 원래 경기·시장·라인·선택이 일치할 때만 정산한다.
무효 선택은 배당 1, 미적중은 0, 적중은 고정 배당을 적용한다. 조합은 모든 선택의 결과가 있어야 정산한다.
정산된 원금 대비 손익으로 ROI를 계산하며 미정산 건수는 별도로 표시한다.
낙폭은 날짜/후보 순서의 가상 손익 기준이며 실제 현금흐름 시간순 낙폭이 아니다.
비교 집단은 이 실험에서 마감 전에 관측한 후보이며 사이트의 모든 추천 이력을 의미하지 않는다.

독립 가정 기대수익률은 `확률1 × 확률2 × 배당1 × 배당2 − 1`이다.
다른 경기여도 상관관계가 있을 수 있으므로 이 수치는 보정된 조합 확률이나 수익 보장이 아니다.
음수 기대수익 후보도 가상 실험에는 기록하며 실제 추천으로 승격하지 않는다.
과거 최고 ROI로 고른 임계값은 과적합 가능성이 있고 이번 전향 기록으로 별도 검증해야 한다.

메모리/저장량을 제한하기 위해 결과와 무관하게 최근 90일만 보관한다. 장기 누적 ROI가 아니다.
추가 메모리 사용이 0은 아니지만 기존 후보의 작은 필드 집합만 기록하며 모든 조합을 열거하지 않는다.
정산은 기존 추천 저장 시점에만 진행하므로 작업 지연 시 정산도 늦어진다.
배포 전에는 기록되지 않으며, 이 PR만으로 운영 적용이나 장기 검증을 완료했다고 보지 않는다.
