# 가상 추천 비교 실험 v2 — 운영 추천과 분리

기존 추천/화면/정식 조합 정책은 변경하지 않는다. 베팅을 실행하지 않으며, 성적이
좋아져도 자동 승격하지 않는다. v1(PR #230)을 대체하는 배포 전 설계 수정이다.
이미 다른 버전으로 등록된 실험은 이 코드가 임의로 변환하거나 초기화하지 않는다.

## 미리 고정하는 규칙

- 정책 ID: `shadow-fixed-budget-28d-v2`.
- 처음 정상 데이터를 받은 다음 KST 날짜 00시부터 28일간의 경기를 관측한다.
  미래 날짜 후보는 사전에 수집할 수 있다. 기간 중 임계값은 바꾸지 않는다.
  기간 종료 후 새 경기를 넣거나 자동 재시작하지 않고 미정산 결과만 계속 연결한다.
- 기존 highlight 규칙을 통과한 경기들을 기본 집단으로 삼는다. 그중 확률 58% 이상,
  60% 이상이면서 배당 1.50 이상인 집단을 별도로 비교한다. 기존 상한 2.20 미만 유지.
- 다섯 전략: 기존 추천 단폴, 58% 조건 단폴, 60% 조건 단폴, 60% 조건 하루 1개
  2경기 조합, 60% 조건 시간대별 1개 2경기 조합.
- 시간대는 KST 00~06 / 06~12 / 12~18 / 18~24의 고정 구간이다. 각 경기 시작
  시각으로 분류한다. 동일 경기의 다른 시장은 중복 제거한다. 시간대 방식 안에서
  고정된 경기 ID는 재사용하지 않는다. 서로 다른 비교 전략 사이에는 같은 경기가
  들어가도 된다. 시작 시각 변경으로 경기 ID가 바뀌는 원천의 한계는 남아 있다.
- 확률 내림차순 → 배당 오름차순 → 경기 ID → 선택 키 순으로 상위 2개를 선택한다.
  2개 미만이면 조합을 강제로 만들지 않는다.

## 시점과 데이터 품질

생성/원천 생성/배당 생성 시각은 모두 실행 시점 기준 15분 이내여야 한다. 누락,
미래 시각, partial/error 응답은 새 스냅샷에 쓰지 않는다. 빈 응답도 기존 기록을
지우지 않는다. 시작 30분 전이 지난 경기로 새 실험 기록을 소급 생성하지 않는다.

일별/시간대별 처음 관측한 후보 중 가장 빠른 경기의 T-30이 마감이며, 이후에는
마감을 앞당길 수만 있다. 마감 전 최신 유효 스냅샷을 다음 저장 때 고정한다.
마감 시점 기준 기록/원천 시각이 15분보다 오래됐으면 해당 집단은 제외한다.
`recorded_at`, `cutoff_at`, `frozen_at`은 서로 다르다. 정확히 T-30에 실행되는
별도 스케줄러를 만들지 않는다.

하루 조합은 첫 마감 뒤 고정된다. 시간대별 방식은 이후 시간대에서 새 후보를
받는다. 같은 시간대의 첫 마감 이후에 새로 나타난 후보는 그 시간대 조합에 추가하지
않는다. 따라서 이 방식도 모든 후보를 활용하지 않으며 누락 비율을 함께 평가한다.

## 예산과 성적

모든 전략에 하루 가상 예산 1단위를 배정한다. 하루 조합은 최대 1단위, 시간대
조합은 각 구간 최대 0.25단위다. 단폴 전략도 구간당 0.25단위를 그 시점의 선택
경기 수로 균등 분배한다. 없는 구간의 예산은 현금으로 남기고 이후 구간에 옮기지
않는다. 이는 동일 예산 상한 비교이지, 실제 투입액을 억지로 같게 하는 비교가 아니다.
단폴 구매 가능 여부를 검증한 기록이 아니므로 단폴은 가상 비교 기준이다.

정확한 사전 경기·시장·라인·선택에 공식 결과를 연결한다. 적중은 고정 배당,
미적중은 0, 무효는 1을 환급 배수로 적용한다. 조합은 모든 선택의 결과가 있어야
정산한다. 미정산을 패배나 수익 0으로 계산하지 않는다.

요약은 선택 경기 수/선택 비율/미선택 수, 실제 투입·미정산·정산 원금, 총손익,
정산 원금 대비 ROI, 종료된 날짜의 손익과 일별 낙폭을 구분한다. 낙폭은 미정산
날짜를 제외한 부분 통계이며 실제 현금흐름 최대 낙폭이 아니다. 관측되지 않은
날짜는 정상 무참여와 장애를 구분할 수 없으므로 별도 개수로 표시한다. 데이터
공백이나 미정산이 있으면 순위를 확정하지 않는다.

coverage의 recommended/p58/p60은 관측 중 한 번이라도 통과한 경기 수다.
이는 각 마감에 실제 선택한 수와 다르다. 분모는 API에서 사전에 관측 가능한
후보 경기이며 세상의 모든 경기나 사이트의 전체 예측 원장이 아니다.

## 해석·운영 제한

확률 출처와 모델/결정 ID를 보존한다. 시장확률과 unknown을 모델 확률로 부르지
않는다. 조합 EV는 독립 가정의 `확률1 × 확률2 × 배당1 × 배당2 − 1`이며 수익
보장이나 보정된 공동확률이 아니다. 음수 EV도 가상 관측에는 포함한다.
과거 성적에서 고른 60% 기준은 과적합 가능성이 있어 이번 미래 표본으로 검증한다.
28일이 지났다는 사실만으로 표본 충분성이나 수익성을 입증하지 않는다.

기존 today_combo 저장 트랜잭션에서만 갱신한다. 별도 데몬/AI 감시/추가 외부 요청,
전수 조합 탐색은 없다. 저장량은 고정된 28일 경기 집합에 한정하지만 추가 메모리가
0인 것은 아니다. 정산 지연은 추천 저장 주기를 따른다. 장기 원본은 자동 삭제하지
않으며 새로운 실험 시작이나 정식 추천 승격은 별도 결정이다.

추천 갱신 정체 수정(PR #231)을 먼저 운영 검증해야 한다. 이 변경은 아직 운영
반영·28일 관측·수익성 검증 완료를 의미하지 않는다.
