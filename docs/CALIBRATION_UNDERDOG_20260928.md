# 외부 미사용 시즌 확률 보정·역배 검증 결과

2026-09-28. 재현 코드와 실험 기록만 변경했다. 운영 추천·DB·수집 서버는 변경하지 않았다.
사전 규칙은 `1b7cd36d`에서 고정했고, 이후 2025–26 시즌 평가 결과로 모델·조건을 수정하지 않았다.

## 결론

저배당 허용 방식의 양의 실현 수익은 확인했지만 안정적인 개선을 입증하지 못했다.
역배를 무조건 배제한 것은 아니다. 승무패 모두 심사했으며, 채택 모델에서 추정 EV 3%를 넘긴 역배는 없었다.
이번 코드는 병합할 수 있지만 해당 모델·선별 방식을 운영 추천 정책으로 올릴 근거는 부족하다.

## 데이터와 모델 선택

고정된 공개 CSV의 EPL 2016–26 총 3,800경기를 사용했다. 학습 1,520경기, 보정 380경기,
모델 선택 380경기, 새 최종 평가 380경기를 시간순으로 분리했다. 나머지는 전력 초기화용이다.
각 시즌 380경기, 배당 누락 0, 데이터 해시는 앞선 실험과 동일하다.
같은 제공자·리그의 새로운 시즌이며 다른 제공자나 리그까지 검증한 것은 아니다.

2024–25의 logloss로 선택한 모델은 **시장 기준 잔차 모델**이었다.
이는 시장 확률을 기본값으로 두고, 7일보다 오래된 전적의 Elo·최근 골득실로 소폭 보정하는 다항 모델이다.
원래 모델, 시장과 원래 모델 50:50 혼합, 온도·클래스 편향 보정, Shin 시장 기준까지 5개 후보를 비교했다.
ROI가 가장 높게 나온 모델을 사후 선택하지 않았다.

2025–26에서 선택 모델의 logloss는 1.019634, 시장은 1.019359로 선택 모델이 조금 나빴다.
Brier는 선택 모델 0.612087, 시장 0.612337로 조금 좋았다.
logloss 차이의 주별 재표집 95% 구간은 −0.002089~+0.002599로 개선이 확실하지 않다.
온도 보정만 쓴 기존 대체 모델의 logloss 1.024248보다는 개선했지만, 시장을 이긴다고 할 수 없다.

## 선택 모델의 최종 두폴 결과

평가 기간 경기일 114일에 하루 1단위 예산을 배정했다. 하루 최대 한 장만 구매하고, 후보 두 개가 없으면 현금을 보유했다.
아래 주결과는 해외 원배당 기준 세전 ROI다. 프로토 절상을 적용한 값은 별도 가정이다.

- 확률 60%·1.50≤배당<2.20: **3조합, 2적중, 원배당 ROI +61.23%**, 절상 가정 +66.67%. 총손익 +1.837단위, 전체 예산 수익 +1.61%. 95% ROI 구간 −100%~+151.20%.
- 확률 60%·1.50 미만 허용(2.20 미만): **26조합, 15적중(57.69%), 원배당 ROI +15.13%**, 절상 가정 +17.69%. 총손익 +3.9328단위, 전체 예산 수익 +3.45%, 최대 낙폭 3단위. 95% ROI 구간 **−23.06%~+53.42%**.
- 배당 상한 없이 추정 EV≥3%: 적격 픽 0개, **0조합, ROI 산출 불가**, 총손익 0. 가장 높은 단일 EV가 +1.34%여서 기준에 미달했다.
- 역배 한정 추정 EV≥3%: 적격 픽 0개, **0조합, ROI 산출 불가**. 무승부도 역배 심사에 포함했다.
- EV 제한 없이 역배를 확률 순으로 고르는 진단 대조군: **74조합, 5적중(6.76%), 원배당 ROI −29.78%**, 절상 −29.46%. 총손익 −22.036단위, 전체 예산 수익 −19.33%, 최대 낙폭 32.1단위.

기존 온도 모델의 p60_range는 같은 2025–26에서 20조합·8적중, ROI +1.48%,
총손익 +0.2963단위, 전체 예산 수익 +0.26%였다.
선택 모델의 저배당 허용 방식은 전체 예산 수익이 3.19%p 높았으나, 차이의 주별 재표집 95% 구간은
**−6.95%p~+13.03%p**로 개선을 확정하지 못했다. 투자 총액은 서로 다르며 예산 배정만 동일하다.
조건 변경으로 선택 경기도 달라지므로 저배당의 인과적 효과라고 해석하지 않는다.

## 다른 모델도 모두 확인

- Shin 시장: 저배당 허용 27조합·15적중, 원배당 ROI +10.03%. 확률만으로 역배 선택 시 74조합·4적중, −46.72%.
- 기존 온도 모델: 저배당 허용 42조합·20적중, +3.94%. EV≥3% 전배당은 48조합·15적중, +7.03%. 역배 EV≥3% 후보는 단 한 경기라 두폴 0장이었다.
- 시장 50:50 혼합: 기존 배당 구간 12조합·7적중, +48.26%; 저배당 허용 37조합·19적중, +11.77%. EV≥3% 후보 4경기는 날짜별 두폴을 만들지 못했다.
- 시장 온도·편향 보정: 기존 배당 구간 14조합·8적중, +45.55%; 저배당 허용 40조합·20적중, +8.78%. EV≥3% 후보 2경기는 두폴을 만들지 못했다.

이 보조 비교 중 높은 수익률이 나왔다고 검증 전에 선택한 모델을 바꾸지 않는다.
앞선 2024–25에서 기존 모델의 저배당 허용 ROI는 절상 가정 −24.35%였고, 이번 시즌에는 +5.48%였다.
시즌에 따라 손익 부호가 바뀌므로 한 시즌 최고값을 미래 기대수익률로 제시할 수 없다.
선택 모델의 저배당 두폴 계산상 기대 ROI는 원배당 −8.21%인데 실현 ROI는 +15.13%였다.
이는 확률 모델의 오차와 적은 표본의 변동이 크다는 뜻이지, 음의 기대값 전략이 유리하다는 증거가 아니다.

## 검증 범위와 결정

- 시간 분리, 결과를 제거해도 동일한 픽 선택, 같은 경기 중복 금지, 역배 동률, 미투자 ROI null,
  잘못된 입력 거부, 확률 합 1, 미래 결과 불변, 주 단위 짝지은 비교를 회귀 테스트했다.
- 로컬 Python 전체 852개 테스트·58개 subtest가 통과했다. 25개 모델·정책 조합의 적중 수와 원배당/절상 손익을 별도 Decimal 계산으로 대조했다. 웹·운영 코드는 변경하지 않아 웹 빌드·브라우저 검증은 실행하지 않았다.
- 코드와 통계 계산을 고정한 뒤 실행했으며, 2025–26은 이후 재튜닝의 독립 검증으로 재사용하지 않는다.
- 5모델×5정책을 비교했으므로 최고값만 선택하면 다중 비교 편향이 발생한다. 제시한 구간은 이 편향이나 모델 학습 오차까지 보정하지 않는다.
- 주 단위 재표집은 같은 주 경기 의존성을 일부 보존하지만 주 사이 의존성까지 해결하지 않는다.
- 실제 경기 시작 및 배당 관측 시각이 없어 같은 날 동시 구매 가능성은 미확인이다. 7일 전적 지연도 이 한계를 해결하지 않는다.
- 해외 배당에 프로토 절상 규칙만 적용한 결과는 한국 프로토 실현 수익이 아니다. 세금·구매 제한·가격 차이는 반영하지 않았다.
- 사전 기준(100조합 이상, 양의 ROI 구간 하한, 기준 대비 양의 예산 수익 차이 하한, 시장보다 나쁘지 않은 logloss)을 통과한 후보는 **0개**다.

따라서 **연구 코드·테스트·결과만 병합하고 운영 정책은 유지**한다. 배포할 운영 코드 변경은 없다.
이 실험의 완료와 수익성 검증 통과는 별개다.
