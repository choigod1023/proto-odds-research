# 추천 범위 확대: 60% → 55%

후속 사용자 승인으로 2.20 배당 상한도 제거했다. 아래 비교는 상한 제거 이전의
55% 완화 실험이며 고배당 성과 검증으로 해석하면 안 된다. 최종 정책은
`daily-p55-o150-unbounded-v4`다. 사전 운영 조회의 고배당(2.20 이상) 선택지 584개는
모두 55% 미만(최고 40.23%)이어서 상한 제거만으로 추가 일반 추천이 생기지 않았다.
낮은 확률의 고배당을 별도 고위험 후보로 표시하는 정책은 이번에 적용하지 않는다.

2026-10-10 사용자가 수익률 악화 가능성을 감수하고 기준 자체를 55%로 낮추도록 승인했다.
이는 추천 빈도에 대한 선호 반영이지 모델 개선이나 양의 기대수익 입증이 아니다.
배당 1.50 이상~2.20 미만, 홀짝·역배 제외, 경기당 최종 방향과 T-30 동결은 유지한다.
새 정책 ID는 `daily-p55-o150-v3`. 이전 60% 정책 및 더 오래된 정책의 추천 이력은
당시 기준으로 복원하며, 이미 동결된 비추천 기록을 추천으로 소급 변경하지 않는다.

## 사전 비교

운영 API 산출물 생성 시각 2026-10-10 12:36:46 KST의 후보 81개에서 배당·안전조건을
통과하는 79개 중 확률 기준별 통과 수는 60%: 6개, 58%: 25개, 55%: 49개였다.
전체 후보 대비 7.4% → 60.5%다. 오늘 화면의 날짜·시작 여부 필터를 적용한 개수는 아니다.

고정 EPL 과거 데이터, 경기별 Shin 시장 최유력, 단폴 동일 1단위로 비교했다.

- 2023–24 (380경기): 60%는 35픽·적중 60.0%·ROI −7.57%,
  55%는 83픽·적중 57.83%·ROI −6.48%.
- 2024–25 (380경기): 60%는 30픽·적중 60.0%·ROI −8.00%,
  55%는 85픽·적중 54.12%·ROI −12.24%.
- 중간 58% 기준도 비교했지만 시즌별 ROI +1.28% / −18.52%로 일관된 개선이 없었다.

이전에 연구에 사용한 데이터이므로 독립 외부표본 재검증이 아니다. 해외 배당이며
정확한 가격 관측 시각이 없어 실제 프로토 구매·T-30 조건을 재현하지 못한다.
조합 ROI, 비용, 구매 가능성도 검증하지 않았다. 이 결과로 수익 개선을 주장하지 않는다.
