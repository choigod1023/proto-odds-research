# 경기별 조합용 픽 가상 비교 v1

기존 추천·하이라이트·자동 조합 비활성 정책을 변경하지 않는다. UI 변경, 실제 구매,
확률 모델 학습, 운영 승격은 포함하지 않는다. PR #232의 시간대별 조합 실험과 독립이다.

## 선정

같은 배당 스냅샷에서 기존 경기별 대표 픽과 실험 픽을 만든다. 실험 후보는 지원되는
시장의 양쪽/세 방향을 비교하며 운영의 최유력 방향 및 1.50~2.20 가격 우선을 적용하지
않는다. 기존 시장 제외 기준, 과도한 오버라운드 제한, 오늘/다음 날 오전 범위는 유지한다.
실제 판매 가능 여부/판매 종료 정보가 완전하지 않으므로 구매 가능성을 보장하지 않는다.

실험은 동일 선택에 연결된 검증 모델·decision ID·artifact hash·검증된 불확실성 하한이
있고 `하한 × 현재 배당 > 1`인 후보 중 최종 적중확률이 가장 높은 하나를 고른다.
동률이면 하한, 선택 식별 키 순이다. 시장확률 fallback을 검증된 하한으로 인정하지
않는다. 검증 확률이 없으면 abstain이며 수익성 추천으로 포장하지 않는다. 새로운
하한이나 과거 적중률을 만들어 넣지 않는다. 따라서 초기 실험 후보 0건일 수 있다.

## 기록

추천 생성 시 작은 `per_event_shadow_proposals`를 만든다. SQLite today_combo 저장
트랜잭션에서 이전 DB 상태를 기준으로 `per_event_shadow` 원장을 합친다. 외부에서
넘긴 원장과 오래된 writer는 신뢰하지 않는다. 파일 전용 모드에는 영속 원장을 추가하지 않는다.

생성/원천/실시간 배당 시각 모두 현재 이전 15분 이내이며 partial/error가 아닐 때만
새 비교를 등록한다. 첫 유효 관측부터 28일간, 최대 2,000개 이벤트를 기록한다. 자동
재시작/오래된 결과 삭제는 없고 이후 정산만 계속한다. 수집 작업이나 타이머를 추가하지 않는다.

경기 시작 30분 이전 **최초 동시 관측**의 기존/실험 픽을 고정한다. 운영 최종 T-30 픽과
같다는 뜻은 아니다. 당시 기존 하이라이트 여부가 아닌 경기별 대표 픽이 기준군이다.
기권도 고정해 이후 좋아진 경기만 골라 기록하지 않는다. 빈/부분 응답은 원장을 지우지
않는다. 키에는 종목/리그/팀/UTC 시작시각이 들어가며 일정 변경은 새 이벤트가 될 수 있다.

선택된 두 픽의 시장/라인/회차/배당/확률/모델 출처와 제외 사유별 개수를 남긴다.
메모리 절약을 위해 모든 대안의 전체 JSON은 보관하지 않으므로 임의의 미래 선정 규칙을
이 원장으로 완전히 재현할 수는 없다. 전체 경기 수가 아니라 관측된 지원 후보 경기 수다.

## 평가와 한계

원래 선택에 공식 결과를 연결하고 무효/미정산을 분리한다. 각 선택 1단위 가상 금액,
무효는 0손익이며 정산 원금에 포함한다. ROI는 정산된 선택에 대해서만 계산하고 0건은
null이다. 이 수치를 2경기 조합 수익률로 제시하지 않는다.

summary는 팔별 선택/정산/적중/실패/무효/미정산/손익/ROI와 기권 수를 제공한다.
두 팔이 모두 정산된 동일 경기의 손익 차이와 실제 선택 변경 수도 별도로 제공한다.
팔별 ROI는 서로 다른 경기 집합일 수 있어 단순 차이를 정책 효과로 해석하지 않는다.
짝지은 비교도 기권 경기를 제외하므로 전체 예산 효과와 구별한다.

28일 또는 통계 구간 하나만으로 수익성을 입증하지 않는다. 확률 모델 자체의 시간순
외부 검증, 시장별 보정, 일정 변경 처리, 조합 동시 구매 가능성 검증은 별도 과제다.
