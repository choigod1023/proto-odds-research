# 외부 과거 데이터 예측·두폴 검증

2026-09-28 실행. 운영 정책·DB·배포는 변경하지 않았다.
이 실험은 운영 AI의 정확한 재현이 아니라 외부 데이터로 만든 별도 대체 모델이다.

## 고정한 방법

- EPL 2016–25 총 3,420경기. 매 시즌 380경기, ID 중복 없음, 두 CSV 완전 일치, 배당 누락 0.
- 2016–19는 전력 초기화, 2019–23 1,520경기 학습, 2023–24 380경기 온도 보정, 2024–25 380경기 최종 평가.
- 기존에 살펴본 2023–24는 독립 검증이라고 부르지 않는다. 이번 최종 평가 결과를 보고 기준을 재조정하지 않았다.
- 입력: 7일보다 오래된 결과로 만든 Elo 차이·최근 5경기 골득실 차이, 비마감 Bet365 승무패 배당의 Shin 확률 로그비.
- 다항 로지스틱, 고정 L2=0.01. 온도 보정 범위 0.5–2.0, 추정 온도 0.793894.
- 승/무/패 모두 평가하고 경기당 EV가 가장 높은 적격 선택 하나만 허용.
- 날짜별 EV 내림차순, 확률 내림차순, 경기 ID 순으로 상위 서로 다른 두 경기만 조합. 하루 최대 한 장. 조건 미달이면 현금 보유.
- 109개 평가 날짜 각각 예산 1단위. 모든 방식에 같은 예산을 주되 강제로 투자하지 않는다. 투자액 대비 ROI와 전체 예산 대비 수익률을 구분한다.
- 세전, 수수료 없음. 해외 배당 원값과 프로토식 조합 절상을 가정한 값 모두 계산한다.

## 새 학습·보정 모델 결과

- 확률 60% 이상·1.50 이상 2.20 미만: 16조합, 4적중(25.0%), 원배당 ROI −38.38%, 절상 가정 ROI −37.50%, 손익 −6단위. 전체 예산 대비 −5.50%.
- 확률 60% 이상·1.50 미만도 허용(2.20 미만): 46조합, 17적중(36.96%), 원배당 −25.42%, 절상 −24.35%, 손익 −11.2단위. 전체 예산 대비 −10.28%.
- 확률 하한 없이 단일 픽 추정 EV 3% 이상·2.20 미만: 18조합, 4적중(22.22%), 원배당 −38.04%, 절상 −37.22%, 손익 −6.7단위. 전체 예산 대비 −6.15%.
- 확률 하한·배당 상한 없이 단일 픽 추정 EV 3% 이상: 22조합, 7적중(31.82%), 원배당 +0.90%, 절상 +1.82%, 손익 +0.4단위. 전체 예산 대비 +0.37%.

마지막 방식의 날짜 재표집 5,000회 95% ROI 구간은 −60.01%~+69.65%다.
이는 탐색적 부트스트랩 구간이며 날짜 간 독립 가정, 모델 추정 오차·다중 비교·시계열 의존성은 반영하지 않는다.
어느 방식도 양의 수익 우위를 입증하지 못했다.

저배당 허용은 투자 ROI와 적중률을 높였지만 베팅이 늘면서 총손실은 −6에서 −11.2단위로 커졌다.
역배를 금지하지 않았으나 최종 선택된 역배 픽은 모든 방식에서 0개였다. 따라서 역배 수익성 검증을 마쳤다고 할 수 없다.

## 확률 신뢰도와 비교 기준

학습 모델의 다항 Brier는 0.582971, logloss는 0.975748.
Shin 시장 기준은 각각 0.578994, 0.970780으로 더 좋았다(둘 다 낮을수록 좋음).
배당 상한 없는 모델 방식의 독립성 가정 기대 ROI는 +11.39%였지만 실제 원배당 ROI는 +0.90%였다.
확률을 곱해 만든 기대수익률을 실제 수익으로 받아들이면 안 된다.

Shin만 사용한 60%·1.50~2.20 미만 기준은 5조합 중 4적중, 절상 ROI +92%였으나 95% 구간 −20%~+145%다.
같은 Shin에 저배당을 허용하면 34조합·17적중, 절상 ROI −7.65%였다.
작은 표본의 최고 수치만 골라 정책을 채택하지 않는다.

## 한계와 다음 검증

새 운영 기록을 기다릴 필요 없이 외부 과거 데이터로 모델 후보를 걸러낼 수 있다는 점은 확인했다.
그러나 해외 배당이므로 한국 프로토에서 같은 가격과 조합을 구매할 수 있었음을 뜻하지 않는다.
날짜는 있으나 정확한 경기 시작·배당 관측 시각이 없어 같은 날 아침 일괄 구매 가능성을 증명하지 못한다.
7일 결과 지연은 전적 누출을 줄이지만 배당 관측 시각 부재를 해결하지는 않는다.
공개 과거 시즌이라 완전한 사전등록 전향 실험도 아니다. 현재 시즌은 모델 개발용으로 소비되었으므로 이후 재튜닝의 독립 검증으로 재사용하지 않는다.

이번 모델은 운영 승격하지 않는다. 다음 후보는 다른 리그·시즌을 잠근 뒤 확률 보정 개선 여부와 두폴 손익을 함께 검증해야 한다.
역배 후보는 별도 사전 고정 비교군을 마련해야 한다. 운영 재현은 실제 사전 기록으로 별도로 확인한다.
