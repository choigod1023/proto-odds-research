# 이용약관 문서 운영

`web/src/lib/service-terms.js`가 조문과 문서 메타데이터의 단일 원본이며 `terms.html`에 표시합니다. 기존 7개 유의사항을 12개 조문과 부칙으로 정리했습니다.

## 정식 적용 전 확인

- 사용자는 운영자명·문의 이메일이 아직 없다고 확인했습니다. 운영자 정보·문의처·시행일을 임의로 만들지 않고, UI에 검토본 상태와 미정 사항을 명시합니다.
- 실제 이용 대상, 수익모델, 개인정보·접속 로그 처리, 외부 처리업체·이전 및 보유기간은 별도 확인해야 합니다. 약관은 개인정보 처리방침을 대신하지 않습니다.
- 법률 전문가 검토 후 정식 적용과 변경 고지 절차를 정합니다. 법적 유효성 검토가 끝난 상용 약관으로 간주하지 않습니다.
- 이번 변경에는 동의 수집, 자동 결제, 유료 상품·환불 기능을 추가하지 않았습니다. 유료 도입 시 별도 조건과 동의를 검토해야 합니다.
- 존재하지 않는 이메일·고객센터·개인정보 처리방침 링크를 만들지 않습니다.
