# 픽 선택 방식 안내 공개 설정

현재 안내는 기본 공개입니다. 상용 빌드에서 `VITE_SHOW_PICK_METHOD=false`를 설정하고 `npm --prefix web run build`를 실행하면 메뉴·관련 링크·안내 본문 청크가 제외됩니다. 이전 research.html 주소에는 경기 분석으로 돌아가는 안내만 표시합니다.

GitHub Actions로 빌드한다면 해당 빌드 단계의 env에도 같은 값을 설정해야 합니다. 다시 공개할 때는 값을 제거하거나 true로 빌드합니다. 자동으로 상용 출시 시점을 판단하지 않습니다.

이 설정은 선택 방식 안내의 공개 범위만 바꾸며, 경기별 데이터 부족 표시·확률 설명·사용자 기록·결과 검증을 제거하지 않습니다. 기존 연구 내용은 Git 이력에 보존되어 있으며 공개 Git 저장소의 과거 내용을 비공개로 만들지는 않습니다.
