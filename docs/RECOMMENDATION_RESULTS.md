# 최근 추천 결과 표시

- 메인 성적은 백분율이 아닌 `최근 추천 N건 중 H건 적중`이다. 최대 10건이며 부족한 표본을 채우지 않는다.
- 제목 아래 `오늘의 추천픽 기준`을 12px 보조 문구로 표시한다.
- 기준: 최근 90일 안에 경기 시작 30분 전까지 실제 생성·보존된 추천 중 공식 결과가 확인된 최근 최대 10건. 경기 시작 시각 내림차순이며 적중 여부로 순서를 고르지 않는다.
- 적중·실패는 색뿐 아니라 텍스트로 표시한다. 칸 클릭 시 당시 선택, 배당, 공식 결과와 보존 시각을 모달로 확인한다.
- 경기 전, 진행 중·미판정, 무효는 별도 건수로 표시한다. 점수 기반 임시 판정과 추천 여부가 확인되지 않은 과거 사전 픽은 제외한다.
- 전체 사전 픽 성적은 별도 접힌 항목에 남긴다. 추천 실적과 혼용하지 않는다.

## 저장과 정산

SQLite `today_combo` artifact를 저장할 때 `recommendation_history`를 같은 트랜잭션으로 보존한다. 기존 DB 스키마나 예측 원장은 변경하지 않는다. 기존 프론트의 날짜·리그별 기본 3개/60% 이상 추가 추천 정책을 기록하며 새 추천 정책을 도입하지 않는다. Python/JS 동등성 테스트를 함께 유지한다.

동일 이벤트의 최신 공개 후보와 추천 여부는 T-30 전에만 갱신한다. T-30 이후에는 선택·라인·배당·추천 여부를 바꾸지 않는다. 최초 도입 시 경기 후 오래된 캡처 시각을 이용한 역산은 금지한다. 과거 후보를 새 성과로 복구하지 않으므로 초기에는 대기 상태가 정상이다. 빈 응답/부분 응답으로 보존 이력을 삭제하지 않으며 명시적으로 추천에서 제외된 미래 후보는 그 상태를 기록한다.

공식 마켓 결과는 팀·날짜·회차·게임번호·마켓·원래 라인이 모두 일치할 때 연결한다. 원천의 회차가 사라져도 이미 확인한 공식 결과는 보존한다. 원천 결과가 수정되면 재반영한다. 아직 결과가 없는 기록은 실패나 무효로 가정하지 않는다.

## 검증

`python -m pytest -q` 및 `npm test --prefix web`, `npm run build --prefix web`.
로컬 예시 데이터는 `web/.vite`의 무시되는 테스트 화면에서만 사용하고 배포 산출물에 포함하지 않는다.
실제 결과 10건·7건 적중 예시의 데스크톱/390px 레이아웃, 칸 클릭 모달 및 Escape 닫기를 확인했다. 이 예시는 운영 성적이 아니다.
