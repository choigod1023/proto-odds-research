# 경기 전 시험 확률 수집

정식 추천의 방향·확률·하이라이트는 변경하지 않는다. 기존 `ai_candidate`를 현재
시점에 복원하는 작업도 아니다. 새 후보는 별도 `validation_shadow`에 저장한다.
버전은 `recent-form-poisson-shadow-v1`이며 학습/검증되지 않은 통계 기준 모델이다.

## 산식과 범위

KBO/NPB/MLB의 선택된 승패 픽만 대상으로, 양 팀 최근 5~10경기의 원점수를 사용한다.
홈 기대 득점은 `(홈 평균 득점 + 원정 평균 실점) / 2`, 원정은 그 반대로 계산한다.
독립 Poisson 득점 분포를 만들고 무승부를 제외한 홈/원정 승리 확률로 환산한다.
5경기 하한·평균 결합·무승부 제외는 미검증 설계 선택이지 성능 최적화 결과가 아니다.
선발·라인업·구장·상대 강도 보정이 없으므로 확률이 잘 보정됐다고 가정하지 않는다.

경량 갱신에서 이미 읽은 DB 폼 자료를 재사용한다. 추가 DB 조회/원천 요청이나 전체
생성기 호출은 없다. 새로 결정하는 사전 픽만 수집하며, 기존 고정 픽에 후보를 소급
추가하거나 갱신하지 않는다. 가격·상태가 그대로인 기존 문서도 소급 수집하지 않는다.
따라서 배포 즉시 모든 예정 경기에서 모델값이 생기는 기능은 아니다.

계산 시각과 원장 수집 시각은 T-30 이전이어야 한다. DB 자료 출처·조회 기준시각,
사용 경기의 날짜·득실점, 후보 버전·선택지/상품 ID, 시장 확률·관측 시각을 함께 남긴다.
자료 부족·지원하지 않는 시장·미래/중복 날짜·잘못된 점수는 확률 대신 사유를 저장한다.
실제 경기 결과를 **지금 DB에서 읽었다**는 기록이며, 과거에도 그 결과를 알고 있었다는
뜻이 아니다. 상대방 원천의 최초 결과 공표 시각을 인증하는 기능도 아니다.

`features.validation_shadow.inputs`에 원자료를 한 번 저장한다.
`predictions.validation_shadow`에는 입력을 제외한 확률/버전/시각/식별자를 저장한다.
정산은 기존 prediction snapshot과 selection ID를 사용한다. 운영 `ai_candidate`와
구버전 score-distribution 모델의 성능을 이 신규 후보와 합쳐 집계하지 않는다.

## 평가

```powershell
python scripts/evaluate_probability_shadow.py <local-ledger.jsonl>
```

읽기 전용으로 마지막 예측 revision과 정확한 정산을 연결해 버전별 동일 표본에서
시장/후보 Brier 점수와 로그손실을 계산한다(낮을수록 좋음). 미정산, 무효, 정정 충돌,
식별자 불일치와 늦은 수집은 제외한다. 시간대 없는 예측 시각은 입력 오류로 실패한다.
출처 진위/해시 체인은 별도로 검증한 원장을 입력해야 한다.

이것은 서술 통계이며 모델 학습·시간순 홀드아웃·신뢰구간·2경기 조합 백테스트가 아니다.
원래 선택지를 그대로 평가하므로 별도 전략 ROI를 계산하지 않으며 승격은 항상 금지한다.
현재 로컬 과거 원장은 마지막 예측 207개 모두 이 신규 후보를 갖고 있지 않아 비교 표본
0건이다. 그 결과를 수익률 0% 또는 모델 실패/성공으로 해석하지 않는다.

다음 단계는 실제 사전 수집과 정산이 쌓인 뒤 평가 구간/모델/선택 규칙을 고정하고,
완전히 분리한 이후 구간에서 보정 성능과 픽 커버리지·실현 ROI를 검증하는 것이다.
동일 경기가 반복 포함된 2경기 조합은 독립 표본으로 세지 않는다.
