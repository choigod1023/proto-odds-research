# 정배·역배 조합 사전 검증 규칙

이 규칙은 신규 자료의 전략별 수익률을 계산하기 전에 고정한다. 운영 추천은 변경하지 않는다.

- 자료: sosthene14/footballdataset, 커밋 e82cf59161e82e0fbcdc49ad02819e45c821a5c8.
  Serie A와 Ligue 1의 2016/17~2024/25. 파일 개수·날짜·결측만 사전 점검했다.
  기존에 평가한 EPL과 독일·스페인 자료는 이번 평가에 사용하지 않는다.
- 2016~19는 과거 특징 준비, 2019/20~2021/22는 학습,
  2022/23은 온도 보정, 2023/24와 2024/25는 고정 모델의 두 평가 시즌이다.
  두 평가 시즌 사이에 계수나 기준을 다시 학습하지 않는다. 과거 경기 특징만 순차 갱신한다.
- 기존 비교 모델: Shin 시장 확률, 시장 확률에 지연 Elo·득실차 폼을 보정한 모델.
  조건부 모델: 여기에 역배 여부, 홈 역배, 무승부, 역배 팀의 Elo·폼·휴식 차이 상호작용을 추가.
  L2=0.1, 온도 범위 0.5~2 고정. 결과 기반 특징은 7일 초과 지연한다.
  휴식은 이전 리그 경기 날짜만 사용하며 컵·국제대회 일정은 없다.
- 비교 전략: 시장, 기본 모델, 기본+역배 고정 순위 가산점, 조건부 모델,
  기본+가산점으로 자격 기준까지 완화하는 위험 대조군.
  가산점은 역배 한 선택당 순위 점수 +0.03이며 확률에는 더하지 않는다.
  위험 대조군만 역배의 EV 자격 검사에 +0.03을 더한다. 실제 기대값과 구별한다.
- 최저 배당은 1 초과, 상한 없음. 정배는 Bet365 H/D/A 최저 배당(동률 포함),
  역배는 그 밖의 선택으로 무승부도 포함한다. 홈·원정 역배만의 해석과 구별한다.
- 조합 유형: 정배+정배, 정배+역배, 역배+역배, 구성 제한 없음.
  기본은 각 선택의 EV>=3%; 강제 선택 대조군은 EV 필터 없이 모든 후보를 비교한다.
  순위는 log(p1*o1*p2*o2)+가산점이며 같은 경기의 두 선택은 묶지 않는다.
  동일 리그·날짜당 상위 한 조합, 1단위 예산. 조합 없으면 현금 보유.
  구성 고정 시 역배 개수도 고정되므로 순위 가산점만으로는 선택이 바뀌지 않아야 한다.
- 가격 비교: Bet365 비마감 배당 / B365,BW,IW,PS,WH,VC 중 존재하는 비마감 최고 배당.
  후자는 동시 체결 가능성이 검증되지 않은 낙관적 가격 시나리오다.
  마감 배당은 쓰지 않는다. 배당 관측 시각과 실제 프로토 배당은 없으므로 실행성은 미검증이다.
- 출력: 시즌·리그별 및 통합 표본수, 적중률, 원배당/한국식 조합 올림 ROI,
  같은 예산 총손익, 최대 낙폭, 주 단위 5,000회 부트스트랩 신뢰구간,
  기본 대비 바뀐/추가된 조합의 성과, 홈 역배·폼/Elo/휴식 우위별 결과.
  추가 선택은 가산점 전략만 선택한 조합(기존 조합 대체 포함)이며 순수 추가 날짜도 별도 집계한다.
  데이터별 독립 시행을 전제로 신뢰구간을 좁히지 않고 같은 ISO 주는 함께 재표집한다.
- 다중 비교는 탐색으로 취급한다. 평가에서 가장 높은 ROI를 찾았다고 운영 후보로 승격하지 않는다.
  최소 100조합, 두 시즌 모두 원배당 이익, 원배당 ROI와 기본 대비 예산 차이의
  95% 신뢰구간 하한이 모두 양수인지 기술적으로 표시하되 다중비교 보정 전 결과임을 명시한다.
- 부상·라인업·로테이션과 배당 이동은 당시 관측 시각을 갖춘 자료가 없어 검증 불가.
  가상의 부상 정보를 만들거나 현재 정보를 과거 경기에 붙이지 않는다.
