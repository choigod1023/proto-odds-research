이 표의 입력은 편의 표본이며 서비스 전체 누락률이 아니다. 원천 작성 시각의
주장이나 이 조사에서 확보한 HTML은 운영 측 최초 수신의 증거로 쓰지 않는다.
운영 서버가 보관한 수집 로그에는 접근하지 못해 원천 차단 여부와 실제 제외 사유는
확인하지 못했다.

`칼초`를 일괄적으로 레체와 동일시하지 않는다. 프로시노네 대 칼초 세리에A 제목에서
본문에 프로시노네와 레체가 각각 팀 항목으로 순서대로 있고 결과 예측 구간이 뒤따를
때만 레체로 해석한다. 해당 근거가 빠지거나 중복되면 기존처럼 경기 연결을 보류한다.

변경은 확인된 리그·팀 별칭과 전체 경기 선택 형식만 추가한다. 경기 종목, 팀 쌍,
날짜와 단일 매칭, 최초 실제 수신, T-30 동결을 유지하며 전반전·핸디·승1패·합계는
일반 승패 투표로 쓰지 않는다. 대괄호가 없거나 야구 예상 승리팀, 농구 승부 예측,
명확한 첫 줄 팀 승패를 읽고 서로 다른 선택 문구가 복수면 보류한다.

골리 목록에서는 판정 전인 유일한 대상 경기를 최대 4개 먼저 살핀다. 각 목록의
최신 글과 나머지 순환 예산을 유지하고 본문 요청 수는 기존 16개 이하를 넘지 않는다.
목록 제목은 요청 순서만 바꾸며, 본문을 받은 뒤 동일한 검증을 다시 통과해야 한다.
