# 종목별 유한 모델 탐색 — 실행 전 계약

## 목적과 범위

운영 변경 없이 야구(bs), 축구(sc), 농구(bk), 배구(vl)의 주 승패 시장을 로컬에서 비교한다.
축구만 무승부를 포함한다. 모든 가능한 모델을 탐색한다는 뜻이 아니다.
픽스터·선발·결장 자료는 이 대규모 과거 CSV와 경기 전 시점으로 연결되지 않아 이번 입력에서 제외한다.
이 결과를 기존 운영 모델 또는 픽스터 75:25 혼합과 직접 비교한 것으로 설명하지 않는다.

## 고정 후보군

종목별 37개 확률 모델 (실행 전 독립 검토에서 동일한 절편 보정의 중복 ridge 후보를 제거):

- 시장 내재확률 1개.
- 시장 오프셋 보정, 시장+Elo/Pi, 시장+전체 과거 폼, 시장 없는 전체 과거 폼의 4개 선형 계열.
- 절편만 있는 보정은 하나만 사용. 나머지 선형 계열 L2 계수 0.001 / 0.01.
- 깊이 2 / 4 히스토그램 부스팅, 100회, 학습률 0.05, 최소 잎 50, L2=1.
- 위 9개 학습 모델 각각 시장확률과 혼합. 학습 모델 비중 25 / 50 / 75 / 100%.

폼 입력은 Elo, Pi, 최근 승률·점수차·추세·휴식·백투백·연승·홈원정·맞대결이다.
원본 팀 문자열의 현재 경기 점수, 현재 결과, 결과 라벨은 입력하지 않는다.
기존 Pi 설정과 피처 설계도 과거 연구를 참고했으므로 독립적인 사전 확정 설정은 아니다.

## 분할과 선택

2023 학습, 2024 후보 선택, 2023–2024 재학습 후 2025 비교.
날짜 전체를 같은 구간에 둔다. 학습 중 결측치 대체와 스케일도 학습 구간에서만 계산한다.
이전 날짜의 관측된 결과로 레이팅을 순차 갱신한다. 같은 날짜의 결과는 같은 날짜 입력에 반영하지 않는다.

- 적중률 후보: 2024 argmax 픽 적중률 최대, 동률이면 Brier 최소.
- 확률 품질 후보: 2024 Brier 최소.
- 수익 후보: 2024 가상 2폴 30장 이상, 순이익 양수, 수익 월 6개월 이상인 구성 중 순이익 최대. 동률이면 최대낙폭 최소.
- 적격 수익 후보가 없으면 없음으로 남긴다. 2025 결과로 교체 후보를 다시 고르지 않는다.

2025는 이전 연구에서 이미 열람한 자료다. 이번 실행 내부의 시간 분할이지, 처음 보는 독립 최종 검증이 아니다.
종목별 37모델 × 4규칙 × 주 2/3회 = 296개 가상 운용 구성, 총 1,184개를 2024에서 탐색한다.
다중 탐색 편향이 있으므로 승자를 곧바로 운영 채택하지 않는다.

## 가상 운용 규칙

1. 확률 55% 이상·배당 1.50 이상, 확률 순.
2. 위 조건에 추정 기대값 양수 추가, 기대값 순.
3. 확률 50% 이상·배당 1.50 이상·추정 기대값 3% 이상, 기대값 순.
4. 확률 60% 이상·배당 1 초과·추정 기대값 양수, 확률 순.

배당 상한 없음. 하루 한 장, 다른 두 경기, 장당 1만 원, 주 2회·3회 각각 비교.
월 손실 5만 원: 다음 티켓이 전액 손실이어도 한도를 넘지 않을 때만 발행한다.
다음날 정산을 가정하고 미정산 노출도 제한한다. 정산은 티켓 발행월에 귀속한다.
2폴 배당은 곱의 소수 둘째 자리까지 절사 후 소수 첫째 자리 올림이라는 연구용 가정을 사용한다.
서로 다른 종목은 각각 별도 가상 계좌이며, 네 종목 수익을 합쳐 하나의 5만원 제한 계좌 수익이라고 하지 않는다.

과거 CSV에는 배당 관측·판매 시각, 동일 회차 구매 가능성, 실제 경기 종료 시각이 없다.
따라서 가상 티켓은 실제 구매 가능성을 검증한 티켓이 아니다. 정산된 경기만 남은 자료의 선택 편향도 있다.

## 보고

검증·비교 표본 수, 적중률, Brier, 단폴 전체 경기 ROI와 선택된 2폴 ROI를 구분한다.
2폴 순이익·티켓수·수익월수·최악월·최대낙폭을 함께 제시한다.
시장과 같은 경기의 적중률·Brier 차이에 7개 관측일 블록 bootstrap 2,000회를 사용한다.
이는 달력 7일과 다르며 다중검정 보정이나 미래 수익 보장이 아니다.
시장이 최고이거나 후보가 전부 손실이면 그대로 보고한다. 코드·데이터 해시와 실행 산출물을 남긴다.
수익 결론은 2024에서 선택한 모델·규칙·주간 횟수 전체 조합으로 한정한다. 선택이 없으면 없음으로 보고한다.
적중률/Brier 신뢰구간을 수익률의 신뢰구간으로 설명하지 않는다.
