# 2026-11-05 다종목·다시장 확대 분석 계획

확대 결과 확인 전에 분석 대상을 고정한다. 기존 44경기만으로 모델 우열을 판단하지 않는다.

- 원천: 기존 147개 회차 매니페스트와 명시한 추가 Betman 공식 원문 아카이브. 모든 압축 해제 본문 SHA256, 요청·응답 회차, 원본 표 구조를 확인한다. 외부 원본은 수정하지 않는다.
- 같은 회차는 기존 매니페스트의 스냅샷을 우선한다. 신규 회차의 서로 다른 본문은 수신 시각, 경로 순서로 선택한다. 결과나 수익에 따라 원문을 고르지 않는다. 다른 본문 및 중복 수를 기록한다.
- 기간: 2025-01-01~2026-11-05. 원문 내 미래·미완료 경기와 취소·지원하지 않는 상품은 별도 집계한다.
- 대상: 축구·야구·농구의 전 경기 언더오버 및 핸디캡 중 정산 규칙을 입증한 상품. 부분 경기, 0.25 단위, 단위를 모르는 상품, 2선택 정수 핸디캡은 제외한다.
- 대표 상품은 동일 물리 경기·시장 유형 안에서 회차 숫자, matchSeq 숫자가 가장 작은 상품이다. 라인·가격·모델 결과에 따른 사후 선택을 하지 않는다. 전체 상품 분석은 비독립 민감도 결과로만 표시한다.
- 비교: 실제 동결된 KBO M0 득점분포가 있는 경기에서 동일 라인·동일 배당·동일 공식 결과로 M0와 시장 선호 방향을 비교한다. 일반 승패 배당이 이전 667경기 집합과 같은지는 totals/handicap 적격 요건으로 쓰지 않는다. 이전 44경기 결과는 따로 재현한다.
- 축구·농구는 실제 동결 예측을 확인하지 못하면 시장 기준만 계산한다. 시장 확률을 M0·선수 모델·픽스터 예측으로 이름만 바꾸지 않는다. 픽스터의 정확한 라인·방향·경기 전 원문 시점을 증명하지 못하면 비교하지 않는다.
- 동일 1단위 베팅, 적중률·환급률·순수익률·최대 누적 손실폭·월별/기간별 안정성·서로 다른 픽 수를 계산한다. 월 손실 5만원 모의 원장은 변경하지 않는다.
- 2026년 KBO는 이미 살펴본 회고 비교다. 2023~2025 학습 M0에 2025 경기를 평가 표본으로 넣어 미관측 성과라 하지 않는다. 과거 자료의 오늘 수신 시각이나 파일 해시는 당시 구매 가능한 가격·경기 전 수신을 증명하지 않는다.
- 테스트·커밋·push·draft PR로 근거를 보존한다. 이번 확대 연구는 모델 채택·병합·배포·서버 변경 권한을 뜻하지 않는다.

## 고정 모델 추가 비교 (확대 모델별 결과 계산 전)

공식 경기 ID가 없는 239개 동결 예측도 별도로 연결 가능성을 확인한다. 예측 ID 문자열에서 팀을 추정하는 대신 원래 예측 입력의 해시 검증된 경기일·홈·원정 식별자를 사용한다. 같은 날짜·팀의 모델 입력과 공식 원문의 경기 시작 시각이 유일한 경우에만 추가하며, 더블헤더·중복·모호성은 제외한다. 이 연결 표본은 원래 공식 ID 기반 엄격 표본과 별도로 보존하고, 점수·승패로 경기 정체성을 결정하지 않는다.

같은 709개 동결 파일 안의 `m0_actual`, `m0_projected`, `m1_projected`를 동일 적격 상품에서 비교한다. 새 계수·배당 구간·필터를 맞추지 않는다. actual/projected는 보존된 모델 학습 사양 이름이며 오늘의 실시간 운영 모델이나 경기 전 수신 인증을 뜻하지 않는다. 세 모델 모두 고정 계수의 독립 Poisson 득점분포이며 미보정 연구 추정치다. 확률 동률/비정상 값이면 세 모델의 공통 표본에서 제외한다.

선택한 상품의 1단위 손익을 시장 선호 선택과 짝지어 비교하고, 경기 날짜 단위 군집 재추출 5,000회(고정 시드 20261105)의 기술적 95% 구간을 제시한다. 시간상 앞·뒤 절반은 결과와 무관하게 날짜 중앙값으로 나눈다. 계절 의존·반복 연구·사후 자료 문제를 제거한 검증 구간으로 해석하지 않는다. 구형 상품 ID를 추정한 표본과 명시적 상품 ID가 있는 표본은 분리한다.
