# 선수 입력 연구 어댑터: 준비와 미평가

PR #433의 팀 상태 모델을 그대로 복사해 provisional-v0 입력 경계에 연결했다. 선수자료가 없으면 `lineup_unavailable`, 유효해도 선수 효과가 학습되지 않아 `player_effects_not_fitted`를 반환하며 둘 다 기준 모델의 확률을 그대로 반환한다. 실제 선수 효과, 모델 재학습, 성과·ROI는 계산하지 않았다. 합성 입력은 경계 검증에만 사용했다.

경기·상품·팀 ID, aware 시각, 경기 전 결정과 원천 최초/수정 수신, 확정·예상 구분, 원문 SHA256, 경기별 팀별 출전량을 검사한다. 축구는 팀당 990분·선수당 최대 90분, 야구는 팀당 9이닝·선발 한 명과 불펜 투수별 기대 이닝을 요구한다. 이는 연장 없는 정규시간 연구 입력의 명시적 제한이며, 불완전한 입력은 거부한다. 야구 타순·타자와 선수별 기여는 아직 처리하지 않는다. 허용 필드 외 결과·현재 점수 등의 입력은 거부한다. 수신 시각과 게시 주장은 별개이며 외부 증명 검증기가 없으므로 인증 true도 거부한다. 결정 시점 이후 상태는 원본 모델이 거부한다.

출력은 원본 상태와 입력 revision, 확률, 진단, 정렬 JSON SHA256을 포함하는 분리된 후보 스냅샷이다. 해시는 변조 감지용이며 외부 인증이나 append-only 저장을 제공하지 않는다. 원본 상태의 과거 결과 가용성·원문 해시의 진위·외부 시각을 이 어댑터가 증명하지 않는다. 호출자가 선수 ID와 팀 ID를 실제 경기와 연결하고 product_id가 전체 경기 승패/승무패에 해당하는지 독립 확인해야 한다. 야구는 비무승부 조건부 2방향, 축구는 승무패 3방향이다. 공통 v0의 모든 페이로드를 구현한 범용 파서는 아니다.

기준 코드 출처: PR433 연구 worktree 커밋 `0ed675a0e7ee53d75691d071b41739099edb1a65`, `experiments/dynamic-score-state-model-20261030/model.py`, SHA256 `97658e8e16b758ff867baf73bdad1daae6c27de2e8d0e4bbe3c58e0f807d31e1`. 해당 파일을 수정 없이 복사했다. 실자료 적격 표본은 이번 작업에서 조사하지 않았고 독립 인증 표본의 기존 연구 수치는 0이다. 새로운 성과 후보 평가 전 사전 프로토콜·자료 가용성·독립 정산이 필요하다. 구조 워커 v1은 총괄의 호환성 결정 전 적용하지 않는다.

연구 전용이며 운영 채택·병합·배포는 수행하지 않았다.
