# 선수 입력 연구 어댑터: 검토 수정과 미평가

PR #442 교차 검토 후 상품·팀·시점 경계를 강화했다. PR #433 팀 상태 모델은 선수 효과를 학습하지 않았고, 유효한 선수 입력이나 선수 입력이 없는 경우 모두 같은 기준 확률을 반환한다. 알려진 불완전·무효 선수 입력도 폐기하고 `lineup_invalid`와 상세 사유를 반환한다. 경기·상품·기준 상태·배당·시점·팀 매핑이 무효하거나 검증을 받지 못하면 예외로 중단하며 확률을 반환하지 않는다. 늦은 선수 리비전은 사용하지 않는 선수 입력으로 취급한다. 늦은 배당이나 T-30 후 판정은 핵심 시점 오류다.

## 신뢰 경계

`infer`는 공식·정규 경기 ID, 팀 ID, 전체 경기 승패/승무패 상품 ID·market=`win`·period=`full`·line=null·순서가 명시된 선택지, 같은 상품의 완전 배당과 실제 수신 시각을 요구한다. KBO/NPB/MLB는 홈·원정, K리그1/2는 홈·무·원정 순서다. 상품·시점이 올바르고 `observed`여야 하며 T-30을 넘기면 중단한다. 판정 시각은 계약의 필수 항목이며 요청과 시간대가 포함된 동일 시각이어야 한다. 원본 계약의 시각도 독립 검증자에게 전달된다. 공식 팀 ID는 양 팀이 서로 다른 기존 학습 상태 팀 이름에 일대일 매핑돼야 하며 미등록 팀 사전분포는 사용하지 않는다. 상태 해시와 가용 시점, 상태 clock을 확인한다.

호출자는 `verify_contract(contract, state_export)`를 반드시 제공해야 한다. 이 검증자는 외부에서 신뢰할 수 있는 자료를 근거로 **전체 계약**, 경기·상품·팀의 연결, 해당 상태의 해시와 모든 학습 결과의 실제 가용 시점 및 양 팀 학습 이력을 검증해야 한다. 상태 clock이나 자체 해시만으로 과거 학습 누출이 없음을 증명할 수 없다. 이 저장소는 그 독립 검증자·권위 ID 데이터·외부 증인을 제공하지 않는다. 따라서 실제 검증자를 연결하기 전에는 안전한 실자료 추론을 할 수 없다. 테스트의 고정 계약 대조 함수는 합성 fixture일 뿐 인증 수단이 아니다. `external_receipt_verified=true`는 검증기가 없어 거부한다.

## v1.2 연결 범위

`bridge.infer_v1`은 v1.2 경기·공식 alias·상품·배당·관측을 선택하고 주입된 core 검증기와 독립 계약을 모두 요구한다. 계약과 v1.2 내용이 다르면 중단한다. 모델 추론 전에 freeze를 만들어내지 않으며 v1.2 freeze와 settlement를 모델 입력으로 사용하지 않는다. #438 v1.2 validator의 전체 `validate`는 freeze 최소 1개를 요구하므로, 테스트는 해당 원본의 `shape`와 스키마를 핵심 필드에 적용하고 bridge 및 infer에서 관계·시점을 따로 검사한다. 이는 완전한 v1.2 validator 실행이나 기존 freeze 검증의 대체물이 아니다. freeze가 없는 새 추론 입력을 사용한다. 원본 fixture는 별도로 전체 validator를 통과시켰다. v1.2 콘텐츠 해시를 사용해 기존 freeze를 인증하거나 외부 수신을 증명하지 않는다.

같은 관측을 공유하는 양 팀 선수 revision만 현재 결합할 수 있다. 부분 입력, 서로 다른 관측, 중복·누락, 경기 불일치, 알려진 사후 입력 등은 버리고 사유와 기준 확률을 반환한다. 선수 식별자의 진위는 증명하지 않는다. 출전량은 야구 팀당 9이닝·축구 팀당 990분 등 정규시간 제약이며 결측을 채우지 않는다. invalid 입력은 출력에도 복사하지 않아 현재 점수 같은 필드가 피처가 되지 않는다. 결과 봉투의 해시는 자체 변조 확인용일 뿐 외부 증명·불변 저장이나 v1 freeze 해시가 아니다.

원본 모델은 PR433 커밋 `0ed675a0e7ee53d75691d071b41739099edb1a65`의 `model.py`, SHA256 `97658e8e16b758ff867baf73bdad1daae6c27de2e8d0e4bbe3c58e0f807d31e1`을 수정 없이 복사했다. v1.2 validator·schema·fixture는 PR #438 커밋 `33b49a590d607a573ca5bd6832f549aeca9c9300`에서 변경 없이 복사했으며 해시는 handoff에 있다.

합성 데이터는 인터페이스와 누출 경계 검사용이다. 새로운 선수 계수, 적중률·ROI와 실자료 표본은 산정하지 않았다. 실제 평가에는 사전 프로토콜과 검증된 독립 수신·상태 이력·정산이 필요하다. 운영 모델 변경, 병합, 배포는 수행하지 않았다.
