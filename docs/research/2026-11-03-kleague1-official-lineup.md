# K리그1 공식 명단의 회고 복원과 수신 시각 한계

최초 파일럿으로 2023·2024·2025년 각 1경기의 공식 경기 페이지에서 **실제 경기 선발 기록**을 복원했다. 각 경기 양 팀 11명, 총 66명 모두 공식 선수 ID와 포지션을 가진다. 대기 선수 50명, 포메이션 6개, 교체 이벤트 27건도 추출했다. 세 경기의 점수와 종료 상태는 같은 공식 페이지가 호출하는 별도 결과 응답에서 확인했다. 이 파일럿과 2026년 확장 코호트는 별도로 보존한다.

- `kleague:2023:1:1`: 2023-02-25 울산 HD–전북 현대 2-1, 선발 11+11명, 대기 7+7명, 포메이션 4231/4321, 교체 이벤트 9건.
- `kleague:2024:1:1`: 2024-03-01 울산 HD–포항 스틸러스 1-0, 선발 11+11명, 대기 9+9명, 포메이션 4231/442, 교체 이벤트 8건.
- `kleague:2025:1:96`: 2025-05-28 광주FC–울산 HD 1-1, 선발 11+11명, 대기 9+9명, 포메이션 442/442, 교체 이벤트 10건.

공식 경기 페이지의 라인업 표 첫 표는 포지션·선수 ID가 있는 11명, 두 번째 표는 `대기 명단`이다. 파서는 각 첫 표의 ID 집합이 공식 경기장 배치도에 표시된 양 팀 11명과 정확히 일치할 때만 통과시킨다. 감독 행은 제외한다. 경기장 배치, 선수별 경기 기록 및 교체 내역이 포함된 **사후 페이지**이므로 이를 경기 전 최초 공지의 실제 수신이라고 주장하지 않는다. 경기 당시 명단 최초 발표 시각 0/3건, 독립 실제 사전 수신 증명 0/3건이다. 이는 당시 공지가 없었다는 뜻이 아니다. 결장 사유와 최초 공지 이후의 선발 변경도 이번 자료만으로는 확인하지 못했다.

공식 [경기 페이지 예시](https://www.kleague.com/match.do?year=2025&leagueId=1&gameId=96&meetSeq=1&startTabNum=2)의 `updateMatchInfo`가 공개적으로 호출하는 `/api/ddf/match/matchInfo.do`를 동일한 `year`, `meetSeq`, `gameId` 폼값으로 조회했다. GET 3회와 조회 전용 POST 3회 모두 200, 실제 수신은 2026-11-03 10:45:11~10:45:18 KST다. 상세 요청·응답별 시각·바이트 크기·SHA256은 `requests.json`, 원문은 `raw/`에 보존한다. GET 바이트는 무손실 gzip으로 보존하고 기록한 원문 해시는 압축 해제한 HTTP 바이트의 SHA256이다. POST 응답은 원문 그대로다. 각 요청은 15초와 크기 상한을 적용했고 로그인·우회는 없었다. 결과 API는 FE 점수와 교체 시간·선수 ID 두 개를 제공한다. 교체 선수 방향은 응답 순서만 보고 임의로 지정하지 않았다.

## 2026년 종료 경기 확장

2026년 공식 1~12월 일정 12건을 모두 조회해 전체 228경기를 분모로 고정했다. 2026-11-03 현재 원천 상태 기준 종료 204경기와 미종료 24경기다. 종료된 204경기 **전체**에서 공식 선발 4,488명(각 팀 11명), 대기 3,653명, 포메이션 408개, 교체 이벤트 1,935건을 복원했다. 204경기 모두 공식 일정과 경기 ID·날짜·홈원정 팀 ID·점수가 일치했고 미수집 또는 파싱 실패는 0건이다. 미종료 24경기는 아직 명단이나 최종 결과가 없어 별도 대기한다. 발표 시각과 당시 실제 사전 수신을 입증한 경기는 0건이다.

기존 PR #505 동결 연구 자료와 같은 공식 ID·팀·날짜로 연결한 결과, 보관된 3-way 가격과 연구용 동결 예측은 각각 77경기다. 별도 후기 가격 감사에서 같은 ID·팀·날짜·시각의 가격 후보가 35경기 더 연결돼 두 집합의 합집합은 112경기다. 이 가격들은 당시 실제 수신이나 원문 상품·가격의 실행 가능성이 인증되지 않았다. 77개는 연구용 예측이며 실제 운영 동결픽이 아니다. 현재 운영 동결픽과의 정확한 ID 교집합은 미확인이다. 과거 이벤트 원장의 `evt_` ID를 공식 경기 ID로 임의 변환하지 않았다.

결과나 수익률에 따라 경기를 고르지 않고 공식 일정에서 `FE`·종료 상태인 204경기를 날짜 순으로 수집했다. 2026년 경기 페이지 GET 204회와 페이지가 호출한 결과 조회 POST 204회, 월별 일정 조회 POST 12회는 모두 200이다. 요청·응답별 실제 수신 시각과 원문 해시를 저장했으며 최종 수신은 2026-11-03 11:06:37 KST다. 최초 파일럿 6회를 포함한 전체 요청은 426회다. 선수의 해당 경기 후 성적은 별도 표본의 입력 변수로 만들지 않았다.

다음 순서인 2025년 228경기, 2024년 228경기, 2023년 228경기는 기존 파일럿이 각 1경기뿐이므로 **연도별 227경기씩 미완료**다. 수집 횟수와 이들 분모는 `cohort-plan.json`, 실제 교집합과 참조 blob 해시는 `coverage-2026.json`, 이월 정보는 `handoff.json`에 있다. 자동 수집 예약은 만들지 않았다.

저장된 2026 완료 경기 대상의 중단 후 재개는 아래 명령을 사용한다. 완료된 요청은 해시 검증 후 재사용하며 동시 실행은 잠금 파일로 차단한다. 401·403·429에서는 중단한다. 미종료 경기를 나중에 수집하려면 새로운 명시적 조사에서 공식 일정을 새로 확인해야 한다.

```powershell
python experiments/kleague1-official-lineup-20261103/collector.py --capture --season-plan --max-fixtures 204
python experiments/kleague1-official-lineup-20261103/coverage.py
python experiments/kleague1-official-lineup-20261103/verify_artifacts.py
python -m pytest -q tests/test_kleague1_official_lineup.py
```

`coverage.py`는 별도 연구 worktree의 PR #505 커밋 `248de71574694e5a3c1395bd0ed2111115543a8b` Git blob을 읽고 원문 SHA를 검증한다. 이 worktree가 없는 환경에서는 해당 커밋의 같은 blob을 확보해야 하며, 가격 후보 35건의 당시 수신은 계속 미인증이다. `verify_artifacts.py`는 파일·원본 HTTP 바이트 해시와 산출물 간 해시 연결을 오프라인으로 점검한다.

## 기존 연구와 연결

PR #488의 시장·DC 잔차 후보는 공식 선수 정보를 입력하지 않았고, PR #505의 탐색 후보는 시장·DC와 팀 최근 성적 및 휴식일을 썼다. 이번 자료는 그 연구에 없던 **경기별 선수 ID가 붙은 선발·대기·포지션·포메이션·교체 기록**이다. 새 예측 성적이나 신호의 우세가 아니다. 기존 연구를 재튜닝하거나 ROI를 계산하지 않았다.

동결된 공통 OOF 입력 455행의 Git 원문 SHA256 `158cd931f3fa576b97678dfcc0b44042b9ef1a5826183853fb6d9b0beb314f05`를 검증하고, 세 경기의 경기 ID·홈원정 팀 ID·날짜·최종 점수로 대조했다. 2024년과 2025년 2경기는 각각 정확히 1행과 연결되며 두 행 모두 보관된 3-way 가격 벡터가 있다. 2023년 경기는 해당 2024·2025 OOF에 없으므로 연결 0건이다. `crosswalk.json`은 사후 연결 여부만 나타내며 실제 매수 가능 가격이나 당시 수신 인증은 0건이다. 다른 자료에 2023 가격이 없다는 뜻도 아니다.

## 확장과 검증

공식 일정에서 확인한 경기 ID를 명시해 아래 명령으로 제한적으로 확장할 수 있다. 1회 최대 228경기, 기본 1경기, 경기마다 GET·POST 각 1회, 요청 간 1초 간격, 성공 원문은 SHA를 검증하고 재사용한다. 401·403·429가 있으면 자동 재시도를 중단한다. 실제 원문이 없는 ID를 미리 만들어 넣지 않는다.

```powershell
python experiments/kleague1-official-lineup-20261103/collector.py --capture --target 2026:<공식경기번호> --max-fixtures 1
python experiments/kleague1-official-lineup-20261103/collector.py
python experiments/kleague1-official-lineup-20261103/compare_oof.py --oof <동결_LF_원본_oof.jsonl>
python -m pytest -q tests/test_kleague1_official_lineup.py
```

`collector.py`의 인수 없는 실행은 저장 원문만 읽어 파생 결과를 재생한다. 축구 시작 시각은 공식 페이지의 현지 표기를 보존했지만 시간대는 독립 인증하지 않았다. `manifest.json`은 표본·원문 압축파일 해시와 미확인 항목을 기록한다. 실제 원문 3경기와 합성 오류·중복·캐시를 다룬 테스트 11개는 **파싱·연결 검사**이지 적중률 검증이 아니다. 이 자료를 모델에 적용하려면 경기 전 명단 가용 시점과 전날 이전 선수 이력, 가격 근거를 따로 갖춰야 한다. 운영·DB·스케줄·월 손실 제한·배포는 변경하지 않았다.
