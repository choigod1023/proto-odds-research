# K리그2 이력 및 공식 선발 자료 연결 조사

2026-10-30 KST에 독립 연구에서 수집했다. 모델 성과나 운영 변경은 다루지 않았다.

기존 자료 생성기는 `games.csv.tmp`와 공식 일정 캐시, K리그1 전용 상세 자료를 합친다. CSV에는 2023·2024 K리그2가 있으나 2025 K리그2 행은 없었다. 상세 자료는 K리그1 소속 팀만 연결한다. 기존 공식 캐시의 수집 기간은 2025-10-28~2026-10-27이므로 2025 K리그2는 시즌 말 23경기뿐이었다. 이는 23경기가 시즌 전체라는 뜻이 아니다. 생성기와 원본 파일은 변경하지 않았다.

[공식 월별 일정](https://www.kleague.com/getScheduleList.do)을 2025년 2~12월 리그2로 조회해 종료 상태 FE, endYn Y, 같은 연도·월·리그·대회, 점수가 있는 경기 275개를 확보했다. 각 행은 공식 복합 경기 ID, 홈·원정 구단 ID와 이름, KST 시작시각, 최종 점수, 응답 SHA256, 실제 수신 완료 시각을 보존한다. 275개는 고유 ID 기준이며 승무패 상품이나 과거 가격 연결 수가 아니다. 기존 이력 23개는 리그·날짜·홈·원정 팀이 일치하는 유일한 공식 경기와 연결했고 미연결·모호 사례는 0개다. 점수는 연결 대상을 고르는 데 쓰지 않고 연결 후 별도로 대조했으며 23건 모두 일치했다. 같은 날짜·팀 후보가 둘 이상이거나 기존 이력 키가 중복되면 점수가 같더라도 모호로 제외한다. 나머지 252개는 기존 이력에 추가 가능한 사후 결과 후보다. 이름/날짜 기준 연결은 기존 이력에 시작시각과 공식 ID가 없어 독립 ID 대조가 아니다. 취소·미완료, 다른 대회는 제외했고 전체 일정의 완전성은 독립 대조하지 않았다.

현재 예정 일정 조회는 K리그1 24, K리그2 32, KBO 1경기다. K리그 각 1경기의 공식 출전명단 PDF 경로는 200 HTML을 반환했지만 확인 가능한 명단을 추출하지 못했다. KBO 공식 GameCenter에서 11월 1일 1경기의 선발 타순 API를 조회했으나 확정 명단이 없었다. 선발투수도 공식 예정 응답에 없었다. 경기 전 수신된 확정/예상 선수 행은 0개이며 외부 독립 수신 인증 0개다. 일정 수신은 명단 수신이 아니다. 해당 시점 이후 발표 여부는 확인하지 않았다. 상품 ID, 판정 시각, 게시 주장, 선수 ID 등 미확보 값은 null이다. 경기 종료 시각 역시 미확보다.

요청 원장에는 실제 수신 완료 시각과 응답 해시를 기록했다. 직접 HTTP 요청은 초기 점검 3회, 본 수집 19회, 출전명단 경로 2회, 총 24회이며 요청별 15초 제한을 적용했다. 별도 검색 도구의 검색 1회는 출전명단 경로 확인에 사용했다. 원문 응답은 배포하지 않고 최소 필드와 해시만 보존했다. 사후 결과의 수신을 2025년 경기 전으로 소급하지 않는다. 라인업 경기 전 증명 및 선수 ID 연결은 새 관측과 독립 검증이 필요하다. [기존 연구 범위 정정](../research/2026-10-25-research-scope-correction.md)을 따른다.

`match.py`는 보존된 23건의 축약 이력과 공식 결과를 다시 연결한다. `links.json`의 입력 SHA256은 파생 JSON 파일의 줄바꿈을 LF로 정규화한 바이트의 해시다. 각 공식 행의 `raw_sha256`은 당시 HTTP 응답 본문 바이트의 해시이며 파생 JSON의 해시가 아니다. 원문 응답을 보존하지 않았으므로 해당 바이트 해시는 지금 다시 계산할 수 없다. 점수 오염 및 중복 후보 회귀 검사는 실제 연결 함수에 적용했다.

독립 검토에서 서로 다른 날짜·대진의 공식 행에 같은 경기 ID가 들어갈 경우 기존 로직이 두 이력을 같은 ID로 연결할 수 있음을 발견했다. 이제 전체 공식 입력에서 ID가 누락되거나 중복되면 점수와 후보를 보기 전에 연결 전체를 중단한다. 실제 저장 자료는 275개 ID가 모두 고유하며, 재계산한 유일 연결 23건·추가 후보 252건은 유지된다.
