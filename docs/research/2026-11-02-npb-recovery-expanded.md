# NPB 2023년 공식 결과 아카이브 확장 복원

누락 선발 935경기(2023년 879, 2026년 56) 중 **2023년 256경기**의 양 팀 실제 출전 선발 표기와 최종 점수를 공식 경기 결과 원문으로 연결했다. 2023-03-30~2023-05-25, 49일이다. 최초 보고한 3경기를 포함한 수치이며 이번 확장의 순증은 253경기다. 원본 3,248행 중 양쪽 이름이 있던 2,313행에 별도 회고 코호트 256행을 더하면 2,569/3,248행이다. 원본은 수정하지 않았다. 복원 256경기 모두 공식 최종 점수와 원래 점수가 일치한다.

935건의 상태는 복원 256, 2023년 한도 때문에 미조회 621, 2026년 미조회 54, 구단 외 올스타 경기 제외 4다. **실제 조회 후 일별 목록에서 미발견 0, HTTP 실패 0**이며 675건의 미조회는 미발견이나 복원 불가능을 뜻하지 않는다. 일별 목록 수신 뒤에는 해당 날짜·홈/원정 팀 코드가 유일한지, 결과 페이지 링크가 일치하는지, 원본 시작 시각과 공식 실제 시작 시각이 30분 이내인지 검사했다. 목록에서 같은 팀 조합이 여러 번이면 더블헤더를 임의로 결합하지 않는다. 2023년 구단 별칭은 연도 한정으로 매핑하며 원래 gameId를 공식 ID로 가정하지 않는다. 날짜·팀·시각은 가능한 신원 오류를 줄이나 독립적인 교차 시스템 인증 자체는 아니다.

이번 확장에서 공식 서버에 순차 요청 300회(상한 300, 최소 간격 0.45초, 동시성 1)를 보냈고 300회 모두 HTTP 200이었다. 165.33초에 요청 상한으로 중지했다. 기존 원문 5건을 재사용해 공식 일별 목록 49건과 경기 원문 256건, 합계 305건을 보관했다. 최초 표본의 원문 5건도 그대로 유지했다. 신규 300회는 2026-11-02 02:15:09~02:17:54 UTC에 수신됐다. `manifest-expanded.json`의 305개 URL·원문 SHA256·수신 시각·로컬 경로와 `collection-log.json`의 시도별 HTTP 기록을 제공한다. 해시는 보존 바이트의 무결성만 뜻하며 과거 시점 수신 증명이 아니다.

공식 경기 페이지의 양 팀 선발은 각 팀 투수표의 첫 행으로 추출했다. 페이지의 일본어 약칭만으로 선수 ID를 추정하지 않아 공식 선수 ID 양쪽 연결은 0/256이다. 2023년 경기 전 실제 수신 증거는 0/256이며 복원 입력은 사후 자료다. 별도 `data/raw/overseas/NPB.json` 182행 중 복원된 날짜에 해당하는 배당 행은 0개다. 저장소의 모든 가격을 전수 조사하지 않았고 같은 상품·시간·정산까지 일치하는 배당과 현행 운영 동결픽의 연결은 미측정이다. 적중률·ROI·새 모델 검증은 하지 않았다.

원자료: `data/raw/npb_starters.json` SHA256 `6f3c2cfabc21e8a30d6bd475d55e0c7d6091e813181bb8678aa89e3baadf2ed0`; 이전 공식 원문 `experiments/npb-recovery-20261102/raw/`; 새 압축 원문 `experiments/npb-recovery-20261102/expanded_raw/`. 원문 내용 해시는 압축 해제 바이트 기준이며, URL별 원본·메타데이터는 덮어쓰지 않았다. 경기별 결과는 `cohort-expanded.jsonl`, 실행·출처 명세는 `manifest-expanded.json`이다. 이전 #425 아카이브 조사 범위와 결측 원인은 최초 연구 기록에 보존한다.

실행 명령: `python experiments/npb-recovery-20261102/expanded_recover.py`; `python -m pytest tests/test_npb_recovery_20261102.py tests/test_npb_recovery_expanded_20261102.py -q`. 원문 해시, 원래 3건 유지, 일별 목록 불완전·동일 팀 중복 거부, 분모와 사전 수신 미검증 표시를 검사했다. 선수 ID, 당시 수신, 가격·정산과 나머지 미조회 경기의 자료 확보는 남았다. 운영 모델·DB·원장·스케줄을 변경하지 않았다.
