# GAP 초기값·적응 속도: 실행 전 고정

앞선 PR #260 결과를 보고 설계한 후속 탐색이다. 독일·스페인 2019/20–2024/25
자료는 이미 노출됐으며 새 holdout이나 실제 Proto 수익 검증이 아니다.
이 문서를 단독 커밋한 뒤 실자료를 실행한다. 운영·DB·웹은 변경하지 않는다.

## 네 가지 요인 조합

GAP의 평점 순서는 각 통계별 [홈공격, 홈수비, 원정공격, 원정수비]다.
통계는 총슈팅과 유효슈팅 두 종류. 기존 `local_gap_information.py`의
예측·갱신식, ridge=1의 시장-offset 분류기, +7일 통계 공개를 재사용한다.

- zero_constant: 처음 본 팀의 평점 0, 일정한 학습률. 이전 GAP와 동일 대조군.
- prior_constant: 처음 본 팀만 인과적 리그 평균으로 초기화, 일정한 학습률.
- zero_fast: 0 초기화, 각 팀·통계의 첫 6번 유효 업데이트에 학습률 max(기본값,.2).
- prior_fast: 인과적 평균 초기화와 첫 6번 빠른 적응을 모두 사용.

초기화는 팀이 자료에 처음 나타난 경기의 사전 예측 시점에 한 번 한다.
그 시점에 공개된(+7일) 과거 같은 리그의 유효 통계 쌍만 누적 평균한다.
평균이 홈 h, 원정 a이면 [h,a,a,h]를 넣는다. 과거가 없으면 0.
학습기간 전체 평균·현재 경기·미래 시즌 구성은 사용하지 않는다.
동일 날짜의 첫 예측 전에 공개 큐를 처리하고, 동일 날짜 통계는 반영하지 않는다.
결측 쌍은 해당 통계 업데이트와 유효 횟수에서 제외한다.

재등장 팀은 기존 상태와 업데이트 횟수를 유지한다. 별도의 승강 명단이나
하부리그 자료가 없으므로 승격 팀을 정확히 식별하거나 재등장 팀을 리셋하지 않는다.
이 제한을 명시하고 다음 사전정보 기준 그룹을 진단한다:
1) 최소 한 팀·통계의 공개된 업데이트가 6회 미만인 cold 경기,
2) 해당 팀의 시즌 첫 등장 당시 전 시즌 관측이 없던 entrant 경기,
3) 나머지 경기. entrant는 관측상 새 진입이며 실제 승격과 동의어가 아니다.
전체 시즌 진입 표시는 해당 시즌 첫 등장 때 고정한다. 시즌 전체 팀 명단은 쓰지 않는다.

## 학습과 공정 비교

기존 pinned 12 CSV와 같은 출처 해시, 같은 두 fold:
2019–21 학습/2022 내부선택/2023 평가, 2019–22 학습/2023 내부선택/2024 평가.
학습 결과는 평가 시작보다 최소 7일 이전이어야 한다.
기본 학습률 {.05,.10,.20}, 홈/원정 공유비율 {.50,.80}는 이전 격자 그대로다.
네 계열×6 설정×2 fold = 48개 내부 후보. 내부 log loss로 계열별 설정을 선택하고
학습+내부 자료로 재적합한다. 네 계열 전체 선택 경로도 내부 점수로만 결정한다.

추가로 이전 GAP가 선택한 해당 fold의 학습률·공유비율을 네 계열에 똑같이
고정한 비교를 보고한다. 초기값/적응 효과와 파라미터 재선택 효과를 분리한다.
평가 결과를 보고 격자·정책·초기값·평가 대상을 변경하지 않는다.
이전 JSON과 zero_constant 확률이 일치하는지 먼저 확인한다.

모든 계열의 통계별 MAE/MSE를 전체·cold·entrant·그 외 그룹으로 보고한다.
승무패 log loss/Brier/정확도, 같은 5개 정책의 2경기 조합 적중·ROI·coverage와
예산 수익을 보고한다. 현금 날짜를 포함한 리그/날짜별 1단위 예산을 보존한다.
모든 정산 가격은 B365 원가격. Proto 배당 반올림·세금·한도·체결은 재현하지 않는다.
순수 Shin, 기존 GAP, 새로운 전체 내부선택 경로를 구별한다.
같은 ISO 주 paired bootstrap 5,000회(seed20261001)로 기존 GAP/Shin 대비
log loss와 정책 지표의 차이 구간을 계산한다. 다중 탐색 전체 보정은 아니다.
그룹 진단을 근거로 불리한 경기를 사후 제외하지 않는다.
