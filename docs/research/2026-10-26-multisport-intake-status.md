# 다종목 픽스터 연결 진행 상태

## 완료한 범위

- 기존 운영 수집기는 `src/pickster_watch.py`의 MLB TailSlips 입력뿐이다.
- 킹콩티비의 공개 농구·배구 분석 글을 웹 조회로 확인했다.
  - https://www.goli.tv/board/analysis/297856?page=1
  - https://www.goli.tv/board/analysis/297857?page=1
- `multisport_tipster_intake.py`는 추출된 기사 메타데이터와 본문에서 명시적 전체 경기 승리 방향만 읽는다.
- KBL/NBA/WKBL/KBO/NPB/KOVO컵/V리그의 정확한 종목·리그·팀·날짜와 단일 경기 일치를 검사한다.
- 게시 시각과 실제 관측 시각을 구별하고, T-30 이후 관측·동일 날짜 중복 경기·모호한 선택은 제외한다.
- 기사 제목의 팀 순서를 홈/원정으로 가정하지 않는다. 핸디캡·승5패 추천을 일반 승리로 바꾸지 않는다.

## 아직 하지 않은 것

- 이 모듈은 입력 파서/매칭 준비 코드다. HTML 메타데이터 자동 추출, 정기 수집, 운영 DB 기록, 확률 혼합과 웹 표시는 연결하지 않았다.
- 축구 3-way 무승부 시장은 아직 지원하지 않는다.
- 다른 종목의 실제 수집 표본, ROI, 모델 개선 결과는 없다. 단위 테스트의 합성 경기 시간을 실제 사이트의 경기 시간으로 해석하면 안 된다.
- 과거 공개 글을 오늘 읽었다는 사실만으로 당시 경기 전 확보한 자료라고 간주하지 않는다.

## 수집 연결 장애와 다음 검증

2026-10-26 KST 작업에서 로컬 Python requests와 curl로 킹콩티비·아톰티비 HTTPS 연결을 시도했지만 연결 reset으로 실패했다. 웹 검색 도구에서는 킹콩티비 글을 읽었다. 이것은 로컬 실패의 원인이나 운영 서버에서도 실패한다는 증거는 아니다.

실제 수집 경로의 정상 응답과 HTML 메타데이터 추출을 확인한 뒤, 원문 해시/최초 관측 시각을 append-only로 저장해야 한다. 이후 실제 예정 경기의 정확한 시장과 연결하여 운영 혼합 로직·프론트 정책 허용 목록·동결 회귀 테스트를 함께 바꾼다. 그 전에는 다종목 적용 완료나 배포 완료로 보고하지 않는다. 기존 MLB 운영 모델 및 월 손실 5만 원 제한은 변경하지 않았다.
