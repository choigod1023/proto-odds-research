# 2025 K리그1 국내 경기일·결과 대조

상태: `partial_official_cohort`. 국내 2025년 K리그1 전체 경기 승무패 자료와 공식 원천을 제한적으로 대조했다. 공식 경기 페이지 3건의 날짜·표시 시각·홈/원정과 그중 1건의 최종 점수를 확보했다. 시즌 전체 공식 결과를 수집한 것은 아니다. 모델 학습, 수익률 계산, 운영 변경은 하지 않았다.

## 입력과 인코딩

- 지정 원본 `games.csv.tmp` 전체 25,019,789바이트는 UTF-8 엄격 디코딩에 성공했다. 원본 SHA256 `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`. 원시 바이트가 표현하는 리그명은 정확히 `K리그1`이며 K리그2를 섞지 않았다.
- main 정규화 파일 `domestic.jsonl.gz` SHA256 `4bf3abf8bb82838ee72975e1ef486a471b357a03ee4d8627808780f046dae51a`, 전체 47,729행이다. UTF-8을 엄격 해독해 같은 `K리그1` 문자열로 필터링했다. 과거 콘솔에서 보인 깨진 표시는 출력 경로의 표현 문제였으며, 해당 두 입력의 리그명 바이트가 깨졌다는 증거가 아니다.
- 2025년 `sc`·`K리그1` 원본은 상품별 865행, 그중 라벨 없는 경기 전체 3-way 승무패는 227행이다. 정규화도 227행이고 세 경기 외에 원본과 정규화의 행별 동등성을 보증하지 않는다. 각각 회차+경기번호 중복과 정규화 ID 중복은 0건이었다. 핸디캡 점수를 일반 점수로 읽지 않았다.

## 공식 대조 결과

결과 분모는 위 국내 정규화 227행이다. 세 연결은 공식 경기 ID, 실제 홈·원정 표기, 날짜·원본 회차/경기번호, 정규화 ID를 사람이 경기별로 명시했다. 이는 이 세 경기의 특정 연결이며 팀명에 대한 일반 자동 별칭 사전이 아니다. 대조 스크립트는 각 식별자가 유일하고 원본과 정규화 팀 표기가 명시된 값에 맞을 때만 비교한다.

| 항목 | 일치 | 불일치 | 미확인 |
|---|---:|---:|---:|
| 원본 경기 날짜 | 3 | 0 | 224 |
| 정규화 경기 날짜 | 3 | 0 | 224 |
| 원본·공식 표시 시각의 시·분 | 3 | 0 | 224 |
| 정규화·공식 표시 시각의 시·분 | 3 | 0 | 224 |
| UTC 순간·시간대 | 0 | 0 | 227 |

정규화 파일은 전체 점수 대신 `y` 결과 범주를 가진다. 시·분의 숫자 일치는 UTC 순간 인증이 아니다. 세 공식 페이지에서 별도의 시간대 근거를 확보하지 못했고, 정규화 입력에도 `minute_timezone_uncertified`로 기록되어 UTC 변환은 하지 않았다. 세 경기의 명시된 연결에서 복수 매칭 0건·고유 매칭 3건이며 나머지 224건은 공식 대조 자체가 없어 미확인이다. 미확인은 불일치가 아니다. 취소·연기와 가격도 같은 의미다.

- [경기 96](https://www.kleague.com/match.do?year=2025&leagueId=1&gameId=96&meetSeq=1&startTabNum=0): 2025-05-28 19:30 광주FC 홈·울산 HD 원정. [연맹이 게시한 구단 공식 기사](https://www.kleague.com/news_view.do?orderBy=seq&page=3&seq=93724&viewOption=album)는 5월 28일 광주 원정 1-1을 확인한다. 원본 1-1 및 정규화 무승부와 일치한다.
- [경기 110](https://www.kleague.com/match.do?year=2025&leagueId=1&gameId=110&meetSeq=1&startTabNum=0): 2025-06-17 19:30 전북 현대 홈·수원FC 원정. 페이지의 점수 위젯은 별도 POST로 로드하므로 이 GET 응답만으로 최종 점수는 확인하지 않았다.
- [경기 140](https://www.kleague.com/match.do?year=2025&leagueId=1&gameId=140&meetSeq=1&startTabNum=0): 2025-07-26 19:00 수원FC 홈·FC안양 원정. 같은 이유로 점수는 미확인이다.

원본 바이트·SHA·URL·UTC 실제 요청 및 수신 시각은 `experiments/verified-cohort-20261101/kleague1/manifest.json`에 보존했다. 직접 GET 5회는 모두 200이었고, 별도로 웹 검색 8질의와 웹 열람 3회를 사용했다. 검색·열람 각각의 정확한 조회 시각은 계측하지 못했다. 직접 GET은 2026-11-01 09:57:54~09:58:33 KST에 수신했다. 공식 시즌 일정 페이지는 결과 목록을 POST로 불러오는 구조여서 GET만 허용된 이번 범위에서 전수 수집하지 않았다. 차단 우회나 POST는 수행하지 않았다.

## 한계와 재현

공식 경기 페이지의 해당 시점 조회는 2025년 경기 전 수신을 증명하지 않는다. 원본 배당이 같은 판매 상품의 실제 경기 전 가격으로 수신됐는지, 선발과 결장이 그때 가용했는지도 미확인이다. 국내 원본에 노르웨이 외부 자료의 날짜 오류를 전파하지 않았다.

main의 `data/raw/prediction_ledger/pregame.jsonl`은 SHA256 `77c224f03c28217f552cb98b96a02e350a1e0e79d12a7145a81a3296a693d4e0`인 2026-08-28~09-01의 1,326행 로컬 스냅샷이라는 총괄의 별도 확인을 기록한다. 현행 `tipster-vote-v1`과 canonical fixture 필드가 없으며 최신 서버 원장 조사 결과가 아니다. 2025년에 현행 정책의 실제 동결픽을 필수로 요구하지 않았고 실제 운영 재생이나 가상 과거 정책 성능도 계산하지 않았다.

```powershell
python -m src.research_kleague_dates --raw <games.csv.tmp> --normalized experiments/all-sports-underdog-20261031/inputs/domestic.jsonl.gz --fixtures experiments/verified-cohort-20261101/kleague1/fixtures.jsonl --output <comparison.json>
python -m pytest -q tests/test_research_kleague_dates.py
```

합성 불일치·복수 매칭·다른 리그/핸디캡·미확인 상태와 보존된 공식 바이트를 확인하는 테스트 5개가 통과했다. 이는 나머지 224경기나 미래 수익성을 검증한 것이 아니다. 운영 코드·DB·일정·지갑·배포는 건드리지 않았다.
