# 2025 K리그1 국내 경기일·결과 대조

상태: `official_season_compared`. 공식 페이지의 조회 전용 POST로 2025년 2~11월의 K리그1 경기 228건을 확보했다. 경기 ID는 모두 다르고 결과 상태는 모두 `FE`다. 1~38라운드에 각각 6경기, 12개 구단에 각각 38경기가 있다. 1월과 12월은 조회하지 않았으므로 응답상 시즌 228경기를 확보한 범위를 넘어서 월별 빈 목록까지 확인했다고 주장하지 않는다.

국내 원본과 정규화 자료의 2025년 경기 전체 3-way 승무패는 각각 227행이다. 2025 시즌의 공식 구단 ID와 국내 표기를 수동으로 1대1 검토해 `team-map.json`에 보존했다. 각 연결에는 같은 날짜와 홈·원정 방향을 요구하며, 경기마다 공식·정규화·원본 후보가 각각 하나일 때만 비교했다. 자동 유사도나 다른 시즌으로 전파하는 별칭 병합은 하지 않았다.

## 대조 결과

분모는 국내 정규화 227행이다. 유일하게 연결된 227경기는 모두 공식 자료와 날짜·홈원정·표시 시각·원본 최종 점수·정규화 승무패 결과가 일치했다. 비교 항목마다 일치 227, 불일치 0, 미확인 0이다. 같은 날짜를 연결 조건으로 사용했으므로 연결되지 않은 경우 날짜가 틀렸는지 단정할 수 없다. 이번에는 국내 227행 모두 연결되었다. `FE`와 `endYn=Y`도 각 227건에서 확인했고 국내 원본의 `is_void`도 모두 `False`였다. 과거 취소·연기 이력이나 정산 규정까지 확인한 것은 아니다.

공식 경기 228건 중 국내 227행에 연결되지 않은 경기 1건은 **2025-06-29 서울 홈–포항 원정, 4-1**, 공식 경기 ID `kleague:2025:1:126`이다. 지정 원본에서 해당 날짜의 서울 홈·포항 원정 행을 찾지 못했다. 이 사실만으로 누락이 생긴 원인이나 다른 자료에 존재하지 않는다고 단정하지 않는다. 세부 연결 227건과 월별·라운드별·팀별 건수는 `comparison.json`에 있다.

정규화 자료는 전체 점수 대신 결과 범주 `y`를 가진다. 표시된 시·분은 일치했지만 정규화 입력의 시간대는 인증되지 않았으며, 공식 목록 응답의 별도 시간대 근거도 확인하지 못했다. 따라서 UTC 순간 비교는 227건 전부 미확인이다. 실제 당시 동일 상품 가격 수신도 227건 전부 미확인이다. 공식 사후 경기 확인은 사전 선발·배당 수신을 증명하지 않는다.

## 출처와 제한

공식 [일정 페이지](https://www.kleague.com/schedule.do?leagueId=1&year=2025)의 저장된 HTML에서 `onChangedNew`가 `/getScheduleList.do`로 `leagueId`, `teamId`, `year`, `month`, `ticketYn`을 보내 목록을 렌더링하는 코드를 확인했다. 이 요청은 결과 목록을 읽는 용도다. 그와 동일한 매개변수로 월 1회씩 10회의 읽기 전용 POST를 수행했다. 15초 timeout, 응답 3,000,000바이트 한도를 적용했고 모두 HTTP 200, `resultCode=200`이었다. 응답 원문·각 POST payload·실제 수신 시각·SHA256을 `manifest.json`과 `post-requests.json`에 보존했다. 최종 POST 수신은 2026-11-01 10:03:21 KST다. 이전 직접 GET 5회와 별도 웹 검색 8질의, 웹 열람 3회도 기록했다. 검색·열람 각각의 정확한 시각은 계측하지 못했다. 로그인이나 접근 제한 우회는 하지 않았다.

지정 원본 `games.csv.tmp` 25,019,789바이트는 UTF-8 엄격 디코딩에 성공했고 SHA256은 `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`다. 정규화 `domestic.jsonl.gz`는 전체 47,729행이고 SHA256은 `4bf3abf8bb82838ee72975e1ef486a471b357a03ee4d8627808780f046dae51a`다. 두 입력의 실제 리그명은 `K리그1`이다. 이전 콘솔의 깨진 글자는 출력 표현 문제이며 원본 리그명 바이트 손상의 증거가 아니다. 원본 전체 K리그1 상품 행 865건에서 라벨 없는 전체 경기 승무패만 227건으로 골랐고 핸디캡을 섞지 않았다. 원본 회차+경기번호와 정규화 ID 중복은 각각 0건이다.

처음 GET으로 확인한 3경기와 1개 점수의 결과는 `pilot-fixtures.jsonl`, `pilot-comparison.json`에 별도 보존한다. 10개 월별 POST 응답은 `schedule-2025-MM.json`, 전체 공식 fixture는 `fixtures.jsonl`이다. 국내 경기와의 연결 정보·점수 비교는 `comparison.json`에 저장한다. 공식 바이트와 파생 산출물의 Git 저장 해시를 검증한다.

main의 `data/raw/prediction_ledger/pregame.jsonl`은 SHA256 `77c224f03c28217f552cb98b96a02e350a1e0e79d12a7145a81a3296a693d4e0`인 2026-08-28~09-01 1,326행 로컬 스냅샷이라는 총괄의 별도 확인을 기록한다. 현행 `tipster-vote-v1`과 canonical fixture 필드가 없고 최신 서버 원장 조사 결과가 아니다. 2025년 현행 동결픽을 요구하거나 실제 운영 재생·과거 가상정책·ROI를 계산하지 않았다.
