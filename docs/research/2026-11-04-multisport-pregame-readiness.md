# 2025년 이후 종목 확대와 선수·픽스터 모델 공통 비교 준비

2026-11-04. 요청한 기간은 2025-01-01부터 실행 시점까지, 종목은 축구·야구·농구다. 사전작업을 감사하고 종목별 수집 워커 3개, 프로토 가격 워커 1개와 독립 검토 워커 1개를 유한 작업으로 실행했다. 기존 선수 모델과 결과는 남아 있었다. **그러나 사전 명단·선수 이력·원문 투표·당시 배당·각 모델 예측·공식 결과를 모두 연결한 비교 준비는 완료돼 있지 않았다. 이번에도 전체 기간 수집 및 전 모델의 최종 순위 검증이 끝났다고 주장하지 않는다.**

## 현재 답할 수 있는 범위

새 통합 묶음은 입력 19,608레코드, 요청 평가 기간 안의 18,873레코드를 포함한다. 정규화한 경기 키 후보는 12,712개다. 원천별 식별자 미연결과 중복 가능성이 있어 이를 독립된 공식 경기 12,712개라고 부르면 안 된다. 로컬 원문·메타데이터 묶음 90개를 해시 대조했고 오류는 없었다. 본문 해시 일치는 의미상 추출값이나 독립된 외부 수신 시각 인증과 다르다.

`experiments/pregame-multisport-20261104/intake-v2/`의 공통 비교를 실제 실행한 결과, 모든 요청 모델이 동시에 적격인 표본은 **0경기**였다. 이번 묶음에서 통과한 투표·시장·9:1 공통 표본도 0경기다. 적중률과 ROI는 0%가 아니라 **산출 불가(null)**다. 이것은 새로 구성한 묶음의 결과이며 과거의 모든 원천에 적격 자료가 전혀 없다는 결론이 아니다. 이전 14/21/260경기 연구를 이번 선수 모델 비교 결과로 대체하지 않았다.

## 사전작업 감사에서 확인한 사실

- main에 선수 수집·KBO 선발·NPB/축구 라인업과 `pregame_player_capture.py`가 남아 있다. 문서의 업데이트 시각이나 선수 이름이 있다는 사실만으로 확정 사전 명단이 되지는 않는다.
- `operating_model_capture.py`/`operating_model_comparison.py`에 시장·9:1·저장 점수 모델·별도 야구 후보 슬롯이 있다. 그 점수 모델을 KBO 연구 M0/M1/M2라고 바꿔 부르지 않았다.
- 기존 KBO M0 전향 runner의 `status`를 실행했다. 로컬 capture/settlement 0, source-verified paired settlement 0, source adapter 미연결, schedule 미설치라고 반환했다. 이는 이 로컬 연구 runner의 상태이며 운영 전체 수집이 멈췄다는 뜻은 아니다.
- 기존 Python 투표 모의 원장 workflow는 11월 3~4일 성공한 실행이 있었다. 이것은 M0/M1/M2의 동시 사전 검증이 돌아간다는 증거가 아니다. 상세는 `prerequisite-audit.json`에 보존했다.

## 실제로 비교 가능한 과거 참고값

다음은 저장된 예측·가격·결과의 동일 경기 교집합을 재계산한 **회고 진단**이다. 당시 확정 명단 수신과 가격 관측을 검증한 요청 결과는 아니다. 원문 투표와 9:1도 결합하지 못했으므로 여섯 모델 비교의 완료로 해석하면 안 된다. 후보 선택에 이미 사용하거나 열람한 기간이어서 새 블라인드 검증도 아니다.

단폴 1단위, 같은 경기의 같은 양방향 가격, 무승부 환급으로 계산했다. 적중률은 환급 경기를 제외한 분모이고 ROI에는 환급 베팅액도 포함했다. 월 손실 한도 계좌의 실제 수익이 아니다.

2025년 확정 명단 학습 계열, 동일 가격 **676경기**:

- 시장: 403/676, 적중률 **59.62%**, ROI **-10.30%**.
- M0_actual: 378/676, **55.92%**, **-9.29%**.
- M2_actual: 384/676, **56.80%**, **-8.70%**.
- 해당 계열의 M1 출력은 없었다. 다른 계열의 M1을 이 자리에 끼워 넣지 않았다.

2026년 동일 가격 **667경기**, 이 중 무승부 환급 15경기, 적중률 분모 **652경기**:

- 시장: 387/652, **59.36%**, ROI **-9.03%**.
- 확정 명단 학습 M0_actual: 395/652, **60.58%**, **-4.36%**.
- 확정 명단 학습 M2_actual: 374/652, **57.36%**, **-7.38%**.
- 별도 예상 명단 학습 계열 M0: 378/652, **57.98%**, **-8.30%**.
- 별도 선수 역할 효과 M1: 347/652, **53.22%**, **-13.16%**.
- 별도 선수 역할 효과 M2: 368/652, **56.44%**, **-8.73%**.

이 참고 표에서는 2026 M0_actual이 가장 좋았지만 모두 손실이다. 2025에는 M2_actual의 ROI가 더 좋았다. 표본·시점 검증 문제와 미연결 투표를 남긴 상태에서 전 기간 최적 모델이나 미래 우위를 정할 수 없다.

M0 -4.36%와 -8.30%의 차이는 가격 바꿔치기가 아니었다. 같은 667경기의 가격 출처·가격·상품 ID·승자는 모두 같았고, 두 M0의 확률은 667경기, 선택은 80경기에서 달랐다. 전자는 실제 명단 paired 학습 2,182경기, 후자는 예상 명단 학습 2,187경기로 계수가 다르다. 새 비교기는 두 종류의 M0와 M2를 별도 arm으로 유지하고 원래 연도별 artifact ID도 보존한다. 전체 709경기 적중률과 가격 표본 652경기 적중률을 섞지 않았다.

## 구현한 연결과 검증

`run_pregame_multisport_study.py`는 등록된 Python 수집기 실행, 원문 receipt/해시 검사, 모델 artifact registry 검사, 기간 제한, 동일 상품 비교와 봉인된 입력 재생을 제공한다. 원문·메타데이터·완료 시각 기준이 서로 맞아야 하며, caller가 넣은 `receipt_verified=true`는 그대로 믿지 않는다. 이 검사는 로컬 무결성과 선언된 학습 종료 시각의 대조다. 원문 추출값과 학습 계보의 의미를 독립 인증한 것으로 과장하지 않는다.

종목별 수집기는 요청 상한·캐시·재개 경로를 갖췄다. KBO 여러 경기일의 명단 누락, 첫 미확정 캐시의 영구 재사용, 순연/시간 변경 후 일정 캐시가 남는 경로를 고쳤다. 같은 본문의 새 수신도 관측별 ID로 보존하고 최초 수신을 덮어쓰지 않는다. 픽스터 수집기에는 전체 HTML 바이트 보존과 명시 픽/상품 매핑을 추가했다. **운영 배포나 자동 스케줄 활성화는 하지 않았다. 현재 최신 경기의 모든 모델 예측이 자동 축적된다고 주장하지 않는다.**

독립 검토에서 발견한 환급 분모 누락, 예측 이후 선수 이력, 서로 다른 상품 투표 혼입, 완료 시각 허용 목록 문제를 회귀 테스트로 막았다. 공식 결과는 최신 수정/미확정 상태를 먼저 반영하고 점수를 판정한다. 축구는 90분 승무패, 야구·농구는 해당 상품의 최종 경기·연장/환급 조건을 구별한다. 일반 적용 시간·무승부 처리는 [공식 게임 안내](https://www.sportstoto.co.kr/proto_intro.php)와 [2023년 규칙 개정 안내](https://www.sportstoto.co.kr/view.php?idx=2398&page=16&text_search=&type=notice)에서 확인했으나, 과거 API 상품별 식별자가 충분하지 않은 가격은 여전히 `settlement_rule=unknown`으로 보류했다.

실제 적중률/ROI의 공식 순위를 내려면 남은 기간 자료 수집, 원문 투표와 공식 ID/상품 연결, 사전 명단/선수 이력 검증, 각 모델의 같은 시점 동결 출력이 추가로 필요하다. 과거에 수신 기록이 없는 자료는 지금 조회했다고 경기 전 자료로 바뀌지 않는다. 축구·농구에는 해당 종목에 맞는 선수 모델의 명세와 동결 출력 확인도 필요하며 KBO 모델을 그대로 적용하지 않는다.

기존 월 -5만 원 모의 원장·운영 추천·DB·스케줄은 보존했다. 병합·배포·증설·재시작·실베팅·이메일 발송은 수행하지 않았다. AI 정기 점검도 다시 켜지 않았다.
