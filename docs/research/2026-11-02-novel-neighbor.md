# 시장·팀 예측과 과거 경기의 최근접 이웃 비교

2025년 K리그1의 동일한 227경기에서 새 최근접 이웃 후보는 **96/227 적중(42.29%)**, 시장은 **99/227 적중(43.61%)**이었습니다. 적중률이 올라갔다고 확인하지 못했습니다. 균등 단위 가상 ROI는 후보 −7.95%, 시장 −14.69%였으나, 같은 경기의 주간 블록 재표집 95% 구간은 [-7.69, 21.39]%p로 0을 포함합니다. 이 기간은 이미 반복 열람한 회고 표본이며 실제 수신·거래 가격을 인증하지 못했습니다.

## 후보와 기존 연구

시장과 이미 시간 분리된 DC 팀 모형의 승·무·패 확률을 연결한 6차원 벡터에서 과거 유사 경기를 유클리드 거리로 찾습니다. 각 결과의 이웃 수에 1을 더하고 k+3으로 나눈 단순 확률입니다. 시장과 가중 혼합하거나 팀별 선형 잔차를 학습하지 않습니다. [Cover와 Hart의 원 논문](https://isl.stanford.edu/~cover/papers/transIT/0021cove.pdf)은 최근접 이웃 분류의 근거이며, 여기의 k개 균등 표·가산 평활 및 스포츠 시간 분할은 프로젝트의 별도 설계입니다. 논문의 점근적 이론이 이 자료의 성공을 보장하지 않습니다.

`prior-model-audit.json`은 확인한 범위를 기록합니다. #364는 선형 FORM/시장 offset과 부스팅 트리, #425는 선수·투구 입력과 잔차, #426은 작성자 신뢰도, #430·#453·#455는 시장 조건부 잔차 계열입니다. #433은 동적 베이지안 팀 상태이며, 사용자 메모의 #448은 확인 결과 운영 응답 개선 PR이었습니다. #488은 시장 득점률 기반 Laplace, #490은 득점 베이지안·혼합 전문가·FL-GLM입니다. 이 연구 코드와 저장소 Python 검색 범위에서 근접 이웃 분류 구현은 찾지 못했습니다. 이는 저장소 밖을 포함한 모든 과거 연구에 없었다는 증명은 아닙니다.
