# K리그2 공식 선발: Dixon–Coles 후속 비교

기존 포아송 평가 결과를 이미 확인한 뒤 사용자 요청으로 수행한 후속 진단이다. **블라인드 평가가 아니며**, 이 결과로 포아송과 Dixon–Coles 중 운영 모델을 선택하지 않는다. 두 모델 모두 공식 경기기록상 실제 선발 XI를 경기 전 이미 알고 있다고 가정했다. 명단과 가격은 경기 후 수신해 당시 발표·실제 수신 및 배당 집행 가능성을 인증하지 못했다. 기존 포아송 프로토콜·예측·결과는 변경하지 않았다.

## 설계와 동결

기존 `src/score_dist.py`의 `dixon_coles_tau`와 `scripts/local_dc_incremental.py`의 저득점 공동우도·확률 보정 방식을 확인했고 기존 관련 검사 10개가 통과했다. 기존 팀 극값만으로는 추가 선발 변수의 모든 경우에 tau 양수를 보장하지 못하므로, 이 실험에서는 같은 포아송 팀 설계 행렬에 rho만 추가하고 선발 연속성·최근 세 경기 선발 횟수의 가능한 범위와 미등록 팀의 0 효과까지 포함한 보수적 rho 경계로 확장했다. (0,0), (0,1), (1,0), (1,1)에만 기존 tau를 적용한다. rho는 학습 우도에서 추정하며 평가를 보고 조정하지 않는다.

팀 전력·홈 효과·선발 특징·결측 처리·180일 감쇠·정규화 후보 1/10/100, 90분 정규리그 라벨과 홈/무/원정 argmax 동률 우선순위는 기존 실험과 같다. 2025 정규 273경기를 학습, 2026년 6월까지 120경기를 검증, 7월 이후 128경기를 평가했다. 2025 플레이오프 2건은 90분 결과 확인이 부족해 제외했다. 예측 128건과 가격 127건의 경기 집합은 포아송 비교와 정확히 같다. 선발 외 다른 특징은 추가하지 않았다.

포아송 평가가 알려진 상태임을 명시한 추가 프로토콜을 `d576040ecae5010380abf2df1c433dbf09add13e`에 고정했다. 검증 득점쌍 로그손실로 두 모델 모두 alpha 100을 선택했고 학습+검증 전체로 한 번 재적합했다. 팀 기준 rho는 -0.042172, 선발 후보 rho는 -0.036724다. 정답을 기록하지 않은 평가 예측은 `bfb3c162a2c33936e4edb347ed41c2af0d393b3c`에 먼저 커밋했으며 SHA-256은 `b3e4783a3af9c16fdd04dfe6d37b9a565f765091c4b18b7805cf6ba62e13bf13`이다. 검사한 최소 평가 tau는 각각 0.935524와 0.944691이며 확률합은 1이다.

## 128경기 전체

Dixon–Coles 팀 기준은 57/128 적중 44.53%, 승무패 로그손실 1.075218, Brier 0.649473, 득점쌍 로그손실 2.929109이었다. 선발 후보는 58/128 적중 45.31%, 승무패 로그손실 1.076245, Brier 0.650310, 득점쌍 로그손실 2.931168이었다. 선택 방향은 10경기에서 달랐다. 선발 후보−팀 기준 로그손실 차이의 16개 주 단위 쌍체 bootstrap 95% 구간은 -0.000874~+0.002932다. 선발 변수의 확률 정확도 개선 근거를 확인하지 못했다.

동일 128경기의 기존 포아송 팀 기준은 58/128·로그손실 1.077142·Brier 0.650448, 포아송 선발 후보는 59/128·1.077819·0.651109이었다. 이전 평가가 알려진 뒤 추가 family를 실행한 만큼 어느 family가 더 낫다는 선택 근거로 삼지 않는다.

## 동일 배당 127경기

같은 경기와 공식 가격 입력에서 각 모델의 argmax 방향을 1단위 단폴로 가상 정산했다. 시장의 원배당 역수 확률은 마진을 정규화했다.

- 시장: 62/127 적중 48.82%, ROI -11.54%, 로그손실 1.029665, Brier 0.616739, 일별 종가 최대 낙폭 17.62단위.
- 포아송 팀 기준: 57/127, ROI -17.99%, 로그손실 1.078460, Brier 0.651328, 낙폭 29.81단위. 포아송 선발: 58/127, -16.72%, 1.079259, 0.652084, 낙폭 28.20단위.
- Dixon–Coles 팀 기준: 56/127, ROI -19.54%, 로그손실 1.076430, Brier 0.650289, 낙폭 31.77단위. Dixon–Coles 선발: 57/127, -18.63%, 1.077600, 0.651233, 낙폭 28.20단위.

Dixon–Coles 선발 후보−팀 기준 ROI 차이는 +0.91%p이고 주별 쌍체 bootstrap 95% 구간은 -7.44~+9.13%p다. 선발 후보의 월별 손익은 2026년 7월 -10.44, 8월 -8.72, 9월 -5.96, 10월 +1.27, 11월 +0.19단위다. 모든 방법의 월별 손익·구간·득점쌍 손실은 `experiments/kleague2-dc-lineup-20261103/results/metrics.json`에 있다. 이 수익률은 사후 수신 가격에 대한 연구 계산이며 실제 구매·수익을 뜻하지 않는다.

대상 경기의 선수별 경기 후 골·교체·출장 시간은 특징에 넣지 않았다. 이력은 해당 팀의 이전 날짜 K리그2 선발만 포함하며 K1, 컵, 국가대표 경기는 빠진다. 평가 구간의 이전 경기 없음·최근 세 경기 부족·미등록 팀은 각각 0개 팀-경기 행이지만, 이것이 선수의 전체 활동을 안다는 뜻은 아니다. 현재 서비스의 동결픽이나 9:1 정책을 비교하지 않았다.

## 검증

기존 DC 관련 10개 검사와 새 DC 검사 9개, 기존 포아송 검사 8개가 통과했다. 새 검사에는 양쪽 rho 부호에서 수치 미분과 해석적 기울기 비교, rho=0의 원래 포아송 동등성, 저득점 공동분포를 독립 점수격자로 합산한 확률 검증, 미등록 팀·특징 범위·외부 코호트 거부, 대상·미래 라벨 오염, 예측 동결 Git 바이트와 이전 산출물 해시 보존이 포함된다. 별도 Decimal 장부로 시장을 포함한 다섯 설정의 127경기 손익·최대 낙폭을 검산하고 적중·로그손실·Brier를 독립 계산했다. 운영 모델, 지갑, 월 손실 한도, 추천, 배포와 병합은 변경하지 않았다.
