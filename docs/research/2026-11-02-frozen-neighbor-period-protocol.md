# 고정 보정 후보의 다른 기간 비교 계획

작성 시점: 2026-11-02. 이 문서는 새 기간의 세 후보 성적을 계산하기 전에 고정한다.
이전 연구 PR #499의 head는 `c3312a2211d7e532dfde7bed6fe7f6f23939c9f3`이다.
이번 작업은 로컬 연구이며 운영 모델·배포·DB·일정·모의 월 손실 5만원 원장을 바꾸지 않는다.

## 질문과 고정 대상

2024년 이웃 은행 228경기와 이미 열람한 2025년 평가 227경기를 다시 선정하거나
재평가하지 않는다. 2026년 K리그1 전체 경기 3-way 자료를 우선 조사하고, 과거 연구의
사용 이력을 별도 감사한다. 이번 후보가 평가하지 않은 기간과 프로젝트 전체가 전혀
열람하지 않은 기간은 다르다. 기존 연구에 쓰였으면 독립 맹검이라고 부르지 않는다.
2023년처럼 은행보다 앞선 경기를 미래의 2024년 은행으로 평가하는 역전도 금지한다.

세 후보는 다음으로 고정하며 새 설정 선택·재학습·새 변수·선택률 최적화를 하지 않는다.

1. 시장: 이전 연구와 같은 Shin 방식으로 기록된 홈/무/원정 가격 벡터를 보정한다.
2. 단순 보정: 2024년 은행의 평균 `(정답 one-hot − 시장 확률)`에 60/90을 곱해
   대상 시장 벡터에 더하고, 각 원소를 1e-6 이상으로 자른 뒤 정규화한다.
3. 최근접 이웃 보정: 같은 2024년 은행, 시장+DC 6차원 유클리드 거리, 균등 가중,
   k=60, prior=30. 이전 코드의 ID 순 거리 동률과 홈/무/원정 예측 동률 규칙을 유지한다.

DC 보조 입력은 이전 `src.research_kleague_dc`의 180일 반감기·L2=10 및 고정
rho 제한을 유지한다. 월초 기준 7일 이전까지의 공식 완료 경기만 사용한다. 이는
연구상 결과 가용 시점 가정이지 실제 당시 수신 증명이 아니다. 입력을 못 만들면
시장-only 이웃이나 2025년 결과로 대체하지 않고 부족 사유를 보고한다.

## 자료 자격과 실행 순서

모델 성적보다 먼저 원본 파일 SHA·날짜 범위·이전 사용 기록·팀 식별자·시장 종류·
가격 순서·공식 완료 결과·중복/누락을 감사한다. 가격의 기록 날짜와 실제 수신/체결
시각은 구별한다. 동일 상품 가격과 공식 경기 identity를 연결할 수 없거나 경기
종료 여부가 불확실하면 평가에서 제외하고 사유와 전체 기회 분모를 남긴다.
중간 점수 0:0을 최종 무승부로 취급하지 않는다. 취소/몰수/무효/모호한 경기는
억지 정산하지 않는다. 현재 배당으로 과거 가격을 만들지 않는다.

이 문서 commit 후 자료 준비·예측 코드와 입력 명세를 고정한 commit을 추가로
남긴 뒤 새 기간 성적을 한 번 계산한다. 데이터 준비 시 공식 결과는 연결과 정산에
필요하지만 예측 함수의 대상 입력에는 결과·득점·적중 여부를 전달하지 않는다.
공식 결과 확인이 있어도 과거 가격 실제 수신이나 실거래 가능성을 인증하지 않는다.

## 비교와 판정

모든 자격 경기에서 세 후보를 같은 가격·같은 결과로 계산한다. 선택은 확률 최댓값,
100% 커버리지, 고정 단위금액 단폴이다. 이는 실제 모의 지갑과 별도인 연구 회계다.
적중 수/적중률, ROI/손익, 로그손실/Brier, 월별 손익, 일 마감 최대 낙폭, 시장 및
단순 보정 대비 바뀐 픽과 회복/상실 수를 모두 보고한다. 관측 주 단위 쌍체 bootstrap
5,000회, seed=20261102의 차이 구간을 계산하되 표본 부족과 과거 열람 한계를 표시한다.

평가 구간의 최고값을 새 설정으로 채택하지 않는다. 후보가 시장과 단순 보정 각각에
대해 적중률·ROI 차이 95% 구간의 하한이 0보다 크고 로그손실/Brier도 악화되지
않을 때만 추가 채택 검토 대상으로 기록한다. 이 조건을 통과해도 자동 운영 전환은
없다. 입력 시점과 실제 운영 공통 비교가 부족하면 별도 미검증 상태로 남긴다.
중간 결과가 나빠도 평가 날짜/가격/표본을 성적에 맞춰 바꾸지 않는다.

독립 Python 확률·Decimal 정산 재계산, 대상 라벨/미래 결과 오염, 중복 identity,
잘못된 시장/가격, 학습과 평가 기간 역전 거부를 실제 테스트한다. 자료가 없으면
실제 조사 범위와 부족 파일/필드를 보고하고 가상의 새 ROI를 만들지 않는다.
