# GAP-style 사전 슈팅 예측 추가 검증

## 결론

상대와 홈·원정을 반영한 슈팅 예측을 시장 확률에 추가하자 전체 log loss와 최고확률 2경기 조합의 수익률 점추정은 개선됐다. 그러나 **수익은 여전히 음수이며, 두 대조군 대비 개선의 95% paired CI가 모두 0을 포함한다.** 운영 적용이나 수익 우위 입증으로 해석할 수 없다.

앞선 lagged 결과를 확인한 뒤 설계한 후속 탐색이다. 이미 노출된 D1/SP1 자료를 재사용했으므로 새로운 holdout 검증이 아니다. outer 최고 계열을 고르지 않고, 앞선 실험에서 실제 inner 선택한 2023 `no_surprise:r1.0`, 2024 `shots:r0.1`을 그대로 비교했다.

## 실행과 고정 선택

- 프로토콜만 `c1c875e9`에 먼저 커밋했다. 데이터 로딩 전에 실제 커밋과 현재 프로토콜의 LF 정규화 바이트 일치를 검사했다.
- λ={0.05,0.10,0.20}, φ1=φ2={0.50,0.80}, 결과 분류기 ridge=1 고정. inner 후보 총 12개, 리그별 분류기 적합 28회다. inner log loss로 2023에는 λ=.05/φ=.5, 2024에는 λ=.2/φ=.8을 선택했다. 통계 MSE나 outer ROI로 선택하지 않았다.
- 2019–21 학습→2022 inner→2023 outer, 2019–22 학습→2023 inner→2024 outer. 각 outer 686경기, 총 1,372경기다. 2024 한 경기의 슈팅 통계 결측만 통계 오차에서 제외했다. 경기 결과와 예산에서는 제외하지 않았다.
- 실자료 실행은 1회이며 재튜닝·기술적 재실행은 없었다. 측정한 계산 구간은 2.49초(다운로드·JSON 저장 제외), optimizer 실패 0회다. 새 테스트 13개가 통과했다.
- 원본 12 CSV의 해시·경기 정답·배당을 이전 결과와 대조했다. 결과 JSON에 프로토콜, 코드, 이전 결과 파일의 LF 해시와 모든 inner 시도, 확률, 통계 예측, 베팅 원장을 저장했다. 이전 코드·결과는 수정하지 않았다.

## 통계 예측 자체는 좋아졌는가

아래 값은 `GAP / 학습기간 리그·경기장별 고정 평균` 순이다. 평균 대조군은 각 outer 전 train+inner에서만 계산했다. 평균을 과거 훈련 평점 초기화에 사용하지 않았다.

2023 outer:

- 홈 총슈팅: MAE 4.6281 / 4.1877, MSE 37.3737 / 29.2556.
- 원정 총슈팅: MAE 3.8173 / 3.5929, MSE 23.5147 / 21.3969.
- 홈 유효슈팅: MAE 2.1185 / 2.1052, MSE 7.9254 / 7.4606.
- 원정 유효슈팅: MAE 1.7363 / 1.8111, MSE 4.8320 / 5.1582.

2024 outer:

- 홈 총슈팅: MAE 4.0237 / 4.3145, MSE 26.9164 / 32.1729.
- 원정 총슈팅: MAE 3.5229 / 3.6931, MSE 19.7899 / 22.0406.
- 홈 유효슈팅: MAE 1.9050 / 2.0253, MSE 5.6199 / 6.7270.
- 원정 유효슈팅: MAE 1.7068 / 1.7771, MSE 4.6314 / 4.9108.

2024에는 네 통계 모두 평균 기준보다 낫지만 2023에는 원정 유효슈팅만 낫다. 모든 팀 평점은 0으로 시작하고 새 팀도 0이므로 초기 적응 오차가 남는다. 특히 낮은 λ는 적응이 느리다. 이 영향의 크기를 따로 분해하지 않았으며, 결과를 보고 초기값·평가 대상·격자를 변경하지 않았다. 통계 예측력이 일관되게 확보됐다거나, 실패 원인이 오직 승패 확률 변환에 있다고 결론낼 수 없다.

## 경기 결과와 실제 계산한 2경기 조합

전체 log loss는 GAP **0.956502**, Shin 0.956820, 이전 inner-selected 0.957501이다. GAP−Shin의 95% CI는 [−0.001572,+0.000886], GAP−이전 선택은 [−0.003761,+0.001939]다. GAP Brier는 0.567767, 정확도는 54.5190%다. Brier·정확도는 점추정이다.

2023 LL은 GAP/Shin/이전 선택 순으로 0.944566/0.945030/0.944630, 2024는 0.968438/0.968610/0.970372다. 각 시즌 모두 LL 점추정은 낮아졌지만 그 차이는 작다.

최고확률 정책은 세 모델 모두 482 리그·날짜 중 306장(coverage 63.4855%)을 집행했다. GAP 118장 적중(38.5621%), ROI **−5.7641%**, 전체 예산 수익률 −3.6594%다. Shin은 115장/−8.6633%, 이전 선택은 115장/−8.1873%다. GAP의 ROI 차이 CI는 Shin 대비 **[−0.8139,+7.0263]%p**, 이전 선택 대비 **[−3.7246,+8.5349]%p**다. GAP 자체 ROI CI는 [−21.1008,+9.7382]%다. 2023은 155장/60적중/ROI −9.3528%, 2024는 151장/58적중/−2.0803%다.

다른 고정 정책도 빠짐없이 기록했다:

- p60range: 10장/4적중, coverage 2.0747%, ROI −3.4390%, 예산 수익률 −0.0713%.
- p60low: 88장/48적중, coverage 18.2573%, ROI −1.1453%, 예산 수익률 −0.2091%. 앞선 선택 모델의 +5.0541%보다 낮다. 차이 CI는 [−18.0883,+4.8595]%p다.
- EV≥.02: 1장/0적중, coverage 0.2075%, ROI −100%, 예산 수익률 −0.2075%. 표본 1장으로 일반화할 수 없다.
- EV≥.05: 전부 현금, ROI·적중률 정의 불가, 예산 수익률 0%.

fold별·전체 정책 지표와 두 대조군 대비 CI는 결과 JSON에 있다. 같은 주 단위 paired bootstrap 5,000회, seed=20261001이며 다중 탐색 보정은 없다. 무집행 표본의 ROI는 0으로 바꾸지 않고 null과 유효 반복 수를 표시한다.

## 원문 적용 범위와 사용 제한

[Wheatcroft (2020) 원문](https://arxiv.org/pdf/2001.09097)의 §3 및 부록 식 (7),(8)을 확인했다. 팀별 홈/원정 공격·수비 평점, 상대와의 평균 예측, 오차 기반 갱신을 적용했다. 원문과 달리 대칭 고정 격자, 총슈팅·유효슈팅만 사용하며 통계 공개를 7일 지연한다. ordinal regression 대신 강한 ridge의 multinomial Shin offset을 쓴다. 승강팀 평균 초기화나 시즌 양끝 경기 제외도 하지 않는다. 새 개념 발명이나 논문 전체 재현이 아니다.

원문의 여러 업체 최대배당 쇼핑과 홈/원정 단일 베팅 수익을 고정 B365 H/D/A 2경기 조합이나 Proto로 옮겨 주장하지 않는다. 실제 체결 시각·배당 변화·조합 상관·세금·한도는 검증하지 않았다. 여기의 실제 계산은 공개 역사 데이터의 모의 정산이지 운영 수익 실적이 아니다.

[Football-Data 원 제공자 안내](https://football-data.co.uk/data.php)는 개인 이용을 대상으로 하며 상업적 사용·자동 수집/AI를 이용한 학습 제품 사용을 제한한다. 공개 mirror에서 받을 수 있다는 사실이 그런 사용 허가를 뜻하지 않는다. 운영·상용 적용 전 별도 이용조건과 허가 확인이 필요하다.

재현: `python scripts/local_gap_information.py` 및 `python -m pytest tests/test_local_gap_information.py -q`. 실행은 프로토콜 커밋 객체가 필요하며, squash 후에는 해당 객체를 가져와야 한다. 단위 테스트는 Git 조회를 mock하고 실제 결과물 해시는 파일로 검사한다. 운영 파일 변경·배포·push는 하지 않았다.
