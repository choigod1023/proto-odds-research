# 실제 픽스터 투표 성적과 과거 미정산 복구

## 집계 기준

기준 원장은 운영 DB를 읽기 전용으로 내보낸 9,496행(예측 8,075행, 정산 1,421행)이다. JSONL 원본 SHA-256은 `a5c367a6c8b7c7c9415dded3fad5f7eda7e0cbe06dc8dd8d94308df6e44a50aa`이며 기존 PredictionLedger 검증기로 전체 해시 체인을 확인했다.

경기마다 최신 저장 revision을 먼저 고른 뒤 정책·T-30·선택을 검사한다. 뒤의 보류나 폴백이 있으면 과거의 유리한 투표 revision을 되살리지 않는다. `model.selection_policy == tipster-vote-v1`만 대상으로 하고, 실제 최다표 선택과 `market_fallback_no_votes`를 분리한다. 투표가 적용된 운영 승인 메타데이터·유일 최다표·선택 방향·작성자 수를 대조한다. 정산은 같은 snapshot의 마지막 정산만 연결한다.

## 현재 투표 모델

2026-10-29~11-03 KST 경기 중 실제 투표 최종 선택 14건은 모두 정산돼 있다. 8적중·6미적중, 적중률 57.1429%, 동결 가격으로 매번 1만원 단폴을 가정한 ROI -4.50%, 가상 순손익 -6,300원이다. 축구는 12건 중 7적중(58.33%, ROI -0.1667%), 야구 1건 적중, 농구 1건 미적중으로 종목별 우열을 평가하기에는 작다. 14건의 기존 판정을 공식 베트맨 원문 결과로 다시 계산했고 전부 일치했다.

무투표 시장 폴백은 별도 271건이다. 정산된 190건은 119적중·71미적중(62.63%, ROI +3.2526%), 무효 1건·미정산 80건이다. 이 80건의 예정 시각은 이번 추출 시점보다 미래다. 과거 정책 1,409건의 성적을 현재 투표 모델 성적으로 사용하지 않는다. 두 군은 선택 대상이 달라 이 숫자로 동일 경기에서의 모델 우열을 주장할 수 없다.

ROI는 hit의 당시 동결 배당 수익과 miss의 원금 손실을 합산해 정산된 유효 베팅 원금으로 나눈 값이다. 무효·미정산·보류는 제외한다. 이는 실제 베팅 손익이나 월 한도 모의 계정 실적이 아니며 월 손실 5만원 원장과 거래를 변경하지 않는다.

## 공식 결과 확보

직접 API는 PC 연결 재설정, Fly 연결 타임아웃으로 실패했다. 이를 성공으로 세거나 2차 미러를 공식 발매처라고 표시하지 않았다. 공식 베트맨 공개 마감게임 UI에서 프로토 승부식 101~130회차 링크를 확인하고, 각 선택 회차와 URL을 대조해 렌더링 DOM을 수집했다.

공식 결과표 30개, 상품 행 18,895개다. 원자료는 렌더링 DOM이며 HTTP 응답 원문을 확보했다고 주장하지 않는다. 파일별 URL·수신 시각·바이트 SHA-256 manifest는 `8b7a5f338b4e7ebf9f64ec703b1fd1456606636a3aba51509d5ca424e8cca075`다. 경기 시각은 공식 DOM의 표시 시각과 epoch를 대조했다. 당시 원장에 fixture가 없더라도 경기·선택·offer 해시를 정확히 재현하는 경우에만 exact 방식으로 연결한다.

공식 링크 예시:
- https://www.betman.co.kr/main/mainPage/gamebuy/closedGameSlipIFR.do?gmId=G101&gmTs=260126&isIFR=Y
- https://www.betman.co.kr/main/mainPage/gamebuy/closedGameSlipIFR.do?gmId=G101&gmTs=260128&isIFR=Y

## 복구 계획과 경계

종료 예정 시각이 충분히 지난 미정산 1,324건 중 exact-offer 방식 1,055건, 공식 점수와 동결 조건으로 계산한 방식 189건으로 총 1,244건의 계획을 만들었다. 후자는 원래 상품번호·실제 판매 여부가 검증됐다고 주장하지 않으며 `official_score_with_frozen_terms`로 구분한다. 핸디캡 점수에 이미 반영된 공식 기준점을 먼저 제거한 뒤 원래 기준점을 적용한다. 전반·전체 경기와 점수 단위는 섞지 않으며 공식 점수가 충돌하면 보류한다. 가격·선택·원래 예측은 바꾸지 않는다.

남은 80건은 동일 경기·시장 공식 점수 부재 72, 동결 기준점 누락 5, 배구 점수 단위 불명 2, 동결 선택 불일치 1이다. 원래 예측 입력을 추측해 채우거나 다른 경기/상품 결과를 대입하지 않는다.

승인 계획 raw JSON SHA-256은 `b2cd07ebfad89d16adac970a51827d3b0312f7b1e2a445c1cb2be753facec7fd`다. 운영 적용 전 로컬 원장 사본에서 dry-run 1,244건, 실제 사본 append 1,244건, 재실행 추가 0건을 확인했다. 기존 9,496행의 해시는 전부 보존됐고 최종 사본은 10,740행이다.

운영 적용은 별도의 명시적 1회 명령이다. 원장 잠금 안에서 최신 snapshot과 원래 record_hash를 다시 확인하고, 기존 다른 정산이 있으면 전부 중단한다. 배치 전체를 검증한 뒤 표준 append API만 사용한다. 기본은 dry-run이고 파일 SHA 승인이 필요하다. 운영 메모리 여유 512MiB 미만에서는 적용하지 않는다. 재시작·배포·신규 스케줄이나 실제 지갑 거래를 수행하지 않는다. 이 문서의 수치는 로컬 계획/사본 검증이며 실제 운영 반영은 별도 실행 기록으로 확인해야 한다.

기존 자동 정산이 현재 전달된 발매 회차만 검사하므로 과거 회차 결과가 빠지면 pending이 누적된다. 이 PR은 재현 가능한 정책별 감사와 수동 복구 도구를 제공하며, 과거 회차 네트워크 수집을 운영 스케줄에 자동 추가하지 않는다.
