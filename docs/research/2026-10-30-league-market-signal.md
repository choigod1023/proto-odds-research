아니오. 시장 단독보다 적중률이 통계적으로 개선된 리그·상품·배당 조건을 확인하지 못했습니다. 사전에 정한 앞 두 구간에서 모두 흑자인 두 조건은 뒤 구간에서 모두 적자였습니다. 다중 비교 보정 후 남는 조건은 없습니다.

## 입력과 고정 규칙

PR #421·#422의 2023-01-01~2026-10-30 회고 아카이브 44,396프레임을 사용했습니다. 팀·시각 기반 경기키이며 운영사 독립 경기 ID 인증은 아닙니다. 원래 166,463상품·389,203선택지 중 전체 승패/승무패·핸디캡·언더오버만 포함하고, 경기·상품 가족마다 발매연도→회차→게임번호→상품 ID 순으로 한 상품을 고릅니다. 결과를 보고 상품이나 라인을 선택하지 않습니다. 후보 내에서는 해당 배당 구간의 최저 배당 선택을 택합니다. 같은 상품에서 시장의 최저 배당 선택을 대조군으로 삼습니다.

134개 리그×3상품 가족×6배당 구간 = **2,412후보**를 고정했습니다. 구간은 [1.01,1.5), [1.5,2), [2,3), [3,5), [5,10), [10,∞)입니다. 결과가 없는 빈 후보도 다중 비교 분모에서 빼지 않았습니다. 보류 없이 모든 후보를 실제 적용한 적중률·수익률·커버리지를 `results/results.json`의 cells에 보존했습니다.

연구 프로토콜 선행 커밋은 `a71e6648`입니다. 고유 KST 날짜 순 앞 1/3 학습(2023-01-01~2024-02-20), 다음 1/3 검증(2024-02-21~2025-05-23), 뒤 1/3 평가(2025-05-24~2026-10-30)입니다. 앞 두 구간 합이 요청한 앞 2/3입니다. 학습 비환불 30건 이상·검증 15건 이상, 두 구간에서 각각 양의 ROI인 조건만 선택합니다. 평가 결과로 조건을 바꾸지 않았습니다. 단위 1의 균등 단폴이며 운영 월 손실 한도·지갑은 바꾸지 않습니다.

**이미 살펴본 정산 완료 자료를 다시 사용한 회고 연구입니다.** 당시 가격 수신·구매 가능성·최종 배당이 아닌지 인증할 수 없습니다. availability_at=T−24h는 원 자료의 가정일 뿐 실제 수신으로 쓰지 않습니다. 인증된 사전 가격은 0건이며, 결과를 입력으로 쓰지 않았다는 코드 검사와 원천의 사전성 인증은 다릅니다. 전반·홀짝·승①패·승⑤패를 일반 승패로 섞지 않습니다.

| 라리가 HC [3, 5] | 480 / 5.16% | 445 / 6.87% | 447 / 96.96% | 25.28% / -13.74% | -26.62% [-33.11, -20.41]%p | -1.01% [-17.27, 15.02]%p |
| 잉글FA컵 ML [3, 5] | 47 / 7.77% | 46 / 1.52% | 32 / 84.21% | 25.00% / -14.22% | -25.00% [-47.37, -8.00]%p | 7.66% [-46.25, 48.31]%p |

커버리지는 해당 리그·상품 가족·기간의 비교 가능한 전체 상품 중 픽이 가능한 비율입니다. 적중률 분모에서 환불은 빼고 ROI 투입 분모에는 넣습니다. 동일 경기의 여러 후보를 독립 경기로 더하지 않습니다. 총 130,722개 정규 상품에서 후보별 215,782개 예측 행을 만들었으며, 이는 215,782개 독립 경기나 실제 구매 기록이 아닙니다.

각 후보의 평가 ROI>0, 같은 상품 시장 대비 적중률>0, 시장 대비 ROI>0의 단측 검정을 모두 보존했습니다. 전체 7,236가설에 사전에 이름을 지정한 KBL 예외의 3가설을 더해 7,239가설을 함께 BH-FDR 보정했습니다. 두 선택 조건은 q=1입니다. 주간 블록 부트스트랩 2,000회, 주간 부호 무작위화 9,999회를 사용했습니다. 같은 주에는 모든 경기·선택에 같은 부호를 적용하므로 중복 선택의 독립성을 가정하지 않습니다. 적어도 8주를 요구하며, 작은 표본은 p=1로 둡니다. 부호 검정은 주간 점수의 영가설 대칭성을 가정하는 근사 추론으로, 무작위로 베팅한 실험의 정확 검정은 아닙니다. 주간 블록 간 독립도 완전히 보증할 수 없습니다. 95% 구간은 개별 기술 구간이며 최종 판단은 전체 FDR 보정값으로 합니다.

## KBL 5~10배 예외의 출처 구분

원 자료를 감사하니 일반 승패는 17선택·ROI −29.12%, 기존 양수 예외는 **승⑤패 195선택·ROI +4.31%**였습니다. 승⑤패는 점수 차 구간에 베팅하는 별도 3방향 시장이므로 일반 승패로 바꾸어 보고하면 안 됩니다. 주 프로토콜의 일반 승패 범위로 이 예외를 검증했다고 주장하지 않습니다.

주 분석 결과를 본 뒤 이 범위 오류를 발견해, 사용자 요청에 이미 이름이 있던 예외만 별도 문서로 고정했습니다. `471965a8`은 이 특수 시장의 기간별 평가 **전** 커밋입니다. 원 주 분석을 수정하거나 새 구간을 탐색하지 않았습니다. 다만 엄격한 의미의 한 번에 완성된 사전 등록이 아니므로 이 추가 진단을 독립적인 확증 검증으로 해석하지 않습니다. 이 제약 자체도 운영 채택을 막습니다.

## 9:1 비교와 새 기간의 실제 한계

아카이브에는 실제 작성자 투표가 없어 9:1 확률을 만들어낼 수 없습니다. 시장값을 복제해 9:1이라고 부르지 않았습니다. 별도 PR #402의 strict 원장 492공통 경기와 원래 Shin 시장·실제 투표 9:1을 동결 입력으로 보존했습니다. 선택된 리그·배당 조건과 겹치는 실제 픽스터 경기는 **0건**입니다. 따라서 이 정책의 9:1 대비 쌍체 차이·구간은 **미산정**이며, 비교를 완료한 것처럼 표시하지 않습니다. 주제 B/D/E가 실제 투표가 있는 비교를 담당합니다.

PR #425의 7,401개 확장 케이스도 대조했습니다. 아카이브 종료일 2026-10-30 이후 케이스는 **0건**입니다. 이전에 새로 수집했다는 이유로 아카이브와 겹치는 과거 경기를 추가 기간이라고 다시 세지 않았습니다. 독립된 새 기간 평가는 아직 실행할 자료가 없습니다. 이 연구는 앞/뒤 기간 회고 검증까지이며, 새로운 미노출 기간 검증까지 끝났다고 주장하지 않습니다.

## 리그별 필요 표본

유의수준 5% 양측·검정력 80%의 정규근사입니다. 동일 경기의 두 모델을 비교하는 쌍체 설계에서 정확도 차이 D∈{−1,0,1}, 불일치율 q라 두면 n=ceil((z.975√q+z.8√(q−δ²))²/δ²)입니다. q=0.2일 때 +3%p는 1,742경기, +5%p는 626경기이고 q=0.5일 때 각각 4,359/1,568경기입니다. 리그별 불일치율을 모르는 상태에서 최소 경기 수를 단정할 수 없습니다. 아래 독립 두 군의 각 군 표본은 관측 시장 적중률을 기준으로 한 별도 계획값이며 쌍체 표본과 합산하지 않습니다. 다중 검정·주간 상관·결측·시즌 변화는 필요한 수를 더 늘릴 수 있습니다.
