# 점수 기반 모델 토너먼트: 탐색적 회고 실험

이번 고정 후보군에서 Elo·공격/수비 Poisson을 추가해 Shin보다 나은 예측을
얻었다는 근거는 없었다. 2023/24 outer에서 inner가 선택한 두 혼합 모델 모두
log loss가 나빠졌고, 2024/25를 위한 inner 선택은 두 계열 모두 시장 비중
100%였다. 이 결과를 본 뒤 후보·혼합 비중·정책을 다시 고르지 않았다.

이미 이전 연구에 노출된 데이터이므로 새 holdout이 아니다. 아래 수익은
해외 B365 기록 배당을 사용한 가상 정산이며 실제 Proto 수익률이 아니다.
운영 모델·추천·배당·원장은 변경하지 않았다.

## 비교 방법과 실제 적합 수

Fold A는 2019–21 시즌 시작 연도를 학습(2,058경기), 2022를 inner(686경기),
2023을 outer(686경기)로 썼다. 선택 후 2019–22의 2,744경기로 재적합했다.
Fold B는 2019–22를 학습(2,744경기), 2023을 inner(686경기), 2024를
outer(686경기)로 썼으며 2019–23의 3,430경기로 재적합했다.

결과 기반 Elo 상태는 예측일보다 최소 7일 이전에 열린 경기만 반영한다.
같은 날짜의 상태 업데이트는 묶어서 처리한다. 평가 중에도 7일 이상 지난
실제 결과는 Elo 상태에 추가되지만 회귀계수는 바뀌지 않는다. Poisson의
팀 효과는 각 fold의 재적합 후 고정한다. 학습 마지막 날짜도 첫 평가일보다
최소 7일 이전으로 제한한다. 리그 간 팀 이름은 섞지 않으며 처음 등장한
팀은 미래 결과가 아닌 학습 리그의 중립 효과를 받는다.

Elo는 K=20/40 × ridge=1/10, Poisson은 ridge=1/10이다. 각 구성에 시장
비중 0/.25/.5/.75/1을 적용했다. 30개 ID × 2개 inner = **60회 후보 평가**이며
시장 비중 1의 중복 후보도 이 수에 포함한다. 기본 구성의 리그별 inner 적합
24회, 계열별 선택 구성 재적합 8회로 실제 적합은 **32회**다. 전체 선택이
계열별 선택과 같으면 기존 재적합을 재사용했다. 모든 적합이 수렴했고
Poisson 평가 평균 득점의 수치 clipping은 0건이었다.

## 예측 결과

낮은 log loss/Brier가 좋다. `시장 .75`는 점수 모델 .25 + Shin .75이다.
outer 수치는 비교 보고용이며 이를 기준으로 승자를 다시 선택하지 않았다.

| Outer 시즌 | Inner에서 선택한 구성 | Log loss | Brier | 정확도 |
| --- | --- | ---: | ---: | ---: |
| 2023/24 | Shin | .945030 | .560573 | 54.81% |
| 2023/24 | Elo K20/ridge10, 시장 .75 | .950656 | .563999 | 54.52% |
| 2023/24 | Poisson ridge10, 시장 .75 | .953393 | .565482 | 53.94% |
| 2024/25 | Shin 및 두 계열 선택 모두 시장 1 | .968610 | .575475 | 53.21% |

Fold A의 전체 inner 선택은 Poisson ridge10/시장 .75(inner log loss
.984576)였다. Fold B의 전체 선택 ID는 Elo K20/ridge10/시장 1이었다.
이는 순수 Shin과 같은 확률이며 Elo의 우위를 뜻하지 않는다. 같은 log loss인
후보들 사이에서 미리 정한 ID 순서로 선택했다.

ISO 주 단위 paired bootstrap 5,000회, seed 20261001의 outer log loss 차이
(모델−Shin) 95% CI는 Fold A Elo `[.001556, .009477]`, Poisson
`[.003996, .012584]`였다. 이번 비교에서는 모두 손실이 증가한 방향이다.
Fold B 차이는 정확히 0이다. 이 CI는 다중 후보 탐색·기존 데이터 노출을
교정하지 않은 설명용 구간이다.

## 고정 정책별 가상 수익

각 리그/날짜 예산은 1이다. 서로 다른 경기의 두 선택으로 만든 티켓을 최대
하나만 사며, 두 경기를 채울 수 없으면 현금을 유지한다. 단식이나 다른
리그/날짜 조합은 없다. 모든 H/D/A와 1.5 미만 배당을 후보에 포함한다.

`highestprob`는 EV 하한 없이 확률 곱을 최대화한다. `p60range`는 각 선택이
p≥.60이고 1.5≤배당<2.2, `p60low`는 p≥.60이고 배당<2.2이다. `ev02`와
`ev05`는 각 선택 EV≥.02/.05이며 티켓 EV 순으로 고른다. `p60range`는
역사적 정책 비교용이다. 현재 운영 코드의 1.5 선호·저배당 폴백·비인기 방향
제외 등 전체 정책을 재현한 결과가 아니다.

2023/24는 리그/날짜 예산 242개다. ROI는 사용한 stake 대비 수익, 예산수익은

## 모델의 근거와 한계

[Maher (1982)](https://doi.org/10.1111/j.1467-9574.1982.tb00782.x)는 팀의
공격·수비 강도를 반영한 독립 Poisson이 득점 분포를 비교적 잘 설명하지만
체계적인 잔차 차이가 남는다고 보고했다. 이번 계열은 그 구조를 L2 축소와
정적 효과로 단순하게 구현한 것이다. 팀 효과는 합이 0이 되도록 식별하며,
신규 팀 효과는 0, 리그 절편과 홈 효과는 학습에서 추정한다.

[Dixon–Coles (1997)](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/1467-9876.00065)의
완전한 제약 우도·저득점 상관 보정은 구현하지 않았다. 0–0/1–0/0–1/1–1
같은 셀의 독립성 오차, 팀 전력 변화와 시간 감쇠 부재는 남는다. 결과를
확인하고 임의 무승부 배수를 추가하지 않았다. 이번 제외는 성능 비교로
DC가 불필요하다고 판정한 것이 아니라 사전 구현 범위의 한계다.

[Hvattum–Arntzen (2010)](https://www.sciencedirect.com/science/article/pii/S0169207009001708)은
Elo 기반 결과 예측의 연구 출처다. 본문 접근 제한 때문에 저자의 정확한
알고리즘을 재현했다고 주장하지 않는다. 이번 방법은 고정 Elo 상태에
L2 multinomial HDA 회귀를 결합한 별도 단순 모델이다. 확률 수준의 선형
시장 혼합도 Bayesian scoring-rate 혼합과 동일한 방법이 아니다.

검증 데이터의 B365 배당이 실제 결정 시점에 가용했다는 보장이 없고,
체결 변화·세금·수수료·취소·배당 반올림·티켓 내 의존성을 모델링하지
않았다. 주 단위 bootstrap은 장기 전력 변화나 데이터 재사용의 모든
불확실성을 다루지 않는다. Fold A outer는 이후 Fold B inner로 재사용되어
두 개의 독립적인 새 검증으로 해석할 수 없다. 운영 수익이나 이익 보장은
이 실험의 결론이 아니다.

## 검증

관련 단위 테스트 11개 통과. 확률 정규화, 미래/동일 날짜/6일 이내 결과
변경 불변성, 정확히 7일 이전 업데이트 허용, 리그 분리와 신규 팀 사전값,
엄격한 배당 상한, 서로 다른 두 경기와 예산·원장 정합성, 배당 누락 날짜의
현금 보존, 학습 날짜 경계, 프로토콜 바이트 고정, bootstrap 재현성을
확인했다. 실제 실행의 source 12개·60개 trial·32개 적합은 결과 JSON에서
검사할 수 있다. 다른 에이전트 소유 파일은 수정하지 않았다.
