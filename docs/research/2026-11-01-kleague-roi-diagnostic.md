# K리그 시간가중 점수 모델의 실제 예비 성적

이번 고정 후보는 채택하지 않는다. 같은 2025년 227경기에서 시장 최고확률 선택보다 적중률·ROI·log loss·Brier·최대 낙폭이 모두 나빴다. 차이의 신뢰구간은 0을 포함하므로 통계적으로 열등하다고 확정하지도 않는다. 확인된 것은 교체를 정당화할 개선 근거가 없다는 점이다.

## 실제 계산 결과

모든 적격 경기에서 단폴 1단위씩, 같은 세 배당과 같은 공식 승무패 결과로 정산했다. 확률·배당·EV 필터나 월 손실 중단을 연구 계산에 추가하지 않았다. 운영 모의 원장의 월 손실 5만원 한도는 변경하지 않았다. 가격은 과거 수신·실제 구매 가능성이 미확인인 보관 배당이므로 실제 벌거나 잃은 돈이 아니다.

- **시장 기준(Shin 마진 보정 후 최고확률)**: 227건 중 99건 적중, 적중률 **43.61%**, 순손익 **−33.34단위**, ROI **−14.69%**. Log loss 1.06766, Brier 0.64598, 일별 마감 기준 최대 낙폭 37.99단위.
- **시간가중 Dixon–Coles 후보**: 227건 중 94건 적중, 적중률 **41.41%**, 순손익 **−34.43단위**, ROI **−15.17%**. Log loss 1.07510, Brier 0.65015, 최대 낙폭 40.55단위.
- 후보는 선택을 **54경기** 바꿨다. 시장보다 적중 5건 감소, 손익 −1.09단위, 적중률 −2.20%p, ROI −0.48%p였다. 두 모델 모두 동률 보류 없이 227건을 선택했으므로 이번에는 경기당 손익 차이와 거래당 ROI 차이의 분모가 같다.

관측된 37개 경기 주를 짝지어 10,000회 재추출한 후보−시장 차이의 탐색적 95% 구간은 ROI **−12.56~+12.29%p**, 적중률 **−7.17~+2.91%p**다. 시장 대비 log-loss 개선 구간도 −0.02419~+0.01085로 0을 포함한다. 관측 주 블록에 조건부인 구간이며 표본 선택·미검증 가격 시각·과거 반복 열람 문제를 해결하지 않는다.

월별 플러스인 달은 시장 2/10개월, 후보 4/10개월이었다. 후보의 수익 월이 더 많아도 누적 손익과 최대 낙폭은 더 나빴다. 유리한 지표 하나만 골라 수익 안정성이 개선됐다고 보고하지 않는다. 월별 원수치는 `results.json`에 모두 보존했다.

## 무엇을 계산했는가

학습용으로 공식 K리그 조회 응답 24개에서 2023·2024년 정규 시즌 **456경기**를 새로 확보했다. 각 연도 228경기이며 승강 플레이오프 8행은 제외했다. 현재 읽은 공식 사후 결과로, 당시 수신 영수증은 아니다. 공식 2025년 228경기도 이력에 포함하되 해당 평가월 월초−7일 이전 결과만 사용했다. 가격이 없는 공식 2025년 한 경기 역시 그 날짜 이후의 학습 이력에는 남겨, 배당 없는 경기 결과를 전력 이력에서 임의로 삭제하지 않았다.

평가 기간은 **2025-02-15~2025-11-30**, 보관된 국내 전체 경기 승무패 시장과 공식 경기 ID를 유일하게 연결한 227경기다. 국내 원본 SHA `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`, 정규화 입력 SHA `4bf3abf8bb82838ee72975e1ef486a471b357a03ee4d8627808780f046dae51a`를 확인했다. 각 경기 원본 배당 세 개와 정규화 배당도 Decimal로 일치시켰다. 공식 날짜·점수·결과, 취소 여부와 최종 평가 ID 집합을 검사했다.

후보는 팀별 공격·수비 전력, 홈 이점, 저득점 상관계수 rho를 매월 과거 자료로만 적합한 점수 분포다. 가중치는 반감기 180일, 고정 L2=10이고 팀 효과는 평균 0으로 식별한다. 새 승격팀은 학습에서 관측되기 전까지 팀 효과 0을 사용했으며 해당 평가 경기는 2건이었다. Poisson 평균은 0.05~6, rho는 −0.15~0.025로 사전 고정해 저득점 확률이 음수가 되지 않게 했다. 그리드는 0~30골, 확률 누락 질량 1e-10 초과 시 중단한다. 10개 월별 적합 중 rho가 상한에 도달한 달은 6개다. 이 제약이 최선이라고 검증한 것이 아니며, 결과를 보고 범위를 바꾸어 다시 좋은 숫자를 고르지 않았다.

시간가중과 저득점 보정의 문헌 근거는 [Dixon–Coles 원 논문](https://ajbuckeconbikesail.net/wkpapers/Airports/MVPoisson/soccer_betting.pdf)이다. 논문의 영국 리그 결과가 K리그 수익성을 입증하는 것은 아니다.

사전 규칙·모델 코드를 `d3017de1`/`6b57dc1e`, 입력 해시를 `274dc11d`에 저장했다. 경로 정규화와 Git 고정 검사를 보완한 **`881e9ff9b57ffec4b6740849ffba5e28d6f23a4d` 이후 처음 모델을 적합**했다. 그 커밋의 프로토콜·입력 해시·모델 코드와 현재 실행 내용을 대조한다. 후보나 선택 규칙 탐색은 0회다.

## 나빠진 이유로 확인한 사실과 아직 가설인 것

후보가 선택한 배당 평균은 2.14로 시장의 1.99보다 높았지만, 적중률 감소를 상쇄하지 못했다. 적중한 경기의 평균 배당도 시장 1.9562, 후보 2.0486이었다. 결과적으로 각각 `99×1.9562−227≈−33.34`, `94×2.0486−227≈−34.43`단위가 됐다. 높은 배당 선택 자체가 우위는 아니었다.

후보는 홈을 168번, 시장은 152번 선택했다. 실제 결과는 홈승 94·무승부 60·원정승 73이었다. 후보는 최근 점수 이력만 쓰며 선발·결장·로테이션·당시 픽스터 입력을 사용하지 않았다. 시장에 이미 반영된 정보를 팀 점수 모델이 충분히 따라가지 못했을 가능성이 있지만, 어느 누락 변수가 손실의 원인인지는 이번 계산으로 분리하지 못했다. 평균 배당 역수 합은 1.14595여서 가격 마진 부담도 존재한다. 이 값을 그대로 예상 손실률이라고 해석하지 않는다.

## 여기서 해야 할 일

1. **이 고정 후보를 운영으로 교체하지 않는다.** 시장 기준도 이 표본에서 손실이므로 시장 최고확률 선택을 수익 전략으로 새로 승인하지 않는다. 기존 운영 정책의 우열 역시 이번 비교에서 확인하지 않았다.
2. 다음 후보는 시장확률을 버리는 대신 과거 팀 전력·새 정보가 시장에 더하는 잔차만 작게 보정하는 방식으로 가설을 하나 고정한다. K리그 선발·결장·일정 부담, KBO 확정 선발·타순·불펜 등 실제로 사전에 확보한 변수를 사용한다. 현재 결과가 나쁘다는 이유로 같은 2025년에 비중·EV·역배 가산점을 계속 탐색해 최댓값을 채택하지 않는다.
3. 별도 기간을 먼저 정하고 그 기간의 공식 경기·동일 상품 배당·입력 시점 증거를 확보한다. 동일 경기 전체의 확률 점수와 선택 적중률·ROI·보류율·월별 손익·낙폭을 함께 비교한다. 2025년은 이미 여러 연구에서 열람한 자료이므로 이번 결과는 손대지 않은 검증 구간의 성과가 아니다.
4. 픽스터 투표/9:1은 당시 적격 픽스터 입력을 연결한 뒤 별도 기준선으로 비교한다. 보관 원장의 옛 모델이나 `투표 자료 미확인`을 `실제 투표 0명`으로 바꾸어 채우지 않는다. KBO 선수 모델도 사전 자료 교집합 0건 상태에서 ROI를 만들어내지 않는다.

## 검증과 한계

모델 분석 기울기와 수치 미분, Poisson 차이의 별도 Skellam CDF, 저득점 보정의 비음수·확률합·평균, 미래 라벨 변조, 동결 입력과 종료 상태를 검사했다. 독립 검토가 지적한 평가 집합 축소·비종료 학습 행을 차단하는 회귀 검사도 추가했다. Git 사전 동결 검사는 첫 적합 전에 이미 들어갔으며 이후 고정 사전 커밋을 직접 지정하도록 강화했다. 실제 자료는 모두 이 검사를 통과해 성적은 그대로다.

독립 검토에서 초기 검증기가 DC 확률만 독립 재생하면서 시장까지 포함한 454개를 같은 범위로 표현한 점을 지적했다. 시장의 Shin 방정식도 별도 유리화 표현과 이분법으로 풀도록 추가하고, 선택·정산을 그대로 두고 시장 확률만 변조하는 회귀 검사도 넣었다. 최종 재생기는 모델/실행기 함수를 가져오지 않고 **454개 확률과 Decimal 정산**을 검사한다. DC 확률은 Poisson 재귀식으로 재생해 최대 차이 6.67e-16 미만, 시장 확률은 3.25e-13 미만이다. 관련 검사 18개가 통과했다. 이 보강으로 성적이나 모델은 바뀌지 않았다.

이 계산은 #483 정식 검증의 최소 평가 300경기·가격/선수 수신·독립 기간 조건을 통과하지 못한다. 그 프로토콜을 소급 완화하지 않고 별도 예비 진단으로 남겼다. 월초−7일은 사후 결과의 과거 가용성을 가정한 보수적 규칙이며 실제 당시 수신을 인증하지 않는다. 확정 선수·픽스터·현재 운영 동결픽·실제 구매 가능 가격은 사용/검증하지 않았다. 따라서 기존 서비스 모델보다 좋거나 나쁘다는 직접 비교, 실제 실현 수익, 미래 수익률 보장은 하지 않는다.

## 재현

```powershell
python experiments/kleague-roi-diagnostic-20261101/run.py --raw <games.csv.tmp> --training experiments/kleague-roi-diagnostic-20261101/training/fixtures.jsonl
python experiments/kleague-roi-diagnostic-20261101/verify.py
python -m pytest tests/test_research_kleague_dc.py tests/test_kleague_roi_diagnostic.py tests/test_kleague_training_capture.py -q
```

고정 Git 커밋을 포함한 이력이 필요하다. `input-hashes.json`, `protocol.json`, `training/manifest.json`, 경기별 `ledger.jsonl`, 월별 `states.json`, `results.json`, `verification.json`이 실행 근거다. 운영 코드·DB·지갑·스케줄·배포·실제 베팅은 변경하지 않았다.

전체 Python 검사는 2,241개 통과·6개 건너뜀·93 subtests였다(195.39초). 이후 시장 독립 재생과 고정 기준선 코드 검사 보강을 포함한 최종 관련 18개도 통과했다. 최종 커밋 전체 검사는 CI로 별도 확인한다.
