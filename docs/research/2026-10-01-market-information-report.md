# B365 외부 북메이커 정보 증분 검증

B365와 다른 북메이커의 비마감 가격을 실제 추가해 비교했다. D1/SP1에서는 평균 consensus의 확률오차가 커졌고, E0/I1/F1에서는 소폭 줄었으나 95% 구간이 0을 포함했다. 같은 선택 정책에서 일관된 수익 개선은 확인하지 못했다. 이는 이 고정 원천·기간·방법에 대한 결과이며 다른 정보원 전체가 무용하다는 결론은 아니다.

## 고정 범위와 재현

프로토콜 커밋 `8427619c`, 의존 기준 `ec96bf37`(PR258), 브랜치 `codex/new-information-validation-20261001`. 결과 평가 전에 [프로토콜](2026-10-01-market-information-protocol.md)을 커밋했다. 4확률원천 × 5기존 정책 = **20설정**, 2 folds의 inner/core outer/external outer = **실행당120개 평가**다. 최초 실행4.7311초 이후 감사용 해시·예측값·정산 원천 저장을 보완해 기술적 재실행을2회 수행했다(4.4552초, 최종 **3.8136초**, 다운로드 포함). 설정을 추가하거나 결과로 재선택하지 않았고 winner와 주요 지표는 동일했다. Python3.14.3/NumPy2.5.1, 유료 연산 없음. NumPy import 전에 OPENBLAS_NUM_THREADS/OMP_NUM_THREADS/MKL_NUM_THREADS를1로 설정한 실제 환경값을 저장했다. 네이티브 연산 풀의 실효 스레드 수는 측정하지 않았다.

```powershell
python -B scripts/local_market_information.py --audit
python -B -m unittest tests.test_local_market_information -v
python -B scripts/local_market_information.py --output docs/research/2026-10-01-market-information-results.json
```

원천은 [고정 미러 revision e82cf591](https://github.com/sosthene14/footballdataset/tree/e82cf59161e82e0fbcdc49ad02819e45c821a5c8/datasets)의 18파일/6,248경기다. D1/SP1 2019/20~2024/25 4,116경기와 E0/I1/F1 2023/24~2024/25 2,132경기다. D1/SP1뿐 아니라 외부 세 리그도 이전 연구에서 노출된 자료이므로 **새로운 독립 holdout이 아닌 후향 탐색·리그 간 적용 점검**이다. E0/I1/F1 결과는 이번 설정 선택에는 쓰지 않았다.

`--audit`는 outcome을 추출하지 않고 헤더·가격 유효성만 검사한다. 처음 5개 북메이커 집합에서 2024/25 결측 증가를 확인하고, 결과를 보지 않은 상태에서 BF/1XB를 포함한 최종 whitelist를 고정했다. 비마감 BW/IW/PS/WH/VC/BF/1XB의 가용 H/D/A만 사용한다. **B365·closing 열·BFE(exchange)·Avg·Max는 consensus에서 제외**했다. 다른 북메이커의 최대 가격을 구매 가격으로 사용하지 않았다.

공통 표본은 B365+PS 가격과 외부3개 이상을 요구하며 파일별95% 이상이어야 진행한다. 전체 공통6,244/6,248: SP1 2019/20 PS누락2, 2021/22 PS누락1, F1 2024/25 외부3개 미달1을 제외했다. 모든 파일 커버리지는99.47~100%. outer는 D1/SP1 **1,372/1,372**, external **2,131/2,132**다. 결측을 B365 확률로 대체하지 않았고, 제외 경기의 원래 날짜 예산도 보존했다. 전체 B365만 기준선도 따로 저장했으며 이번 outer 최고확률 정책 결과는 공통 표본 기준선과 같았다. 원천 구성은 시즌마다 달라진다.

## 방법과 공정 비교

모델은 B365 Shin 기준, 외부 Shin 확률 산술평균, 외부 중앙값 후 정규화, PS 단독 Shin의4개다. 새 정보는 다른 북메이커 가격이며 같은 B365 확률을 다시 보정한 실험이 아니다. 가중치·계수 학습은 없다. 2019~21은 원천 감사 자료이며 결과 기반 모델 학습에 사용하지 않았다.

기존 `local_score_model_tournament.py`의 highestprob/p60range/p60low/ev02/ev05 선택·정산·bootstrap을 명시적으로 재사용했다. 모든 평가·정산 가격은 **B365H/D/A**다. highestprob에는 저배당(<1.5)을 허용하고 EV 바닥이 없다. p60range는 과거60%구간 대리 기준이며 현재 운영정책이 아니다. 리그-날짜 예산1단위, 서로 다른 경기 두폴 최대1개, 불충족 시 현금이다.

2022/23 D1/SP1 inner로2023/24를, 2023/24 inner로2024/25를 평가했다. inner probability winner는 log loss 최소, policy winner는20조합 이상 중 예산당 순손익 최대다. 선택 ID를 먼저 고정한 뒤 같은 해 core/external outer에 적용했고 날짜 경계가 엄격히 분리됨을 검사했다.

- fold23: 확률 winner PS, 정책 winner B365/highestprob. inner 정책154조합, 예산당−0.0350%.
- fold24: 확률 winner B365, 정책 winner consensus_median/p60low. inner 정책40조합, 예산당+3.8693%.

## 문헌·원천·해석 한계

[Kaunitz et al.2017](https://arxiv.org/abs/1710.02824)은 시장 가격에 포함된 확률 정보를 이용한 mispricing 탐색을 다룬다. 초록의 장기 closing 시뮬레이션과 고빈도/실제 베팅 실험은 이번 비마감 CSV와 조건이 다르다. [2010 다중 북메이커 예측 연구](https://www.sciencedirect.com/science/article/pii/S0169207009001733)는 제목·초록 검색정보를 참고했고 발행처 원문은403으로 읽지 못했다. 문헌은 시험할 방법의 근거이지 이번 수익의 보장이 아니다.

주 담당자가 확인한 [Football-Data 공식 설명](https://football-data.co.uk/data.php)은 첫 가격 집합과 C표시 closing 가격을 구분한다. 이번에는 non-C 열만 썼지만 정확한 관측시각·여러 원천의 동시성·그 시점 B365 구매 가능성은 증명하지 못한다. 공식 페이지의 2025-07-23 이후 Pinnacle API 지연 경고보다 이번 평가 종료일2025-05-25가 앞서더라도 현재 실시간 활용의 신뢰성을 보장하지 않는다. 해당 페이지의 개인 이용 및 상업·자동화/AI 데이터 이용 제한도 확인돼 있으므로 **운영 자동 feed나 모델 제품에 사용하기 전 사용권을 해결해야 한다**. 이번에 운영을 연결하거나 배포하지 않았다.

여러 원천이 같은 정보·가격을 공유할 수 있고 계열사/확률오차 독립성을 검증하지 않았다. 두폴 확률 곱은 가정이며 주 bootstrap으로 독립성이 증명되지 않는다. 20설정, 반복 노출 자료와 과거 가설 탐색까지 보정한 유의성 검증이나 White Reality Check는 아니다. 실제 Proto 구매가격·세금·체결 기록이 없으므로 모든 ROI는 B365 원가격의 가상 정산이다.

## 검증·인계

합성 회귀7개를 통과한 뒤 최초 평가했다. 최종 테스트는 **10개 통과**다. target/closing/Avg/Max 변경에도 consensus 불변, 외부 가격 변경 반영, 결과 없는 예측,95%/3원천/PS 결측, 시간 경계, parser 중복 거부, B365 정산·cash·distinct games를 확인했다. Git 이력 없이 코드·의존성·프로토콜 해시를 검사하며, LF/CRLF 동등성을 시험한다. 모든 주요 원장의 leg y·가격·날짜·리그를 별도 settlement_rows와 대조해 승패와 Decimal 정산을 재계산한다. 공통 표본에서 제외한 F1 경기까지 settlement_rows에 포함했다. 저장 확률로 pooled 확률·단일픽 지표, 원장으로 pooled 정책 요약을 재계산한다. 부동소수점은 절대오차1e-12, 건수와 해시는 정확히 비교한다. 전체 운영 테스트는 실행하지 않았다. 주 담당자의 별도 감사에서도 최초120개 요약과5,920개 원장 행을 pinned 원천에 대조했다.

최종 스크립트 LF정규화 SHA256 `bce75817cec48808e23f5b59553209d0f92d619e8a5ff9c5b4f533ae8809babc`, 프로토콜 해시 `78c92694b5b625e55f809ee2b31aeee9cd8bbda02dd886ff703b91669e07a23f`. 코드·의존성·프로토콜은 CRLF→LF 바이트 정규화, 의존성 키는 POSIX 상대경로다. 원천 CSV 해시는 변환하지 않은 원시 바이트 기준을 유지한다. JSON에는18원천 URL/해시/헤더/결측수,120평가 요약, inner선택, 주요정책 날짜별 기록과 CI, outer 경기별4모델 확률·B365가격·y, 전체 outer 정산용 경기 자료가 있다. 결과 확인 뒤 바꾼 것은 감사용 저장·해시 및 회귀검사뿐이며 모델·정책·분할은 변경하지 않았다. 소유 파일만 수정했고 최종 커밋/push/PR은 주 담당자에게 남겼다. 운영·DB·운영수집·배포 작업 없음.
