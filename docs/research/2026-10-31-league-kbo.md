## 확인한 자료 범위와 수량

이번에 직접 검사한 범위는 main의 `experiments/baseball-candidate-bridge-20261029/official-kbo-{20261028,20261029}.json` 및 메타데이터 두 쌍이다. 28일 0경기, 29일 1경기, 합계 KBO 경기 기회 1건이다. **시장 종류 미연결**이며 모든 KBO 시장 또는 운영 원장 전체에 대한 집계가 아니다. 이 1건에서 경기 전 실제 수신 입증 0, 같은 상품의 사전 가격 연결 0, 공식 결과 1, 경기 전 공식 확정 선수·타순 연결 0, 24/48시간 불펜 이력 연결 0, 동결 운영픽 연결 0이다. 따라서 이 범위에서 비교 적격 n=0이며, 이를 전체 데이터의 적격 건수가 0이라는 뜻으로 확대하지 않는다. 가격·운영픽·불펜 문서는 이 두 원문에 연결되어 있지 않았고, 공식 29일 응답은 경기 시작 후 수신되었다. 28일 빈 일정은 누락된 경기나 불펜 휴식을 증명하지 않는다.

Python으로 두 실제 원문 바이트와 메타데이터 SHA-256 일치 2/2, 29일 경기 시작 이후 수신 1/1을 확인했다. 29일 응답은 18:30 KST 시작 경기의 22:53:54 KST 수신 기록이다. 해시 일치는 보존 바이트의 정합성이며 독립 수신 인증은 아니다. 원문에 선발 관련 필드가 있더라도 경기 후 응답이므로 경기 전 확정 증거로 삼지 않는다. 중복 문서·시점 누출·미래 라벨 변조의 실제 입력 검사는 결합 자료와 구현이 없어 아직 수행하지 않았다.

기존 [정보 연구 #455](https://github.com/choigod1023/proto-odds-research/pull/455), [후보 #453](https://github.com/choigod1023/proto-odds-research/pull/453), [검토 #454](https://github.com/choigod1023/proto-odds-research/pull/454), [기존 연구 비교 #451](https://github.com/choigod1023/proto-odds-research/pull/451)을 참조했다. #455에서 반복 열람한 평가 KBO 51경기의 시장은 62.75% / ROI -2.41%, 픽스터 잔차 후보는 54.90% / -15.67%다. 이 수치는 새 독립 검증이 아니고, 공식 선수 정보가 적격하게 연결된 표본도 아니다. 구체적인 당시 상품·가격·실제 수신과 운영 동결픽은 이 보고서에서 독립 확인하지 않았다. 이전 KBO e0 연구 후보는 2026 평가 198경기에서 ROI -7.2980%였지만 사전 가용성은 미증명이고 현재 운영 동결픽 재생이 아니다. 같은 표본을 재학습하지 않았다.

## 후보와 결정 규칙

같은 시점의 전체 경기 시장 확률을 기준으로, 공식 확정 선발·9인 타순·타자 손잡이, 구장과 과거 완료 경기에서 얻은 24/48시간 불펜 투구 수 및 휴식이 시장·사실 없는 기준 모델에 추가 예측력을 주는지 검증한다. 한 개의 정규화된 시장 오프셋 후보만 평가하고, 선수 효과를 임의 확률 보너스로 지정하지 않는다. 확정 전 예상 선발은 별도 상태로 남긴다. 경기 간 선수·팀·상품 ID 교차표, 이전 경기 종료 및 실제 결과 수신 시각, 원문 바이트·출처·실수신 시각, 완전한 가격 벡터, 판정·동결·결과·정산이 필요하다.

시간 순서로 학습·선택·새 평가를 분리하고 평가 결과 열람 전에 날짜와 입력 manifest를 고정한다. 최소 학습 200, 검증 50, 새 평가 100경기와 각 분할 전체 기회의 사실 입력 완비율 80% 미만이면 중단한다. 이 기준은 실험 가능성 기준일 뿐 통계적 검정력의 보증이 아니다. 정규화 강도만 검증 로그손실로 한 번 선택한다. 실제 수신이 판정 이후이거나 T-30을 넘으면 제외한다. 2-way 무승부 환불과 3-way 무승부는 시장별 계약에 맞게 분리한다. 동일 경기·시각·상품·선택지별 가격·정산에서 시장, 실제 동결 운영픽(보류 포함), 사실 없는 기준, 후보를 비교하고 공통 표본과 보류를 따로 보인다.

새 실제 자료 확보 후에만 누출·중복 원문·현재/미래 라벨 변조 검사를 Python으로 수행하고 기회 수, 제외 사유, 커버리지, 적중률, ROI, log loss, Brier, 일 마감 최대 낙폭을 보고한다. 현재는 입력 부족으로 모든 신규 성능 지표가 미산출이다. 운영 모델·월 손실 제한·원장·스케줄은 변경하지 않는다.
