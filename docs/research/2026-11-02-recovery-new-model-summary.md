# 자료 연결 복원과 미실행 후보 비교 — 2026-11-02

자료 복원과 기존 구현에서 찾지 못한 최근접 이웃 후보의 계산을 병렬로 수행했다.
**초기 후보는 적중률이 낮아졌고, 후속 튜닝은 탐색 수치가 좋아졌지만 독립적인 개선을
입증하지 못했다. 현행 모델을 교체하거나 운영에 배포하지 않는다.**

## 기존과 다른 후보와 실제 입력

기존 #364, #425, #426, #430, #433, #453, #455, #488, #490 및 저장소 Python
검색 범위에서 같은 최근접 이웃 구현을 찾지 못했다. 이것은 모든 미등록·외부
연구까지 조사했다는 뜻이 아니다. 같은 시장과 시간 분리된 DC 팀 예측의 승·무·패
확률 6개를 입력으로 삼고, 가까운 과거 경기의 결과 빈도로 새 확률을 만든다.
[Cover·Hart 원 논문](https://isl.stanford.edu/~cover/papers/transIT/0021cove.pdf)은
최근접 이웃 분류의 이론적 배경이다. 이번 유한 표본의 스포츠 성능이나 별도 가산
평활·시간 분할이 좋다는 증명으로 사용하지 않는다.

가설·규칙은 `ba8755fc04624142cc9134239f78e314b7e3f01a`에 먼저 고정했다.
2024년 학습 144경기, 검증 78경기와 사이 간격 6경기를 사용해 k=15/30/60 중
로그손실로 k=60을 선택했다. 이후 2024년 228경기 전체를 이웃 풀로 고정하고
2025년 2~11월 227경기를 평가했다. 대상 정답·점수는 예측 특징에 넣지 않았다.

입력은 #490의 보존된 OOF 예측 455행이다. **복원한 선수 명단을 이번 후보의
특징에 사용한 것은 아니다.** 실제 픽스터·동결 9:1·현행 운영 선택도 이 공통
표본에 없어서 이들과 비교했다고 주장하지 않는다. 2025년은 이미 반복 열람한
탐색 기간이며 새 blind holdout이 아니다. 실제 가격 수신·체결 가능성은 미인증이다.

## 1차 후보: 같은 227경기, 선택 커버리지 100%의 결과

- 시장: **99적중 / 43.61%**, 단위금액 가상 ROI **−14.69%**, 일 마감 최대 낙폭 37.99단위.
- 기존 DC: **94적중 / 41.41%**, ROI **−15.17%**, 최대 낙폭 40.55단위.
- 새 최근접 이웃: **96적중 / 42.29%**, ROI **−7.95%**, 최대 낙폭 25.58단위.

새 후보는 시장보다 3경기 덜 맞혔고 선택 77개가 달랐다. 적중률 차이는 약
−1.32%p, 관측 주 단위 쌍체 부트스트랩 95% 구간은 −7.23~+4.53%p다.
ROI 차이는 +6.74%p지만 구간 −7.69~+21.39%p로 0을 포함한다. 로그손실과
Brier도 시장보다 나빴다. 이 손실 감소를 신뢰할 우세나 미래 수익으로 보지 않는다.
어려운 경기를 빼서 적중률 분모를 줄이거나 결과를 본 뒤 k를 다시 선택하지 않았다.

위 ROI는 모델 비교용 같은 단위금액·단폴 회고 계산이며, 월 5만원 제한을 적용한
사용자의 실제 모의 운용 재생이 아니다. 운영 모의 원장과 월 손실 한도는 변경하지 않았다.

## 남은 제약

복원은 여러 원문과 기존 보관 worktree를 읽는 수동 연구 도구다. 과거 원자료의
절대 경로와 해시를 manifest에 남겼지만 모든 원문을 이 PR에 복제하지는 않았다.
완전한 재생은 해당 보관 자료가 필요하다. 반면 새 후보의 입력·예측·정산과 KBO
단일 운영 연결은 이 브랜치에 보존한 파일로 검산할 수 있다. 자동 수집·대기열
발행을 새로 연결하거나 새 시즌·다른 리그의 개선을 확인한 작업은 아니다.

1차 후보를 운영으로 전환할 근거는 확보하지 못했다. 가용 자료에서 복원 가능한
연결은 보존하고 기존 모델을 유지한다.

새 이웃 후보는 홈 223개·무 0개·원정 4개를 선택했다. 바뀐 77픽 중 시장 오답을

항상 홈을 선택하는 고정 대조군은 94/227 적중(41.41%), ROI −10.08%였다.
새 후보의 성적 상당 부분이 홈승 쏠림과 겹치므로 ROI 한 숫자만으로 독자적 정보를
배웠다고 해석하지 않는다. 원자료와 계산값은
`experiments/input-link-recovery-20261102/neighbor-error-diagnostics.json`에 보존한다.

후속은 k를 무제한 탐색하는 대신 시장 확률을 기준으로 남겨 두는 이웃 잔차 보정,
거리/가중과 평활 강도를 제한된 설정으로 비교하도록 별도 프로토콜을 고정한다.
이 방식은 기존 시장 잔차·혼합 연구와 연결되므로 완전히 새 모델이라는 명칭으로
재포장하지 않는다. 2024년 시간 분리 검증에서만 설정을 고르고 검증 개선이 없으면
시장을 유지하는 선택지도 포함한다. 같은 2025년을 다시 계산하더라도 탐색 결과이며
모델 교체 근거로 승격하지 않는다. 후속 계산과 독립 검산 결과는 아래에 분리한다.

## 후속 튜닝: 시장 잔차만 보정

사용자의 추가 요청 뒤 계획을 `4b73a51`, 결과 전 구현을 `94d6702`에 고정했다.
시장 또는 시장+DC 거리, 균등 또는 거리 가중, 이웃 30/60개, 평활 강도 30/120의
16개 설정만 비교했다. 각 이웃의 실제 정답 one-hot에서 그 경기의 시장 확률을 뺀
오차를 모아, 대상 경기의 시장 확률에 제한적으로 더한다. 과거 이웃의 홈승 비율로
현재 시장 확률 전체를 대체하지 않는다. 이는 기존 잔차·혼합 연구와 이어지는
NN 튜닝이며 완전히 새 원리라고 주장하지 않는다.

2024년 같은 학습 144·검증 78·간격 6개를 사용하고, 시장보다 검증 적중이 늘면서
로그손실이 악화되지 않은 후보만 허용했다. 조건을 만족하지 못하면 시장을 유지한다.
선택은 시장+DC 거리·균등 가중·이웃 60·평활 30이다. 검증 적중은 시장 33/78,
선정 후보 35/78, 로그손실은 1.074765→1.063019였다. 선택과 정답 오염 검사를
독립 Python으로 재실행했으며 설정 선택은 2025년 정답을 읽지 않는다.

이미 본 2025년 227경기, 같은 가격·100% 선택률에서:

- 시장: **99/227, 43.61%, ROI −14.69%**, 최대 낙폭 37.99단위.
- 1차 NN: **96/227, 42.29%, ROI −7.95%**, 최대 낙폭 25.58단위.
- 튜닝 NN: **106/227, 46.70%, ROI −5.96%**, 최대 낙폭 13.68단위.
- 항상 홈: **94/227, 41.41%, ROI −10.08%**, 최대 낙폭 30.42단위.

튜닝 뒤 홈 선택은 223개에서 173개로 줄었다. 시장 대비 바뀐 23개 중 정답 회복
13개, 정답 상실 6개, 둘 다 오답 4개였다. 적중률 차이는 +3.08%p지만 주 단위
쌍체 구간은 −1.35~+7.08%p, ROI 차이 구간은 −1.96~+18.70%p로 0을 포함한다.
로그손실 1.07012와 Brier 0.64616은 시장 1.06766/0.64598보다 조금 나빴다.

이 설계 자체가 2025년의 홈 쏠림 진단을 보고 만들어졌고 그 자료를 여러 번
열람했다. 따라서 설정 선택 코드에 미래 라벨이 들어가지 않았다는 검사와
별개로 독립 맹검이 아니다. 실제 운영·9:1·픽스터의 우세를 측정한 것도 아니다.
독립 워커와 총괄이 16개 검증 설정, 227개 보정 확률, 다섯 대조군 1,135개
Decimal 정산을 확인했다. 최대 확률 차이는 약 1.11e-16이다.

상세 수식·후보별 점수·코드는 [튜닝 보고서](2026-11-02-neighbor-tuning.md)와
`experiments/neighbor-tuning-20261102/`에 보존한다. 동일 평가에 맞춰 추가 탐색하거나
이번 결과를 근거로 모델을 자동 교체하지 않는다. 새 미열람 기간에서의 동일 조건
검증은 이번에 완료한 작업이 아니다.

## 복잡한 튜닝이 필요한가: 단순 보정 대조군

추가 탐색 없이 선택된 평활 비율 60/(60+30)을 그대로 사용하고, 이웃을 고르는
대신 2024년 전체 228경기의 평균 `정답 one-hot − 시장 확률`만 대상 시장 확률에
더했다. 이는 이미 살펴본 2025년의 사후 진단이며 새로운 후보 선정 절차가 아니다.
단순 보정은 **105/227 적중(46.26%), ROI −8.13%, 손익 −18.45단위**였다.
독립 검토자가 227개 확률과 Decimal 손익을 다시 계산해 일치함을 확인했다.

튜닝 NN의 106적중은 단순 보정보다 순 1경기 많다. 두 모델의 선택이 다른
13경기 중 NN만 맞은 것은 6개, 단순 보정만 맞은 것은 5개다. 따라서 복잡한
모델이 새로운 정보를 배워 추가 적중을 만들었다고 단정하지 않는다. 확률 오차도
여전히 시장보다 나쁘고 수익은 음수다. 원자료 기반 진단과 평가 라벨 오염 검사는
`scripts/diagnose_global_market_offset.py`,
`tests/test_global_market_offset_diagnostic.py`,
`experiments/input-link-recovery-20261102/global-offset-diagnostic.json`에 보존한다.

다음 튜닝은 이웃 수를 더 잘게 쪼개는 방향보다 단순 보정 대비 추가 효과를 먼저
검사해야 한다. 입력·가격·정산이 같은 새 미열람 기간에서 시장/단순 보정/선정 NN을
동시에 고정 평가하고, 날짜 순으로 분리한 복수 구간에서 적중률·로그손실·ROI·낙폭을
함께 비교한다. 선발/라인업 변수를 넣을 때는 경기 전 공개와 실제 수신 시각을
각각 보존한 행만 별도 대상으로 삼고, 전체 기회 대비 연결률도 보고한다. 이미 본
227경기에 변수를 계속 추가해 얻은 최고값은 운영 채택 근거로 쓰지 않는다.
