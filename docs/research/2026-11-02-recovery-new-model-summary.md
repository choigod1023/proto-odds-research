# 자료 연결 복원과 미실행 후보 비교 — 2026-11-02

자료 복원과 기존 구현에서 찾지 못한 최근접 이웃 후보의 계산을 병렬로 수행했다.
**적중률 개선은 확인하지 못했다. 현행 모델을 교체하거나 운영에 배포하지 않는다.**

## 무엇을 실제로 복원했나

- **K리그1 2025:** 공식 경기 228개 중 227개에서 날짜·양 팀·시간·점수와
  원래 3-way 배당을 다시 연결했다. 228개에서 보존 선수 명단 원자료를 대조했다.
  선수 ID는 공급자 ID이며 공식 등록 ID와 동치라고 인증한 것은 아니다.
  이미 다른 연구에서 사용한 경기이고 새 독립 표본을 227개 수집한 것이 아니다.
- **KBO 2026-03-28~04-04:** 기존 후보 55행 중 같은 경기 중복 20행을 제거했다.
  공식 고유 경기 35개 중 34개에서 배당·결과를 연결했다. 나머지 1개는 5–5로,
  사후 정산용 1.00/1.00을 실제 사전 가격으로 쓰지 않았다.
- **NPB:** 선발 공란이 있던 935개 중 공식 2023년 아카이브의 3개에서 양쪽
  실제 출전 선발 이름과 최종 점수를 복원했다. 나머지 928개는 이번 제한된
  탐색에서 미발견, 4개는 올스타라 구단별 매칭에서 제외했다. 928개가 복원
  불가능하다는 결론이 아니다. 3개 모두 현재 수신한 사후 자료이며, 공식 선수
  ID와 과거 당시 수신은 0개, 동일 상품·시점 배당 연결은 미측정이다.
- **KBO 2026-11-01 삼성–KIA:** 운영 DB를 읽기 전용으로 추출해 경기 전
  판정 revision 1개, 먼저 보존한 공식 예고 선발 2명, 원장 내부 양측 가격과
  판정 전 별도 가격 관측, 공식 최종 결과 원문을 연결했다. 전체 배당 696행은
  1경기·8상품·87관측이다. 원장의 가격 시각과 똑같은 외부 행은 없어서 원가격
  원문 복원이라고 부르지 않는다. 최근 원장 256행의 개별 해시와 인접 연결은
  검산했지만 이전 원장 전체 및 최종 동결 여부는 확인하지 않았다.

위 회고 연결과 일부 사전 관측은 서로 다른 증거 수준이다. 확정 선수 명단·정확한
최종 동결 revision·같은 시점 전체 가격·공식 정산을 모두 입증한 새 선수 모델
평가 코호트가 생긴 것은 아니다. 미래 시점 정보를 과거 가용 자료로 소급하지 않았다.

## 기존과 다른 후보와 실제 입력

기존 #364, #425, #426, #430, #433, #453, #455, #488, #490 및 저장소 Python
검색 범위에서 같은 최근접 이웃 구현을 찾지 못했다. 이것은 모든 미등록·외부
연구까지 조사했다는 뜻이 아니다. 같은 시장과 시간 분리된 DC 팀 예측의 승·무·패
확률 6개를 입력으로 삼고, 가까운 과거 경기의 결과 빈도로 새 확률을 만든다.
[Cover·Hart 원 논문](https://isl.stanford.edu/~cover/papers/transIT/0021cove.pdf)은
최근접 이웃 분류의 이론적 배경이다. 이번 유한 표본의 스포츠 성능이나 별도 가산
평활·시간 분할이 좋다는 증명으로 사용하지 않는다.

가설·규칙은 `ba8755fc04624142cc9134239f78e314b7e3f01a`에 먼저 고정했다.
2024년 학습 144경기, 검증 78경기와 사이 간격 6경기를 사용해 k=15/30/60 중
로그손실로 k=60을 선택했다. 이후 2024년 228경기 전체를 이웃 풀로 고정하고
2025년 2~11월 227경기를 평가했다. 대상 정답·점수는 예측 특징에 넣지 않았다.

입력은 #490의 보존된 OOF 예측 455행이다. **복원한 선수 명단을 이번 후보의
특징에 사용한 것은 아니다.** 실제 픽스터·동결 9:1·현행 운영 선택도 이 공통
표본에 없어서 이들과 비교했다고 주장하지 않는다. 2025년은 이미 반복 열람한
탐색 기간이며 새 blind holdout이 아니다. 실제 가격 수신·체결 가능성은 미인증이다.

## 같은 227경기, 선택 커버리지 100%의 결과

- 시장: **99적중 / 43.61%**, 단위금액 가상 ROI **−14.69%**, 일 마감 최대 낙폭 37.99단위.
- 기존 DC: **94적중 / 41.41%**, ROI **−15.17%**, 최대 낙폭 40.55단위.
- 새 최근접 이웃: **96적중 / 42.29%**, ROI **−7.95%**, 최대 낙폭 25.58단위.

새 후보는 시장보다 3경기 덜 맞혔고 선택 77개가 달랐다. 적중률 차이는 약
−1.32%p, 관측 주 단위 쌍체 부트스트랩 95% 구간은 −7.23~+4.53%p다.
ROI 차이는 +6.74%p지만 구간 −7.69~+21.39%p로 0을 포함한다. 로그손실과
Brier도 시장보다 나빴다. 이 손실 감소를 신뢰할 우세나 미래 수익으로 보지 않는다.
어려운 경기를 빼서 적중률 분모를 줄이거나 결과를 본 뒤 k를 다시 선택하지 않았다.

위 ROI는 모델 비교용 같은 단위금액·단폴 회고 계산이며, 월 5만원 제한을 적용한
사용자의 실제 모의 운용 재생이 아니다. 운영 모의 원장과 월 손실 한도는 변경하지 않았다.

## 남은 제약

복원은 여러 원문과 기존 보관 worktree를 읽는 수동 연구 도구다. 과거 원자료의
절대 경로와 해시를 manifest에 남겼지만 모든 원문을 이 PR에 복제하지는 않았다.
완전한 재생은 해당 보관 자료가 필요하다. 반면 새 후보의 입력·예측·정산과 KBO
단일 운영 연결은 이 브랜치에 보존한 파일로 검산할 수 있다. 자동 수집·대기열
발행을 새로 연결하거나 새 시즌·다른 리그의 개선을 확인한 작업은 아니다.

이번 후보를 운영으로 전환할 근거는 확보하지 못했다. 가용 자료에서 복원 가능한
연결은 보존하고 기존 모델을 유지한다.
