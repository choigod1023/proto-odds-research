# PR #556 배포 검증 기록

## CI 복구

기존 연구의 `study.py`는 로컬 Git에만 존재하는 11개 과거 blob을 읽었다. 얕은 CI 체크아웃에는 해당 커밋의 파일이 없어 전체 검사가 실패했다. 원래 결과의 `source_hashes`와 하나씩 대조한 원본 바이트를 약 1.5MB의 압축 replay 묶음으로 보존했다. manifest 자체도 고정 SHA-256으로 검사하고, blob 크기·원본 SHA·결과를 검증한다. 원본이 손상되면 현재 checkout이나 새 결과로 대체하지 않는다. Git subprocess를 금지한 상태에서도 전체 과거 점수 재현을 검사한다.

후속 Linux CI에서는 전체 결과의 단순 Python 객체 동등 비교가 실패했다. Windows Python 3.14와 3.12의 재계산은 완전히 일치했다. 재현 비교는 경로별 진단을 제공하고, 유한 부동소수 지표에만 절대 1e-12 이내의 수치 오차를 허용하도록 바꿨다. 정수 건수·금액 문자열·입력 해시·모든 identity와 부울 값은 타입까지 정확히 일치해야 한다. 확률·적중·ROI 산식과 원래 저장 결과는 바꾸지 않았다. 큰 수치 변화, 비유한 수치, 금액/해시/identity 변경은 거부하는 회귀 검사를 추가했다.

## 실제 원문 연결

직접 HTTP로 수신한 [공개 원문](https://www.goli.tv/board/free/298798)은 2026-11-04 07:37 KST 게시 표시의 조합글이다. Fly 수집 서버에서 실제 수신 완료한 시각은 10:07:01.872241 KST, 응답 바이트 SHA-256은 `04acebc17b3226f106019a1d2e392ce44040f620ed1369986bace39124b741aa`다. 그날 19:00 시작하는 네 경기를 경기 API의 종목·리그·고유 팀쌍·일시와 대조했다.

- KBL 서울SK–한국가스: 원문 팀 기준 −6점, 당시 프로토 홈 기준 −6.5점.
- WKBL 신한은행–우리은행: 원문 원정팀 기준 −7점, 당시 프로토 홈 기준 +6.5점.
- KOVO남 KB손보–OK저축: 원문 오버 182.5점, 당시 프로토 186.5점.
- KOVO여 흥국생명–대전정관: 원문 오버 179.5점, 당시 프로토 180.5점.

모두 기준점이 다르며 기간·정산 방식도 원문에서 확증하지 못했다. 따라서 정확한 판매 상품 후보나 최종 추천으로 승격하지 않고, `reference_only` 원문 참고 후보로 보여 준다. 원문의 조합글 맥락, 선택팀 기준 부호, 미확인 범위와 실제 수신 시각을 보존한다. 조합글에서 하키를 포함한 다른 경기나 시작한 경기는 가져오지 않는다. 원문의 승패 추천 유무와 무관하게 이 제한된 참고글 형식을 읽으며, 기존 승패/승무패 투표와는 분리한다.

정상 수집 경로가 같은 목록에서 참고글을 발견하고 최대 16개 본문 예산 안에서 하나를 읽는다. 없으면 공개 목록 한 번을 추가 조회한다. 참고 이벤트는 별도 스트림에 최초 관측으로 저장하고, 조회 상한/실패도 승패 투표 입력에 영향을 주지 않는다. 참고 스트림만 바뀌어도 감독자가 후속 게시를 요청하며, 표시 변경은 기존 예측 revision을 덮어쓰지 않는다. 같은 글을 다시 수신했을 때 중복 저장·불필요한 게시가 없는지도 로컬 DB로 검사했다.

## 검증 상태

실제 원문을 이용한 로컬 파싱과 현재 경기의 기준점 비교에서 4건을 확인했다. 이는 아직 운영 자동 수집·배포 웹 성공을 뜻하지 않는다. 운영 배포와 실제 자동 주기, 웹 표시 검증 결과는 아래에 후속 기록한다. 원문 전체 HTML과 비밀 값은 저장소에 커밋하지 않았다.

로컬 검증: Python 관련 경로 217개 통과, 웹 297개 통과, Vite production build 통과. 재구성 전용 `--sanitize-existing`와 API 읽기 경로는 별개이며, 이 기능은 재구성된 사전 픽을 새 원문 증거로 취급하지 않는다.
