# KOVO 공식 원천 연결과 리시브 모델 가설

공식 KOVO DB Bank 경기 원문 3개를 실제로 읽고 세트별 점수 및 팀 기록을 파싱해 보존 가격 자료의 경기 3개와 연결했다. 남자 1경기, 여자 2경기다. 다만 과거 결과의 실제 수신 시각·경기 전 가격 수신 시각과 리시브 분모는 없어 새 모델 학습 및 2026 성능 평가는 **미실행**이다. 수집 시각이 오래된 경기의 사전 수신을 입증하지 않는다. 이번 자료만으로 적중률·ROI 개선을 주장할 수 없다.

## 원천과 실제 연결

KOVO의 경기 결과 HTML은 `https://dbbank.kovo.co.kr/game/11110_pop_result.asp?PID=<식별자>`다. 표에 경기 날짜, 번호, 홈·원정 순서, 세트별 실제 득점, 경기 시작·종료 시각, 양팀 선수별 출전세트·포지션·득점·공격 성공률·리시브 효율이 있다. 선수 링크의 `pcode`가 선수 ID다. 팀 합계에는 전위/후위 공격 득점, 블로킹 득점, 서브 득점, 선수 범실, 공격 성공률·효율, 유효 블로킹, 리시브 효율이 있다. 선수 명단은 실제 경기의 사후 출전 표이며 사전 확정 라인업으로 취급하지 않는다. 팀 합계의 리시브 효율이 sideout 성공률과 같다는 근거는 없고 이 HTML에서 분모는 확인하지 못했다. PDF 경기 후 요약은 경기 번호·날짜·시간·세트 원점수와 공격·블로킹·서브·리시브·범실을 제공한다.

- [2025-01-09 여자 132번](https://dbbank.kovo.co.kr/game/11110_pop_result.asp?PID=gIzMxoTMwIjOxIDM): IBK기업은행–페퍼저축은행 2:3, 세트 19:25, 25:23, 25:17, 22:25, 14:16. 가격 자료 `domestic|f70be62c6339dd11935d58ba`와 날짜·시작 19:00·팀 별칭·승패 일치.
- [2025-12-27 남자 120번](https://dbbank.kovo.co.kr/game/11110_pop_result.asp?PID=gAjMxoTMwIjOyIDM): 한국전력–현대캐피탈 3:1, 세트 25:22, 25:21, 17:25, 25:19. `domestic|48fdd218284ff760cbb6b1fe`와 날짜·시작 14:00·팀 별칭·승패 일치. [같은 경기 PDF](https://dbbank.kovo.co.kr/upload/gamereport/A_022201120.pdf)도 세트 점수를 확인했다.
- [2026-01-15 여자 153번](https://dbbank.kovo.co.kr/game/11110_pop_result.asp?PID=gMTNxoTMwIjOyIDM): GS칼텍스–IBK기업은행 1:3, 세트 21:25, 15:25, 25:17, 23:25. `domestic|2e7b13032d789119359c37a9`와 날짜·시작 19:00·팀 별칭·승패 일치.

세트 **승수** 3:1과 각 세트의 **원점수** 25:22 등은 다른 열이다. 자동 연결은 하지 않았고 위 세 팀 별칭은 원문·가격 자료를 직접 보고 수동 확인했다. `matched-samples.json`에 결과·ID·시각·두 배당·원문 해시와 팀 합계를 담았다. 실제 HTTP 200, body 길이, SHA-256, 수신 시각은 `receipts.json`에 있으며, 전체 바이트는 별도 로컬 산출물 폴더 `C:/Users/user/.codex/visualizations/2026/11/08/01a1b9e6-33f0-7b92-895d-2849b37ebce2/kovo-source-20261108d/`에 보존했다. 데이터 원본은 커밋하지 않았다.

PID를 뒤집어 base64 복호화하면 확인한 예시는 `021:201:132`, `022:201:120`, `022:201:153`이다. 021은 2025-01-09, 022는 2025-12-27과 2026-01-15에 대응한다. 남녀 두 경기 모두 022:201을 쓰므로 201만으로 성별을 분리할 수 없다. 이 소수 사례에서 시즌·대회 코드의 완전한 역매핑이나 2025–2026 전체 경기 열람 범위를 확증하지 못했다. 알려진 원문 URL이나 경기 후 PDF에서 시즌·대회·번호를 확인한 후 개별 PID를 사용할 수 있다. 날짜 범위 일괄 API와 누락 없는 목록은 미확인이다. 추측한 `/game/11110_list.asp`는 HTTP 200이지만 본문은 `Not Found`로 목록 조회 실패다. 비공개 API, 차단 우회, 대량 수집은 시도하지 않았다. 이용 약관·자동 요청 제한·재배포 라이선스는 별도 확인이 필요하다.

독립 CLI `python experiments/volleyball-source-20261108d/kovo_collect.py --url <공식결과URL> --output <새폴더>`는 한 경기만 받아 HTML 원문, 수신 시각·상태·해시 및 파싱 JSON을 저장한다. DB나 예약 작업을 사용하지 않는다. PID·경기번호, 세트 점수 합계 및 최종 세트 승수 불일치를 거부하며, 점수 형태를 확인한 상태를 `score_indicates_complete`로 표시한다. 취소·기권 여부나 공식 발표·수정 시각의 독립 증명은 아니다. 로컬 CLI 실제 실행과 합성 손상·ID 불일치 테스트를 수행했다. 파서는 아직 선택지 ID, 공식 취소 상태, 원문 발표 시각, 리시브 분모를 추출하지 않는다.

## 픽스터 원문

이전 [Goli 참고 원문 조사](2026-11-04-goli-free-reference-proof.md)는 경기 전 수신된 작성자 1명의 11월 4일 KOVO 남녀 오버를 확인했다. 원문 182.5·179.5점은 당시 프로토 186.5·180.5와 각각 다르고, 경기 범위·정산 단위도 확인되지 않아 `reference_only`다. 동일 기준점 투표·공식 상품 연결 0건이다. 기존 pick79 수집 `experiments/pregame-multisport-20261104/tipster-capture-v1/`은 요청 6건, 유효 records 0건으로 명시적 픽 부재·HTTP 308·시간 제한·Goli 연결 오류를 보존한다. 선택된 운영 원장 배구 11건은 작성자 0명의 시장 fallback이다. 이를 픽스터 성과나 원문 작성자 집단의 전체 표본으로 취급하지 않는다. 이번 조사에서 새 적격 동일 상품 투표는 확보하지 못했다.

## 사전 고정 가설과 다음 검증의 조건

사전 규약 `720e7a5e`는 리시브 효율 기반 상대 전력과 시장 offset을 결합하는 후보 하나만 정의한다. `logit(P홈승) = logit(P시장) + 절편 + β×(홈 리시브 전력−원정 리시브 전력)`이며, 상대 팀 영향을 보정한 직전 관측을 가중하고 리그별로 분리한다. 수신이 경기 전이고 직전 경기가 종료된 실제 원문만 허용한다. 구체적인 모집단·분할·ridge·평가 기준은 `protocol.md`에 있다. 이는 PR #656의 세트 승수 20% 혼합과 다른 입력 가설이며, 기존 시장이나 배구 운영 모델이 이미 이 정보를 얼마나 반영하는지는 검증 전이다. 접촉별 서브·리시브 효과와 상대 전력을 분리한 [연구](https://arxiv.org/abs/2402.01083), 서브 상태별 득점확률에서 경기 확률을 도출한 [연구](https://doi.org/10.1515/jqas-2013-0098)는 가설의 동기일 뿐 KOVO 또는 시장 대비 우월성의 증거가 아니다.

연결된 공식 경기 n=3(2025 남1·여1, 2026 여1); 해당 과거 경기의 사전 예측 시점에 이용 가능했음을 증명한 과거 공식 리시브 이력 n=0, 실제 사전 수신 가격·정산이 함께 검증된 2026 평가 경기 n=0이다. 학습 최소 30경기/리그를 충족하지 못했고 `receive_attempts`, `result_received_at`, `pregame_price_received_at`, 공식 상품 규칙·시점별 선수/팀 일치가 빠져 LL/Brier·적중률·ROI·coverage·MDD·paired CI를 산출하지 않았다. 0% 성과가 아니다. 2023/24 180경기 세트 수축 실험이나 PR #657–659의 농구·야구·1픽 연구를 반복하지 않았다. 자동 수집기를 운영에 연결하지 않았고 모델·추천 정책·동결 원장·지갑·스케줄·배포를 변경하지 않았다.
