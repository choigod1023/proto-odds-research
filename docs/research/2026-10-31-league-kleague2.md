# K리그2 공식 결과 감사와 확정 선발 후보 설계

기준 커밋 `7000e0f0bcffa50bfed38d6b3ff4fea525d48547`, 사전 프로토콜 커밋 `cc43dc0efe3921cf1a7d23028f67a1f97d057134`. 상태는 **blocked_data**다. 분석 대상은 보존된 2025 공식 결과와 축약 경기 이력, `accuracy-review-20261030/inputs/targets.jsonl.gz`다. 전체 저장소나 운영 DB의 모든 예측 원장을 조사한 수치는 아니다.

- K리그2 공식 정규 일정 종료 결과 275경기, 고유 ID 275개. 사후 수신이며 전체 일정의 완전성은 독립 대조하지 않았다.
- 기존 결과 이력 23경기는 리그·날짜·홈/원정 유일 키로 연결되고 점수 23건이 일치한다. 기존 이력에 공식 ID·정확한 시작시각이 없어 그것으로 독립 대조한 것은 아니다. 나머지 252건은 결과만 있는 추가 후보다.
- 지정 평가 입력에는 2025 K리그2 목표 경기가 0건이며 275건과 일치하는 경기, 같은 상품 가격·사전 예측·결과가 결합된 경기도 그 입력 안에서는 0건이다. 275건 각각의 상품별 실제 기회 수, 전체 보유 원장의 동결 운영픽과 사전 배당 교집합은 미확인이다. 시장 구분이 없는 결과를 승무패 가격 표본으로 바꾸지 않았다.
- 공식 결과 파일에는 상품 ID가 없고 경기 전 확정 선수 수신이나 독립 인증이 없다. 해당 자료의 확정 선수 연결 0건, 인증된 사전 선수 수신 0건이다. 과거 가격·사전 판정·선발 수신 누락은 측정 범위에서 확인되지 않았다는 뜻이며 저장소 밖 자료의 부재를 증명하지 않는다. 공식 원문 바이트는 보존되지 않아 저장된 원문 해시를 재검증할 수 없다. 파생 파일의 현재 바이트 해시는 감사 JSON에 기록했다.
- 2026년 다른 회고 연구의 K리그2 네 경기 시장·새 후보는 같은 선택 4개, 각 3/4 적중·ROI +43.75%다. 별도 이미 열람한 표본이며 2025년 275건에 합치지 않는다. 이 수치는 선수 효과나 새 독립 검증이 아니다. 전체 122경기 새 후보는 고정 51.64% / -18.47%, 순차 53.28% / -15.70%로 시장 54.92% / -13.07%보다 낮아 채택되지 않았다. 재계산 픽은 동결 운영픽 재생이 아니다. [관련 연구](https://github.com/choigod1023/proto-odds-research/pull/455).

후보는 공식 확정 선발 11명과 선수별 과거 365일 공식 출전 시간을 경기 전 실제 수신해, 최근 450분 이상 뛴 선수 수의 홈·원정 차이가 같은 시점 시장 대비 추가 예측력을 주는지 검증하는 시장 오프셋 3분류 모델 하나다. 이전 픽스터 방향·저자 잔차 후보와 입력이 다르나 선수 효과 자체는 미측정이다. 승격·플레이오프 구분과 휴식일은 사전 가용성이 입증된 경우 별도 층으로만 기록하며 후보 입력에 섞지 않는다. 예상 명단은 확정 선발이 아니다.

상품·기간·선택·가격·결과·정산을 동일하게 맞춰 시장, 사실 없는 기준선, 후보, 실제 확보된 운영 동결픽을 구분한다. 수신 완료와 판정이 T-30 이내 조건을 만족해야 하고 원문 바이트와 선수·경기·상품 ID가 필요하다. 신규 전향 자료만 날짜 순 60/20/20으로 나누고 경기일을 분리하지 않는다. 총 300경기, 각 구간 최소 180/60/60과 평가 구간 확정 명단 최소 30경기 미달 시 중단한다. 검증 구간에서 후보 로그손실이 시장과 기준선 각각보다 0.005 이상 낮지 않으면 평가 구간을 열지 않는다. 통과 시 단 한 번 평가하며 n·커버리지·적중률·단위 ROI·다항 로그손실·Brier·일별 최대 낙폭과 일별 블록 불확실성을 보고한다. 프로토콜 세부사항은 `experiments/league-research-20261031/kleague2/protocol.json`이다.

Python은 실제 275·23 연결 및 점수 일치를 재확인하고 합성 사례로 T-30과 실제 수신 경계, 같은 경기 문서 해시 중복, 현재·미래 결과 오염을 검사했다. 이는 감사 보조 함수의 검사이며 후보 학습·실제 문서 복제 검증이나 시장 대비 성능 입증이 아니다. 적격 전향 표본, 실제 배당·동결 운영픽·공식 확정 선수의 연결 수와 새 후보 정확도·ROI·로그손실·Brier·낙폭은 미확인이다.

필요한 새 자료: 경기와 선수의 공식 ID, 완전한 공식 확정 명단과 원문 바이트·실제 수신 완료 시각 및 독립 수신 증거, 이전 공식 출전 시간과 그 가용 시각, 공식 경기 단계와 이전 경기 완료·수신 시각, 동일 상품의 전체 배당과 관측·수신 시각, 동결 운영 판정, 공식 결과와 정산 규칙. 공개 주장 시각이나 내부 해시만으로 수신 인증을 대체하지 않는다. 새 증거 이벤트와 입력 해시가 주어질 때만 후속 검토한다.
