# 고배당 단폴과 저배당 조합 비교 — 2026-10-30

저배당을 많이 묶는 전략을 채택할 근거는 확인하지 못했다. 장기간 시장 배당 기준 자료에서 KBO·NPB·MLB·NBA의 3~4폴은 2폴보다 손실이 컸다. 같은 저배당 픽을 단폴로 나눈 대조군은 이들 리그에서 조합보다 손실이 작았다. 고배당 단폴도 안정적인 흑자를 보장하지 않았다.

현재 모델별 사전 기록은 공통 비교 표본이 매우 작다. 특히 픽스터의 실제 방향을 반영한 고배당 단폴과 저배당 2폴을 같은 날·회차에 구성할 수 있는 날이 거의 없었다. 따라서 장기 시장 실험 결과를 ‘현재 픽스터 9:1의 장기 수익’으로 바꾸어 말해서는 안 된다.

운영 모델·서버·베팅 설정은 바꾸지 않았다. 월 5만 원 손실 한도는 연구 계산에서만 적용하지 않았다. 아래 손익은 가상 전략의 실현 손익이며 미래 기대수익 보장이 아니다.

## 자료와 비교 조건

- 사전 저장 자료: 7,458개 전체 수정본, 86,806개 선택지. 경기 시각은 2026-08-28~2026-10-30. 내부에 남은 판단·배당 시각을 사용하며, 과거 특정 1년 전체의 모델 성적이 아니다. 빈 수정본 252개도 유지해 오래된 예측으로 되돌아가지 않는다.
- 픽스터 회고 자료: 서로 다른 597경기, 1,257개 가격 선택지, 2025-10-29~2026-10-27. KBO 217·NPB 117·MLB 116·NBA 99·KBL 18·K리그1 19·K리그2 11. strict 508경기에는 투표 동률 16경기(KBO 14·NPB 2)가 포함된다. 앞선 492경기는 이 동률을 제외한 표본이었다. strict 508경기와 중복 없는 standard-OT NBA 89경기는 별도 cohort로 유지했다. 서로 다른 출처/정산 계약을 자동으로 합치지 않았다.
- 장기 시장 회고 자료: 2023-01-01~2026-10-30, 44,396경기, 166,463시장, 389,203선택지. 정산 완료·가격 존재 자료만 남은 이전 정규화 자료이므로 취소·누락 선택 편향이 있다. 모든 결과를 운영사 원문과 독립적으로 재대조한 자료도 아니다.
- 시장 회고 모델은 `p_i=(1/배당_i)/Σ(1/배당_j)`이다. 저장된 Shin 확률이나 실제 서비스 자체 모델과 다르다. 픽스터 회고의 시장 모델은 저장 배당 전체 벡터의 Shin 계산이며, `market90_vote10`은 시장 90%+실제 투표 비중 10%다.
- 자체 모델 비교에는 저장된 시장, 당시 최종 확률, 점수 예측 확률, 시장90%+점수예측10%를 사용했다. 마지막 혼합은 **시장90%+픽스터10%와 다른 실험**이다. 투표 비율은 지지 점수이며 보정된 적중확률로 간주하지 않았다.
- 세 자료는 섞어 합산하지 않았다. 출처·원본 해시·누락 사유는 `inputs/*/manifest.json`, `TIMED/provenance.json`에 보존했다. 저장 시각을 증명할 수 없는 회고 자료의 가용 시각은 경기 24시간 전이라는 가정이며 실행 가능성을 입증하지 못한다.

전략은 ROI 계산 전에 프로토콜 커밋 `5a5a4282`로 고정했다. 전략당 같은 총액 12,000원이다. 단폴 분산 대조군까지 1,000원 단위로 나누기 위해 이 금액을 사용했다. 금액을 10,000원으로 비례 환산해도 ROI는 같다.

- 고배당 단폴: 3.00 이상 5.00 미만, 별도 5.00 이상 10.00 미만.
- 저배당 조합: 각 1.10~1.50의 2·3·4폴. 민감도 분석은 각 1.10~1.80까지 확대.
- 같은 리그·한국 날짜·발매 연도/회차에서 선택. 사전 판단을 30분 간격으로 확인하고 모든 경기 시작 30분 전까지 관측된 선택지만 사용. 양 전략이 동시에 구성되는 최초 시각에 1장씩 산다. 서로 다른 경기·팀만 묶는다.
- 사전 확률(투표 모델은 지지 점수) 순으로 경기별 한 선택을 고르고, 조합 점수의 곱이 가장 큰 조합을 선택한다. 상위 20경기까지만 탐색한다. 별도로 확률×배당 순위도 계산했다. 결과·적중 여부는 선정에 사용하지 않는다.
- 최신 경기 수정본을 먼저 고른 후 모델 존재 여부를 확인한다. 발매 경기번호가 없는 선택지는 정산 결과와 무관하게 제외한다. 최신본에서 모델이 없으면 과거 모델을 가져오지 않는다. 미정산 선택지도 먼저 고른 뒤 미정산으로 남긴다. 비교표에서는 모든 비교 모델·전략의 구성 경기 결과가 함께 확인된 경우만 비교한다.
- 사전 저장 자료에서도 선택된 leg 인스턴스(전략별 중복 포함)의 1.14%는 관측 후 120분 이상 지난 배당이었다. 최장 약 54.4시간이다. 고정 프로토콜에 배당 나이 제한이 없었으며 결과를 본 후 유리한 기준으로 자르지 않았다. 내부 관측 시각이 있다는 것과 그 배당이 구매 시점에도 유효했다는 것은 다르므로, 저장 자료 역시 확정 실전 수익으로 읽으면 안 된다.
- 단폴은 저장 배당 그대로, 조합은 배당을 곱하고 소수 둘째 자리까지 절사한 뒤 소수 첫째 자리로 올림한다. 예: 단폴 1.49는 1.49, 1.49×1.49 조합은 2.3이다. 환불 경기의 배당은 1.00. 전부 환불이면 원금을 돌려준다. [공식 배당 규정](https://www.sportstoto.co.kr/terms_allocation.php), [프로토 게임 안내](https://www.betman.co.kr/gameguide/protoVictory.html).
- 과거 모든 상품의 단폴 구매 가능 지정 여부는 확인되지 않았다. 따라서 단폴 손익은 배당의 경제성을 비교하는 가상 기준이지, 해당 표본을 전부 실제 단폴 구매할 수 있었다는 뜻이 아니다.
- 개별 배당 1.50 이하 2폴의 최종 배당은 최대 2.3이다. 3~5배 단폴과 지급 규모가 같지 않다. 이를 숨기지 않고 3·4폴과 최종 지급배당 구간별 결과도 함께 계산했다. 전체 원시 결과는 `results/summary.json.gz`에 있다.

## 리그별 조절: 앞 2/3 날짜로 고른 전략을 뒤 1/3에서 평가

각 리그 안에서 앞부분의 ROI로만 다섯 전략 중 하나를 선택했다. 최소 학습 10회·평가 5회 조건을 적용했다. 전체 데이터를 보고 잘 나온 배당을 채택한 표가 아니다. 다만 자료 자체를 앞선 연구에서도 사용했으므로 새로운 미공개 검증 기간은 아니다.

- **K리그1**: 학습 12회·평가 7회, 앞기간 선택 `single_long_3_5`, 뒤기간 ROI +72.14%. 평가 기간 2026-05-17~2026-10-24.
- **K리그2**: 학습 2회·평가 1회, 표본 부족으로 전략 채택하지 않음.
- **KBO**: 학습 254회·평가 128회, 앞기간 선택 `single_control`, 뒤기간 ROI -3.73%. 평가 기간 2025-06-17~2026-10-07.

## 실제 픽스터 투표와 시장90:투표10

597경기 자료 전체를 사용해 계산했지만 ‘고배당 단폴 대 저배당 조합’을 같은 리그·날짜·회차에 구성하는 데 필요한 경기 수가 부족했다. 순수 투표에서 아무도 지지하지 않은 방향의 점수는 0으로 유지해 선택하지 않았다. 자료에 없는 고배당 픽을 픽스터가 추천한 것처럼 만들지 않았다.

## 해석과 현재 적용 방향

‘배당이 높다/낮다’만으로 수익률을 결정하지 않는다. 단폴의 이론적 순수익률은 `p×배당−1`이다. 서로 독립이고 환불이 없다면 조합은 `Πp×최종배당−1`이다. 반면 같은 돈을 단폴로 나누면 각 단폴 순수익률의 가중평균이다. 개별 픽에 손실이 내재돼 있으면 조합은 그 손실을 키우기 쉽고, 확률 추정이 틀리면 그 오차도 누적된다. 실제 조합 손익은 독립 확률을 시뮬레이션하지 않고 관측된 경기 결과로 정산했다.

- **KBO·NPB·NBA**: 저배당 3~4폴 확대 근거가 없다. 단폴 분산을 비교 기준으로 유지한다. 단폴이 불가능한 상품이면 구매하지 않는 대안도 포함해야 하며 억지로 조합하지 않는다.
- **MLB**: 일부 저장 구간에서는 2폴이 흑자였지만 장기 시장 자료와 기간 분리 평가에서는 유지되지 않았다. 2폴을 검증 후보로 남길 수는 있어도 수익 정책으로 확정하지 않는다.
- **K리그1·2**: 고배당 단폴의 특정 구간 흑자를 발견했지만 공통 표본과 기간 검증이 부족하다. 고배당이라서 유리하다고 결론 내리지 않는다.
- **KBL**: 3~4폴을 비교할 공통 표본이 특히 부족하다. 저배당 다폴을 기본값으로 두지 않는다.

현재 자료가 지지하는 방향은 **고배당 한방이나 다폴 확대를 기본값으로 채택하지 않고, 같은 픽의 분산 단폴을 먼저 기준으로 삼는 것**이다. 단폴도 흑자가 검증된 상태는 아니다. 향후 각 경기의 사전 확률·당시 구매 가능한 배당·실제 투표 방향을 함께 남겨야 현재 서비스의 배당별 손익과 조합 효과를 충분한 공통 표본에서 구별할 수 있다.

## 재현과 검증

```powershell
python -X utf8 scripts/single_parlay_research.py --inputs experiments/single-parlay-20261030/inputs/TIMED/events.jsonl.gz experiments/single-parlay-20261030/inputs/VOTES/events.jsonl.gz experiments/single-parlay-20261030/inputs/ARCHIVE/events.jsonl.gz --output .local-test/reproduce-single-parlay

```

`results/sessions.jsonl.gz`에 각 조합의 배당·선택 방향·경기/발매/수정본 ID·시각·정산을 저장했다. `summary.json.gz`에는 모델·리그·순위 규칙·비교 조건·동일 모델 집합별 결과와 지급배당 구간, 최대 연속 손실·낙폭·월별 손익을 저장했다. 비교 조건·모델 집합이 다른 행은 합치지 않는다. 학습 선택은 `league-selection.json`, 원본 파일 해시는 각 manifest에 있다. 수집기 원본 코드는 보존용이며 과거 작업 경로를 참조한다. **위 정규화 입력 파일을 이용한 재계산은 독립 실행 가능**하다.

최종 로컬 검증은 신규 테스트 17개, 전체 1,862개·93 subtests 통과(환경에 따른 skip 6개)다. 별도 구현으로 271,905개 비교 세션·408,017개 투표권·769,333개 leg 인스턴스의 원본 연결·사전 시각·회차·중복·정산·모델 공통 집합을 전수 대조했다. 최종 독립 검증의 모든 계약 검사를 통과했다. 중간 검증에서 발매 경기번호 누락을 발견해 결과와 무관한 신원 필터를 추가하고 전부 재계산했다.

변경은 로컬 연구 스크립트·테스트·자료·보고서뿐이다. 병합·배포·운영 설정 변경은 하지 않았다.
