# 고정 보정 후보의 2026년 추가 기간 검증

**이번 고정 이웃 보정 후보는 채택 검토 조건을 통과하지 못했다.** 같은 국내 기록
배당의 77경기에서 시장보다 적중률·ROI·확률 오차·낙폭 모두 나빴다. 2025년 탐색에서
좋아 보였던 수치가 다른 기간에서 재현되지 않았다. 현행 운영 모델을 변경하지 않는다.

## 사전 고정과 실제 실행

- [총괄 계획](2026-11-02-frozen-neighbor-period-protocol.md): `46879d82`.
- 공식 원문·자료 준비 코드 등록: `614e4ed7`, `d830f59a`, 연도 스키마 보완 `32182d0a`.
- 엔진: 연구 워커 초안 PR #501, `9717b5d389ad58104681965dabeab45dfd6ad223`.
- 최초 코드·입력 등록: `50fdae5514188a62d283722d2824f913e35b9008`.
- 해외 자료 자격 오류 정정 후 등록: `2cadaeb0a6eb823aa3faa7090a7abe91070e69fa`.

세 후보를 고정했다. 시장은 동일한 Shin 확률, 단순 보정은 2024년 228경기의
평균 `(정답 one-hot − 시장 확률)`에 60/90을 곱한 값, 이웃 보정은 같은 은행의
시장+DC 6차원 거리·균등 가중·k=60·prior=30이다. 신규 설정 선택·변수 탐색이나
은행 갱신은 하지 않았다. 대상 선택은 확률 최댓값, 적격 경기 100%다.

DC는 기존 코드의 LF SHA `79187243175ed45556af79f1c376f8628844747188865cb57b5e0b627e48bf3f`를
보존했다. 180일 반감기·L2=10·rho 제한을 유지하고, 각 월초보다 7일 이전까지의
공식 완료 경기만 사용했다. 기존 2023~2025년 공식 경기 684건과 새 2026년 공식
종료 결과를 결합해 대상 월의 인과적 과거 이력을 만들었다. 실제 당시 결과 수신이
확인된 것은 아니며 7일 가용성은 연구 가정이다. 선발·명단·픽스터 입력은 쓰지 않았다.

## 자료 분모와 제외

공식 K리그 `getScheduleList.do`에 2026년 1~11월을 순차로 11회 요청했고 모두 HTTP
200이었다. 응답 원문과 실제 수신 완료 시각·SHA를 보존했다. 원문 223행 중 연도/대회가
다른 1행과 미종료 18행을 제외해 FE·Y인 공식 최종 경기 204건을 확인했다. 원문은
2026-11-02 사후 수신이며 가격의 경기 전 수신 증거가 아니다.

국내 CSV 원본 SHA는 `9ffddb2dcbc4297c32e6ad3826f392e1842e52e10b509e4cbe47eed1f84b9da4`다.
2026-02-28~05-17 K리그1 전체 경기 승무패·3방향 상품 89행을 추출했다. 같은
날짜와 방향의 6경기 12행은 어느 가격을 선택할지 임의로 결정하지 않고 모두 제외했다.
남은 **77경기**는 날짜·홈/원정 공식 팀 ID·현지 경기 시각을 유일하게 연결한 뒤
공식 최종 점수와 원배당 행의 점수도 확인했다. 89행 중 77행인 86.52%이며, 공식
204경기 전체의 대표 표본이라고 부르지 않는다. 실제 가격 수신·구매 가능성은 미검증이다.

해외 보존 자료는 경기 식별상 120행이 공식 결과에 연결되며 국내 77경기를 모두
포함한다. 그러나 세 배당값의 역사적 상품·선택지 순서를 원문으로 인증하지 못했다.
기존 수집기는 HTML에서 먼저 발견한 `data-odd` 값을 순서대로 추출하며 보존 JSON은
상품명과 선택지 라벨을 담지 않는다. 따라서 **해외 120행은 최종 평가에서 전부 제외**했다.
현재 사이트 표를 확인해 과거 가격 순서를 인증한 것으로 처리하지 않는다.

처음에는 해외도 적격으로 계산했으나 독립 검토 지적 뒤 바로 자격을 정정했다.
초기 결과와 정산은 삭제하지 않고 루트 실험 파일 및
[초기 실행 정정 기록](../../experiments/frozen-neighbor-period-20261102/INITIAL_RUN_STATUS.md)에
보존한다. 유효 최종 결과는 `verified-inputs/`와 `verified-results/`다. 국내 결과는
정정 전후 완전히 동일함을 검산했다. 77+120을 독립 197경기로 합산하지 않는다.

## 유효 국내 77경기 결과

모든 후보는 같은 기록 가격·같은 공식 결과를 사용한다. 단위금액 정액 단폴 연구이며
사용자 모의 지갑의 월 손실 5만원 중단을 적용한 실제 운용 재생이 아니다. 기존 지갑과
월 손실 한도는 변경하지 않았다.

- 시장: **39/77, 적중률 50.65%, ROI −1.66%, 순손익 −1.28단위**.
  로그손실 1.04670, Brier 0.63117, 일 마감 최대 낙폭 7.74단위.
- 단순 평균 잔차 보정: **38/77, 49.35%, ROI −4.87%, −3.75단위**.
  로그손실 1.06029, Brier 0.63959, 최대 낙폭 9.33단위.
- 고정 이웃 잔차 보정: **31/77, 40.26%, ROI −25.40%, −19.56단위**.
  로그손실 1.07215, Brier 0.64618, 최대 낙폭 21.64단위.

이웃 보정이 시장과 다르게 고른 8경기는 모두 시장이 맞고 이웃이 틀렸다. 시장 오답을
회복한 경기는 0개다. 원정→홈 변경 7개와 홈→원정 변경 1개였고, 홈 선택은 시장 47개,
이웃 53개였다. 이웃의 월별 순손익은 2월 −0.83, 3월 −13.46, 4월 +2.62,
5월 −7.89단위로, 네 달 모두 같은 달 시장보다 낮았다. 2024년의 국소 잔차가
2026년에도 유효할 것이라는 가정을 지지하지 않는다. 원인을 특정 선수나 부상으로
인과적으로 설명할 증거는 이번 입력에 없다.

시장 대비 이웃의 적중률 차이는 −10.39%p, ROI 차이는 −23.74%p다. 관측 11주를
쌍체 블록으로 5,000회 재표집한 95% 구간은 각각 −17.24~−4.49%p,
−39.45~−10.09%p다. 단순 보정 대비 구간도 음수다. 표본 77경기와 열람 이력의
한계 때문에 이를 보편적 미래 성능의 확정으로 쓰지는 않지만, 승격 조건을 통과하지
못했다는 판정은 명확하다. 시장 역시 손실이므로 수익 모델로 인증한 것이 아니다.

## 독립성·현재 운영 비교의 한계

이번 이웃 모델은 이 2026년 기간을 처음 계산했지만, 프로젝트 전체의 독립 맹검은
아니다. 기존 #425 자료와 국내 후보 66경기·해외 후보 70경기가 겹치며, 이전 K리그
감쇠 실험의 대상과도 일부 겹친다. 따라서 이전 2025년을 반복 계산한 연구와는
구분하되, 새 독립 증거를 확보했다고 과장하지 않는다.
[자료 가용성·선행 사용 감사](../../experiments/frozen-neighbor-period-20261102/availability-audit.md)에
원본 경로와 SHA·이전 사용 범위를 남겼다. 과거 연구와 겹치지 않는 소수 경기만
사후 선택해 새 우수 성적을 만들지 않았다.

실제 운영 동결 선택·픽스터 투표·과거 9:1의 동일 시점 입력은 이 코호트에 없다.
따라서 이 연구로 현재 운영 모델이나 실제 사용자 수익을 평가한 것이 아니다.
이번 후보를 승격하지 않고, 같은 표본을 더 잘게 튜닝하는 작업도 반복하지 않는다.

## 검산과 재현

총괄의 별도 스칼라 구현과 독립 검토 워커가 각각 77경기×3개 확률 벡터와 231개
Decimal 정산을 재계산했다. 확률 최대 차이는 1.11e-16이고 정산 손익은 모두 일치했다.
독립 검토는 11주 재표집 구간과 승격 조건 미충족도 확인했다. 공식 원문
해시·FE/Y·팀 방향·월별 학습 경계·cutoff 이후 결과 오염 검사를 실행했다. 관련
엔진/입력 회귀 테스트 30개가 통과했으며 최종 전체 테스트와 해당 head의 CI 상태는
총괄 PR 본문에 기록한다. 코드 검사 통과는 모델 개선 증명이 아니다.

원문 재수집 없이 보존 파일로 검산하는 명령:

```text
python experiments/frozen-neighbor-period-20261102/verify.py
python -m pytest tests/test_frozen_neighbor_period_inputs.py tests/test_frozen_neighbor_engine_20261102.py -q
```

최종 평가 코드와 입력은 등록 commit `2cadaeb0`에 고정돼 있다. 원래 결과 생성은
`run.py --registration 2cadaeb0a6eb823aa3faa7090a7abe91070e69fa`로 수행했으며,
이미 있는 결과를 조용히 덮어쓰지 않도록 재실행을 거부한다. 검산기는 결과 파일을
덮어쓰지 않는다. 운영 코드·DB·스케줄·추천 정책·병합·배포는 바꾸지 않았다.
