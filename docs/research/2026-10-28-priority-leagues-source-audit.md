## 현재 코드에서 확인한 것

- `src/public_tipster_votes.py`의 실제 공개 승패 수집 허용 출처는 `pick79.com`, `www.goli.tv`다. TailSlips는 `src/pickster_watch.py`의 별도 수집 경로다. ATTV·Named·Kingkong을 조사한 이력과 실제 운영 입력을 혼동하지 않는다.

두 파일 모두 행의 `observed_at`, `published_at`, `source_url`이 없다. 따라서 해당 경기의 선발을 당시에 알고 있었다고 주장할 수 없다. 과거 경기 결과를 엄격히 지연한 성향 분석과, 당일 선발을 사용하는 예측 실험은 분리한다. 로컬 파일 범위는 현재 운영 서버의 수집 최신성을 뜻하지 않는다.

- **bettingexpert**는 과거 링크가 다음 맞대결로 바뀌어 당시 픽 시각을 복원하지 못한 표본이 있었다.
- 픽스티비·해피토토 원문은 웹 도구에서 읽혔지만 일부 Python 직접 요청은 ConnectionError였다. 무료 열람과 기존 수집기의 자동 접근 성공을 구분한다. 재시도 폭증이나 우회 경로를 추가하지 않았다.
- 기사에 쓰인 선발·결장·순위·적중률·시뮬레이션 결과는 제공자 주장이다. 공식 확인 없이 사실 특성이나 신뢰도 가중치로 넣지 않는다.
- 현재 조사 표본 중 과거 경기 전 공개를 **독립적인 당시 보관본**으로 입증한 신규 출처는 없다. 사이트 게시 날짜만으로 과거 사전 표본에 편입하지 않는다.

## 비교 실험에 들어갈 순서

1. K리그부터 출처별로 경기 ID·시장·작성자·최초 관측 시각·원문 해시·수정 버전을 저장한다. 한 기사/영상/경기 페이지와 복제 글은 독립 표가 아니다. 출처 그룹의 중복 여부가 미확인이면 독립성 미확인으로 남긴다.
2. 경기·킥오프·홈/원정·시장·연장/무승부/취소 정산을 공식 기록 및 프로토와 맞춘다. 기사 자체 예상 스코어·판매 가격·정산 결과로 공식 결과를 대신하지 않는다.
3. 과거 게시 시각 주장만 있는 자료는 탐색 표본으로 구분한다. 시점 증거가 없는 당일 선발·결장·픽을 실제 사전 실험의 입력으로 넣지 않는다. 이미 본 과거 데이터도 새 홀드아웃으로 부르지 않는다.
4. 같은 경기·같은 프로토 구매 가능 가격·같은 선택 및 정산 조건으로 현행 9:1, 신규 픽스터 추가 9:1, 공식 컨텍스트 추가, 양쪽 추가를 비교한다. 픽스터 단독도 별도 대조군으로 둔다. 모델을 고정한 공통 경기 비교와 전체 추천 범위 변화는 따로 보고한다.
5. 리그별 표본·연결 실패·추천 수·적중률·Brier/log loss·ROI·최대 낙폭·월 손익을 함께 기록한다. 원문에 확률이 없는 단일 픽에 임의 확률을 부여해 확률 지표를 계산하지 않는다. 월 손실 5만 원 한도는 미정산 노출을 포함해 동일하게 적용하고, 시즌/출처/시간 구간을 나눈다.

실행 순서는 관심 리그 순서를 유지한다. K리그의 활용 조건이나 KBL 접근이 막히면 그 리그의 상태를 남기고 뒤 리그의 독립 조사는 계속할 수 있다. **현재는 수익 개선 수치를 산출하지 않았고 새 사이트를 운영에 투입하지 않았다.**

## 실행 근거

- `experiments/priority-source-audit-20261028/local_inventory.json`: 로컬 5개 상세 파일의 해시·경기 수·연도·시점 필드 검사.
- `public_probes.json`: 로컬에서 수행한 공식/기존 제3자 경로 11회 요청의 응답·해시·파싱 요약. 도쿄 서버 네트워크 실측이 아니다.
