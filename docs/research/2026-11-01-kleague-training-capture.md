# K리그1 2023·2024 공식 학습 이력 수집

공식 [일정 페이지](https://www.kleague.com/schedule.do?leagueId=1&year=2025)에 명시된 조회 전용 `/getScheduleList.do` POST와 동일한 필드(`leagueId=1`, `teamId=''`, `year`, `month`, `ticketYn=''`)를 사용했다. 2023·2024년의 각 1~12월을 1회씩, 총 24회 요청해 모두 HTTP 200 및 `resultCode=200`을 받았다. 요청은 한 번에 하나씩, timeout 15초·응답 3,000,000바이트 제한으로 실행했다. 재시도는 없었다. 실제 요청 시작은 2026-11-01 10:19:33 KST, 마지막 수신은 10:19:43 KST다. 각 원문 응답 바이트·정확한 시각·payload·상태·SHA256은 `raw/`, `requests.json`, `manifest.json`에 보존한다.

공식 응답 464행 중 정규 K리그1(`leagueId=1`, `meetSeq=1`)의 종료·점수·식별 조건을 통과한 경기는 2023년 228건, 2024년 228건이다. 두 해 모두 38라운드 각 6경기, 12개 팀 각 38경기다. 8행은 승강 플레이오프(`meetSeq=3`)로 분리해 제외했다. 정규 시즌 결과의 타깃 연도·월 불일치, 미종료·취소, 중복 경기 ID, 같은 팀 ID의 원천 표시명 변경, 잘못된 점수로 인한 제외는 0건이다. 팀명 변경 검사는 확보한 경기 행의 `homeTeamName`/`awayTeamName` 기준이며 구단의 다른 전체 명칭이나 외부 식별자 검증은 포함하지 않는다.

모든 월의 요청은 성공했으며 누락월은 없다. 원천의 빈 응답은 2023년 1월, 2024년 1·2월이다. 2024년 12월은 빈 응답이 아니라 플레이오프 3행만 반환했다. 플레이오프 나머지 5행은 2023년 12월 4행과 2024년 11월 1행이다.

`fixtures.jsonl`은 공식 경기 ID·팀 ID·팀명·날짜·시각·원천 종료 상태·점수·원문 식별자·수신 시각·해시를 보존한다. 시각은 원천 표시값이며 시간대/UTC 순간은 별도로 인증하지 않았다. 이 자료는 **현재 조회한 사후 공식 결과**로, 2023·2024년 경기 전 실제 수신 증거가 아니다. 배당·선발 수신을 제공하지 않고, 2025년 평가 자료를 이 파일의 선정에 사용하지 않았다. 모델 학습이나 ROI 실험도 수행하지 않았다.

재현: `python experiments/kleague-roi-diagnostic-20261101/training/fetch.py`는 이미 보존한 바이트만 읽어 산출물을 재생한다. `--capture`는 요청 로그가 존재하면 재요청을 거부한다. `python -m pytest -q tests/test_kleague_training_capture.py`로 범위 밖 대회, 미종료, 잘못된 점수·날짜, 중복 ID, 팀명 변경, 해시 훼손과 재수집 차단을 검사한다. 운영 코드·DB·스케줄·정책·지갑·배포는 변경하지 않았다.
