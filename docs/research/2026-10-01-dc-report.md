# DC·시간 감쇠의 증분 검증

기존과 비슷한 실험이 맞다. 기존 문서에도 DC와 시간 감쇠가 있었고 현재
`src/score_dist.py`에도 저득점 보정 함수가 있다. 이번에 추가한 것은 공식을
새로 만드는 일이 아니라 **ρ를 학습하고, 감쇠 효과와 분리해 같은 예산에서
얼마나 달라지는지 측정하는 절제된 비교**다.

그 결과 DC는 기존 Poisson 혼합의 log loss를 조금 줄였지만 Shin을 넘지
못했다. 최근 경기 가중치를 추가한 선택 모델은 오히려 나빠졌다. 다음
fold에서는 네 계열 모두 시장 비중 100%를 선택했다. 이 결과로 운영 모델을
바꾸거나 수익을 보장할 근거는 없다.

## 기존 자산과 이번 추가분

- `docs/사전조사_원본.md` 296/320행은 외부 `wc2026-predictor`의
  `score_model.py`와 DC+시간 감쇠를 이미 구현된 자산으로 소개한다.
  `HANDOFF.md`에도 DC 설명이 있다. 과거 개념·원형이 있었다는 근거이지,
  현재 운영에서 ρ를 학습해 사용한다는 증거는 아니다.
- 현재 `src/score_dist.py`의 `dixon_coles_tau`는 그대로 import했다.
  해당 파일의 기본값 ρ=0은 독립 Poisson이다. 운영 파일은 수정하지 않았다.
- PR258의 `local_score_model_tournament.py`는 loader, Shin, fold 가드,
  정책·정산·paired bootstrap을 그대로 재사용했다. 이전 실험의 ridge=10
  독립 Poisson 확률과 이번 기준선의 동일성을 단위 테스트로 확인했다.
- 새 연구 코드는 공동 제약 우도에 따른 ρ 적합, 정규화한 지수 시간 가중치,
  4계열 비교, raw/혼합 예측의 감사 기록이다. 최초 발명이나 원논문의 완전한
  재현을 주장하지 않는다.

## 사전 고정과 실행 이력

실제 데이터 로딩 전에 프로토콜만 `751451c5`로 커밋했다.
[프로토콜](2026-10-01-dc-protocol.md)의 LF 정규화 SHA-256은
`b7f333f9d750ee530689ea9c1a59e158ab93ec42d97330cf7f426f3ae33d1db8`이다.
실행기는 명시한 커밋과 프로토콜을 비교한 뒤 자료를 읽는다. 결과에 코드와
재사용 의존성의 LF 정규화 해시를 POSIX 상대 경로로 기록했다.

**실제 데이터 실행은 두 번 했다.** 첫 실행은 tensor 방식의 점수 합산으로
끝났다. 이후 메모리 검토에서 잠재적으로 큰 `경기수×득점격자²` 할당을
발견해 같은 분포를 Poisson CDF 합산으로 계산하도록 바꿨다. 목적함수,
ρ 제약, 득점 지원 범위, 후보와 선택 규칙은 바꾸지 않았다. 작은 tensor와
동등성 테스트를 추가하고 기술 수정 재실행을 했다. 두 실행의 선택 ID는
모두 같았고 최대 예측 확률 차이는 `5.551115123125783e-16`이었다.
첫 실제 실행이 메모리 검토보다 먼저였다는 점을 숨기지 않는다.

고유 후보 평가는 60개, 한 실행의 실제 리그별 적합은 40회다. 같은 고정
평가를 두 번 실행했으므로 계산상 후보 평가 120회·적합 80회다. 두 번째
실행은 새 모델 탐색이나 결과에 따른 재조정이 아니다. 최종 실행의 계산
시간은 약 3.62초(다운로드 제외), 결과 JSON은 약 5.1MB compact 형식이다.

## 데이터와 비교 조건

이미 공개되고 이전 연구에 노출된 D1/SP1 2019/20–2024/25 4,116경기다.
원본은 `footballdataset` 커밋
`e82cf59161e82e0fbcdc49ad02819e45c821a5c8`의 12개 CSV이며 source 해시를
모두 남겼다. 이번 원본의 배당 누락은 0건이다. 누락이 생겨도 실제 경기가
있는 날짜의 예산은 유지하며, 가격이 없는 경기는 베팅에서 제외한다.

Fold A: 2019–21 학습 2,058경기 / 2022 inner 686경기 / 2023 outer
686경기. 선택 후 2019–22의 2,744경기로 재적합했다. Fold B: 2019–22
학습 2,744경기 / 2023 inner 686경기 / 2024 outer 686경기. 선택 후
3,430경기로 재적합했다. 시즌 표기는 시작 연도다. 각 적합은 첫 평가일
최소 7일 이전 결과까지만 쓰며, 평가 기간의 결과로 정적 계수를 갱신하지
않는다. Fold A outer가 Fold B inner로 재사용되므로 독립적인 새 검증이 아니다.

기본 구성은 독립 Poisson, DC만, 감쇠만(180/365일), DC+감쇠(180/365일)의
6개다. 각각 시장 비중 0/.25/.5/.75/1을 적용해 30개×2 fold를 평가했다.
ridge=10은 이전 노출된 연구에서 가져온 고정값이다. 각 계열과 전체의
선택 기준은 **inner HDA log loss**이며 outer ROI로 선택하지 않았다.
시장 비중 1에서의 같은 점수는 ID 순서로 처리해 특정 계열의 승리로
해석하지 않는다. 선택된 기본 모델의 raw 확률도 진단용으로 보존했다.

## 수학·안전 검증

감쇠 가중치를 학습 경기 수 n으로 정규화해 우도 총가중치와 ridge의
상대 크기를 비교 간에 유지했다. DC는 기존 네 저득점 셀의 `log(tau)`를
우도에 포함하고 공격·수비·홈 효과·ρ를 함께 적합한다. 경기 후 임의의
무승부 배율을 붙인 방식이 아니다.

각 최적화 단계에서 팀 효과의 극값으로 가능한 홈·원정 득점률 상한을
구하고, 그 상한 전체에서 τ가 양수가 되도록 ρ를 매개화했다. 중립 신규
팀 효과도 이 범위에 포함된다. 이 보수적 경계 자체의 미분도 목적함수
gradient에 반영했다. 관측된 경기쌍에만 제약을 두는 적합보다 ρ가 더 제한될
수 있다는 차이는 남는다.

모든 최적화가 수렴했고 실제 최소 τ는 양수였다. 다음 값은 outer용 재적합
ρ이며, 감쇠 모델의 유효 표본 수는 원래 경기 수보다 줄어든다.

| Outer | DC D1 / SP1 ρ | DC+180일 D1 / SP1 ρ | 180일 유효 n D1 / SP1 |
| --- | --- | --- | --- |
| 2023/24 | -.138678 / -.048474 | -.174432 / .044789 | 446.2 / 550.6 |
| 2024/25 | -.137094 / -.051439 | -.165709 / -.014952 | 458.7 / 571.6 |

감쇠 없는 유효 n은 각각 1,224/1,520 및 1,530/1,900이다. 득점 지원은
최소 0..40, Poisson 꼬리 기준으로 확장하며 실제 자료에서는 40이었다.
CDF 합산으로 quadratic tensor 할당을 피했고, 네 저득점 셀의 확률 변화만
H/D/A에 더했다. 정규화와 잘린 전체 확률질량을 함께 검증한다.

## 재현·한계

```powershell
python -m pytest tests/test_local_dc_incremental.py -q
python scripts/local_dc_incremental.py
```

최종 관련 테스트 14개가 통과했다. 양·음 ρ의 해석적 gradient와 수치 미분,
기존 독립 모델 동일성, 극단/신규 팀 τ 양수, CDF와 작은 tensor의 동등성,
질량 정규화, 감쇠 가중치 총합, 미래 결과 불변성·7일 가드, 누락 배당 날짜와
원장, LF·POSIX provenance를 확인했다. 프로토콜 Git 조회는 단위 테스트에서
mock하고 최종 artifact 해시는 실제 파일로 검사해 squash CI와 구분했다.

[Dixon & Coles (1997) 공식 출판사 초록](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/1467-9876.00065)은
Poisson 회귀와 팀 전력의 시간 변화, 최대우도 접근을 설명한다. 이번 ridge,
보수적인 ρ 경계, 고정 반감기 격자, 확률 단계의 시장 혼합은 명시적인 구현
차이다. 원논문의 당시 수익 사례를 이번 실험이나 현재 서비스의 수익으로
옮겨 주장할 수 없다.

배당은 공개 B365 기록으로 실제 의사결정 시점 가용성·체결·세금·수수료·취소·
반올림·티켓 의존성을 검증하지 않았다. 자료는 이미 노출됐고 이 비교도
탐색적 회고 실험이다. 오래된 아이디어의 신규 발명, 새로운 holdout,
실제 Proto 수익, 운영 배포 효과 중 어느 것도 입증한 결과가 아니다.
