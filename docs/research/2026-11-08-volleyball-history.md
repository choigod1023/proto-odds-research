# 배구 리시브 이력 수집과 VNL 회고 실험

추가 조사에서 KOVO 일반 팬 사이트의 일정 경로를 찾아 2025–26 정규리그 252경기와 공개 결과 원문을 연결했다. KOVO 남 63·여 62경기의 회고 평가에서 리시브 후보는 확률을 바꿨지만 선택은 바꾸지 않았다. 아래 VNL 대체 실험은 별도로 보존한다.

## 수집 경로와 제한

KOVO DB Bank의 `/robots.txt`는 HTTP 200이지만 본문은 `Not Found` HTML이고 루트는 로그인 화면이다. 처음에는 공개 경기 목록을 찾지 못해 추정 PID를 순회하지 않았다. 이후 일반 팬 사이트의 공개 일정으로 별도 결과 URL을 확인했으며 아래 추가 조사에 기록한다. 메인 `kovo.co.kr/robots.txt`도 robots 문서 대신 사이트 HTML을 반환한다. 별도 [SportQuanta V리그 API 문서](https://docs.sportquanta.com/ko/api/volleyball/)는 경기·세트·팀 기록을 설명하지만 인증 없는 실제 요청은 401이었다. 인증이나 차단을 우회하지 않았다. 접근 점검 시각·상태·해시는 `access-check.json`에 있다. 이전 PR #660의 수동 공식 표본 3건은 연속 이력이 아니다.

대체 원천은 [공개 VNL 저장소](https://github.com/volleyballdataroom/VNL)의 2025·2026 남녀 팀 CSV 네 개이며 공식 기록 원문으로 독립 인증된 자료가 아니다. 각각 1회 요청했고 성공 4/4, 응답 해시·수신 시각·크기는 `summary.json`의 `source_files`에 기록했다. `collect.py`는 제한된 네 URL만 순차 요청하고 2초 지연, 429/서버 오류 backoff, 실패 상태·체크포인트·해시 검증 재개를 지원한다. 403/404는 중단 상태로 남긴다. 원본 파일은 `C:/Users/user/.codex/visualizations/2026/11/08/01a1b9e6-33f0-7b92-895d-2849b37ebce2/vnl-history-20261108e/`에 저장했으며 커밋하지 않았다. GitHub API 라이선스 조회는 404여서 재배포 권한을 확인하지 못했다.

파일에는 양 팀의 경기번호·팀·상대·날짜·세트 승수, 세트별 점수 및 리시브 성공·시도가 있다. 남자 2026 파일은 날짜가 Excel 일련번호이고 첫 세트행 번호가 전체 합계를 뜻해 나머지 세트 합계와 정확히 맞는 경우만 처리했다. 팀 쌍·상대·날짜·승패·리시브 수치를 대조한 유효 경기는 2025 남/여 각 116, 2026 남 116·여 114경기다. 2026 여자 2경기는 총계 불일치 또는 유효하지 않은 통계로 제외했다. 원천 출처, 정확한 경기 종료 및 결과 공개 시점, 취소·환불의 완전성은 미인증이다.

보존 가격 자료와 리그·날짜·양 팀 별칭·결과를 정확히 맞췄다. 시간대·실제 배당 수신·집행 가능성 및 상품별 정산은 미인증이고, 날짜가 다른 일치 후보는 추측해 합치지 않았다. 2026 가격 행은 남 106·여 110이다. 남자는 미일치/모호 56, 이력 부족 2, 평가 가능 48이고, 여자는 미일치/모호 26, 이력 부족 3, 평가 가능 81이다. 각각 전체 가격행 대비 coverage 45.28%, 73.64%다. 누락 경기가 결과를 바꿀 수 있다. 동일 상품 2-way 정상 정산을 가정한 ROI이며 모의 지갑과 무관하다.

## 모델과 결과

사전 규약 `3f6b8836`은 리시브 성공/시도를 100회 가상 표본으로 0.5에 수축한 두 팀 차이를 시장 logit의 ridge 잔차로 사용하는 후보 1개를 고정했다. 각 경기의 특징은 날짜가 최소 4일 이전인 경기만 사용하며 각 팀의 유효 경기 5건 이상을 요구한다. 당일 결과와 최종 시즌 통계를 피처에 넣지 않았다. 최초 규약의 7월 전 학습 가능 수가 남 0·여 6이라 2026 성과 계산 전에 `83e2cbcf`에서 2025년 시간순 약 80/20과 최소 20경기로 완화했다. 2025 남 27·여 26건 중 남 21/6, 여 21/5로 학습/검증하고 2025 전체를 재학습해 2026에 고정했다. 검증 날짜가 학습 날짜와 겹치지 않도록 경계일을 통째로 학습에 두는 정정을 최초 2026 계산 후 추가했지만, 최종 2026 계수는 두 경우 모두 같은 2025 전체를 사용해 변경되지 않았다. 검증으로 후보나 계수 범위를 고르지 않았다. 회귀 테스트는 네 날 지연과 미래값 변경 불변을 확인한다.

## 추가: KOVO 공식 일정과 결과 연결

일반 팬 사이트 `https://kovo.co.kr/KOVO`는 공개 JS `/assets/index-DVULM5Z7.js`를 불러오고 일정 화면은 API `GET https://user-api.kovo.co.kr/matches/001/seasons`, `/matches/001/seasons/022/leagues`, `/games/schedules?match=001&season=022&league=201`을 사용한다. 022는 2025–26, 201은 정규리그다. 마지막 호출은 남녀 각 126건 총 252건의 경기번호·날짜·성별·팀 ID·시작/종료·세트 승수를 반환했다. 이후 확인한 API 호스트 robots.txt는 `Disallow: /`이므로 **확인 직후 해당 API 호스트 자동 요청을 중단**했다. 이미 수신한 응답을 보존했고 API를 더 호출하지 않았다. robots 응답의 해시와 API 수신 영수증은 `kovo-receipts.json`에 있다. DB Bank의 별도 공개 결과 경로는 robots 주소가 Not Found HTML이고, 사용자 승인 범위에서 일정에 실제 기재된 번호만 사용해 2초 간격으로 호출했다. 로그인이나 차단 우회, PID 무차별 탐색은 하지 않았다. 이용약관과 재배포 권한은 별도 확인이 필요하다.

일정의 `022:201:경기번호`를 길이 12로 공백 채운 뒤 base64 역순으로 바꾸면 DB Bank 공개 결과 PID가 되며, 이미 독립 확인한 남자 120번 및 여자 153번과 일치한다. 252건 결과 원문 모두 수신했고, 별도 분석에서 공식 일정의 날짜·팀 이름·경기번호·시작 시각·세트 승수가 같은지 검사하여 **252/252 일치**했다. 원문 팀 합계는 공격·블로킹·리시브 효율 등이며 이번 피처는 리시브 효율이다. 경기번호만으로 남녀를 추정하지 않고 일정의 성별을 썼다. 252건 원문과 전체 일정 응답은 로컬 `C:/Users/user/.codex/visualizations/2026/11/08/01a1b9e6-33f0-7b92-895d-2849b37ebce2/kovo-public-20261108/`에 보존하고, `kovo-receipts.json`에 개별 원문 해시·수신 시각을 저장했다. 이 날짜의 수신은 과거 실시간 수신을 증명하지 않는다.

### KOVO 회고 모델

가격 자료를 날짜·리그·양 팀·결과로 연결했다. 2026년 가격행 남 63·여 62 모두 공식 일정·결과 및 최소 5경기 팀 이력과 연결됐다. 이 100%는 해당 시즌·기간에 보존된 가격행의 coverage이며 모든 프로토 판매 기회의 coverage가 아니다. 양방향 정상 정산 가정의 1단위 가상 ROI이며 당시 가격 관측·구매 가능성과 공식 상품 환불 규칙은 미인증이다. 2025년 가격행 남 63·여 64 중 이력 부족은 각각 21건, 적격 42·43건이다. 가격 중복 경기 키와 공식 경기번호 중복은 거부한다.

규약 `06b03093`에서 팀별 최근 최대 10경기 리시브 효율 차이와 시장 logit offset을 고정했고, 결과 확인 전 `898016da`에서 백분율 차이를 비율로 변환한 후 **학습 구간의 표준편차로만 나누는** 방법을 고정했다. 중심화하지 않아 차이가 0이면 시장 offset을 유지한다. 피처는 대상 경기보다 최소 4일 전의 공식 경기에 한정한다. 최초 결과를 본 뒤 검토에서 학습 정답에도 4일 지연이 필요함을 발견해 이를 추가했다. 이는 시간 누출 방지 수정이며 첫 결과를 본 후 적용했다는 점을 숨기지 않는다. 최종 2026 정답의 2025 학습 마감은 12월 28일이고 남 40·여 41경기다. 별도 검증용 학습은 남 30·여 31경기, 검증 각 9경기다. 예측 125건의 이력 경기번호를 독립 검사한 결과 4일 미만 참조 0건이고 공식 경기번호 125개는 모두 유일했다. 각 예측의 이력 경기번호는 `kovo-predictions.jsonl.gz`에 있다.

평균 배당은 남 1.366·여 1.327, MDD는 남 10.74·여 17.02 단위로 양 모델이 같다. 적중률·ROI 차이의 paired 95% CI는 0이다. LL 차이 CI는 남 [-0.00442, +0.00102], 여 [-0.00436, +0.02190]으로 모두 0을 포함한다. 학습 feature 표준편차와 계수는 남 0.05303·0.02650, 여 0.07308·0.06818이며, 최대 확률 변화는 각각 1.23%p·3.80%p다. 월별 결과와 지표는 `kovo-summary.json`에 있다. 표본·사전 수신 미인증의 한계에서 우열을 단정하지 않는다.

기존 VNL 모델의 학습 피처 표준편차는 남 0.06594·여 0.07702, 계수 0.00138·0.00408이며 최대 확률 변화는 각각 0.0042%p·0.0205%p였다. 원 단위와 강한 ridge가 변화량을 작게 만들었을 수 있어 리시브 정보가 무용하다는 증거로 해석하지 않는다. VNL 모델이나 결과는 바꾸지 않았다.
