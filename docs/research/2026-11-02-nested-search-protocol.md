# 넓은 모델·튜닝 탐색의 사전 계획

사용자 요청은 더 넓게 탐색해 적중률이 높은 설정/모델을 찾는 것이다. 유한 데이터에서
무한히 많은 설정의 최고값을 고르면 선택 과정도 과적합될 수 있으므로, 이번 작업은
아래 4,334개 정의를 시간 분리된 개발 구간에서 비교하고 이후 구간을 따로 평가한다.
이는 모든 가능한 모델의 전역 최적해라는 주장이 아니다. 무기한 프로세스·예약·자동
모델 승격을 만들지 않는다. 실제 운영·DB·원장·월 손실 5만원 한도는 그대로 둔다.

## 입력과 자료 수준

이전 연구의 검증된 K리그1 2024년 OOF 228행과 2025년 OOF 227행을 사용한다.
공식 과거 결과로 산출한 보조 특징은 각 대상 날짜보다 7일 앞선 완료 경기까지만 쓴다.
경기 전 선수·명단·픽스터 자료를 사용한 실험이라고 부르지 않는다. 실제 가격 수신과
실거래 가능성은 미검증이다. 해외 120행은 상품·배당 순서가 미검증이므로 제외를 유지한다.

2026년 국내 77경기는 이미 평가한 기간이다. 이 후보들의 설정 선택에 사용하지 않고
나중에 진단하되 독립 맹검이라고 주장하지 않는다. 2026-07-27~11-01의 추가 국내
가격은 메타데이터 감사로 적격 자료가 확인될 때만 별도 사용한다. 경기·상품·홈무원정
가격 순서·공식 종료 결과가 확인되지 않는 행은 제외한다. 새 가격이 없으면 부족하다고
보고하고 기존 77경기를 새로운 독립 표본이라고 소개하지 않는다.

## 특징과 시간 분리

- base 6차원: 시장과 DC의 log 확률 각각 3개.
- disagreement 11차원: base + 시장−DC 3개 + 가격 역수합−1 + 시장 엔트로피.
- form 23차원: disagreement + 각 팀의 인과적 최근 5경기 승/무/패 비율, 평균
  득점/3, 실점/3, min(휴식일,60)/60. 과거 경기가 없으면 비율과 득실점 0,
  휴식일 60으로 표시한다. 현재 경기 점수·정답·결과 ID를 특징에 넣지 않는다.

2025년을 개발 선택에 사용한다. 3개 시간 블록의 적중 수 합계를 최대화한다.
각 블록의 학습은 블록 시작보다 7일 이전 자료만 허용한다.

1. 2025-02-01~06-30: 2024년 이전 가용 행으로 학습.
2. 2025-07-01~08-31: 2025-06-24까지의 과거 행으로 학습.
3. 2025-09-01~11-30: 2025-08-25까지의 과거 행으로 학습.

시장/DC 자체는 기존 월별 인과적 OOF이며 앞선 블록 내 완료 경기에서 정보를 얻을
수 있다. 메타 모델은 블록 내 정답으로 다시 맞추지 않는다. 최종 후보는 2024~2025년
가용 개발 행으로만 학습하며 2026년 정답으로 설정을 고르거나 학습하지 않는다.
2026년의 인과적 팀 성적·DC 특징에는 해당 시점 이전 결과가 쓰일 수 있고 이 연구
가용성 가정과 최종 메타 모델의 학습 범위를 구분한다.

## 고정 탐색 공간

1. 잔차 이웃 3,360개: k=[10,20,30,45,60,90,120], prior=[10,30,60,120,240],
   공간=[시장,시장+DC,시장+DC+form12], 가중=[균등,1/(거리+.05)],
   반감기=[없음,30,90,180일], 보정 비중=[.25,.5,.75,1].
   유사도 가중합을 k로 맞춘 뒤 시간 가중치를 곱한다.
   q=시장+비중×sum(w×(one-hot 정답−과거시장))/(sum(w)+prior), 하한1e-6 뒤 정규화.
   form 공간의 표준화는 학습 자료로만 맞춘다. 해당 대상의 적격 과거가 k보다 적으면
   시장으로 명시적 대체하며 경기 수를 줄이지 않는다.
2. 로그 확률 혼합·편향 504개: 시장/DC 혼합 비중=[0,.1,.25,.5,.75,1],
   온도=[.75,1,1.25,1.5], 홈 편향=[−.15,−.1,−.05,0,.05,.1,.15],
   무승부 편향=[−.1,0,.1], 원정 편향=−홈−무승부.
3. 지도학습·시장 혼합 468개: 3특징군 × 26개 기본 설정 × 혼합 비중
   [0,.1,.25,.5,.75,1]. 로지스틱 C=[.01,.1,1,10]×class_weight=[없음,균형],
   RF depth=[2,4,없음]×leaf=[5,15], HGB leaves=[3,7,15]×L2=[0,10]×학습률=[.05,.1].
   RF tree64, HGB iter100/leaf15/early_stopping=False, seed20261102, 작업 스레드1.
4. 시장과 DC 2개를 기본 대조군으로 함께 선택 대상에 넣는다.

총 4,334개는 정의 수다. 시장 혼합 0 등 중복되는 예측이 존재하며 독립된 가설 수로
과장하지 않는다. 학습 모델의 예측은 세 클래스 열을 맞추고 양의 확률로 정규화한다.
전처리와 모델 상태는 학습 자료에만 맞춘다. 입력 크기가 제한돼 반복 학습 비용은
기본 설정별 캐시로 줄인다. 학습 실패/수렴 실패/잘못된 확률은 별도 기록하고 조용히
정상 후보로 취급하지 않는다. 실제 탐색 누락이 생기면 그 수와 이유를 보고한다.

## 선택·평가·산출물

개발 적중 수가 최대인 후보를 고르고 동률이면 개발 로그손실, 더 단순한 가족
(시장,DC,혼합,잔차이웃,로지스틱,RF,HGB), 마지막으로 고정 ID 순이다. ROI는 함께
보고하지만 개발 적중률 최고 후보를 몰래 ROI 최고 후보로 바꾸지 않는다. 이후
기간에서 가장 잘 나온 설정을 다시 선택하는 것은 금지한다.

개발 선택은 이후 정답 파일을 읽지 않는 단계로 분리한다. 선택 artifact와 후보 예측을
먼저 고정한 뒤 이후 구간의 정답을 연결한다. 전체 적격 경기 100% 선택, 같은 가격의
단위금액 단폴로 적중률·ROI·logloss·Brier·월별 손익·일 마감 최대낙폭·바뀐 픽·주 단위
쌍체 5,000회(seed20261102) 구간을 보고한다. 이는 실제 모의 지갑의 월중 중단 재생이
아니다. 이후 구간에서 이긴 관측만으로 현행 서비스 우세나 미래 수익을 인증하지 않는다.

원자료·코드·탐색 정의 해시, 모든 개발 trial 성적, 선정 설정, 실제 실행 수·시간,
실패/중복 수, 선택 전후 시간 경계와 한계를 보존한다. 미래/대상 정답 오염, 특징
허용 목록, 전처리 학습 범위, 중복 경기·가격 및 확률·Decimal 정산 검사를 실행한다.
새 외부 적격 자료가 없으면 독립적 채택 증거 부족을 유지한다.

참고: [Cawley·Talbot 2010](https://jmlr.org/papers/v11/cawley10a.html)은 유한 검증
점수를 최적화하는 모델 선택 자체의 과적합을 다룬다. 시간 순서 분리의 개념은
[scikit-learn TimeSeriesSplit 문서](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)를
참고하되 이번 블록은 위 달력 날짜로 직접 구성한다. 이 문헌이 스포츠 수익 개선을
보장하는 것은 아니다.
