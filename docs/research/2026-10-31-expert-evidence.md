# 작성자별 선택 자료 연결 및 시점 점검

기존 연구 입력을 재사용해 작성자·발행처·선택, 발표 주장시각, 저장 관측시각, 동일 상품의 가격·시장확률과 결과를 연결했다. 이 파일은 **회고용 자료 목록이며 경기 전 사용이나 모델 학습에 적격인 데이터가 아니다.** 결과는 `results.jsonl`에 분리했고 `features.jsonl`에 결과값은 없다. 원문 기사 전문은 복사하지 않았다. 새로운 자료 수집이나 성과 계산은 하지 않았다.

2025년 1경기·작성자 선택 1건, 2026년 445경기·선택 459건이다. 2026년은 KBO 199, NPB 110, MLB 112, K리그1 15, K리그2 9경기다. 이 445경기는 PR #433의 실제 투표 평가 445경기와 겹친다. 신규 홀드아웃이 아니다. 기존 446개 대상 전부가 연결됐고 결과도 별도 대조 446건 일치했다. 이 대조는 서로 연관된 저장 자료 사이의 일치이며 독립 정산 검증이 아니다. 기존 대상 자체가 이미 필터된 연구 코호트이므로 전체 발행처나 전체 경기의 모집단이 아니다.

대상·사례·프레임의 리그와 event ID, 원천 홈/원정 이름, 기존 identity bridge의 정규화 이름, 시간대 포함 시작시각, 승패 방향과 가격 벡터를 비교했다. 시장확률은 부동소수 표현 오차 1e-12 이내를 허용하고 가격은 정확히 대조했다. 종목 상품은 경기 전체 승패 또는 승무패이며 기준점은 null이다. 14경기에 회차가 다른 복수 상품이 보존돼 있어 사례의 연도·회차·경기번호와 정확히 같은 가격 벡터만 선택했다. 상품 ID는 저장 좌표로 만든 파생 키이며 독립 인증된 상품 ID는 아니다. 다른 회차를 같은 상품으로 합치지 않았다. 경기 전 판정은 발표 주장 ≤ 판정 ≤ 시작 30분 전인 작성자만 남긴다. 점수는 경기 식별에 사용하지 않고 연결 후 대조한다.

2026년 459건 모두 발표 *주장*이 판정 이전이고 `document_sha256` 121건 또는 `source_sha256` 338건의 해시 필드가 있다. 그러나 저장된 관측은 모두 판정 이후이며 해당 관측이 최초 수신이라는 사실은 입증되지 않았다. 독립 수신 인증 0건, 원문을 다시 읽어 확인한 해시 0건, 판정 이전 가격 관측이 인증된 경기 0건이다. 따라서 인증된 수신과 가격을 모두 요구하는 전향 입력은 **0경기**다. 발행처가 주장한 과거 게시시각과 현재 저장된 관측을 혼동하지 않으며 해시가 있다는 사실만으로 진위를 증명하지 않는다. `first_received_at`은 미확보로 null이다.

2026년에는 6개 발행처, 발행처별 이름을 구분한 11개 작성자 키 중 10개가 두 경기 이상 등장했다(90.9%). 459행 중 458행(99.8%)이 반복 작성자에 속한다. 두 발행처 이상이 등장한 경기는 14개다. 같은 경기·발행처·작성자 중복 행은 0개다. 같은 종류의 해시가 반복되는 행은 256개이고 고유 해시 값은 263개다. 이는 한 문서가 여러 경기를 다룬 경우 등을 포함하며 독립 확인된 복제 수가 아니다. 같은 경기 안에서 같은 종류의 해시가 반복된 행은 0개다. 같은 선택이라는 이유로 문서나 작성자를 복제로 간주하지 않았다. 2025년 1경기는 작성자 1명·발행처 1개, 반복 0이며 해시 필드는 있으나 검증되지 않았다.

`audit.json`은 연도별 분할과 원본 파일 해시를 기록한다. 원본은 PR #433 `targets.jsonl.gz`, 출처 provenance의 `votes.jsonl.gz`, `cases.jsonl.gz`이며 `prepare.py`에 경로를 인자로 전달해 재생성한다. 각 해시는 입력 압축파일의 바이트 SHA256이다. `document_sha256`과 `source_sha256`은 원본에서 주장된 종류를 구분해 보존하고 이 작업에서 독립 검증하지 않았다. 작성자 키는 발행처와 원문 작성자 문자열 조합이며 동명이인·별칭·사이트 간 동일인 여부는 미확인이다. 저장 가격이 과거 그 시각에 실제로 구매 가능했는지도 미확인이다. 최초 수신, 실시간 가격과 외부 증거를 앞으로 별도 확보해야 한다.
