# PR #433 독립 검토: 저장 자료의 검산과 시점 경계

2026-10-30. 검토 대상 `0ed675a0e7ee53d75691d071b41739099edb1a65`, 이 작업의 기준 main `f5d4ff541d63c6855a9d7deaa0b97df41e2a9681`. [PR #433](https://github.com/choigod1023/proto-odds-research/pull/433)은 반복 열람된 회고 연구이며 운영 실적이나 독립 블라인드 시험이 아니다.

## 확인된 문제

`prepare.py:70-79`는 원천의 게시 주장 시각을 경기 시작과만 비교한다. 따라서 게시 주장 10:15, 판정 10:00, 경기 시작 10:30인 기록은 해당 게시 시각 검사에서 통과해 판정 시점보다 늦은 의견을 사용할 수 있다. `late-publication-fixture.json`과 테스트에 재현을 보존했다. 최소 수정 제안은 각 원천 주장 시각을 `decision_at` 이하로 추가 제한하고 실제 최초 수신은 별도 필수 조건으로 검증하는 것이다. 게시 주장만으로 수신을 증명해서는 안 된다. 원본은 수정하지 않았다.

다만 보존된 2026년 실제투표 445경기에서는 이 조건을 위반한 게시 주장이 0건이었으므로 이 결함의 현재 표본 적중률·ROI 영향은 **0으로 관측**됐다. 445경기는 모두 실제 경기 전 수신의 외부 인증이 없어 전향 자료라고 판정할 수 없다. 결과 및 가격의 실제 수신 시각도 검증되지 않았다.

## 독립 정산 검산

원 모델 함수를 호출하지 않는 `recheck.py`는 보존된 710개 정규화 원문 입력과 5,544개 저장 예측을 `(event_id, cohort)`로 연결해 경기·팀·결정 시각·선택지·배당·결과를 대조하고, 별도 Decimal 원장으로 23,752개 선택의 적중과 손익을 재계산했다. 이는 독립 경기 수가 아니다. 리그·후보·방식별 1,400개 요약 항목의 최대 절대 오차는 0이고 불일치는 0이다. 별도로 상위 정규화 cases와 710개 표본의 ID 및 경기 시각·선택지·가격·결과·시장 확률을 비교해 누락/중복 및 필드 불일치가 각각 0이었다. 이 비교는 상위 자료의 실제 공식 원천이나 가격 집행 가능성을 인증하지 않는다. 투표 동률의 기권은 coverage에 반영했다. 기록의 주 표본은 이미 void가 제외돼 있어 취소 정산은 별도 검증하지 못했다.

2026년 실제투표 공통표본에서 선택된 outcome-static의 frozen 결과는 K리그1 7/15, ROI +4.80%; KBO 108/199, -12.17%; NPB 66/110, -3.42%; MLB 52/112, -23.30%다. 각 coverage는 해당 공통표본 안에서만 100%다. K리그2는 검증 23건으로 사전 하한 50건에 못 미쳐 미선택이다. K리그1은 15경기 모두 홈을 선택했고 홈 상수와 같다. NPB 시장 대비 같은 경기에서 모델만 적중 15, 시장만 적중 15이며 ROI 차이의 기존 주간 95% 구간은 -11.42%p~+18.94%p다. 이 구간은 독립 재계산이 아닌 원 연구 결과다. 순차 NPB는 57/110, ROI -15.23%다. 저장된 80개 비교 중 원 연구의 개선 판정은 0개다. 검산은 독립적인 새로운 성능 평가가 아니다.

## 설계 검토와 한계

- `model.py:24-27, 205-220`은 이력 날짜의 UTC 자정 +4일 뒤에만 결과를 사용한다. 이는 실제 결과 확정·수신 증거가 아니며 중단/재개 예외를 인증하지 않는다. `run.py:165-189`의 frozen은 2026 결과를 갱신하지 않고 prequential은 과거 가용 가정이 지난 결과만 갱신한다. 두 방식은 같은 표본이다.
- `run.py:165-207`은 2025 순차 로그손실과 사전 최소 표본으로 후보를 선택한다. 사전 프로토콜은 `0de1f67c`이며 2026 결과를 본 뒤 후보를 새로 선택한 증거는 확인하지 못했다. 검증은 저장된 기록과 코드 검토이며 독립 실행으로 전체 훈련을 재현하지 않았다.
- `model.py:30-38, 165-189`의 고유분해 루트와 7점 Gauss–Hermite 적분은 예측 선형 조합의 공분산을 사용한다. score 야구는 적분된 승·무·패에서 무승부를 제외한 조건부 확률이다. 수학적 구현 검토이지 모든 근사의 정확도나 동적 상태 보정을 독립 증명한 것은 아니다.
- `run.py:80-108, 214-225`는 동일 경기 쌍체 주간 구간과 불일치 경기 단측 이항검정을 구분하고 80개 p값에 Holm 보정한다. 주간 구간은 시간 의존을 완전히 제거하지 않고, 이항검정의 경기 독립 가정과 회고 자료의 반복 열람은 남는다. 이 검토에서 구간과 p값을 독립 재계산하지 않았다.
- 실제투표와 `historical_market_proxy`를 별도 집계하고, 9:1은 과거 혼합 대조군이다. 이는 현재 운영 동결 예측을 재생한 것이 아니다. 공통 경기·동일 가격은 입력 내 일치로만 확인했다. `prepare.py`는 팀명 브리지와 기존 정규화에 의존하며 더블헤더 누락 가능성과 원천 단계의 오류는 남는다.
- 기준 main의 `src/ai_decision.py`에는 시장 fallback이 있으나 `docs/PRODUCTION_CONTRACT.md`의 2026-10-28 조항은 무투표 시 보류라고 적어 서로 맞지 않는다. #435 이후 코드와 오래된 문구의 차이로, 서버 배포 버전은 확인하지 않았다. 운영 정책을 이 검토에서 변경하지 않는다.

## 잠정 인터페이스 검토

`provisional-v0`는 게시 주장과 최초/수정 수신, 판정, 결과 확정을 구분하고 외부 증인 없는 인증을 금지한다. 이 방향은 유효하나 현재 PR433 입력은 실제 수신 시각·전체 상품 ID·원천 raw hash·독립 정산 원본을 갖추지 못해 이를 충족하지 않는다. 전향 사용 전에는 timestamp의 timezone과 순서, 수정별 불변 raw hash, 정식 경기 및 상품/line/정산 범위의 유일성, void와 누락의 차이, append-only 동결 해시의 정규화 규칙을 기계적으로 검증할 필요가 있다. 정책상 잠정 브리지이며 총괄 승인 전 다른 워커가 스키마를 전환하면 안 된다.

적중률 향상이나 운영 반영의 근거는 확인되지 않았다. 가격·시점이 인증된 독립 전향 자료와 정산 연결이 다음 의존성이다. 저장된 입력의 정합성 검산은 원천 수집 시점, 전체 모집단 coverage, 미래 수익 또는 운영 배포를 증명하지 않는다.
