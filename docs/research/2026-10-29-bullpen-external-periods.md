# 불펜 후보의 새 경기·다른 리그 검증

**이전 MLB 116경기의 한 경기 개선은 새 경기에서 재현되지 않았다.** 기존 계수 그대로 새로운230경기에 적용하면 시장 단독 대비 적중률53.91%→53.48%, ROI -16.85%→-17.57%로 소폭 악화됐다. KBO의 별도 공통 입력 후보는198경기에서 순손익300원 차이뿐이었고, NPB는115경기에서 적중2건·순손익32,900원 개선이 있었지만7월 이후에는 추가 개선이0건이었다. 이번 결과로 운영 모형을 교체하지 않는다.

## 서로 다른 검사를 구분한다

1. **MLB 동결 후보 검사:** [PR #408](https://github.com/choigod1023/proto-odds-research/pull/408)의 `bullpen:l1` 계수·스케일을 그대로 사용했다. 2024년에 학습한 투구 수·연투·과거 세이브/홀드 상위3명 사용·K-BB의5변수다. 기존116경기를 모두 제외한 새230경기에 적용했다. 새 경기의 픽스터가 없어 **시장 단독 대비**이며 독립적인9:1 비교가 아니다.
2. **KBO·NPB 공통 입력 후보:** 동일 자료를 확보하지 못한 항목이 있어 MLB와 같은 모형이라고 부르지 않는다. 전일/3일 구원 아웃 수, 이틀 연속 등판 인원, 과거28일 구원 아웃 수 상위3명의 전일 사용, 아웃 수당K-BB로 별도 학습했다. 원래 MLB의 투구 수·세이브/홀드·실제BF와 다른 정의다. 같은 경기의 비교용9:1과 대조했다.

9:1은 시장90%+픽스터10% 산식이며 현재 운영 투표 모델 전체의 동결 재현이 아니다. ROI는 단폴1건1만원 동일 금액·월 손실 한도 없이 계산한 과거 실현 수익률이다. 실제 매수·체결 또는 미래 기대수익률을 뜻하지 않는다.

## 실제로 확장한 자료

- NPB 공식2024년877경기,2026년9월16일까지777경기의 박스스코어를 새로 수집했다. 기존2023년 공식 복원본876경기도 재사용했다. 수집한907/816개 URL 중 각각30/39개는 공식 종료 상태가 아니어서 제외했다.
- NPB의 `0+`, `5+` 투구 이닝 표기 때문에 생긴 누락을 수정하고 실패한 경기를 다시 수집했다. 완료 아웃 수는 각각0,15개로 처리한다. 이름이 같아도 공식 선수 URL의ID로 구별하고 투수 표의 소속 팀을 표 순서 대신 팀 제목으로 확인한다.
- KBO는 보유 Naver 투수 기록을 재사용했다. 2023년724·2024년728·2025년733·2026년471경기를 정규시즌 개막 이후 자료로 정리했다. 원천 선수ID로 구별하고 더블헤더 등판은 gameId로 따로 보존한다. `bf`를 실제 상대 타자 수로 간주하지 않는다.
- KBO38경기는 고유한 날짜·팀 조합의 별도 점수 원장과 연결되지 않아 원천 내부의 양 팀 투수 실점 합계 검산으로 보존했다. 별도 점수와 모순된20경기, 개막 전208경기는 제외했다. 따라서 KBO 과거 자료 전체를 독립적인 공식 원장과 모두 대조했다고 주장하지 않는다.
- 최종 과거 투수 경기 자료는 KBO2,656+NPB2,530=5,186경기다. 양 팀 투수 실점 합계와 저장 점수를 대조했다.

KBO 보유 상세 기록은2026-07-26에서 끝났다. 누락된 기록을 ‘불펜이 쉬었다’고 계산하지 않도록 과거28일에 알려진 경기 중 투수 기록이 빠진 대상은 학습·검증·평가 모두에서 제외했다. 평가203경기 중5경기가 제외돼198경기를 비교했다. Naver 일정 및 유효 경기ID의 기록 조회에서 읽기 시간 초과가 발생했고, 시험한 KBO 사이트 주소의 HTML 응답도 투수 기록의 대체 자료로 사용할 수 없었다. 원인 차단 여부는 확정하지 않는다. 요청 결과는 `kbo-source-probes.json`, `kbo-valid-source-probes.json`에 남겼다.

## MLB 새230경기

2026-07-26~08-23 보존 시계열에서 경기 전 승패2자 시장만 사용했다. 다음 조건을 고정했다.

- 공식 일정의 팀·날짜·예정 시각±15분에 고유하게 연결돼야 한다.
- 최근24시간 안의 마지막 관측이며 예정 시작과 실제 첫 투구보다10분 이상 빨라야 한다.
- 같은 시각 가격이 여러 개로 충돌하는41경기는 제외한다.
- 기존116경기는 전부 제외한다. 과거 불펜 입력은 **해당 가격 관측 시각까지 끝난 경기**만 사용한다.
- 기존2026년115경기의 불펜5변수를 별도 코드로 재계산해 원래 정의와 최대 오차0으로 일치시킨 뒤 확장했다.

과거 경기 완료 경계는 공식 실제 첫 투구+경기 시간+지연 시간+안전 여유60분이다. 재개 표시·필수 시간 누락은 제외한다. 이 경계의 한계와 원천 소급 정정 가능성은 이전 연구와 같으며, 전체 시점의 완벽한 보증은 아니다.

‘새230경기’는 기존116경기에서 제외되어 이번 동결 후보를 새로 적용한 집합이라는 뜻이다. 보존 시계열 자체는 다른 연구에 쓰였을 수 있으므로 모든 연구에서 미열람한 홀드아웃이라고 주장하지 않는다.

| 구간 | 건수 | 시장 적중률 → 동결 후보 | 시장 ROI → 동결 후보 | 선택 변경 |
|---|---:|---:|---:|---:|
| 전체 | 230 | 53.91% → 53.48% | -16.85% → -17.57% | 5 |
| 8월10일 이전 | 100 | 52.00% → 52.00% | -19.19% → -19.11% | 2 |
| 8월10일 이후 | 130 | 55.38% → 54.62% | -15.05% → -16.38% | 3 |

총230만원 투입 가정에서 시장은 -387,600원, 후보는 -404,000원으로16,400원 더 손실이다. 일말 최대낙폭은446,200원→445,200원으로1,000원 작아졌지만, 적중률·최종 수익이 더 나빠 우위로 보지 않는다. 최대낙폭은 일별 합산 잔액 기준이며 실제 경기별 정산 순서까지 재현한 수치가 아니다.

관측 주는4개뿐이다. 주 단위 paired bootstrap의 ROI 차이95%구간은 약 -3.53~+1.82%p로0을 포함하고 주 수도 적다. 초기 한 경기 개선을 일반적인 추가 수익으로 확대하지 않는다. 시장과의 비교이므로 ‘새230경기에서9:1보다 나빴다’로 표현해서도 안 된다.

## KBO·NPB 선택·기간 고정

리그별2023년 가격 연결 경기로 학습하고2024년에서 적중률→Brier→이름 순으로 선택했다. 후보는 업무량4변수/업무량+품질5변수×정규화0.01/0.1/1와 추가 효과 없는 시장 기준, 각7개다. 이후2023+2024로 재학습하고2026년 평가에 적용했다. 7월1일 전후 경계와 후보 집합은 결과 확인 전에 고정했다.

| 리그 | 2023 학습 | 2024 선택 | 2026 평가 | 검증에서 선택된 후보 |
|---|---:|---:|---:|---|
| KBO | 710 | 712 | 198/203 | 업무량+품질, 정규화1 |
| NPB | 819 | 809 | 115/115 | 업무량+품질, 정규화0.01 |

같은 날짜·팀 조합의 여러 가격/경기, 모순된 점수, 과거28일의 알려진 경기 기록 누락은 제외했다. KBO/NPB는 엄격하게 **이전 날짜**의 기록만 쓰는 일자 기준 회고 분석이다. 과거 게시·기록 정정·당시 매수의 정확한 시각까지 인증한 자료는 아니다. 현재 경기의 실제 선발·투수 기록을 입력으로 쓴 것도 아니다.

평가 집합은 이전 연구에서도 사용했다. 새 선수 자료를 연결했어도 새 미열람 미래 검증으로 부르지 않는다. 누락 때문에 표본이 줄었을 때 전체203건의 기존 수익과198건의 새 수익을 비교하지 않고 동일198건의 기준을 재계산했다.

| 리그·구간 | 건수 | 9:1 적중률 → 새 후보 | 9:1 ROI → 새 후보 | 선택 변경 |
|---|---:|---:|---:|---:|
| KBO 전체 | 198 | 60.10% → 60.10% | -7.40% → -7.39% | 2 |
| KBO 7월 이전 | 152 | 60.53% → 59.87% | -6.90% → -7.94% | 1 |
| KBO 7월 이후 | 46 | 58.70% → 60.87% | -9.07% → -5.57% | 1 |
| NPB 전체 | 115 | 58.26% → 60.00% | -9.97% → -7.11% | 8 |
| NPB 7월 이전 | 88 | 57.95% → 60.23% | -10.08% → -6.34% | 8 |
| NPB 7월 이후 | 27 | 59.26% → 59.26% | -9.63% → -9.63% | 0 |

KBO는119적중으로 동일하고, 총198만원 투입 가정에서 -146,600원→-146,300원이다. 앞 기간에서 틀린 선택 변경1건과 뒤 기간에서 맞힌1건이 상쇄됐다. 일말 최대낙폭157,700원도 같다. 의미 있는 개선으로 보기 어렵다.

NPB는67→69적중, 총115만원에서 -114,700원→-81,800원으로32,900원 손실이 줄었다. 일말 최대낙폭은176,600원→155,100원이었다. 하지만8번의 선택 변경이 모두7월 이전에 몰렸고 뒤27경기에서는 차이가 없다. ROI 차이의 주 단위 bootstrap95%구간도 약 -5.53~+11.49%p로0을 포함한다. NPB는 후속 후보로 보존할 수 있지만, 지속적인 우위나 흑자를 입증한 상태가 아니다.

## 판단

- 기존 MLB 후보는 새 경기에서 적중률·ROI 개선이 유지되지 않았다. 이 후보를 운영에 추가할 근거가 부족하다.
- KBO 별도 후보의300원 차이는 채택 근거가 아니다.
- NPB 별도 후보는 손실 감소와 일말 낙폭 개선이 관측됐지만 다른 기간에서 개선이 반복되지 않았다. 운영 전환 없이 후속 검증 대상으로 남긴다.

모든 후보의 전체 ROI는 여전히 음수다. 결과를 보고 정규화·구간·리그를 바꿔 다시 우승 후보를 만들지 않았다. 다른 모형이 불펜 정보에서 이익을 얻을 가능성까지 부정한 것은 아니지만, 이번 후보의 검증 결과를 긍정적으로 포장하지 않는다. 운영 코드·DB·추천 정책·배포 변경은 없다.

## 재현과 검증

`experiments/baseball-bullpen-external-periods-20261029/`에 새 평가 경기·선택 가격·모형·원자료·정규화 과거 기록·원천 실패 사유·해시를 저장했다. 저장된 자료만으로 모형을 다시 실행할 수 있다.

```powershell
python -X utf8 scripts/build_asian_bullpen_features.py --output experiments/baseball-bullpen-external-periods-20261029 --replay
python -X utf8 scripts/backtest_bullpen_external.py --folder experiments/baseball-bullpen-external-periods-20261029
python -X utf8 scripts/verify_bullpen_external.py --folder experiments/baseball-bullpen-external-periods-20261029
python -m pytest tests/test_bullpen_external.py -q
python -m pytest -q
```

신규19건과 전체1,581건·93 subtests 통과,5건 skip. 독립 검증기는 학습 함수를 호출하지 않고543개 평가 행,13,381개 계수 기반 확률,46개 정산을 대조했다. 원자료에서 공통 특징16,815개와 MLB 특징1,150개도 다시 계산하고,5,186경기의 양 팀 투수 실점 합계를 검산했다. 자체 저장 입력으로 특징을 재생했을 때 SHA256도 같았다.
