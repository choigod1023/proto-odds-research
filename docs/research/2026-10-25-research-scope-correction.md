# 2026-10-25 연구 범위 정정 및 미완료 작업

## 사용자 요청과 실제 실행의 차이

사용자는 앞선 픽스터 연구를 포함하여 종목별로 픽스터 단독·기존 모델 단독·하이브리드를 비교하고, 혼합 비중과 픽 선정까지 평가하기를 요청했다.

PR #364에서 실제 실행한 것은 시장확률·과거 팀 전력·최근 성적·확률 보정·부스팅·시장과의 혼합을 비교한 연구다. 종목별 37개 탐색 모델, 4개 선택 규칙, 주 2/3회 설정으로 총 1,184개 구성을 검사했다. 대규모 아카이브와 경기 전 시점으로 연결한 픽스터 입력은 사용하지 않았다.

따라서 이 연구는 요청한 픽스터 비교의 완료가 아니다. 실제 계산 결과가 존재하더라도, 다른 질문에 답하는 실험을 요청의 완료로 보고한 것은 잘못이다.

## 이 결과로 판단하면 안 되는 것

- 픽스터 75:25 하이브리드의 효과나 채택 여부.
- 모든 픽스터 사이트·종목·과거 경기를 수집하고 사용했다는 주장.
- 현재 운영 서버가 어떤 픽스터 입력과 모델을 실제 사용하는지.
- 과거 ROI가 미래 기대수익 또는 사용자의 실제 수익으로 재현된다는 주장.

이 실험의 혼합 비중은 학습 모델과 시장확률의 비중이다. 픽스터와 자체 모델의 혼합 비중이 아니다.
`existing_research_reference`는 같은 자료로 재학습한 기존 연구 대조군이며, 동결된 운영 예측을 재생한 것이 아니다.
2025년은 과거 연구에서도 사용했다. 배당 관측 시각·실제 구매 가능성·정확한 종료 시각도 검증하지 못했다.

결과를 삭제하거나 다른 입력을 사용한 것처럼 변경하지 않는다. PR 병합은 위 범위의 연구 기록을 보존하는 작업이며, 수익 모델의 운영 채택이나 배포를 뜻하지 않는다.

## 여전히 해야 하는 비교

1. 확보한 픽스터 자료의 사이트·작성자·게시 시각·수집 시각·대상 경기·추천 방향을 조사한다. 과거 실험의 요약 수치만으로 전체 수집 여부를 추정하지 않는다.
2. 경기 전 증거가 있는 자료와 사후 회고 자료를 분리하고, 누락·중복·연결 실패의 사유와 건수를 남긴다.
3. 동일 경기·동일 배당·동일 결과·동일 정산 규칙으로 자체 모델, 픽스터 단독, 하이브리드를 나란히 비교한다. 모델 확률 및 픽스터 집계 정의도 고정한다.
4. 혼합 비중과 픽 선정 규칙은 평가 구간을 보기 전에 선택한다. 종목별 표본 부족은 부족으로 보고한다.
5. 장당 1만 원·2폴·주 2/3회·월 순손실 5만 원 제한을 동일하게 적용하고, 누적 손익·ROI·수익 월·최대 낙폭·미정산 노출을 함께 보고한다.

위 작업은 이 정정 문서를 저장하거나 #364를 병합하는 것만으로 완료되지 않는다.
