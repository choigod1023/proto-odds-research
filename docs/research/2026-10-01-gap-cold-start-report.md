# GAP 초기 평점·초반 적응 검증

## 판단

리그 평균으로 초기화하면 슈팅 예측은 개선됐다. 그러나 승무패와 2경기 조합의
수익 개선으로 이어진다는 근거는 부족하다. 운영 추천에는 반영하지 않는다.
이 결과는 이미 여러 번 분석한 과거 자료의 후속 탐색이며, 새로운 holdout이나
실제 Proto 체결 수익, 앞으로 기대해도 되는 수익률이 아니다.

내부 검증 log loss로 사전에 고른 최종 경로의 최고확률 2경기 조합은
306장 중 115장 적중, ROI **−8.1591%**다. 기존 GAP는 같은 306장 중 118장,
**−5.7641%**였다. 차이는 −2.3950%p이며 ISO 주 단위 paired bootstrap
95% 구간은 [−5.4880, 0.0000]%p다. 순수 Shin의 −8.6633% 대비 차이 구간도
[−2.7671, +3.9954]%p여서 우위를 입증하지 못한다.

## 자료와 실행 기준

- 독일 D1·스페인 SP1, 2019/20–2024/25, pinned CSV 12개, 총 4,116경기.
- 외부 평가 2023/24·2024/25 각각 686경기, 합계 1,372경기. 평가 배당 결측 없음.
- 2019–21 학습/2022 내부 선택/2023 평가와 2019–22 학습/2023 내부 선택/2024 평가.
- 경기 통계는 경기일 +7일부터 사용. 학습 결과도 평가 시작 7일 전까지만 사용.
- 처음 관측한 팀의 0 또는 과거 리그 평균 초기화 × 일정 속도 또는 첫 6회 빠른 적응.
- 계열별 alpha {.05,.10,.20} × phi {.50,.80}, 총 48개 내부 후보, 실제 리그별 적합 116회.
- 기존 GAP가 선택한 파라미터를 고정한 비교와 계열별 재선택을 함께 보존했다.
- 프로토콜을 `e2f608dc`에 먼저 커밋했다. 원천·코드·프로토콜·이전 결과 해시를 JSON에 저장했다.

최초 관측 시점의 공개된 유효 통계 쌍으로 리그 홈 평균 h, 원정 평균 a를 계산해
[홈공격, 홈수비, 원정공격, 원정수비]를 [h,a,a,h]로 초기화한다. 과거가 없으면 0이다.
복귀 팀의 상태는 유지한다. 첫 6회 유효 갱신에만 max(alpha,.2)를 쓰고 이후 원래
alpha를 쓴다. 두 통계의 결측·유효 횟수는 별도로 처리한다.

실제 승격 명단이 없으므로 entrant는 시즌 첫 등장 당시 직전 시즌 관측이 없던 팀이다.
시즌별 표시를 그때 고정하며 실제 승격과 같은 뜻이 아니다. cold는 최소 한 팀·통계가
6회 미만 갱신된 경기다. 두 그룹은 겹칠 수 있고 other는 둘 다 아닌 경기다.
외부 평가의 cold는 20·12경기, entrant는 각 174경기, other는 각 512경기다.

## 슈팅 예측: 초기값의 효과는 확인

기존 파라미터를 고정하고 초기값만 0→과거 평균으로 바꾼 MSE다.
순서는 홈 총슈팅/원정 총슈팅/홈 유효슈팅/원정 유효슈팅이며 낮을수록 좋다.

- 2023/24 전체: **37.374→27.060 / 23.515→19.844 / 7.925→6.556 / 4.832→4.584**.
- 2024/25 전체: **26.916→25.580 / 19.790→18.747 / 5.620→5.476 / 4.631→4.451**.
- 2023/24 cold 20경기: **107.936→31.809 / 54.651→27.015 / 24.706→9.913 / 9.427→7.152**.
- 2024/25 cold 12경기: **48.983→22.185 / 38.125→13.048 / 10.573→7.230 / 13.618→7.729**.

전체 8개 통계·시즌 비교에서 오차가 줄었다. 평균 초기화 모델은 전체 평가에서
학습기간 단순 평균 예측보다도 8개 MSE가 모두 낮았다. 다만 cold 표본은 총 32경기로
작다. 이는 이 자료의 오차 비교이지 일반적인 유의성 검정 결과가 아니다.
모든 계열·그룹의 MAE/MSE와 경기별 예측은 결과 JSON에 남겼다.

2024 평가의 기존 alpha=.2에서는 빠른 적응의 max(.2,.2)가 동일하므로
zero_fast=zero_constant, prior_fast=prior_constant가 된다. 이 동등성을 개선 효과로 세지 않는다.

## 수익: 좋은 통계 예측이 더 좋은 조합을 보장하지 않음

모든 정책은 리그/날짜별 예산 1단위, 최대 한 장의 서로 다른 경기 2개 조합이다.
조건을 못 채우면 현금으로 남긴다. 정산은 B365 원배당 곱이며 Proto 반올림·세금·한도·체결은
재현하지 않는다. 실제 공동 결과로 정산했지만 경기 독립성이나 확률 곱의 정확성을 입증한 것은 아니다.

최고확률 조합의 306장 표본에서:

- 기존 GAP: 118적중, 적중률 38.5621%, ROI −5.7641%.
- 파라미터 고정·평균 초기화만: 119적중, 38.8889%, ROI −4.6334%.
- 파라미터 고정·빠른 적응만: 117적중, 38.2353%, ROI −6.8181%.
- 파라미터 고정·둘 다: 118적중, 38.5621%, ROI −5.6874%.
- 계열별 재선택 후 평균 초기화: ROI −5.9603%; 빠른 적응: −6.8181%; 둘 다: −8.0824%.
- 전체 내부 선택 경로: 115적중, 37.5817%, ROI −8.1591%.

평균 초기화만 고정 비교한 +1.1307%p는 이익 차이 3.46단위다. 조합이 달라진 날은
8개이고, 실제 이익 차이는 **2024-01-20 한 날짜의 한 조합**에서 전부 발생했다.
차이 구간 [0.0000,+3.5306]%p의 하한이 0인 점과 작은 차이 표본을 함께 봐야 한다.
반복 가능한 우위로 판단하지 않는다.

확률 ≥60%, 배당 <2.20(1.50 미만 포함) 정책에서는 기존 GAP 88장/48적중/−1.1453%,
고정 평균 초기화 90장/50적중/**+1.7388%**, 전체 내부 선택 87장/47적중/−2.2074%다.
고정 평균 초기화의 ROI 자체 구간은 **[−20.1978,+24.1786]%**, 기존 GAP 대비 차이 구간은
[−1.8270,+8.6739]%p다. 2023/24 +24.7702%였지만 2024/25는 −18.4138%였다.
이 양수 하나만 골라 채택하면 사후 선택이다.

확률 ≥60%, 1.50≤배당<2.20 정책의 전체 내부 선택은 10장/4적중/−3.4390%다.
EV≥2%는 1장/0적중/−100%, EV≥5%는 베팅 0장이라 ROI를 정의하지 않는다.
후자는 수익률 0% 전략으로 표시하지 않는다. 모든 계열의 다섯 정책 원장을 보존했다.

승무패 log loss는 기존 .9565019, 고정 평균 초기화 .9564611,
전체 내부 선택 .9566191이다. 전체 내부 선택과 기존의 차이 구간은
[−.0003075,+.0005308]로 0을 포함한다. 정확도는 .5451895→.5473761로 소폭
올랐지만 조합 수익은 나빠졌다. 적중률·확률 오차·배당을 각각 구분해야 한다.

## 선택과 재현

2023 평가의 계열별 선택은 zero_constant(.05,.5), prior_constant(.2,.5),
zero_fast(.05,.5), prior_fast(.05,.5)이며 전체 승자는 zero_constant였다.
2024는 각각 (.2,.8),(.2,.8),(.2,.8),(.1,.8)이고 전체 승자는 prior_fast였다.
선택에는 해당 외부 평가 결과를 쓰지 않았다. 다만 실험 설계 자체가 이전 외부 결과를
본 뒤 이루어졌으므로 전체 절차를 완전히 미노출 검증이라고 부를 수 없다.

기존 zero_constant의 경기별 확률 최대 차이는 두 fold 모두 **0**이었다.
시간 경계·미래 정보 변조·결측·리그 분리·복귀 팀·첫 6회 경계를 합성 테스트했다.
독립 Decimal 계산으로 26,510개 원장 행과 집계 ROI를 대조하고 코드 해시도 확인했다.
ISO 주 단위 paired bootstrap은 seed=20261001, 5,000회다. 같은 주의 두 리그를
함께 재표집하며, 모든 과거 실험과 후보 선택을 포괄하는 다중검정 보정은 아니다.

따라서 초기화 방식은 **통계 예측을 위한 연구 후보**로 보존하되 운영 픽 교체는 보류한다.
추가 탐색에서는 단순 초기값 재튜닝보다 슈팅의 질 같은 새로운 사전정보가 시장 확률에
없는 설명력을 갖는지 확인할 필요가 있다. 이번 결과로 그 후속 가설의 성공까지 주장하지 않는다.
