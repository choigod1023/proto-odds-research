# 픽스터 수집 확대 — 구현과 실제 수집 검증

작성 기준: 2026-10-28 KST. 운영 추천은 픽스터 최다 득표 정책이지만, 본 수집 실험과 입력 비교는 **로컬 DB에서 실행**했다. 운영 배포나 수익성 개선 검증을 완료했다는 뜻이 아니다.

## 변경 이유와 범위

픽스터 수를 늘리는 것만으로 적중률·ROI 상승을 보장하지 않는다. 서로 다른 근거를 확보하고 동일 분석의 복제를 별도 표로 늘리지 않는 것이 목적이다. 출처·리그별 실제 적중률과 ROI는 경기 전 관측을 공식 결과·당시 배당에 연결한 뒤 평가해야 한다.

실제 HTTP로 확인한 픽천국 야구 목록은 오래된 글부터 2,858개 상세 링크를 나열했고, 앞에는 6월 글이 있었다. 기존 앞 12개 제한은 최근 글을 놓칠 수 있었다. URL의 날짜 힌트로 오래된 글을 제외하고 현재 대진과 사용자 선호 리그를 우선하도록 수정했다. 날짜 힌트는 요청 순서에만 쓰며 경기 전 증명으로 쓰지 않는다.

추가한 출처는 [Q-EDGE 스포츠 데이터랩](https://golfmasterj.tistory.com/)이다. 작성자 표기는 마스터제이이며 발행처/작성자 한 표로 센다. 단일 대진·리그·KST 일정과 최종 승패 방향을 모두 읽을 수 있는 글만 사용한다. 축구는 명시적 정규 90분 방향을 요구한다. 다경기 요약, 진출 예측, 서술상 우세, 복수 선택, 핸디/합계는 현재 어댑터에서 제외한다. 원문이 제시한 확률을 우리 모델의 확률로 사용하지 않는다.

기존 자료를 대조해 K리그·NPB·NBA의 누락된 정확한 팀명 별칭과 골리의 MLS·잉리그컵 리그명을 보완했다. 이름 유사도 매칭이나 리그를 넘나드는 추측 연결은 하지 않는다.

200자 이상 분석의 공백 정규화 해시가 정확히 같으면 작성자별 최초 투표를 고른 뒤 한 표로 합친다. 동일 내용인데 선택 방향이 서로 다르면 해당 복제 묶음을 제외한다. 비슷한 의견, 공통 정보, 같은 추천만으로 복제로 단정하지 않는다. 해시가 없는 과거 원문과 다른 작성자 사이의 독립성을 증명한 것은 아니다.

## 실제 실행 결과

로컬에서 2026-10-28 23:50 KST경 자동 수집 함수 `public_tipster_votes.collect`를 그대로 실행했다. 공개 API에서 가져온 98경기 identity만 로컬 SQLite에 넣었으며 운영 DB에는 쓰지 않았다.

- 목록 최대 6회 + 본문 최대 15회 = 기존 총 21요청 한도 유지. 실제 이번 실행은 본문 15개, 18.423초였다.
- 파싱 14건, 경기 전 조건을 통과해 저장한 표 **4건**, 고유 대진 **3경기**, 작성자/발행처 **2개**.
- 픽천국: 본문 12건 요청, 12건 파싱, 3표 연결. AC밀란 홈승, 파르마–우디네세 무승부, 인테르 원정승.
- Q-EDGE: 본문 3건 요청, 2건 파싱, 1표 연결. 베네치아–인테르 원정승. 최종 파서 수정 후에도 해당 원문을 다시 HTTP 수신해 연결을 확인했다.
- 제외: 일정/대진 불일치 또는 모호함 5건, 경기 전 허용 시점 밖 5건, 지원 구조의 홈/원정 표시 없음 1건.
- 골리 목록은 이번 로컬 접속에서 ConnectionError였다. 새 수집으로 세지 않았다. 배구 목록은 적용 가능한 링크가 없었다.
- `attv24.com`, `gaosportstv.com`, `quicksportstv.com`도 로컬 HTTP 접속 실패로 이번 운영 어댑터에 추가하지 않았다. [이방인의 스포츠 분석](https://sportsoutlander.com/)은 현재 글을 읽었지만 단순 우세 전망을 명시적 승패 픽으로 바꾸지 않았다. SportsDataLab은 확인 당시 최근 글이 10월 20일 경기여서 현재 경기 신규 표로 사용하지 않았다.

## 실제 추천 입력의 변화 — 수익률 검증 아님

운영에서 읽은 최근 공개 원문 관측 20건과 새 표 4건을 동일 시각·동일 공개 대진에 넣어 비교했다. TailSlips MLB 입력은 이 비교에 포함하지 않았다. 따라서 전체 운영 추천 수 비교가 아니다.

- 공개 원문만의 선택 가능 경기: 1경기 → 2경기.
- AC밀란–볼로냐: 표 없음 → AC밀란 1표, 홈 선택.
- 파르마–우디네세: 기존 골리 원정 1표 → 원정 1표·무승부 1표, 동률 보류.
- 베네치아–인테르: 표 없음 → 서로 다른 발행처의 인테르 2표, 원정 선택.

선택 가능 경기를 늘리는 동시에 기존 단독 의견을 보류하게 만들 수도 있음을 확인했다. 두 발행처라는 사실만으로 정보가 완전히 독립적이거나 더 정확하다고 주장하지 않는다. 해당 경기는 수집 시점에 경기 전이므로 **추가 표의 적중률·ROI·월 수익 안정성은 아직 미측정**이다. 과거 연구 수익률을 이번 확대의 성과로 재사용하지 않는다.

관측 요약·원문 URL·실제 수신 시각·해시·연결된 대진·로컬 입력 비교는 `evidence/2026-10-28-diverse-tipsters.json`에 보존했다. 원문 전체는 저장소에 재배포하지 않는다.

`python scripts/replay_diverse_tipster_audit.py`로 같은 시각·입력의 선택 변경을 네트워크 없이 재현할 수 있다. 전체 Python 1,585개·93 subtests 통과(5 skip), 웹 270개 테스트와 production build 통과. 새 adapter의 경기 연결·동결·오인식 제외·정확한 복제 제외·요청 수·기한과 별칭을 회귀 테스트했다.
