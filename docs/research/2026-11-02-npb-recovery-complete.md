# NPB 선발 누락 935경기 공식 아카이브 확장 결과

기존 256경기 표본에 이어 같은 격리 브랜치에서 남은 675경기(2023년 621, 2026년 54)를 확인했다. 원본 `data/raw/npb_starters.json` SHA256 `6f3c2cfabc21e8a30d6bd475d55e0c7d6091e813181bb8678aa89e3baadf2ed0`의 총 3,248행 중 양쪽 선발명 공란이 있는 935행을 분모로 사용했다. 원본은 수정하지 않았다.

- **확정 회고 연결 927/935**: 2023년 875경기, 2026년 52경기. 기존 256경기 모두 포함하며 추가 671경기다. 기존 양쪽 이름 2,313행과 합산하면 별도 코호트 3,240/3,248행이다.
- **시작 시각 차이로 보류 2/935**: 2023-07-13 한신–요코하마는 원본 18:00, 공식 실제 시작 18:39; 2023-08-11 라쿠텐–오릭스는 원본 19:00, 공식 실제 시작 19:46이다. 같은 날 유일한 양 팀 경기이고 공식 최종 점수도 원본과 각각 일치하나 기존의 30분 제한을 사후 완화하지 않는다. 공식 선발명·점수는 후보 필드에 보존하며 확정 927에 포함하지 않았다. 시각 차이의 원인은 확인하지 않았다.
- **우천 취소 2/935**: 2026-06-08 한신–라쿠텐, 2026-07-31 라쿠텐–소프트뱅크는 공식 문서에 우천 취소가 표시돼 실제 선발·결과를 연결하지 않는다.
- **올스타 제외 4/935**: 2023년 7월 19·20일, 2026년 7월 28·29일은 구단별 경기 매핑 밖이다. 적격 경기 중 미조회 0, 원문 HTTP 실패 0, 일별 목록 실제 미발견 0이다.

2026년 공식 박스스코어의 양 팀 투수표 첫 선발행에는 `/bis/players/<ID>.html` 공식 프로필 링크가 있다. 해당 경기의 날짜·일별 목록·양 팀 ID·선발행·선수명을 대조해 **양쪽 공식 선수 ID 52/927경기**를 연결했다. 두 우천 취소 경기에는 실제 선발행이 없다. 2023년 확인한 877경기(확정 875, 시각 보류 2)의 투수표 첫 행에는 공식 선수 프로필 링크가 없어 2023년 선수 ID는 0/877이다. 이름만으로 ID를 추정하지 않았다. 선발명은 해당 결과 원문에서의 실제 출전 표기다.

확정 927경기 중 공식 최종 점수는 기존 저장 점수와 873경기에서 일치하고 54경기에서 다르다. 차이 54건은 2023년 2건(6월 5일, 7월 5일)과 2026년 52건이다. 원본의 점수와 공식 최종 점수를 각기 보존했고 기존 점수를 변경하지 않았다. 이 차이와 우천 취소는 과거 예측을 새로 정산해도 된다는 뜻이 아니다.

2023년 일별 목록·경기 페이지와 2026년 공식 박스스코어를 순차 수집했다. 이번 추가 요청 **821회 모두 HTTP 200**, 최초 추가 요청부터 마지막 요청까지 578.76초였고, 허용 상한 추가 1,000회·15분 이내다. 이전 확장 300회와 합친 로그상 요청은 1,121회다. 별도로 앞선 최초 보관 원문 5건을 재사용해 보관 원문은 총 1,126건이다. 최초 탐색 중 보관하지 않은 중복 요청은 이 로그 합계에 포함하지 않는다. 403·429·연속 실패는 없었다. 2026년 일별 목록은 2023년과 구조가 달라 처음 형식 미인식으로 기록된 행을 재처리했으며 미발견으로 세지 않았다.

`raw/`, `expanded_raw/`, `continuation_raw/`, `continuation_raw2/`는 각 원문의 압축 해제 바이트 또는 원본 바이트와 URL·실제 수신 시각·SHA256을 보존한다. 기존 원문과 메타데이터는 덮지 않았다. `manifest-continuation.json`은 1,126개 원문별 URL·SHA256·경로를 포함하고, `cohort-continuation.jsonl`은 935행의 상태·근거·원래/공식 점수를 담는다. `collection-log-continuation.json`과 `collection-log-2026.json`은 추가 요청을 기록한다. 해시는 바이트 무결성만 검증하며 과거 수신을 독립적으로 인증하지 않는다.

원문은 2026-11-02에 실제 수신한 사후 자료다. 경기 전 실제 수신 증거는 0/927이고, 같은 상품·시점의 가격 및 정산과 실제 운영 동결픽의 교집합은 미측정이다. 공식 최종 타순이나 회고 선발을 과거 경기 전 확정 정보로 승격하지 않는다. 이 작업은 모델 학습이나 적중률 검증이 아니다. 미조회 경기 없이 원문 조회를 마쳤지만 위 보류·취소·올스타와 선수 ID 미확보는 남는다.

재현: `python experiments/npb-recovery-20261102/continuation_recover.py`; 테스트: `python -m pytest tests/test_npb_recovery_20261102.py tests/test_npb_recovery_expanded_20261102.py tests/test_npb_recovery_continuation_20261102.py -q`. 현재 모델·운영 DB·원장·스케줄 및 원본 데이터는 변경하지 않았다.
