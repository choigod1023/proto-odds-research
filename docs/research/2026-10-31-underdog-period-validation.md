# 득점 모델의 역배 포함 효과: 기간·리그별 추가 검증

역배를 포함하는 것이 가장 좋은 수익률을 만든다는 결론은 나오지 않았다. 기존 score-static 모델은 실제 저장 quote 2026년 445건에서 시장 방향보다 손실을 줄였지만, 모델이 선택한 역배 111건 자체는 −0.08단위였다. 시기와 리그에 따라 부호가 바뀌었고 순차 갱신에서는 성과가 더 나빠졌다. 운영 전환 근거로 삼지 않는다.

## 고정한 질문과 실제 실행

앞서 본 7월 이후 122건에서 발견한 score-static의 역배 선택을 바꾸지 않고, 앞선 323건과 별도 가격 proxy 자료에서 비교했다. 모델·가중치·배당 문턱을 다시 탐색하지 않았다. 구현 전에 `protocol.json`을 커밋 `02e08282`로 고정했다.

- 원본: [PR #433](https://github.com/choigod1023/proto-odds-research/pull/433)의 `experiments/dynamic-score-state-model-20261030/`. 원본 SHA256은 `audit.json`에 남겼다.
- 발견 구간: [PR #470](https://github.com/choigod1023/proto-odds-research/pull/470)에서 재사용한 2026년 7월 이후 122건. 이번 검증의 독립 표본이 아니다.
- 모델: 과거 득점으로 공격·수비 잠재 전력과 불확실성을 추정한 기존 score-static/q=0. 전체 경기 승무패 확률의 argmax를 선택한다. **이 모델에 픽스터 투표·선발·라인업을 추가한 실험은 아니다.** 실제 픽스터 자료와 연결된 코호트에서 평가하되, 픽스터 자체를 새 모델 입력으로 쓰지 않았다.
- 시장 대조군: 같은 경기의 저장 `market_p`에서 확률이 가장 높은 방향. 실제 운용 모델이나 현재 웹 추천을 재생했다는 뜻이 아니다.
- 역배: 모델이 선택한 방향의 저장 시장확률이 시장 최고확률보다 낮은 경우. 2.20 같은 배당 상한·하한, 임의 보너스, 수익 문턱은 없다. 시장 최고확률 동률은 별도 그룹으로 둔다.
- 주 분석: 2026년 시작 시점에 동결한 frozen. prequential은 과거 결과를 +4일 뒤 사용한 별도 민감도 분석이며 결과를 보고 주 모델과 교체하지 않는다.
- 정산: 매 선택에 같은 1단위 단폴. 적중 시 `배당−1`, 실패 시 `−1`, 취소 시 0. 월 손실 제한·사용자 지갑을 변경하거나 실제 베팅을 실행하지 않았다. 모두 제한 없는 단위 정산이다.

17,337건은 학습용 과거 점수 이력이다. 배당까지 연결된 평가 경기 수가 17,337건이라는 뜻이 아니다. 이번에는 보존된 평가 quote 710건을 사용했다. 그중 2026년 693건은 frozen/prequential 두 모드로 각각 정산하여 원장 행은 1,403개다. 두 모드를 독립 경기처럼 합산하지 않는다.

## 주 분석: 실제 저장 quote, 2026년

기간은 UTC 의사결정 시각을 기준으로 나눴다. 앞선 323건도 과거 연구에서 열람한 자료이므로 새 맹검 검증이라고 부르지 않는다. 아래 `전체`는 위 두 기간의 합계로 별도 표본이 아니다.

| 기간 | 시장 전 경기 ROI / 손익 | 득점 모델 전 경기 ROI / 손익 | 모델 정배만 ROI / 손익 | 모델 역배만 ROI / 손익 |
|---|---:|---:|---:|---:|
| 7월 이전 323건 | −8.65% / −27.94 | −2.36% / −7.63 | 245건, −3.39% / −8.31 | 78건, +0.87% / +0.68 |
| 7월 이후 122건 | −13.07% / −15.94 | −6.92% / −8.44 | 89건, −8.63% / −7.68 | 33건, −2.30% / −0.76 |
| 전체 445건 | −9.86% / −43.88 | −3.61% / −16.07 | 334건, −4.79% / −15.99 | 111건, −0.07% / −0.08 |

손익은 단위다. 전 경기 모델의 적중률은 앞선 구간 195/323=60.37%, 뒤 구간 67/122=54.92%, 전체 262/445=58.88%다. 시장은 각각 58.82%, 54.92%, 57.75%다. 역배만의 적중률은 전체 56/111=50.45%다.

**ROI 비율 개선과 총손실 감소는 다르다.** 뒤 122건에서 역배를 더하면 정배만의 −7.68단위가 −8.44단위로 나빠진다. 베팅 건수가 늘어 ROI 비율은 −8.63%에서 −6.92%로 좋아 보인다. 전체에서도 정배만 −15.99보다 포함 −16.07이 0.08단위 더 손해다. 반대로 앞선 구간에서는 역배 순익 +0.68만큼 실제 손실도 줄었다.

모델이 역배를 고른 **동일 경기**에서 시장 방향과 비교하면:

| 기간 | 모델 역배 | 동일 경기 시장 방향 | 차이 |
|---|---:|---:|---:|
| 앞선 78건 | +0.68 / +0.87% | −19.63 / −25.17% | +20.31단위 |
| 뒤 33건 | −0.76 / −2.30% | −8.26 / −25.03% | +7.50단위 |
| 전체 111건 | −0.08 / −0.07% | −27.89 / −25.13% | +27.81단위 |

이는 이 표본에서 시장 방향을 바꾼 효과이며, 역배를 추가로 사는 것이 건너뛰기보다 수익성이 좋다는 뜻은 아니다. 선택된 부분집합 비교이고 무작위 실험도 아니다.

## 리그별: 효과가 일정하지 않았다

아래는 frozen 모델이 고른 역배의 ROI다. 기간마다 역배를 선택한 경기 구성이 다르며 작은 표본을 최적 리그 선정에 쓰지 않는다.

| 리그 | 7월 이전 역배 | 7월 이후 역배 | 전체 역배 | 전체 역배 손익 |
|---|---:|---:|---:|---:|
| K리그1 | 1건, −100.00% | 4건, +2.50% | 5건, −18.00% | −0.90 |
| K리그2 | 1건, −100.00% | 1건, −100.00% | 2건, −100.00% | −2.00 |
| KBO | 37건, +12.08% | 12건, −44.75% | 49건, −1.84% | −0.90 |
| NPB | 8건, −3.13% | 7건, +12.86% | 15건, +4.33% | +0.65 |

KBO는 앞 구간의 이점이 뒤집혔다. MLB의 뒤 구간 +51.22%는 9건 중 7건 적중에 의존한다. 이 9건을 보고 앞으로 MLB만 채택하면 사후 선택이 된다. NPB·축구도 역배 표본이 충분하지 않다. KBL/NBA/배구는 이번 원본 평가 코호트에 없으므로 검증했다고 말할 수 없다.

## 수익 안정성과 별도 자료

- 전체 frozen 모델의 일별 마감 최대 낙폭은 시장 57.53단위, 모델 전 경기 29.18단위, 모델 정배만 28.57단위, 모델 역배만 8.48단위다. 역배만은 투입 건수가 적어 직접 같은 위험으로 해석하면 안 된다. 이 값은 UTC 의사결정 날짜에 손익을 귀속한 값으로, 실제 정산 시각·미정산 노출을 반영한 지갑 낙폭은 아니다.
- 역배만의 8개월 손익은 3월 −0.18, 4월 −3.88, 5월 +2.96, 6월 +1.78, 7월 −5.03, 8월 +1.41, 9월 +2.96, 10월 −0.10단위다. 수익 월 4개·손실 월 4개다. 한 달씩 빼면 합계가 −3.04부터 +4.95단위로 바뀐다.
- 주 대비인 앞선 323건의 모델−시장 ROI 차이는 +6.29%p지만, 주 단위 재표집 2,000회 기술적 95% 구간은 **−3.86~+16.21%p**다. 앞선 역배 78건의 동일 경기 차이는 +26.04%p, 구간 **−15.03~+63.81%p**다. 두 구간 모두 0을 포함한다. 반복 탐색에 대한 보정이나 새 독립 검증을 대신하지 않는다.
- 별도 **가격 proxy 2026년 248건**: 시장 −11.40%, 모델 전체 −4.31%, 모델 역배 47건 +7.28%(+3.42단위). KBO 역배 37건 +11.65%, NPB 역배 10건 −8.90%로 실제 저장 quote 코호트와 리그별 방향도 다르다. 이 코호트는 실제 구매 가능 가격이 검증되지 않았다. 실제 quote와 정확한 경기 서명 기준 **133건이 겹치므로** 독립 표본으로 더하지 않는다. 5월을 빼면 proxy 역배 손익도 −0.71단위다.
- **2024년 가격 proxy MLB 9건**: 시장·모델 모두 +3.00%, 역배 선택 0건. 역배 검증 근거가 아니다.
- **2025년 가격 proxy MLB 7건**: 시장 −7.14%, 모델 −29.71%, 역배 2건 모두 실패(−100%). 시장 최고확률 동률 1건은 정배·역배 어디에도 넣지 않았다. 실제 저장 quote 2025년 1건은 별도로 두었으며 시장·모델 모두 +50%, 역배 0건이다. 17건을 여러 시즌의 충분한 검증이라고 부를 수 없다.
- **순차 갱신 보조 분석**: 실제 quote 2026년 445건의 모델 ROI는 −12.63%, 역배 133건은 −17.95%(−23.88단위). 같은 경기 시장보다도 전체적으로 나빴다. 따라서 결과를 자주 갱신하거나 역배를 포함하면 자동 개선된다는 근거는 없다.

## 시간 누출·정산 검증

2024·2025년 재생에는 해당 연도 이전 결과만 넣고 각 연도 1월 5일까지의 원래 +4일 가용성 규칙으로 상태를 동결했다. 2026년 상태를 과거로 가져가지 않았다. 날짜 전용 이력만 허용하고 quote는 시간대를 확인해 UTC로 변환했다. q=0이어도 예측 때 평균 회귀는 적용되므로 원본 Engine의 복제 예측을 그대로 사용했다.

원본 상태를 예측 호출로 바꾸지 않는지 확인했고, 해당 연도와 미래 결과를 뒤집어도 예측·상태 지문이 그대로인지 회귀 테스트했다. 반대로 포함된 이전 연도 결과를 바꾸면 예측이 달라지는지도 검사했다. 날짜+4일은 **실제 당시 수신 시각의 증명은 아니다.** 학습 이력의 점수·팀 연결 품질은 원본 연구의 한계를 그대로 가진다.

독립 `verify.py`는 runner를 import하지 않고 원본 배당·결과와 예측을 대조한다. 원장 1,403행의 모델·시장 **2,806개 정산**, 기간·리그·정책 집계, 분모·월 손익·일별 낙폭을 다시 계산한다. 빈 표본, 취소 환급, 시장 동률, 무베팅 분모, ROI는 개선되지만 손실이 커지는 예제도 테스트한다. 실행 결과는 `verification.json`에 저장한다.

실행 결과는 정산 2,806개·정책 집계 450개 불일치 0건이다. 관련 테스트 37개를 통과했고 전체 `pytest`는 **2,161 passed, 6 skipped, 93 subtests passed**였다. 테스트 후 재실행한 원장·전체 집계 해시도 동일했다. 표의 백분율은 표시용 반올림이며 계산·정산에는 원래 배당과 Decimal 손익을 사용했다.

## 판단과 남은 검증

기존 시장 방향보다 손실이 작았다는 관측은 보존할 만하다. 다만 역배 포함 자체의 안정적 수익성이나 모든 리그의 우월성은 확인하지 못했다. 역배를 무조건 배제할 근거도, 전면 채택할 근거도 이 결과만으로는 부족하다. 규칙을 고정한 비교 후보로 유지하고, 이후 경기의 사전 예측·게시/수집 시각·실제 접근 가능한 배당·결과를 연결한 별도 기간에서 확인해야 한다. 이번 계산에서 새로 독립 인증된 경기 수는 0이다.

운영 모델·추천 조건·지갑 한도·서버에는 변경이 없다. 연구 PR의 저장/병합과 운영 채택·배포는 별개다.

## 재현

```powershell
python -X utf8 experiments/underdog-period-validation-20261031/runner.py
python -X utf8 experiments/underdog-period-validation-20261031/verify.py
python -m pytest -q tests/test_underdog_period_validation.py tests/test_dynamic_score_state_model.py
```

규칙 `protocol.json`, 실행 `runner.py`, 분리 원장 `ledger.jsonl.gz`, 전체 집계 `results.json`, 출처·상태 `audit.json`, 독립 검사 `verification.json`은 모두 `experiments/underdog-period-validation-20261031/`에 있다. 입력 전체를 다시 복제하지 않고 해시로 연결했다.
