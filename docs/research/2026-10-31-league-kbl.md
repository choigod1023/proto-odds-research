# KBL 자료 감사와 선수 결장 가설 — 2026-10-31

상태: **blocked_data**. 신규 선수 입력의 효과·ROI는 계산하지 않았으며, 재열람 자료를 새로운 블라인드 검증으로 취급하지 않는다. 조사 범위는 저장소의 `operating-ledger-comparison-20261029/comparison.json` 1개와 기존 농구 토너먼트 보고, 별도 참조한 정보 연구 및 PR #451·#453·#454·#455다. 전체 운영 DB, 전체 일정이나 모든 시장을 조사한 수치가 아니다.

## 자료 감사

비교 파일의 KBL 전체 경기 승패 기회는 서로 다른 event_id **4건**이다. 저장된 as_of와 captured_at이 모두 T-30 이전인 건 4, 저장된 시장 선택과 해당 배당 4, proto 결과 연결 4다. 이들은 원장 값의 시점과 정산 연결에 대한 저장 산출물 검사이며 원장 원문, 전 배당 벡터, 실행 가능 가격을 독립적으로 인증한 수치는 아니다. 선수별 공식 결장 문서·실제 수신·선수 ID가 연결된 건 이 파일에서 **0/4**다. 경기 전 투표 비교 입력은 2건이며 선수 사실의 확인이 아니다. 현행 `tipster-vote-v1` 운영 선택은 1건, 과거 정책 3건이다. 전체 4건이 현행 운영 정책인 것은 아니다. 핸디캡·합계는 이 비교 파일에서 조사한 평가 기회가 0건이며, 전체 서비스 기회가 없었다는 뜻이 아니다. 모든 선수 사실 결합 표본은 0건이므로 사전 수신·가격·결과를 모두 갖춘 결장 후보 평가도 0건이다. 평가 커버리지·적중률·ROI·logloss·Brier·낙폭은 미산출이다.

기존 농구 토너먼트의 2025 테스트 KBL 309건은 경기 전 실제 수신이나 구매 가능 배당이 확인되지 않은 반복 열람 데이터이며 선수 결장 모델의 표본이 아니다. #453의 122경기는 KBO·NPB·MLB·K리그로 KBL이 없고, 시장 54.92%/ROI -13.07%, 새 고정 51.64%/-18.47%, 순차 53.28%/-15.70%였다. 같은 표본의 시장 오프셋 픽스터 선택 연구로 신규 KBL 실증이 아니며 채택하지 않았다. 9:1 재계산도 현행 동결 운영픽 재생이 아니다.

## 공식 규칙

[KBL 2024-25 규칙서](https://kbl.or.kr/upfiles/ebook/2025_rules.pdf) 제8조는 10분 4쿼터, 동점이면 승패가 날 때까지 5분 연장이다. 해당 연도 자료이므로 평가 대상 시즌 개정 여부를 다시 확인해야 한다. [프로토 승부식 공식 안내](https://www.sportstoto.co.kr/proto_intro)는 농구 결과에 연장을 포함하고 핸디캡·언더오버는 구매 시점 기준값을 사용한다고 설명한다. 일반 농구 승패의 무승부에는 1.0배를 적용하며 취소·무효에도 별도 규칙이 있다. 핸디캡은 기준 반영 후 승무패, 언더오버는 양팀 합계와 기준을 비교한다. 기준 일치·예외 등 해당 회차의 세부 정산은 원문과 함께 확인 전까지 별도 보류한다. 경기 규칙이 상품별 정산을 증명하지 않는다.

## 사전 등록 가설

`protocol.json`은 결과 평가 전 커밋 `f4120966cd4584c6fb7f9bd9b34382b481869923`에 고정했다. 선수 효과를 지금 학습하지 않는다. 후보 하나는 시장 확률을 오프셋으로, 공식 확인된 결장 선수의 직전 적격 10경기 평균 출전시간을 양 팀 차로 만든 L2 로지스틱 모델이다. 외국인 여부, 출전 가능성, 로테이션, 페이스, 휴식과 이동도 수집 대상이지만 검증된 계수 없이 임의 보너스로 넣지 않는다. 결장·직전 기록 모두 실제 판정 이전에 수신해야 하고 예상 출전과 확정을 구분한다. 결장 없음 역시 공식 근거가 필요하며 미확인은 0이 아니다. 결장 없는 기준은 동일한 시장 확률이다.

커밋 이후 새 event_id만 순서대로 60/20/20 분할하며 같은 날은 한 구간에 둔다. 최소 학습 200, 검증 60, 평가 100 및 각 구간 결장 신호 30건과 양쪽 결과 조건이 안 되면 학습 없이 중단한다. 검증에서 후보 logloss가 시장보다 낮을 때만 단 한 번 평가하고 그렇지 않으면 중단한다. 표본 기준은 검증 가능성을 위한 사전 조건이지 통계적 검정력이나 수익을 보장하지 않는다. 시장·결장 후보는 동일 경기·상품·기준점·시각·가격·결과·정산으로 비교하고 동결 운영 선택은 실제 확보된 공통 부분집합에서만 따로 비교한다. 보류·취소·미정산과 결측 이유를 보존한다. 자동 승격은 없다.

필요한 새 자료: 경기/팀/선수 공식 ID와 경기 시작, 판정·실제 수신 시각, 선수 상태의 공식 원문 바이트와 버전, 과거 공식 박스스코어와 수신 시각, 휴식·이동과 페이스의 근거, 전체 배당 및 기준점·수신, 해당 상품 약관, 동결 운영 revision, 수정 이력 포함 공식 결과와 수신 시각. 게시 주장 시각과 실제 수신은 다르고, 내부 해시만으로 독립 인증되지 않는다.

## 검증 한계

`audit.py`는 저장된 4건의 시각·선택 가격·결과 연결과 ID를 확인하고, 합성 예제로 늦은 수신·원문 바이트 해시 비교·미래 결과 변경의 학습 전 필터 불변을 검사한다. 실제 원문 중복 여부, 선수 입력 시점 누출, 전체 시장 벡터, 모델 적합 또는 미래 결과 오염에 대한 실데이터 검사는 자료가 없어 수행하지 않았다. 합성 검사는 데이터 구조 점검이지 적중률 개선의 증거가 아니다.
